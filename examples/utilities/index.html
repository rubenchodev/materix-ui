Utilities

Mobile-first mtx-* classes for display, flex, alignment, gap, spacing, sizing, text, color, position, borders and elevation, to build layouts without custom CSS.

Basic usage

Combine mtx-* classes in the HTML. They all use !important to win over component styles, and the breakpoint ones use min-width.

Breakpoints

xs (no infix) 0px · sm 600px · md 900px · lg 1200px · xl 1536px. The infix goes before the value: mtx-d-md-none, mtx-p-lg-4. Resize the window: only one box is visible in each range.

Spacing

mtx-{m,mt,mb,ms,me,mx,my,p,pt,pb,ps,pe,px,py}-{n}. s/e are logical (line start/end, RTL-aware). All margins (m, mt, mb, ms, me, mx, my) and p, px, py have responsive variants (mtx-ms-md-2, mtx-mt-lg-0…). Auto margins, also responsive: mtx-{m,ms,me,mx,mt,mb}-auto and mtx-ms-{bp}-auto. The aliases mtx-ml-*, mtx-mr-*, mtx-pl-*, mtx-pr-* (0–4) are kept.

Color

mtx-color-* for text and mtx-bg-* for backgrounds. mtx-bg-primary and mtx-bg-secondary also set the contrast color. All values come from the tokens: they change with the theme.

text-primary text-secondary text-disabled primary secondary success error warning info
bg-paper bg-default bg-primary bg-secondary bg-action-hover bg-action-selected

Accessibility

mtx-visually-hidden hides content visually but keeps the text for screen readers; mtx-visually-hidden-focusable shows it when it receives focus; mtx-skip-link is the “skip to content” link, fixed at the top left and visible only on focus (press Tab after this section's button to see it).

Position, overflow and layers

mtx-position-*, mtx-sticky-top / mtx-sticky-{bp}-top (sits below the App Bar using --mtx-app-bar-height), mtx-top-0, mtx-inset-0, mtx-z-{0,1,2,3,app-bar,drawer,modal}, mtx-overflow-{hidden,auto,visible}, mtx-overflow-x-auto and mtx-overflow-y-auto. For anchors: mtx-scroll-smooth (on <html>, disabled by prefers-reduced-motion) and mtx-scroll-mt-app-bar (the target lands below the App Bar; with a fixed/sticky App Bar, <html> already gets an automatic scroll-padding-top).

Miscellaneous

mtx-stretched-link makes the whole ancestor with position: relative clickable; plus mtx-pointer-events-none, mtx-user-select-none, mtx-cursor-pointer and mtx-object-cover.

The whole card is clickable thanks to mtx-stretched-link, without nesting interactive elements.

Controls above the stretched link

Bootstrap pattern: the link's ::after has z-index: 1; controls that must keep working get mtx-stretched-link-above (or mtx-position-relative mtx-z-2). The action list uses mtx-list-unstyled (no bullets, padding or margin) with role="list".
