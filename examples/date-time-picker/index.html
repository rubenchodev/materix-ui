Basic usage

An <input> with data-mtx="date-picker", "time-picker" or "datetime-picker". It becomes a TextField with a mask and an icon, and opens the picker on click. Typing directly is also supported.

Keyboard and accessibility

WAI-ARIA Date Picker Dialog pattern: the end icon is a button with aria-haspopup="dialog" and aria-expanded; the picker is a role="dialog" named "Choose date" and the calendar a role="grid" with roving tabindex. Focus the calendar button with Tab and press Enter, or type in the field and press Alt+↓: focus moves to the selected day (or today).

Limits, initial value and format

data-min/data-max disable days outside the interval (they accept today); value or data-value set the initial value and data-format changes the format and the mask.

Language and texts

data-locale sets a field's language and accepts regions (es-MX uses the es texts); without it, the lang of the nearest ancestor or of <html> is used (this page is en). Months and days come from the i18n dictionary, or from Intl if the language is not registered, and the default format follows the locale order (en: MM/DD/YYYY; es: DD/MM/YYYY) unless data-format is set. data-today-text, data-cancel-text and data-ok-text replace the button texts.

Programmatic usage

The buttons call the instance's real API; the console shows the mtx:date-time-picker:open, :close and :change events (a single emission per selection; mtx:open, mtx:close and mtx:change are still emitted as deprecated aliases).

Date and time
Range 

      
const picker = Materix.getInstance(document.getElementById('picker-api'));
button.addEventListener('click', (e) => { e.stopPropagation(); picker.open(); });
picker.setDateTime('2026-12-25 20:00');
picker.getDate('YYYY-MM-DD');   // "2026-12-25"
picker.input.addEventListener('mtx:date-time-picker:change', (e) => console.log(e.detail.value, e.detail.iso));
