Fab

Floating action button for a screen's primary action: circular (56/48/40px) or extended with text (48px).

Basic usage Variants Sizes With icons Colors States Position Grid layout Programmatic usage Manual BEM usage

Basic usage

An empty <button> with data-icon generates a circular FAB; add data-label and it becomes extended. The circular FAB needs an aria-label because it only shows an icon.

<button data-mtx="fab" data-icon="add" aria-label="Create"></button>
<button data-mtx="fab" data-icon="navigation" data-label="Navigate"></button>

Variants

The circular FAB is the standard shape. The extended one adds a text label to make the action more explicit; enable it with data-label, or with data-variant="extended" if you write the content yourself.

Sizes

With data-size: large 56px (default), medium 48px and small 40px. The extended FAB is 48px by default, 40px in medium and 34px in small. Each row aligns it with controls of the same height.

Large · 56px (default) — next to a medium TextField (56px)
Medium · 48px — next to a large Button, a large IconButton and an extended FAB
Small · 40px and medium extended (40px) — next to a small TextField and a medium Button
Small extended · 34px

With icons

Combine data-icon and data-label depending on what you need to communicate. The generated icon is always decorative (aria-hidden="true").

Colors

Primary is the default. data-color accepts any palette color plus default, a neutral surface with a border for screens where the primary color is already very present.

States

Hover to see the elevation rise, press to see the ripple and use Tab to see the focus ring. With disabled it loses its elevation and color.

Enabled · hover, focus and press
Disabled · disabled

Position

mtx-fab--fixed-br and mtx-fab--fixed-bl pin the FAB 24px from the bottom-right or bottom-left corner of the window. mtx-fab--absolute-center centers it over the top edge of its positioned container, as in a bottom bar.

absolute-center over a bottom bar

Screen content. The FAB stays centered and sits on top of the bar.

<!-- Fixed to the bottom-right corner of the window -->
<button data-mtx="fab" data-icon="add" class="mtx-fab--fixed-br" aria-label="Create"></button>

Grid layout

Inside a grid the FAB keeps its size; use it as the primary action of each card or column.

Programmatic usage

The size and color properties are read-write: assigning them swaps the modifier classes. It also has disable() and enable(). Fab emits no events of its own: listen to the native click.

Manual BEM usage

      
The full structure writes the base class, the modifiers and the content (icon and label) by hand. The instance binds to it without duplicating anything.

      

        
        
        
      

      
<button class="mtx-fab mtx-fab--extended" data-mtx="fab" type="button">
  <span class="material-icons" aria-hidden="true">add</span>
  <span>New ticket</span>
</button>
