List

Continuous vertical list of text, icons or avatars, with static or interactive items, subheaders, density and selection.

Basic usage

A <ul data-mtx="list"> with data-mtx="list-item" rows. data-icon adds the icon and data-secondary the secondary text.

  • Inbox
  • Drafts
  • Sent
<ul data-mtx="list" aria-label="Mail">
  <li data-mtx="list-item" data-icon="inbox" data-secondary="3 new messages">Inbox</li>
  <li data-mtx="list-item" data-icon="send">Sent</li>
</ul>

Row content

Text only, with an icon, with an avatar and with primary and secondary text. An avatar is set with data-avatar="url" or by writing the data-mtx="avatar" inside the row: the component wraps it in mtx-list-item-avatar (56px, like ListItemAvatar). data-align-start aligns the avatar with the first line of long texts.

Interactive rows

list-item-button on a <button> adds hover, focus, ripple and selection: clicking a row selects it and unselects the previous one. With data-selectable="false" the rows only run their action.

Selectable
No selection (data-selectable="false")

States

Hover to see the hover state and use Tab for focus. data-disabled disables the row (disabled attribute on buttons, aria-disabled on links).

  • Disabled link
  • Disabled static row

Subheaders

list-subheader (with the mtx-list-subheader class) titles groups. data-inset aligns the title with the text; data-sticky pins it while the list scrolls.

Nested

A list with data-nested inside an item indents its rows by 48px. Here the page adds the expand/collapse behavior: the parent row toggles hidden and aria-expanded.

Secondary actions

Wrap the action in mtx-list-item-secondary-action (ListItemSecondaryAction): it is aligned to the end, accepts several actions of any width, and a trailing IconButton snaps to the edge (edge="end"). With the simplified syntax, data-icon and data-secondary build the text without touching the action. For a clickable row with a separate action, use an <li data-mtx="list-item" data-disable-padding> with the list-item-button and the action as siblings.

  • Annual report.pdf
  • Budget.xlsx
  • MacBook Pro 
<li data-mtx="list-item" data-icon="description" data-secondary="2.4 MB">
  Annual report.pdf
  <span class="mtx-list-item-secondary-action">
    <button data-mtx="icon-button" data-icon="delete" aria-label="Delete Annual report.pdf"></button>
  </span>
</li>

Use cases

Side navigation with links: the selected row gets aria-current="page" (on a <button>, aria-current="true"; aria-selected only with role="option" or role="tab"). Links are not underlined and inherit the list's color.

Programmatic usage

Click a row to see the real mtx:list:select event (with detail.item). The buttons use the ListItemButton API: selected, disable() and enable() on the “Calendar” row.
