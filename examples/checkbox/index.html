Checkbox

A box for selecting one or more options from a list or confirming a condition; supports an indeterminate state.

Basic usage

Write just the <input type="checkbox"> with data-mtx="checkbox" and data-label. The library wraps it in a <label class="mtx-checkbox">, draws the box and the label, and keeps name, value, checked and every other native attribute.

<input type="checkbox" data-mtx="checkbox" data-label="Remember me" checked />

Sizes

Two sizes, as in MUI: medium (18px box, default) and small (16px and body2 text) with data-size="small", for tables and dense forms.

With and without label

Without data-label only the box is drawn; in that case add aria-label (or aria-labelledby) so the control has an accessible name, as in table rows.

Colors

Primary is the default. Use data-color on the input (or the mtx-checkbox--{color} class, which is moved to the generated wrapper).

States

Hover to see the border change color, press to see the ripple, and use Tab and Space to focus and check. The native input does not support readonly: to lock a checkbox use disabled.

Error and helper text

Helper and error (FormHelperText)

data-helper-text wraps the checkbox in .mtx-form-control and adds a .mtx-form-helper-text below it, linked with aria-describedby (outside the <label>, so it does not mix with the name). An empty data-error turns on the error state and keeps the helper; with text, the message replaces it. In both cases the input gets aria-invalid="true" and the box border turns red.

Indeterminate

The indeterminate state shows that only some child options are checked. Declare it with data-indeterminate or the indeterminate property; the library keeps aria-checked="mixed" in sync. Check or uncheck the options to see it in action.

Grouping

Group related checkboxes in a <fieldset> with a <legend>: screen readers announce the legend when entering the group. Use the same name to submit them together in a form.

Programmatic usage

Materix.getInstance(input) returns the instance (it also works with the generated <label>). Changes made from code do not fire events; user changes emit the input's native change, logged below.

Manual BEM usage

      
The full structure declares the wrapping <label> with data-mtx, the input, the visual box and the label. The library reuses the existing nodes without duplicating them.

      

        
        
      

      
<label class="mtx-checkbox" data-mtx="checkbox">
  <input type="checkbox" checked />
  <span class="mtx-checkbox__box"></span>
  <span class="mtx-checkbox__label">Checked</span>
</label>
