Tooltip

Short informative label shown on hover, keyboard focus or long press. Add data-mtx-tooltip to any element: no initialization required.

Basic usage

Add data-mtx-tooltip="Text" to any element: nothing needs to be initialized (global delegation, also for content added later). Hover or use Tab; Escape hides it.

Link with tooltip 
<button data-mtx="icon-button" data-icon="delete" data-mtx-tooltip="Delete"></button>
<button class="mtx-button mtx-button--contained" data-mtx="button" data-mtx-tooltip="Saved to your account">Save</button>

Placement

data-tooltip-placement accepts 12 positions (top|bottom|left|right with -start|-end). Defaults to bottom. If it doesn't fit, it flips to the opposite side and shifts to stay on screen.

Bottom
Left and right 
<button class="mtx-button mtx-button--outlined" data-mtx="button"
        data-mtx-tooltip="top-start" data-tooltip-placement="top-start">top-start</button>

Arrow

data-tooltip-arrow adds an arrow that points at the center of the trigger, even when the tooltip shifts to fit.

<button data-mtx="icon-button" data-icon="add" data-mtx-tooltip="Add" data-tooltip-arrow></button>

With and without icons

It works on text buttons, buttons with a start or end icon and, above all, on icon-only buttons, where it also provides the accessible name.

Start / end icon

States

Disabled elements don't receive pointer or focus events: wrap them with data-mtx="tooltip" (a <span> with data-title) to keep explaining why they are unavailable, as MUI recommends.

<span data-mtx="tooltip" data-title="Fill in the required fields to continue">
  <button class="mtx-button mtx-button--contained" data-mtx="button" disabled>Continue</button>
</span>

Delays

By default it appears after 100 ms (as in MUI) and disappears on leave. data-tooltip-enter-delay and data-tooltip-leave-delay change both timings. After one closes, the next one appears with no delay for 800 ms, ideal for toolbars.

<button … data-mtx-tooltip="Appears after 500 ms" data-tooltip-enter-delay="500">…</button>

Follow cursor

data-tooltip-follow-cursor anchors the tooltip to the pointer while it moves over the trigger.

Move the cursor around this area.

<div data-mtx-tooltip="I follow the cursor" data-tooltip-follow-cursor>…</div>

Long text

The maximum width is 300 px (--mtx-tooltip-max-width) and the text wraps onto several lines.

Accessibility

If the trigger has no accessible name (an icon-only button without aria-label), the text is applied as aria-label. If it already has one, the tooltip describes it with aria-describedby while visible. It is hoverable (you can move the cursor over it) and is dismissed with Escape. On touch screens it appears with a long press (700 ms) and hides 1.5 s after release.

No name → aria-label
With name → aria-describedby
aria-label="Print invoice"

Programmatic usage

Materix.tooltip.show(el) / hide(el) control any trigger; Materix.tooltip.get(el) returns the instance with open(), close() and setTitle(). Events mtx:tooltip:open and mtx:tooltip:close.

Advanced usage

      
data-mtx="tooltip" creates a registered instance (Materix.getInstance) on a container; it reads data-title and the unprefixed options (data-placement, data-arrow, data-enter-delay, data-leave-delay, data-follow-cursor). The generated surface is .mtx-tooltip with role="tooltip".

      

        
          
        
      

      
<span data-mtx="tooltip" data-title="Export to CSV" data-placement="right" data-arrow>
  <button class="mtx-button mtx-button--outlined" data-mtx="button" data-start-icon="download">Export</button>
</span>

<!-- Generated surface (portaled to body) -->
<div class="mtx-tooltip mtx-tooltip--open mtx-tooltip--arrow" role="tooltip" id="mtx-tooltip-1" data-side="right">
  <span class="mtx-tooltip__label">Export to CSV</span>
  <span class="mtx-tooltip__arrow" aria-hidden="true"></span>
</div>
