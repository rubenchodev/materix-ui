Popover

Floating Paper with arbitrary content anchored to a trigger. Closes on click away or Escape and returns focus to the trigger.

Basic usage

An element with data-mtx="popover" and an id, plus a trigger with data-open-popover="#id". It opens below the trigger, aligned to the start, on an elevation-8 Paper; focus moves to the first control (or to the panel) and returns to the trigger on close.

The content of the popover. 
<button class="mtx-button mtx-button--contained" data-mtx="button" data-open-popover="#popover-basic">Open popover</button>
<div data-mtx="popover" id="popover-basic" data-label="Basic popover" class="mtx-p-2">
  The content of the popover.
</div>

Placement

data-placement uses the same engine as Tooltip (top|bottom|left|right with -start|-end; bottom-start by default), with automatic flip and shift. data-offset sets the gap in px (0 by default).

<div data-mtx="popover" id="popover-top" data-placement="top" data-offset="8" data-label="Top" class="mtx-p-2">…</div>

Anchor origins

The MUI API: data-anchor-origin="vertical horizontal" (the point on the anchor) and data-transform-origin (the point on the popover attached to it). Values are top|center|bottom and left|center|right, or pixels. The popover stays 16 px away from the viewport edges.

anchor: bottom left · transform: top left
anchor: center center · transform: center center
anchor: top right · transform: bottom right
<div data-mtx="popover" id="popover-origin-3"
     data-anchor-origin="top right" data-transform-origin="bottom right">…</div>

With icons

Any button can be a trigger; icon-only ones need an aria-label (or a data-mtx-tooltip, which provides it). The trigger gets aria-haspopup="dialog", aria-controls and aria-expanded.

States

A disabled trigger does not open the popover. Buttons with data-mtx-popover-close inside the popover close it.

Position by coordinates

open({ x, y }) anchors the popover to a point in the viewport (MUI's anchorPosition). Right-click inside the area.

Right-click here to open a popover at the cursor.

Modal

By default the popover is non-modal: tabbing out of it closes it. With data-modal it traps focus, locks scroll and sets aria-modal="true", like MUI's Popover.

Dialog from a popover

A button inside the popover opens a Dialog. Interacting with the dialog does not close the popover; the first Escape closes only the dialog (focus returns to the button) and the second one closes the popover.

Manual BEM usage

      
An initialized popover has this structure: the mtx-popover class (plus mtx-popover--open when open), role="dialog", tabindex="-1" and an accessible name. You can write it as is for SSR; the component respects any existing role, aria-label/aria-labelledby and tabindex.
