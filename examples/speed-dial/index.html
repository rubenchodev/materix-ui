Speed Dial

Floating action button that reveals three to six related, labeled actions in four directions, on click or on hover.

Basic usage Directions Colors States Labels Open on hover Real-world examples Grid Programmatic usage Manual BEM usage

Basic usage

A container with data-icon and data-label, and one <button> per action with data-icon and data-tooltip (which also provides the aria-label if it is missing). Press the FAB.

The actions take up space even when hidden: place the SpeedDial in a corner with absolute or fixed positioning.

<div data-mtx="speed-dial" data-icon="add" data-label="Create">
  <button data-icon="description" data-tooltip="Document" aria-label="Document"></button>
  <button data-icon="table_chart" data-tooltip="Spreadsheet" aria-label="Spreadsheet"></button>
  <button data-icon="slideshow" data-tooltip="Presentation" aria-label="Presentation"></button>
</div>

Directions

data-direction="up|down|left|right". For horizontal directions data-tooltip-hover is recommended so the labels do not overlap.

up · default
down
left · data-tooltip-hover
right · data-tooltip-hover

Colors

data-color on the container colors the main FAB (primary by default); on each action, it colors that action's FAB (secondary by default).

Defaults · primary + secondary
secondary + error · success · info

States

Closed and open (the main icon rotates 45°). Hover or use Tab to see hover and focus; Escape closes it and returns focus to the FAB. An action with disabled is shown disabled.

Closed
Open · with a disabled action

Labels

By default, every label shows when it opens (using the Tooltip tokens). With data-tooltip-hover each action uses a real Tooltip: it appears on hover and when focused with Tab, and Escape hides it.

Always visible
data-tooltip-hover

Open on hover

data-event="hover" opens when the pointer enters and closes when it leaves; clicking still toggles it (touch and keyboard).

Programmatic usage

open(), close(), toggle() and the direction property. The log shows the mtx:speed-dial:open and mtx:speed-dial:close events (the old mtx-speed-dial-open|close names are still emitted as deprecated aliases until 1.0).


      
const dial = Materix.getInstance(document.getElementById('speed-dial-api'));
dial.open();
dial.direction = 'left';
dial.element.addEventListener('mtx:speed-dial:open', (e) => console.log(e.detail.speedDial));
