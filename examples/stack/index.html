Stack

Stacks elements in one direction (column or row) with even spacing, alignment, wrapping, dividers and per-breakpoint changes.

Basic usage Direction Spacing Responsive Alignment Dividers Wrap Grid Real-world examples Programmatic usage Manual BEM usage

Basic usage

A single data-mtx="stack" element. As in MUI, the default direction is column; data-spacing sets the gap in multiples of 8px.

</div>

Responsive

data-direction-{bp} and data-spacing-{bp} (sm 600px, md 900px, lg 1200px, xl 1536px) change the direction and spacing from that width up. Here: a column with 8px on mobile, a row with 16px from 600px and 32px from 900px.

Alignment

data-align aligns on the cross axis (start, center, end, stretch, baseline) and data-justify distributes along the main axis (start, center, end, between, around, evenly). CSS values are accepted too (flex-start, space-between…).

Dividers

data-divider inserts a Divider between each pair of children: horizontal in a column and vertical in a row (also when the direction changes per breakpoint). They are decorative (aria-hidden="true").

Wrap

With data-wrap the children move to the next line when they do not fit (useful for groups of chips or buttons). The gap also separates the lines.

Grid

A Stack inside each mtx-grid item: the grid splits the columns and the stack arranges the content of each one.

Programmatic usage

setDirection(), setSpacing(), setAlign(), setJustify(), setWrap(), setDivider() and refresh() (regenerates the dividers after adding children). Stack emits no events.

1
2
3

      
const stack = Materix.getInstance(document.getElementById('stack-api'));
stack.setDirection('column');
stack.setDirection('row', 'md');   // from 900px
stack.setSpacing(3);
stack.setDivider(true);
stack.element.append(newChild);
stack.refresh();

// ES modules
import { Stack } from '@rubenchodev/materix-ui';
new Stack(document.querySelector('#actions'));
