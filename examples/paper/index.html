Paper

The base Material Design surface, with background, border radius and shadow, that groups content and expresses elevation.

Basic usage Variants Elevations Shape Dark theme Grid Programmatic usage Manual BEM usage

Basic usage

A <div data-mtx="paper"> gets a paper background, a 4px border radius and elevation 1. Adjust the shadow with data-elevation.

Elevation 1
Elevation 8
<div data-mtx="paper">Elevation 1</div>
<div data-mtx="paper" data-elevation="8">Elevation 8</div>

Variants

elevation (default) separates the surface with a shadow; data-variant="outlined" outlines it with a 1px border and no shadow.

Surfaces in the dark theme

Paper consumes --mtx-color-background-paper and --mtx-color-text-primary, so it changes with the theme. This block forces data-mtx-theme="dark" on a container: as in MUI, each elevation adds a white overlay (--mtx-overlay-elevation-N) that lightens the surface the higher it is; outlined has no overlay.

Programmatic usage

Paper has no methods or events of its own: initializing it is enough. Create dynamic surfaces with Materix.init(el, 'paper'); the data-* attributes are read only once, on initialization.


      
const el = document.createElement('div');
el.setAttribute('data-elevation', '4');
container.append(el);
const paper = Materix.init(el, 'paper');   // Materix.Paper instance
el.className;                              // "mtx-paper mtx-paper--elevation-4"
