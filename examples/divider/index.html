Divider

A thin line that separates and groups content in lists, menus and layouts, horizontally or vertically and optionally with text.

Basic usage

An <hr> with data-mtx="divider": a 1px line in the theme's divider color with an implicit separator role.

Variants

Without data-variant it spans the full width; middle leaves 16px on each side; inset leaves 72px on the left to align with the text of lists with icons.

Vertical orientation

data-orientation="vertical" creates a line that stretches to the height of its flex row. Use a <div>: the component adds role="separator" and aria-orientation="vertical" for you (like MUI).

With text

Write the text as the content of a <div> or use data-text. data-text-align moves it to left or right; it is centered by default.

In lists

Use an <li> as the divider to keep the HTML valid; inset aligns the line with the text. Inside a list the component keeps the <li> as a list item (no role="separator", which a list can't contain) and hides the empty one from screen readers with aria-hidden="true". Alternatively, data-divider on each list-item draws a bottom border.

Programmatic usage

Divider has no methods or events; you only need to initialize the ones created dynamically with Materix.init(el, 'divider').
