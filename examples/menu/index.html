Menu

Temporary list of options anchored to a trigger: icons, dividers, selection, submenus, context menu and full keyboard navigation.

Basic usage

A trigger with data-open-menu="#id" and a data-mtx="menu" with data-mtx="menu-item" items. It closes when an option is chosen, on a click outside, with Escape or with Tab.

Profile
My account
Sign out
<button class="mtx-button mtx-button--contained" data-mtx="button" data-open-menu="#menu-basic">Open menu</button>
<div data-mtx="menu" id="menu-basic">
  <div data-mtx="menu-item">Profile</div>
  <div data-mtx="menu-item">My account</div>
  <div data-mtx="menu-item">Sign out</div>
</div>

Triggers

The menu needs an id and an explicit trigger (the previous sibling is no longer used): data-open-menu="#id" or its alias data-mtx-menu-trigger, aria-controls="id", or data-anchor on the menu. data-open-menu triggers added later work through delegation: click “Add row” and open the new row's menu.

States

      
Normal, selected (data-selected, receives focus when opened with the keyboard) and disabled (data-disabled). Hover for the hover state; open with Enter and move with the arrow keys for focus.

Checkable options

      
role="menuitemcheckbox" toggles aria-checked on click; role="menuitemradio" checks the option and unchecks the others in its role="group". data-checked sets the initial state and the check mark is only shown on checked options.

Context menu

      
Materix.Menu.createContextMenu(selector, items) builds the menu from JSON and opens it on right-click at the pointer position.

      
Right-click here

      
Materix.Menu.createContextMenu('#menu-context-area', [
  { label: 'Copy', icon: 'content_copy', action: () => {} },
  { label: 'Paste', icon: 'content_paste', disabled: true },
  { label: 'Share', icon: 'share', submenu: [
    { label: 'Email', icon: 'mail', action: () => {} },
  ] },
]);

Programmatic usage

      
open() and close() control the menu; the log shows the real mtx:menu:open, mtx:menu:select and mtx:menu:close events.

      

        
        

          
Save

          
Export

        

        
        
      

      

      
const menu = Materix.getInstance(document.getElementById('menu-api'));
menu.open();
menu.close({ restoreFocus: false });
menu.element.addEventListener('mtx:menu:select', (e) => console.log(e.detail.item));
