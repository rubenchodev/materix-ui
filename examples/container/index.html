Container

Centers page content with a per-breakpoint max width and responsive side gutters (16px on mobile, 24px from 600px).

Basic usage Max width Fixed Gutters Grid Real-world use cases Programmatic usage Manual BEM usage

Basic usage

A single element with data-mtx="container". Without data-max-width the cap is lg (1200px), as in MUI. The shaded area is the container; the inner strip, its gutters.

Centered content · max. 1200px
<main data-mtx="container">…</main>

Max width

data-max-width sets the cap: xs 444px, sm 600px, md 900px, lg 1200px, xl 1536px or false to take the full width.

Fixed

data-fixed makes the max width jump to the minimum of each breakpoint (600, 900, 1200, 1536px) instead of growing fluidly. Useful when the design targets specific widths. Resize the window to see it.

data-fixed
<div data-mtx="container" data-fixed>…</div>

Gutters

By default the container adds 16px of side padding on mobile and 24px from 600px. data-disable-gutters removes them, for example to make an image or a table touch the edges.

16px / 24px on each side
data-disable-gutters
No side padding

Grid

Container bounds the width and Grid splits the columns inside it. No wrapper with overflow is needed: Grid spaces items with gap.

Real-world use cases

An article page: a full-width header and a reading body capped at sm to keep a comfortable line length.

What's new in version 0.1

Layout utilities, Container and Stack.

Materix ships a mobile-first utility system for building layouts without writing your own CSS. Container centers the content and Stack stacks blocks with even spacing.

Programmatic usage

setMaxWidth(), setFixed() and setGutters() replace the matching class. Container emits no events: the log shows the resulting classes.

Container controlled by the API

      
const container = Materix.getInstance(document.getElementById('container-api'));
container.setMaxWidth('md');   // 'xs' | 'sm' | 'md' | 'lg' | 'xl' | false
container.setGutters(false);
container.setFixed(true);

// ES modules
import { Container } from 'materix-ui';
new Container(document.querySelector('#main'));
