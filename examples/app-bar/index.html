Basic usage

A <header data-mtx="app-bar"> with data-title, data-start-icon and data-end-icon generates the Toolbar, the title and the IconButtons. Children are placed after the title. These examples use data-position="static" so the bar stays inside the page.

<header data-mtx="app-bar" data-position="static" data-color="primary"
        data-title="News" data-start-icon="menu">
  <button class="mtx-button mtx-button--text" data-mtx="button">Login</button>
</header>

Colors

data-color accepts primary, secondary, default (paper surface, the default value), transparent and inherit. data-elevation changes the shadow (4 by default); with data-elevation="0" the bar gets mtx-app-bar--flat and, in default, a single bottom divider. transparent never has a shadow.

Sizes

The regular Toolbar is 56px tall on mobile and 64px from 600px. data-dense reduces it to 48px for dense desktop interfaces.

With and without icons

data-start-icon adds the navigation icon and data-end-icon a trailing action. Their accessible labels are set with data-start-icon-label and data-end-icon-label (the menu icon uses "Open navigation" / "Abrir navegación" from the i18n dictionary). For several actions, write the buttons yourself as children.

Position

data-position: fixed (default, fixed to the top of the window), sticky, static, absolute and relative. Scroll each frame: the fixed one uses transform to contain the bar; on a real page it stays fixed to the window. Place a <div class="mtx-toolbar-offset"> at the start of the content to reserve its height (56px on mobile, 64px from 600px; --dense 48px).

Anchors: with a fixed or sticky AppBar on the page, <html> automatically gets scroll-padding-top: var(--mtx-app-bar-height), so a #anchor link leaves the target below the bar (adjustable with --mtx-scroll-padding-top, can be disabled with <html data-mtx-scroll-padding="false">; for specific targets, mtx-scroll-mt-app-bar). Try it: go to "Scroll".

Menu and search

Actions open a Menu with data-open-menu="#id". For search, use the .mtx-app-bar-search pattern (40px tall; its colors derive from the bar color, in the dark theme too) or a TextField with data-variant="no-label" and data-size="small". .mtx-app-bar-search--grow fills the free space (up to 560px, --mtx-app-bar-search-max-width) without changing width on focus.

Scroll

data-elevate-on-scroll starts without a shadow and adds it on scroll; data-hide-on-scroll hides the bar when scrolling down (past 50px) and shows it when scrolling up. data-scroll-target sets the observed container (the window by default). Scroll each box.

Responsive

The Toolbar changes height and margins at 600px. For navigation, show text links on wide screens and an icon with a Menu on narrow ones (resize the window below 720px).

With Drawer

With data-drawer="id" the generated navigation icon toggles the Drawer (equivalent to writing a button with data-mtx-drawer-toggle="id"), with aria-controls and aria-expanded kept in sync. If the drawer is responsive, the icon is hidden while it is permanent. For the full layout (fixed AppBar + responsive drawer + .mtx-toolbar-offset) open the app shell.

Programmatic usage

The instance exposes setColor(color) and setPosition(position). AppBar emits no events: the log shows each call and the resulting classes.

setColor()
setPosition() 

      
const appBar = Materix.getInstance(document.getElementById('app-bar-api'));
appBar.setColor('secondary');
appBar.setPosition('sticky');

    


    

      
Manual BEM usage

      
If the bar already contains a .mtx-toolbar it is not auto-scaffolded. The full syntax allows variants without an attribute, such as the 128px prominent Toolbar or several Toolbars.

      

        

          
          Prominent title
          
          
        

      

      
<header class="mtx-app-bar mtx-app-bar--static mtx-app-bar--primary" data-mtx="app-bar">
  <div class="mtx-toolbar mtx-toolbar--prominent">
    <button class="mtx-icon-button mtx-toolbar__navigation-icon" data-mtx="icon-button" aria-label="Open navigation">
      <span class="material-icons" aria-hidden="true">menu</span>
    </button>
    <span class="mtx-toolbar__title">Prominent title</span>
    <button class="mtx-icon-button" data-mtx="icon-button" aria-label="Search">...</button>
  </div>
</header>
