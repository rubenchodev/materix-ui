Breadcrumbs

Hierarchical navigation trail that shows where the user is and lets them jump back to any parent level.

Basic usage

A single <ol data-mtx="breadcrumbs">. The component wraps it in a <nav aria-label>, turns the <a> elements into Materix Links, inserts the separators and marks the last item with aria-current="page".

</ol>

From a list of links

It can also be initialized on a <nav> with the links as direct children: the component generates the <ol> and one <li> per link.

Help Billing Change payment method 
<nav data-mtx="breadcrumbs" aria-label="Location in help center">
  <a href="/help">Help</a>
  <a href="/help/billing">Billing</a>
  <span>Change payment method</span>
</nav>

Programmatic usage

File-manager style folder navigation: setItems() rebuilds the trail and mtx:breadcrumbs:navigate (cancelable) reports the clicked item. Items without href are rendered as a Link on a <button>.

  1. My Drive

      
const crumbs = Materix.getInstance(document.querySelector('#bc-dynamic'));
crumbs.setItems([
  { label: 'My Drive', icon: 'folder', data: { folder: 'root' } },
  { label: 'Projects', data: { folder: 'p1' } },
  { label: 'Q3 report' }             // last: current page
]);
crumbs.element.addEventListener('mtx:breadcrumbs:navigate', (event) => {
  event.preventDefault();            // SPA navigation
  openFolder(event.detail.item.data.folder);
});
