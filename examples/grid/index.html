Grid

A 12-column flexbox grid with five breakpoints (xs–xl), gap-based spacing in multiples of 8px (also per breakpoint) and alignment, for responsive layouts.

Spacing

data-spacing="n" separates rows and columns by n × 8px using gap (like MUI Grid v2): no negative margins or padding on the items, so the grid never overflows its parent. Values: any integer from 0 to 12 and the half steps 0.5, 1.5 and 2.5 from the utility scale (also 0_5, 1_5, 2_5). Each column width subtracts its proportional share of the gap, so 12 columns always add up to 100%.

Programmatic usage

The setSpacing(n, bp?), setRowSpacing(), setColumnSpacing(), setJustifyContent(), setAlignItems() and setDirection() methods replace the corresponding class. New items are registered with Materix.init(). Grid emits no events: the log shows the resulting classes.

1
2
3

      
const grid = Materix.getInstance(document.getElementById('grid-api'));
grid.setSpacing(4);
grid.setJustifyContent('center');
grid.setDirection('row-reverse');

const item = document.createElement('div');
item.setAttribute('data-xs', '6');
grid.element.append(item);
Materix.init(item, 'grid');
