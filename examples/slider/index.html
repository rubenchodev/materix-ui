Slider

Lets users pick a value or a range by dragging along a track, built on accessible native range inputs.

Basic usage

A single <input type="range" data-mtx="slider"> generates the rail, track, thumb and value label. It keeps min, max, step, value and name, so it is submitted with the form; data-label provides the accessible name.

<input type="range" data-mtx="slider" name="volume" min="0" max="100" value="30" data-label="Volume">

Like MUI: medium (4px rail, 20px thumb) and small (2px rail, 12px thumb, no shadow).

Value label

The value label is drop-shaped (Material Design 2). data-value-label-display: off (default), auto (on hover, focus and drag) or on (always). data-value-label-format replaces {value} and is also used as aria-valuetext.

Marks

data-marks="true" marks every step; a "value:label,…" list creates labeled marks. With data-marks-only the value can only land on the marks (equivalent to MUI's step={null}).

One mark per step · step="10"

Edge mark labels

As in MUI, the labels of the first and last marks are centered on their mark, so long texts overflow the rail by a few pixels. In narrow containers (cards, side panels) add data-marks-inset: the first label aligns to the start of the rail and the last one to the end, while the intermediate labels stay centered.

Default (centered, like MUI) data-marks-inset data-marks-inset · long labels

Range

data-range with data-value="20,60" generates two thumbs, each with its own native input ({name}-start and {name}-end) and its accessible label "Minimum"/"Maximum". When they cross, the thumbs swap as in MUI; data-disable-swap locks them and data-min-distance enforces a minimum gap.

Track

data-track: normal (default), inverted (highlights the part after the value) or false (no track, useful with marks).

Vertical

data-orientation="vertical" grows from bottom to top (200px by default; adjustable with --mtx-slider-vertical-length). The up/down arrow keys change the value and the input exposes aria-orientation.

RTL

Inside a dir="rtl" container the value grows from right to left; the left arrow key increments it.

Programmatic usage

The instance exposes value (a number or [a, b], without events), min, max, step, disable(), enable(), focus() and destroy(). It emits mtx:slider:input while dragging and mtx:slider:change on release, both with detail.value.

Manual BEM usage

      
For SSR you can write the full structure: a .mtx-slider container, rail, track and one .mtx-slider__thumb per input. The library reuses the nodes and adds the value label if it is missing.

      

        
          
          
          
            
          
        
      

      
<span class="mtx-slider" data-mtx="slider" data-value-label-display="auto">
  <span class="mtx-slider__rail"></span>
  <span class="mtx-slider__track"></span>
  <span class="mtx-slider__thumb">
    <input type="range" class="mtx-slider__input" name="brightness" min="0" max="10" value="4" aria-label="Brightness">
  </span>
</span>
