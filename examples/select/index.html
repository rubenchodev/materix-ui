Select

Select with a custom MUI-style menu: search, multiple selection, bulk actions, groups, limits and icons or images in the options.

Basic usage

Just the <select> with data-mtx="select" and data-label. The native <select> remains the source of truth and is submitted with the form. Only need the system dropdown? Use NativeSelect.

<select data-mtx="select" data-label="City" name="city">
  <option value="mdx">Mexico City</option>
  <option value="gdl">Guadalajara</option>
</select>

Colors

data-color accepts the whole MUI palette (primary, secondary, error, warning, info, success): it changes the label, the border or underline on focus, and the selected option in the menu. Use Tab or open them to compare.

States

Helper (data-helper-text), error (data-error), disabled (disabled) and read-only (data-readonly). Use Tab to see the focus and Enter to open.

Placeholder and long text

In single selection, data-placeholder is shown while no option has the selected attribute (the select's value stays empty and required validates it). Long text is truncated with an ellipsis without widening the field.

Search

data-search filters by text and value; data-header adds a header and data-none-results-text the no-match message ({0} = search term). Try typing "zz".

Multiple selection

With multiple, each option gets a checkbox and the menu stays open. data-actions-box adds bulk actions and data-selected-text-format controls the text in the control.

Groups and selection limit

<optgroup> elements are shown as subheaders; disabled options cannot be chosen and data-max-options="2" locks the rest once the limit is reached.

Automatic positioning

The menu is mounted in a portal, repositions itself on scroll and opens upwards when it doesn't fit below, limiting its height to the available space.

Grid

A shipping form in mtx-grid combining Select, TextField and Button: one column on mobile and three on desktop.

Programmatic usage

The buttons call the instance's real API; the console shows the native <select>'s change event.

Existing instance 

      

      

        Create and initialize dynamically
        

          
          
        

        

      

      
const select = Materix.getInstance(document.getElementById('select-api'));
select.value = 'prod';             // does not emit change
select.open();
select.disabled ? select.enable() : select.disable();
select.select.addEventListener('change', () => console.log(select.value));

    


    

      
Manual BEM usage

      
Full structure for SSR or fine-grained control. The component reuses the label, control and chevron, and generates the rest.

      

        

          
          

            
            
          

          
Choose at least one

        

      

      
<div class="mtx-select mtx-select--outlined" data-mtx="select" data-search data-actions-box>
  <label class="mtx-select__label">Skills</label>
  <div class="mtx-select__control">
    <select class="mtx-select__native" multiple title="Choose…">
      <option value="js" selected>JavaScript</option>
      <option value="ts">TypeScript</option>
    </select>
    <span class="mtx-select__chevron"></span>
  </div>
  <div class="mtx-select__helper-text" id="skills-help">Choose at least one</div>
</div>
