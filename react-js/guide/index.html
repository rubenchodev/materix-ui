Guide

Getting started and cross-cutting concepts of Materix UI for React: installation, bundlers, SSR, theming, languages and migration from vanilla.

Everything you need before opening a component page. Read them in order the first time; afterwards they work as a reference.

PageWhat it covers
Installationnpm package, base stylesheet, fonts and the root provider.
Usage with ViteA Vite + React + TypeScript project from scratch.
Usage with Next.jsApp Router, server rendering, 'use client' and theme without flashes.
ThemingThemeProvider, useTheme, --mtx-* tokens and data-mtx-theme.
InternationalizationI18nProvider, useT, built-in languages and custom strings.
Migrating from vanillaFrom data-* attributes and Materix.* to props, hooks and providers.
  • download Installation Install @rubenchodev/materix-react, import the base stylesheet, load Roboto and Material Icons, and wrap your app in MaterixProvider.
  • bolt Usage with Vite Create a Vite + React + TypeScript project and add Materix UI: base stylesheet, fonts, provider and the first component.
  • dns Usage with Next.js Use Materix UI in the Next.js App Router: global CSS in the root layout, 'use client' boundaries and getThemeScript to apply the theme before hydration.
  • palette Theming Light, dark and system themes with ThemeProvider and useTheme, theme without flashes, brand themes by overriding --mtx-* tokens, and the full token reference.
  • translate Internationalization Language of the built-in texts (close buttons, pickers, pagination…): I18nProvider, useT, per-component locale, overridden strings and custom languages.
  • swap_horiz Migrating from vanilla Move from the vanilla library to React: data-* attributes become props, mtx:* events become callbacks, Materix.theme becomes useTheme and initialization disappears.
