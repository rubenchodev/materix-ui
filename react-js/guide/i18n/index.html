Internationalization

Language of the built-in texts (close buttons, pickers, pagination…): I18nProvider, useT, per-component locale, overridden strings and custom languages.

Components that render their own texts (aria-labels, the date picker, pagination, the Drawer close button…) take them from a dictionary. English (en) and Spanish (es) are included; you can override any string or register new languages.

Choosing the language#

Precedence, from highest to lowest:

  1. The locale prop of a component that supports it.
  2. The closest I18nProvider (or MaterixProvider) locale.
  3. The lang attribute of <html>.
  4. en.

Regional codes are accepted (es-MX, en-GB): texts come from the base language and dates and numbers are formatted with the full code through Intl.

import { I18nProvider } from '@rubenchodev/materix-react';

export function App() {
  return (
    <I18nProvider locale="es-MX">
      <Checkout />
    </I18nProvider>
  );
}

MaterixProvider accepts the same locale and messages props, so you rarely need I18nProvider on its own. Providers can be nested: an inner provider overrides the language for its subtree.

Overriding strings#

Pass messages, keyed by language, with only the strings you want to change. They are deep-merged over the built-in dictionary:

<I18nProvider
  locale="en"
  messages={{
    en: { drawer: { close: 'Hide menu' } },
    es: { drawer: { close: 'Ocultar menú' } },
  }}
>
  <App />
</I18nProvider>

Registering a language#

Register a dictionary once, at startup, outside React. Missing keys fall back to English.

import { addLocale, updateLocale } from '@rubenchodev/materix-react';

addLocale('fr', {
  code: 'fr',
  name: 'Français',
  drawer: { close: 'Fermer' },
});

// Change some strings of an existing language for the whole app.
updateLocale('es', { drawer: { close: 'Cerrar panel' } });

Components re-render automatically when the registry changes.

useT in your own components#

useT(component) returns a translation function bound to the current language. Use it in custom components that should follow the same language as Materix:

import { useT } from '@rubenchodev/materix-react';

function CloseLabel() {
  const t = useT('drawer');
  return <span>{t('close')}</span>;
}

t(key, params?, fallback?) interpolates {name} placeholders with params. Related hooks: useLocale() returns the resolved language (es) and useIntlLocale() the full code for Intl (es-MX).
