Icon Button

Botón circular de solo icono para acciones compactas en barras de herramientas, tarjetas y filas de tabla. Siempre con aria-label.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { IconButton } from '@rubenchodev/materix-react';

Icon Button dispara una acción representada solo por un icono reconocible: buscar, cerrar, compartir, abrir un menú. Es la opción adecuada en barras de herramientas, cabeceras de tarjetas y acciones por fila, donde el espacio es limitado. Si el icono no es inequívoco, usa un Button con texto; si es la acción principal de la pantalla, usa un Fab.

warning

aria-label es obligatorio

Un Icon Button no tiene texto visible: sin aria-label (o aria-labelledby) los lectores de pantalla solo anunciarían “botón”. Describe la acción, no el icono: “Eliminar factura”, no “papelera”.

import { IconButton } from '@rubenchodev/materix-react';
// o solo este componente:
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

Uso básico#

Pasa el nombre de Material Icons en icon. El componente renderiza <button type="button" class="mtx-icon-button">, el glifo de 24px (con aria-hidden="true") y el ripple centrado.

Uso básico open_in_new
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  return (
    <div className="demo-row">
      <IconButton icon="search" aria-label="Buscar" />
      <IconButton icon="favorite" color="error" aria-label="Añadir a favoritos" />
      <IconButton icon="share" color="primary" aria-label="Compartir" />
      <IconButton icon="delete" aria-label="Eliminar" />
    </div>
  );
}

Colores#

Sin color el icono usa el gris de acción activa (--mtx-color-action-active), como en MUI. color acepta cualquier color de la paleta, o inherit para tomar el color del texto que lo rodea (superficies oscuras o de color, como un AppBar).

Colores open_in_new
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

Estados#

Posición en el borde#

edge="start|end" aplica un margen negativo de 12px para que el glifo quede alineado ópticamente con el borde del contenido, como la prop edge de MUI. Úsalo en el primer o último elemento de una barra.

Posición en el borde open_in_new
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  return (

        <span>Ajustes de la cuenta</span>
        <IconButton icon="chevron_right" edge="end" aria-label="Abrir ajustes de la cuenta" />
      </div>

}

Con insignia#

Envuelve el Icon Button en un Badge para mostrar contadores e incluye el número en el aria-label. El botón no recorta su contenido (el ripple se recorta en un contenedor interno), así que la insignia nunca se corta.

Con insignia open_in_new
import { Badge } from '@rubenchodev/materix-react/components/badge';

  return (
    <div className="demo-row">
      <Badge badgeContent={4} color="error">

      </Badge>
      <Badge badgeContent={12} color="primary">
        <IconButton icon="mail" aria-label="Correo: 12 mensajes nuevos" />
      </Badge>
    </div>

}

Con tooltip#

Un icono solo no siempre se explica por sí mismo. Envuelve el Icon Button en un Tooltip para mostrar su nombre al pasar el puntero, al enfocarlo con el teclado o con una pulsación larga. Si el botón no tiene aria-label, el texto del tooltip pasa a ser su nombre accesible; si ya lo tiene, el tooltip se enlaza como descripción (aria-describedby).

Con tooltip open_in_new
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';

export default function Demo() {
  return (
    <div className="demo-row">
      <Tooltip title="Eliminar">
        <IconButton icon="delete" />
      </Tooltip>
      <Tooltip title="Archivar (E)">
        <IconButton icon="archive" aria-label="Archivar" />
      </Tooltip>
      <Tooltip title="Más opciones" placement="top" arrow>
        <IconButton icon="more_vert" />
      </Tooltip>
    </div>
  );
}

Recomendado en botones de solo icono

MUI recomienda envolver todo botón de solo icono en un Tooltip. Un botón deshabilitado no recibe eventos de puntero: envuélvelo en un <span> dentro del Tooltip.

Uso programático#

Los métodos de vanilla pasan a ser props: disabled sustituye a disable()/enable() y ref te da el elemento DOM. Icon Button no emite eventos propios: usa onClick y cualquier otro manejador nativo.

Uso programático open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

const icons = ['bookmark', 'push_pin', 'flag', 'label'];

export default function Demo() {
  const [disabled, setDisabled] = useState(false);
  const [extra, setExtra] = useState<string[]>([]);
  const [log, setLog] = useState<string[]>([]);
  const ref = useRef<HTMLElement>(null);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const toggle = (value: boolean) => {
    setDisabled(value);
    write(`disabled = ${value}`);
  };

  const add = () => {
    const icon = icons[extra.length % icons.length];
    setExtra((prev) => [...prev, icon]);
    write(`render <IconButton icon="${icon}" /> · ref.current: <${ref.current?.tagName.toLowerCase()}>`);
  };

  return (
    <>
      <div className="demo-group">
        <span className="demo-label">Botón controlado</span>
        <div className="demo-row">
          <IconButton
            ref={ref}
            icon="favorite"
            color="error"
            aria-label="Me gusta"
            disabled={disabled}
            onClick={() => write('clic en "Me gusta"')}
          />
          <span className="demo-status">disabled: {String(disabled)}</span>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Acciones</span>
        <div className="demo-row">
          <Button variant="outlined" size="small" onClick={() => toggle(true)}>
            disabled = true
          </Button>
          <Button variant="outlined" size="small" onClick={() => toggle(false)}>
            disabled = false
          </Button>
          <Button variant="outlined" size="small" onClick={add}>
            Añadir botón
          </Button>
        </div>
        <div className="demo-row">
          {extra.map((icon, index) => (
            <IconButton key={index} icon={icon} aria-label={`Acción ${index + 1}`} />
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Registro de eventos</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </>
  );
}

Referencia de la API#

Props#

PropTipoPor defectoDescripción
iconReactNode—Nombre de Material Icons ("search") o un nodo (SVG…). Se ignora si hay children.
size'small' | 'medium' | 'large''medium'Área de 32 / 40 / 48px.
color'default' | 'inherit' | 'primary' | 'secondary' | 'success' | 'error' | 'warning' | 'info''default'Color del icono.
edge'start' | 'end' | falsefalseMargen negativo de 12px en ese lado.
disabledbooleanfalsedisabled nativo; aria-disabled en enlaces.
disableRipplebooleanfalseDesactiva el ripple centrado.
hrefstring—Renderiza un <a>.
componentElementType'button' / 'a'Elemento raíz propio (p. ej. un enlace del router). Sin href/to recibe role="button", tabIndex=0, Enter (keydown) y Espacio (keyup); con href/to se trata como enlace.
childrenReactNode—Contenido propio (icono anidado).
className, style, ref, aria-*, on*…——Se reenvían a la raíz; className se concatena.

type vale "button" por defecto para no enviar un formulario por accidente.

Accesibilidad#

  • Renderiza un <button> nativo: enfocable y activable con Enter / Espacio sin código extra.
  • aria-label es obligatorio; el icono generado lleva aria-hidden="true".
  • En botones que alternan un estado (favorito, negrita) añade aria-pressed={pressed}.
  • El anillo de foco solo aparece al navegar con teclado (:focus-visible).
TeclaAcción
Tab / Shift+TabMueve el foco al elemento siguiente / anterior.
Enter / EspacioEjecuta la acción.
