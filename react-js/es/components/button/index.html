Button

Botón de acción con variantes text, outlined y contained, tres alturas canónicas (48/40/32px), colores de la paleta, iconos y estado de carga.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Button } from '@rubenchodev/materix-react';

Button permite al usuario ejecutar una acción o confirmar una decisión con un clic: guardar un formulario, abrir un diálogo, enviar un mensaje. Úsalo cuando la acción tenga un texto que la describa. Si la acción solo puede representarse con un icono, usa Icon Button; si es la acción principal y persistente de toda la pantalla, usa Fab. Para navegar a otra página, pasa href y el botón renderiza un <a>.

lightbulb

¿Button, Icon Button o Fab?

ComponenteCuándo usarloEjemplo
ButtonAcción con texto; jerarquía mediante la variante.“Guardar”, “Cancelar”
Icon ButtonAcción compacta reconocible por su icono, en barras o filas.Buscar, cerrar, más opciones
FabLa acción principal de la pantalla, flotando sobre el contenido.Redactar correo, crear evento

Importación#

import { Button } from '@rubenchodev/materix-react';
// o solo este componente
import { Button } from '@rubenchodev/materix-react/components/button';

El componente importa su propio CSS (button.css y progress.css para el spinner de carga). Importa @rubenchodev/materix-ui/base.css una vez en tu aplicación.

Uso básico#

Un único <Button> con su variant. El componente renderiza un <button type="button"> nativo, añade el ripple y gestiona el estado deshabilitado; no hay estructura interna que escribir.

Uso básico open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  return (
    <div className="demo-row">
      <Button variant="contained">Save</Button>
      <Button variant="outlined">Preview</Button>
      <Button>Cancel</Button>
    </div>
  );
}

Variantes#

La jerarquía visual se expresa con la variante, igual que en MUI:

  • Contained (variant="contained"): énfasis alto, relleno y con elevación. Reservado para la acción principal; idealmente una por bloque.
  • Outlined (variant="outlined"): énfasis medio, para acciones secundarias importantes.
  • Text (variant="text", por defecto): énfasis bajo, para acciones en diálogos, tarjetas o junto a un botón contained.

Con iconos#

startIcon y endIcon aceptan el nombre de la ligadura de Material Icons (startIcon="add") o cualquier nodo (un <svg>, otra fuente de iconos). El botón los envuelve en <span class="mtx-button__icon mtx-button__icon--start" aria-hidden="true"> (o --end), añade material-icons cuando pasas un nombre y los desplaza 4px hacia el borde (2px en small) como MUI. Los iconos son decorativos porque el texto ya nombra la acción; un <svg> se pinta a 24 × 24px con currentColor.

Con iconOnly el botón pasa a ser cuadrado y circular (48/40/32px según el tamaño). Requiere aria-label. Para iconos sin fondo es preferible Icon Button.

Colores#

Primary es el color por defecto. color acepta secondary, success, error, warning, info e inherit en las tres variantes. Con inherit, text y outlined toman el color del contenedor: úsalo sobre superficies oscuras o de color (AppBar, banners, llamadas a la acción).

Sobre una superficie de color#

surface="primary" (o secondary) adapta el botón a un fondo de ese color: contained se invierte (fondo papel con texto primary, mtx-button--on-primary) y text/outlined toman el color del contenedor.

Contraste AA#

Los botones cumplen WCAG AA (4.5:1) por defecto: text y outlined usan --mtx-color-{color}-text y contained warning/info usa texto oscuro. Para obtener los colores exactos de MUI, añade data-mtx-contrast="mui" a <html> o a un contenedor.

Carga#

Con loading el botón entra en estado de carga como el loading de MUI: se deshabilita (disabled, o aria-disabled en enlaces), recibe aria-busy="true" y muestra un CircularProgress decorativo de 16px del color del texto. loadingPosition elige la posición: center (por defecto; el texto se vuelve transparente y el ancho no cambia), start o end (sustituyen el icono inicial o final sin cambiar el ancho; sin icono, el indicador se añade en ese lado). loadingIndicator muestra un texto (o cualquier nodo) en lugar del spinner.

Cuando loading vuelve a false, se recupera el estado previo: un botón con disabled sigue deshabilitado. El botón conserva su nombre accesible; para anunciar el progreso, añade tu propia región aria-live.

Carga open_in_new
import { useEffect, useRef, useState } from 'react';
import { Button, type ButtonOwnProps } from '@rubenchodev/materix-react/components/button';

interface LoadingOnClickProps extends ButtonOwnProps {
  onStatus: (text: string) => void;
}

/** Botón que entra en carga 2 s al hacer clic. */
function LoadingOnClick({ onStatus, ...props }: LoadingOnClickProps) {
  const [loading, setLoading] = useState(false);
  const timer = useRef<ReturnType<typeof setTimeout>>(undefined);
  useEffect(() => () => clearTimeout(timer.current), []);
  const handleClick = () => {
    setLoading(true);
    onStatus('Saving…');
    timer.current = setTimeout(() => {
      setLoading(false);
      onStatus('Changes saved');
    }, 2000);
  };
  return <Button {...props} loading={loading} onClick={handleClick} />;
}

export default function Demo() {
  const [status, setStatus] = useState('');
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Static · loading</span>
        <div className="demo-row">
          <Button variant="contained" loading>Save</Button>
          <Button variant="outlined" loading loadingPosition="start" startIcon="save">Save</Button>
          <Button loading loadingPosition="end" endIcon="send">Send</Button>
          <Button variant="outlined" loading loadingIndicator="Loading…">Download</Button>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Interactive · click → 2 s loading</span>
        <div className="demo-row">
          <LoadingOnClick variant="contained" onStatus={setStatus}>Save</LoadingOnClick>
          <LoadingOnClick variant="contained" loadingPosition="start" startIcon="save" onStatus={setStatus}>
            Save
          </LoadingOnClick>
          <LoadingOnClick variant="outlined" loadingPosition="end" endIcon="send" onStatus={setStatus}>
            Send
          </LoadingOnClick>
          <LoadingOnClick variant="outlined" loadingIndicator="Paying…" onStatus={setStatus}>
            Pay $49
          </LoadingOnClick>
          <LoadingOnClick variant="contained" size="small" onStatus={setStatus}>Small</LoadingOnClick>
          <LoadingOnClick variant="contained" size="large" onStatus={setStatus}>Large</LoadingOnClick>
        </div>
        <p className="demo-status" role="status" aria-live="polite">

Como enlace#

Si la acción navega a otra URL, pasa href: el botón renderiza un <a> y conserva la semántica de enlace (abrir en otra pestaña, copiar la dirección) con el aspecto de un botón. Como <a> no admite disabled, un enlace deshabilitado recibe aria-disabled="true", tabindex="-1" y se bloquea su clic.

Para usar el enlace de un router, pásalo en component con la prop que espera ese router: to en React Router o href en Next.js. Con href o to el botón conserva la semántica de enlace (no se fuerzan role ni tabindex):

import { Link as RouterLink } from 'react-router-dom';
import NextLink from 'next/link';

<Button component={RouterLink} to="/plans">Ver planes</Button>
<Button component={NextLink} href="/plans">Ver planes</Button>

Cualquier otro elemento sin destino (component="span", component="div" o component="a" sin href) recibe role="button", tabindex="0" y activación por teclado como un botón nativo: Enter al pulsar y Espacio al soltar.

Como enlace open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';

Uso programático#

En React el estado vive en las props: disabled, loading y el resto los controla tu estado. ref apunta al elemento DOM raíz (focus(), medidas). Button no emite eventos propios: usa onClick y los demás manejadores nativos.

Uso programático open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const [disabled, setDisabled] = useState(false);
  const [extra, setExtra] = useState<number[]>([]);
  const [log, setLog] = useState<string[]>([]);
  const ref = useRef<HTMLButtonElement>(null);
  const write = (text: string) =>
    setLog((lines) => [`[${new Date().toLocaleTimeString()}] ${text}`, ...lines].slice(0, 8));

  const changeDisabled = (value: boolean) => {
    setDisabled(value);
    write(`disabled = ${value}`);
  };

  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Controlled button</span>
        <div className="demo-row">
          <Button ref={ref} variant="contained" disabled={disabled} onClick={() => write('click on "Controlled button"')}>
            Controlled button
          </Button>
        </div>
        <p className="demo-status">disabled: {String(disabled)}</p>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          <Button variant="outlined" size="small" onClick={() => changeDisabled(true)}>
            Disable
          </Button>
          <Button variant="outlined" size="small" onClick={() => changeDisabled(false)}>
            Enable
          </Button>
          <Button
            variant="outlined"
            size="small"
            onClick={() => {
              ref.current?.focus();
              write('ref.current.focus()');
            }}
          >
            Focus (ref)
          </Button>
          <Button
            variant="outlined"
            size="small"
            onClick={() => {
              setExtra((list) => [...list, list.length + 1]);
              write('new <Button> rendered');
            }}
          >
            Add button
          </Button>
        </div>
        {extra.length ? (
          <div className="demo-row">
            {extra.map((n) => (
              <Button key={n} variant="outlined" size="small">
                New #{n}
              </Button>
            ))}
          </div>
        ) : null}
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

Accesibilidad#

  • Usa <Button> (un <button> nativo) para acciones y href para navegar.
  • Los botones de solo icono (iconOnly) necesitan aria-label. Los iconos junto al texto llevan aria-hidden="true".
  • disabled saca el botón del orden de tabulación. En enlaces aplica aria-disabled="true" y tabindex="-1" y bloquea el clic.
  • Durante la carga el botón está deshabilitado con aria-busy="true" y conserva su nombre accesible. El indicador es aria-hidden.
  • El ripple respeta prefers-reduced-motion.
