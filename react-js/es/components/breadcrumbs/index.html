Breadcrumbs

Ruta de navegación jerárquica que muestra dónde está el usuario y le permite volver a cualquier nivel superior.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Breadcrumbs, Link } from '@rubenchodev/materix-react';

Breadcrumbs pinta la ruta desde la raíz del sitio o la app hasta la página actual, como el Breadcrumbs de MUI: un <nav> con una lista ordenada, separadores ocultos a las tecnologías de asistencia y el último ítem marcado con aria-current="page". Úsalo en jerarquías de tres o más niveles (catálogos, documentación, gestores de archivos). No lo uses como navegación principal ni para flujos lineales.

Importación#

import { Breadcrumbs, Link } from '@rubenchodev/materix-react';

Uso básico#

Pasa Links y la página actual como hijos. Cada hijo va en un <li>, los enlaces reciben color="inherit" y subrayado en hover (salvo que fijen los suyos), el texto suelto pasa a ser un <span class="mtx-breadcrumbs__text"> y el último ítem se marca como página actual. Los hijos <a> y <button> nativos se convierten en Link.

Uso básico open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  return (
    <div className="demo-stack">
      <Breadcrumbs>
        <Link href="#">Inicio</Link>
        <Link href="#">Catálogo</Link>
        Accesorios
      </Breadcrumbs>
    </div>
  );
}

Página actual como enlace#

Si el último ítem debe seguir siendo un enlace, pon tú mismo aria-current="page": el componente lo respeta y no marca ningún otro ítem.

Página actual como enlace open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  return (
    <div className="demo-stack">
      <Breadcrumbs>
        <Link href="#">Inicio</Link>
        <Link href="#">Catálogo</Link>
        <Link href="#" aria-current="page">
          Auriculares
        </Link>
      </Breadcrumbs>
    </div>
  );
}

Separadores#

separator acepta cualquier texto (por defecto /), cualquier nodo o el nombre de un icono Material: un string de minúsculas, dígitos y guiones bajos, de tres o más caracteres (navigate_next, chevron_right), se pinta como icono.

Separadores open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';

const SEPARATORS = ['›', '-', 'navigate_next'];

export default function Demo() {
  return (
    <div className="demo-stack">
      {SEPARATORS.map((separator) => (
        <Breadcrumbs key={separator} separator={separator} aria-label={`ruta de navegación (${separator})`}>
          <Link href="#">Inicio</Link>
          <Link href="#">Catálogo</Link>
          Accesorios
        </Breadcrumbs>
      ))}
    </div>
  );
}

Con iconos#

data-icon en un hijo (o icon en items) añade un icono Material decorativo antes del texto. Como en MUI, el icono queda fuera del flujo del texto: en hover solo se subraya la etiqueta.

Con iconos open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  return (
    <div className="demo-stack">
      <Breadcrumbs>
        <Link href="#" data-icon="home">
          Inicio
        </Link>
        <Link href="#" data-icon="whatshot">
          Proyectos
        </Link>
        <span data-icon="grain">Rediseño del sitio web</span>
      </Breadcrumbs>
      <Breadcrumbs
        aria-label="ruta de navegación (items)"
        separator="chevron_right"
        items={[
          { label: 'Inicio', href: '#', icon: 'home' },
          { label: 'Biblioteca', href: '#', icon: 'local_library' },
          { label: 'Datos', icon: 'storage' },
        ]}
      />
    </div>
  );
}

Ruta colapsada#

Cuando hay más ítems que maxItems (8 por defecto), solo se muestran itemsBeforeCollapse (1) e itemsAfterCollapse (1), separados por un botón “Mostrar ruta”. Al activarlo se revelan los ítems ocultos, el foco pasa al primero y se llama a onExpand. La ruta vuelve a colapsarse cuando cambian sus ítems.

Ruta colapsada open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  return (
    <div className="demo-stack">
      <Breadcrumbs maxItems={2} aria-label="ruta de navegación (maxItems 2)">
        <Link href="#">Inicio</Link>
        <Link href="#">Catálogo</Link>
        <Link href="#">Accesorios</Link>
        <Link href="#">Nueva colección</Link>
        Cinturones
      </Breadcrumbs>
      <Breadcrumbs
        maxItems={4}
        itemsBeforeCollapse={2}
        itemsAfterCollapse={2}
        separator="navigate_next"
        aria-label="ruta de navegación (2 + 2)"
      >
        <Link href="#">Inicio</Link>
        <Link href="#">Documentos</Link>
        <Link href="#">2026</Link>
        <Link href="#">Contabilidad</Link>
        <Link href="#">T3</Link>
        Facturas
      </Breadcrumbs>
    </div>
  );
}

Tipografía#

Como MUI, usa body1 en text.secondary y la página actual en text.primary. Para una ruta más compacta, usa variant="body2" (añade la clase de Typography mtx-typography--body2).

Tipografía open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-stack">
      <Typography variant="overline" color="text-secondary">
        body1
      </Typography>
      <Breadcrumbs aria-label="ruta de navegación (body1)">
        <Link href="#">Configuración</Link>
        Seguridad
      </Breadcrumbs>
      <Typography variant="overline" color="text-secondary">
        body2
      </Typography>
      <Breadcrumbs variant="body2" aria-label="ruta de navegación (body2)">
        <Link href="#">Configuración</Link>
        Seguridad
      </Breadcrumbs>
    </div>
  );
}

Estados#

Los enlaces mantienen los estados de Link (subrayado en hover, anillo de foco con Tab). Un enlace de la ruta puede deshabilitarse con disabled, y su propio color lo cambia.

Estados open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  return (
    <div className="demo-stack">
      <Breadcrumbs aria-label="ruta de navegación (ítem deshabilitado)">
        <Link href="#">Inicio</Link>
        <Link href="#" disabled>
          Archivado
        </Link>
        Pedido n.º 4821
      </Breadcrumbs>
      <Breadcrumbs aria-label="ruta de navegación (enlaces primary)">
        <Link href="#" color="primary">
          Inicio
        </Link>
        <Link href="#" color="primary">
          Clientes
        </Link>
        Ana Torres
      </Breadcrumbs>
    </div>
  );
}

Desde una lista de ítems#

items describe la ruta como datos ({ label, href?, icon?, current?, disabled?, data? }), equivalente a setItems() de vanilla. Los ítems con href son Link; la página actual (la última, salvo que un ítem indique current) es texto; el resto, Link sobre un <button>. data se convierte en atributos data-*.

Desde una lista de ítems open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';

const TRAIL = [
  { label: 'Ayuda', href: '#' },
  { label: 'Facturación', href: '#' },
  { label: 'Cambiar método de pago' },
];

export default function Demo() {
  return (
    <div className="demo-stack">
      <Breadcrumbs items={TRAIL} aria-label="Ubicación en el centro de ayuda" />
    </div>
  );
}

Ejemplo real#

Cabecera de página de un panel de administración: ruta, título y acción principal.

Uso programático#

onNavigate(event, detail) se dispara al activar un enlace o botón de la ruta, con { index, href, label, current, item }. Devuelve false o llama a event.preventDefault() para cancelar la navegación nativa y gestionarla tú (routers SPA, navegación de carpetas).

Uso programático: navegación de carpetas open_in_new
import { useState } from 'react';
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Button } from '@rubenchodev/materix-react/components/button';

const FOLDERS = ['Mi unidad', 'Proyectos', 'Cliente Andina', 'Entregables', 'Informe T3'];

export default function Demo() {
  const [depth, setDepth] = useState(0);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 6));

  const items = FOLDERS.slice(0, depth + 1).map((name, index) => ({
    label: name,
    icon: index === 0 ? 'folder' : undefined,
    data: { depth: index },
  }));

  return (
    <div className="demo-stack">
      <Breadcrumbs
        separator="chevron_right"
        maxItems={4}
        items={items}
        aria-label="Carpetas"
        onExpand={() => write('onExpand')}
        onNavigate={(event, detail) => {
          event.preventDefault();
          setDepth(detail.index);
          write(`onNavigate → índice ${detail.index} (${detail.label})`);
        }}
      />
      <div className="demo-row">
        <Button
          variant="outlined"
          disabled={depth >= FOLDERS.length - 1}
          onClick={() => {
            setDepth(depth + 1);
            write(`abrir "${FOLDERS[depth + 1]}"`);
          }}
        >
          Abrir subcarpeta
        </Button>
        <Button variant="text" disabled={depth === 0} onClick={() => setDepth(0)}>
          Restablecer
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accesibilidad#

  • Landmark <nav> con aria-label="breadcrumb" (traducido con i18n breadcrumbs.label; se conserva tu propio aria-label o aria-labelledby).
  • Lista ordenada (<ol>): los lectores de pantalla anuncian el número de niveles.
  • Los separadores son <li aria-hidden="true"> y no se leen.
  • La página actual tiene aria-current="page".
  • El botón de colapso es un <button> real con la etiqueta traducida “Mostrar ruta”; tras expandir, el foco pasa al primer ítem revelado para no perderse.
