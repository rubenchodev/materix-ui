Switch

Interruptor que activa o desactiva una opción al instante, como una preferencia de ajustes; usa role=switch sobre un checkbox nativo.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Switch } from '@rubenchodev/materix-react';

Switch activa o desactiva una única opción con efecto inmediato: Wi-Fi, modo oscuro, notificaciones. Renderiza un <input type="checkbox" role="switch"> nativo dentro de un <label class="mtx-switch">, por lo que se anuncia como «activado / desactivado». Si el cambio solo se aplica al enviar un formulario, o hay varias opciones que confirmar, usa un Checkbox.

lightbulb

¿Switch o Checkbox?

Pregúntate si el usuario espera ver el efecto sin pulsar «Guardar». Si la respuesta es sí, es un Switch («Modo oscuro»). Si el valor se envía con un formulario («Acepto los términos», «Suscribirme al boletín»), es un Checkbox.

import '@rubenchodev/materix-ui/base.css';
import { Switch } from '@rubenchodev/materix-react';

<Switch label="Wi-Fi" defaultChecked />

Uso básico#

Basta un elemento con label: el componente renderiza el <label>, el input nativo, la pista con su thumb y el texto.

Uso básico open_in_new
import { Switch } from '@rubenchodev/materix-react/components/switch';

export default function Demo() {
  return (
    <div className="demo-row">
      <Switch label="Wi-Fi" defaultChecked />
      <Switch label="Bluetooth" />
    </div>
  );
}

Texto de ayuda y error#

helperText envuelve el interruptor en .mtx-form-control y añade debajo un .mtx-form-helper-text enlazado con aria-describedby. error añade aria-invalid="true"; pasa el mensaje como helperText. Dentro de un FormControl el interruptor hereda error y disabled.

Ayuda y error (FormHelperText) open_in_new
import { Switch } from '@rubenchodev/materix-react/components/switch';

export default function Demo() {
  return (
    <div className="demo-grid-3">
      <div className="demo-group">
        <span className="demo-label">Helper text</span>
        <Switch label="Automatic backups" helperText="Every night at 2:00 AM." defaultChecked />
      </div>
      <div className="demo-group">
        <span className="demo-label">Error with message</span>
        <Switch label="Two-step verification" error helperText="Required for administrators." />
      </div>

        <span className="demo-label">Disabled with helper</span>
        <Switch label="Security alerts" helperText="Always on." defaultChecked disabled />

}

Ejemplos reales#

Un panel de preferencias donde cada interruptor aplica su cambio al instante.

Casos de uso open_in_new
import { useEffect, useState } from 'react';
import { Switch } from '@rubenchodev/materix-react/components/switch';

/** Lee el tema activo de la página (`<html data-mtx-theme>`). */
const isDarkPage = () => typeof document !== 'undefined' && document.documentElement.getAttribute('data-mtx-theme') === 'dark';

export default function Demo() {
  const [dark, setDark] = useState(false);

  // Sincroniza el interruptor con el tema real de la página (también si se cambia desde la barra superior).
  useEffect(() => {
    const root = document.documentElement;
    setDark(isDarkPage());
    const observer = new MutationObserver(() => setDark(isDarkPage()));
    observer.observe(root, { attributes: true, attributeFilter: ['data-mtx-theme'] });
    return () => observer.disconnect();
  }, []);

  const handleTheme = (next: boolean) => {
    const theme = next ? 'dark' : 'light';
    const root = document.documentElement;
    root.setAttribute('data-mtx-theme', theme);
    root.style.colorScheme = theme;
    document.dispatchEvent(new CustomEvent('demo:themechange', { detail: { theme } }));
  };

  return (
    <div className="demo-panel demo-fixed-width">
      <span className="demo-label">Preferences</span>
      <Switch label="Dark mode" checked={dark} onChange={(_, next) => handleTheme(next)} />
      <Switch label="Autoplay videos" defaultChecked />
      <Switch label="Show link previews" defaultChecked />
    </div>
  );
}

Uso controlado#

Con checked + onChange el estado lo gestiona el padre; toggle(), disable() y setError() de vanilla pasan a ser cambios de estado y focus() usa inputRef.

Uso controlado open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Switch } from '@rubenchodev/materix-react/components/switch';

export default function Demo() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [checked, setChecked] = useState(false);
  const [disabled, setDisabled] = useState(false);
  const [error, setError] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ['toggle', () => setChecked((value) => !value)],
    ['checked = true', () => setChecked(true)],
    ['checked = false', () => setChecked(false)],
    ['disabled = true', () => setDisabled(true)],
    ['disabled = false', () => setDisabled(false)],
    ['focus()', () => inputRef.current?.focus()],
    ['error = true', () => setError(true)],
    ['error = false', () => setError(false)],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Controlled switch</span>
        <div className="demo-row">
          <Switch
            label="Controlled switch"
            inputRef={inputRef}
            checked={checked}
            disabled={disabled}
            error={error}
            helperText={error ? 'Turn this option on.' : undefined}
            onChange={(_, next) => {
              setChecked(next);
              write(`onChange (user) → checked: ${next}`);
            }}
          />
          <span className="demo-status">
            checked: {String(checked)} · disabled: {String(disabled)}
          </span>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          {actions.map(([label, run]) => (
            <Button
              key={label}
              variant="outlined"
              size="small"
              onClick={() => {
                run();
                write(label);
              }}
            >
              {label}
            </Button>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

Accesibilidad#

  • El input conserva su semántica nativa con role="switch": los lectores anuncian «interruptor, activado/desactivado» a partir del estado nativo (sin aria-checked redundante). Los interruptores no controlados son nativos (defaultChecked), así que form.reset() los restaura.
  • El texto de ayuda queda fuera del <label> y se enlaza con aria-describedby; error añade aria-invalid="true".
  • Toda la fila es clicable. Sin label, usa aria-label o aria-labelledby.
  • readOnly mantiene el control enfocable y legible sin simular un estado deshabilitado, y añade aria-readonly="true".
