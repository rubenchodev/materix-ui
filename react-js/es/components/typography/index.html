Typography

Aplica la escala tipográfica de MUI (h1 a overline) a cualquier elemento, separando la semántica HTML del estilo visual.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Typography } from '@rubenchodev/materix-react';

Typography aplica los estilos de texto de MUI (encabezados, subtítulos, cuerpo, botón, leyenda y overline) con la fuente Roboto y los tokens del tema. Úsalo para que todo el texto de la interfaz comparta una única escala. No lo necesitas para el texto que ya estiliza su componente (botones, campos, listas…).

import { Typography } from '@rubenchodev/materix-react';
// o solo este componente:
import { Typography } from '@rubenchodev/materix-react/components/typography';

Uso básico#

Sin props, <Typography> es un párrafo body1. variant elige el estilo y component la etiqueta.

Uso básico open_in_new
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div>
      <Typography component="h3" variant="h4" gutterBottom>
        Informe mensual
      </Typography>
      <Typography variant="body1">Las ventas crecieron un 12 % respecto al mes anterior, impulsadas por el canal en línea.</Typography>
    </div>
  );
}

Escala tipográfica#

Las 13 variantes de MUI. Como en MUI, ninguna variante tiene márgenes (ni siquiera h1–h6): añádelos con gutterBottom (0.35em) o paragraph (16 px).

Cambia las etiquetas por defecto con variantMapping (por ejemplo variantMapping={{ subtitle1: 'h6' }}) o pasa component para un único elemento.

Semántica frente a estilo#

component define la estructura del documento y variant el aspecto, de modo que puedes mantener una jerarquía de encabezados correcta sin depender del tamaño visual. Un component de encabezado (h1–h6) sin variant toma la variante de la etiqueta, como en vanilla.

Semántica frente a estilo open_in_new
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-panel">
      <Typography component="h3" variant="h5" gutterBottom>
        h3 semántico con estilo h5
      </Typography>
      <Typography component="h4" variant="subtitle1">
        h4 semántico con estilo subtitle1
      </Typography>
      <Typography variant="body2">Párrafo con estilo body2.</Typography>
    </div>
  );
}

Márgenes y truncado#

gutterBottom añade un margen inferior de 0.35em; paragraph añade 16 px (y renderiza un <p> si no hay component); noWrap mantiene el texto en una línea y lo trunca con puntos suspensivos.

Márgenes y truncado open_in_new
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">gutterBottom y paragraph</span>
        <div className="demo-panel">
          <div>
            <Typography variant="subtitle2" gutterBottom>
              Título con gutterBottom
            </Typography>
            <Typography variant="body2" paragraph>
              Párrafo con margen inferior de 16px (paragraph).
            </Typography>
            <Typography variant="body2">Párrafo siguiente.</Typography>
          </div>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">noWrap</span>
        <div className="demo-panel">
          <Typography noWrap className="demo-fixed-width">
            Texto muy largo que no cabe en una sola línea y se trunca con puntos suspensivos.
          </Typography>
        </div>
      </div>
    </div>
  );
}

Tipografía responsive#

  • Variante por breakpoint (mobile-first; sm 600 px, md 900 px, lg 1200 px, xl 1536 px): variantSm, variantMd, variantLg y variantXl sustituyen a variant desde ese ancho.
  • Escala fluida (responsiveFontSizes de MUI): responsive escala h1–h6 con clamp() entre su tamaño móvil y el de escritorio. La clase mtx-typography--responsive también funciona en cualquier ancestro (por ejemplo en <html>).
Tipografía responsive open_in_new
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Por breakpoint · h5 → md h4 → lg h3</span>
        <div className="demo-panel">
          <div>
            <Typography component="h2" variant="h5" variantMd="h4" variantLg="h3" gutterBottom>
              Novedades de octubre
            </Typography>
            <Typography variant="body2" variantMd="body1">
              body2 en móvil, body1 desde 900px
            </Typography>
          </div>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Escala fluida · clamp()</span>
        <div className="demo-panel">
          <div>
            <Typography component="h2" variant="h2" responsive gutterBottom>
              Titular fluido
            </Typography>
            <Typography component="h3" variant="h4" responsive>
              Subtítulo fluido
            </Typography>
          </div>
        </div>
      </div>
    </div>
  );
}

Grilla#

KPI en una grilla: cifra en h4, etiqueta en overline y variación en caption.

Grilla open_in_new
import { Grid } from '@rubenchodev/materix-react/components/grid';
import { Typography } from '@rubenchodev/materix-react/components/typography';

const kpis = [
  { label: 'Ingresos', value: '$48.200', change: '+12 % este mes', color: 'success' as const },
  { label: 'Pedidos', value: '1.284', change: '+4 % este mes', color: 'success' as const },
  { label: 'Devoluciones', value: '37', change: '+9 % este mes', color: 'error' as const },
];

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {kpis.map(({ label, value, change, color }) => (
        <Grid key={label} xs={12} sm={4}>
          <div className="demo-panel">
            <Typography variant="overline" color="text-secondary">
              {label}
            </Typography>
            <Typography variant="h4" component="p">
              {value}
            </Typography>
            <Typography variant="caption" color={color}>
              {change}
            </Typography>
          </div>
        </Grid>
      ))}
    </Grid>
  );
}

Uso programático#

Typography no tiene estado: renderízalo a partir de tus datos y cambia variant como cualquier otra prop.

Uso programático open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Typography, type TypographyVariant } from '@rubenchodev/materix-react/components/typography';

const variants: TypographyVariant[] = ['h5', 'h6', 'subtitle1', 'overline'];

export default function Demo() {
  const [count, setCount] = useState(0);
  const items = Array.from({ length: count }, (_, i) => ({ n: i + 1, variant: variants[i % variants.length] }));
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="outlined" onClick={() => setCount((n) => n + 1)}>
          Añadir título dinámico
        </Button>
        <Button variant="text" onClick={() => setCount(0)}>
          Limpiar
        </Button>
      </div>
      <div>
        {items.map(({ n, variant }) => (
          <Typography key={n} variant={variant} component="p">
            Título dinámico {n} ({variant})
          </Typography>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {items.map(({ variant }) => `<Typography variant="${variant}"> → mtx-typography mtx-typography--${variant}`).join('\n')}
      </pre>
    </div>
  );
}

Accesibilidad#

  • Elige la etiqueta por su función (h1–h6 para la jerarquía, p para párrafos) con component, y el aspecto con variant: los lectores de pantalla navegan por etiqueta, no por tamaño.
  • No te saltes niveles de encabezado para conseguir un tamaño. Los subtítulos se renderizan como <p> por defecto para no crear encabezados por accidente.
  • Los colores de estado y disabled no deben ser la única forma de transmitir información; acompáñalos de texto.
  • El texto truncado con noWrap queda oculto visualmente: si es importante, ofrécelo completo en otro lugar (por ejemplo en un title).
