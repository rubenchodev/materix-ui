Divider

Línea fina que separa y agrupa contenido en listas, menús y maquetaciones, en horizontal o vertical y opcionalmente con texto.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Divider } from '@rubenchodev/materix-react';

Divider es una línea de 1 px en el color divider del tema que separa grupos de contenido. Puede ser horizontal o vertical, con sangría o con margen a ambos lados, y llevar texto centrado o alineado.

import { Divider } from '@rubenchodev/materix-react';
// o solo este componente:
import { Divider } from '@rubenchodev/materix-react/components/divider';

Uso básico#

<Divider /> renderiza un <hr class="mtx-divider">, que tiene el rol separator de forma nativa.

Uso básico open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';

export default function Demo() {
  return (
    <div className="demo-panel">
      <span>Contenido de la primera sección.</span>
      <Divider className="demo-wide" />
      <span>Contenido de la segunda sección.</span>
    </div>
  );
}

Variantes#

fullWidth (por defecto) ocupa todo el ancho; middle deja 16 px a cada lado; inset deja 72 px a la izquierda para alinearse con el texto de las listas con icono.

Variantes open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Ancho completo</span>
        <Divider />
      </div>
      <div className="demo-group">
        <span className="demo-label">Middle · 16px a cada lado</span>
        <Divider variant="middle" />
      </div>
      <div className="demo-group">
        <span className="demo-label">Inset · 72px a la izquierda</span>
        <Divider variant="inset" />
      </div>
    </div>
  );
}

Orientación vertical#

orientation="vertical" renderiza un <div> con role="separator" y aria-orientation="vertical". Dentro de una fila flex, flexItem lo estira a la altura de la fila.

Orientación vertical open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Entre botones de icono</span>
        <div className="demo-row" role="toolbar" aria-label="Formato de texto">
          <IconButton icon="format_bold" aria-label="Negrita" />
          <IconButton icon="format_italic" aria-label="Cursiva" />
          <Divider orientation="vertical" flexItem />
          <IconButton icon="format_align_left" aria-label="Alinear a la izquierda" />
          <IconButton icon="format_align_center" aria-label="Centrar" />
          <IconButton icon="format_align_right" aria-label="Alinear a la derecha" />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Entre texto</span>
        <div className="demo-row">
          <span>Inicio</span>
          <Divider orientation="vertical" />
          <span>Productos</span>
          <Divider orientation="vertical" />
          <span>Contacto</span>
        </div>
      </div>
    </div>
  );
}

Con texto#

Los children se convierten en el texto del divisor (envuelto en .mtx-divider__text). textAlign lo lleva a left o right; por defecto va centrado.

Con texto open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Centrado (children)</span>
        <Divider>CENTRO</Divider>
      </div>
      <div className="demo-group">
        <span className="demo-label">Izquierda (textAlign="left")</span>
        <Divider textAlign="left">IZQUIERDA</Divider>
      </div>
      <div className="demo-group">
        <span className="demo-label">Derecha (textAlign="right")</span>
        <Divider textAlign="right">DERECHA</Divider>
      </div>
    </div>
  );
}

En listas#

Usa component="li" para que el HTML de la lista siga siendo válido. Como en vanilla, el <li> conserva su rol de elemento de lista (una lista no puede contener role="separator") y, si está vacío, se oculta a los lectores de pantalla con aria-hidden="true". inset alinea la línea con el texto. Como alternativa, divider en cada ListItem dibuja un borde inferior.

En listas open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';
import { List, ListItem } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Divisor inset entre elementos</span>
        <Paper variant="outlined">
          <List aria-label="Buzón">
            <ListItem icon="inbox">Bandeja de entrada</ListItem>
            <Divider component="li" variant="inset" />
            <ListItem icon="drafts">Borradores</ListItem>
            <Divider component="li" variant="inset" />
            <ListItem icon="send">Enviados</ListItem>
          </List>
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">divider en los elementos</span>
        <Paper variant="outlined">
          <List aria-label="Carpetas">
            <ListItem icon="folder" divider>
              Documentos
            </ListItem>
            <ListItem icon="image" divider>
              Fotos
            </ListItem>
            <ListItem icon="videocam">Vídeos</ListItem>
          </List>
        </Paper>
      </div>
    </div>
  );
}

Maquetación en grilla#

Métricas en una grilla con un divisor entre la cifra y su descripción.

Maquetación en grilla open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';
import { Grid } from '@rubenchodev/materix-react/components/grid';
import { Paper } from '@rubenchodev/materix-react/components/paper';

const metrics = [
  { value: '1.284', label: 'Pedidos este mes' },
  { value: '96%', label: 'Entregas a tiempo' },
  { value: '4,8', label: 'Valoración media' },
];

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {metrics.map(({ value, label }) => (
        <Grid key={label} xs={12} sm={4}>
          <Paper variant="outlined">
            <div className="demo-panel">
              <strong>{value}</strong>
              <Divider className="demo-wide" />
              <span>{label}</span>
            </div>
          </Paper>
        </Grid>
      ))}
    </Grid>
  );
}

Uso programático#

Los divisores se renderizan desde el estado como cualquier otro elemento; no hay nada que inicializar.

Uso programático open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Divider } from '@rubenchodev/materix-react/components/divider';

export default function Demo() {
  const [count, setCount] = useState(0);
  const blocks = Array.from({ length: count }, (_, i) => i + 1);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="outlined" onClick={() => setCount((n) => n + 1)}>
          Añadir divisor con texto
        </Button>
        <Button variant="text" onClick={() => setCount(0)}>
          Limpiar
        </Button>
      </div>
      <div className="demo-stack">
        {blocks.map((n) => (
          <Divider key={n} textAlign={n % 2 === 0 ? 'left' : 'center'}>
            Bloque {n}
          </Divider>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {blocks
          .map((n) => `<Divider${n % 2 === 0 ? ' textAlign="left"' : ''}>Bloque ${n}</Divider> → role="separator"`)
          .join('\n')}
      </pre>
    </div>
  );
}

API#

Props#

PropTipoPor defectoDescripción
orientation'horizontal' | 'vertical''horizontal'vertical añade .mtx-divider--vertical y aria-orientation="vertical".
variant'fullWidth' | 'middle' | 'inset''fullWidth'Añade .mtx-divider--middle o .mtx-divider--inset.
flexItembooleanfalseAñade .mtx-divider--flex-item (se estira en una fila flex).
textAlign'center' | 'left' | 'right''center'Posición del texto; añade .mtx-divider--text-{left|right}.
childrenReactNode—Texto del divisor: añade .mtx-divider--text y el span .mtx-divider__text.
componentElementType'hr' ('div' si es vertical o lleva texto)Elemento raíz. 'li' conserva el rol de elemento de lista.
classNamestring—Se concatena con las clases del componente.
refRef<HTMLElement>—Apunta al elemento raíz.

El resto de props (role, aria-*, style, data-*…) se reenvían al elemento raíz; tu propio role o aria-orientation tienen prioridad.

Callbacks#

Divider no emite eventos.

Clases CSS#

ClaseDescripción
.mtx-dividerLínea de 1 px en --mtx-color-divider.
.mtx-divider--verticalLínea vertical que se estira a la altura de su fila.
.mtx-divider--middle / .mtx-divider--insetMargen de 16 px a ambos lados / 72 px a la izquierda.
.mtx-divider--flex-itemalign-self: stretch con altura automática.
.mtx-divider--textDisposición línea — texto — línea.
.mtx-divider--text-left / .mtx-divider--text-rightTexto alineado a un lado.
.mtx-divider__textContenedor del texto.

Accesibilidad#

  • <hr> tiene el rol implícito separator; es la opción por defecto para divisores horizontales sin texto.
  • Sobre un <div> (vertical o con texto) el componente añade role="separator" salvo que pases tu propio role (por ejemplo role="presentation" para un divisor puramente decorativo), y aria-orientation="vertical" en los verticales, como MUI.
  • Con component="li" el divisor conserva el rol de elemento de lista; vacío recibe aria-hidden="true" y, con texto, sigue siendo legible.
  • El texto de un divisor es contenido legible: escríbelo con sentido («o», «Sección 2»), no con símbolos.
