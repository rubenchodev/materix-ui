Select

Selector con menú propio al estilo MUI: búsqueda, selección múltiple, acciones masivas, grupos, límites e iconos o imágenes en las opciones.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Select } from '@rubenchodev/materix-react';

Select permite elegir uno o varios valores de una lista mediante un menú propio con estética MUI: búsqueda, selección múltiple con casillas, acciones masivas, grupos y opciones con icono o imagen. Un <select> nativo oculto refleja la selección, de modo que el valor se envía con el formulario y el navegador valida required. Si solo necesitas el desplegable del sistema operativo, más ligero y mejor en móviles, usa NativeSelect; para texto libre, usa TextField.

import '@rubenchodev/materix-ui/base.css';
import { Select } from '@rubenchodev/materix-react';

<Select label="Ciudad" name="city">
  <option value="mdx">Ciudad de México</option>
  <option value="gdl">Guadalajara</option>
</Select>

Uso básico#

Basta un elemento con label: el componente genera el contenedor, el label flotante, el combobox, el <select> nativo oculto, el chevron y, en outlined, el borde con muesca. Las opciones se escriben como children <option>/<optgroup> (con data-icon/data-image como en vanilla) o se pasan con la prop options. Sin defaultValue queda seleccionada la primera opción habilitada, como en un select nativo.

Uso básico open_in_new

export const description = {

  es: "Un único `<Select>` con `label` y children `<option>`. El componente genera el label, el combobox, el borde con muesca y un `<select>` nativo oculto que se envía con el formulario. ¿Solo necesitas el desplegable del sistema? Usa NativeSelect.",
};

  return (

        <option value="gdl">Guadalajara</option>
        <option value="mty">Monterrey</option>
      </Select>

}

Uso controlado#

Con value + onChange y open + onOpen/onClose el estado lo lleva el padre; los métodos de la instancia vanilla pasan a ser cambios de estado (value = …, open(), disable(), helperText = …) y focus() usa controlRef.

Uso controlado open_in_new
import { useRef, useState } from 'react';
import { Select } from '@rubenchodev/materix-react/components/select';
import { Button } from '@rubenchodev/materix-react/components/button';

export const description = {
  en: "With `value` + `onChange` and `open` + `onOpen` / `onClose` the parent owns the state; the buttons replace the vanilla instance methods and `focus()` uses `controlRef`.",
  es: "Con `value` + `onChange` y `open` + `onOpen` / `onClose` el estado lo lleva el padre; los botones sustituyen a los métodos de la instancia vanilla y `focus()` usa `controlRef`.",
};

export default function Demo() {
  const controlRef = useRef<HTMLDivElement>(null);
  const [env, setEnv] = useState('dev');
  const [regions, setRegions] = useState<string[]>([]);
  const [open, setOpen] = useState(false);
  const [disabled, setDisabled] = useState(false);
  const [helper, setHelper] = useState('Use the buttons or the menu');
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ["value = 'prod'", () => setEnv('prod')],
    ["value = ['eu', 'sa']", () => setRegions(['eu', 'sa'])],
    ['open = true', () => setOpen(true)],
    ['disabled = !disabled', () => setDisabled((prev) => !prev)],
    ['helperText', () => setHelper(`Updated at ${new Date().toLocaleTimeString()}`)],
    ['focus()', () => controlRef.current?.focus()],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-grid-2">
        <Select
          label="Environment"
          controlRef={controlRef}
          helperText={helper}
          value={env}
          open={open}
          disabled={disabled}
          onOpen={() => {
            setOpen(true);
            write('onOpen');
          }}
          onClose={() => {
            setOpen(false);
            write('onClose');
          }}
          onChange={(_, next) => {
            setEnv(next as string);
            write(`onChange → ${JSON.stringify(next)}`);
          }}
          options={[
            { value: 'dev', label: 'Development' },
            { value: 'staging', label: 'Staging' },
            { value: 'prod', label: 'Production' },
          ]}
        />
        <Select
          label="Regions"
          multiple
          actionsBox
          value={regions}
          onChange={(_, next) => {
            setRegions(next as string[]);
            write(`onChange → ${JSON.stringify(next)}`);
          }}
          options={[
            { value: 'us', label: 'United States' },
            { value: 'eu', label: 'Europe' },
            { value: 'sa', label: 'South America' },
          ]}
        />
      </div>
      <span className="demo-status">
        env: {env} · regions: {JSON.stringify(regions)} · open: {String(open)} · disabled: {String(disabled)}
      </span>
      <div className="demo-row">
        {actions.map(([label, run]) => (
          <Button
            key={label}
            variant="outlined"
            size="small"
            onClick={() => {
              run();
              write(label);
            }}
          >
            {label}
          </Button>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Dentro de un Dialog#

El menú portado se registra como capa superior: la trampa de foco del Dialog deja entrar el foco en su caja de búsqueda, Esc cierra solo el menú (una segunda pulsación cierra el diálogo) y su z-index queda por encima del diálogo.

Dentro de un Dialog open_in_new

Accesibilidad#

  • Patrón WAI-ARIA select-only combobox: el control tiene role="combobox", aria-haspopup="listbox", aria-expanded y aria-controls; el menú contiene un role="listbox" con elementos role="option" (aria-selected, aria-disabled) y role="group" para los grupos. Con multiple, el listbox lleva aria-multiselectable.
  • El foco se queda en el combobox y la opción activa se anuncia con aria-activedescendant; con search, el foco pasa a la caja de búsqueda, que lleva aria-activedescendant.
  • El label da nombre al combobox (aria-labelledby); sin label usa aria-label. error añade aria-invalid, required aria-required, readOnly aria-readonly y helperText se enlaza con aria-describedby.
  • El <select> nativo oculto es aria-hidden y queda fuera del orden de tabulación; Escape llega por la pila común de capas (solo se cierra la capa superior).
