Speed Dial

Botón de acción flotante que despliega de tres a seis acciones relacionadas con etiquetas, en cuatro direcciones, por clic o al pasar el cursor.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { SpeedDial, SpeedDialAction, SpeedDialIcon } from '@rubenchodev/materix-react';

SpeedDial es un Fab principal que, al pulsarlo, despliega varias acciones secundarias como FAB pequeños con etiqueta, igual que el SpeedDial de MUI. Úsalo cuando la acción principal de una pantalla tiene de tres a seis variantes relacionadas (crear documento, hoja, presentación). Si solo hay una acción, usa un Fab; si las opciones son muchas o no son acciones de creación, usa un Menu.

import { SpeedDial, SpeedDialAction, SpeedDialIcon } from '@rubenchodev/materix-react';
// o solo este componente:
import { SpeedDial, SpeedDialAction, SpeedDialIcon } from '@rubenchodev/materix-react/components/speed-dial';

Uso básico#

ariaLabel nombra el FAB principal y cada SpeedDialAction recibe icon y tooltipTitle. El componente pinta el FAB, el contenedor de acciones y las etiquetas.

Uso básico open_in_new
import '@rubenchodev/materix-ui/utilities.css';
import { SpeedDial, SpeedDialAction } from '@rubenchodev/materix-react/components/speed-dial';

/** Esquina inferior derecha del panel (utilidades de posición). */
const corner = 'mtx-position-absolute mtx-right-0 mtx-bottom-0 mtx-m-2';

export default function Demo() {
  return (
    <div className="demo-panel demo-panel--tall">
      <SpeedDial ariaLabel="Crear" className={corner}>
        <SpeedDialAction icon="description" tooltipTitle="Documento" />
        <SpeedDialAction icon="table_chart" tooltipTitle="Hoja de cálculo" />
        <SpeedDialAction icon="slideshow" tooltipTitle="Presentación" />
      </SpeedDial>
    </div>
  );
}
<SpeedDial ariaLabel="Crear">
  <SpeedDialAction icon="description" tooltipTitle="Documento" />
  <SpeedDialAction icon="table_chart" tooltipTitle="Hoja de cálculo" />
  <SpeedDialAction icon="slideshow" tooltipTitle="Presentación" />
</SpeedDial>
warning

Nombre accesible de cada acción

tooltipTitle crea la etiqueta visible y, si la acción no tiene aria-label, también se usa como su aria-label, así las acciones de solo icono siempre tienen nombre accesible. Si tooltipTitle no es un texto, pasa tú el aria-label.

Cerrado, las acciones son invisibles pero siguen ocupando su espacio en el flujo, como en MUI: coloca el SpeedDial en una esquina con posición absoluta o fija, por ejemplo con las utilidades className="mtx-position-absolute mtx-right-0 mtx-bottom-0 mtx-m-2" dentro de un contenedor posicionado (ver «Oculto y posición»).

Direcciones#

direction fija hacia dónde se despliegan las acciones: up (por defecto), down, left o right. En vertical las etiquetas aparecen a la izquierda de cada acción; en horizontal, encima. Las flechas siguen la dirección.

Etiquetas#

Por defecto las etiquetas de todas las acciones se ven mientras el SpeedDial está abierto (tooltipOpen de MUI), con los tokens del Tooltip. Con tooltipHover en el SpeedDial cada acción usa un Tooltip real que aparece al pasar el puntero o al enfocar con el teclado, a la izquierda en direcciones verticales y encima en horizontales; recomendado en horizontal para que no se solapen. En una acción, tooltipOpen fuerza un modo y tooltipPlacement mueve su Tooltip.

Teclado

En ambos modos la etiqueta se ve al recorrer las acciones: en el modo persistente siempre, y con tooltipHover el Tooltip aparece con el foco de teclado y se oculta con Escape. El nombre accesible de cada acción sigue siendo su aria-label (las etiquetas persistentes son aria-hidden para no leerse dos veces).

Abrir al pasar el puntero#

event="hover" abre el SpeedDial al entrar el ratón y lo cierra al salir. El clic en el FAB sigue alternándolo, así que también funciona en pantallas táctiles y con teclado.

Iconos#

Sin icon el FAB muestra <SpeedDialIcon /> (add), que rota 45° al abrir. openIcon (en el SpeedDial o en SpeedDialIcon) lo sustituye por otro icono mientras está abierto: el icono cerrado rota y se desvanece mientras el de apertura gira hasta su sitio. Los iconos pueden ser nombres de Material Icons o nodos como un <svg> (24px).

Ejemplos reales#

Galería de fotos: el SpeedDial es controlado, así que cada acción hace su tarea y lo cierra.

Ejemplos reales open_in_new
import '@rubenchodev/materix-ui/utilities.css';
import { useState } from 'react';
import { SpeedDial, SpeedDialAction } from '@rubenchodev/materix-react/components/speed-dial';

/** Esquina inferior derecha del panel (utilidades de posición). */
const corner = 'mtx-position-absolute mtx-right-0 mtx-bottom-0 mtx-m-2';
const actions = [
  ['photo_camera', 'Hacer foto'],
  ['upload', 'Subir archivo'],
  ['create_new_folder', 'Nuevo álbum'],
] as const;

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [status, setStatus] = useState('Elige una acción.');

  return (
    <div className="demo-panel demo-panel--tall">
      <p className="demo-status mtx-m-2" aria-live="polite">
        {status}
      </p>
      <SpeedDial
        ariaLabel="Añadir a la galería"
        icon="add_a_photo"
        open={open}
        onOpen={() => setOpen(true)}
        onClose={() => setOpen(false)}
        className={corner}
      >
        {actions.map(([icon, label]) => (
          <SpeedDialAction
            key={icon}
            icon={icon}
            tooltipTitle={label}
            onClick={() => {
              setStatus(`Acción: ${label}`);
              setOpen(false);
            }}
          />
        ))}
      </SpeedDial>
    </div>
  );
}

Oculto y posición#

hidden encoge el FAB principal con una transición de escala y cierra las acciones (por ejemplo al hacer scroll): si estaba abierto, se llama a onClose(null, 'hidden') y reaparece cerrado. position="fixed-br" y "fixed-bl" lo fijan a 24px de la esquina inferior derecha o izquierda de la ventana, por encima del contenido (z-index 1050).

Oculto y posición open_in_new
import '@rubenchodev/materix-ui/utilities.css';

import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const [hidden, setHidden] = useState(false);
  return (

      <div className="demo-row">

          hidden

      </div>
      <div className="demo-panel demo-panel--tall">

          <SpeedDialAction icon="mail" tooltipTitle="Correo" />
          <SpeedDialAction icon="event" tooltipTitle="Evento" />

Uso programático#

open(), close(), toggle() y direction de vanilla pasan a ser las props open y direction. En modo no controlado usa defaultOpen; onOpen y onClose reciben el evento y el motivo.

Uso programático open_in_new
import '@rubenchodev/materix-ui/utilities.css';
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { SpeedDial, SpeedDialAction } from '@rubenchodev/materix-react/components/speed-dial';
import type { SpeedDialDirection } from '@rubenchodev/materix-react/components/speed-dial';

/** Esquina inferior derecha del panel (utilidades de posición). */
const corner = 'mtx-position-absolute mtx-right-0 mtx-bottom-0 mtx-m-2';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [direction, setDirection] = useState<SpeedDialDirection>('up');
  const [log, setLog] = useState<string[]>([]);
  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));
  const nextDirection: SpeedDialDirection = direction === 'up' ? 'left' : 'up';

  return (
    <>
      <div className="demo-group">
        <span className="demo-label">Acciones</span>
        <div className="demo-row">
          <Button variant="outlined" size="small" onClick={() => setOpen(true)}>
            open()
          </Button>
          <Button variant="outlined" size="small" onClick={() => setOpen(false)}>
            close()
          </Button>
          <Button variant="outlined" size="small" onClick={() => setOpen((value) => !value)}>
            toggle()
          </Button>
          <Button variant="outlined" size="small" onClick={() => setDirection(nextDirection)}>
            direction = &apos;{nextDirection}&apos;
          </Button>
        </div>
      </div>
      <div className="demo-panel demo-panel--tall">
        <SpeedDial
          ariaLabel="Acciones para compartir"
          open={open}
          direction={direction}
          tooltipHover={direction === 'left'}
          onOpen={(_, reason) => {
            setOpen(true);
            write(`onOpen (motivo: ${reason})`);
          }}
          onClose={(_, reason) => {
            setOpen(false);
            write(`onClose (motivo: ${reason})`);
          }}
          className={corner}
        >
          <SpeedDialAction icon="mail" tooltipTitle="Correo" onClick={() => write('clic en "Correo"')} />
          <SpeedDialAction icon="link" tooltipTitle="Enlace" onClick={() => write('clic en "Enlace"')} />
        </SpeedDial>
      </div>
      <div className="demo-group">
        <span className="demo-label">Registro de eventos · open: {String(open)}</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </>
  );
}
const [open, setOpen] = useState(false);

          <div className="mtx-speed-dial__action-wrapper">
            <span className="mtx-speed-dial__tooltip" aria-hidden="true">
              Documento
            </span>
            <button
              type="button"
              className="mtx-fab mtx-fab--small mtx-fab--secondary mtx-speed-dial__action"
              aria-label="Documento"
            >

  );
}

Accesibilidad#

  • El FAB principal recibe aria-haspopup="true", un aria-expanded sincronizado y aria-controls hacia el contenedor de acciones; su nombre sale de ariaLabel.
  • Las acciones son <button> nativos con icono decorativo (aria-hidden), nombrados por tooltipTitle o aria-label.
  • Cerrado, el contenedor de acciones recibe inert y aria-hidden="true" y cada acción tabIndex={-1}, así las acciones invisibles quedan fuera del orden de tabulación. Si el foco está en las acciones al cerrar, vuelve al FAB.
  • Las etiquetas persistentes son aria-hidden (el nombre ya está en el aria-label); en modo tooltipHover el Tooltip no duplica el nombre si coincide con el texto.
  • Escape pasa por la pila común de capas: primero se oculta un Tooltip visible y después se cierra el SpeedDial.
  • Respeta prefers-reduced-motion: la rotación del icono y el cambio a openIcon no tienen transición.
