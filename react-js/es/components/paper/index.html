Paper

Superficie base de Material Design con fondo, radio y sombra que agrupa contenido y expresa elevación.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Paper } from '@rubenchodev/materix-react';

Paper es la superficie física de Material Design: un contenedor con fondo de papel, radio de 4 px y una sombra que indica su elevación. Es la base visual de Card, Dialog, Menu o AppBar. Úsalo para agrupar contenido arbitrario sobre el fondo de la página; si el bloque tiene cabecera, imagen y acciones, usa directamente Card.

import { Paper } from '@rubenchodev/materix-react';
// o solo este componente:
import { Paper } from '@rubenchodev/materix-react/components/paper';

Uso básico#

<Paper> renderiza un <div class="mtx-paper"> con elevación 1. Cambia la sombra con elevation.

Uso básico open_in_new
import { Paper } from '@rubenchodev/materix-react/components/paper';

const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface">
      <Paper className={boxClass} style={box}>
        Elevación 1
      </Paper>
      <Paper elevation={8} className={boxClass} style={box}>
        Elevación 8
      </Paper>
    </div>
  );
}

Variantes#

La variante por defecto (elevation) separa la superficie con una sombra. variant="outlined" la delimita con un borde de 1 px (--mtx-color-divider) y sin sombra; elevation={0} la deja plana.

Variantes open_in_new
import { Paper } from '@rubenchodev/materix-react/components/paper';

const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface">
      <div className="demo-group">
        <span className="demo-label">Elevación</span>
        <Paper className={boxClass} style={box}>
          Sombra
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">Contorneado</span>
        <Paper variant="outlined" className={boxClass} style={box}>
          Borde
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">Elevación 0</span>
        <Paper elevation={0} className={boxClass} style={box}>
          Plano
        </Paper>
      </div>
    </div>
  );
}

Elevaciones#

Solo existen como tokens (--mtx-elevation-*) las elevaciones de MUI 0 a 8, 12, 16 y 24. Cualquier otro valor genera una clase sin estilo y la superficie conserva la elevación base 1.

Elevaciones open_in_new
import { Paper, type PaperElevation } from '@rubenchodev/materix-react/components/paper';

const levels: PaperElevation[] = [0, 1, 2, 3, 4, 5, 6, 7, 8, 12, 16, 24];
const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface">
      {levels.map((level) => (
        <Paper key={level} elevation={level} className={boxClass} style={box}>
          {level}
        </Paper>
      ))}
    </div>
  );
}

Forma#

Las esquinas usan --mtx-shape-radius (4 px). square las deja rectas, útil para superficies pegadas a los bordes de la ventana.

Forma open_in_new
import { Paper } from '@rubenchodev/materix-react/components/paper';

const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface">
      <div className="demo-group">
        <span className="demo-label">Redondeado · 4px</span>
        <Paper elevation={3} className={boxClass} style={box}>
          Redondeado
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">Cuadrado</span>
        <Paper elevation={3} square className={boxClass} style={box}>
          Cuadrado
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">Contorneado cuadrado</span>
        <Paper variant="outlined" square className={boxClass} style={box}>
          Contorneado
        </Paper>
      </div>
    </div>
  );
}

Tema oscuro#

Paper consume --mtx-color-background-paper y --mtx-color-text-primary, así que sigue al tema. data-mtx-theme="dark" también funciona sobre un contenedor concreto. En el tema oscuro, como en MUI, cada elevación añade una capa blanca (--mtx-overlay-elevation-N) mediante background-image, de modo que las superficies más altas se ven más claras; outlined no lleva capa.

Superficies en el tema oscuro open_in_new
import { Paper } from '@rubenchodev/materix-react/components/paper';

const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface" data-mtx-theme="dark">
      {[0, 1, 4, 8, 24].map((level) => (
        <Paper key={level} elevation={level} className={boxClass} style={box}>
          Elevación {level}
        </Paper>
      ))}
      <Paper variant="outlined" className={boxClass} style={box}>
        Contorneado
      </Paper>
    </div>
  );
}

Grilla#

Paper es el contenedor habitual de los elementos de una grilla: la columna decide el ancho y Paper aporta la superficie.

Grilla open_in_new
import { Grid } from '@rubenchodev/materix-react/components/grid';
import { Paper } from '@rubenchodev/materix-react/components/paper';

const box = { height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface">
      <Grid container spacing={2} className="mtx-w-100">
        <Grid xs={12} md={8}>
          <Paper className={boxClass} style={box}>
            xs=12 md=8
          </Paper>
        </Grid>
        <Grid xs={12} md={4}>
          <Paper className={boxClass} style={box}>
            xs=12 md=4
          </Paper>
        </Grid>
        <Grid xs={6} md={4}>
          <Paper variant="outlined" className={boxClass} style={box}>
            xs=6 md=4
          </Paper>
        </Grid>
        <Grid xs={6} md={8}>
          <Paper variant="outlined" className={boxClass} style={box}>
            xs=6 md=8
          </Paper>
        </Grid>
      </Grid>
    </div>
  );
}

Uso programático#

No hay nada que inicializar: elevation, variant y square son props normales, así que al cambiarlas se actualizan las clases en el siguiente render.

Uso programático open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Paper, type PaperElevation } from '@rubenchodev/materix-react/components/paper';

const levels: PaperElevation[] = [0, 1, 2, 3, 4, 6, 8, 12, 16, 24];
const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  const [items, setItems] = useState<PaperElevation[]>([]);
  const add = () => setItems((prev) => [...prev, levels[prev.length % levels.length]]);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" onClick={add}>
          Crear Paper
        </Button>
        <Button variant="outlined" onClick={() => setItems([])}>
          Limpiar
        </Button>
      </div>
      <div className="demo-surface">
        {items.map((level, index) => (
          <Paper key={index} elevation={level} className={boxClass} style={box}>
            Elevación {level}
          </Paper>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {items.map((level) => `<Paper elevation={${level}} /> → mtx-paper mtx-paper--elevation-${level}`).join('\n')}
      </pre>
    </div>
  );
}

Elemento semántico y composición#

component cambia la etiqueta raíz (section, article, aside…) sin alterar el aspecto. Combínalo con Typography para el contenido.

Elemento semántico y composición open_in_new
import { Paper } from '@rubenchodev/materix-react/components/paper';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-surface">
      <Paper component="section" elevation={2} aria-labelledby="order-summary" className="mtx-p-2 demo-wide">
        <Typography id="order-summary" component="h3" variant="h6" gutterBottom>
          Resumen del pedido
        </Typography>
        <Typography variant="body2">3 artículos · Envío estándar · Total $74.90</Typography>
      </Paper>
    </div>
  );
}

API#

Props#

PropTipoPor defectoDescripción
elevation0–8 | 12 | 16 | 24—Añade .mtx-paper--elevation-{n}. Sin ella se aplica la sombra base (elevación 1).
variant'elevation' | 'outlined''elevation'outlined añade .mtx-paper--outlined (borde, sin sombra).
squarebooleanfalseAñade .mtx-paper--square (sin radio).
componentElementType'div'Elemento o componente raíz.
classNamestring—Se concatena con las clases del componente.
refRef<HTMLElement>—Apunta al elemento raíz.

El resto de props (id, style, aria-*, data-*, eventos) se reenvían al elemento raíz.

Callbacks#

Paper no emite eventos.

Clases CSS#

ClaseDescripción
.mtx-paperFondo de papel, color de texto primario, radio de 4 px y elevación 1.
.mtx-paper--elevation-{n}Sombra --mtx-elevation-{n} para n = 0–8, 12, 16, 24.
.mtx-paper--outlinedBorde de 1 px --mtx-color-divider y sin sombra (prevalece sobre cualquier elevación).
.mtx-paper--squareborder-radius: 0.

Accesibilidad#

  • Paper es puramente visual y no añade roles ni ARIA: elige el elemento semántico con component (section, article, aside) y dale un encabezado (aria-labelledby) cuando agrupe contenido relevante.
  • La elevación no transmite información por sí sola; usa outlined o un encabezado cuando la superficie deba quedar claramente delimitada.
  • No es interactivo: si toda la superficie debe ser clicable, usa una Card con área de acción.
