Menu

Lista temporal de opciones anclada a un disparador: iconos, atajos, separadores, selección, opciones marcables, submenús, menú contextual y navegación completa por teclado.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Menu, MenuItem, MenuList, MenuDivider, MenuGroup, Submenu, ContextMenu, useMenu, useContextMenu } from '@rubenchodev/materix-react';

Menu muestra una lista temporal de acciones u opciones sobre una superficie elevada, anclada al elemento que la abre, como el Menu de MUI (Popper + Paper + MenuList). Úsalo para acciones contextuales sobre un elemento (editar, duplicar, eliminar), menús de cuenta o barras de herramientas compactas. Para elegir un valor en un formulario usa un NativeSelect; para la navegación principal, Tabs.

import { Menu, MenuItem, useMenu } from '@rubenchodev/materix-react';
// o solo este componente:
import { Menu, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';

Anatomía: .mtx-menu__popper (posicionado en un portal) › .mtx-menu__paper (elevación 8) › .mtx-menu (role="menu") › .mtx-menu-item (role="menuitem") con .mtx-menu-item__icon, texto, atajo y .mtx-menu-item__check / .mtx-menu-item__expand opcionales.

Uso básico#

useMenu() equivale al data-open-menu de vanilla: esparce triggerProps en el disparador y menuProps en el Menu. El disparador alterna el menú y recibe aria-haspopup, aria-expanded y aria-controls. El menú se cierra al elegir una opción, con un clic fuera, con Escape o con Tab.

Uso básico open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';
import { Menu, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';

export default function Demo() {
  const menu = useMenu();
  return (
    <div className="demo-row">
      <Button variant="contained" {...menu.triggerProps}>
        Open menu
      </Button>
      <Menu {...menu.menuProps}>
        <MenuItem>Profile</MenuItem>
        <MenuItem>My account</MenuItem>
        <MenuItem>Sign out</MenuItem>
      </Menu>
    </div>
  );
}

Disparadores#

Sin useMenu, el menú es totalmente controlado, como en MUI: open, anchorEl y onClose. Un único Menu puede servir a todas las filas de una lista: cada botón se guarda como anchorEl, así que también funcionan las filas añadidas después (vanilla necesitaba delegación de clics para ello).

Disparadores open_in_new
import { useState } from 'react';
import type { MouseEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';
import { List, ListItem } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';
import { Menu, MenuDivider, MenuItem } from '@rubenchodev/materix-react/components/menu';

export default function Demo() {
  const [rows, setRows] = useState([
    { name: 'Annual report.pdf', size: '2.4 MB' },
    { name: 'Budget.xlsx', size: '310 KB' },
  ]);
  const [anchor, setAnchor] = useState<{ el: HTMLElement; name: string } | null>(null);
  const [log, setLog] = useState<string[]>([]);

  const openFor = (name: string) => (event: MouseEvent<HTMLElement>) => {
    const el = event.currentTarget;
    setAnchor((prev) => (prev?.el === el ? null : { el, name }));
  };

  return (
    <div className="demo-stack">
      <Paper variant="outlined" className="demo-wide">
        <List aria-label="Files">
          {rows.map((row) => (
            <ListItem
              key={row.name}
              icon="description"
              secondary={row.size}
              secondaryAction={
                <IconButton
                  icon="more_vert"
                  aria-label={`Actions for ${row.name}`}
                  aria-haspopup="menu"
                  aria-expanded={anchor?.name === row.name}
                  aria-controls={anchor?.name === row.name ? 'menu-row-actions' : undefined}
                  onClick={openFor(row.name)}
                />
              }
            >
              {row.name}
            </ListItem>
          ))}
        </List>
      </Paper>
      <Menu
        id="menu-row-actions"
        open={anchor !== null}
        anchorEl={anchor?.el}
        onClose={() => setAnchor(null)}
        onSelect={({ value }) => setLog((lines) => [`${value} → ${anchor?.name}`, ...lines].slice(0, 5))}
      >
        <MenuItem icon="edit" value="rename">
          Rename
        </MenuItem>
        <MenuItem icon="content_copy" value="duplicate">
          Duplicate
        </MenuItem>
        <MenuDivider />
        <MenuItem icon="delete" value="delete">
          Delete
        </MenuItem>
      </Menu>
      <div className="demo-row">
        <Button
          variant="outlined"
          startIcon="add"
          onClick={() => setRows((list) => [...list, { name: `New file ${list.length + 1}.txt`, size: '1 KB' }])}
        >
          Add row
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Estados#

selected resalta la opción actual y recibe el foco cuando el menú se abre con teclado; disabled añade aria-disabled="true" y la saca de la navegación.

Estados open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Menu, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';

const VIEWS = [
  { value: 'list', label: 'List', icon: 'view_list', disabled: false },
  { value: 'grid', label: 'Grid', icon: 'grid_view', disabled: false },
  { value: 'timeline', label: 'Timeline (coming soon)', icon: 'view_timeline', disabled: true },
];

export default function Demo() {
  const menu = useMenu();
  const [view, setView] = useState('list');
  const current = VIEWS.find((v) => v.value === view) ?? VIEWS[0];
  return (
    <div className="demo-row">
      <Button variant="outlined" {...menu.triggerProps}>
        View: {current.label}
      </Button>
      <Menu {...menu.menuProps} onSelect={({ value }) => value && setView(value)}>
        {VIEWS.map((v) => (
          <MenuItem key={v.value} value={v.value} icon={v.icon} selected={v.value === view} disabled={v.disabled}>
            {v.label}
          </MenuItem>
        ))}
      </Menu>
    </div>
  );
}

Opciones marcables#

role="menuitemcheckbox" alterna aria-checked al hacer clic (checked + onCheckedChange, o defaultChecked). Los ítems role="menuitemradio" dentro de un MenuGroup con value/defaultValue funcionan como opción única; onSelect también recibe el nuevo estado checked. La marca solo se ve en las opciones marcadas.

Opciones marcables open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Menu, MenuDivider, MenuGroup, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';

export default function Demo() {
  const menu = useMenu();

  const [grid, setGrid] = useState(false);
  const [density, setDensity] = useState('Comfortable');
  return (
    <div className="demo-row">
      <Button variant="outlined" {...menu.triggerProps}>
        View
      </Button>
      <Menu {...menu.menuProps}>
        <MenuItem role="menuitemcheckbox" checked={ruler} onCheckedChange={setRuler}>
          Ruler
        </MenuItem>
        <MenuItem role="menuitemcheckbox" checked={grid} onCheckedChange={setGrid}>
          Grid
        </MenuItem>
        <MenuDivider />
        <MenuGroup label="Density" value={density} onChange={setDensity}>
          <MenuItem role="menuitemradio" value="Comfortable">
            Comfortable
          </MenuItem>
          <MenuItem role="menuitemradio" value="Compact">
            Compact
          </MenuItem>
        </MenuGroup>
      </Menu>
      <span className="demo-status" aria-live="polite">

      </span>
    </div>
  );
}

Posicionamiento#

El menú se abre bajo el ancla, alineado a su borde inicial (placement="bottom-start"); si no hay sitio voltea hacia arriba y, mientras la página se desplaza, conserva el lado elegido (lockSide). El alto se limita al espacio disponible y, en RTL, la alineación se refleja. matchWidth iguala el ancho del ancla; anchorEl puede ser cualquier elemento, una ref o un ancla virtual. Si el ancla sale de la vista el menú pide cerrarse con anchorHidden.

Posicionamiento open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Chip } from '@rubenchodev/materix-react/components/chip';
import { Menu, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';

const SORTS = ['Relevance', 'Newest', 'Price'];
const FILTERS = ['All', 'Active', 'Archived'];

export default function Demo() {
  const sort = useMenu();
  const top = useMenu();
  const [sortBy, setSortBy] = useState('Relevance');
  const chipRef = useRef<HTMLElement>(null);
  const [filterOpen, setFilterOpen] = useState(false);
  const [filter, setFilter] = useState('All');

  return (
    <div className="demo-row">
      <div className="demo-group">
        <span className="demo-label">matchWidth</span>
        <div className="demo-row">
          <Button variant="contained" {...sort.triggerProps}>
            Sort by: {sortBy.toLowerCase()}
          </Button>
          <Menu {...sort.menuProps} matchWidth onSelect={({ value }) => value && setSortBy(value)}>
            {SORTS.map((s) => (
              <MenuItem key={s} value={s} selected={s === sortBy}>
                {s}
              </MenuItem>
            ))}
          </Menu>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">placement=&quot;top-start&quot;</span>
        <div className="demo-row">
          <Button variant="outlined" {...top.triggerProps}>
            Open upwards
          </Button>
          <Menu {...top.menuProps} placement="top-start">
            <MenuItem>Above</MenuItem>
            <MenuItem>The trigger</MenuItem>
          </Menu>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">anchorEl = Chip</span>
        <div className="demo-row">
          <Chip
            ref={chipRef}
            variant="outlined"
            label={`Filter: ${filter.toLowerCase()}`}
            clickable
            aria-haspopup="menu"
            aria-expanded={filterOpen}
            aria-controls={filterOpen ? 'menu-anchor-chip' : undefined}
            onClick={() => setFilterOpen((v) => !v)}
          />
          <Menu
            id="menu-anchor-chip"
            open={filterOpen}
            anchorEl={chipRef}
            onClose={() => setFilterOpen(false)}
            onSelect={({ value }) => value && setFilter(value)}
          >
            {FILTERS.map((f) => (
              <MenuItem key={f} value={f} selected={f === filter}>
                {f}
              </MenuItem>
            ))}
          </Menu>
        </div>
      </div>
    </div>
  );
}

Submenús#

<Submenu label icon> pinta un ítem con aria-haspopup="menu" y un chevron que abre un menú anidado a su lado: con hover (tras 100 ms), con clic, o con →, Enter o Espacio. Pasar a otro ítem lo cierra a los 50 ms; ← o Escape lo cierran y devuelven el foco a su ítem. Elegir una opción cierra toda la cadena y llega al onSelect raíz. En RTL se abre hacia la izquierda, el chevron se refleja y las flechas se invierten; si no hay sitio, voltea al otro lado.

Menú contextual#

<ContextMenu target items> equivale a Materix.Menu.createContextMenu(selector, items): target es un elemento, una ref o un selector CSS (delegado en document, así que también sirven las áreas añadidas después); cada ítem acepta label, icon, image, shortcut, disabled, divider, action y submenu. Se abre con clic derecho en la posición del puntero (anchorPosition); con la tecla Menú o Mayús+F10 se ancla al área y enfoca la primera opción. Para un marcado propio, useContextMenu() devuelve onContextMenu y las props de un Menu.

Menú contextual open_in_new

  const custom = useContextMenu();

  return (
    <div className="demo-stack">
      <div ref={areaRef} className="demo-panel" tabIndex={0} role="region" aria-label="Context menu area">
        Right-click here (ContextMenu)
      </div>
      <ContextMenu
        target={areaRef}
        items={[
          { label: 'Copy', icon: 'content_copy', shortcut: '⌘C', action: () => write('Copy') },
          { label: 'Paste', icon: 'content_paste', disabled: true },
          { divider: true },
          {
            label: 'Share',
            icon: 'share',
            submenu: [
              { label: 'Email', icon: 'mail', action: () => write('Share → Email') },
              { label: 'Copy link', icon: 'link', action: () => write('Share → Copy link') },
            ],
          },
        ]}
      />
      <div
        className="demo-panel"
        tabIndex={0}
        role="region"
        aria-label="Custom context menu area"
        onContextMenu={custom.onContextMenu}
      >
        Right-click here (useContextMenu)
      </div>
      <Menu {...custom.menuProps} onSelect={({ value }) => value && write(`useContextMenu → ${value}`)}>
        <MenuItem icon="refresh" value="reload">
          Reload
        </MenuItem>
        <MenuItem icon="print" value="print">
          Print
        </MenuItem>
      </Menu>
      <pre className="demo-log" aria-live="polite">

      </pre>

Uso programático#

El equivalente de open()/close() es la prop open. onOpen, onSelect(detail, event) y onClose(event, reason) equivalen a mtx:menu:open, mtx:menu:select y mtx:menu:close. restoreFocusTo decide quién recibe el foco al cerrarse el menú.

Uso programático open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Menu, MenuItem } from '@rubenchodev/materix-react/components/menu';

export default function Demo() {
  const anchorRef = useRef<HTMLButtonElement>(null);
  const [open, setOpen] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 6));

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button ref={anchorRef} variant="outlined">
          Menu anchor
        </Button>
        <Button variant="contained" onClick={() => setOpen(true)}>
          setOpen(true)
        </Button>
        <Button variant="text" onClick={() => write(`open = ${open}`)}>
          Read open
        </Button>
      </div>
      <Menu
        open={open}
        anchorEl={anchorRef}
        restoreFocusTo={anchorRef}
        onOpen={() => write('onOpen')}
        onSelect={({ value }) => write(`onSelect → ${value}`)}
        onClose={(_event, reason) => {
          write(`onClose → ${reason}`);
          setOpen(false);
        }}
      >
        <MenuItem icon="save" value="save">
          Save
        </MenuItem>
        <MenuItem icon="file_download" value="export">
          Export
        </MenuItem>
      </Menu>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Composición completa#

Accesibilidad#

  • La lista tiene role="menu" y cada ítem role="menuitem" (o menuitemcheckbox / menuitemradio con aria-checked sincronizado) y tabindex="-1" (foco itinerante); los separadores, role="separator". useMenu da al disparador aria-haspopup="menu", aria-expanded, aria-controls (mientras está abierto) y etiqueta el menú con aria-labelledby.
  • Abierto con teclado, el foco va a la opción seleccionada o a la primera habilitada; con ratón, al contenedor del menú. Tras Escape o una elección, el foco vuelve al disparador; tras un clic fuera, se queda donde el usuario pulsó.
  • Los iconos generados son decorativos (aria-hidden). Da a los disparadores de solo icono un aria-label.
  • Escape se entrega mediante la pila de capas compartida: cierra solo el menú o submenú superior, nunca un diálogo inferior.
  • Con prefers-reduced-motion el menú aparece sin la animación Grow.
