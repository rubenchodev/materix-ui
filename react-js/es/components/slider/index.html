Slider

Permite elegir un valor o un rango arrastrando sobre una pista, construido sobre inputs range nativos accesibles.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Slider } from '@rubenchodev/materix-react';

Slider permite seleccionar un valor (o un rango) dentro de una escala continua o por pasos: volumen, brillo, filtros de precio, temperaturas. Como en MUI, cada thumb se apoya en un <input type="range"> nativo visualmente oculto, así que el teclado, los lectores de pantalla y el envío de formularios funcionan sin código extra. Para un número exacto que el usuario deba escribir, usa un campo de texto con type="number"; para pocas opciones discretas, usa Radio.

import '@rubenchodev/materix-ui/base.css';
import { Slider } from '@rubenchodev/materix-react';

<Slider aria-label="Volumen" name="volume" defaultValue={30} />

Uso básico#

Basta un elemento: el componente genera el rail, el track, el thumb con su input nativo y el value label. Dale nombre con aria-label (o aria-labelledby).

Uso básico open_in_new
import { Slider } from '@rubenchodev/materix-react/components/slider';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <Slider aria-label="Volume" name="volume" defaultValue={30} />
    </div>
  );
}

Etiqueta de valor#

El value label es un globo en forma de gota de Material Design 2. valueLabelDisplay es off (por defecto), auto (en hover, foco y arrastre) u on (siempre visible). valueLabelFormat acepta una plantilla con {value} (el número localizado, que también se usa como aria-valuetext) o una función (value, index) => ReactNode; getAriaValueText define un texto hablado distinto.

Etiqueta de valor open_in_new
import { Slider } from '@rubenchodev/materix-react/components/slider';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <div className="demo-group">
        <span className="demo-label">Auto (hover, focus and drag)</span>
        <div className="mtx-pt-5">
          <Slider aria-label="Auto label" defaultValue={30} valueLabelDisplay="auto" />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Always on, template format</span>
        <div className="mtx-pt-5">
          <Slider aria-label="Temperature" min={-10} max={40} defaultValue={21} valueLabelDisplay="on" valueLabelFormat="{value} °C" />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Function format and getAriaValueText</span>
        <div className="mtx-pt-5">
          <Slider
            aria-label="Storage"
            min={0}
            max={10}
            defaultValue={4}
            valueLabelDisplay="on"
            valueLabelFormat={(value) => `${2 ** value}G`}
            getAriaValueText={(value) => `${2 ** value} gigabytes`}
          />
        </div>
      </div>
    </div>
  );
}

Marcas#

marks (booleano) añade una marca en cada step; un array [{ value, label }] añade marcas con etiqueta (que puede ser cualquier nodo), y también funciona la sintaxis de vanilla "0:0 °C,20:20 °C". Con step={null} el valor solo puede caer en una marca.

Etiquetas de marcas en los extremos#

Cada etiqueta se centra sobre su marca, por lo que las de min y max sobresalen del rail la mitad de su ancho. En contenedores estrechos añade marksInset: la primera etiqueta se alinea al inicio del rail y la última al final (abajo/arriba en vertical, en espejo en RTL).

Rango#

Un valor array (defaultValue={[20, 60]}) o range crea dos thumbs, cada uno con su input nativo llamado {name}-start y {name}-end y etiquetado «Mínimo» / «Máximo» (con el prefijo de aria-label o del texto de aria-labelledby). Cuando los thumbs se cruzan se intercambian, como en MUI; disableSwap los bloquea y minDistance impone una distancia mínima.

Ejemplos reales#

Un filtro de precio controlado que actualiza un resumen mientras se arrastra y envía los dos inputs nativos.

Casos de uso open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Slider } from '@rubenchodev/materix-react/components/slider';
import type { SliderValue } from '@rubenchodev/materix-react/components/slider';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [price, setPrice] = useState<SliderValue>([200, 700]);
  const [status, setStatus] = useState('');
  const [low, high] = price as number[];

  const submit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const data = new FormData(event.currentTarget);
    setStatus(`Applied: price-start=${data.get('price-start')}, price-end=${data.get('price-end')}`);
  };

  return (
    <form className="demo-stack demo-wide" aria-label="Product filter" onSubmit={submit}>
      <Typography variant="subtitle2" component="span" id="slider-filter-label">
        Price (USD)
      </Typography>
      <Slider
        name="price"
        min={0}
        max={1000}
        step={10}
        value={price}
        minDistance={50}
        valueLabelDisplay="auto"
        valueLabelFormat="${value}"
        aria-labelledby="slider-filter-label"
        onChange={(_, value) => setPrice(value)}
      />
      <Stack direction="row" spacing={2} alignItems="center">
        <Typography variant="body2" component="span" aria-live="polite">
          ${low} – ${high}
        </Typography>
        <Button variant="contained" type="submit">
          Apply filter
        </Button>
      </Stack>
      {status ? (
        <Typography variant="body2" color="text-secondary">
          {status}
        </Typography>
      ) : null}
    </form>
  );
}

Uso controlado#

Con value + onChange el estado lo gestiona el padre. onChange se dispara durante el arrastre o con el teclado y onChangeCommitted al soltar el puntero (o tras un cambio con teclado). Los setters de vanilla (value, max, disable()) pasan a ser cambios de props y focus() usa inputRef.

Uso controlado open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Slider } from '@rubenchodev/materix-react/components/slider';
import type { SliderValue } from '@rubenchodev/materix-react/components/slider';

export default function Demo() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [value, setValue] = useState<SliderValue>(40);
  const [max, setMax] = useState(100);
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ['value = 75', () => setValue(75)],
    ['max = 200', () => setMax(200)],
    ['max = 100', () => setMax(100)],
    ['disabled = true', () => setDisabled(true)],
    ['disabled = false', () => setDisabled(false)],
    ['focus()', () => inputRef.current?.focus()],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-group demo-wide">
        <span className="demo-label">Controlled slider</span>
        <Slider
          aria-label="Controlled slider"
          inputRef={inputRef}
          value={value}
          max={max}
          disabled={disabled}
          valueLabelDisplay="auto"
          onChange={(_, next) => {
            setValue(next);
            write(`onChange → ${String(next)}`);
          }}
          onChangeCommitted={(_, next) => write(`onChangeCommitted → ${String(next)}`)}
        />
        <span className="demo-status">
          value: {String(value)} · max: {max} · disabled: {String(disabled)}
        </span>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          {actions.map(([label, run]) => (
            <Button
              key={label}
              variant="outlined"
              size="small"
              onClick={() => {
                run();
                write(label);
              }}
            >
              {label}
            </Button>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

Accesibilidad#

  • Cada thumb es un <input type="range"> nativo: el navegador expone role="slider", aria-valuemin, aria-valuemax y aria-valuenow. Con valueLabelFormat o getAriaValueText el componente añade aria-valuetext («21 °C»).
  • En rango cada thumb recibe un nombre traducido: «Precio: Mínimo» / «Precio: Máximo» («Price: Minimum» / «Price: Maximum» en inglés).
  • Los sliders verticales usan aria-orientation="vertical". El value label y las marcas son decorativos (aria-hidden).
  • El indicador de foco es el halo de 8px alrededor del thumb; las animaciones se desactivan con prefers-reduced-motion.
