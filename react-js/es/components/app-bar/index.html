App Bar

Barra superior con el título, la navegación y las acciones principales de la pantalla actual.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { AppBar, Toolbar, ToolbarTitle, ToolbarOffset } from '@rubenchodev/materix-react';

AppBar es la barra superior de la aplicación: muestra el título de la pantalla, el botón de navegación y las acciones más frecuentes dentro de una Toolbar. Úsala una vez por pantalla como cabecera. Para cambiar entre vistas del mismo nivel usa Tabs, para la navegación principal combínala con un Drawer y para una acción principal flotante usa un Fab.

import { AppBar, Toolbar } from '@rubenchodev/materix-react';
// o solo este componente:
import { AppBar, Toolbar } from '@rubenchodev/materix-react/components/app-bar';

Uso básico#

title, startIcon y endIcon generan la Toolbar, el título y los IconButton (el equivalente de la sintaxis simplificada vanilla). Los hijos se colocan tras el título. La barra es fixed por defecto; estas demos usan position="static" para que quede dentro de la página.

Uso básico open_in_new
import { AppBar } from '@rubenchodev/materix-react/components/app-bar';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  return (
    <div className="demo-stack">
      <AppBar position="static" color="primary" title="News" startIcon="menu">
        <Button variant="text">Login</Button>
      </AppBar>
    </div>
  );
}

Colores#

color admite primary, secondary, default (superficie paper; el valor por defecto), transparent e inherit. elevation cambia la sombra (4 por defecto); se escribe en la variable --mtx-app-bar-shadow para que transparent y --flat puedan anularla. Con elevation={0} la barra recibe mtx-app-bar--flat y, en default, un único divisor inferior en lugar de la sombra.

      </div>

}

Con y sin iconos#

startIcon añade el botón de navegación (.mtx-toolbar__navigation-icon) y endIcon una acción final; ambos aceptan un nombre de Material Icons o un nodo. Sus nombres accesibles se fijan con startIconLabel y endIconLabel; sin ellos, el icono menu (o cualquier icono inicial con navigationControls) se etiqueta “Open navigation” desde el diccionario i18n (appBar.openNavigation) y los demás usan su nombre. Para varias acciones escríbelas como hijos y marca el título con ToolbarTitle. Dentro de la Toolbar, los Button text y outlined y los IconButton heredan el color de la barra; los contained conservan sus colores.

Posición#

position define cómo se comporta la barra al desplazar la página.

ValorComportamiento
fixed (por defecto)Fija arriba del viewport (z-index de app bar). Empieza el contenido con <ToolbarOffset /> para reservar su altura (56px, 64px desde 600px; dense 48px).
stickyFluye con el contenido y se pega arriba al alcanzarlo.
staticForma parte del flujo normal; se desplaza con la página.
absoluteAnclada arriba del ancestro posicionado; con bottom, abajo.
relativePosición relativa, sin anclaje.

clipped eleva el z-index por encima de un Drawer recortado. Cuando la página tiene una barra fixed o sticky, el CSS añade scroll-padding-top a <html> para que los destinos #ancla no queden ocultos bajo ella (ajústalo con --mtx-scroll-padding-top). En la demo, la barra fixed queda contenida por un transform en su marco; en una página real queda fija a la ventana.

Menú y búsqueda#

Las acciones abren un Menu con useMenu() (el equivalente de data-open-menu en vanilla). Para buscar, usa el patrón .mtx-app-bar-search (40px de alto, con los modificadores --grow, --right, --centered y --compact) o un TextField con variant="no-label" y size="small", que puede encogerse dentro de la Toolbar. Su relleno, texto y placeholder derivan del color de la barra, así que conservan el contraste en primary, secondary, default y en el tema oscuro. Envuelve el patrón con role="search" y da al input un aria-label.

Scroll#

elevateOnScroll empieza sin sombra y aplica la elevación al desplazarse; hideOnScroll oculta la barra al bajar (más de 50px) y la muestra al subir. Por defecto se observa la ventana; scrollTarget acepta una ref, un elemento, una función o un selector CSS del contenedor con scroll. El cálculo se hace una vez por frame y el frame pendiente se cancela al desmontar.

Con Drawer#

En vanilla, data-drawer="id" convierte el botón de navegación en disparador de un Drawer. En React, onNavigationClick abre el Drawer y navigationControls / navigationExpanded mantienen sincronizados aria-controls y aria-expanded. Para el app shell completo (barra fija + Drawer responsive recortado + ToolbarOffset), consulta la página de Drawer.

Uso programático#

Los métodos setColor() y setPosition() de vanilla pasan a ser las props color y position; cualquier cambio es un nuevo render. La barra vanilla no emite eventos.

Uso programático open_in_new
import { useState } from 'react';
import { AppBar } from '@rubenchodev/materix-react/components/app-bar';
import type { AppBarColor, AppBarPosition } from '@rubenchodev/materix-react/components/app-bar';
import { Button } from '@rubenchodev/materix-react/components/button';

const colors: AppBarColor[] = ['primary', 'secondary', 'default', 'transparent'];
const positions: AppBarPosition[] = ['static', 'relative'];
const elevations = [0, 4, 8, 16];

/**
 * Grupo de botones de opción exclusiva.
 * @param {object} props Etiqueta, opciones, valor y callback.
 * @returns {JSX.Element} Grupo.
 */
function Options<T extends string | number>({ label, options, value, onChange }: { label: string; options: T[]; value: T; onChange: (next: T) => void }) {
  return (
    <div className="demo-row" role="group" aria-label={label}>
      {options.map((option) => (
        <Button key={option} variant={option === value ? 'contained' : 'outlined'} aria-pressed={option === value} onClick={() => onChange(option)}>
          {`${label.toLowerCase()} ${option}`}
        </Button>
      ))}
    </div>
  );
}

export default function Demo() {
  const [color, setColor] = useState<AppBarColor>('primary');
  const [position, setPosition] = useState<AppBarPosition>('static');
  const [elevation, setElevation] = useState(4);
  return (
    <div className="demo-stack">
      <AppBar position={position} color={color} elevation={elevation} title={`${color} · ${position} · elevation ${elevation}`} />
      <Options label="Color" options={colors} value={color} onChange={setColor} />
      <Options label="Position" options={positions} value={position} onChange={setPosition} />
      <Options label="Elevation" options={elevations} value={elevation} onChange={setElevation} />
    </div>
  );
}

Composición con Toolbar#

Si los hijos incluyen una Toolbar, no se genera ninguna (el equivalente de la sintaxis BEM completa vanilla): úsalo para varias Toolbar, barras prominent o el control total del contenido.

Composición con Toolbar open_in_new
import { AppBar, Toolbar, ToolbarTitle } from '@rubenchodev/materix-react/components/app-bar';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  return (
    <div className="demo-stack">
      <AppBar position="static" color="primary">
        <Toolbar variant="prominent">
          <IconButton className="mtx-toolbar__navigation-icon" icon="menu" aria-label="Open navigation" />
          <ToolbarTitle>Prominent title</ToolbarTitle>
          <IconButton icon="search" aria-label="Search" />
        </Toolbar>
      </AppBar>
      <AppBar position="static" color="secondary">
        <Toolbar variant="dense">
          <ToolbarTitle>First toolbar</ToolbarTitle>
        </Toolbar>
        <Toolbar variant="dense">
          <ToolbarTitle>Second toolbar</ToolbarTitle>
          <IconButton icon="filter_list" aria-label="Filter" />
        </Toolbar>
      </AppBar>
    </div>
  );
}

Clases y variables CSS#

Las mismas que la librería vanilla: mtx-app-bar (--fixed, --sticky, --static, --absolute, --relative, --primary, --secondary, --default, --transparent, --inherit, --flat, --bottom, --clipped, --hidden, --animated), mtx-toolbar (--dense, --prominent, --disable-gutters, __navigation-icon, __title, __spacer), mtx-toolbar-offset (--dense) y mtx-app-bar-search (--grow, --right, --centered, --compact). --animated se añade tras el primer frame pintado para que el color y la elevación iniciales no se animen. Variables: --mtx-app-bar-shadow, --mtx-app-bar-height, --mtx-scroll-padding-top, --mtx-app-bar-search-max-width, --mtx-z-index-app-bar y --mtx-toolbar-action-gap.

Accesibilidad#

  • La raíz es un <header>: es el landmark banner cuando está en el nivel superior de la página.
  • Los IconButton generados siempre tienen aria-label (startIconLabel/endIconLabel, el “Open navigation” de i18n o el nombre del icono) y sus iconos son aria-hidden. Fija etiquetas explícitas para iconos cuyo nombre no sea significativo.
  • Con navigationControls, el botón de navegación expone aria-controls y el aria-expanded que pases en navigationExpanded.
  • Agrupa los enlaces de navegación en un <nav aria-label="…">. Las transiciones siguen las duraciones de los tokens y se desactivan con prefers-reduced-motion; con hideOnScroll la barra reaparece al subir.
