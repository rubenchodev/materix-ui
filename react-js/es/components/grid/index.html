Grid

Grilla flexbox de 12 columnas con cinco breakpoints (xs–xl), separación con gap en múltiplos de 8px (también por breakpoint) y alineación, para páginas responsivas.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Grid } from '@rubenchodev/materix-react';

Grid reparte el ancho disponible en 12 columnas y deja que cada ítem declare cuántas ocupa en cada breakpoint, igual que el Grid de MUI (v2: flexbox con gap, sin márgenes negativos). Úsalo para maquetar páginas, formularios y paneles que cambian de columnas según el ancho de pantalla. Para apilar elementos en una sola dirección con una separación fija no necesitas una grilla: usa Stack; para centrar y limitar el ancho de la página, Container.

import { Grid } from '@rubenchodev/materix-react';
// o solo este componente
import { Grid } from '@rubenchodev/materix-react/components/grid';

Uso básico#

Un <Grid container> con spacing e ítems con columnas por breakpoint mediante size (API de MUI Grid v2). Redimensiona la ventana: 1 columna en móvil, 2 en tablet y 4 en escritorio.

Uso básico open_in_new
import './demo.css';
import { Grid } from '@rubenchodev/materix-react/components/grid';

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {[1, 2, 3, 4].map((n) => (
        <Grid key={n} size={{ xs: 12, sm: 6, md: 3 }}>
          <div className="demo-grid-item">xs=12 sm=6 md=3</div>
        </Grid>
      ))}
    </Grid>
  );
}

Un Grid sin container ni tamaño actúa como contenedor (igual que en vanilla) y un Grid con tamaño es un ítem. Los tamaños se escriben como size={{ xs: 12, md: 6 }}, como array size={[12, 6]} (desde xs) o con las props sueltas xs, sm, md, lg, xl (los atributos data-xs… de vanilla); las props sueltas prevalecen sobre size.

Columnas#

Cada ítem ocupa n/12 del ancho. Cuando la suma supera 12, los siguientes ítems saltan a una nueva línea.

Columnas open_in_new
import './demo.css';
import { Grid, type GridSize } from '@rubenchodev/materix-react/components/grid';

const rows: Array<[GridSize, boolean]> = [
  [12, false],
  [6, false],
  [6, false],
  [4, false],
  [4, false],
  [4, false],
  [3, false],
  [3, false],
  [3, false],
  [3, false],
  [8, true],
  [4, true],
];
const pairs = Array.from({ length: 11 }, (_, i) => i + 1) as GridSize[];

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">12 · 6+6 · 4+4+4 · 3×4 · 8+4</span>
        <Grid container spacing={1}>
          {rows.map(([size, isAlt], i) => (
            <Grid key={i} size={size}>
              <div className={isAlt ? 'demo-grid-item demo-grid-item--alt' : 'demo-grid-item'}>{String(size)}</div>
            </Grid>
          ))}
        </Grid>
      </div>
      <div className="demo-group">
        <span className="demo-label">Parejas que suman 12: n + (12 − n)</span>
        <Grid container spacing={1}>
          {pairs.flatMap((n) => [
            <Grid key={`a${String(n)}`} size={n}>
              <div className="demo-grid-item">{String(n)}</div>
            </Grid>,
            <Grid key={`b${String(n)}`} size={(12 - Number(n)) as GridSize}>
              <div className="demo-grid-item demo-grid-item--alt">{12 - Number(n)}</div>
            </Grid>,
          ])}
        </Grid>
      </div>
    </div>
  );
}

Breakpoints#

Mobile-first: cada valor aplica desde su ancho mínimo hacia arriba. xs 0px · sm 600px · md 900px · lg 1200px · xl 1536px. Declara siempre xs como base.

Espaciado#

spacing={n} separa filas y columnas n × 8px con gap de CSS, como MUI Grid v2. No hay márgenes negativos ni rellenos en los ítems, así que la grilla nunca desborda a su padre ni necesita un envoltorio con overflow: hidden. El ancho de cada columna descuenta su parte proporcional del gap (100% · n/12 − gap · (12 − n)/12), de modo que 12 columnas siempre suman el 100%.

Vale cualquier entero de 0 a 12 y los medios pasos 0.5, 1.5 y 2.5 (4, 12 y 20px). Los valores fuera de la escala se ignoran con un aviso en desarrollo. El espaciado solo se aplica a contenedores.

Espaciado open_in_new
import './demo.css';
import { Grid, type GridSpacing } from '@rubenchodev/materix-react/components/grid';

const values: GridSpacing[] = [0, 0.5, 1, 1.5, 2, 2.5, 3, 4, 5, 6, 7, 8, 10, 12];

export default function Demo() {
  return (
    <div className="demo-stack">
      {values.map((spacing) => (
        <div className="demo-group" key={spacing}>
          <span className="demo-label">
            spacing={'{'}
            {spacing}
            {'}'} · {Number(spacing) * 8}px
          </span>
          <Grid container spacing={spacing}>
            {[1, 2, 3].map((n) => (
              <Grid key={n} size={4}>
                <div className="demo-grid-item">{spacing}</div>
              </Grid>
            ))}
          </Grid>
        </div>
      ))}
    </div>
  );
}

Auto-layout#

size="grow" (o true, por ejemplo xs como prop booleana) hace que el ítem crezca y reparta el espacio libre con los demás ítems que crecen. size="auto" ajusta el ítem al ancho de su contenido (flex: 0 0 auto).

Alineación y dirección#

justifyContent distribuye los ítems en horizontal (flex-start, center, flex-end, space-between, space-around, space-evenly) y alignItems los alinea en vertical (flex-start, center, flex-end, stretch, baseline). También se aceptan los alias cortos start, end, between, around y evenly.

Alineación open_in_new
import './demo.css';
import { Grid, type GridAlign, type GridJustify } from '@rubenchodev/materix-react/components/grid';

const justify: GridJustify[] = ['flex-start', 'center', 'flex-end', 'space-between', 'space-around', 'space-evenly'];
const align: GridAlign[] = ['flex-start', 'center', 'flex-end', 'stretch'];

export default function Demo() {
  return (
    <div className="demo-stack">
      {justify.map((value) => (
        <div className="demo-group" key={value}>
          <span className="demo-label">justifyContent=&quot;{value}&quot;</span>
          <Grid container spacing={2} justifyContent={value}>
            <Grid size={3}>
              <div className="demo-grid-item">{value}</div>
            </Grid>
            <Grid size={3}>
              <div className="demo-grid-item">{value}</div>
            </Grid>
          </Grid>
        </div>
      ))}
      {align.map((value) => (
        <div className="demo-group" key={value}>
          <span className="demo-label">alignItems=&quot;{value}&quot;</span>
          <Grid container spacing={2} alignItems={value}>
            <Grid size={4}>
              <div className="demo-grid-item">bajo</div>
            </Grid>
            <Grid size={4}>
              <div className="demo-grid-item demo-grid-item--tall demo-grid-item--alt">alto</div>
            </Grid>
            <Grid size={4}>
              <div className="demo-grid-item">bajo</div>
            </Grid>
          </Grid>
        </div>
      ))}
    </div>
  );
}

Props controladas#

En vanilla, setSpacing(n, bp?), setRowSpacing(), setColumnSpacing(), setJustifyContent(), setAlignItems() y setDirection() sustituyen clases y los ítems nuevos se registran con Materix.init(). En React las props son la API y los ítems nuevos son simplemente nuevos hijos.

Props controladas open_in_new
import { useEffect, useRef, useState } from 'react';
import './demo.css';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Grid, type GridJustify, type GridSpacing } from '@rubenchodev/materix-react/components/grid';

export default function Demo() {
  const [spacing, setSpacing] = useState<GridSpacing>(2);
  const [justify, setJustify] = useState<GridJustify>('flex-start');
  const [reversed, setReversed] = useState(false);
  const [count, setCount] = useState(3);
  const [log, setLog] = useState<string[]>([]);
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const classes = Array.from(ref.current?.classList ?? []).filter((c) => c.startsWith('mtx-grid--'));
    setLog((lines) => [...lines.slice(-5), `ítems=${count} → ${classes.join(' ')}`]);
  }, [spacing, justify, reversed, count]);

  return (
    <div className="demo-stack">
      <div className="demo-row">
        {([0, 2, 4] as GridSpacing[]).map((value) => (
          <Button key={value} variant="outlined" onClick={() => setSpacing(value)}>
            spacing {value}
          </Button>
        ))}
        <Button variant="outlined" onClick={() => setJustify('center')}>
          justify center
        </Button>
        <Button variant="outlined" onClick={() => setJustify('flex-start')}>
          justify flex-start
        </Button>
        <Button variant="outlined" aria-pressed={reversed} onClick={() => setReversed((r) => !r)}>
          direction reverse
        </Button>
        <Button variant="contained" onClick={() => setCount((c) => c + 1)}>
          Añadir ítem
        </Button>
      </div>
      <Grid ref={ref} container spacing={spacing} justifyContent={justify} direction={reversed ? 'row-reverse' : 'row'}>
        {Array.from({ length: count }, (_, i) => (
          <Grid key={i} size={{ xs: 6, md: 3 }}>
            <div className="demo-grid-item">{i + 1}</div>
          </Grid>
        ))}
      </Grid>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Referencia de API#

Props#

PropTipoPor defectoDescripción
containerbooleanfalseContenedor flex de 12 columnas. Sin container ni tamaño, Grid actúa como contenedor.
itembooleanfalseFuerza el papel de ítem sin tamaño.
sizeGridResponsive<GridSize>—Columnas por breakpoint (MUI Grid v2).
xs, sm, md, lg, xlGridSize—Columnas desde ese breakpoint (prevalecen sobre size).
spacingGridResponsive<GridSpacing>—Separación de filas y columnas × 8px (solo contenedores).
rowSpacingGridResponsive<GridSpacing>—Separación entre filas × 8px.
columnSpacingGridResponsive<GridSpacing>—Separación entre columnas × 8px.
direction'row' | 'column' | 'row-reverse' | 'column-reverse'— (row)Dirección flex.
wrap'wrap' | 'nowrap' | 'wrap-reverse'— (wrap)Ajuste de línea.
justifyContent'flex-start' | 'center' | 'flex-end' | 'space-between' | 'space-around' | 'space-evenly'—Distribución horizontal.
alignItems'flex-start' | 'center' | 'flex-end' | 'stretch' | 'baseline'—Alineación vertical.
componentElementType'div'Elemento o componente raíz.
classNamestring—Se concatena con las clases del componente.
refRef<HTMLElement>—Apunta al elemento raíz.

GridSize es 1–12, true / 'grow' o 'auto'. GridSpacing es 0–12, 0.5, 1.5 o 2.5. GridResponsive<T> es T, { xs?, sm?, md?, lg?, xl? } o un array desde xs. Cualquier otra prop se reenvía al elemento raíz. También se exportan los normalizadores normalizeGridSize() y normalizeGridSpacing().

Variables CSS#

VariableUso
--mtx-spacing-unitUnidad de espaciado (8px).

Accesibilidad#

  • La grilla es puramente visual: no añade roles ni cambia la semántica. Usa elementos con significado (component="main", "section", "form") para los bloques que maquetas.
  • El orden de lectura y de tabulación sigue al JSX, no a la posición visual. Con direction="row-reverse" o column-reverse el orden visual se invierte pero el del teclado no: úsalos solo cuando el orden no importe.
  • Comprueba que el contenido siga siendo legible a 320px de ancho (WCAG 1.4.10): define siempre xs para que las columnas se apilen en móvil.
