Container

Centra el contenido de la página con un ancho máximo por breakpoint y márgenes laterales responsive (16px en móvil, 24px desde 600px).

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Container } from '@rubenchodev/materix-react';

Container es el bloque de maquetación más básico: centra su contenido en horizontal, lo limita a un ancho máximo y añade un relleno lateral (gutters) que crece con la pantalla, igual que el Container de MUI. Úsalo para envolver <main>, secciones de una landing o una barra de herramientas. Para repartir columnas dentro usa Grid; para apilar bloques, Stack.

import { Container } from '@rubenchodev/materix-react';
// o solo este componente
import { Container } from '@rubenchodev/materix-react/components/container';

Uso básico#

Un único <Container>. Sin maxWidth el tope es lg (1200px), como en MUI. La zona sombreada es el contenedor; la franja interior, sus gutters.

Uso básico open_in_new
import './demo.css';
import { Container } from '@rubenchodev/materix-react/components/container';

export const description = {
  en: 'A single `<Container>`. Without `maxWidth` the cap is `lg` (1200px), as in MUI. The shaded area is the container; the inner strip, its gutters.',
  es: 'Un único `<Container>`. Sin `maxWidth` el tope es `lg` (1200px), como en MUI. La zona sombreada es el contenedor; la franja interior, sus gutters.',
};

export default function Demo() {
  return (
    <div className="demo-container-frame">
      <Container>
        <div className="demo-container-box">Centered content · max. 1200px</div>
      </Container>
    </div>
  );
}

Ancho máximo#

maxWidth fija el tope: xs 444px, sm 600px, md 900px, lg 1200px, xl 1536px o false para ocupar todo el ancho.

Ancho máximo open_in_new
import './demo.css';
import { Container, type ContainerMaxWidth } from '@rubenchodev/materix-react/components/container';

export const description = {
  en: '`maxWidth` sets the cap: `xs` 444px, `sm` 600px, `md` 900px, `lg` 1200px, `xl` 1536px or `false` to take the full width.',
  es: '`maxWidth` fija el tope: `xs` 444px, `sm` 600px, `md` 900px, `lg` 1200px, `xl` 1536px o `false` para ocupar todo el ancho.',
};

const options: Array<{ value: ContainerMaxWidth; label: string }> = [
  { value: 'xs', label: 'maxWidth="xs" · 444px' },
  { value: 'sm', label: 'maxWidth="sm" · 600px' },
  { value: 'md', label: 'maxWidth="md" · 900px' },
  { value: 'lg', label: 'maxWidth="lg" · 1200px (default)' },
  { value: false, label: 'maxWidth={false} · fluid' },
];

export default function Demo() {
  return (
    <div className="demo-stack">
      {options.map(({ value, label }) => (
        <div className="demo-group" key={String(value)}>
          <span className="demo-label">{label}</span>
          <div className="demo-container-frame">
            <Container maxWidth={value}>
              <div className="demo-container-box">{String(value)}</div>
            </Container>
          </div>
        </div>
      ))}
    </div>
  );
}

Ancho fijo#

fixed hace que el ancho máximo salte al mínimo de cada breakpoint (600, 900, 1200, 1536px) en lugar de crecer de forma fluida. Útil cuando el diseño apunta a anchos concretos. Redimensiona la ventana para verlo.

Ancho fijo open_in_new
import './demo.css';
import { Container } from '@rubenchodev/materix-react/components/container';

export const description = {
  en: '`fixed` makes the max width jump to the minimum of each breakpoint (600, 900, 1200, 1536px) instead of growing fluidly. Useful when the design targets specific widths. Resize the window to see it.',
  es: '`fixed` hace que el ancho máximo salte al mínimo de cada breakpoint (600, 900, 1200, 1536px) en lugar de crecer de forma fluida. Útil cuando el diseño apunta a anchos concretos. Redimensiona la ventana para verlo.',
};

export default function Demo() {
  return (
    <div className="demo-container-frame">
      <Container fixed>
        <div className="demo-container-box">fixed</div>
      </Container>
    </div>
  );
}

Márgenes laterales#

Por defecto el contenedor añade 16px de relleno lateral en móvil y 24px desde 600px. disableGutters los elimina, por ejemplo para que una imagen o una tabla toque los bordes.

Márgenes laterales open_in_new
import './demo.css';
import { Container } from '@rubenchodev/materix-react/components/container';

export const description = {
  en: 'By default the container adds 16px of side padding on mobile and 24px from 600px. `disableGutters` removes them, for example to make an image or a table touch the edges.',
  es: 'Por defecto el contenedor añade 16px de relleno lateral en móvil y 24px desde 600px. `disableGutters` los elimina, por ejemplo para que una imagen o una tabla toque los bordes.',
};

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">With gutters</span>
        <div className="demo-container-frame">
          <Container maxWidth="sm">
            <div className="demo-container-box">16px / 24px on each side</div>
          </Container>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">disableGutters</span>
        <div className="demo-container-frame">
          <Container maxWidth="sm" disableGutters>
            <div className="demo-container-box">No side padding</div>
          </Container>
        </div>
      </div>
    </div>
  );
}

Grilla#

Container limita el ancho y Grid reparte las columnas dentro. No hace falta un envoltorio con overflow: Grid separa los ítems con gap.

Grilla open_in_new
import './demo.css';
import { Container } from '@rubenchodev/materix-react/components/container';
import { Grid } from '@rubenchodev/materix-react/components/grid';

export const description = {
  en: 'Container bounds the width and Grid splits the columns inside it. No wrapper with `overflow` is needed: Grid spaces items with `gap`.',
  es: 'Container limita el ancho y Grid reparte las columnas dentro. No hace falta un envoltorio con `overflow`: Grid separa los ítems con `gap`.',
};

export default function Demo() {
  return (
    <div className="demo-container-frame">
      <Container maxWidth="md">
        <Grid container spacing={2}>
          <Grid size={{ xs: 12, sm: 6, md: 4 }}>
            <div className="demo-container-box">xs=12 sm=6 md=4</div>
          </Grid>
          <Grid size={{ xs: 12, sm: 6, md: 4 }}>
            <div className="demo-container-box">xs=12 sm=6 md=4</div>
          </Grid>
          <Grid size={{ xs: 12, md: 4 }}>
            <div className="demo-container-box">xs=12 md=4</div>
          </Grid>
        </Grid>
      </Container>
    </div>
  );
}

Props controladas#

En vanilla, setMaxWidth(), setGutters() y setFixed() cambian las clases de un elemento existente. En React las props son la API: cámbialas desde el estado y el componente se vuelve a renderizar con las clases correspondientes.

Props controladas open_in_new
import { useEffect, useRef, useState } from 'react';
import './demo.css';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Container, type ContainerMaxWidth } from '@rubenchodev/materix-react/components/container';

export const description = {
  en: 'The vanilla `setMaxWidth()`, `setFixed()` and `setGutters()` become props driven by state. Container emits no events: the log shows the resulting classes.',
  es: 'Los `setMaxWidth()`, `setFixed()` y `setGutters()` de vanilla pasan a ser props controladas por el estado. Container no emite eventos: el registro muestra las clases resultantes.',
};

const sizes: ContainerMaxWidth[] = ['xs', 'sm', 'md', false];

export default function Demo() {
  const [maxWidth, setMaxWidth] = useState<ContainerMaxWidth>('sm');
  const [gutters, setGutters] = useState(true);
  const [fixed, setFixed] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const classes = ref.current?.className ?? '';
    setLog((lines) => [...lines.slice(-5), `maxWidth=${String(maxWidth)} gutters=${gutters} fixed=${fixed} → ${classes}`]);
  }, [maxWidth, gutters, fixed]);

  return (
    <div className="demo-stack">
      <div className="demo-row">
        {sizes.map((value) => (
          <Button
            key={String(value)}
            variant={maxWidth === value ? 'contained' : 'outlined'}
            aria-pressed={maxWidth === value}
            onClick={() => setMaxWidth(value)}
          >
            {String(value)}
          </Button>
        ))}
        <Button variant="outlined" aria-pressed={!gutters} onClick={() => setGutters((g) => !g)}>
          Toggle gutters
        </Button>
        <Button variant="outlined" aria-pressed={fixed} onClick={() => setFixed((f) => !f)}>
          Toggle fixed
        </Button>
      </div>
      <div className="demo-container-frame">
        <Container ref={ref} maxWidth={maxWidth} disableGutters={!gutters} fixed={fixed}>
          <div className="demo-container-box">Container controlled by React state</div>
        </Container>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Sintaxis BEM completa#

Las clases funcionan sin el componente (por ejemplo, en marcado generado en el servidor).

Uso manual BEM open_in_new
import '@rubenchodev/materix-ui/components/container.css';
import './demo.css';

export const description = {
  en: 'The classes work without the component.',
  es: 'Las clases funcionan sin el componente.',
};

export default function Demo() {
  return (
    <div className="demo-container-frame">
      <div className="mtx-container mtx-container--sm mtx-container--disable-gutters">
        <div className="demo-container-box">mtx-container mtx-container--sm mtx-container--disable-gutters</div>
      </div>
    </div>
  );
}

Referencia de API#

Props#

PropTipoPor defectoDescripción
maxWidth'xs' | 'sm' | 'md' | 'lg' | 'xl' | false— (lg en CSS)Tope de ancho. false ocupa todo el ancho (mtx-container--fluid).
fixedbooleanfalseEl ancho máximo salta al mínimo de cada breakpoint.
disableGuttersbooleanfalseQuita el relleno lateral de 16px / 24px.
componentElementType'div'Elemento o componente raíz (main, section, article…).
classNamestring—Se concatena con las clases del componente.
refRef<HTMLElement>—Apunta al elemento raíz.

Cualquier otra prop (id, aria-*, data-*, eventos, style) se reenvía al elemento raíz.

Equivalencia con vanilla#

VanillaReact
data-mtx="container"<Container>
data-max-width="md"maxWidth="md"
data-max-width="false"maxWidth={false}
data-fixedfixed
data-disable-guttersdisableGutters
setMaxWidth(v), setFixed(b), setGutters(b)Cambia la prop correspondiente.

Clases CSS#

ClaseDescripción
mtx-containerBloque base: centrado, width: 100%, gutters.
mtx-container--{xs|sm|md|lg|xl}Tope de ancho.
mtx-container--fluidSin tope (maxWidth={false}).
mtx-container--fixedAncho fijo por breakpoint.
mtx-container--disable-guttersSin relleno lateral.

Callbacks#

Container no tiene eventos propios.

Variables CSS#

VariableUso
--mtx-container-maxTope de ancho actual (lo fijan los modificadores mtx-container--*).
--mtx-container-fixedAncho fijo del breakpoint actual.
--mtx-spacing-2, --mtx-spacing-3Gutters en móvil y desde 600px.

Accesibilidad#

  • Container es puramente visual: no añade roles. Usa component para renderizar el elemento semántico adecuado (<main>, <header>, <section>, <footer>) en lugar de añadir un <div> extra.
  • Los gutters evitan que el texto toque los bordes de la pantalla en móvil; no los desactives en bloques de texto.
  • Limitar el ancho de lectura (sm o md) mejora la legibilidad: líneas de 60–80 caracteres.
