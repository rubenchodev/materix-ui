Toggle Button

Los botones de alternancia agrupan opciones relacionadas con selección exclusiva o múltiple; solos funcionan como interruptor de una única acción.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { ToggleButton, ToggleButtonGroup } from '@rubenchodev/materix-react';

Toggle Button agrupa opciones relacionadas en un bloque de bordes unidos: alineación de texto, formato, vista de lista o cuadrícula. Un ToggleButtonGroup gestiona la selección exclusiva (como un radio) o múltiple (como casillas), y un ToggleButton independiente activa y desactiva una sola acción, como marcar un favorito. Para elegir entre muchas opciones usa un Select; para un ajuste que se aplica al instante, un Switch.

warning

aria-label obligatorio en botones de solo icono

Un botón sin texto visible necesita un aria-label (o aria-labelledby) que describa la opción: “Alinear a la izquierda”, no “flecha”. Nombra también el grupo con aria-label o label.

Importación#

import { ToggleButton, ToggleButtonGroup } from '@rubenchodev/materix-react';

Uso básico#

Un <ToggleButtonGroup> con hijos <ToggleButton>. Cada botón solo necesita value y, si es de solo icono, icon y aria-label; el grupo une sus bordes, gestiona aria-pressed y propaga por contexto su tamaño, color y estado deshabilitado.

Uso básico open_in_new

export const description = {
  en: "A `ToggleButtonGroup` with `ToggleButton` children: each button only needs `value` and, when icon-only, `icon` and `aria-label`. The group joins the borders and manages `aria-pressed`.",
  es: "Un `ToggleButtonGroup` con hijos `ToggleButton`: cada botón solo necesita `value` y, si es de solo icono, `icon` y `aria-label`. El grupo une los bordes y gestiona `aria-pressed`.",
};

export default function Demo() {
  return (
    <div className="demo-row">
      <ToggleButtonGroup exclusive defaultValue="left" aria-label="Text alignment">

        <ToggleButton value="center" icon="format_align_center" aria-label="Center" />

Selección exclusiva y múltiple#

Con exclusive solo un botón puede estar activo y el valor es un string (o null). Sin él la selección es múltiple (lo predeterminado en MUI) y el valor es un string[] en orden del DOM.

Ejemplo real#

La barra de un editor: formato múltiple y alineación exclusiva obligatoria, ambos controlados.

Ejemplo real: barra de un editor open_in_new
import { useState } from 'react';
import type { ReactNode } from 'react';
import { Paper } from '@rubenchodev/materix-react/components/paper';
import { ToggleButton, ToggleButtonGroup } from '@rubenchodev/materix-react/components/toggle-button';
import type { ToggleButtonGroupValue } from '@rubenchodev/materix-react/components/toggle-button';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export const description = {
  en: "Editor toolbar: multiple formatting plus required exclusive alignment, both controlled and applied to the text.",
  es: "Barra de un editor: formato múltiple y alineación exclusiva obligatoria, ambos controlados y aplicados al texto.",
};

type Align = 'left' | 'center' | 'right';

export default function Demo() {
  const [formats, setFormats] = useState<ToggleButtonGroupValue>(['bold']);
  const [align, setAlign] = useState<ToggleButtonGroupValue>('left');
  const list = Array.isArray(formats) ? formats : [];

  let text: ReactNode = 'The quick brown fox jumps over the lazy dog.';
  if (list.includes('underlined')) text = <u>{text}</u>;
  if (list.includes('italic')) text = <em>{text}</em>;
  if (list.includes('bold')) text = <strong>{text}</strong>;

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <ToggleButtonGroup size="small" value={formats} onChange={(_, next) => setFormats(next)} aria-label="Formatting">
          <ToggleButton value="bold" icon="format_bold" aria-label="Bold" />
          <ToggleButton value="italic" icon="format_italic" aria-label="Italic" />
          <ToggleButton value="underlined" icon="format_underlined" aria-label="Underline" />
        </ToggleButtonGroup>
        <ToggleButtonGroup
          exclusive
          enforceValueSet
          size="small"
          value={align}
          onChange={(_, next) => setAlign(next)}
          aria-label="Alignment"
        >
          <ToggleButton value="left" icon="format_align_left" aria-label="Left" />
          <ToggleButton value="center" icon="format_align_center" aria-label="Center" />
          <ToggleButton value="right" icon="format_align_right" aria-label="Right" />
        </ToggleButtonGroup>
      </div>
      <Paper variant="outlined" className="demo-panel">
        <Typography variant="body1" align={align as Align}>
          {text}
        </Typography>
      </Paper>
    </div>
  );
}

Uso programático#

El grupo se controla con value + onChange(event, value): escribir value desde código no dispara onChange, igual que el setter de vanilla.

Uso programático open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { ToggleButton, ToggleButtonGroup } from '@rubenchodev/materix-react/components/toggle-button';
import type { ToggleButtonGroupValue } from '@rubenchodev/materix-react/components/toggle-button';

export const description = {
  en: "Controlled `value` + `onChange`: setting `value` from code fires no `onChange`, and `disabled` toggles the whole group.",
  es: "`value` + `onChange` controlados: fijar `value` desde código no dispara `onChange`, y `disabled` alterna todo el grupo.",
};

export default function Demo() {
  const [value, setValue] = useState<ToggleButtonGroupValue>(['bold']);
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 6));

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <ToggleButtonGroup
          value={value}
          disabled={disabled}
          onChange={(_, next) => {
            setValue(next);
            write(`onChange → ${JSON.stringify(next)}`);
          }}
          aria-label="Formatting"
        >
          <ToggleButton value="bold" icon="format_bold" aria-label="Bold" />
          <ToggleButton value="italic" icon="format_italic" aria-label="Italic" />
          <ToggleButton value="underlined" icon="format_underlined" aria-label="Underline" />
        </ToggleButtonGroup>
      </div>
      <div className="demo-row">
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setValue(['italic', 'underlined']);
            write('value = ["italic","underlined"]');
          }}
        >
          Set italic + underline
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setDisabled(!disabled);
            write(`disabled = ${!disabled}`);
          }}
        >
          Toggle disabled
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accesibilidad#

  • Cada botón es un <button> nativo con aria-pressed (patrón toggle button de WAI-ARIA), también en modo exclusivo. Como en MUI, el grupo usa role="group" y no radiogroup: los botones conservan su semántica de botón, todos son tabulables y pueden deseleccionarse. Si necesitas semántica estricta de opción única, usa Radio.
  • Nombra el grupo con aria-label, aria-labelledby o label, y cada botón de solo icono con aria-label.
  • Los iconos llevan aria-hidden="true". Los botones deshabilitados usan el disabled nativo.
