Text Field

Campo de texto con label flotante, variantes MUI, iconos, contadores, máscaras de entrada y validación.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { TextField } from '@rubenchodev/materix-react';

TextField permite escribir y editar texto en formularios: nombre, correo, contraseña, importes o comentarios largos. Renderiza el mismo marcado que el componente vanilla tras inicializarse: el <label> flotante, el borde con muesca (NotchedOutline, un fieldset con legend), los iconos, el texto de ayuda y el contador, alrededor de un <input>, <textarea> o <select> nativo. Para elegir entre un conjunto cerrado de opciones usa Select o NativeSelect.

import '@rubenchodev/materix-ui/base.css';
import { TextField } from '@rubenchodev/materix-react';

<TextField label="Nombre completo" />

Uso básico#

Basta un elemento con label. Las props nativas (id, name, type, autoComplete, required, disabled, readOnly, maxLength, autoFocus…) van al control nativo; className, style y el resto de atributos van al <div> raíz. Sin label, el placeholder se usa como label (como en vanilla). multiline renderiza un <textarea>.

Uso básico open_in_new
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  return (
    <div className="demo-grid-3">
      <TextField label="Nombre completo" />
      <TextField placeholder="Correo (label desde el placeholder)" type="email" />
      <TextField label="Comentario" multiline rows={1} />
    </div>
  );
}

Variantes#

outlined (por defecto, con borde y muesca), filled (fondo y línea inferior) y standard (solo línea inferior). variant="no-label" dibuja un borde completo sin label ni muesca, para buscadores y filtros. Con select, el campo envuelve un <select> nativo (opciones como children) y añade un único chevron.

Con iconos#

startIcon y endIcon aceptan un nombre de Material Icons ("email"), una URL de imagen (se pinta como <img class="mtx-text-field__adornment--image">) o un nodo (SVG, Material Symbols). Con icono inicial, el label se traslada exactamente 32px para que su primera letra coincida con el texto escrito. startAdornment y endAdornment aceptan contenido libre, como un prefijo $ o un sufijo kg; como en MUI, un startAdornment libre mantiene el label flotando y alineado con el inicio del campo (el prefijo ocupa el lugar donde empezaría el texto), en las tres variantes, porque su ancho no es el de un icono de 24px.

Adornos interactivos#

El equivalente a InputAdornment + IconButton de MUI. passwordToggle (solo con type="password") añade el botón mostrar/ocultar con aria-pressed, aria-controls y nombre traducido, y llama a onPasswordVisibilityChange(visible); el estado puede controlarse con passwordVisible. startAction / endAction crean un IconButton con el icono indicado y llaman a onAdornmentClick({ position, button, input }); nómbralos con startActionLabel / endActionLabel. El clic con ratón no roba el foco del campo y los botones se deshabilitan junto con él.

Adornos interactivos open_in_new
import { useState } from 'react';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  const [search, setSearch] = useState('Materix');

  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((prev) => [`${new Date().toLocaleTimeString()}  ${text}`, ...prev].slice(0, 6));
  const onVisibility = (visible: boolean) => write(`onPasswordVisibilityChange → visible: ${visible}`);

  return (
    <div className="demo-stack">
      <div className="demo-grid-3">
        <div className="demo-group">
          <span className="demo-label">Contraseña · outlined</span>
          <TextField
            label="Contraseña"
            type="password"
            passwordToggle
            autoComplete="new-password"
            helperText="Al menos 8 caracteres"
            onPasswordVisibilityChange={onVisibility}
          />
        </div>
        <div className="demo-group">
          <span className="demo-label">Contraseña · filled + icono inicial</span>
          <TextField
            label="Contraseña"
            variant="filled"
            startIcon="lock"
            type="password"
            passwordToggle
            autoComplete="new-password"
            onPasswordVisibilityChange={onVisibility}
          />
        </div>
        <div className="demo-group">
          <span className="demo-label">Contraseña · small + contador</span>
          <TextField
            label="PIN"
            size="small"
            type="password"
            passwordToggle
            maxLength={6}
            inputMode="numeric"
            autoComplete="off"
            onPasswordVisibilityChange={onVisibility}
          />
        </div>
        <div className="demo-group">
          <span className="demo-label">Acción final · limpiar</span>
          <TextField
            label="Buscar"
            startIcon="search"
            endAction="close"
            endActionLabel="Limpiar búsqueda"
            type="search"
            value={search}
            onChange={(_, next) => setSearch(next)}
            onAdornmentClick={({ input }) => {

          <span className="demo-label">Acción inicial · standard</span>

              setLocation('Ciudad de México, CDMX');
              write('onAdornmentClick (start) → ubicación aproximada');
            }}
          />
        </div>
        <div className="demo-group">
          <span className="demo-label">Deshabilitado</span>
          <TextField label="Contraseña" type="password" passwordToggle defaultValue="secreto" disabled />
        </div>
      </div>

multiline renderiza un <textarea> con rows (3 por defecto). autoResize hace crecer el campo al escribir y maxRows limita el crecimiento antes de mostrar scroll. Como en MUI, minRows o maxRows activan por sí solos el auto-resize.

Máscaras de entrada#

mask acepta un patrón (0 dígito, a letra minúscula, A letra mayúscula, * alfanumérico; cualquier otro carácter es un literal), un atajo (phone, phone-intl, credit-card, date, date-short, time, time-ampm, time-seconds, cpf, cnpj, zip, postal-code) o currency, configurable con currencyOptions (prefix, suffix, thousands, decimal, precision). El valor se formatea al escribir y el cursor conserva su posición. onChange recibe el valor formateado y { unmaskedValue, isMaskComplete }.

Validación#

Combina la validación nativa (required, type, checkValidity() mediante inputRef) con error y helperText. Dentro de un FormControl, el campo hereda error, disabled y required y enlaza los textos de ayuda del FormControl con aria-describedby. En modo no controlado, el reset del formulario restaura el valor inicial.

Validación open_in_new
import { useRef, useState } from 'react';
import type { FormEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [message, setMessage] = useState('');

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const input = inputRef.current;
    if (!input) return;
    if (input.checkValidity()) setMessage('');
    else setMessage(input.value ? 'Correo no válido' : 'El correo es obligatorio');
  };

  return (
    <form className="demo-stack demo-wide" noValidate onSubmit={handleSubmit} onReset={() => setMessage('')}>
      <TextField
        inputRef={inputRef}
        label="Correo"
        startIcon="email"
        required
        type="email"
        error={Boolean(message)}
        helperText={message || 'Te enviaremos la confirmación'}
      />
      <div className="mtx-d-flex mtx-justify-content-end mtx-gap-1">
        <Button variant="text" type="reset">
          Limpiar
        </Button>
        <Button variant="contained" type="submit">
          Validar
        </Button>
      </div>
    </form>
  );
}

Uso controlado#

Con value + onChange el padre es dueño del valor. Con máscara, value puede ser el valor limpio ("125000"): se muestra formateado ("$ 1,250.00"). Los métodos de la instancia vanilla pasan a ser estado: value/unmaskedValue = … → setValue(), setError()/clearError() → error + helperText, disable()/enable() → disabled, y focus() usa inputRef. Los campos creados en tiempo de ejecución son simplemente nuevos elementos del estado (el equivalente a Materix.init() / initAll()).

Uso controlado open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { TextField, isMaskComplete, resolveMask, unmaskValue } from '@rubenchodev/materix-react/components/text-field';

const CURRENCY = resolveMask('currency');

const DYNAMIC: { variant: 'outlined' | 'filled' | 'standard'; startIcon?: string }[] = [
  { variant: 'outlined', startIcon: 'edit' },
  { variant: 'filled' },
  { variant: 'standard' },
];

export default function Demo() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [value, setValue] = useState('');
  const [error, setError] = useState('');
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const [fields, setFields] = useState<number[]>([]);
  const write = (text: string) => setLog((prev) => [`${new Date().toLocaleTimeString()}  ${text}`, ...prev].slice(0, 8));

  return (
    <div className="demo-stack">
      <div className="demo-fixed-width">
        <TextField
          inputRef={inputRef}
          label="Campo controlado"
          mask="currency"
          value={value}
          onChange={(_, next, details) => {
            setValue(next);
            write(`onChange → value "${next}" · unmaskedValue "${details.unmaskedValue}"`);
          }}
          onFocus={() => write('focus')}
          onBlur={() => write('blur')}
          disabled={disabled}
          error={Boolean(error)}
          helperText={error || 'Escribe o usa los botones'}
        />
      </div>
      <div className="demo-row">
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setValue('125000');
            write('value = "125000" → "$ 1,250.00"');
          }}
        >
          value = 125000
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setError('Importe fuera de rango');
            write('error + helperText');
          }}
        >
          Poner error
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setError('');
            write('error eliminado');
          }}
        >
          Quitar error
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setDisabled(!disabled);
            write(`disabled = ${!disabled}`);
          }}
        >
          Deshabilitar / habilitar
        </Button>
        <Button variant="outlined" size="small" onClick={() => inputRef.current?.focus()}>
          Enfocar (inputRef)
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            const shown = inputRef.current?.value ?? '';
            write(`value "${shown}" · unmaskedValue "${unmaskValue(shown, CURRENCY)}" · isMaskComplete ${isMaskComplete(shown, CURRENCY)}`);
          }}
        >
          Leer valores
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
      <div className="demo-group">
        <span className="demo-label">Crear campos dinámicamente</span>
        <div className="demo-row">
          <Button
            variant="text"
            onClick={() => {
              const next = fields.length + 1;
              setFields([...fields, next]);
              write(`campo #${next} añadido al estado`);
            }}
          >
            Añadir campo
          </Button>
          <Button variant="text" disabled={!fields.length} onClick={() => setFields([])}>
            Quitar todos
          </Button>
        </div>
        <div className="demo-grid-3">
          {fields.map((n) => {
            const config = DYNAMIC[(n - 1) % DYNAMIC.length];
            return <TextField key={n} label={`Campo #${n}`} variant={config.variant} startIcon={config.startIcon} />;
          })}
        </div>
      </div>
    </div>
  );
}

Accesibilidad#

  • El label es un <label for> asociado al id del control (generado con useId si falta).
  • El texto de ayuda y el contador (.mtx-text-field__supporting-text) se enlazan con aria-describedby, conservando los ids que pases y los de un FormControl padre.
  • El estado de error (error, un FormControl padre o un límite superado) pone aria-invalid="true".
  • El contador usa aria-live="polite". Los iconos generados llevan aria-hidden="true".
  • En no-label y hiddenLabel no hay label visible: añade un aria-label.
  • required añade el asterisco visual; el atributo nativo lo anuncia a los lectores de pantalla.
  • El botón de contraseña es un <button type="button"> con aria-label traducido, aria-pressed y aria-controls; los botones de acción necesitan startActionLabel / endActionLabel.
