Pagination

Permite elegir una página dentro de un conjunto grande de resultados, con elipsis, botones primera/última y modo enlaces para SSR.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Pagination, PaginationItem, usePagination } from '@rubenchodev/materix-react';

Pagination implementa el Pagination de MUI: botones de página con elipsis calculadas con el mismo algoritmo que usePagination, botones anterior/siguiente y, opcionalmente, primera/última, variantes text y outlined, formas circular y rounded, tres tamaños y tres colores. Úsalo para recorrer listas de resultados, artículos de un blog o catálogos.

import '@rubenchodev/materix-ui/base.css';
import { Pagination } from '@rubenchodev/materix-react';

<Pagination count={10} />

Uso básico#

Basta con count (total de páginas). El componente pinta el landmark <nav>, la lista, los botones, las elipsis y los aria-label traducidos. Por defecto no es controlado (defaultPage, base 1); usa page + onChange para controlarlo.

Uso básico open_in_new
import { Pagination } from '@rubenchodev/materix-react/components/pagination';

export default function Demo() {
  return (
    <div className="demo-stack">
      <Pagination count={10} aria-label="Paginación básica" />
      <Pagination count={10} color="primary" aria-label="Paginación primaria" />
      <Pagination count={10} color="secondary" aria-label="Paginación secundaria" />
      <Pagination count={10} disabled aria-label="Paginación deshabilitada" />
    </div>
  );
}

Modo enlaces (SSR)#

Con getItemHref(page) cada ítem es un <a href>: funciona con renderizado en servidor, se puede abrir en otra pestaña y no necesita JavaScript para navegar. Los ítems que no pueden navegar llevan aria-disabled="true" y no tienen href.

Modo enlaces open_in_new
import { useState } from 'react';
import { Pagination } from '@rubenchodev/materix-react/components/pagination';

export default function Demo() {
  const [status, setStatus] = useState('Pulsa una página: la navegación se cancela y se gestiona en el cliente.');
  return (
    <div className="demo-stack">
      <Pagination
        count={8}
        defaultPage={3}
        variant="outlined"
        shape="rounded"
        color="primary"
        aria-label="Paginación con enlaces"
        getItemHref={(page) => `?page=${page}`}
        onChange={(event, page) => {
          event.preventDefault();
          setStatus(`Navegación a ?page=${page} cancelada con preventDefault(); página actualizada en el cliente.`);
        }}
      />
      <span className="demo-status" aria-live="polite">
        {status}
      </span>
    </div>
  );
}
info

Navegación cancelable

En modo enlaces, al pulsar una página se llama a onChange(event, page) antes de navegar. Si llamas a event.preventDefault(), se cancela la navegación nativa y la página cambia en el cliente (útil para cargar los resultados con fetch y conservar los enlaces para los buscadores). Es el equivalente del evento cancelable mtx:pagination:change de vanilla.

Ejemplo real#

Lista de artículos paginada en el cliente, construida con List dentro de un Paper.

Ejemplo real open_in_new
import { useState } from 'react';
import { List, ListItem } from '@rubenchodev/materix-react/components/list';
import { Pagination } from '@rubenchodev/materix-react/components/pagination';
import { Paper } from '@rubenchodev/materix-react/components/paper';

const ARTICLES = [
  'Cómo diseñar formularios accesibles',
  'Guía de tokens de color',
  'Tipografía responsive con clamp()',
  'Sombras y elevación en MUI',
  'Estados de foco visibles',
  'Patrones de navegación móvil',
  'Tablas con ordenación y filtros',
  'Microinteracciones con ripple',
  'Modo oscuro sin parpadeo',
  'Iconografía en cuadrícula de 24px',
  'Rejillas de 12 columnas',
  'Diálogos y gestión del foco',
];
const PER_PAGE = 3;

export default function Demo() {
  const [page, setPage] = useState(1);
  const start = (page - 1) * PER_PAGE;
  return (
    <div className="demo-stack">
      <Paper variant="outlined">
        <List aria-label="Artículos" aria-live="polite">
          {ARTICLES.slice(start, start + PER_PAGE).map((name, index) => (
            <ListItem key={name} icon="article" secondary={`Artículo ${start + index + 1} de ${ARTICLES.length}`}>
              {name}
            </ListItem>
          ))}
        </List>
      </Paper>
      <Pagination
        count={Math.ceil(ARTICLES.length / PER_PAGE)}
        page={page}
        onChange={(_, next) => setPage(next)}
        color="primary"
        aria-label="Paginación de artículos"
      />
    </div>
  );
}

Uso controlado y usePagination#

En modo controlado el padre es dueño de page, así que puede cambiarse desde fuera (botones, URL, store). usePagination expone la misma lógica que el hook de MUI para construir tu propia interfaz: devuelve items ({ type, page, selected, disabled, onClick }), page y goTo.

Uso controlado y usePagination open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Pagination, usePagination } from '@rubenchodev/materix-react/components/pagination';

const COUNT = 10;

export default function Demo() {
  const [page, setPage] = useState(1);
  const [log, setLog] = useState<string[]>([]);
  const go = (next: number, source: string) => {
    const clamped = Math.min(Math.max(1, next), COUNT);
    if (clamped === page) return;
    setLog((prev) => [`${source} → página ${clamped} (anterior: ${page})`, ...prev].slice(0, 12));
    setPage(clamped);
  };
  const { items } = usePagination({ count: 5, defaultPage: 2 });

  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Pagination controlada</span>
        <Pagination
          count={COUNT}
          page={page}
          onChange={(_, next) => go(next, 'onChange (usuario)')}
          color="primary"
          showFirstButton
          showLastButton
          aria-label="Paginación controlada"
        />
        <Stack direction="row" spacing={1} wrap alignItems="center">
          <Button variant="outlined" size="small" onClick={() => go(page - 1, 'anterior')}>
            anterior
          </Button>
          <Button variant="outlined" size="small" onClick={() => go(page + 1, 'siguiente')}>
            siguiente
          </Button>
          <Button variant="outlined" size="small" onClick={() => go(7, 'page = 7')}>
            page = 7
          </Button>
          <span className="demo-status">page: {page}</span>
        </Stack>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
      <div className="demo-group">
        <span className="demo-label">Interfaz propia con usePagination</span>
        <Stack component="nav" direction="row" spacing={1} wrap alignItems="center" aria-label="Paginación personalizada">
          {items.map(({ type, page: target, selected, disabled, onClick }, index) =>
            type === 'start-ellipsis' || type === 'end-ellipsis' ? (
              <span key={`${type}-${index}`} aria-hidden="true">
                …
              </span>
            ) : (
              <Button
                key={`${type}-${index}`}
                size="small"
                variant={selected ? 'contained' : 'text'}
                disabled={disabled}
                aria-current={selected ? 'page' : undefined}
                onClick={onClick}
              >
                {type === 'page' ? target : type}
              </Button>
            ),
          )}
        </Stack>
      </div>
    </div>
  );
}

usePagination#

usePagination({ count, page, defaultPage, onChange, siblingCount, boundaryCount, showFirstButton, showLastButton, hidePrevButton, hideNextButton, disabled }) devuelve { items, page, count, goTo, setPage }. La función pura getPaginationItems(options) (import { getPaginationItems } from '@rubenchodev/materix-react') devuelve la lista sin procesar ('previous', 1, 'start-ellipsis'…), con el tipo PaginationItemEntry[].

warning

Enlaces de router

En modo enlaces, si un Link de router pintado con renderItem cancela la navegación por su cuenta, el componente no controlado también lo detecta (vuelve a comprobar defaultPrevented en un microtask). Con un router, es preferible el modo controlado: deriva page de la URL.

Accesibilidad#

  • Landmark <nav> con aria-label="pagination navigation" (traducido con la clave i18n pagination.label; tu propio aria-label o aria-labelledby prevalece). Da a cada paginación de la misma página su propia etiqueta.
  • Cada página es un <button> real (o <a href> en modo enlaces) con la etiqueta «Ir a la página N»; la actual lleva aria-current="page" y la etiqueta «página N».
  • Botones de navegación: «Ir a la primera/anterior/siguiente/última página»; su icono SVG es aria-hidden.
  • Los ítems de los extremos se deshabilitan con disabled (o aria-disabled en modo enlaces); el foco nunca se pierde.
