Native Select

El <select> del navegador con estética MUI: ligero, accesible por defecto y con el selector táctil nativo en móviles.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { NativeSelect } from '@rubenchodev/materix-react';

NativeSelect aplica la estética de MUI al <select> del navegador sin sustituir su menú: la lista la dibuja el sistema operativo, lo que lo hace el selector más ligero, rápido con listas largas y cómodo en móviles. Úsalo en formularios simples. Si necesitas búsqueda, multiselección con casillas o iconos en las opciones, usa Select.

info

¿Select o NativeSelect?

NecesidadSelectNativeSelect
Menú con estética MUI (Paper, marca de selección)SíNo, usa el del sistema
Búsqueda dentro del menúSíNo
Selección múltiple cómodaSí, con casillasLista nativa (multiple, Ctrl/Cmd + clic)
Iconos o imágenes en las opcionesSíNo
Peso y rendimiento con miles de opcionesMedioMínimo
Experiencia táctil nativa en móvilesMenú propioSelector del sistema

Regla práctica: NativeSelect para formularios simples y listas largas en móvil; Select cuando necesites búsqueda, selección múltiple, iconos o coherencia visual total.

import '@rubenchodev/materix-ui/base.css';
import { NativeSelect } from '@rubenchodev/materix-react';

<NativeSelect label="Edad" name="age" defaultValue="20">
  <option value="10">Diez</option>
  <option value="20">Veinte</option>
</NativeSelect>

Uso básico#

Basta un elemento con label: el componente genera el contenedor, el label flotante (asociado con for/id, así el select ya tiene nombre accesible), el <select> nativo y el chevron. Como en NativeSelect de MUI, la variante predeterminada es standard. Las opciones se escriben como hijos <option>/<optgroup> o se pasan con la prop options.

Uso básico open_in_new
import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';

export default function Demo() {
  return (
    <div className="demo-fixed-width">
      <NativeSelect label="Edad" name="age" defaultValue="20">
        <option value="10">Diez</option>
        <option value="20">Veinte</option>
        <option value="30">Treinta</option>
      </NativeSelect>
    </div>
  );
}

Variantes#

outlined (borde completo), filled (fondo y esquinas superiores redondeadas) y standard (línea inferior, predeterminada) con variant.

Variantes open_in_new
import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';

const COUNTRIES = [
  { value: 'co', label: 'Colombia' },
  { value: 'mx', label: 'México' },
  { value: 'es', label: 'España' },
];

export default function Demo() {
  return (
    <div className="demo-grid-3">
      {(['outlined', 'filled', 'standard'] as const).map((variant) => (
        <div key={variant} className="demo-group">
          <span className="demo-label">{variant}</span>
          <NativeSelect variant={variant} label="País" options={COUNTRIES} />
        </div>
      ))}
    </div>
  );
}

Tamaños#

Medium 56px (por defecto) y small 40px con size="small" (también reduce el texto a 14px). Las alturas coinciden con TextField y Select, así un NativeSelect small se alinea con un TextField small y un Button medium.

Estados#

error pinta de rojo el borde, el label y el chevron y añade aria-invalid="true"; disabled deshabilita el <select>; required añade el atributo nativo y el asterisco al label. Al enfocar, el borde y el label pasan al color primario.

Texto de ayuda y de error#

Fuera de un FormControl el campo siempre va envuelto en .mtx-form-control (así el select no se remonta y conserva el foco cuando aparece el texto de ayuda); helperText añade debajo un FormHelperText enlazado con aria-describedby. Junto con error se convierte en el mensaje de error. Dentro de un FormControl el select hereda error, disabled y required.

Texto de ayuda y de error open_in_new
import { useState } from 'react';
import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';

const SIZES = [
  { value: '', label: 'Sin elegir' },
  { value: 's', label: 'S' },
  { value: 'm', label: 'M' },
  { value: 'l', label: 'L' },
];

export default function Demo() {
  const [size, setSize] = useState('');
  return (
    <div className="demo-grid-2">
      <NativeSelect
        variant="outlined"
        label="Envío"
        helperText="El plazo de entrega depende del método."
        options={[{ value: 'std', label: 'Estándar (5 días)' }, { value: 'exp', label: 'Exprés (1 día)' }]}
      />
      <NativeSelect
        variant="outlined"
        label="Talla"
        required
        value={size}
        onChange={(_, value) => setSize(value as string)}
        error={size === ''}
        helperText={size === '' ? 'Elige una talla.' : `Talla ${size.toUpperCase()} seleccionada.`}
        options={SIZES}
      />
    </div>
  );
}

Grupos y selección múltiple#

<optgroup> y <option disabled> funcionan de forma nativa, también con options (un elemento con options se convierte en <optgroup>). Con multiple (y htmlSize para las filas visibles) se muestra la lista del navegador con el borde o fondo de su variante y sin chevron; value/onChange usan entonces un array.

Grilla#

Dentro de un Grid cada select ocupa todo el ancho de su columna: uno por fila en móvil, dos desde 600px y cuatro desde 900px.

Grilla open_in_new
import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';
import { Grid } from '@rubenchodev/materix-react/components/grid';

const FIELDS: Array<[string, string[]]> = [
  ['Año', ['2024', '2025', '2026']],
  ['Mes', ['Enero', 'Febrero', 'Marzo']],
  ['Día', ['1', '2', '3']],
  ['Moneda', ['USD', 'EUR', 'COP']],
];

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {FIELDS.map(([label, values]) => (
        <Grid key={label} size={{ xs: 12, sm: 6, md: 3 }}>
          <NativeSelect
            variant="outlined"
            label={label}
            helperText={label === 'Moneda' ? 'Código ISO 4217' : undefined}
            options={values.map((value) => ({ value, label: value }))}
          />
        </Grid>
      ))}
    </Grid>
  );
}

Uso controlado#

Con value + onChange el padre es dueño del valor; los métodos de la instancia vanilla pasan a ser cambios de estado (value = … → setValue, disable() → disabled) y focus() usa inputRef.

Uso controlado open_in_new
import { useRef, useState } from 'react';
import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const inputRef = useRef<HTMLSelectElement>(null);
  const [value, setValue] = useState('s');
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ['value = "l"', () => setValue('l')],
    ['disabled = !disabled', () => setDisabled((prev) => !prev)],
    ['focus()', () => inputRef.current?.focus()],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <div className="demo-fixed-width">
          <NativeSelect
            variant="outlined"
            label="Talla"
            inputRef={inputRef}
            value={value}
            disabled={disabled}
            onChange={(_, next) => {
              setValue(next as string);
              write(`onChange (usuario) → value: ${String(next)}`);
            }}
            options={[{ value: 's', label: 'S' }, { value: 'm', label: 'M' }, { value: 'l', label: 'L' }]}
          />
        </div>
        <span className="demo-status">
          value: {value} · disabled: {String(disabled)}
        </span>
      </div>
      <div className="demo-row">
        {actions.map(([label, run]) => (
          <Button
            key={label}
            variant="outlined"
            size="small"
            onClick={() => {
              run();
              write(label);
            }}
          >
            {label}
          </Button>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accesibilidad#

  • Es un <select> real: el navegador y los lectores de pantalla lo anuncian y manejan de forma nativa.
  • El label se asocia al <select> con for/id, así el nombre accesible es el texto del label. Sin label, usa aria-label o aria-labelledby.
  • error añade aria-invalid="true"; helperText se enlaza con aria-describedby; el chevron es decorativo (aria-hidden).
