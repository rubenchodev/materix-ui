CSS Baseline

Base global de Materix: tipografía Roboto, colores de fondo y texto del tema, box-sizing, foco visible y color-scheme claro u oscuro.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { CssBaseline, ScopedCssBaseline } from '@rubenchodev/materix-react';

CssBaseline añade la clase mtx-root a <body>, que activa la base de estilos de Materix: tipografía Roboto a 16px, colores de fondo y texto del tema, box-sizing: border-box en todo el árbol, anillo de foco accesible y color-scheme coherente con el tema claro u oscuro. Además importa @rubenchodev/materix-ui/base.css (tokens + base). Renderízalo una sola vez en la raíz de tu app; usa ScopedCssBaseline cuando Materix conviva con otros estilos. No es un reset completo: no elimina márgenes de encabezados ni listas ni normaliza formularios.

import { CssBaseline, ScopedCssBaseline } from '@rubenchodev/materix-react';
// o solo este componente
import { CssBaseline } from '@rubenchodev/materix-react/components/css-baseline';

Uso básico#

Renderiza <CssBaseline /> una vez, junto a tu app. Añade mtx-root a <body> en un efecto (seguro en SSR) y lo retira al desmontarse, salvo que la clase ya estuviera. Varias instancias se cuentan por referencia: la clase se mantiene hasta que se desmonta la última. Los hijos, si los hay, se renderizan tal cual.

export function App() {
  return (
    <>
      <CssBaseline />
      <Main />
    </>
  );
}
Uso básico open_in_new
import { useEffect, useState } from 'react';
import { CssBaseline } from '@rubenchodev/materix-react/components/css-baseline';

export default function Demo() {
  const [bodyClass, setBodyClass] = useState('');

  useEffect(() => {
    const read = () => setBodyClass(document.body.className);
    read();
    const observer = new MutationObserver(read);
    observer.observe(document.body, { attributes: true, attributeFilter: ['class'] });
    return () => observer.disconnect();
  }, []);

  return (
    <div className="demo-group">
      <CssBaseline />
      <span className="demo-label">Clases actuales de body</span>
      <p className="demo-status" aria-live="polite">
        class=&quot;{bodyClass}&quot;
      </p>
    </div>
  );
}
lightbulb

Equivalencia

<CssBaseline />, <body data-mtx="css-baseline"> y <body class="mtx-root"> son equivalentes. Escribir la clase en tu plantilla HTML (o usar MaterixProvider, que renderiza un contenedor .mtx-root) evita un salto visual antes de que React hidrate.

Con y sin línea base#

A la izquierda, un bloque con los estilos del navegador; a la derecha, el mismo contenido dentro de ScopedCssBaseline: Roboto 16px, interlineado 1.5, colores del tema y negrita a 700.

Con y sin línea base open_in_new

        <span className="demo-label">Navegador</span>

          <p>
            Texto con la tipografía del navegador y <strong>negrita</strong>.
          </p>
          <input type="text" aria-label="Campo sin línea base" placeholder="Campo nativo" />
        </div>

        <ScopedCssBaseline className="demo-css-baseline-box">

}

Qué aplica#

Todas las reglas salen de base.css y se limitan a .mtx-root y sus descendientes. La de movimiento reducido solo afecta a los elementos de Materix (clases mtx-*).

SelectorPropiedadesEfecto
.mtx-root, .mtx-root *, ::before, ::afterbox-sizing: border-boxEl relleno y el borde se incluyen en el ancho.
body.mtx-rootmargin: 0Quita el margen del <body>. Un contenedor acotado conserva su margen.
.mtx-rootfont-family: var(--mtx-font-family); font-weight: 400; font-size: 1rem; line-height: 1.5Tipografía base Roboto (equivalente a body1).
.mtx-rootcolor: var(--mtx-color-text-primary); background-color: var(--mtx-color-background-default)Colores de texto y fondo del tema activo.
.mtx-rootcolor-scheme: lightControles nativos, barras de scroll y autocompletado en claro.
.mtx-root[data-mtx-theme='dark'], [data-mtx-theme='dark'] .mtx-rootcolor-scheme: darkControles nativos en oscuro cuando el tema es oscuro.
.mtx-root-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscaleSuavizado de fuente en macOS.

Box sizing#

Dentro de mtx-root todo usa box-sizing: border-box: una caja con width: 100%, 16px de relleno y un borde de 4px no desborda su contenedor.

Box sizing open_in_new
import './demo.css';
import { ScopedCssBaseline } from '@rubenchodev/materix-react/components/css-baseline';

export default function Demo() {
  return (
    <ScopedCssBaseline className="demo-group">
      <span className="demo-label">width 100% + padding 16px + border 4px</span>
      <div className="demo-css-baseline-sizing">Ocupa exactamente el ancho disponible.</div>
    </ScopedCssBaseline>
  );
}

Foco visible#

Usa Tab: botones, enlaces y elementos enfocables muestran el anillo --mtx-focus-ring-color solo al navegar con el teclado. Los campos de texto se excluyen porque su borde ya indica el foco.

Foco visible open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';
import { ScopedCssBaseline } from '@rubenchodev/materix-react/components/css-baseline';
import { Link } from '@rubenchodev/materix-react/components/link';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  return (
    <ScopedCssBaseline className="demo-row">
      <Button variant="outlined">Botón</Button>
      <Link href="#focus">Enlace</Link>
      <TextField label="Campo" variant="outlined" size="small" type="text" />
    </ScopedCssBaseline>
  );
}

Tema claro y oscuro#

El tema se elige con data-mtx-theme en <html> (o en cualquier ancestro), normalmente mediante ThemeProvider / MaterixProvider (ver Temas). Los tokens cambian y .mtx-root adopta el fondo, el texto y el color-scheme correspondientes, así que los controles nativos (<input type="date">, barras de scroll) también se ven oscuros. Cambia el tema de esta página para verlo.

Esquema de color open_in_new
import { useEffect, useRef, useState } from 'react';
import { ScopedCssBaseline } from '@rubenchodev/materix-react/components/css-baseline';

export default function Demo() {
  const ref = useRef<HTMLDivElement>(null);
  const [scheme, setScheme] = useState('');

  useEffect(() => {
    const read = () => setScheme(ref.current ? getComputedStyle(ref.current).colorScheme : '');
    read();
    const observer = new MutationObserver(read);
    observer.observe(document.documentElement, { attributes: true, attributeFilter: ['data-mtx-theme'] });
    return () => observer.disconnect();
  }, []);

  return (
    <ScopedCssBaseline ref={ref} className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Controles nativos</span>
        <div className="demo-row">
          <input type="date" aria-label="Fecha nativa" />
          <input type="color" aria-label="Color nativo" defaultValue="#4818d0" />
          <select aria-label="Select nativo">
            <option>Opción nativa</option>
            <option>Otra opción</option>
          </select>
          <input type="range" aria-label="Rango nativo" />
        </div>
      </div>
      <p className="demo-status" aria-live="polite">
        color-scheme: {scheme}
      </p>
    </ScopedCssBaseline>
  );
}

Línea base acotada#

ScopedCssBaseline renderiza un contenedor .mtx-root (un div, o el elemento indicado en component) en lugar de tocar <body>, por ejemplo al incrustar un widget de Materix en una página con otros estilos. Solo ese subárbol recibe la tipografía, los colores y el box-sizing.

Línea base acotada open_in_new
import './demo.css';
import { ScopedCssBaseline } from '@rubenchodev/materix-react/components/css-baseline';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Contenedor sin línea base</span>
        <div className="demo-css-baseline-box demo-css-baseline-raw">
          <h3>Widget externo</h3>
          <p>Hereda los estilos del sitio anfitrión.</p>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">&lt;ScopedCssBaseline component=&quot;section&quot;&gt;</span>
        <ScopedCssBaseline component="section" className="demo-css-baseline-box">
          <Typography variant="h6" component="h3" gutterBottom>
            Widget de Materix
          </Typography>
          <Typography variant="body2">Tipografía y colores del tema dentro del contenedor.</Typography>
        </ScopedCssBaseline>
      </div>
    </div>
  );
}
info

Alcance

Un contenedor acotado conserva su margen (solo body.mtx-root recibe margin: 0). La regla de prefers-reduced-motion solo reduce las animaciones de los elementos con clases mtx-*; el resto de la página conserva las suyas.

Aplicar en tiempo de ejecución#

En vanilla, Materix.init(el, 'css-baseline') marca un contenedor creado en tiempo de ejecución. En React, renderiza ScopedCssBaseline de forma condicional.

Aplicar en tiempo de ejecución open_in_new
import { useEffect, useRef, useState } from 'react';
import './demo.css';
import { Button } from '@rubenchodev/materix-react/components/button';
import { ScopedCssBaseline } from '@rubenchodev/materix-react/components/css-baseline';

export default function Demo() {
  const [applied, setApplied] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!applied || !ref.current) return;
    const el = ref.current;
    setLog((lines) => [...lines.slice(-5), `aplicar → class="${el.className}" · font-family: ${getComputedStyle(el).fontFamily}`]);
  }, [applied]);

  const toggleTheme = () => {
    const root = document.documentElement;
    const next = root.getAttribute('data-mtx-theme') === 'dark' ? 'light' : 'dark';
    root.setAttribute('data-mtx-theme', next);
    setLog((lines) => [...lines.slice(-5), `data-mtx-theme="${next}" → color-scheme: ${getComputedStyle(document.body).colorScheme}`]);
  };

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" aria-pressed={applied} onClick={() => setApplied((a) => !a)}>
          {applied ? 'Quitar de la caja' : 'Aplicar a la caja'}
        </Button>
        <Button variant="outlined" onClick={toggleTheme}>
          Alternar tema
        </Button>
      </div>
      {applied ? (
        <ScopedCssBaseline ref={ref} className="demo-css-baseline-box">
          <p>Caja con la línea base aplicada desde React.</p>
        </ScopedCssBaseline>
      ) : (
        <div className="demo-css-baseline-box demo-css-baseline-raw">
          <p>Caja creada sin línea base. Pulsa &quot;Aplicar a la caja&quot;.</p>
        </div>
      )}
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Referencia de API#

Props de CssBaseline#

PropTipoPor defectoDescripción
target'body' | 'html''body'Elemento global que recibe mtx-root.
childrenReactNode—Se renderiza tal cual (opcional).

CssBaseline no renderiza un elemento propio, así que no acepta ref ni className.

Props de ScopedCssBaseline#

PropTipoPor defectoDescripción
componentElementType'div'Elemento o componente raíz (section, main…).
classNamestring—Se concatena con mtx-root.
refRef<HTMLElement>—Apunta al elemento raíz.

Cualquier otra prop se reenvía al elemento raíz.

Equivalencia con vanilla#

VanillaReact
<body data-mtx="css-baseline"><CssBaseline />
<div data-mtx="css-baseline"><ScopedCssBaseline>
<section data-mtx="css-baseline"><ScopedCssBaseline component="section">
Materix.init(el, 'css-baseline')Renderiza ScopedCssBaseline de forma condicional.
data-mtx-theme en un ancestroEl mismo atributo, normalmente gestionado por ThemeProvider.

Clases CSS#

ClaseDescripción
mtx-rootActiva la base descrita en «Qué aplica» para el elemento y sus descendientes.

Callbacks#

CssBaseline y ScopedCssBaseline no emiten eventos.

Variables CSS#

VariableUso
--mtx-font-familyFamilia tipográfica base.
--mtx-color-text-primaryColor del texto.
--mtx-color-background-defaultColor de fondo.
--mtx-focus-ring-width, --mtx-focus-ring-colorAnillo de :focus-visible.

Accesibilidad#

  • El anillo de foco solo aparece con el teclado (:focus-visible) y tiene un desplazamiento de 2px para no tapar el contenido. Los campos de texto se excluyen porque ya indican el foco con su borde.
  • color-scheme hace que los controles nativos y las barras de scroll respeten el contraste del tema oscuro.
  • Con prefers-reduced-motion: reduce, las animaciones y transiciones de los elementos de Materix se reducen a 0.01ms.
  • La base no cambia la semántica: sigue usando encabezados, listas y landmarks reales.
