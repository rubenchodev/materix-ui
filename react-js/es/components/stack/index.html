Stack

Apila elementos en una dirección (columna o fila) con separación uniforme, alineación, ajuste de línea, divisores y cambios por breakpoint.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Stack } from '@rubenchodev/materix-react';

Stack coloca sus hijos uno tras otro en una sola dirección y los separa con gap, igual que el Stack de MUI. Úsalo para formularios, barras de acciones, listas de tarjetas o cualquier bloque que se apile en móvil y pase a fila en escritorio. Cuando el contenido necesita columnas alineadas entre filas, usa Grid; para centrar y limitar el ancho de la página, Container.

import { Stack } from '@rubenchodev/materix-react';
// o solo este componente
import { Stack } from '@rubenchodev/materix-react/components/stack';

Uso básico#

Un único <Stack>. La dirección por defecto es columna (como en MUI) y spacing fija la separación en múltiplos de 8px.

Uso básico open_in_new
import './demo.css';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  return (
    <Stack spacing={2}>
      <div className="demo-stack-item">Item 1</div>
      <div className="demo-stack-item">Item 2</div>
      <div className="demo-stack-item">Item 3</div>
    </Stack>
  );
}

Dirección#

direction: column (por defecto), row, column-reverse o row-reverse (col se acepta como alias heredado de column). El orden de lectura y de tabulación sigue al JSX.

Dirección open_in_new
import './demo.css';
import { Stack, type StackDirection } from '@rubenchodev/materix-react/components/stack';

const directions: StackDirection[] = ['row', 'row-reverse', 'column', 'column-reverse'];

export default function Demo() {
  return (
    <div className="demo-grid-2">
      {directions.map((direction) => (
        <div className="demo-group" key={direction}>
          <span className="demo-label">direction=&quot;{direction}&quot;</span>
          <Stack direction={direction} spacing={1}>
            <div className="demo-stack-item">1</div>
            <div className="demo-stack-item">2</div>
            <div className="demo-stack-item">3</div>
          </Stack>
        </div>
      ))}
    </div>
  );
}

Espaciado#

Escala 0, 0.5, 1, 1.5, 2, 2.5, 3, 4, 5, 6, 8, 10 (× 8px) aplicada con gap: sin márgenes en los hijos. Los valores fuera de la escala se ignoran (con un aviso en desarrollo).

Espaciado open_in_new
import './demo.css';
import { Stack, type StackSpacing } from '@rubenchodev/materix-react/components/stack';

const values: StackSpacing[] = [0.5, 1, 2, 4, 8];

export default function Demo() {
  return (
    <div className="demo-stack">
      {values.map((spacing) => (
        <div className="demo-group" key={spacing}>
          <span className="demo-label">
            spacing={'{'}
            {spacing}
            {'}'} · {Number(spacing) * 8}px
          </span>
          <Stack direction="row" spacing={spacing}>
            <div className="demo-stack-item">A</div>
            <div className="demo-stack-item">B</div>
            <div className="demo-stack-item">C</div>
          </Stack>
        </div>
      ))}
    </div>
  );
}

Responsive#

direction y spacing aceptan un objeto por breakpoint (sm 600px, md 900px, lg 1200px, xl 1536px) o un array que empieza en xs, como en MUI. Cada valor aplica desde ese ancho hacia arriba. Aquí: columna con 8px en móvil, fila con 16px desde 600px y 32px desde 900px.

Responsive open_in_new
import './demo.css';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  return (
    <Stack direction={{ xs: 'column', sm: 'row' }} spacing={{ xs: 1, sm: 2, md: 4 }}>
      <div className="demo-stack-item">One</div>
      <div className="demo-stack-item">Two</div>
      <div className="demo-stack-item">Three</div>
    </Stack>
  );
}
<Stack direction={{ xs: 'column', sm: 'row' }} spacing={{ xs: 1, sm: 2, md: 4 }}>…</Stack>
// lo mismo con arrays (xs, sm, md…)
<Stack direction={['column', 'row']} spacing={[1, 2, 4]}>…</Stack>

Alineación#

alignItems alinea en el eje cruzado (start, center, end, stretch, baseline) y justifyContent distribuye en el eje principal (start, center, end, between, around, evenly). También se aceptan los valores CSS (flex-start, space-between…).

Alineación open_in_new
import './demo.css';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">alignItems=&quot;center&quot;</span>
        <Stack className="demo-stack-frame" direction="row" spacing={2} alignItems="center">
          <div className="demo-stack-item">short</div>
          <div className="demo-stack-item demo-stack-item--tall">tall</div>
          <div className="demo-stack-item">short</div>
        </Stack>
      </div>
      <div className="demo-group">
        <span className="demo-label">alignItems=&quot;end&quot;</span>
        <Stack className="demo-stack-frame" direction="row" spacing={2} alignItems="end">
          <div className="demo-stack-item">short</div>
          <div className="demo-stack-item demo-stack-item--tall">tall</div>
          <div className="demo-stack-item">short</div>
        </Stack>
      </div>
      <div className="demo-group">
        <span className="demo-label">justifyContent=&quot;between&quot;</span>
        <Stack className="demo-stack-frame" direction="row" justifyContent="between">
          <div className="demo-stack-item">start</div>
          <div className="demo-stack-item">center</div>
          <div className="demo-stack-item">end</div>
        </Stack>
      </div>
      <div className="demo-group">
        <span className="demo-label">justifyContent=&quot;center&quot;</span>
        <Stack className="demo-stack-frame" direction="row" spacing={1} justifyContent="center">
          <div className="demo-stack-item">A</div>
          <div className="demo-stack-item">B</div>
        </Stack>
      </div>
      <div className="demo-group">
        <span className="demo-label">Column · alignItems=&quot;center&quot;</span>
        <Stack className="demo-stack-frame" spacing={1} alignItems="center">
          <div className="demo-stack-item">Narrow item</div>
          <div className="demo-stack-item">Somewhat wider item</div>
        </Stack>
      </div>
    </div>
  );
}

Divisores#

divider inserta un <hr class="mtx-divider mtx-stack__divider" aria-hidden="true"> decorativo entre cada par de hijos: horizontal en columna y vertical en fila (también cuando la dirección cambia por breakpoint). También puedes pasar tu propio nodo, como en MUI: divider={<span aria-hidden="true">·</span>}. Los divisores se recalculan solos al cambiar los hijos (no hace falta refresh()).

Divisores open_in_new
import './demo.css';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Row with dividers</span>
        <Stack direction="row" spacing={2} divider>
          <div className="demo-stack-item">Inbox</div>
          <div className="demo-stack-item">Sent</div>
          <div className="demo-stack-item">Spam</div>
        </Stack>
      </div>
      <div className="demo-group">
        <span className="demo-label">Column with dividers</span>
        <Stack spacing={1} divider>
          <div className="demo-stack-item">Inbox</div>
          <div className="demo-stack-item">Sent</div>
          <div className="demo-stack-item">Spam</div>
        </Stack>
      </div>
    </div>
  );
}

Ajuste de línea#

Con wrap los hijos pasan a la línea siguiente cuando no caben (útil para grupos de chips o botones). El gap también separa las líneas.

Ajuste de línea open_in_new
import { Chip } from '@rubenchodev/materix-react/components/chip';
import { Stack } from '@rubenchodev/materix-react/components/stack';

const tags = ['JavaScript', 'CSS', 'HTML', 'Accessibility', 'Material UI', 'Responsive design', 'Vanilla', 'Design tokens'];

export default function Demo() {
  return (
    <Stack direction="row" spacing={1} wrap>
      {tags.map((tag) => (
        <Chip key={tag} label={tag} />
      ))}
    </Stack>
  );
}

Grilla#

Un Stack dentro de cada ítem de Grid: la grilla reparte las columnas y el stack ordena el contenido de cada una.

Grilla open_in_new
import './demo.css';
import { Grid } from '@rubenchodev/materix-react/components/grid';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  return (
    <Grid container spacing={2}>
      <Grid size={{ xs: 12, md: 6 }}>
        <Stack spacing={1}>
          <div className="demo-stack-item">Column A · 1</div>
          <div className="demo-stack-item">Column A · 2</div>
        </Stack>
      </Grid>
      <Grid size={{ xs: 12, md: 6 }}>
        <Stack spacing={1}>
          <div className="demo-stack-item">Column B · 1</div>
          <div className="demo-stack-item">Column B · 2</div>
        </Stack>
      </Grid>
    </Grid>
  );
}

Props controladas#

En vanilla, setDirection(), setSpacing(), setAlign(), setJustify(), setWrap(), setDivider() y refresh() modifican un elemento existente. En React cambias las props desde el estado; los divisores siguen a los hijos en cada render.

Props controladas open_in_new
import { useEffect, useRef, useState } from 'react';
import './demo.css';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack, type StackSpacing } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  const [row, setRow] = useState(true);
  const [spacing, setSpacing] = useState<StackSpacing>(2);
  const [divider, setDivider] = useState(false);
  const [count, setCount] = useState(3);
  const [log, setLog] = useState<string[]>([]);
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const classes = ref.current?.className ?? '';
    setLog((lines) => [...lines.slice(-5), `children=${count} → ${classes}`]);
  }, [row, spacing, divider, count]);

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="outlined" onClick={() => setRow((r) => !r)}>
          Toggle direction
        </Button>
        <Button variant="outlined" onClick={() => setSpacing(0.5)}>
          spacing 0.5
        </Button>
        <Button variant="outlined" onClick={() => setSpacing(3)}>
          spacing 3
        </Button>
        <Button variant="outlined" aria-pressed={divider} onClick={() => setDivider((d) => !d)}>
          Toggle dividers
        </Button>
        <Button variant="contained" onClick={() => setCount((c) => c + 1)}>
          Add child
        </Button>
      </div>
      <Stack ref={ref} direction={row ? 'row' : 'column'} spacing={spacing} divider={divider}>
        {Array.from({ length: count }, (_, i) => (
          <div className="demo-stack-item" key={i}>
            {i + 1}
          </div>
        ))}
      </Stack>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Sintaxis BEM completa#

Las clases funcionan sin el componente; en ese caso los divisores se escriben a mano.

Uso manual BEM open_in_new
import '@rubenchodev/materix-ui/components/stack.css';
import '@rubenchodev/materix-ui/components/divider.css';
import './demo.css';

export default function Demo() {
  return (
    <div className="mtx-stack mtx-stack--column mtx-stack--sm-row mtx-stack--spacing-1 mtx-stack--sm-spacing-3 mtx-stack--align-center">
      <div className="demo-stack-item">mtx-stack--column</div>
      <hr className="mtx-divider mtx-stack__divider" aria-hidden="true" />
      <div className="demo-stack-item">mtx-stack--sm-row</div>
    </div>
  );
}

Referencia de API#

Props#

PropTipoPor defectoDescripción
directionStackResponsive<'row' | 'column' | 'row-reverse' | 'column-reverse' | 'col'>— (column en CSS)Dirección flex, fija o por breakpoint.
spacingStackResponsive<0 | 0.5 | 1 | 1.5 | 2 | 2.5 | 3 | 4 | 5 | 6 | 8 | 10>—Separación × 8px, fija o por breakpoint.
alignItems'start' | 'center' | 'end' | 'stretch' | 'baseline' (+ flex-start, flex-end)—Alineación en el eje cruzado.
justifyContent'start' | 'center' | 'end' | 'between' | 'around' | 'evenly' (+ valores CSS)—Distribución en el eje principal.
wrapbooleanfalsePermite que los hijos salten de línea.
dividerboolean | ReactNode—true inserta un <hr> decorativo; un nodo se inserta tal cual.
componentElementType'div'Elemento o componente raíz (form, nav, ul…).
classNamestring—Se concatena con las clases del componente.
refRef<HTMLElement>—Apunta al elemento raíz.

StackResponsive<T> es T, { xs?, sm?, md?, lg?, xl? } o un array [xs, sm, md, lg, xl]. Cualquier otra prop se reenvía al elemento raíz.

Accesibilidad#

  • Stack no añade roles: usa component para renderizar el elemento semántico adecuado (<form>, <nav>, <ul> con hijos <li>…).
  • Los divisores generados son decorativos (aria-hidden="true"): la estructura ya comunica la agrupación. Si pasas tu propio nodo en divider, márcalo también con aria-hidden cuando sea solo visual.
  • Con row-reverse / column-reverse el orden visual se invierte pero el de lectura y tabulación sigue al JSX: úsalos solo cuando el orden no importe.
