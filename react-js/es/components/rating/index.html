Rating

Valoración con estrellas para opinar sobre un producto o mostrar una puntuación media, accesible con radios nativos y teclado.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Rating } from '@rubenchodev/materix-react';

Rating permite elegir una puntuación de 1 a N iconos (estrellas por defecto) o mostrar una media en modo solo lectura. Como en MUI, por debajo hay radios nativos ocultos con etiquetas (“3 estrellas”), así funciona con teclado, lectores de pantalla y formularios sin código extra. Para una escala numérica larga usa un Slider o un Native Select.

import '@rubenchodev/materix-ui/base.css';
import { Rating } from '@rubenchodev/materix-react';

<Rating defaultValue={3} name="product-score" aria-label="Valoración del producto" />

Uso básico#

Un único <Rating /> genera cinco estrellas. defaultValue fija el valor inicial y name el name de los radios (se envía con el formulario; si se omite, se genera). Un clic sobre el valor actual lo borra (null).

Uso básico open_in_new
import { Rating } from '@rubenchodev/materix-react/components/rating';

export default function Demo() {
  return <Rating defaultValue={3} name="product-score" aria-label="Valoración del producto" />;
}

Precisión#

precision={0.5} permite medias estrellas: cada estrella contiene dos radios y su mitad izquierda elige el valor x.5. También sirven otras fracciones de 1 como 0.25; los valores se redondean a la precisión.

Precisión open_in_new
import { Rating } from '@rubenchodev/materix-react/components/rating';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">precision = 1 (por defecto)</span>
        <Rating defaultValue={4} aria-label="Precisión entera" />
      </div>
      <div className="demo-group">
        <span className="demo-label">precision = 0.5</span>
        <Rating defaultValue={2.5} precision={0.5} aria-label="Precisión de media estrella" />
      </div>
      <div className="demo-group">
        <span className="demo-label">precision = 0.25</span>
        <Rating defaultValue={3.75} precision={0.25} aria-label="Precisión de cuarto de estrella" />
      </div>
    </div>
  );
}

Tamaños#

Tamaños MUI con size: small 18px, medium 24px (por defecto) y large 30px.

info

Iconos y tamaño

Los iconos incluidos (star, star_border, star_outline, favorite, favorite_border, thumb_up, thumb_up_off_alt, circle, radio_button_unchecked) se dibujan en SVG, que escala sin perder nitidez. Cualquier otro nombre usa el glifo de Material Icons a su tamaño nativo de 24px en todos los tamaños: nunca se fuerza su font-size (regla de iconografía de Materix). Un SVG propio pasado como nodo escala con --mtx-rating-icon-size.

Tamaños open_in_new
import { Rating } from '@rubenchodev/materix-react/components/rating';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Large · 30px</span>
        <Rating defaultValue={4} size="large" aria-label="Grande" />
      </div>
      <div className="demo-group">
        <span className="demo-label">Medium · 24px (por defecto)</span>
        <Rating defaultValue={4} aria-label="Mediano" />
      </div>
      <div className="demo-group">
        <span className="demo-label">Small · 18px</span>
        <Rating defaultValue={4} size="small" aria-label="Pequeño" />
      </div>
    </div>
  );
}

Iconos#

icon (lleno) y emptyIcon (vacío) aceptan un nombre de Material Icons o cualquier nodo de React (por ejemplo tu propio <svg>). Si solo indicas icon, el estado vacío usa el mismo icono en gris. Personaliza el color con --mtx-rating-color.

Iconos open_in_new
import type { CSSProperties } from 'react';
import { Rating } from '@rubenchodev/materix-react/components/rating';

const ERROR_COLOR = { '--mtx-rating-color': 'var(--mtx-color-error)' } as CSSProperties;

/** Icono SVG propio pasado como nodo: escala con `--mtx-rating-icon-size`. */
const Bolt = (
  <svg viewBox="0 0 24 24" focusable="false">
    <path d="M7 2v11h3v9l7-12h-4l4-8z" />
  </svg>
);

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">icon="favorite" + emptyIcon="favorite_border"</span>
        <Rating defaultValue={3} precision={0.5} icon="favorite" emptyIcon="favorite_border" style={ERROR_COLOR} aria-label="Me gusta" />
      </div>
      <div className="demo-group">
        <span className="demo-label">emptyIcon="star" (estrellas grises)</span>
        <Rating defaultValue={2} emptyIcon="star" aria-label="Estrellas grises" />
      </div>
      <div className="demo-group">
        <span className="demo-label">icon="thumb_up" + emptyIcon="thumb_up_off_alt"</span>
        <Rating defaultValue={3} icon="thumb_up" emptyIcon="thumb_up_off_alt" aria-label="Aprobación" />
      </div>
      <div className="demo-group">
        <span className="demo-label">Glifo de Material Icons (24px nativos)</span>
        <Rating defaultValue={2} icon="sentiment_satisfied" aria-label="Estado de ánimo" />
      </div>
      <div className="demo-group">
        <span className="demo-label">Nodo SVG personalizado</span>
        <Rating defaultValue={4} size="large" icon={Bolt} aria-label="Energía" />
      </div>
    </div>
  );
}

Estados#

Al pasar el cursor se previsualiza el valor (la estrella activa crece 1,2×); con Tab y las flechas cambia con un anillo de foco visible. readOnly muestra una valoración fija (role="img") y disabled la atenúa.

Texto al pasar el cursor#

onChangeActive(event, value) informa del valor bajo el cursor o del radio enfocado (null al salir) para mostrar una etiqueta descriptiva, como la demo hover feedback de MUI. getLabelText personaliza la etiqueta accesible de cada radio.

Texto al pasar el cursor open_in_new
import { useState } from 'react';
import { Rating } from '@rubenchodev/materix-react/components/rating';

const LABELS: Record<number, string> = {
  0.5: 'Inútil',
  1: 'Inútil+',
  1.5: 'Pobre',
  2: 'Pobre+',
  2.5: 'Aceptable',
  3: 'Aceptable+',
  3.5: 'Bueno',
  4: 'Bueno+',
  4.5: 'Excelente',
  5: 'Excelente+',
};

export default function Demo() {
  const [value, setValue] = useState<number | null>(2);
  const [active, setActive] = useState<number | null>(null);
  const shown = active ?? value;
  return (
    <div className="demo-row">
      <Rating
        value={value}
        precision={0.5}
        aria-label="Calidad"
        getLabelText={(n) => `${n} estrella${n !== 1 ? 's' : ''}, ${LABELS[n]}`}
        onChange={(_, next) => setValue(next)}
        onChangeActive={(_, next) => setActive(next)}
      />
      <span className="demo-status">{shown !== null ? LABELS[shown] : 'Sin valoración'}</span>
    </div>
  );
}

Casos de uso reales#

Un resumen de producto con la media en solo lectura y un formulario de reseña que envía el valor como cualquier otro radio.

Casos de uso reales open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Rating } from '@rubenchodev/materix-react/components/rating';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Card, CardContent } from '@rubenchodev/materix-react/components/card';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [status, setStatus] = useState('');

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const score = new FormData(event.currentTarget).get('review-score');
    setStatus(score ? `¡Gracias! Tu valoración: ${String(score)}.` : 'Elige primero una valoración.');
  };

  return (
    <div className="demo-grid-2">
      <Card elevation={1}>
        <CardContent>
          <Typography variant="h6" component="h3">Auriculares inalámbricos</Typography>
          <div className="demo-row">
            <Rating value={4.5} precision={0.5} size="small" readOnly />
            <Typography variant="body2" color="text-secondary">4,5 · 1.284 opiniones</Typography>
          </div>
        </CardContent>
      </Card>
      <form className="demo-stack" aria-label="Escribir opinión" onSubmit={handleSubmit}>
        <Typography variant="subtitle2" component="span" id="rating-review-label">Tu valoración</Typography>
        <Rating name="review-score" aria-labelledby="rating-review-label" />
        <div className="demo-row">
          <Button variant="contained" type="submit">Enviar opinión</Button>
          <span className="demo-status" role="status">{status}</span>
        </div>
      </form>
    </div>
  );
}

Grilla#

Varios criterios de valoración repartidos en columnas responsive de Grid, cada uno nombrado con aria-labelledby.

Grilla open_in_new
import { Grid } from '@rubenchodev/materix-react/components/grid';
import { Rating } from '@rubenchodev/materix-react/components/rating';

const CRITERIA: Array<[string, string, number]> = [
  ['grid-clean', 'Limpieza', 5],
  ['grid-location', 'Ubicación', 4],
  ['grid-value', 'Relación calidad-precio', 3],
];

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {CRITERIA.map(([id, label, value]) => (
        <Grid key={id} size={{ xs: 12, sm: 6, md: 4 }}>
          <div className="demo-group">
            <span className="demo-label" id={id}>{label}</span>
            <Rating defaultValue={value} aria-labelledby={id} />
          </div>
        </Grid>
      ))}
    </Grid>
  );
}

Uso controlado#

Con value + onChange el padre es dueño del valor; los miembros de la instancia vanilla pasan a ser cambios de estado (rating.value = 5 → setValue(5), disable() → disabled).

Uso controlado open_in_new
import { useRef, useState } from 'react';
import { Rating } from '@rubenchodev/materix-react/components/rating';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const ref = useRef<HTMLSpanElement>(null);
  const [value, setValue] = useState<number | null>(3);
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const focus = () => {
    const root = ref.current;
    const target = root?.querySelector<HTMLInputElement>('input:checked:not([value=""])') ?? root?.querySelector('input');
    target?.focus();
  };

  const actions: Array<[string, () => void]> = [
    ['value = 5', () => setValue(5)],
    ['value = null', () => setValue(null)],
    ['disabled = true', () => setDisabled(true)],
    ['disabled = false', () => setDisabled(false)],
    ['focus()', focus],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Rating
          ref={ref}
          value={value}
          disabled={disabled}
          aria-label="Valoración controlada"
          onChange={(_, next) => {
            setValue(next);
            write(`onChange → ${String(next)}`);
          }}
          onChangeActive={(_, next) => write(`onChangeActive → ${String(next)}`)}
        />
        <span className="demo-status">value: {String(value)} · disabled: {String(disabled)}</span>
      </div>
      <div className="demo-row">
        {actions.map(([label, run]) => (
          <Button
            key={label}
            variant="outlined"
            size="small"
            onClick={() => {
              run();
              write(label);
            }}
          >
            {label}
          </Button>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accesibilidad#

  • Interactivo: radios nativos con el mismo name, cada uno con su etiqueta traducida (“1 estrella”, “3 estrellas”; “3 Stars” en inglés) más un radio “Sin valoración”. El navegador gestiona la exclusión mutua y las flechas.
  • Cuando el componente tiene nombre (label, aria-label o aria-labelledby) recibe role="radiogroup".
  • Solo lectura: role="img" con un aria-label traducido (“Valoración: 4 de 5” / “Rated 4 out of 5”); los iconos son decorativos.
  • El foco de teclado se muestra como un anillo alrededor del icono enfocado.
