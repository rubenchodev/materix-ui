Tooltip

Etiqueta informativa breve que aparece al pasar el puntero, enfocar con teclado o mantener pulsado. Envuelve cualquier elemento con <Tooltip title>.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Tooltip } from '@rubenchodev/materix-react';

Un Tooltip muestra una etiqueta de texto breve que identifica o explica un elemento cuando el usuario pasa el puntero por encima, lo enfoca con el teclado o lo mantiene pulsado en una pantalla táctil, igual que el Tooltip de MUI. Es ideal para botones de solo icono y barras de herramientas. No pongas en él información esencial ni contenido interactivo (enlaces, botones): para mensajes persistentes usa un texto de ayuda o un Alert.

import { Tooltip } from '@rubenchodev/materix-react';
// o solo este componente:
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';

Uso básico#

Envuelve un único hijo con <Tooltip title="…">. El hijo recibe la ref fusionada y los manejadores de puntero y foco encadenados, así que debe ser un elemento o un componente que los reenvíe (todos los de Materix lo hacen). Si el hijo no tiene nombre accesible (un IconButton de solo icono), el título pasa a ser su aria-label.

Uso básico open_in_new
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  return (
    <div className="demo-row">
      <Tooltip title="Delete">
        <IconButton icon="delete" />
      </Tooltip>
      <Tooltip title="Add to favorites">
        <IconButton icon="favorite" color="error" />
      </Tooltip>
      <Tooltip title="Saved to your account">
        <Button variant="contained">Save</Button>
      </Tooltip>
      <Tooltip title="Back to the top of the page">
        <Link href="#">Link with tooltip</Link>
      </Tooltip>
    </div>
  );
}

Posición#

placement admite 12 posiciones (top|bottom|left|right con -start|-end); por defecto bottom. Si no cabe, voltea al lado opuesto y se desplaza para seguir en pantalla.

Posición open_in_new
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';
import type { TooltipProps } from '@rubenchodev/materix-react/components/tooltip';
import { Button } from '@rubenchodev/materix-react/components/button';

type Placement = NonNullable<TooltipProps['placement']>;

const GROUPS: Array<{ label: string; placements: Placement[] }> = [
  { label: 'Top', placements: ['top-start', 'top', 'top-end'] },
  { label: 'Bottom', placements: ['bottom-start', 'bottom', 'bottom-end'] },
  { label: 'Left and right', placements: ['left-start', 'left', 'left-end', 'right-start', 'right', 'right-end'] },
];

export default function Demo() {
  return (
    <div className="demo-grid-3">
      {GROUPS.map(({ label, placements }) => (
        <div className="demo-group" key={label}>
          <span className="demo-label">{label}</span>
          <div className="demo-row">
            {placements.map((placement) => (
              <Tooltip key={placement} title={placement} placement={placement}>
                <Button variant="outlined">{placement}</Button>
              </Tooltip>
            ))}
          </div>
        </div>
      ))}
    </div>
  );
}

Elementos deshabilitados#

Los elementos deshabilitados no reciben eventos de puntero ni de foco: envuélvelos en un <span> para que el tooltip siga explicando por qué no están disponibles, como recomienda MUI. El nombre accesible se aplica al primer elemento enfocable del envoltorio.

Retardos#

Por defecto aparece a los 100 ms (enterDelay) y desaparece al salir (leaveDelay 0). Tras cerrarse uno, el siguiente abre con enterNextDelay (0 ms) durante 800 ms, ideal para barras de herramientas.

Retardos open_in_new
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  return (
    <div className="demo-row">
      <Tooltip title="Appears after 100 ms">
        <Button variant="outlined">Default</Button>
      </Tooltip>
      <Tooltip title="Appears after 500 ms" enterDelay={500}>
        <Button variant="outlined">enter 500 ms</Button>
      </Tooltip>
      <Tooltip title="Stays 1 s after you leave" leaveDelay={1000}>
        <Button variant="outlined">leave 1000 ms</Button>
      </Tooltip>
      <Tooltip title="Waits 500 ms even right after another one" enterDelay={500} enterNextDelay={500}>
        <Button variant="outlined">enterNextDelay 500 ms</Button>
      </Tooltip>
    </div>
  );
}

Seguir el cursor#

followCursor ancla el tooltip al puntero mientras se mueve sobre el disparador. Ese tooltip no puede alcanzarse con el puntero, así que no lo retiene (como con disableInteractive).

import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';

        <Typography variant="body2" color="text-secondary">
          Move the cursor around this area.
        </Typography>
      </Paper>
    </Tooltip>
  );
}

Contenido enriquecido#

title admite cualquier ReactNode (formato, atajos de teclado). Mantenlo no interactivo. Con un título no textual, un disparador sin nombre se etiqueta con aria-labelledby mientras el tooltip es visible; describeChild lo convierte en descripción.

Contenido enriquecido open_in_new
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  return (
    <div className="demo-row">
      <Tooltip
        arrow
        placement="right"
        title={
          <>
            <strong>Two-factor authentication</strong>
            <br />
            Asks for a code from your phone each time you sign in on a new device.
          </>

      >
        <Button variant="outlined" startIcon="security">
          2FA
        </Button>

}

Demostración de accesibilidad#

Si el disparador no tiene nombre accesible, el texto se aplica como aria-label. Si ya lo tiene, el tooltip lo describe con aria-describedby mientras es visible.

Accesibilidad open_in_new
import { useEffect, useRef, useState } from 'react';
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  const unnamed = useRef<HTMLElement>(null);
  const [label, setLabel] = useState('');
  useEffect(() => {
    setLabel(unnamed.current?.getAttribute('aria-label') || '');
  }, []);
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">No name → aria-label</span>
        <div className="demo-row">
          <Tooltip title="Print" ref={unnamed}>
            <IconButton icon="print" />
          </Tooltip>
          <span className="demo-status">aria-label=&quot;{label}&quot;</span>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">With name → aria-describedby</span>
        <div className="demo-row">
          <Tooltip title="Uses the default printer">
            <IconButton icon="print" aria-label="Print invoice" />
          </Tooltip>
          <span className="demo-status">aria-label=&quot;Print invoice&quot;</span>
        </div>
      </div>
    </div>
  );
}

Uso programático#

open hace el tooltip controlado: onOpen(event) y onClose(event) solicitan el cambio (equivalen a mtx:tooltip:open y mtx:tooltip:close). Para acciones puntuales sin estado, la ref action expone open(), close(), toggle(), update() e isOpen, el equivalente de Materix.tooltip.show/hide y getTooltip(). hideAllTooltips() oculta todos los tooltips visibles.

Uso programático open_in_new
import { useRef, useState } from 'react';
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';
import type { TooltipActions } from '@rubenchodev/materix-react/components/tooltip';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const actions = useRef<TooltipActions>(null);
  const [open, setOpen] = useState(false);
  const [text, setText] = useState('Copy link');
  const [log, setLog] = useState<string[]>([]);
  const write = (line: string) => setLog((lines) => [`${new Date().toLocaleTimeString()}  ${line}`, ...lines]);

  return (
    <div className="demo-stack demo-wide">
      <div className="demo-group">
        <span className="demo-label">Controlled (open / onOpen / onClose)</span>
        <div className="demo-row">
          <Tooltip
            title={text}
            placement="top"
            open={open}
            onOpen={() => {
              write('onOpen');
              setOpen(true);
            }}
            onClose={() => {
              write('onClose');
              setOpen(false);
            }}
          >
            <Button variant="outlined" startIcon="content_copy">
              Copy
            </Button>
          </Tooltip>
          <Button variant="text" size="small" onClick={() => setOpen(true)}>
            open = true
          </Button>
          <Button variant="text" size="small" onClick={() => setOpen(false)}>
            open = false
          </Button>
          <Button
            variant="text"
            size="small"
            onClick={() => {
              setText('Copied!');
              setOpen(true);
            }}
          >
            title = &apos;Copied!&apos;
          </Button>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Imperative (action ref)</span>
        <div className="demo-row">
          <Tooltip title="Opened from code" action={actions} arrow>
            <Button variant="outlined" startIcon="code">
              Target
            </Button>
          </Tooltip>
          <Button variant="text" size="small" onClick={() => actions.current?.open()}>
            action.open()
          </Button>
          <Button variant="text" size="small" onClick={() => actions.current?.close()}>
            action.close()
          </Button>
        </div>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}
const actions = useRef<TooltipActions>(null);

<Tooltip title="¡Copiado!" action={actions}>
  <Button onClick={() => actions.current?.open()}>Copiar</Button>
</Tooltip>;

openboolean—Visibilidad controlada.

disableFocusListenerbooleanfalseNo abre con el foco de teclado.

disableInteractivebooleanfalseEl tooltip no retiene el puntero (implícito con followCursor).
describeChildbooleanfalseEl título describe al hijo (aria-describedby) en lugar de nombrarlo.

Accesibilidad#

  • La superficie tiene role="tooltip" y se vincula al disparador según el patrón tooltip de WAI-ARIA:
    • Si el disparador no tiene nombre accesible, el texto se aplica como su aria-label (marcado con data-mtx-tooltip-label y retirado al desmontar).
    • Si ya tiene nombre, se conserva y el tooltip se vincula con aria-describedby mientras es visible; si ambos textos coinciden, no se duplica. describeChild usa siempre aria-describedby.
  • Se abre con el foco de teclado (Tab sí, clic de ratón no) y se oculta al perder el foco.
  • Hoverable (WCAG 1.4.13): el puntero puede pasar del disparador al tooltip sin que desaparezca.
  • Descartable: Escape lo oculta sin mover el foco, y solo a él: un menú o diálogo debajo sigue abierto.
  • Persistente: sigue visible hasta que se retira el hover o el foco, o se descarta.
  • En pantallas táctiles aparece con una pulsación larga (700 ms) y se oculta 1,5 s después de soltar; tocar en otro sitio lo oculta.
  • Respeta prefers-reduced-motion y dibuja un borde en modo de colores forzados.
