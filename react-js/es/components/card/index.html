Card

Superficie que agrupa contenido y acciones sobre un mismo tema: encabezado, imagen, texto y botones.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Card, CardHeader, CardMedia, CardContent, CardActions, CardActionArea } from '@rubenchodev/materix-react';

Card agrupa la información y las acciones de un único elemento sobre una superficie elevada: un producto, una receta, un perfil. Se construye con partes opcionales —encabezado, imagen, contenido, acciones y área de acción— que puedes generar con props abreviadas en Card o componer con subcomponentes. Úsala cuando el bloque es autónomo y se recorre dentro de una colección; para una superficie genérica sin estructura usa Paper y para listas densas List.

import { Card, CardContent, CardActions } from '@rubenchodev/materix-react';
// o solo este componente:
import { Card } from '@rubenchodev/materix-react/components/card';

Uso básico#

title, subheader, avatar, actionIcon e image generan el encabezado y la imagen (el equivalente a la sintaxis simplificada de vanilla); el contenido y las acciones son hijos: CardContent y CardActions.

Uso básico open_in_new
import { Card, CardActions, CardContent } from '@rubenchodev/materix-react/components/card';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  return (
    <div className="demo-surface">
      <Card
        className="demo-fixed-width"
        avatar="R"
        title="Shrimp and Chorizo Paella"
        subheader="September 14, 2026"
        actionIcon="more_vert"
        image="https://images.unsplash.com/photo-1534080564583-6be75777b70a?auto=format&fit=crop&w=800&q=80"
      >
        <CardContent>
          A Mediterranean dish with bomba rice, saffron, free-range chicken and fresh vegetables, perfect for sharing.
        </CardContent>
        <CardActions>
          <IconButton icon="favorite" aria-label="Add to favorites" />
          <IconButton icon="share" aria-label="Share" />
        </CardActions>
      </Card>
    </div>
  );
}

Variantes#

Por defecto la tarjeta tiene elevación 1. variant="outlined" la delimita con un borde sin sombra; raised la eleva a 8 (como raised de MUI); elevation acepta 0–8, 12, 16 y 24; square quita el radio. Los estilos de h1–h6 y p dentro de CardContent tienen especificidad cero, así que Typography (o cualquier clase mtx-typography--*) siempre gana.

Encabezado#

El encabezado (.mtx-card__header) se genera si hay title, subheader o avatar. Un avatar de texto se pinta como un Avatar primario con ese texto; cualquier otro nodo (por ejemplo un <Avatar>) se pinta tal cual. actionIcon añade un IconButton a la derecha (su nombre sale de actionLabel, por defecto “Acciones” / “Actions”), y action acepta cualquier nodo en su lugar.

Acciones#

CardActions es una fila con 8 px de padding y separación; sus botones toman el tamaño compacto de MUI y se alinean a la derecha por defecto (ver Alineación de las acciones). La clase mtx-card__actions-end empuja un elemento al extremo derecho y disableSpacing quita la separación.

Alineación de las acciones#

Las acciones se alinean a la derecha por defecto, igual que las de un diálogo. Cámbialo con align="start|center|end|between" en CardActions, o para todas las filas de una tarjeta con actionsAlign en Card (el align propio de la fila gana).

info

Desviación consciente de MUI

CardActions de MUI alinea sus botones a la izquierda. Materix los alinea a la derecha por defecto para que tarjetas y diálogos compartan la misma posición de acciones. Usa align="start" (o actionsAlign="start" en la tarjeta) para recuperar el estilo MUI.

Área de acción#

CardActionArea convierte la imagen y el texto en una única zona pulsable con ripple, hover y foco, sin afectar a las acciones. Pinta un <button type="button">, un <a> cuando recibe href, o cualquier elemento con component (entonces recibe role="button", tabIndex={0} y Enter/Espacio). Con clickable toda la tarjeta es interactiva (role="button", ripple, Enter y Espacio).

Área de acción open_in_new

Estados#

Normal, hover y foco (pasa el ratón o usa Tab) y deshabilitado. disabled en una tarjeta clickable o en CardActionArea reduce la opacidad, quita el puntero y la saca del orden de tabulación (aria-disabled="true"; en un <button>, además, el disabled nativo).

Elevación en el tema oscuro#

En modo oscuro, como en MUI, cada elevación suma una capa blanca (--mtx-overlay-elevation-N): la elevación 0 no lleva capa, la tarjeta elevada a 8 se ve más clara que la de elevación 1, y outlined tampoco lleva capa.

Elevación en el tema oscuro open_in_new
import { Card, CardContent } from '@rubenchodev/materix-react/components/card';

export default function Demo() {
  return (
    <div className="demo-surface" data-mtx-theme="dark">
      <Card elevation={0} title="Elevation 0" subheader="elevation={0}" className="demo-fixed-width">
        <CardContent>No shadow, no overlay.</CardContent>
      </Card>
      <Card title="Elevation 1" subheader="Default" className="demo-fixed-width">
        <CardContent>5% white overlay.</CardContent>
      </Card>
      <Card elevation={8} title="Elevation 8" subheader="elevation={8}" className="demo-fixed-width">

      <Card variant="outlined" title="Outlined" subheader="No overlay" className="demo-fixed-width">
        <CardContent>Border only.</CardContent>
      </Card>
    </div>
  );
}

Uso programático#

Los métodos de vanilla pasan a props y refs: disabled sustituye a disable()/enable(), ref.current.focus() a focus() y la prop image de CardMedia a su setter. No hay eventos mtx:*: usa onClick (también lo disparan Enter y Espacio en elementos no nativos).

Uso programático open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Card, CardActionArea, CardContent, CardMedia } from '@rubenchodev/materix-react/components/card';

const images = [
  'https://images.unsplash.com/photo-1513326738677-b964603b136d?auto=format&fit=crop&w=800&q=80',
  'https://images.unsplash.com/photo-1555881400-74d7acaacd8b?auto=format&fit=crop&w=800&q=80',
];

export default function Demo() {
  const cardRef = useRef<HTMLDivElement>(null);
  const [cardDisabled, setCardDisabled] = useState(false);
  const [areaDisabled, setAreaDisabled] = useState(false);
  const [image, setImage] = useState(0);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((prev) => [...prev.slice(-5), `${new Date().toLocaleTimeString()}  ${text}`]);

  return (
    <div className="demo-stack">
      <div className="demo-surface">
        <Card
          ref={cardRef}
          clickable
          disabled={cardDisabled}
          variant="outlined"
          avatar="S"
          title="Settings"
          subheader="Clickable card"
          className="demo-fixed-width"
          onClick={() => write('click  clickable card')}
        >
          <CardContent>The whole card is interactive.</CardContent>
        </Card>
        <Card className="demo-fixed-width">
          <CardActionArea disabled={areaDisabled} onClick={() => write('click  action area')}>
            <CardMedia height={120} alt="City view" image={images[image]} />
            <CardContent>Action area</CardContent>
          </CardActionArea>
        </Card>
      </div>
      <div className="demo-row">
        <Button
          variant="outlined"
          onClick={() => {
            setCardDisabled(true);
            write('card disabled={true}');
          }}
        >
          Disable card
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setCardDisabled(false);
            write('card disabled={false}');
          }}
        >
          Enable card
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            cardRef.current?.focus();
            write('cardRef.current.focus()');
          }}
        >
          Focus card
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setAreaDisabled((value) => !value);
            write('action area disabled toggled');
          }}
        >
          Toggle action area
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setImage((index) => (index + 1) % images.length);
            write('CardMedia image changed');
          }}
        >
          Swap image
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accesibilidad#

  • Usa component="article" o "section" cuando la tarjeta es contenido autónomo.
  • En una tarjeta clickable que no es <button>/<a> se añaden role="button" y tabIndex={0}; su nombre accesible sale de su contenido. Evita un aria-label que no contenga el texto visible (WCAG 2.5.3 Label in Name).
  • Prefiere CardActionArea (<button> o <a> nativos): conserva su semántica y deja los botones de CardActions como controles independientes. No anides botones dentro del área.
  • Las imágenes generadas con image son decorativas salvo que pases imageAlt; con CardMedia, usa alt.
  • Los IconButton de las acciones necesitan aria-label.
