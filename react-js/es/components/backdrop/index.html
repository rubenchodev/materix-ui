Backdrop

Capa a pantalla completa que oscurece la página y centra un indicador mientras dura una operación; no sustituye a un diálogo.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Backdrop } from '@rubenchodev/materix-react';

Backdrop cubre toda la pantalla con una capa semitransparente y centra su contenido, normalmente un CircularProgress. Úsalo para indicar que la página está ocupada durante una operación breve (guardar, sincronizar, procesar un pago). No es un diálogo: no tiene rol, no atrapa el foco ni ofrece título o acciones; si el usuario debe leer un mensaje o tomar una decisión, usa un Dialog, que ya incluye su propio fondo (reutiliza este componente).

import { Backdrop } from '@rubenchodev/materix-react';
// o solo este componente:
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';

Uso básico#

<Backdrop open={…}> con el contenido a centrar. open es controlado: onClose solicita el cierre y tú actualizas el estado. Con closeOnClick un clic en la capa la cierra, y con closeOnEscape, la tecla Escape. El contenido es blanco por defecto, así que un CircularProgress color="inherit" destaca en ambos temas.

Uso básico open_in_new
import { useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  const [open, setOpen] = useState(false);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="contained" onClick={() => setOpen(true)}>
        Show backdrop
      </Button>
      <Backdrop open={open} onClose={() => setOpen(false)} closeOnClick closeOnEscape>
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
    </Stack>
  );
}

Variantes#

Dos variantes, como en MUI: la predeterminada oscurece la página con --mtx-backdrop-bg e invisible deja la capa transparente (sigue bloqueando los clics). Con invisible el contenido conserva el color del texto, así que usa un indicador con color.

Variantes open_in_new
import { useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  const [open, setOpen] = useState<'default' | 'invisible' | null>(null);
  const close = () => setOpen(null);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="outlined" onClick={() => setOpen('default')}>
        Default (dimmed)
      </Button>
      <Button variant="outlined" onClick={() => setOpen('invisible')}>
        Invisible
      </Button>
      <Backdrop open={open === 'default'} onClose={close} closeOnClick closeOnEscape>
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
      <Backdrop open={open === 'invisible'} invisible onClose={close} closeOnClick closeOnEscape>
        <CircularProgress label="Loading" />
      </Backdrop>
    </Stack>
  );
}

Con contenido#

Los hijos se centran con flexbox; combínalos con Stack y Typography. Cualquier elemento marcado con data-mtx-backdrop-close cierra la capa (motivo click), incluso sin closeOnClick.

Con contenido open_in_new
import { useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [open, setOpen] = useState(false);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="contained" onClick={() => setOpen(true)}>
        Sync with message
      </Button>
      <Backdrop open={open} onClose={() => setOpen(false)} closeOnEscape>

            Syncing your files…
          </Typography>

        </Stack>
      </Backdrop>
    </Stack>
  );
}

Cierre#

  • closeOnClick: un clic en la capa o en contenido no interactivo solicita el cierre (motivo click). Los clics en botones, enlaces o campos del contenido se ignoran.
  • closeOnEscape: Escape solicita el cierre (motivo escape) a través de la pila común de capas, así que solo llega a la capa superior.
  • Sin ninguno de los dos, la capa solo se cierra al poner open={false} (por ejemplo, al terminar la operación).
Cierre open_in_new
import { useEffect, useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import type { BackdropCloseReason } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

type Mode = 'click' | 'escape' | 'timer';

export default function Demo() {
  const [open, setOpen] = useState<Mode | null>(null);
  const [last, setLast] = useState('—');
  const close = (_event: unknown, reason: BackdropCloseReason) => {
    setLast(reason);
    setOpen(null);
  };

  useEffect(() => {
    if (open !== 'timer') return undefined;
    const timer = setTimeout(() => {
      setOpen(null);
      setLast('timer (open = false)');
    }, 2000);
    return () => clearTimeout(timer);
  }, [open]);

  return (
    <Stack spacing={2}>
      <Stack direction="row" spacing={2} wrap alignItems="center">
        <Button variant="outlined" onClick={() => setOpen('click')}>
          Close on click
        </Button>
        <Button variant="outlined" onClick={() => setOpen('escape')}>
          Close with Escape
        </Button>
        <Button variant="outlined" onClick={() => setOpen('timer')}>
          Close after 2 s
        </Button>
      </Stack>
      <Typography variant="caption" color="text-secondary" component="p" role="status">
        Last reason: {last}
      </Typography>
      <Backdrop open={open === 'click'} closeOnClick onClose={close}>
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
      <Backdrop open={open === 'escape'} closeOnEscape onClose={close}>
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
      <Backdrop open={open === 'timer'}>
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
    </Stack>
  );
}

Estados#

lockScroll bloquea el scroll del <body> mientras está abierto (gestor modal compartido con Dialog) e inertOthers marca el resto del documento como inert (sin foco, sin clics y oculto a lectores de pantalla) y lo restaura al cerrar. Con cualquiera de los dos el backdrop entra en la pila de capas y consume Escape aunque no se cierre con él.

Estados open_in_new
import { useEffect, useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  const [open, setOpen] = useState(false);

  useEffect(() => {
    if (!open) return undefined;
    const timer = setTimeout(() => setOpen(false), 3000);
    return () => clearTimeout(timer);
  }, [open]);

  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="outlined" onClick={() => setOpen(true)}>
        Lock scroll and inert (3 s)
      </Button>
      <Backdrop open={open} lockScroll inertOthers>
        <CircularProgress color="inherit" label="Processing payment" />
      </Backdrop>
    </Stack>
  );
}

Ejemplos reales#

Guardar un formulario: el backdrop cubre la página mientras dura la petición y se cierra solo al terminar; después un Snackbar confirma el resultado. El nombre del proyecto es un TextField.

Ejemplos reales open_in_new
import { useEffect, useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { TextField } from '@rubenchodev/materix-react/components/text-field';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [saving, setSaving] = useState(false);
  const [saved, setSaved] = useState(false);

  useEffect(() => {
    if (!saving) return undefined;
    const timer = setTimeout(() => {
      setSaving(false);
      setSaved(true);
    }, 2000);
    return () => clearTimeout(timer);
  }, [saving]);

  return (
    <Stack component="form" spacing={2} alignItems="flex-start" onSubmit={(event) => {
      event.preventDefault();
      setSaving(true);
    }}>
      <TextField label="Project name" variant="outlined" defaultValue="Materix UI" name="project" />
      <Button type="submit" variant="contained" startIcon="save">
        Save
      </Button>
      <Backdrop open={saving} lockScroll>
        <Stack spacing={2} alignItems="center">
          <CircularProgress color="inherit" decorative />
          <Typography variant="subtitle1" color="inherit" role="status">
            Saving changes…
          </Typography>
        </Stack>
      </Backdrop>
      <Snackbar open={saved} onClose={() => setSaved(false)} message="Project saved" role="status" autoHideDuration={4000} />
    </Stack>
  );
}

Maquetación en grilla#

La capa se renderiza en un portal (el contenedor compartido [data-mtx-portal-root] al final de <body>) y no participa en la maquetación; aquí una grilla de disparadores abre el mismo backdrop con mensajes distintos.

Maquetación en grilla open_in_new
import { useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Grid } from '@rubenchodev/materix-react/components/grid';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

const ACTIONS = [
  { label: 'Export', message: 'Exporting report…' },
  { label: 'Invite', message: 'Sending invitations…' },
  { label: 'Archive', message: 'Archiving project…' },
];

export default function Demo() {
  const [message, setMessage] = useState<string | null>(null);
  const [lastMessage, setLastMessage] = useState('');
  const show = (text: string) => {
    setLastMessage(text);
    setMessage(text);
  };
  return (
    <>
      <Grid container spacing={2}>
        {ACTIONS.map(({ label, message: text }) => (
          <Grid key={label} size={{ xs: 12, sm: 4 }}>
            <Button variant="outlined" fullWidth onClick={() => show(text)}>
              {label}
            </Button>
          </Grid>
        ))}
      </Grid>
      <Backdrop open={message !== null} onClose={() => setMessage(null)} closeOnClick closeOnEscape>
        <Stack spacing={2} alignItems="center">
          <CircularProgress color="inherit" decorative />
          <Typography variant="subtitle1" color="inherit" role="status">
            {lastMessage}
          </Typography>
        </Stack>
      </Backdrop>
    </>
  );
}

Uso programático#

El equivalente de open()/close() es la prop open. No hay toggle(): el estado vive en tu componente, así que alternar es setOpen((value) => !value). onOpen y onClose(event, reason) equivalen a mtx:backdrop:open y mtx:backdrop:close; onExited se llama al terminar el fundido de salida.

Uso programático open_in_new
import { useEffect, useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [auto, setAuto] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [...lines, `${new Date().toLocaleTimeString()}  ${text}`]);

  useEffect(() => {
    if (!auto) return undefined;
    const timer = setTimeout(() => {
      setAuto(false);
      setOpen(false);
      write('open = false (after 1.5 s)');
    }, 1500);
    return () => clearTimeout(timer);
  }, [auto]);

  return (
    <Stack spacing={2}>
      <Stack direction="row" spacing={2} wrap alignItems="center">
        <Button variant="contained" onClick={() => setOpen(true)}>
          open = true
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setOpen(true);
            setAuto(true);
          }}
        >
          Open and close after 1.5 s
        </Button>
      </Stack>
      <Typography variant="caption" color="text-secondary" component="p" role="status">
        open: {String(open)}
      </Typography>
      <Backdrop
        open={open}
        closeOnClick
        closeOnEscape
        onOpen={() => write('onOpen')}
        onClose={(_event, reason) => {
          write(`onClose   reason: ${reason}`);
          setAuto(false);
          setOpen(false);
        }}
        onExited={() => write('onExited')}
      >
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </Stack>
  );
}

Reutilización en otros overlays#

Dialog, Drawer y otros componentes modales pintan Backdrop como capa de fondo. Estas son las props en las que se apoyan:

<Backdrop
  open={open}                 // muestra la capa con el fundido
  invisible={false}           // capa transparente para menús y popovers
  onClick={handleBackdropClick} // siempre se llama, antes de la lógica de cierre
  className="mtx-dialog__backdrop"
  transitionDuration={{ enter: 225, exit: 195 }}
  disablePortal               // el overlay ya se renderiza dentro de su propio portal
/>

Referencia de la API#

Props de Backdrop#

PropTipoPor defectoDescripción
openboolean—Muestra la capa (controlado).
invisiblebooleanfalseCapa transparente (.mtx-backdrop--invisible).
closeOnClickbooleanfalseUn clic en la capa o en contenido no interactivo solicita el cierre.
closeOnEscapebooleanfalseEscape solicita el cierre (pila de capas).
lockScrollbooleanfalseBloquea el scroll del <body> mientras está abierto.
inertOthersbooleanfalseMarca el resto del documento como inert mientras está abierto.
onClick(event) => void—Clic en la capa; siempre se llama.
onClose(event, reason: 'click' | 'escape') => void—Solicitud de cierre.
onOpen() => void—open pasa de false a true.
onExited() => void—Terminó el fundido de salida.
transitionDurationnumber | { enter?, exit? }{ enter: 225, exit: 195 }Duración del fundido en ms.
disablePortalbooleanfalseRenderiza en su sitio en lugar de en la raíz de portales.
containerElement | ref | () => Element[data-mtx-portal-root] en <body>Destino del portal.
keepMountedbooleanfalseMantiene el nodo (con hidden) mientras está cerrado.

className se combina; ref, style (por ejemplo un zIndex propio) y cualquier otro atributo van al <div> raíz.

Accesibilidad#

  • Por defecto la capa se porta al final de <body>, fuera de tus landmarks. Si debe quedarse dentro de <main> (por ejemplo, para que su contenido pertenezca a ese landmark o herede su ámbito de tema), usa disablePortal; es position: fixed, así que sigue cubriendo el viewport.

  • El backdrop no tiene rol ni mueve el foco: es un indicador visual. Da un nombre accesible al indicador (CircularProgress label="Cargando").

  • Cerrado o durante el fundido de salida lleva aria-hidden="true".

  • Para que los usuarios de teclado y lector de pantalla no interactúen con la página mientras está ocupada, usa inertOthers. Para mensajes o decisiones usa un Dialog, que atrapa el foco.

TeclaAcción
EscapeCierra la capa con closeOnEscape (solo si es la capa superior).
TabRecorre el contenido interactivo de la capa.
