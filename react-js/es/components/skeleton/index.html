Skeleton

Placeholders con la forma del contenido mientras se cargan los datos, con animación pulse o wave.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Skeleton, SkeletonRegion } from '@rubenchodev/materix-react';

Skeleton muestra un bloque gris con la forma del contenido que todavía no ha llegado (texto, avatar, imagen, tarjeta). Reduce la espera percibida y evita saltos de maquetación cuando aparecen los datos. Úsalo en cargas cortas de contenido con estructura conocida; si no sabes qué forma tendrá el resultado, o la operación no carga contenido (guardar, enviar), usa Progress.

import { Skeleton, SkeletonRegion } from '@rubenchodev/materix-react';
// o solo este componente:
import { Skeleton, SkeletonRegion } from '@rubenchodev/materix-react/components/skeleton';

Uso básico#

Sin variante, <Skeleton /> es una línea de texto que ocupa el ancho disponible y toma la altura de la tipografía. width y height aceptan números (px) o cualquier unidad CSS.

Uso básico open_in_new
import { Skeleton } from '@rubenchodev/materix-react/components/skeleton';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <Skeleton />
      <Skeleton variant="circular" width={40} height={40} />
      <Skeleton variant="rectangular" width={210} height={60} />
      <Skeleton variant="rounded" width={210} height={60} />
    </div>
  );
}

Variantes#

Cuatro formas, como en MUI: text (por defecto, reducida al 60 % de la altura de línea), circular, rectangular (sin radio) y rounded (radio de 4px).

Variantes open_in_new
import { Skeleton } from '@rubenchodev/materix-react/components/skeleton';

export default function Demo() {
  return (
    <div className="demo-grid-4">
      <div className="demo-group">
        <span className="demo-label">text</span>
        <Skeleton variant="text" />
      </div>
      <div className="demo-group">
        <span className="demo-label">circular</span>
        <Skeleton variant="circular" width={56} height={56} />
      </div>
      <div className="demo-group">
        <span className="demo-label">rectangular</span>
        <Skeleton variant="rectangular" height={56} />
      </div>
      <div className="demo-group">
        <span className="demo-label">rounded</span>
        <Skeleton variant="rounded" height={56} />
      </div>
    </div>
  );
}

Animaciones#

animation="pulse" (por defecto), "wave" o false (estático; también se acepta la cadena "false"). Con prefers-reduced-motion: reduce la animación se desactiva automáticamente.

Animaciones open_in_new
import { Skeleton, type SkeletonAnimation } from '@rubenchodev/materix-react/components/skeleton';

const animations: SkeletonAnimation[] = ['pulse', 'wave', false];

export default function Demo() {
  return (
    <div className="demo-grid-3">
      {animations.map((animation) => (
        <div key={String(animation)} className="demo-group">
          <span className="demo-label">{String(animation)}</span>
          <Skeleton variant="rounded" height={80} animation={animation} />
        </div>
      ))}
    </div>
  );
}

Tamaños#

La variante text hereda el tamaño de la tipografía que la contiene: colócala dentro del mismo elemento que tendrá el texto real. Las formas circulares siguen los tamaños canónicos de Avatar (24, 40 y 56px).

Tamaños open_in_new
import { Skeleton } from '@rubenchodev/materix-react/components/skeleton';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      {(['h3', 'h5', 'body1'] as const).map((variant) => (
        <div key={variant} className="demo-group">
          <span className="demo-label">{variant}</span>
          <Typography variant={variant} component="div">
            <Skeleton />
          </Typography>
        </div>
      ))}
      <div className="demo-group">
        <span className="demo-label">caption</span>
        <Typography variant="caption" component="div">
          <Skeleton width="40%" />
        </Typography>
      </div>
      <div className="demo-row">
        <Skeleton variant="circular" width={24} height={24} />
        <Skeleton variant="circular" width={40} height={40} />
        <Skeleton variant="circular" width={56} height={56} />
      </div>
    </div>
  );
}

Párrafos#

lines={3} genera un bloque .mtx-skeleton-lines con varias líneas de texto; la última es más corta (60 % por defecto, configurable con lastWidth). Con lines, variant y height no tienen efecto.

Párrafos open_in_new
import { Skeleton } from '@rubenchodev/materix-react/components/skeleton';

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">3 líneas</span>
        <Skeleton lines={3} />
      </div>
      <div className="demo-group">
        <span className="demo-label">5 líneas · wave · la última al 30 %</span>
        <Skeleton lines={5} animation="wave" lastWidth="30%" />
      </div>
    </div>
  );
}

Con hijos#

Cuando el skeleton envuelve contenido, toma su tamaño exacto y lo oculta (visibility: hidden, clase .mtx-skeleton--with-children). El texto directo se envuelve en .mtx-skeleton__text para ocultarlo también, en lugar de dejar texto transparente que falla las comprobaciones de contraste.

Con hijos open_in_new
import { Avatar } from '@rubenchodev/materix-react/components/avatar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Skeleton } from '@rubenchodev/materix-react/components/skeleton';

export default function Demo() {
  return (
    <div className="demo-row">
      <Skeleton component="div" variant="circular">
        <Avatar icon="person" />
      </Skeleton>
      <Skeleton component="div" variant="rounded">
        <Button variant="contained" tabIndex={-1}>Guardar cambios</Button>
      </Skeleton>
      <Skeleton component="div" className="mtx-typography--h5">
        Un título de longitud real
      </Skeleton>
    </div>
  );
}

Estados#

Región de carga#

SkeletonRegion es el equivalente React de Materix.skeleton.set(). Mientras loading es true pone data-loading y aria-busy="true" en la raíz, muestra el placeholder (dentro de [data-skeleton-placeholder], siempre aria-hidden) y oculta los hijos (dentro de [data-skeleton-content]). Ambos contenedores siguen montados y el CSS oculta el inactivo, así que el contenido conserva su estado. Con aria-live="polite" el contenido se anuncia al terminar la carga. Usa placeholderProps y contentProps para dar estilo a los contenedores.

Estados open_in_new
import { useState } from 'react';
import { Avatar } from '@rubenchodev/materix-react/components/avatar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Skeleton, SkeletonRegion } from '@rubenchodev/materix-react/components/skeleton';
import { Typography } from '@rubenchodev/materix-react/components/typography';

const row = { className: 'mtx-d-flex mtx-align-items-center mtx-gap-2' };

export default function Demo() {
  const [loading, setLoading] = useState(true);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="outlined" aria-controls="skeleton-region" onClick={() => setLoading((value) => !value)}>
          Alternar carga
        </Button>
      </div>
      <SkeletonRegion
        id="skeleton-region"
        className="demo-fixed-width"
        aria-live="polite"
        loading={loading}
        placeholderProps={row}
        contentProps={row}
        placeholder={
          <>
            <Skeleton variant="circular" width={40} height={40} />
            <div className="mtx-flex-1">
              <Skeleton width="60%" />
              <Skeleton width="40%" />
            </div>
          </>
        }
      >
        <Avatar color="secondary">LM</Avatar>
        <div>
          <Typography variant="body1" component="div">Lucía Martín</Typography>
          <Typography variant="body2" color="text-secondary" component="div">Diseñadora de producto</Typography>
        </div>
      </SkeletonRegion>
    </div>
  );
}

Si prefieres desmontar el contenido durante la carga, también sirve el patrón de MUI: loading ? <Skeleton /> : <Contenido />.

Grilla#

Los bloques sin ancho fijo llenan su columna.

Grilla open_in_new
import { Grid } from '@rubenchodev/materix-react/components/grid';
import { Skeleton } from '@rubenchodev/materix-react/components/skeleton';

const columns = [6, 6, 12] as const;

export default function Demo() {
  return (
    <Grid container spacing={2} className="mtx-w-100">
      {columns.map((sm, i) => (
        <Grid key={i} xs={12} sm={sm} md={4}>
          <Skeleton variant="rounded" height={120} />
          <Skeleton />
          <Skeleton width="70%" />
        </Grid>
      ))}
    </Grid>
  );
}

Uso controlado#

variant y animation son props normales (sustituyen a setVariant() y setAnimation()); SkeletonRegion llama a onChange({ loading }) cada vez que cambia loading tras el montaje.

Uso controlado open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import {
  Skeleton,
  SkeletonRegion,
  type SkeletonAnimation,
  type SkeletonVariant,
} from '@rubenchodev/materix-react/components/skeleton';

const variants: SkeletonVariant[] = ['rounded', 'circular', 'rectangular', 'text'];
const animations: SkeletonAnimation[] = ['pulse', 'wave', false];

export default function Demo() {
  const [v, setV] = useState(0);
  const [a, setA] = useState(0);
  const [loading, setLoading] = useState(true);
  const [log, setLog] = useState<string[]>([]);
  const write = (line: string) => setLog((lines) => [line, ...lines].slice(0, 6));

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Skeleton variant={variants[v]} animation={animations[a]} width={120} height={120} />
        <SkeletonRegion
          loading={loading}
          onChange={({ loading: value }) => write(`onChange → loading = ${value}`)}
          placeholder={<Skeleton width={160} />}
        >
          Contenido cargado
        </SkeletonRegion>
      </div>
      <div className="demo-row">
        <Button
          variant="outlined"
          onClick={() => {
            const next = (v + 1) % variants.length;
            setV(next);
            write(`variant="${variants[next]}"`);
          }}
        >
          Cambiar variante
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            const next = (a + 1) % animations.length;
            setA(next);
            write(`animation=${JSON.stringify(animations[next])}`);
          }}
        >
          Cambiar animación
        </Button>
        <Button variant="outlined" onClick={() => setLoading((value) => !value)}>
          Alternar carga
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">{log.join('\n')}</pre>
    </div>
  );
}

Accesibilidad#

  • Todos los skeletons son decorativos (aria-hidden="true").
  • Anuncia el estado de carga en el contenedor: SkeletonRegion fija aria-busy y, con aria-live="polite", el contenido se lee al llegar.
  • Las animaciones respetan prefers-reduced-motion.
