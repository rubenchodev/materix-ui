List

Lista vertical continua de texto, iconos o avatares; con ítems estáticos o interactivos, subcabeceras, densidad y selección.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { List, ListItem, ListItemButton, ListItemText, ListItemIcon, ListItemAvatar, ListItemSecondaryAction, ListSubheader } from '@rubenchodev/materix-react';

List agrupa elementos relacionados en una columna continua: menús de navegación, bandejas de entrada, ajustes o resultados. Cada fila puede llevar icono o avatar, texto principal y secundario y una acción al final. Para datos con varias columnas comparables usa Table; para un menú flotante usa Menu.

import { List, ListItem, ListItemButton } from '@rubenchodev/materix-react';
// o solo este componente:
import { List, ListItem } from '@rubenchodev/materix-react/components/list';

Uso básico#

Una List (un <ul>) con filas ListItem (<li>). La prop icon añade el icono y secondary el texto secundario; los hijos de texto son el texto principal (el equivalente a la sintaxis simplificada de vanilla).

Uso básico open_in_new
import { List, ListItem } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';

export default function Demo() {
  return (
    <Paper variant="outlined" className="demo-fixed-width">
      <List aria-label="Mail">
        <ListItem icon="inbox" secondary="3 new messages">
          Inbox
        </ListItem>
        <ListItem icon="drafts" secondary="Saved 2 hours ago">
          Drafts
        </ListItem>
        <ListItem icon="send">Sent</ListItem>
      </List>
    </Paper>
  );
}

Contenido de la fila#

Solo texto, con icono, con avatar y con texto principal y secundario. avatar acepta una URL de imagen (se pinta como Avatar con avatarAlt, decorativo por defecto) o cualquier nodo, por ejemplo un <Avatar>; se envuelve en ListItemAvatar (56px). alignItems="flex-start" alinea el avatar con la primera línea de los textos largos.

Filas interactivas#

ListItemButton pinta un <button type="button"> (o un <a> con href) con hover, foco, ripple y selección: al pulsar una fila se selecciona y se deselecciona la anterior dentro de la misma List. La selección es no controlada por defecto (defaultValue, el value de la fila inicial) o controlada con value + onSelect. Con selectable={false} las filas solo ejecutan su acción.

Subcabeceras#

ListSubheader titula grupos (un <li> por defecto). inset alinea el título con el texto de las filas con icono; sticky lo fija mientras la lista se desplaza. También puedes pasarla con la prop subheader de List.

Subcabeceras open_in_new
import { List, ListItem, ListSubheader } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';

const contacts = [
  { letter: 'A', names: ['Anna Garcia', 'Andrew Lopez', 'Ariana Stone'] },
  { letter: 'C', names: ['Charles Reed', 'Carmen Vidal'] },
  { letter: 'L', names: ['Lucy Mendez', 'Luis Perez'] },
];

/** Alto del contenedor desplazable que demuestra las subcabeceras fijas. */
const scrollArea = { maxHeight: 240, overflow: 'auto' } as const;

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Inset</span>
        <Paper variant="outlined">
          <List aria-label="Settings by category">
            <ListSubheader inset>General</ListSubheader>
            <ListItem icon="account_circle">Account</ListItem>
            <ListItem icon="security">Privacy</ListItem>
            <ListSubheader inset>Communications</ListSubheader>
            <ListItem icon="notifications">Notifications</ListItem>
          </List>
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">Sticky (scroll the list)</span>
        <Paper variant="outlined">
          <List aria-label="Contacts by letter" tabIndex={0} style={scrollArea}>
            {contacts.map((group) => [
              <ListSubheader key={group.letter} sticky>
                {group.letter}
              </ListSubheader>,
              ...group.names.map((name) => <ListItem key={name}>{name}</ListItem>),
            ])}
          </List>
        </Paper>
      </div>
    </div>
  );
}

Listas anidadas#

Una List con nested dentro de una fila sangra sus filas 48px (nested={2}: 72px) y comparte la selección de la lista padre. Envuélvela en Collapse (exportado por el paquete) para desplegarla y plegarla; la fila padre usa aria-expanded, aria-controls y disableSelect para no quedar seleccionada.

Anidadas open_in_new
import { useId, useState } from 'react';
import { Collapse } from '@rubenchodev/materix-react';
import { List, ListItemButton } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';

export default function Demo() {
  const [open, setOpen] = useState(true);
  const nestedId = useId();
  return (
    <Paper variant="outlined" className="demo-fixed-width">
      <List aria-label="Folders">
        <li>
          <ListItemButton
            icon="inbox"
            primary="Inbox"
            disableSelect
            aria-expanded={open}
            aria-controls={nestedId}
            onClick={() => setOpen((value) => !value)}
          >
            <span className="material-icons" aria-hidden="true">
              {open ? 'expand_less' : 'expand_more'}
            </span>
          </ListItemButton>
          <Collapse in={open}>
            <List nested id={nestedId} aria-label="Subfolders">
              <li>
                <ListItemButton icon="star_border">Starred</ListItemButton>
              </li>
              <li>
                <ListItemButton icon="label">Invoices</ListItemButton>
              </li>
            </List>
          </Collapse>
        </li>
        <li>
          <ListItemButton icon="send">Sent</ListItemButton>
        </li>
      </List>
    </Paper>
  );
}

Acciones secundarias#

secondaryAction en ListItem pinta la acción en ListItemSecondaryAction: alineada al final, admite varias acciones de cualquier ancho y un IconButton final se ajusta al borde. Para una fila pulsable con una acción aparte, usa un ListItem disablePadding con el ListItemButton como hijo y la acción en secondaryAction.

Uso programático#

onSelect es el equivalente al evento vanilla mtx:list:select: recibe { item, value } (el elemento de la fila y su valor). El setter selected y disable()/enable() pasan a la prop value de List (o selected en la fila) y disabled.

Uso programático open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { List, ListItemButton } from '@rubenchodev/materix-react/components/list';
import type { ListSelectDetail } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';

export default function Demo() {
  const [value, setValue] = useState<string | null>(null);
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((prev) => [...prev.slice(-5), text]);

  const handleSelect = ({ item, value: next }: ListSelectDetail) => {
    setValue(next);
    write(`onSelect  value: "${next}" · item: "${item.textContent?.trim()}"`);
  };

  return (
    <div className="demo-stack">
      <Paper variant="outlined" className="demo-fixed-width">
        <List aria-label="Views" value={value} onSelect={handleSelect}>
          <li>
            <ListItemButton value="list" icon="view_list">
              List
            </ListItemButton>
          </li>
          <li>
            <ListItemButton value="grid" icon="grid_view">
              Grid
            </ListItemButton>
          </li>
          <li>
            <ListItemButton value="calendar" icon="calendar_month" disabled={disabled}>
              Calendar
            </ListItemButton>
          </li>
        </List>
      </Paper>
      <div className="demo-row">
        <Button
          variant="outlined"
          onClick={() => {
            setValue('calendar');
            write('value="calendar"');
          }}
        >
          Select Calendar
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setValue(null);
            write('value={null}');
          }}
        >
          Clear selection
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setDisabled((current) => !current);
            write(`Calendar disabled={${!disabled}}`);
          }}
        >
          Toggle disabled
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Clases CSS#

Las mismas que la librería vanilla: mtx-list (--dense, --nested, --nested-2, --disable-padding), mtx-list-item (--dense, --divider, --align-start, --disable-padding, --disable-gutters, --selected, --disabled), mtx-list-item-button, mtx-list-item-icon, mtx-list-item-avatar, mtx-list-item-secondary-action, mtx-list-item-text (__primary, __secondary) y mtx-list-subheader (--inset, --sticky).

Accesibilidad#

  • Mantén <ul>/<li> para que los lectores de pantalla anuncien el número de elementos, y nombra la lista con aria-label si no tiene un título visible.
  • Las filas interactivas deben ser un <button> (acciones) o un <a href> (navegación) dentro de un <li>; con component y sin role, la fila recibe role="button", tabIndex={0} y Enter/Espacio.
  • La selección se comunica con ARIA válido para cada elemento: un <a> recibe aria-current="page"; un <button>, aria-current="true"; solo las filas con role="option" o role="tab" (u otro rol seleccionable) reciben aria-selected.
  • Los iconos generados con icon son decorativos; el texto de la fila es el nombre accesible. Los botones de acción secundaria necesitan su propio aria-label.
