Tabs

Pestañas para alternar entre vistas del mismo nivel, con indicador animado, iconos, orientación vertical y navegación completa por teclado.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Tabs, Tab, TabPanel, TabContext, TabsContainer } from '@rubenchodev/materix-react';

Tabs organiza contenido relacionado en vistas del mismo nivel y permite alternar entre ellas sin salir de la página, con un indicador que se desliza bajo la pestaña activa. Úsalo cuando haya entre dos y unas siete secciones hermanas que se consultan de una en una (perfil, seguridad, notificaciones). No lo uses para pasos secuenciales ni para navegar entre páginas principales.

import '@rubenchodev/materix-ui/base.css';
import { Tab, TabContext, TabPanel, Tabs, TabsContainer } from '@rubenchodev/materix-react';

<TabContext defaultValue="overview">
  <Tabs aria-label="Proyecto">
    <Tab value="overview" label="Resumen" />
    <Tab value="activity" label="Actividad" />
  </Tabs>
  <TabPanel value="overview">…</TabPanel>
  <TabPanel value="activity">…</TabPanel>
</TabContext>

Uso básico#

TabContext comparte el valor activo entre Tabs y los TabPanel: genera los ids, enlaza aria-controls / aria-labelledby y oculta los paneles inactivos con hidden. Sin defaultValue, se activa la primera pestaña habilitada. TabsContainer es opcional: agrupa pestañas y paneles sobre una superficie con borde (.mtx-tabs-container).

Uso básico open_in_new
import { Tab, TabContext, TabPanel, Tabs, TabsContainer } from '@rubenchodev/materix-react/components/tabs';

export default function Demo() {
  return (
    <TabContext defaultValue="overview">
      <TabsContainer>
        <Tabs aria-label="Project">
          <Tab value="overview" label="Overview" />
          <Tab value="activity" label="Activity" />
          <Tab value="settings" label="Settings" />
        </Tabs>
        <TabPanel value="overview">Project overview: 12 open tasks and 3 pending reviews.</TabPanel>
        <TabPanel value="activity">Last activity 5 minutes ago.</TabPanel>
        <TabPanel value="settings">Project preferences.</TabPanel>
      </TabsContainer>
    </TabContext>
  );
}

Variantes#

Por defecto las pestañas tienen su ancho natural (variant="standard"). variant="fullWidth" reparte el ancho entre ellas y centered las centra. Un Tab sin value recibe su índice, así que una barra sin paneles solo necesita hijos <Tab label>. TabsContainer añade una superficie con borde; con borderless solo agrupa.

Variantes open_in_new

Con y sin iconos#

icon acepta un nombre de Material Icons (se pinta como <span class="material-icons mtx-tab__icon"> decorativo) o un nodo propio. iconPosition="start" (por defecto) o "end". Las pestañas de solo icono necesitan aria-label.

Colores#

La pestaña activa y el indicador usan --mtx-color-primary; como en vanilla, no hay props textColor / indicatorColor. Para otro tono, redefine el token en un contenedor.

Colores open_in_new
import type { CSSProperties } from 'react';
import { Tab, Tabs } from '@rubenchodev/materix-react/components/tabs';

/** El color activo sale de `--mtx-color-primary`: se redefine en un contenedor. */
const secondary = { '--mtx-color-primary': 'var(--mtx-color-secondary)' } as CSSProperties;

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">primary · default</span>
        <Tabs aria-label="Primary">
          <Tab label="Item one" />
          <Tab label="Item two" />
        </Tabs>
      </div>
      <div className="demo-group">
        <span className="demo-label">--mtx-color-primary: var(--mtx-color-secondary)</span>
        <div style={secondary}>
          <Tabs aria-label="Secondary">
            <Tab label="Item one" />
            <Tab label="Item two" />
          </Tabs>
        </div>
      </div>
    </div>
  );
}

Estados#

Una pestaña disabled se atenúa, no responde a clics y el teclado la salta. Pasa el ratón para ver el fondo de hover, pulsa para ver el ripple (disableRipple lo desactiva) y usa Tab para ver el anillo de foco.

Estados open_in_new
import { Tab, Tabs } from '@rubenchodev/materix-react/components/tabs';

export default function Demo() {
  return (
    <div className="demo-group">
      <span className="demo-label">Active · disabled · available (hover, focus-visible, pressed)</span>
      <Tabs aria-label="States">
        <Tab label="Active" />
        <Tab label="Disabled" disabled />
        <Tab label="Available" />
      </Tabs>
    </div>
  );
}

Desplazable#

Si las pestañas no caben, la barra se desplaza en horizontal (táctil, rueda o teclado) y el indicador sigue a la pestaña activa. La barra de desplazamiento está oculta y no hay botones de flecha (a diferencia del variant="scrollable" de MUI).

Desplazable open_in_new
import { Tab, Tabs } from '@rubenchodev/materix-react/components/tabs';

const MONTHS = [
  'January',
  'February',
  'March',
  'April',
  'May',
  'June',
  'July',
  'August',
  'September',
  'October',
  'November',
  'December',
];

export default function Demo() {
  return (
    <Tabs aria-label="Months">
      {MONTHS.map((month) => (
        <Tab key={month} value={month} label={month} />
      ))}
    </Tabs>
  );
}

orientation="vertical" apila las pestañas, coloca el indicador a la derecha y cambia las flechas a ↑/↓. Un Stack en fila coloca los paneles junto a la barra.

Activación manual y automática#

Por defecto las flechas solo mueven el foco y la pestaña se activa con Enter o Espacio (activación manual, recomendada por WAI-ARIA cuando cargar un panel es costoso). Con selectionFollowsFocus la pestaña se activa en cuanto recibe el foco.

Activación manual y automática open_in_new
import { Tab, TabContext, TabPanel, Tabs, TabsContainer } from '@rubenchodev/materix-react/components/tabs';

function Group({ follows }: { follows: boolean }) {
  return (
    <TabContext defaultValue="day">
      <TabsContainer>
        <Tabs selectionFollowsFocus={follows} aria-label={follows ? 'Automatic activation' : 'Manual activation'}>
          <Tab value="day" label="Day" />
          <Tab value="week" label="Week" />
          <Tab value="month" label="Month" />
        </Tabs>
        <TabPanel value="day">Daily view.</TabPanel>
        <TabPanel value="week">Weekly view.</TabPanel>
        <TabPanel value="month">Monthly view.</TabPanel>
      </TabsContainer>
    </TabContext>
  );
}

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Manual · arrows move focus, Enter/Space activate</span>
        <Group follows={false} />
      </div>
      <div className="demo-group">
        <span className="demo-label">selectionFollowsFocus · arrows activate</span>
        <Group follows />
      </div>
    </div>
  );
}

Uso controlado y cambio cancelable#

Controla el valor con value + onChange en TabContext (o directamente en Tabs si no hay paneles). onBeforeChange(value, previousValue) se ejecuta antes del cambio: si devuelve false, lo cancela (equivale al cancelable mtx:tabs:before-change).

Uso controlado y cambio cancelable open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Tab, TabContext, TabPanel, Tabs, TabsContainer } from '@rubenchodev/materix-react/components/tabs';
import type { TabValue } from '@rubenchodev/materix-react/components/tabs';

export default function Demo() {
  const [value, setValue] = useState<TabValue>('general');
  const [log, setLog] = useState<string[]>([]);
  const write = (message: string) => setLog((prev) => [message, ...prev].slice(0, 12));

  return (
    <div className="demo-stack">
      <TabContext value={value} onChange={(_, next) => setValue(next)}>
        <TabsContainer>
          <Tabs
            aria-label="Settings"
            onBeforeChange={(next, previous) => {
              if (next === 'locked') {
                write(`onBeforeChange(${next}, ${previous}) → false: change cancelled`);
                return false;
              }
              return true;
            }}
            onChange={(_, next) => write(`onChange → ${next}`)}
          >
            <Tab value="general" label="General" />
            <Tab value="advanced" label="Advanced" />
            <Tab value="locked" label="Locked" />
          </Tabs>
          <TabPanel value="general">General settings.</TabPanel>
          <TabPanel value="advanced">Advanced settings.</TabPanel>
          <TabPanel value="locked">Should never be visible.</TabPanel>
        </TabsContainer>
      </TabContext>
      <Stack direction="row" spacing={1} wrap alignItems="center">
        <Button variant="outlined" size="small" onClick={() => setValue('general')}>
          value = &apos;general&apos;
        </Button>
        <Button variant="outlined" size="small" onClick={() => setValue('advanced')}>
          value = &apos;advanced&apos;
        </Button>
        <span className="demo-status">value: {String(value)}</span>
      </Stack>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}
const [value, setValue] = useState('general');

<Tabs value={value} onChange={(event, next) => setValue(next)} onBeforeChange={(next) => next !== 'locked'}>
  <Tab value="general" label="General" />
  <Tab value="locked" label="Bloqueada" />
</Tabs>;

Accesibilidad#

  • La barra tiene role="tablist" y aria-orientation; cada pestaña role="tab", aria-selected y, con TabPanel, aria-controls; cada panel role="tabpanel" y aria-labelledby.
  • Roving tabindex: solo la pestaña activa está en el orden de tabulación (tabindex="0"); a las demás se llega con las flechas.
  • Las pestañas deshabilitadas llevan aria-disabled="true" y el teclado las salta.
  • Nombra la barra con aria-label y da aria-label a las pestañas de solo icono; el icono generado es decorativo.
