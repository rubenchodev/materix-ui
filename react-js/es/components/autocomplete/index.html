Autocomplete

Campo de texto con sugerencias filtrables: selección única o múltiple con chips, valores libres, grupos y carga asíncrona.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Autocomplete } from '@rubenchodev/materix-react';

Autocomplete es un campo de texto enriquecido con una lista de sugerencias: el usuario escribe, la lista se filtra (sin distinguir mayúsculas ni tildes) y elige con el ratón o el teclado. Sigue el patrón WAI-ARIA 1.2 combobox con listbox. Úsalo cuando la lista es larga y buscar es más rápido que desplazarse, cuando los valores vienen de un servidor o cuando se admiten valores libres. Para listas cortas sin búsqueda usa Select o NativeSelect; para texto libre sin sugerencias, TextField.

import '@rubenchodev/materix-ui/base.css';
import { Autocomplete } from '@rubenchodev/materix-react';

<Autocomplete
  label="País"
  name="country"
  options={[
    { value: 'co', label: 'Colombia' },
    { value: 'mx', label: 'México' },
  ]}
/>

Uso básico#

Basta un elemento con label y options: el componente pinta el TextField (label, borde con muesca), los botones de limpiar y abrir, el listbox en un portal y el input oculto que envía el value de la opción con el name. Escribe para filtrar, sin distinguir mayúsculas ni tildes.

Uso básico open_in_new
import { Autocomplete } from '@rubenchodev/materix-react/components/autocomplete';
import { COUNTRIES } from './data';

export default function Demo() {
  return (
    <div className="demo-fixed-width">
      <Autocomplete label="Country" options={COUNTRIES} name="country" />
    </div>
  );
}

Las opciones pueden ser textos u objetos { value, label, group?, disabled?, icon?, description? }, el mismo formato que vanilla. Cualquier otra forma funciona con getOptionLabel (y getOptionValue para la clave enviada).

Grupos y opciones deshabilitadas#

group en cada opción (o groupBy) muestra una cabecera fija; las opciones consecutivas del mismo grupo se agrupan, como en MUI. Las opciones deshabilitadas (disabled o getOptionDisabled) se saltan con el teclado y no admiten clic. El campo de zona horaria usa objetos propios con getOptionLabel, getOptionValue y groupBy.

Carga asíncrona#

Escucha onInputChange (con debounce={300} el motivo input espera a que el usuario deje de escribir), activa loading, pide los datos y pasa las nuevas options. filterOptions={false} deja el filtrado al servidor (y desactiva el resaltado). La demo simula 800 ms de latencia y cancela la petición pendiente en cada búsqueda nueva y al desmontar.

Carga asíncrona open_in_new
import { useEffect, useRef, useState } from 'react';
import { Autocomplete } from '@rubenchodev/materix-react/components/autocomplete';
import type { AutocompleteOption } from '@rubenchodev/materix-react/components/autocomplete';

const REPOS = [
  'materix-ui', 'material-ui', 'mui-x', 'vite', 'vitest', 'hugo', 'react', 'vue', 'svelte',
  'angular', 'bootstrap', 'tailwindcss', 'lit', 'preact', 'solid', 'alpine', 'htmx', 'jquery',
];

/**
 * Simula una búsqueda remota con 800 ms de latencia; se cancela con la señal.
 * @param {string} query Texto buscado.
 * @param {AbortSignal} signal Señal de cancelación.
 * @returns {Promise<AutocompleteOption[]>} Resultados.
 */
function searchRepos(query: string, signal: AbortSignal): Promise<AutocompleteOption[]> {
  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => {
      const q = query.toLowerCase();
      resolve(
        REPOS.filter((name) => name.includes(q)).map((name, i) => ({
          value: name,
          label: name,
          description: `${1200 - i * 57} stars`,
        })),
      );
    }, 800);
    signal.addEventListener('abort', () => {
      clearTimeout(timer);
      reject(new DOMException('Aborted', 'AbortError'));
    });
  });
}

export default function Demo() {
  const [options, setOptions] = useState<AutocompleteOption[]>([]);
  const [loading, setLoading] = useState(false);
  const controller = useRef<AbortController | null>(null);

  // Cancela la petición pendiente al desmontar.
  useEffect(() => () => controller.current?.abort(), []);

  const search = (query: string) => {
    controller.current?.abort();
    const text = query.trim();
    if (!text) {
      setOptions([]);
      setLoading(false);
      return;
    }
    const current = new AbortController();
    controller.current = current;
    setLoading(true);
    searchRepos(text, current.signal)
      .then((results) => {
        setOptions(results);
        setLoading(false);
      })
      .catch(() => undefined);
  };

  return (
    <div className="demo-fixed-width">
      <Autocomplete
        label="Repository"
        name="repo"
        startIcon="search"
        debounce={300}
        filterOptions={false}
        options={options}
        loading={loading}
        onInputChange={(_event, value, reason) => {
          if (reason === 'input') search(value);
        }}
      />
    </div>
  );
}
const [options, setOptions] = useState([]);
const [loading, setLoading] = useState(false);

<Autocomplete
  label="Repositorio"
  debounce={300}
  filterOptions={false}
  options={options}
  loading={loading}
  onInputChange={async (_event, text, reason) => {
    if (reason !== 'input') return;
    setLoading(true);
    setOptions(await searchRepos(text)); // [{ value, label, description }]
    setLoading(false);
  }}
/>

El valor seleccionado conserva su etiqueta cuando llegan opciones nuevas: un defaultValue="co" muestra “co” hasta que se carga una opción con ese value y entonces “Colombia”.

Formularios#

name pasa a inputs ocultos: uno con el valor en selección única; uno por valor en múltiple (como <select multiple>) o un único campo con valueFormat="csv" (y separator). required usa la validación nativa (un texto escrito que no es una opción no es válido salvo con freeSolo); el reset del formulario restaura el valor inicial.

Formulario open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Autocomplete } from '@rubenchodev/materix-react/components/autocomplete';
import { Button } from '@rubenchodev/materix-react/components/button';
import { COUNTRIES } from './data';

const LANGUAGES = [
  { value: 'en', label: 'English' },
  { value: 'es', label: 'Spanish' },
  { value: 'pt', label: 'Portuguese' },
  { value: 'fr', label: 'French' },
];

export default function Demo() {
  const [log, setLog] = useState('');

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const form = event.currentTarget;
    if (!form.checkValidity()) {
      form.reportValidity();
      setLog('Invalid form');
      return;
    }
    const pairs: string[] = [];
    new FormData(form).forEach((value, key) => pairs.push(`${key}=${String(value)}`));
    setLog(`submit → ${pairs.join('&')}`);
  };

  return (
    <form className="demo-stack demo-wide" noValidate onSubmit={handleSubmit} onReset={() => setLog('reset')}>
      <Autocomplete label="Country of residence" options={COUNTRIES} name="country" required />
      <Autocomplete label="Languages" multiple name="languages" options={LANGUAGES} defaultValue={['en']} />
      <Autocomplete label="Interests (CSV)" multiple freeSolo name="interests" valueFormat="csv" options={['design', 'music', 'travel']} />
      <div className="demo-row">
        <Button variant="contained" type="submit">
          Submit
        </Button>
        <Button variant="text" type="reset">
          Reset
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log}
      </pre>
    </form>
  );
}

Uso controlado#

  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const inputRef = useRef<HTMLInputElement>(null);

  const write = (line: string) => setLog((prev) => [...prev.slice(-7), line]);

  return (
    <div className="demo-stack">
      <div className="demo-fixed-width">
        <Autocomplete
          label="Movie"
          options={options}
          value={value}
          open={open}
          disabled={disabled}
          inputRef={inputRef}
          onChange={(_event, next, reason) => {
            setValue(next);
            const key = next && typeof next === 'object' ? next.value : next;
            write(`onChange → ${JSON.stringify({ value: key, reason })}`);
          }}
          onInputChange={(_event, inputValue, reason) => write(`onInputChange → ${JSON.stringify({ inputValue, reason })}`)}
          onOpen={(_event, reason) => {
            setOpen(true);
            write(`onOpen → ${reason}`);
          }}
          onClose={(_event, reason) => {
            setOpen(false);
            write(`onClose → ${reason}`);
          }}
        />
      </div>
      <div className="demo-row">
        <Button variant="outlined" onClick={() => setValue('matrix')}>
          value = matrix
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            inputRef.current?.focus();
            setOpen(true);
          }}
        >
          Open
        </Button>
        <Button variant="outlined" onClick={() => setValue(null)}>
          Clear
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setOptions(OTHER_FILMS);
            write('options = [...3 grouped options]');
          }}
        >
          Change options
        </Button>
        <Button variant="outlined" onClick={() => setDisabled((prev) => !prev)}>
          {disabled ? 'Enable' : 'Disable'}
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accesibilidad#

  • Patrón WAI-ARIA 1.2 combobox con listbox: el foco permanece en el <input role="combobox"> con aria-autocomplete="list", aria-expanded (verdadero cuando hay opciones visibles), aria-controls (el listbox mientras está abierto) y aria-activedescendant (la opción activa).
  • La lista es un role="listbox" nombrado por el label (aria-labelledby, o aria-label sin label), con aria-multiselectable en múltiple y aria-busy durante la carga; cada opción es un role="option" con aria-selected y aria-disabled. Los grupos usan role="group" nombrado por su cabecera.
  • Una región viva role="status" anuncia “N resultados disponibles”, “Sin opciones” o “Cargando…” tras filtrar.
  • Los botones de limpiar y abrir/cerrar tienen aria-label traducido y quedan fuera del orden de tabulación (tabindex="-1"), como en MUI: todo se puede hacer con el teclado desde el campo.
  • aria-required, aria-readonly, aria-invalid y aria-describedby (texto de ayuda) se sincronizan; required usa la validación nativa.
  • Escape pasa por la pila común de capas: solo cierra la capa superior y no llega a un Dialog contenedor.
  • Los chips se alcanzan con las flechas desde el campo (tabindex="-1", fuera del orden de tabulación, como en MUI) y se eliminan con Retroceso/Supr.
