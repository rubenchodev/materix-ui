Avatar

Representa a una persona o entidad con una imagen, sus iniciales o un icono; AvatarGroup apila varios y resume el excedente.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Avatar, AvatarGroup } from '@rubenchodev/materix-react';

Avatar muestra la identidad de una persona o entidad en un espacio compacto: una foto, sus iniciales o un icono. Úsalo en listas de usuarios, cabeceras de tarjetas, comentarios o barras de aplicación. Si necesitas una etiqueta con texto que se pueda eliminar o pulsar, usa Chip; para un indicador numérico sobre un icono, usa Badge.

import { Avatar, AvatarGroup } from '@rubenchodev/materix-react';
// o solo este componente:
import { Avatar, AvatarGroup } from '@rubenchodev/materix-react/components/avatar';

Uso básico#

Las iniciales van como hijos, src genera la imagen e icon inserta un icono de Material (una cadena es el nombre del icono; también se acepta cualquier nodo, como un SVG).

Uso básico open_in_new
import { Avatar } from '@rubenchodev/materix-react/components/avatar';

export default function Demo() {
  return (
    <div className="demo-row">
      <Avatar color="primary">RD</Avatar>
      <Avatar icon="folder" color="secondary" role="img" aria-label="Folder" />
      <Avatar src="https://i.pravatar.cc/120?img=47" alt="Anna Grant" />
      <Avatar icon="assignment" variant="rounded" color="success" role="img" aria-label="Tasks" />
    </div>
  );
}

Tamaños#

Tamaños canónicos de 24, 40 (por defecto) y 56px con size="small|medium|large". Un número fija un tamaño personalizado en píxeles (ancho, alto y un tamaño de letra del 45 %).

Estados#

Avatar no es interactivo: sus estados son de contenido. Sin imagen ni icono está en modo fallback (.mtx-avatar--fallback) y muestra los hijos. Si la imagen no carga, el <img> recibe hidden, la raíz pasa a modo fallback y, si no hay hijos, se añade un .mtx-avatar__fallback con la inicial de alt (● sin alt), igual que en vanilla. Un src nuevo reintenta la carga.

Agrupación#

AvatarGroup solapa sus avatares. max (5 por defecto, mínimo 2) cuenta también el indicador +N; total cuenta usuarios que no se renderizan; spacing fija el solapamiento (medium = 8px, small = 16px, o píxeles). Los avatares excedentes siguen montados con hidden. El indicador +N tiene un aria-label traducido ({count} más) que surplusLabel sustituye.

Agrupación open_in_new
import { Avatar, AvatarGroup, type AvatarColor } from '@rubenchodev/materix-react/components/avatar';

const abc: Array<[string, AvatarColor]> = [['A', 'primary'], ['B', 'secondary'], ['C', 'success']];

export default function Demo() {
  return (
    <>
      <div className="demo-group">
        <span className="demo-label">max={'{4}'} with 6 children</span>
        <div className="demo-row">
          <AvatarGroup max={4} label="Participants">
            <Avatar src="https://i.pravatar.cc/120?img=5" alt="Anna Grant" />
            <Avatar src="https://i.pravatar.cc/120?img=12" alt="Chris Reed" />
            <Avatar color="primary">LM</Avatar>
            <Avatar color="secondary">JP</Avatar>
            <Avatar color="success">OT</Avatar>
            <Avatar color="warning">AS</Avatar>
          </AvatarGroup>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">total={'{24}'} with 3 children</span>
        <div className="demo-row">
          <AvatarGroup max={3} total={24} label="Design team" surplusLabel="{count} more people">
            <Avatar color="info">RD</Avatar>
            <Avatar color="error">JM</Avatar>
            <Avatar color="primary">LC</Avatar>
          </AvatarGroup>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Spacing: medium · small · 0</span>
        <div className="demo-row mtx-gap-3">
          {(['medium', 'small', 0] as const).map((spacing) => (
            <AvatarGroup key={spacing} spacing={spacing} label={`Spacing ${spacing}`}>
              {abc.map(([letter, color]) => (
                <Avatar key={letter} color={color}>{letter}</Avatar>
              ))}
            </AvatarGroup>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Small size in a group</span>
        <div className="demo-row">
          <AvatarGroup max={4} label="Reviewers">
            {(['primary', 'secondary', 'success', 'info', 'error'] as const).map((color, i) => (
              <Avatar key={color} size="small" color={color}>
                {String.fromCharCode(65 + i)}
              </Avatar>
            ))}
          </AvatarGroup>
        </div>
      </div>
    </>
  );
}

Uso controlado#

El grupo se recalcula en cada render, así que cambiar max, total o los hijos sustituye a los setters max/total y a refresh() de vanilla.

Uso controlado open_in_new
import { useState } from 'react';
import { Avatar, AvatarGroup, type AvatarColor } from '@rubenchodev/materix-react/components/avatar';
import { Button } from '@rubenchodev/materix-react/components/button';

const colors: AvatarColor[] = ['primary', 'secondary', 'success', 'info', 'warning', 'error'];

export default function Demo() {
  const [state, setState] = useState<{ max: number; total: number | null; count: number }>({ max: 5, total: null, count: 6 });
  const [log, setLog] = useState<string[]>([]);
  const apply = (call: string, patch: Partial<typeof state>) => {
    const next = { ...state, ...patch };
    setState(next);
    const total = Math.max(next.total ?? next.count, next.count);
    const visible = total <= next.max ? next.count : Math.max(1, next.max - 1);
    setLog((lines) => [...lines, `${call} → max: ${next.max}, total: ${total}, visible: ${visible}`].slice(-6));
  };
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <AvatarGroup max={state.max} total={state.total} label="Team">
          {Array.from({ length: state.count }, (_, i) => (
            <Avatar key={i} color={colors[i % colors.length]}>
              {String.fromCharCode(65 + (i % 26))}
            </Avatar>
          ))}
        </AvatarGroup>
      </div>
      <div className="demo-row">
        <Button variant="outlined" onClick={() => apply('max = 3', { max: 3 })}>max = 3</Button>
        <Button variant="outlined" onClick={() => apply('max = 5', { max: 5 })}>max = 5</Button>
        <Button variant="outlined" onClick={() => apply('total = 20', { total: 20 })}>total = 20</Button>
        <Button variant="outlined" onClick={() => apply('total = null', { total: null })}>total = null</Button>
        <Button variant="outlined" onClick={() => apply('add avatar', { count: state.count + 1 })}>Add avatar</Button>
      </div>
      <pre className="demo-log" aria-live="polite">{log.join('\n')}</pre>
    </div>
  );
}

API#

Props de Avatar#

PropTipoPor defectoDescripción
srcstring—Origen de la imagen.
altstring—Texto alternativo; su inicial es el fallback si la imagen falla.
srcSet / sizesstring—Atributos de imagen adaptable.
imgPropsImgHTMLAttributes—Atributos extra del <img> (onError se sigue llamando).
iconReactNode—Icono sin imagen: nombre de Material Icons o un nodo.
variant'circular' | 'rounded' | 'square''circular'Forma.
color'primary' | 'secondary' | 'error' | 'warning' | 'info' | 'success'—Color de fondo.
size'small' | 'medium' | 'large' | number—Tamaño canónico o píxeles.
componentElementType'div'Elemento o componente raíz.
className / ref—Se concatena / elemento raíz.

Props de AvatarGroup#

PropTipoPor defectoDescripción
maxnumber5Elementos visibles, incluido +N (mínimo 2).
totalnumber | null—Total lógico de usuarios.
spacing'small' | 'medium' | number'medium'Solapamiento (--mtx-avatar-group-overlap).
labelstring—Nombre accesible del grupo (aria-label).
surplusLabelstringtraducidoPlantilla de la etiqueta de +N; {count} = cantidad.
localestring—Idioma local de los textos.
className / ref—Se concatena / <div> raíz.

El resto de props se reenvía al elemento raíz. También se exportan las utilidades getAvatarInitial(alt) y getAvatarGroupLayout(count, max, total).

Callbacks#

Avatar y AvatarGroup no emiten eventos (usa imgProps.onError para saber cuándo falla una imagen).

Clases CSS#

ClaseDescripción
.mtx-avatarRaíz (40px, circular).
.mtx-avatar--fallbackSin imagen (o imagen rota).
.mtx-avatar__fallbackInicial generada cuando falla la imagen.
.mtx-avatar--rounded / --squareForma.
.mtx-avatar--small / --medium / --large24 / 40 / 56px.
.mtx-avatar--{color}Fondo de la paleta.
.mtx-avatar-groupGrupo.
.mtx-avatar--surplusIndicador +N.

Accesibilidad#

  • Con imagen, alt describe a la persona; usa alt="" cuando el nombre ya aparece al lado.
  • Los avatares de icono con significado necesitan role="img" y un aria-label; el icono generado es aria-hidden.
  • Da un label a AvatarGroup y mantén significativo el aria-label de +N (surplusLabel).
  • El fondo por defecto cumple contraste AA (4.6:1).
