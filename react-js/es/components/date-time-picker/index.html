Date Time Picker

Selectores de fecha, hora, fecha y hora y rangos con calendario, reloj radial MD2, popover, modal o modo estático, límites y formatos.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { DateTimePicker } from '@rubenchodev/materix-react';

DateTimePicker es un único componente que cubre DatePicker, TimePicker, DateTimePicker y sus versiones de rango (los alias fijan el modo por ti). Pinta un TextField con máscara y un botón de icono final, y abre un calendario o un reloj. Sigue el patrón WAI-ARIA Date Picker Dialog: un diálogo accesible, una cuadrícula de días navegable con teclado y un reloj radial manejable con las flechas. Úsalo cuando la fecha o la hora deban ser válidas y fáciles de elegir; para una fecha que el usuario conoce de memoria (p. ej. la de nacimiento) puede bastar un TextField con mask="date".

import { DatePicker, TimePicker, DateTimePicker, DateRangePicker } from '@rubenchodev/materix-react';
// o solo este componente:
import { DatePicker } from '@rubenchodev/materix-react/components/date-time-picker';

Uso básico#

Elige el componente según el modo. Todas las props de TextField (label, variant, size, helperText, startIcon, name…) funcionan igual. El campo también admite escritura: se aplica una máscara acorde al formato y, según el modo, solo se permiten dígitos, separadores (/ - .), : y las letras de AM/PM.

Popover, modal y estático#

  • Popover (por defecto): se despliega bajo el campo (dentro del TextField, como en vanilla), se ancla a la derecha o se abre hacia arriba si no hay espacio. En pantallas de 600px o menos se muestra centrado sobre un fondo oscuro, con aria-modal y trampa de foco.
  • Modal (display="modal"): un diálogo centrado con cabecera de color MD2 en cualquier tamaño de pantalla. Elegir un día no lo cierra; usa Aceptar.
  • Estático (displayStatic o los alias Static*): calendario o reloj incrustado en la página, sin campo ni botones Cancelar/Aceptar; cada elección llama a onChange.

Límites, valor inicial y formato#

minDate y maxDate deshabilitan los días fuera del intervalo; aceptan un Date, YYYY-MM-DD, el formato del propio campo o today/hoy. shouldDisableDate(date) deshabilita días concretos (se saltan al navegar con el teclado). defaultValue (no controlado) o value (controlado) aceptan un Date, un timestamp, texto ISO o texto en el formato activo.

Sin format, el orden de la fecha sale del locale (en/en-US: MM/DD/YYYY; es, es-MX, en-GB…: DD/MM/YYYY, resuelto con Intl). format define cómo se muestra y se escribe el valor (y deriva la máscara del campo). Tokens: YYYY/AAAA año, YY año corto, MM mes, DD día, HH hora 0-23, hh hora 1-12, mm minutos, ss segundos, A AM/PM y a am/pm. mask sustituye la máscara automática.

Idioma y textos#

Los textos (Hoy, Cancelar, Aceptar, nombres accesibles…) salen del sistema i18n de Materix: la prop locale, luego el I18nProvider y <html lang>. Los códigos regionales se reducen a su idioma base para los textos (es-MX → es) mientras que el código completo se usa con Intl (orden de fecha y nombres accesibles de los días). Meses y días de la semana salen del diccionario cuando el idioma está registrado y de Intl.DateTimeFormat en caso contrario (p. ej. fr-FR). todayText, cancelText, okText y clearText sustituyen los textos de los botones y actions elige los botones (today, clear, cancel, accept).

export const description = {
  en: 'Controlled `value`/`onChange` and `onOpen`/`onClose`, plus the `action` ref (`open()`, `close()`, `toggle()`, `clear()`). The log shows the callbacks equivalent to `mtx:date-time-picker:open`, `:close` and `:change` (a single call per selection).',
  es: '`value`/`onChange` controlados y `onOpen`/`onClose`, más la ref `action` (`open()`, `close()`, `toggle()`, `clear()`). El registro muestra los callbacks equivalentes a `mtx:date-time-picker:open`, `:close` y `:change` (una sola llamada por selección).',
};

export default function Demo() {
  const action = useRef<DateTimePickerActions>(null);
  const [value, setValue] = useState<Date | null>(null);
  const [range, setRange] = useState<DateRange>({ start: null, end: null });
  const [log, setLog] = useState<string[]>([]);
  const write = (message: string) =>
    setLog((prev) => [`${new Date().toLocaleTimeString()}  ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ['open()', () => action.current?.open()],
    ["value = '2026-12-25 20:00'", () => setValue(new Date(2026, 11, 25, 20, 0))],
    ['value = new Date()', () => setValue(new Date())],
    [
      "time = '09:15'",
      () =>
        setValue((prev) => {
          const base = prev ? new Date(prev) : new Date();
          base.setHours(9, 15, 0, 0);
          return base;
        }),
    ],
    ['read value', () => write(`value ${value ? value.toString() : 'null'} · iso ${value ? value.toISOString() : 'null'}`)],
    ["range = ['2026-10-01', '2026-10-15']", () => setRange({ start: new Date(2026, 9, 1), end: new Date(2026, 9, 15) })],
    ['read range', () => write(`range ${JSON.stringify(range)}`)],
    [
      'clear()',
      () => {
        action.current?.clear();
        setRange({ start: null, end: null });
      },
    ],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-grid-2">
        <div className="demo-group">
          <span className="demo-label">Date and time</span>
          <DateTimePicker
            label="Delivery"
            action={action}
            value={value}
            onChange={(next: DateTimePickerValue, detail) => {
              setValue(next instanceof Date ? next : null);
              write(`onChange → value "${detail.value}" · iso ${detail.iso}`);
            }}
            onAccept={(_, detail) => write(`onAccept → "${detail.value}"`)}
            onOpen={() => write('onOpen')}
            onClose={(reason) => write(`onClose (${reason})`)}
          />
        </div>
        <div className="demo-group">
          <span className="demo-label">Range</span>
          <DateRangePicker
            label="Period"
            value={range}
            onChange={(next, detail) => {
              setRange(next as DateRange);
              write(`onChange (range) → "${detail.value}"`);
            }}
          />
        </div>
      </div>
      <div className="demo-row">
        {actions.map(([label, run]) => (
          <Button key={label} variant="outlined" size="small" onClick={run}>
            {label}
          </Button>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Detalle de onChange#

{ value, date, dateTime, time, iso, isRange, startDate, endDate, range: { start, end } }, igual que el detail de vanilla (sin picker). onChange se llama una vez por selección aplicada: un día en modo fecha, el fin del rango, cada cambio de hora, Hoy, Aceptar, escribir un valor completo y válido, o vaciar el campo.

Accesibilidad#

  • Campo: un TextField con <label for>, máscara y aria-describedby. Un clic en el campo abre el selector sin robar el foco; Alt+↓ (o ↓ con él abierto) mueve el foco dentro.
  • Botón: aria-label (Elegir fecha, Elegir hora, Elegir fecha y hora, Elegir rango de fechas, más el valor actual), aria-haspopup="dialog", aria-expanded y aria-controls. Se deshabilita junto con el campo.
  • Diálogo: role="dialog" con aria-label traducido; el modal (y el popover en pantallas ≤ 600px) añade aria-modal="true" y atrapa Tab. Al abrir, el foco va al día seleccionado o a hoy; Esc lo cierra (solo si es la capa superior) y devuelve el foco. En modo popover, salir con Tab lo cierra; solo hay un selector abierto a la vez.
  • Calendario: role="grid" etiquetado por el título de mes/año (aria-live), celdas columnheader con el nombre completo del día y una row por semana. Cada día es un gridcell con aria-label completo (martes, 20 de octubre de 2026 con es-MX), aria-selected, aria-current="date" para hoy y aria-disabled. tabindex itinerante; los días deshabilitados se saltan.
  • Meses y años: role="radiogroup" con opciones radio, aria-checked y tabindex itinerante.
  • Reloj: role="slider" con aria-valuemin/max/now y aria-valuetext; tarjetas y AM/PM exponen aria-label y aria-pressed; las pestañas siguen el patrón Tabs.
