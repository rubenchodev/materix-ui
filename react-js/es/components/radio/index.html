Radio

Botón de radio para elegir exactamente una opción de un grupo visible; RadioGroup lee y establece el valor del grupo.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Radio, RadioGroup } from '@rubenchodev/materix-react';

Radio permite elegir exactamente una opción de un conjunto pequeño en el que conviene ver todas las alternativas a la vez (plan, método de envío, frecuencia). Cada opción es un <input type="radio"> nativo, así que la navegación con flechas y el envío del formulario funcionan sin código extra. RadioGroup comparte un name (lo genera si lo omites), gestiona el valor seleccionado y añade role="radiogroup", un rótulo y texto de ayuda/error.

import { Radio, RadioGroup } from '@rubenchodev/materix-react';

Uso básico#

Envuelve las opciones en un RadioGroup con label y defaultValue. Cada Radio solo necesita value y label.

Uso básico open_in_new
import { Radio, RadioGroup } from '@rubenchodev/materix-react/components/radio';

export default function Demo() {
  // demo-row: el FormControl conserva su ancho natural (en una columna flex se estiraría).
  return (
    <div className="demo-row">
      <RadioGroup label="Plan" defaultValue="basic">
        <Radio value="basic" label="Básico" />
        <Radio value="pro" label="Profesional" />
        <Radio value="enterprise" label="Empresa" />
      </RadioGroup>
    </div>
  );
}

Ayuda y error (FormHelperText)#

helperText añade un .mtx-form-helper-text bajo el grupo, enlazado con aria-describedby. Combina error con el mensaje en helperText para validar al enviar.

Ayuda y error (FormHelperText) open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Radio, RadioGroup } from '@rubenchodev/materix-react/components/radio';

export default function Demo() {
  const [size, setSize] = useState<string | null>(null);
  const [error, setError] = useState(false);

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    setError(size === null);
  };

  const handleReset = () => {
    setSize(null);
    setError(false);
  };

  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Texto de ayuda</span>
        <RadioGroup label="Facturación" helperText="Puedes cambiarla en cualquier momento." defaultValue="monthly">
          <Radio value="monthly" label="Mensual" />
          <Radio value="yearly" label="Anual (2 meses gratis)" />
        </RadioGroup>
      </div>
      <div className="demo-group">
        <span className="demo-label">Validación al enviar</span>
        <form className="demo-stack" noValidate onSubmit={handleSubmit} onReset={handleReset}>
          <RadioGroup
            label="Talla"
            row
            value={size}
            onChange={(_, value) => {
              setSize(value);
              setError(false);
            }}
            error={error}
            helperText={error ? 'Elige una talla para continuar.' : 'Consulta la guía de tallas.'}
          >
            <Radio value="s" label="S" />
            <Radio value="m" label="M" />
            <Radio value="l" label="L" />
          </RadioGroup>
          <div className="demo-row">
            <Button variant="contained" type="submit">
              Añadir al carrito
            </Button>
            <Button type="reset">
              Restablecer
            </Button>
          </div>
        </form>
      </div>
    </div>
  );
}

Ejemplos reales#

Un selector de método de envío que lee el valor elegido al continuar.

Casos de uso open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Radio, RadioGroup } from '@rubenchodev/materix-react/components/radio';

const LABELS: Record<string, string> = {
  standard: 'Estándar (3–5 días) · Gratis',
  express: 'Exprés (24 h) · $6,90',
  pickup: 'Recogida en tienda · Gratis',
};

export default function Demo() {
  const [shipping, setShipping] = useState('standard');
  const [status, setStatus] = useState('');
  return (
    <div className="demo-panel demo-wide">
      <RadioGroup label="Método de envío" value={shipping} onChange={(_, value) => setShipping(value)}>
        {Object.entries(LABELS).map(([value, label]) => (
          <Radio key={value} value={value} label={label} />
        ))}
      </RadioGroup>
      <div className="demo-row">
        <Button variant="contained" onClick={() => setStatus(`Seleccionado: ${LABELS[shipping]}`)}>
          Continuar
        </Button>
        <span className="demo-status" aria-live="polite">
          {status}
        </span>
      </div>
    </div>
  );
}

Uso controlado#

Con value + onChange la selección la gestiona el padre: group.value = 'low' de vanilla pasa a ser setValue('low'), disable()/setError() pasan a ser props y focus() usa inputRef.

Uso controlado open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Radio, RadioGroup } from '@rubenchodev/materix-react/components/radio';

export default function Demo() {
  const highRef = useRef<HTMLInputElement>(null);
  const [value, setValue] = useState<string | null>('medium');
  const [highDisabled, setHighDisabled] = useState(false);
  const [groupDisabled, setGroupDisabled] = useState(false);
  const [error, setError] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ["value = 'low'", () => setValue('low')],
    ["value = 'high'", () => setValue('high')],
    ['Alta: disabled = true', () => setHighDisabled(true)],
    ['Alta: disabled = false', () => setHighDisabled(false)],
    ['Alta: focus()', () => highRef.current?.focus()],
    ['grupo: error = true', () => setError(true)],
    ['grupo: error = false', () => setError(false)],
    ['grupo: disabled = true', () => setGroupDisabled(true)],
    ['grupo: disabled = false', () => setGroupDisabled(false)],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Grupo controlado</span>
        <RadioGroup
          row
          aria-label="Prioridad"
          value={value}
          disabled={groupDisabled}
          error={error}
          helperText={error ? 'Elige una prioridad.' : undefined}
          onChange={(_, next) => {
            setValue(next);
            write(`onChange → value: "${next}"`);
          }}
        >
          <Radio value="low" label="Baja" />
          <Radio value="medium" label="Media" />
          <Radio value="high" label="Alta" inputRef={highRef} disabled={highDisabled || undefined} />
        </RadioGroup>
        <span className="demo-status">value: &quot;{value ?? ''}&quot;</span>
      </div>
      <div className="demo-group">
        <span className="demo-label">Acciones</span>
        <div className="demo-row">
          {actions.map(([label, run]) => (
            <Button
              key={label}
              variant="outlined"
              size="small"
              onClick={() => {
                run();
                write(label);
              }}
            >
              {label}
            </Button>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Registro de eventos</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

PropTipoPor defectoDescripción

className, style y el resto de atributos van al elemento raíz de cada componente. useRadioGroup() devuelve el contexto del grupo (name, value —undefined si no es controlado—, defaultValue, disabled, onChange) para opciones propias. Un grupo no controlado usa radios nativos con defaultChecked, así que form.reset() restaura defaultValue. El grupo se renderiza siempre dentro de un .mtx-form-control estable.

Accesibilidad#

  • Los inputs nativos comparten el name del grupo: el navegador gestiona la exclusión mutua, el foco itinerante y las flechas.
  • RadioGroup renderiza role="radiogroup"; nómbralo con label, aria-label o aria-labelledby. El radio usa su estado nativo (sin aria-checked).
  • Toda la fila es clicable; sin label, usa aria-label en cada Radio.
  • error añade aria-invalid="true" al grupo y el texto de ayuda se enlaza con aria-describedby.
