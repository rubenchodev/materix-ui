Snackbar

Notificación breve y temporal en un borde de la pantalla que confirma una acción y puede ofrecer deshacerla.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Snackbar, SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react';

Snackbar muestra un mensaje corto y flotante en un borde de la pantalla para confirmar el resultado de una acción (“Correo enviado”, “Elemento eliminado”) y, opcionalmente, ofrecer una única acción como “Deshacer”. No interrumpe al usuario y puede cerrarse solo. No lo uses para errores que el usuario debe resolver (usa un Alert junto al contenido) ni para decisiones obligatorias (usa un Dialog).

import { Snackbar, SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react';
// o solo este componente:
import { Snackbar, SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react/components/snackbar';

Uso básico#

Basta con <Snackbar open={…} message="…">. open es controlado: onClose(event, reason) solicita el cierre y tú actualizas el estado. Se cierra con Escape, con un clic fuera o, con autoHideDuration, al agotarse el tiempo.

Uso básico open_in_new
import { useState } from 'react';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  const [open, setOpen] = useState(false);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="contained" onClick={() => setOpen(true)}>
        Show snackbar
      </Button>
      <Snackbar open={open} onClose={() => setOpen(false)} message="Message archived" autoHideDuration={4000} />
    </Stack>
  );
}

Con acción#

Una action de texto genera el botón .mtx-snackbar__action a la derecha; onAction se ejecuta al pulsarlo y closeOnAction cierra el snackbar (motivo action). Cualquier otro nodo (por ejemplo un IconButton) se pinta tal cual.

Con acción open_in_new
import { useState } from 'react';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [open, setOpen] = useState<'text' | 'node' | null>(null);
  const [status, setStatus] = useState('');
  const close = () => setOpen(null);
  return (
    <Stack spacing={2}>
      <Stack direction="row" spacing={2} wrap alignItems="center">
        <Button variant="outlined" onClick={() => setOpen('text')}>
          Delete email
        </Button>
        <Button variant="outlined" onClick={() => setOpen('node')}>
          Custom action
        </Button>
      </Stack>
      <Typography variant="caption" color="text-secondary" component="p" role="status">
        {status}
      </Typography>
      <Snackbar
        open={open === 'text'}
        onClose={close}
        message="Email deleted"
        action="Undo"
        onAction={() => setStatus('Email restored')}
        closeOnAction
        autoHideDuration={6000}
      />
      <Snackbar
        open={open === 'node'}
        onClose={close}
        message="Draft saved"
        autoHideDuration={6000}
        action={
          <IconButton size="small" color="inherit" aria-label="Close" onClick={close}>
            <span className="material-icons">close</span>
          </IconButton>
        }
      />
    </Stack>
  );
}

Posición#

anchorOrigin combina vertical (top/bottom) con horizontal (left/center/right); por defecto, abajo al centro. Por debajo de 600px el snackbar ocupa todo el ancho con 8px de margen lateral.

Posición open_in_new
import { useState } from 'react';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import type { SnackbarOrigin } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

const HORIZONTAL: SnackbarOrigin['horizontal'][] = ['left', 'center', 'right'];
const VERTICAL: SnackbarOrigin['vertical'][] = ['top', 'bottom'];

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [origin, setOrigin] = useState<SnackbarOrigin>({ vertical: 'bottom', horizontal: 'center' });
  const show = (next: SnackbarOrigin) => {
    setOrigin(next);
    setOpen(true);
  };
  return (
    <Stack spacing={2}>
      {VERTICAL.map((vertical) => (
        <Stack key={vertical} spacing={1.5}>
          <Typography variant="overline" color="text-secondary" component="span">
            {vertical === 'top' ? 'Top' : 'Bottom'}
          </Typography>
          <Stack direction="row" spacing={2} wrap alignItems="center">
            {HORIZONTAL.map((horizontal) => (
              <Button key={horizontal} variant="outlined" onClick={() => show({ vertical, horizontal })}>
                {vertical}-{horizontal}
              </Button>
            ))}
          </Stack>
        </Stack>
      ))}
      <Snackbar
        open={open}
        onClose={() => setOpen(false)}
        anchorOrigin={origin}
        message={`${origin.vertical} ${origin.horizontal}`}
        autoHideDuration={3000}
      />
    </Stack>
  );
}

Duración#

Sin autoHideDuration (o con null) el snackbar no se cierra solo. El temporizador se pausa mientras el puntero o el foco están sobre él y se reinicia con la duración completa al salir.

Duración open_in_new
import { useState } from 'react';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';

type Mode = 'short' | 'long' | 'persistent';

export default function Demo() {
  const [open, setOpen] = useState<Mode | null>(null);
  const close = () => setOpen(null);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="outlined" onClick={() => setOpen('short')}>
        2 seconds
      </Button>
      <Button variant="outlined" onClick={() => setOpen('long')}>
        8 seconds
      </Button>
      <Button variant="outlined" onClick={() => setOpen('persistent')}>
        No auto-hide
      </Button>
      <Snackbar open={open === 'short'} onClose={close} message="Closes in 2 seconds" autoHideDuration={2000} />
      <Snackbar
        open={open === 'long'}
        onClose={close}
        message="Closes in 8 seconds (hover over it to pause)"
        autoHideDuration={8000}
      />
      <Snackbar open={open === 'persistent'} onClose={close} message="Stays until you close it" action="Close" closeOnAction />
    </Stack>
  );
}

Consecutivos#

SnackbarProvider mantiene una cola y muestra un aviso a la vez: un aviso nuevo cierra el visible y aparece cuando termina su transición de salida, como el ejemplo Consecutive Snackbars de MUI.

Consecutivos open_in_new
import { SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';

function Buttons() {
  const { enqueue } = useSnackbar();
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      {['A', 'B', 'C'].map((name) => (
        <Button key={name} variant="outlined" onClick={() => enqueue({ message: `Message ${name}`, duration: 2500 })}>
          Message {name}
        </Button>
      ))}
    </Stack>
  );
}

export default function Demo() {
  return (
    <SnackbarProvider>
      <Buttons />
    </SnackbarProvider>
  );
}

Con Alert#

Para notificaciones con severidad, coloca un Alert como hijo de un snackbar sin message. Las utilidades mtx-p-0 mtx-bg-transparent quitan el relleno y el fondo del snackbar y mtx-flex-1 estira la alerta.

Con Alert open_in_new

  const close = () => setOpen(null);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="outlined" onClick={() => setOpen('success')}>
        Success

      <Button variant="outlined" onClick={() => setOpen('error')}>
        Error
      </Button>
      <Snackbar
        open={open === 'success'}
        onClose={close}
        autoHideDuration={4000}
        anchorOrigin={{ vertical: 'bottom', horizontal: 'left' }}
        className="mtx-p-0 mtx-bg-transparent"
      >
        <Alert severity="success" variant="filled" className="mtx-flex-1">
          Profile updated successfully.
        </Alert>
      </Snackbar>
      <Snackbar
        open={open === 'error'}
        onClose={close}
        autoHideDuration={4000}
        anchorOrigin={{ vertical: 'bottom', horizontal: 'left' }}

          The profile could not be saved.

      </Snackbar>

}

Avisos rápidos con useSnackbar()#

Para confirmaciones puntuales no hace falta declarar un snackbar: envuelve la aplicación una vez con <SnackbarProvider> y llama a useSnackbar().enqueue(mensaje | opciones). El snackbar compartido usa role="status" y 4 s de duración por defecto; onAction se ejecuta al pulsar la acción y cierra el aviso. enqueue devuelve una clave que acepta close(key).

Avisos rápidos con useSnackbar() open_in_new
import { useState } from 'react';
import { SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

function Actions() {
  const { enqueue } = useSnackbar();
  const [status, setStatus] = useState('');
  return (
    <Stack spacing={2}>
      <Stack direction="row" spacing={2} wrap alignItems="center">
        <Button variant="contained" onClick={() => enqueue('Link copied')}>
          Copy link
        </Button>
        <Button
          variant="outlined"
          onClick={() =>
            enqueue({
              message: 'Conversation archived',
              action: 'Undo',
              onAction: () => setStatus('Conversation restored'),
              duration: 6000,
              anchorOrigin: { vertical: 'bottom', horizontal: 'left' },
            })
          }
        >
          Archive with undo
        </Button>
      </Stack>
      <Typography variant="caption" color="text-secondary" component="p" role="status">
        {status}
      </Typography>
    </Stack>
  );
}

export default function Demo() {
  return (
    <SnackbarProvider>
      <Actions />
    </SnackbarProvider>
  );
}

Ejemplos reales#

Un formulario de suscripción con un TextField Email: si la dirección es válida, el snackbar compartido lo confirma y ofrece deshacerlo.

Ejemplos reales open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

const EMAIL_RE = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

function SubscribeForm() {
  const { enqueue } = useSnackbar();
  const [email, setEmail] = useState('');
  const [error, setError] = useState(false);

  const submit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    if (!EMAIL_RE.test(email)) {
      setError(true);
      return;
    }
    setError(false);
    const subscribed = email;
    setEmail('');
    enqueue({
      message: `${subscribed} subscribed`,
      action: 'Undo',
      onAction: () => setEmail(subscribed),
      duration: 6000,
    });
  };

  return (
    <Stack component="form" spacing={2} alignItems="flex-start" className="demo-fixed-width" noValidate onSubmit={submit}>
      <TextField
        label="Email"
        type="email"
        name="email"
        variant="outlined"
        value={email}
        onChange={(_event, value) => setEmail(value)}
        error={error}
        helperText={error ? 'Enter a valid email address.' : 'We will send you one email per month.'}
      />
      <Button type="submit" variant="contained" startIcon="mail">
        Subscribe
      </Button>
    </Stack>
  );
}

export default function Demo() {
  return (
    <SnackbarProvider>
      <SubscribeForm />
    </SnackbarProvider>
  );
}

Maquetación en grilla#

Un caso típico: acciones en una Grid donde cada una confirma su resultado con el snackbar compartido.

Maquetación en grilla open_in_new
import { SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import type { ButtonColor } from '@rubenchodev/materix-react/components/button';
import { Grid } from '@rubenchodev/materix-react/components/grid';

const ACTIONS: Array<{ label: string; message: string; color?: ButtonColor }> = [
  { label: 'Copy', message: 'File copied' },
  { label: 'Move', message: 'File moved' },
  { label: 'Delete', message: 'File deleted', color: 'error' },
];

function Actions() {
  const { enqueue } = useSnackbar();
  return (
    <Grid container spacing={2}>
      {ACTIONS.map(({ label, message, color }) => (
        <Grid key={label} size={{ xs: 12, sm: 4 }}>
          <Button variant="contained" color={color} fullWidth onClick={() => enqueue({ message, duration: 3000 })}>
            {label}
          </Button>
        </Grid>
      ))}
    </Grid>
  );
}

export default function Demo() {
  return (
    <SnackbarProvider anchorOrigin={{ vertical: 'bottom', horizontal: 'left' }}>
      <Actions />
    </SnackbarProvider>
  );
}

Uso programático#

El equivalente de open()/close() es la prop open; setMessage()/setAction() son las props message y action. onOpen, onAction y onClose(event, reason) equivalen a mtx:snackbar:open, mtx:snackbar:action y mtx:snackbar:close. Escape solo cierra el snackbar más reciente, y nunca con un diálogo o menú abierto encima.

Uso programático open_in_new
import { useState } from 'react';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [message, setMessage] = useState('Controlled from React state');
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [...lines, `${new Date().toLocaleTimeString()}  ${text}`]);

  return (
    <Stack spacing={2}>
      <Stack direction="row" spacing={2} wrap alignItems="center">
        <Button variant="contained" onClick={() => setOpen(true)}>
          open = true
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setMessage(`Draft saved at ${new Date().toLocaleTimeString()}`);
            setOpen(true);
          }}
        >
          Change message
        </Button>
        <Button variant="outlined" onClick={() => setOpen(false)}>
          open = false
        </Button>
      </Stack>
      <Typography variant="caption" color="text-secondary" component="p" role="status">
        open: {String(open)}
      </Typography>
      <Snackbar
        open={open}
        message={message}
        action="Close"
        closeOnAction
        autoHideDuration={5000}
        onOpen={() => write('onOpen')}
        onAction={() => write('onAction')}
        onClose={(_event, reason) => {
          write(`onClose   reason: ${reason}`);
          setOpen(false);
        }}
        onExited={() => write('onExited')}
      />
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </Stack>
  );
}

PropTipoPor defectoDescripción
openboolean—Muestra el snackbar (controlado).
onClose(event, reason) => void—Solicitud de cierre; reason es timeout, clickaway, escapeKeyDown o action (api queda reservado a useSnackbar().close()).
messageReactNode—Mensaje (.mtx-snackbar__message).
actionReactNode—Texto → botón .mtx-snackbar__action; nodo → se pinta tal cual.
onAction(event) => void—Clic en la acción generada.
closeOnActionbooleanfalseLa acción generada cierra el snackbar (motivo action).
autoHideDurationnumber | nullnullAuto-cierre en ms; null lo desactiva.
anchorOrigin{ vertical, horizontal }{ vertical: 'bottom', horizontal: 'center' }Posición.
role'alert' | 'status''alert'Rol vivo del mensaje.
disableClickAwaybooleanfalseUn clic fuera no solicita el cierre.

onExited() => void—Terminó la transición de salida (el nodo se desmonta).
childrenReactNode—Contenido extra entre el mensaje y la acción (por ejemplo un Alert).

className se combina; ref, style y cualquier otro atributo van al <div> raíz.

Accesibilidad#

  • El mensaje lleva role="alert" (urgente, se anuncia de inmediato) o role="status" para avisos no urgentes; el snackbar compartido de SnackbarProvider usa status.
  • La acción generada es un <button type="button"> nativo; el temporizador se pausa mientras tiene el foco para que los usuarios de teclado tengan tiempo de usarla.
  • Evita información esencial que desaparece: usa un autoHideDuration largo (o ninguno) cuando el aviso tiene una acción.
TeclaAcción
EscapeCierra el snackbar más reciente (motivo escapeKeyDown) si no hay un diálogo o menú abierto.
TabLleva el foco a la acción.
Enter / EspacioActiva la acción.
