Chip

Elemento compacto que representa una etiqueta, un filtro, una entrada o una acción; puede llevar icono, avatar y botón de eliminar.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Chip } from '@rubenchodev/materix-react';

Chip representa una pieza de información compacta: una etiqueta, un filtro activo, un destinatario o una acción breve. Úsalo para listas de etiquetas, filtros seleccionables o entradas que el usuario puede quitar. Para una acción principal usa un Button; para un contador sobre un icono, un Badge.

import { Chip } from '@rubenchodev/materix-react';
// o solo este componente:
import { Chip } from '@rubenchodev/materix-react/components/chip';

Uso básico#

Basta con <Chip label="…" />. icon añade un icono inicial (nombre de Material Icons o cualquier nodo) y onDelete añade el icono de eliminar.

Uso básico open_in_new
import { Chip } from '@rubenchodev/materix-react/components/chip';

export default function Demo() {
  return (
    <div className="demo-row">
      <Chip label="Etiqueta" />
      <Chip label="JavaScript" icon="code" color="primary" />
      <Chip label="Eliminable" color="secondary" onDelete={() => {}} />
      <Chip label="Con borde" variant="outlined" icon="tag" />
    </div>
  );
}

filled (por defecto) usa fondo sólido; outlined usa borde y fondo transparente.

}

Con iconos y avatar#

icon añade un icono inicial, avatar muestra un avatar (recibe la clase mtx-chip__avatar) y onDelete añade el icono de eliminar al final, que puedes sustituir con deleteIcon.

}

Estados#

Un chip con onClick (o clickable) es interactivo: cursor de puntero, estado hover, anillo de foco, role="button" y activación con Enter o Espacio. Con component="button" el chip es un <button> nativo sin borde ni relleno del navegador. disabled baja la opacidad, retira el foco y bloquea los callbacks.

Estados open_in_new
import { Chip } from '@rubenchodev/materix-react/components/chip';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Normal · clicable (hover, foco, pulsado)</span>
        <div className="demo-row">
          <Chip label="Estático" />
          <Chip label="Clicable" clickable />
          <Chip label="Clicable primario" clickable color="primary" />
          <Chip label="Clicable con borde" clickable variant="outlined" />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Sobre un &lt;button&gt; nativo</span>
        <div className="demo-row">
          <Chip component="button" type="button" label="Botón relleno" clickable />
          <Chip component="button" type="button" label="Botón con borde" variant="outlined" clickable />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Deshabilitado</span>
        <div className="demo-row">
          <Chip label="Deshabilitado" disabled />
          <Chip label="Con borde" variant="outlined" disabled />
          <Chip label="Clicable" color="primary" disabled onClick={() => {}} />
          <Chip label="Eliminable" disabled onDelete={() => {}} />
        </div>
      </div>
    </div>
  );
}

Eliminables#

onDelete muestra el icono de eliminar y se invoca al pulsarlo o al presionar Supr/Retroceso con el chip enfocado. El chip no se elimina solo: actualizas tu estado.

Eliminables open_in_new
import { useState } from 'react';
import { Chip } from '@rubenchodev/materix-react/components/chip';
import { Button } from '@rubenchodev/materix-react/components/button';

const INITIAL = ['React', 'Vue', 'Svelte', 'Angular'];

export default function Demo() {
  const [tags, setTags] = useState(INITIAL);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        {tags.map((tag) => (
          <Chip
            key={tag}
            label={tag}
            deleteLabel={`Eliminar ${tag}`}
            onDelete={() => setTags((current) => current.filter((item) => item !== tag))}
          />
        ))}
      </div>
      <div className="demo-row">
        <Button variant="text" onClick={() => setTags(INITIAL)}>
          Restaurar etiquetas
        </Button>
      </div>
    </div>
  );
}

Filtros#

Chips clicables que alternan entre outlined (inactivo) y primary (activo), con aria-pressed como estado accesible.

Filtros open_in_new
import { useState } from 'react';
import { Chip } from '@rubenchodev/materix-react/components/chip';

const FILTERS = ['Abiertas', 'En revisión', 'Cerradas', 'Bloqueadas'];

export default function Demo() {
  const [active, setActive] = useState<string[]>(['Abiertas']);
  const toggle = (name: string) =>
    setActive((current) => (current.includes(name) ? current.filter((item) => item !== name) : [...current, name]));
  return (
    <div className="demo-stack">
      <div className="demo-row" role="group" aria-label="Filtrar incidencias">
        {FILTERS.map((name) => {
          const pressed = active.includes(name);
          return (
            <Chip
              key={name}
              label={name}
              color={pressed ? 'primary' : 'default'}
              variant={pressed ? 'filled' : 'outlined'}
              aria-pressed={pressed}
              onClick={() => toggle(name)}
            />
          );
        })}
      </div>
      <p className="demo-status" aria-live="polite">
        Filtros activos: {active.join(', ') || 'ninguno'}
      </p>
    </div>
  );
}

Uso programático#

El texto, el estado deshabilitado y el resto de props son estado de React; ref apunta al elemento raíz (por ejemplo, para enfocarlo). El registro muestra los callbacks onClick y onDelete.

Uso programático open_in_new
import { useRef, useState } from 'react';
import { Chip } from '@rubenchodev/materix-react/components/chip';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const [label, setLabel] = useState('Chip de prueba');
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const chipRef = useRef<HTMLElement>(null);
  const write = (text: string) => setLog((lines) => [...lines, text]);

  const toggleLabel = () => {
    const next = label === 'Chip de prueba' ? 'Texto actualizado' : 'Chip de prueba';
    setLabel(next);
    write(`label = "${next}"`);
  };
  const changeDisabled = (value: boolean) => {
    setDisabled(value);
    write(`disabled = ${value}`);
  };

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Chip
          ref={chipRef}
          label={label}
          icon="science"
          color="primary"
          disabled={disabled}
          onClick={(event) => write(`onClick (${event.type})`)}
          onDelete={(event) => write(`onDelete (${event.type})`)}
        />
      </div>
      <div className="demo-row">
        <Button variant="outlined" onClick={toggleLabel}>
          Cambiar texto
        </Button>
        <Button variant="outlined" onClick={() => changeDisabled(true)}>
          Deshabilitar
        </Button>
        <Button variant="outlined" onClick={() => changeDisabled(false)}>
          Habilitar
        </Button>
        <Button variant="text" onClick={() => chipRef.current?.focus()}>
          Enfocar (ref)
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accesibilidad#

  • Los chips estáticos son texto sin rol. Los clicables o eliminables reciben role="button" y tabindex="0" (salvo con component button o a); los deshabilitados, aria-disabled="true" y tabindex="-1".
  • Como en MUI, el icono de eliminar no es un control anidado: es un <span aria-hidden="true"> nunca enfocable. El chip se elimina con el ratón sobre el icono o con Supr/Retroceso mientras tiene el foco, anunciado con aria-keyshortcuts="Delete Backspace".
  • El title del icono sale del diccionario i18n (Delete / Eliminar); hazlo específico con deleteLabel (por ejemplo, «Quitar React»).
  • En filtros, indica el estado activo con aria-pressed.
  • Los iconos por nombre se generan con aria-hidden="true"; marca igual tus propios nodos de icono.
TeclaAcción
Tab / Mayús+TabMueve el foco entre chips interactivos.
Enter / EspacioActiva un chip clicable (onClick).
Supr / RetrocesoEn un chip eliminable, invoca onDelete.
EscapeQuita el foco del chip.
