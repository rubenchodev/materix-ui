Progress

Indicadores circulares y lineales que comunican que una operación está en curso o cuánto falta para terminarla.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { CircularProgress, LinearProgress } from '@rubenchodev/materix-react';

Progress indica al usuario que una operación está en marcha. CircularProgress encaja en espacios pequeños (botones, tarjetas, una página cargando) y LinearProgress se coloca en el borde de un contenedor o junto a la tarea que mide. Usa la variante indeterminate cuando no se conoce el tiempo restante y determinate cuando conoces el porcentaje.

Importación#

import { CircularProgress, LinearProgress } from '@rubenchodev/materix-react';

Uso básico#

Un único <CircularProgress /> o <LinearProgress /> renderiza el SVG o las barras, role="progressbar" y el nombre accesible. Sin value es indeterminado; con value pasa a determinado.

Uso básico open_in_new
import { CircularProgress, LinearProgress } from '@rubenchodev/materix-react/components/progress';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <div className="demo-row">
        <CircularProgress />
        <CircularProgress value={75} />
      </div>
      <LinearProgress />
      <LinearProgress value={40} />
    </div>
  );
}

Variantes#

Circular#

Como en MUI: indeterminate (gira con un trazo que crece y se encoge), determinate (un arco proporcional a value) y disableShrink (solo gira, útil cuando el hilo principal está muy ocupado). track añade el anillo de fondo.

Circular open_in_new
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';

export default function Demo() {
  return (
    <div className="demo-grid-4">
      <div className="demo-group">
        <span className="demo-label">Indeterminate</span>
        <div className="demo-row">
          <CircularProgress />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Disable shrink</span>
        <div className="demo-row">
          <CircularProgress disableShrink />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Determinate · 25 / 50 / 100</span>
        <div className="demo-row">
          <CircularProgress value={25} />
          <CircularProgress value={50} />
          <CircularProgress value={100} />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">With track</span>
        <div className="demo-row">
          <CircularProgress value={65} track />
          <CircularProgress track />
        </div>
      </div>
    </div>
  );
}

Lineal#

Cuatro variantes: indeterminate, determinate, buffer (se infiere de valueBuffer) y query (indeterminado invertido, para la fase previa a la carga). 4px de alto, como en MUI; rounded redondea los extremos.

Lineal open_in_new
import { LinearProgress } from '@rubenchodev/materix-react/components/progress';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <div className="demo-group">
        <span className="demo-label">Indeterminate</span>
        <LinearProgress />
      </div>
      <div className="demo-group">
        <span className="demo-label">Determinate · 60</span>
        <LinearProgress value={60} />
      </div>
      <div className="demo-group">
        <span className="demo-label">Buffer · 30 / 55</span>
        <LinearProgress value={30} valueBuffer={55} />
      </div>
      <div className="demo-group">
        <span className="demo-label">Query</span>
        <LinearProgress variant="query" />
      </div>
      <div className="demo-group">
        <span className="demo-label">Rounded</span>
        <LinearProgress value={70} rounded />
      </div>
    </div>
  );
}

Con etiqueta#

showLabel muestra el porcentaje redondeado: centrado en el círculo y a la derecha de la barra. La cifra visual es aria-hidden; los lectores de pantalla obtienen el valor de aria-valuenow.

Con etiqueta open_in_new
import { CircularProgress, LinearProgress } from '@rubenchodev/materix-react/components/progress';

  return (
    <div className="demo-stack demo-wide">
      <div className="demo-row">
        <CircularProgress value={10} showLabel />
        <CircularProgress value={48} showLabel track />
        <CircularProgress value={100} showLabel color="success" />
      </div>
      <LinearProgress value={35} showLabel />
      <LinearProgress value={82} showLabel color="secondary" />
    </div>
  );
}

Colores#

color acepta los colores de la paleta e inherit (toma el color del texto del contenedor). La pista lineal se aclara en el tema claro y se oscurece en el oscuro.

Colores open_in_new
import { CircularProgress, LinearProgress, type ProgressColor } from '@rubenchodev/materix-react/components/progress';
import { Typography } from '@rubenchodev/materix-react/components/typography';

const COLORS: ProgressColor[] = ['primary', 'secondary', 'error', 'warning', 'info', 'success'];

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <div className="demo-row">
        {COLORS.map((color) => (
          <CircularProgress key={color} color={color} label={`Loading (${color})`} />
        ))}
        <Typography color="text-secondary" component="span">
          <CircularProgress color="inherit" label="Loading (inherit)" />
        </Typography>
      </div>
      {COLORS.map((color) => (
        <LinearProgress key={color} color={color} value={color === 'success' ? undefined : 50} label={`Progress (${color})`} />
      ))}
    </div>
  );
}

Escala propia#

min y max cambian la escala (0–100 por defecto): <LinearProgress max={10} value={7} /> expone aria-valuemax="10" y llena el 70%. Si max <= min, max pasa a ser min + 100. El valor se acota al rango.

Estados#

El nombre accesible por defecto es “Loading” / “Cargando” según el idioma (I18nProvider, <html lang> o la prop locale). Personalízalo con label, aria-label o aria-labelledby. Marca la región que se actualiza con aria-busy="true" mientras carga.

Estados y accesibilidad open_in_new
import { useId } from 'react';
import { CircularProgress, LinearProgress } from '@rubenchodev/materix-react/components/progress';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const titleId = useId();
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Custom name (aria-labelledby)</span>
        <Typography variant="body2" component="span" id={titleId}>
          Uploading report.pdf
        </Typography>
        <LinearProgress value={64} aria-labelledby={titleId} />
      </div>
      <div className="demo-group">
        <span className="demo-label">Busy region (aria-busy)</span>
        <div className="demo-row" aria-busy="true" aria-live="polite">
          <CircularProgress size={24} label="Loading comments" />
          <Typography variant="body2" component="span">
            Loading comments…
          </Typography>
        </div>
      </div>
    </div>
  );
}

Ejemplos reales#

Subida de archivos con valor y buffer, uso de plazas y almacenamiento en una escala propia, y un Button con loading, que usa por dentro un CircularProgress decorativo.

Ejemplos reales open_in_new
import { useEffect, useId, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Card, CardContent } from '@rubenchodev/materix-react/components/card';
import { LinearProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

/** Simula una subida con valor y buffer. */
function useUpload() {
  const [state, setState] = useState({ value: 0, buffer: 10 });
  useEffect(() => {
    const reduce = window.matchMedia?.('(prefers-reduced-motion: reduce)').matches;
    const id = setInterval(() => {
      setState(({ value }) => {
        const next = value >= 100 ? 0 : Math.min(100, value + Math.round(Math.random() * 8));
        return { value: next, buffer: Math.min(100, next + 10 + Math.round(Math.random() * 10)) };
      });
    }, reduce ? 1500 : 600);
    return () => clearInterval(id);
  }, []);
  return state;
}

export default function Demo() {
  const upload = useUpload();
  const seatsId = useId();
  const storageId = useId();
  const [saving, setSaving] = useState(false);

  const save = () => {
    setSaving(true);
    setTimeout(() => setSaving(false), 2000);
  };

  return (
    <div className="demo-grid-3">
      <Card>
        <CardContent>
          <Stack spacing={1}>
            <Typography variant="subtitle2" component="span">
              Uploading 3 files
            </Typography>
            <LinearProgress value={upload.value} valueBuffer={upload.buffer} showLabel label="File upload" />
            <Typography variant="caption" color="text-secondary" component="span">
              {upload.value >= 100 ? 'Completed' : `${Math.round(upload.value)}% · 3 files`}
            </Typography>
          </Stack>
        </CardContent>
      </Card>
      <Card>
        <CardContent>
          <Stack spacing={1}>
            <Typography variant="subtitle2" component="span" id={seatsId}>
              Team seats · 7 of 10
            </Typography>
            <LinearProgress max={10} value={7} rounded aria-labelledby={seatsId} />
            <Typography variant="subtitle2" component="span" id={storageId} className="mtx-mt-2">
              Storage · 46 of 50 GB
            </Typography>
            <LinearProgress max={50} value={46} color="warning" rounded aria-labelledby={storageId} />
          </Stack>
        </CardContent>
      </Card>
      <Card>
        <CardContent>
          <Typography variant="subtitle2" gutterBottom>
            Save changes
          </Typography>
          <div className="demo-row">
            <Button variant="contained" loading={saving} loadingPosition="start" startIcon="save" onClick={save}>
              {saving ? 'Saving…' : 'Save'}
            </Button>
          </div>
        </CardContent>
      </Card>
    </div>
  );
}

Uso programático#

Progress es un componente controlado: actualiza value, valueBuffer, color o variant desde tu estado. Pasar value={undefined} vuelve al modo indeterminado.

Uso programático open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress, LinearProgress, type ProgressColor } from '@rubenchodev/materix-react/components/progress';

const COLORS: ProgressColor[] = ['primary', 'secondary', 'success', 'warning', 'error', 'info'];

export default function Demo() {
  const [value, setValue] = useState<number | undefined>(30);
  const [colorIndex, setColorIndex] = useState(0);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 6));
  const color = COLORS[colorIndex];

  const step = (delta: number) => {
    const next = Math.min(100, Math.max(0, (value ?? 0) + delta));
    setValue(next);
    write(`value = ${next}`);
  };

  return (
    <div className="demo-stack demo-wide">
      <div className="demo-row">
        <CircularProgress value={value} showLabel size={56} color={color} />
      </div>
      <LinearProgress value={value} showLabel color={color} />
      <div className="demo-row">
        <Button variant="outlined" onClick={() => step(-10)}>-10</Button>
        <Button variant="outlined" onClick={() => step(10)}>+10</Button>
        <Button
          variant="outlined"
          onClick={() => {
            const next = (colorIndex + 1) % COLORS.length;
            setColorIndex(next);
            write(`color = "${COLORS[next]}"`);
          }}
        >
          Change color
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setValue(undefined);
            write('value = undefined → indeterminate');
          }}
        >
          Indeterminate
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

No hay sección de “Uso manual BEM”: los componentes siempre renderizan la estructura completa del SVG o de las barras, así que no hace falta escribirla a mano.

Accesibilidad#

  • La raíz tiene role="progressbar" y un nombre accesible: label, aria-label o aria-labelledby; si no hay ninguno, “Loading” / “Cargando”.
  • aria-valuenow, aria-valuemin y aria-valuemax solo se exponen en determinate y buffer, como recomienda WAI-ARIA.
  • El SVG y la etiqueta de porcentaje llevan aria-hidden="true", así que el valor se anuncia una sola vez.
  • Dentro de un control que ya comunica la carga (aria-busy), usa decorative para evitar un anuncio duplicado.
  • Respeta prefers-reduced-motion. No es interactivo: no recibe el foco.
