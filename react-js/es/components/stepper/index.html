Stepper

Muestra el progreso a lo largo de una secuencia de pasos numerados, horizontal o vertical, lineal o con pasos clicables, y su versión móvil compacta.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Stepper, Step, StepLabel, StepContent, MobileStepper, useStepper, StepperButton, StepPanel } from '@rubenchodev/materix-react';

Stepper comunica el progreso de un proceso dividido en pasos (alta de cuenta, checkout, asistente de configuración): qué paso está activo, cuáles se completaron y cuáles faltan. Úsalo cuando el orden importa y cada paso tiene sentido por sí mismo. No lo uses para alternar entre vistas del mismo nivel (usa Tabs) ni para indicar el avance de una operación en curso (usa Progress).

  Stepper,
  Step,
  StepLabel,
  StepContent,

Uso básico#

La forma más corta es un <Stepper> con un array steps de etiquetas. El componente genera el <ol> semántico, el icono numerado de 24px, los conectores y el texto accesible (“Paso 2 de 3”), y marca el paso activo con aria-current="step". defaultActiveStep (no controlado) o activeStep (controlado) es el índice del paso activo, empezando en 0.

Uso básico open_in_new
import { Stepper } from '@rubenchodev/materix-react/components/stepper';

export const description = {
  en: "A `Stepper` with a `steps` array: it renders the `<ol>`, the numbered icons, the connectors and the accessible text, and marks the active step with `aria-current=\"step\"`.",
  es: "Un `Stepper` con un array `steps`: genera el `<ol>`, los iconos numerados, los conectores y el texto accesible, y marca el paso activo con `aria-current=\"step\"`.",
};

export default function Demo() {
  return <Stepper defaultActiveStep={1} label="Reset password" steps={['Email', 'Verify code', 'New password']} />;
}

Cada entrada de steps también puede ser un objeto con las props de Step ({ label, optional, error, completed, disabled, icon, expanded, content }), o puedes escribir hijos <Step>.

Lineal con acciones#

En modo lineal (el predeterminado) los pasos anteriores al activo se consideran completados y los siguientes deshabilitados. useStepper() enlaza un stepper mediante apiRef y expone su estado; StepperButton action="back|next|reset" lo controla y se deshabilita en el primer paso (back) o al terminar (next) salvo con keepEnabled; StepPanel muestra el panel del paso activo, e index="finished" el panel final cuando activeStep alcanza el número de pasos.

Comportamiento responsive

Por debajo de 600px, un stepper horizontal sin etiqueta alternativa solo muestra la etiqueta del paso activo; las demás quedan ocultas visualmente pero disponibles para lectores de pantalla. Si todas las etiquetas deben verse en móvil, usa alternativeLabel o la orientación vertical.

Casos de uso reales#

Un asistente de alta de cuenta con validación: el onChange cancelable devuelve false para impedir avanzar mientras el email del TextField no sea válido, y marca con error el paso y el campo (setError(), error + helperText).

Ejemplos reales open_in_new
import { useState } from 'react';
import { Paper } from '@rubenchodev/materix-react/components/paper';
import { TextField } from '@rubenchodev/materix-react/components/text-field';
import { Typography } from '@rubenchodev/materix-react/components/typography';
import {
  StepPanel,
  Stepper,
  StepperButton,
  useStepper,
  type StepperChangeHandler,
} from '@rubenchodev/materix-react/components/stepper';

export const description = {
  en: "A sign-up wizard with validation: the cancelable `onChange` returns `false` while the email is invalid and marks the step with `setError()`.",
  es: "Un asistente de alta con validación: el `onChange` cancelable devuelve `false` mientras el email no sea válido y marca el paso con `setError()`.",
};

const EMAIL = /^[^@\s]+@[^@\s]+\.[^@\s]+$/;

export default function Demo() {
  const stepper = useStepper();
  const [email, setEmail] = useState('');
  const [showError, setShowError] = useState(false);
  const isValid = EMAIL.test(email);

  // Cambio cancelable: no se avanza desde el primer paso con un email inválido.
  const handleChange: StepperChangeHandler = (activeStep, { previousStep }) => {
    if (previousStep === 0 && activeStep > 0) {
      stepper.setError(0, isValid ? false : 'Enter a valid email');
      setShowError(!isValid);
      if (!isValid) return false;
    }
    return undefined;
  };

  return (
    <div className="demo-surface">
      <Paper variant="outlined" className="demo-wide">
        <div className="demo-stack mtx-p-3">
          <Stepper
            apiRef={stepper.apiRef}
            alternativeLabel
            label="Account sign-up"
            onChange={handleChange}
            steps={['Account', 'Company', 'Plan']}
          />
          <StepPanel stepper={stepper} index={0}>
            <TextField
              label="Work email"
              variant="outlined"
              type="email"
              required
              value={email}
              onChange={(_, value) => {
                setEmail(value);
                if (showError && EMAIL.test(value)) {
                  setShowError(false);
                  stepper.setError(0, false);
                }
              }}
              error={showError}
              helperText={showError ? 'Enter a valid email' : undefined}
            />
          </StepPanel>
          <StepPanel stepper={stepper} index={1}>
            <TextField label="Company name" variant="outlined" />
          </StepPanel>
          <StepPanel stepper={stepper} index={2}>
            <Typography variant="body2">Team plan · $12 per user per month.</Typography>
          </StepPanel>
          <StepPanel stepper={stepper} index="finished">
            <Typography variant="body2">Your account is ready.</Typography>
          </StepPanel>
          <div className="demo-row">
            <StepperButton action="back" stepper={stepper}>
              Back
            </StepperButton>
            <StepperButton action="next" stepper={stepper} variant="contained">
              Next
            </StepperButton>
          </div>
        </div>
      </Paper>
    </div>
  );
}
const handleChange: StepperChangeHandler = (activeStep, { previousStep }) => {
  if (previousStep === 0 && activeStep > 0) {
    const valid = EMAIL.test(email);
    stepper.setError(0, valid ? false : 'Enter a valid email');
    if (!valid) return false;
  }

Uso programático#

apiRef expone next(), back(), goTo(i), reset(), setCompleted(i, bool), setError(i, mensaje|false), setDisabled(i, bool), isCompleted(i) y los getters activeStep, length y finished. Todo cambio pasa por onChange, que puede cancelarlo.

Uso programático open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stepper, type StepperApi } from '@rubenchodev/materix-react/components/stepper';

export const description = {
  en: "`apiRef` exposes `next()`, `back()`, `goTo()`, `reset()`, `setCompleted()`, `setError()` and `activeStep`; every change goes through `onChange`.",
  es: "`apiRef` expone `next()`, `back()`, `goTo()`, `reset()`, `setCompleted()`, `setError()` y `activeStep`; todo cambio pasa por `onChange`.",
};

export default function Demo() {
  const api = useRef<StepperApi>(null);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 8));
  const run = (fn: (stepper: StepperApi) => void) => {
    if (api.current) fn(api.current);
  };

  return (
    <div className="demo-stack">
      <Stepper
        apiRef={api}
        nonLinear
        label="API"
        steps={['One', 'Two', 'Three', 'Four']}
        onChange={(activeStep, { previousStep }) => {
          write(`onChange → activeStep ${activeStep}, previousStep ${previousStep}`);
        }}
      />
      <div className="demo-row">
        <Button variant="outlined" size="small" onClick={() => run((s) => s.back())}>
          back()
        </Button>
        <Button variant="outlined" size="small" onClick={() => run((s) => s.next())}>
          next()
        </Button>
        <Button variant="outlined" size="small" onClick={() => run((s) => s.goTo(3))}>
          goTo(3)
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() =>
            run((s) => {
              s.setCompleted(s.activeStep, !s.isCompleted(s.activeStep));
              write(`setCompleted(${s.activeStep})`);
            })
          }
        >
          setCompleted(active)
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() =>
            run((s) => {
              s.setError(s.activeStep, 'Check this step');
              write(`setError(${s.activeStep})`);
            })
          }
        >
          setError(active)
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() =>
            run((s) => {
              s.reset();
              write('reset()');
            })
          }
        >
          reset()
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accesibilidad#

  • Se usa un <ol> semántico: el orden de los pasos forma parte del significado. Nómbralo con label o aria-label.
  • El paso activo lleva aria-current="step" (en el <li>, o en su <button> en modo no lineal).
  • Cada paso incluye texto oculto con su posición y estado: “Paso 2 de 3: Envío, completado”. Iconos y conectores son decorativos (aria-hidden). Los textos se traducen con el idioma del I18nProvider o la prop locale.
  • En modo no lineal los pasos son <button> nativos con foco visible; los deshabilitados usan disabled.
  • En vertical, el contenido de los pasos plegados se marca inert y aria-hidden para que no reciba foco.
  • MobileStepper anuncia el paso actual en una región aria-live="polite"; los puntos y la barra son decorativos.
  • Respeta prefers-reduced-motion.
