Link

Enlace de texto con estilo MUI sobre un <a> nativo: colores de la paleta y tres modos de subrayado, sin perder la semántica.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Link } from '@rubenchodev/materix-react';

Link aplica el estilo de enlace de MUI (color primario, subrayado siempre por defecto) sobre un <a> nativo, sobre un <button> para acciones que no navegan o sobre el componente de enlace de tu router. Hereda la tipografía del texto que lo rodea.

import { Link } from '@rubenchodev/materix-react';
// o solo este componente:
import { Link } from '@rubenchodev/materix-react/components/link';

Uso básico#

<Link href="…"> renderiza un <a class="mtx-link">. Sin más props usa el color primario y va siempre subrayado (por defecto en MUI v5), así que nunca depende solo del color.

Uso básico open_in_new
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  return (
    <div className="demo-row">
      <Link href="#basic">Ver documentación</Link>
      <Link href="#basic" color="secondary">
        Servicios
      </Link>
      <Link href="#basic" underline="hover">
        Términos
      </Link>
    </div>
  );
}

Subrayado#

La variante del enlace es su subrayado: underline="always|hover|none". always es el valor por defecto: un subrayado suave (40 % del color) que se vuelve sólido al pasar el ratón. Usa hover o none solo en enlaces fuera de texto corrido (navegación, listas, pies de página).

Subrayado open_in_new
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">always · por defecto</span>
        <div className="demo-row">
          <Link href="#underline">Siempre subrayado</Link>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">hover</span>
        <div className="demo-row">
          <Link href="#underline" underline="hover">
            Subrayado al pasar el ratón
          </Link>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">none</span>
        <div className="demo-row">
          <Link href="#underline" underline="none">
            Nunca subrayado
          </Link>
        </div>
      </div>
    </div>
  );
}

Colores#

color acepta los seis colores de la paleta, los de texto (text-primary, text-secondary) e inherit, que toma el color del texto que lo rodea (aquí, dentro de un Alert).

Colores open_in_new
import { Alert } from '@rubenchodev/materix-react/components/alert';
import { Link, type LinkColor } from '@rubenchodev/materix-react/components/link';

const palette: LinkColor[] = ['primary', 'secondary', 'error', 'warning', 'info', 'success'];

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Paleta</span>
        <div className="demo-row">
          {palette.map((color) => (
            <Link key={color} href="#colors" color={color === 'primary' ? undefined : color}>
              {color}
            </Link>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Texto</span>
        <div className="demo-row">
          <Link href="#colors" color="text-primary">
            text-primary
          </Link>
          <Link href="#colors" color="text-secondary">
            text-secondary
          </Link>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">inherit · dentro de una alerta</span>
        <Alert severity="info">
          Hay una nueva versión disponible.{' '}
          <Link href="#colors" color="inherit" underline="always">
            Ver novedades
          </Link>
        </Alert>
      </div>
    </div>
  );
}

Estados#

Pasa el ratón para ver el subrayado y usa Tab para ver el anillo de foco. disabled deshabilita el enlace: en <a> pone aria-disabled="true", lo saca del orden de tabulación y cancela los clics; en <button> usa el atributo nativo disabled.

Estados open_in_new
import { useState } from 'react';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  const [disabled, setDisabled] = useState(true);
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Normal · hover · focus-visible</span>
        <div className="demo-row">
          <Link href="#states">Enlace normal</Link>
          <Link href="#states" underline="hover">
            Subrayado al pasar el ratón
          </Link>
          <Link href="#states" color="text-secondary">
            Enlace secundario
          </Link>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Deshabilitado · disabled</span>
        <div className="demo-row">
          <Link href="#states" disabled={disabled}>
            Enlace deshabilitado
          </Link>
          <Link component="button" disabled={disabled}>
            Botón enlace deshabilitado
          </Link>
          <Checkbox label="disabled" checked={disabled} onChange={(_, checked) => setDisabled(checked)} />
        </div>
      </div>
    </div>
  );
}

Como botón#

Para acciones que no navegan pero deben verse como enlace dentro de un texto, usa component="button" (sin fondo, borde ni relleno nativos y con la tipografía del texto que lo rodea). Sin type, recibe type="button" para no enviar formularios.

Como botón open_in_new
import { useState } from 'react';
import { Link } from '@rubenchodev/materix-react/components/link';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [sent, setSent] = useState(0);
  return (
    <div className="demo-group">
      <span className="demo-label">Dentro de un párrafo body2 y otro body1</span>
      <Typography variant="body2">
        ¿No recibiste el código?{' '}
        <Link component="button" onClick={() => setSent((n) => n + 1)}>
          Reenviar código
        </Link>
        {sent > 0 ? <span role="status"> · Enviado {sent}×</span> : null}
      </Typography>
      <Typography variant="body1">
        ¿Olvidaste tu contraseña?{' '}
        <Link component="button" underline="always">
          Recupérala aquí
        </Link>
      </Typography>
    </div>
  );
}

Dentro de un párrafo#

Dentro de texto corrido mantén el subrayado por defecto (always) para que el enlace no dependa solo del color (WCAG 1.4.1). El enlace hereda la tipografía del párrafo, así que encaja en cualquier variante.

Dentro de un párrafo open_in_new
import { Link } from '@rubenchodev/materix-react/components/link';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-group">
      <span className="demo-label">Párrafo body2</span>
      <Typography variant="body2" className="demo-wide">
        Al crear una cuenta aceptas los <Link href="#in-paragraph">términos del servicio</Link> y la{' '}
        <Link href="#in-paragraph">política de privacidad</Link>. Puedes cambiar tus preferencias en cualquier momento desde el panel de ajustes.
      </Typography>
    </div>
  );
}

Enlaces externos#

Con target="_blank" añade siempre rel="noopener noreferrer" y anuncia el cambio de contexto en el texto visible o en un aria-label que lo contenga.

En una grilla#

Pie de página con columnas de enlaces en un Grid: una columna en móvil, dos en tableta y cuatro en escritorio.

En una grilla open_in_new
import { Grid } from '@rubenchodev/materix-react/components/grid';
import { Link } from '@rubenchodev/materix-react/components/link';

const columns = [
  { heading: 'Producto', links: ['Funciones', 'Precios'] },
  { heading: 'Recursos', links: ['Documentación', 'Ejemplos'] },
  { heading: 'Empresa', links: ['Equipo', 'Contacto'] },
  { heading: 'Legal', links: ['Privacidad', 'Términos'] },
];

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {columns.map(({ heading, links }) => (
        <Grid key={heading} xs={12} sm={6} md={3}>
          <div className="demo-stack">
            <span className="demo-label">{heading}</span>
            {links.map((text) => (
              <Link key={text} href="#grid" color="text-primary">
                {text}
              </Link>
            ))}
          </div>
        </Grid>
      ))}
    </Grid>
  );
}

Uso programático y enlaces de router#

Los enlaces se crean desde el estado (no hay métodos). component aplica el estilo de Link sobre cualquier componente: el Link de React Router, el de Next.js, etc. Sus props (to, prefetch…) se reenvían.

Uso programático open_in_new
import { forwardRef, useState, type AnchorHTMLAttributes } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Link, type LinkColor } from '@rubenchodev/materix-react/components/link';

/** Simula el `Link` de un router: recibe `to` en lugar de `href`. */
const RouterLink = forwardRef<HTMLAnchorElement, AnchorHTMLAttributes<HTMLAnchorElement> & { to: string }>(
  function RouterLink({ to, ...props }, ref) {
    return <a ref={ref} href={`#${to}`} {...props} />;
  },
);

interface DynamicLink {
  id: number;
  color: LinkColor;
  underline?: 'always';
}

export default function Demo() {
  const [links, setLinks] = useState<DynamicLink[]>([]);
  const add = (color: LinkColor, underline?: 'always') =>
    setLinks((prev) => [...prev, { id: prev.length + 1, color, underline }]);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="outlined" onClick={() => add('primary')}>
          Crear enlace primary
        </Button>
        <Button variant="outlined" onClick={() => add('error', 'always')}>
          Crear enlace error · always
        </Button>
        <Button variant="text" onClick={() => setLinks([])}>
          Limpiar
        </Button>
      </div>
      <div className="demo-row" aria-live="polite">
        <Link component={RouterLink} to="/dashboard">
          Enlace del router
        </Link>
        {links.map(({ id, color, underline }) => (
          <Link key={id} href="#programmatic" color={color} underline={underline}>
            Enlace dinámico {id}
          </Link>
        ))}
      </div>
      <pre className="demo-log">
        {links
          .map(({ id, color, underline }) => `Enlace dinámico ${id} → mtx-link mtx-link--${color} mtx-link--color-${color}${underline ? ` mtx-link--underline-${underline}` : ''}`)
          .join('\n')}
      </pre>
    </div>
  );
}
import { Link as RouterLink } from 'react-router-dom';

<Link component={RouterLink} to="/dashboard">Panel</Link>

API#

Props#

PropTipoPor defectoDescripción
color'primary' | 'secondary' | 'error' | 'warning' | 'info' | 'success' | 'text-primary' | 'text-secondary' | 'inherit'primario (CSS)Añade .mtx-link--{color} y .mtx-link--color-{color}.
underline'always' | 'hover' | 'none'always (CSS)Añade .mtx-link--underline-{modo}.
disabledbooleanfalse<button>: disabled. Resto: aria-disabled="true", tabIndex={-1} y clics cancelados.
componentElementType'a'Elemento o componente raíz ('button', un enlace de router…).
classNamestring—Se concatena con las clases del componente.
refRef<HTMLElement>—Apunta al elemento raíz.

El resto de props (href, target, rel, onClick, aria-*…) se reenvían al elemento raíz.

Callbacks#

CallbackDescripción
onClick(event)Clic nativo. No se llama mientras está disabled.

Clases CSS#

ClaseDescripción
.mtx-linkBase: color primario, subrayado always, anillo de foco.
.mtx-link--{color} / .mtx-link--color-{color}Color del enlace.
.mtx-link--underline-{always|hover|none}Modo de subrayado.
button.mtx-linkElimina el aspecto de botón nativo.

Accesibilidad#

  • Usa <a href> para navegar: es enfocable, se activa con Enter y se anuncia como enlace. Para una acción sin destino dentro de un texto usa component="button"; para acciones destacadas, Button.
  • El texto debe describir el destino («Leer la política de privacidad»), no «haz clic aquí».
  • Dentro de párrafos mantén el subrayado always (WCAG 1.4.1, axe link-in-text-block).
  • Un <a> deshabilitado conserva su href, pero sale del orden de tabulación y se anuncia como deshabilitado.
  • El foco de teclado muestra un anillo de --mtx-focus-ring-width con 2 px de separación.
TeclaAcción
Tab / Shift+TabMueve el foco al enlace siguiente o anterior.
EnterSigue el enlace (o ejecuta la acción con component="button").
EspacioEjecuta la acción con component="button".
