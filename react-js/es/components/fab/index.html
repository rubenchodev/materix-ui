Fab

Botón de acción flotante para la acción principal de una pantalla: circular (56/48/40px) o extendido con texto (48px).

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Fab } from '@rubenchodev/materix-react';

Fab (Floating Action Button) representa la acción principal o más frecuente de una pantalla —redactar, crear, añadir— y flota sobre el contenido con una elevación alta. Usa como máximo uno por pantalla. Para acciones secundarias usa un Button; para acciones compactas en barras o filas, un Icon Button.

import { Fab } from '@rubenchodev/materix-react';
// o solo este componente:
import { Fab } from '@rubenchodev/materix-react/components/fab';

Uso básico#

icon genera un FAB circular; al añadir label pasa a ser un FAB extendido con texto. El FAB circular necesita aria-label.

Uso básico open_in_new
import { Fab } from '@rubenchodev/materix-react/components/fab';

export default function Demo() {
  return (
    <div className="demo-row">
      <Fab icon="add" aria-label="Create" />
      <Fab icon="edit" color="secondary" aria-label="Edit" />
      <Fab icon="navigation" label="Navigate" />
    </div>
  );
}

Variantes#

  • Circular (por defecto): solo icono, 56px.
  • Extendido (mtx-fab--extended): icono y texto, 48px de alto. Se activa automáticamente con label, o con variant="extended" si escribes tú el contenido como children.
Variantes open_in_new
import { Fab } from '@rubenchodev/materix-react/components/fab';

export default function Demo() {
  return (
    <div className="demo-grid-3">
      <div className="demo-group">
        <span className="demo-label">Circular</span>
        <div className="demo-row">
          <Fab icon="add" aria-label="Create" />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Extended · label</span>
        <div className="demo-row">
          <Fab icon="add" label="New ticket" />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Extended · variant + children</span>
        <div className="demo-row">
          <Fab variant="extended">
            <span className="material-icons" aria-hidden="true">
              add
            </span>
            <span>New ticket</span>
          </Fab>
        </div>
      </div>
    </div>
  );
}

Con iconos#

Combina icon y label: solo icono, icono y texto, o solo texto. Un icono string es decorativo (aria-hidden="true"); icon también acepta un nodo como un <svg> (24px). El texto de label es el nombre accesible del FAB extendido.

        <span className="demo-label">Icon and text</span>

          <Fab icon="shopping_cart" label="Buy" />

Colores#

Primary es el color por defecto. color acepta los colores de la paleta y default, una superficie neutra con borde, útil cuando la pantalla ya tiene mucho color primario. inherit toma fondo y color del contenedor.

El hover sube la elevación de 6 a 12, la pulsación muestra el ripple y el foco de teclado un anillo. disabled quita la elevación y el color (en enlaces usa aria-disabled="true", tabIndex={-1} y bloquea el clic).

Posición#

position="fixed-br" y "fixed-bl" fijan el FAB a 24px de la esquina inferior derecha o izquierda de la ventana (z-index de la capa de SpeedDial). "absolute-center" lo centra sobre el borde superior de su contenedor posicionado, como en una barra inferior.

Posición open_in_new
import { Fab } from '@rubenchodev/materix-react/components/fab';

export default function Demo() {
  return (
    <div className="demo-group">
      <span className="demo-label">absolute-center over a bottom bar</span>
      <div className="demo-panel demo-panel--tall">
        <p className="mtx-m-0 mtx-p-2">Screen content. The FAB stays centered and sits on top of the bar.</p>
        {/* Barra inferior simulada (decorativa): 56px como un BottomAppBar de MUI. */}
        <div className="mtx-position-absolute mtx-start-0 mtx-end-0 mtx-bottom-0 mtx-bg-primary" style={{ height: 56 }}>
          <Fab icon="add" color="secondary" position="absolute-center" aria-label="Create post" />
        </div>
      </div>
    </div>
  );
}

Maquetación en grilla#

Dentro de una grilla el FAB mantiene su tamaño; úsalo como acción principal de cada tarjeta o columna.

Maquetación en grilla open_in_new
import { Fab } from '@rubenchodev/materix-react/components/fab';
import type { FabColor } from '@rubenchodev/materix-react/components/fab';
import { Grid } from '@rubenchodev/materix-react/components/grid';

const items: Array<[string, string, string, FabColor]> = [
  ['Notes', 'note_add', 'New note', 'primary'],
  ['Events', 'event', 'New event', 'secondary'],
  ['Contacts', 'person_add', 'New contact', 'success'],
];

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {items.map(([section, icon, label, color]) => (
        <Grid key={section} size={{ xs: 12, sm: 4 }}>
          <div className="demo-panel">
            <span className="demo-label">{section}</span>
            <Fab icon={icon} size="small" color={color} aria-label={label} />
          </div>
        </Grid>
      ))}
    </Grid>
  );
}

Uso programático#

Los setters size/color y disable()/enable() de vanilla pasan a ser props controladas por tu estado. ref te da el elemento DOM. Fab no emite eventos propios: usa onClick.

Uso programático open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';
import { useState } from 'react';
import { Fab } from '@rubenchodev/materix-react/components/fab';
import type { FabColor, FabSize } from '@rubenchodev/materix-react/components/fab';

const sizes: FabSize[] = ['small', 'medium', 'large'];
const colors: FabColor[] = ['primary', 'secondary', 'success'];

export default function Demo() {
  const [size, setSize] = useState<FabSize>('large');
  const [color, setColor] = useState<FabColor>('primary');
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  return (
    <>
      <div className="demo-group">
        <span className="demo-label">Controlled FAB</span>
        <div className="demo-row">
          <Fab
            icon="bolt"
            aria-label="Quick action"
            size={size}
            color={color}
            disabled={disabled}
            onClick={() => write('click on "Quick action"')}
          />
          <span className="demo-status">
            size: {size} · color: {color} · disabled: {String(disabled)}
          </span>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          {sizes.map((value) => (
            <Button
              key={value}
              variant="outlined" size="small"
              onClick={() => {
                setSize(value);
                write(`size = '${value}'`);
              }}
            >
              size = &apos;{value}&apos;
            </Button>
          ))}
        </div>
        <div className="demo-row">
          {colors.map((value) => (
            <Button
              key={value}
              variant="outlined" size="small"
              onClick={() => {
                setColor(value);
                write(`color = '${value}'`);
              }}
            >
              color = &apos;{value}&apos;
            </Button>
          ))}
        </div>
        <div className="demo-row">
          {[true, false].map((value) => (
            <Button
              key={String(value)}
              variant="outlined" size="small"
              onClick={() => {
                setDisabled(value);
                write(`disabled = ${value}`);
              }}
            >
              disabled = {String(value)}
            </Button>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </>
  );
}

Referencia de la API#

Props#

PropTipoPor defectoDescripción
iconReactNode—Icono inicial: nombre de Material Icons ("add") o un nodo (SVG…).
labelReactNode—Texto en un <span>; convierte el FAB en extendido.
variant'circular' | 'extended''circular'Fuerza la variante extendida (con label siempre es extendido).
size'small' | 'medium' | 'large''large'Ver la tabla de tamaños.
color'primary' | 'secondary' | 'default' | 'success' | 'error' | 'warning' | 'info' | 'inherit''primary'Color del FAB.
position'fixed-br' | 'fixed-bl' | 'absolute-center'—Posición flotante.
disabledbooleanfalsedisabled nativo; aria-disabled en enlaces.
disableRipplebooleanfalseDesactiva el ripple.
hrefstring—Renderiza un <a>.
componentElementType'button' / 'a'Elemento raíz propio.
childrenReactNode—Contenido extra tras el icono y el texto.
className, style, ref, aria-*, on*…——Se reenvían a la raíz; className se concatena.

Clases CSS#

ClaseDescripción

mtx-fab--extendedVariante extendida (48px de alto, esquinas tipo píldora).
mtx-fab--medium / --small48 / 40px circular; 40 / 34px extendido.
mtx-fab--secondary, --success, --error, --warning, --infoColores de la paleta.
mtx-fab--default / --inheritSuperficie neutra con borde / colores heredados.
mtx-fab--fixed-br / --fixed-blFijo abajo a la derecha / izquierda (24px).
mtx-fab--absolute-centerCentrado sobre el borde superior del contenedor posicionado.

VariableUso

Accesibilidad#

  • Renderiza un <button> nativo con type="button". El FAB circular necesita aria-label; el extendido toma el nombre de su texto.
  • Colócalo en un punto lógico del orden de lectura: aunque flote visualmente, su posición en el DOM fija el orden de tabulación.
  • disabled lo saca del orden de tabulación.
TeclaAcción
Tab / Shift+TabMueve el foco.
Enter / EspacioEjecuta la acción.
