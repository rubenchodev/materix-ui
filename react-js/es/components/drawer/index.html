Drawer

Panel lateral de navegación o contenido auxiliar: temporal, persistente, permanente o responsive, con cabecera y pie generados y patrón app shell.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Drawer } from '@rubenchodev/materix-react';

Drawer es un panel que se desliza desde un borde de la pantalla para mostrar la navegación de la aplicación o contenido auxiliar (filtros, detalles, opciones), como el Drawer de MUI. Úsalo para la navegación principal en móvil (temporal) o como barra lateral fija en escritorio (permanente). Para una decisión o un formulario breve que interrumpe el flujo usa un Dialog; para una lista corta de acciones sobre un elemento, un Menu.

import { Drawer } from '@rubenchodev/materix-react/components/drawer';
// piezas para composición manual y el hook responsive:
import { DrawerHeader, DrawerContent, DrawerFooter, DrawerSubmenu, useDrawer, useDrawerMode } from '@rubenchodev/materix-react/components/drawer';

Uso básico#

<Drawer open={…} onClose={…} title="…"> con el contenido directamente dentro. title genera la cabecera con título y botón de cierre; el contenido se envuelve en el panel desplazable .mtx-drawer__content y el drawer temporal añade un Backdrop. open es controlado: onClose(event, reason) solicita el cierre y tú actualizas el estado.

El hook useDrawer() hace esa conexión por ti, como usePopover y useMenu: devuelve { open, setOpen, toggle, getTriggerProps(), drawerProps }. Extiende getTriggerProps() en el disparador (añade aria-controls, aria-expanded y onClick; pasa { action: 'open' } para que solo abra, como data-mtx-drawer-open) y drawerProps (id, open, onClose) en el Drawer. Gracias a aria-controls, el disparador no cuenta como clic fuera.

const drawer = useDrawer();

<Button variant="contained" {...drawer.getTriggerProps({ action: 'open' })}>Abrir navegación</Button>
<Drawer {...drawer.drawerProps} title="Correo">…</Drawer>

App shell: AppBar + Drawer responsive#

La receta principal de una aplicación: una AppBar, una fila con un drawer variant="responsive" (temporal por debajo de breakpoint, permanente desde él) y el contenido principal. La AppBar se conecta al drawer con su botón de navegación, el equivalente React de data-drawer="id" de vanilla:

  • navigationControls={drawerId} pone aria-controls en el botón de menú,
  • navigationExpanded={open} mantiene aria-expanded sincronizado,
  • onNavigationClick alterna el estado,
  • useDrawerMode('responsive', 'md') devuelve el modo actual, así startIcon={mode === 'temporary' ? 'menu' : undefined} oculta el botón mientras el drawer es permanente (vanilla añade .mtx-drawer-trigger--hidden).

El drawer ignora los clics en su propio disparador (cualquier elemento con aria-controls apuntando a su id), así el botón no lo cierra y lo reabre. Aquí el shell vive dentro de un marco (absolute); en una página completa usa clipped y un ToolbarOffset al principio de <main>.

Variantes#

  • temporary (por defecto): modal sobre un fondo. Bloquea el scroll de la página, atrapa el foco, se cierra con Escape, el fondo o un clic fuera, y se renderiza en un portal (la raíz común [data-mtx-portal-root]; disablePortal lo deja en su sitio). El fondo es el componente Backdrop (.mtx-backdrop, con su fundido), no el .mtx-drawer__backdrop de vanilla.
  • persistent: se abre sin fondo y la página sigue usable; desplaza tú el contenido para hacerle sitio.
  • permanent: siempre visible, una caja de ancho fijo en una fila flex con un panel sticky del alto de la ventana. Nunca solicita cerrarse.
  • responsive: ver “Responsive”.

Con absolute el drawer y su fondo quedan dentro del padre posicionado (sin bloqueo de scroll), y el permanente toma el alto del contenedor.

Anchos#

Por defecto responsive: min(85vw, 320px) en móvil, 280px desde 600px y 300px desde 900px. width="narrow" | "wide" | "full" fija 200px, 360px o 100vw; cualquier número (px) o longitud CSS ("40vw") se aplica tal cual y también se escribe en --mtx-drawer-width. Nunca supera el 85% de la ventana salvo con full.

Anchos open_in_new

interface WidthOption {

const options: WidthOption[] = [

Anclas#

Bajo la AppBar (clipped)#

La AppBar ocupa todo el ancho y el drawer empieza debajo. En una página completa usa clipped en un drawer permanent, responsive o persistent: se coloca en --mtx-app-bar-height (56px en móvil, 64px desde 600px) y se apila bajo la AppBar (pon también clipped en la AppBar). El temporal ignora clipped: es modal y cubre la AppBar, como en MUI. Dentro de un marco, como aquí, se consigue con un drawer permanente absolute en la fila bajo la AppBar.

Responsive#

variant="responsive" con breakpoint="sm" | "md" | "lg" | "xl" (600, 900, 1200, 1536px; por defecto md): por debajo es temporal y se abre con su disparador; desde él, permanente. Al cruzar el breakpoint se sincronizan clases, ARIA, fondo y foco sin animación, se llama a onModeChange(mode, previousMode) (mtx:drawer:mode-change en vanilla) y un temporal abierto solicita el cierre con motivo breakpoint para no reaparecer al volver a móvil. Si el foco estaba dentro al pasar a temporal, pasa al disparador visible. El responsive se mantiene montado y en su sitio (sin portal), así su contenido conserva el estado. Con SSR el servidor no conoce el viewport y renderiza el modo temporal; tras hidratar, el drawer pasa al modo real sin llamar a onModeChange (vanilla tampoco emite mode-change al inicializarse). Ese primer cambio aún puede producir un salto en escritorio: si importa, renderiza el shell solo en el cliente o reserva el ancho del drawer. headerMode="temporary" muestra la cabecera generada solo mientras es temporal. Redimensiona la ventana.

Responsive: temporal en móvil, permanente en escritorio open_in_new
import { useId, useState } from 'react';
import { AppBar } from '@rubenchodev/materix-react/components/app-bar';
import { Drawer, useDrawerMode } from '@rubenchodev/materix-react/components/drawer';
import type { DrawerBreakpoint, DrawerMode } from '@rubenchodev/materix-react/components/drawer';
import { List, ListItemButton } from '@rubenchodev/materix-react/components/list';
import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';
import { Typography } from '@rubenchodev/materix-react/components/typography';

const folders = [
  { icon: 'inbox', label: 'Bandeja de entrada' },
  { icon: 'star', label: 'Destacados' },
  { icon: 'send', label: 'Enviados' },
  { icon: 'drafts', label: 'Borradores' },
];

export default function Demo() {
  const navId = useId();

  const mode = useDrawerMode('responsive', breakpoint);

  const handleModeChange = (next: DrawerMode, previous: DrawerMode) =>
    setLog((lines) => [...lines.slice(-3), `onModeChange: ${previous} → ${next}`]);

  return (
    <div className="demo-stack mtx-w-100">

          label="Breakpoint"

        >
          <option value="sm">sm · 600px</option>
          <option value="md">md · 900px</option>
          <option value="lg">lg · 1200px</option>
          <option value="xl">xl · 1536px</option>
        </NativeSelect>
      </div>
      <div className="demo-panel demo-panel--tall mtx-w-100">

          <AppBar

            color="primary"
            title="Correo"

            navigationExpanded={open}
            onNavigationClick={() => setOpen((value) => !value)}
          />
          <div className="mtx-position-relative mtx-d-flex mtx-flex-1 mtx-overflow-hidden">
            <Drawer
              id={navId}
              variant="responsive"
              breakpoint={breakpoint}
              absolute
              width={220}
              title="Correo"
              headerMode="temporary"
              aria-label="Carpetas"
              open={open}
              onClose={() => setOpen(false)}
              onModeChange={handleModeChange}
            >
              <List component="nav" aria-label="Carpetas">
                {folders.map((item) => (
                  <ListItemButton
                    key={item.label}
                    icon={item.icon}
                    selected={folder === item.label}
                    data-mtx-drawer-close

              </Typography>
            </main>
          </div>
        </div>
      </div>
      <pre className="demo-log" aria-live="polite">

      </pre>

Uso programático#

El equivalente de open(), close(reason), toggle() e isOpen es la prop open, o setOpen, toggle y open de useDrawer. onOpen y onClose(event, reason) equivalen a mtx:drawer:open y mtx:drawer:close. El registro muestra los callbacks reales: prueba también Escape, el fondo y la X.

Uso programático open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Drawer, useDrawer } from '@rubenchodev/materix-react/components/drawer';

export default function Demo() {
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [...lines.slice(-7), text]);
  // El hook da el estado, setOpen/toggle (open()/close()/toggle() de vanilla) y las props de disparador y drawer.
  const drawer = useDrawer({
    onOpen: () => write('onOpen'),
    onClose: (reason) => write(`onClose · reason="${reason}"`),
  });

  return (
    <div className="demo-stack demo-wide">
      <div className="demo-row">
        <Button variant="outlined" {...drawer.getTriggerProps({ action: 'open' })}>
          setOpen(true)
        </Button>
        <Button variant="outlined" {...drawer.getTriggerProps()}>
          toggle()
        </Button>
        <Button onClick={() => write(`open → ${drawer.open}`)}>Leer open</Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
      <Drawer anchor="right" title="Control programático" padded {...drawer.drawerProps}>
        <p>Ciérralo desde aquí con setOpen(false).</p>
        <Button variant="contained" onClick={() => drawer.setOpen(false)}>
          Guardar y cerrar
        </Button>
      </Drawer>
    </div>
  );
}

Accesibilidad#

  • temporary: el panel recibe role="dialog", aria-modal="true" y tabindex="-1", nombrado por el título generado o el aria-label / aria-labelledby del drawer. El foco va al primer elemento (o al marcado con data-drawer-autofocus), Tab no sale del panel y el foco vuelve al disparador al cerrar. persistent recibe role="region" y permanent role="navigation" (salvo que pases role). La raíz mantiene aria-hidden sincronizado.
  • Dale nombre al contenido: un <List component="nav" aria-label="…"> para la navegación, o un aria-label en el drawer.
  • El aria-label del botón de cierre generado sale del diccionario i18n (drawer.close: “Close” / “Cerrar”).
  • Conecta el disparador con aria-controls y aria-expanded (la AppBar lo hace con navigationControls y navigationExpanded).
  • Escape pasa por la pila común de capas: un Menu o Popover abierto dentro del drawer se cierra primero.
  • Respeta prefers-reduced-motion: sin transiciones de deslizamiento ni de submenús.
TeclaAcción
Enter / Espacio en el disparadorAbre o cierra el drawer.
Tab / Shift+TabRecorre el drawer; en temporary el foco no sale de él.
EscapeCierra el drawer temporal (salvo disableEscapeKeyDown).
Enter / Espacio en un submenúLo despliega o pliega.
