Dialog

Ventana modal que interrumpe la tarea para pedir una decisión o mostrar información crítica, con foco atrapado y cierre por Escape.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Dialog, DialogTitle, DialogContent, DialogContentText, DialogActions } from '@rubenchodev/materix-react';

Dialog abre un panel modal sobre la página: bloquea el scroll, atrapa el foco del teclado y obliga a resolver una decisión antes de continuar. Úsalo para confirmaciones, formularios cortos o información que el usuario no debe pasar por alto. No lo uses para avisos que no requieren respuesta (usa Snackbar o Alert) ni para navegación lateral (usa un Drawer).

import { Dialog, DialogTitle, DialogContent, DialogContentText, DialogActions } from '@rubenchodev/materix-react';
// o solo este componente:
import { Dialog } from '@rubenchodev/materix-react/components/dialog';

Uso básico#

La forma más simple es un único elemento: <Dialog open={…} onClose={…} title="…"> con el contenido como hijos. open es controlado: onClose(event, reason) solicita el cierre y tú actualizas el estado. El diálogo se renderiza en un portal sobre document.body, con el Backdrop compartido como fondo; Escape y un clic en el fondo lo cierran.

Uso básico open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [open, setOpen] = useState(false);
  return (
    <div className="demo-row">
      <Button variant="contained" onClick={() => setOpen(true)}>
        Open dialog
      </Button>
      <Dialog open={open} onClose={() => setOpen(false)} title="Use the device location">
        <p>Let apps determine your location to show you nearby results. Press Escape or click outside to close.</p>
      </Dialog>
    </div>
  );
}

Con acciones#

actions envuelve sus botones en un DialogActions, que siempre se coloca al final del panel, fuera del contenido. description genera un DialogContentText al inicio del contenido y lo enlaza con aria-describedby. Cualquier elemento con data-mtx-dialog-close dentro del diálogo solicita el cierre (motivo closeButtonClick). La acción principal usa contained y la secundaria text.

Alineación de las acciones#

Como en MUI, las acciones van a la derecha por defecto (end). Cámbiala con align="start|center|end|between" en DialogActions, o para todo el diálogo con actionsAlign (se aplica a las acciones sin align propio). between separa una acción auxiliar a la izquierda de las principales a la derecha. disableSpacing quita la separación entre botones.

Alineación de las acciones open_in_new

Tamaños#

maxWidth fija el ancho máximo del panel: xs (20rem), sm (24rem), md (32rem, por defecto), lg (48rem), xl (64rem) o false (sin límite). El panel ocupa el 100% del ancho disponible hasta ese máximo; con fullWidth={false} se ajusta a su contenido. fullScreen ocupa toda la ventana y quita las esquinas redondeadas, el patrón recomendado en móvil para tareas largas.

Tamaños open_in_new

Confirmación destructiva#

Para acciones irreversibles usa un título en forma de pregunta, explica la consecuencia y colorea la acción con color="error". role="alertdialog" indica a las tecnologías de asistencia que el diálogo requiere una respuesta urgente, y data-dialog-autofocus lleva el foco inicial a “Cancel”, la opción segura.

Confirmación destructiva open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [status, setStatus] = useState('');
  const close = () => setOpen(false);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" color="error" onClick={() => setOpen(true)}>
          Delete project
        </Button>
      </div>
      <p className="demo-status" role="status">
        {status}
      </p>
      <Dialog
        open={open}
        onClose={close}
        role="alertdialog"
        maxWidth="sm"
        title="Delete the project?"
        description="Its 24 files will be deleted and you will not be able to recover them."
        actions={
          <>
            <Button onClick={close} data-dialog-autofocus>
              Cancel
            </Button>
            <Button
              variant="contained"
              color="error"
              onClick={() => {
                setStatus('Project deleted');
                close();
              }}
            >
              Delete
            </Button>
          </>
        }
      />
    </div>
  );
}

Formulario dentro de un diálogo#

Un <form> puede contener los campos TextField y enviarse desde un botón de las acciones (type="submit" form="…"). El primer campo recibe el foco al abrir, o el marcado con data-dialog-autofocus, y Tab no sale del panel. Si el contenido empieza directamente con un campo, el CSS compartido reserva espacio arriba para que el label flotante no se recorte.

Formulario dentro de un diálogo open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog, DialogActions, DialogContent, DialogContentText } from '@rubenchodev/materix-react/components/dialog';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

const AUTOFOCUS = { 'data-dialog-autofocus': '' };

export default function Demo() {
  const [open, setOpen] = useState<'subscribe' | 'rename' | null>(null);
  const [status, setStatus] = useState('');
  const close = () => setOpen(null);

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const form = event.currentTarget;
    if (!form.checkValidity()) {
      form.reportValidity();
      return;
    }
    const email = (form.elements.namedItem('email') as HTMLInputElement).value;
    setStatus(`Subscribed: ${email}`);
    close();
  };

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" onClick={() => setOpen('subscribe')}>
          Subscribe
        </Button>
        <Button variant="outlined" onClick={() => setOpen('rename')}>
          Rename (field first)
        </Button>
      </div>
      <p className="demo-status" role="status">
        {status}
      </p>
      <Dialog open={open === 'subscribe'} onClose={close} maxWidth="sm" title="Subscribe to the newsletter">
        <DialogContent>
          <form className="demo-stack" id="dlg-form-el" onSubmit={handleSubmit}>
            <DialogContentText>Get the Materix UI news once a month.</DialogContentText>
            <TextField label="Name" name="name" defaultValue="Jane" required fullWidth />
            <TextField label="Email" type="email" name="email" required fullWidth inputProps={AUTOFOCUS} />
          </form>
        </DialogContent>
        <DialogActions>
          <Button onClick={close}>Cancel</Button>
          <Button variant="contained" type="submit" form="dlg-form-el">
            Subscribe
          </Button>
        </DialogActions>
      </Dialog>
      <Dialog
        open={open === 'rename'}
        onClose={close}
        maxWidth="sm"
        title="Rename file"
        actions={
          <>
            <Button onClick={close}>Cancel</Button>
            <Button variant="contained" onClick={close}>
              Rename
            </Button>
          </>
        }
      >
        <TextField label="File name" defaultValue="quarterly-report.pdf" fullWidth inputProps={AUTOFOCUS} />
      </Dialog>
    </div>
  );
}
<Dialog open={open} onClose={close} maxWidth="sm" title="Subscribe to the newsletter">
  <DialogContent>
    <form id="subscribe" onSubmit={handleSubmit}>
      <DialogContentText>Get the Materix UI news once a month.</DialogContentText>
      <TextField label="Name" name="name" required fullWidth />
      <TextField label="Email" type="email" name="email" required fullWidth
        inputProps={{ 'data-dialog-autofocus': '' }} />
    </form>
  </DialogContent>
  <DialogActions>
    <Button onClick={close}>Cancel</Button>
    <Button variant="contained" type="submit" form="subscribe">Subscribe</Button>
  </DialogActions>
</Dialog>

Scroll: panel y página#

Con scroll="paper" (por defecto) el contenido hace scroll dentro del panel; DialogContent dividers separa las zonas y DialogTitle sticky / DialogActions sticky fijan el título y las acciones. Con scroll="body" el panel crece con su contenido y lo que hace scroll es el contenedor del diálogo.

Scroll: panel y página open_in_new
import { useState } from 'react';

Comportamiento modal#

Por defecto el diálogo se cierra con un clic en el fondo (backdropClick) y con Escape (escapeKeyDown). disableBackdropClose y disableEscapeKeyDown obligan a elegir una acción explícita (el diálogo sigue consumiendo Escape, así que no llega a las capas de abajo). Mientras está abierto se bloquea el scroll de la página (disableScrollLock lo desactiva).

Comportamiento modal open_in_new
import { useState } from 'react';

        No backdrop close
      </Button>
      <Button variant="outlined" onClick={() => setOpen('strict')}>
        No backdrop or Escape

      <Dialog

        onClose={close}
        disableBackdropClose
        maxWidth="sm"
        title="Unsaved changes"
        actions={
          <>
            <Button onClick={close}>Discard</Button>

        }

        Clicking outside the panel does not close it; Escape does.

}

Diálogos anidados y Escape#

Los diálogos se suman a la pila común de capas: un diálogo abierto desde otro se apila encima (su z-index sube automáticamente), el foco queda atrapado solo en el superior y cada Escape cierra únicamente la capa de arriba.

Diálogos anidados y Escape open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';
import type { DialogCloseReason } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [share, setShare] = useState(false);
  const [permissions, setPermissions] = useState(false);
  const [confirm, setConfirm] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [...lines.slice(-5), text]);
  const closer =
    (name: string, setter: (value: boolean) => void) =>
    (_event: unknown, reason: DialogCloseReason) => {
      write(`${name} closed (${reason})`);
      setter(false);
    };

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" onClick={() => setShare(true)}>
          Open dialog
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
      <Dialog
        open={share}
        onClose={closer('Share', setShare)}
        maxWidth="sm"
        title="Share report"
        description="Each Escape closes only the top dialog; the ones below stay open."
        actions={
          <>
            <Button variant="outlined" startIcon="tune" onClick={() => setPermissions(true)}>
              Permissions
            </Button>
            <Button onClick={() => setShare(false)}>Close</Button>
          </>
        }
      >
        <Dialog
          open={permissions}
          onClose={closer('Permissions', setPermissions)}
          maxWidth="xs"
          title="Permissions"
          description="Remove access for everyone outside the team?"
          actions={
            <>
              <Button onClick={() => setPermissions(false)}>Back</Button>
              <Button variant="contained" color="error" onClick={() => setConfirm(true)}>
                Remove
              </Button>
            </>
          }
        >
          <Dialog
            open={confirm}
            onClose={closer('Confirm', setConfirm)}
            role="alertdialog"
            maxWidth="xs"
            title="Are you sure?"
            description="Third level: Escape closes this one first."
            actions={
              <Button
                variant="contained"
                onClick={() => {
                  write('Access removed');
                  setConfirm(false);
                  setPermissions(false);
                }}
              >
                Confirm
              </Button>
            }
          />
        </Dialog>
      </Dialog>
    </div>
  );
}

Capas apiladas y Escape#

Un Popover, un Menu y un Tooltip abiertos dentro de un diálogo se suman a la misma pila de capas: cada Escape cierra solo la capa superior (primero un tooltip visible), el foco entra en ellos sin que el panel lo recupere e interactuar con ellos nunca cierra el diálogo.

Uso programático#

El equivalente de open()/close() es la prop open. onOpen y onClose(event, reason) equivalen a mtx:dialog:open y mtx:dialog:close; onEntered y onExited se llaman al terminar la animación del panel. Con keepMounted el diálogo permanece en el DOM mientras está cerrado.

Uso programático open_in_new
import { useEffect, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';
import type { DialogCloseReason } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [auto, setAuto] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) =>
    setLog((lines) => [...lines.slice(-7), `${new Date().toLocaleTimeString()}  ${text}`]);

  // Equivalente a `open()` + `close('timeout-demo')` tras 2 s.
  useEffect(() => {
    if (!auto) return undefined;
    const timer = setTimeout(() => {
      write('close  reason=timeout-demo');
      setOpen(false);
      setAuto(false);
    }, 2000);
    return () => clearTimeout(timer);
  }, [auto]);

  const handleClose = (_event: unknown, reason: DialogCloseReason) => {
    write(`onClose  reason=${reason}`);
    setOpen(false);
    setAuto(false);
  };

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" onClick={() => setOpen(true)}>
          open
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setOpen(true);
            setAuto(true);
          }}
        >
          open and close after 2 s
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
      <Dialog
        open={open}
        onClose={handleClose}
        onOpen={() => write('onOpen')}
        onExited={() => write('onExited')}
        keepMounted
        maxWidth="sm"
        title="Programmatic dialog"
        actions={
          <Button variant="contained" data-mtx-dialog-close>
            Close
          </Button>
        }
      >
        Controlled with the <code>open</code> prop. Close it with Escape, the backdrop or the button.
      </Dialog>
    </div>
  );
}

Composición#

Para un control total, compón las piezas: DialogTitle da nombre al diálogo (aria-labelledby) y el primer DialogContentText lo describe (aria-describedby); los ids se generan a partir del id del diálogo (o de un id único). Puedes mezclar ambas formas: title y actions se siguen añadiendo aunque uses DialogContent como hijo.

Composición open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import {
  Dialog,
  DialogActions,
  DialogContent,
  DialogContentText,
  DialogTitle,
} from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const close = () => setOpen(false);
  return (
    <div className="demo-row">
      <Button variant="contained" onClick={() => setOpen(true)}>
        Open composed dialog
      </Button>
      <Dialog open={open} onClose={close} maxWidth="sm">
        <DialogTitle sticky>Composed structure</DialogTitle>
        <DialogContent>
          <DialogContentText>
            DialogTitle names the dialog (aria-labelledby) and the first DialogContentText describes it
            (aria-describedby), with no ids to write by hand.
          </DialogContentText>
        </DialogContent>
        <DialogActions sticky>
          <Button onClick={close}>Cancel</Button>
          <Button variant="contained" onClick={close}>
            OK
          </Button>
        </DialogActions>
      </Dialog>
    </div>
  );
}
<Dialog open={open} onClose={close} maxWidth="sm">
  <DialogTitle sticky>Composed structure</DialogTitle>
  <DialogContent>
    <DialogContentText>…</DialogContentText>
  </DialogContent>
  <DialogActions sticky>
    <Button onClick={close}>Cancel</Button>

  </DialogActions>

Accesibilidad#

  • El panel tiene role="dialog" (o alertdialog) y aria-modal="true"; su nombre viene del título (aria-labelledby) y su descripción del primer DialogContentText (aria-describedby). Sin título, dale un aria-label.
  • Al abrir, el foco va al elemento con data-dialog-autofocus, al primer control enfocable o al panel; al cerrar vuelve al elemento que lo tenía.
  • El foco queda atrapado en el diálogo superior; las capas abiertas desde él (popover, menú) gestionan su propio foco.
  • El scroll de la página se bloquea mientras está abierto.
TeclaAcción
EscapeCierra el diálogo superior (salvo con disableEscapeKeyDown).
Tab / Shift+TabRecorre de forma cíclica los controles del panel.
