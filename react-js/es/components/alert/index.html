Alert

Mensaje breve y destacado que informa del resultado de una acción o del estado del sistema sin interrumpir al usuario.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Alert, AlertTitle } from '@rubenchodev/materix-react';

Alert muestra un mensaje corto e importante dentro del flujo de la página, con un color y un icono que comunican su severidad (success, info, warning, error). Úsalo para confirmar una operación, avisar de un problema o explicar un error de validación junto al contenido afectado. No lo uses para notificaciones temporales que desaparecen solas (usa un Snackbar) ni para decisiones que bloquean la tarea (usa un Dialog).

import { Alert, AlertTitle } from '@rubenchodev/materix-react';
// o solo este componente:
import { Alert, AlertTitle } from '@rubenchodev/materix-react/components/alert';

Uso básico#

Basta con <Alert severity="…">: el componente genera el icono de la severidad, el contenedor .mtx-alert__message y, con title, el título.

Uso básico open_in_new
import { Alert } from '@rubenchodev/materix-react/components/alert';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <Alert severity="success">Your changes were saved successfully.</Alert>
      <Alert severity="error" title="Error">
        Could not connect to the server.
      </Alert>
    </div>
  );
}

Variantes#

Tres variantes, como en MUI: standard (fondo suave, por defecto), filled (fondo sólido) y outlined (solo borde). standard y outlined usan el color de la severidad oscurecido en el tema claro y aclarado en el oscuro, para que el texto mantenga el contraste.

Variantes open_in_new
import { Alert, type AlertVariant } from '@rubenchodev/materix-react/components/alert';
import { Grid } from '@rubenchodev/materix-react/components/grid';

const VARIANTS: Array<[AlertVariant, string]> = [
  ['standard', 'Standard'],
  ['filled', 'Filled'],
  ['outlined', 'Outlined'],
];

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {VARIANTS.map(([variant, name]) => (
        <Grid key={variant} size={{ xs: 12, md: 4 }}>
          <div className="demo-group">
            <span className="demo-label">{name}</span>
            <div className="demo-stack">
              <Alert severity="success" variant={variant}>
                Success: order confirmed.
              </Alert>
              <Alert severity="info" variant={variant}>
                Info: a new version is available.
              </Alert>
              <Alert severity="warning" variant={variant}>
                Warning: your plan expires soon.
              </Alert>
              <Alert severity="error" variant={variant}>
                Error: payment declined.
              </Alert>
            </div>
          </div>
        </Grid>
      ))}
    </Grid>
  );
}

Con y sin iconos#

Por defecto se genera el icono SVG de la severidad a 22px, como en MUI. icon lo sustituye (un nodo, o un nombre de Material Icons, que conserva su rejilla de 24px) e icon={false} lo elimina.

Con y sin iconos open_in_new
import { Alert } from '@rubenchodev/materix-react/components/alert';
import { Grid } from '@rubenchodev/materix-react/components/grid';

export default function Demo() {
  return (
    <Grid container spacing={2}>
      <Grid size={{ xs: 12, md: 4 }}>
        <div className="demo-group">
          <span className="demo-label">Automatic icon</span>
          <Alert severity="info">Icon generated from the severity.</Alert>
        </div>
      </Grid>
      <Grid size={{ xs: 12, md: 4 }}>
        <div className="demo-group">
          <span className="demo-label">Custom icon</span>
          <Alert
            severity="success"
            icon={
              <span className="material-icons" aria-hidden="true">
                cloud_done
              </span>
            }
          >
            Backup completed.
          </Alert>
        </div>
      </Grid>
      <Grid size={{ xs: 12, md: 4 }}>
        <div className="demo-group">
          <span className="demo-label">No icon</span>
          <Alert severity="warning" icon={false}>
            Alert without an icon.
          </Alert>
        </div>
      </Grid>
    </Grid>
  );
}

Severidades#

severity fija el color y el icono. Usa success, info, warning o error según el significado del mensaje; sin la prop se aplica success.

Severidades open_in_new
import { Alert } from '@rubenchodev/materix-react/components/alert';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <Alert severity="success" variant="filled">
        success — the operation completed successfully.
      </Alert>
      <Alert severity="info" variant="filled">
        info — neutral or contextual information.
      </Alert>
      <Alert severity="warning" variant="filled">
        warning — something needs attention soon.
      </Alert>
      <Alert severity="error" variant="filled">
        error — the operation failed and action is required.
      </Alert>
    </div>
  );
}

title genera un .mtx-alert__title en negrita sobre el mensaje. También puedes escribir <AlertTitle> como primer hijo, como en MUI.

Acciones#

action coloca contenido a la derecha del mensaje (por ejemplo, un botón «Deshacer»).

Acciones open_in_new
import { Alert } from '@rubenchodev/materix-react/components/alert';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <Alert
        severity="success"
        action={
          <Button variant="text" size="small" color="success">
            Undo
          </Button>
        }
      >
        1 conversation was deleted.
      </Alert>
      <Alert
        severity="warning"
        variant="outlined"
        title="Storage almost full"
        action={
          <Button variant="text" size="small" color="warning">
            Upgrade
          </Button>
        }
      >
        You have used 92% of your space.
      </Alert>
    </div>
  );
}

Descartables#

onClose (o dismissible) añade un botón de cierre accesible; closeLabel cambia su nombre para lectores de pantalla (por defecto, Close / Cerrar del diccionario i18n). Al cerrarse, la alerta se desvanece durante 200 ms, recibe hidden (sale del flujo: no deja hueco) e invoca onClosed. Las alertas no controladas se cierran solas; con open, onClose es una solicitud y tú actualizas el estado.

Descartables open_in_new
import { useState } from 'react';
import { Alert } from '@rubenchodev/materix-react/components/alert';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const [notice, setNotice] = useState(true);
  const [critical, setCritical] = useState(true);
  return (
    <div className="demo-stack demo-wide">
      <Alert severity="info" open={notice} onClose={() => setNotice(false)} closeLabel="Dismiss notice">
        You can dismiss this notice.
      </Alert>
      <Alert severity="error" variant="filled" title="Critical error" open={critical} onClose={() => setCritical(false)}>
        Synchronization has stopped.
      </Alert>
      <div className="demo-row">
        <Button
          variant="outlined"
          onClick={() => {
            setNotice(true);
            setCritical(true);
          }}
        >
          Restore closed alerts
        </Button>
      </div>
    </div>
  );
}

En formularios#

Vincula open al resultado de la validación (los campos son TextField outlined): una alerta cerrada tiene hidden y no ocupa espacio. Envía el formulario vacío para ver el error y rellénalo para ver el mensaje de éxito.

En formularios open_in_new
import { useState, type FormEvent } from 'react';
import { Alert } from '@rubenchodev/materix-react/components/alert';
import { Button } from '@rubenchodev/materix-react/components/button';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  const [result, setResult] = useState<'idle' | 'error' | 'success'>('idle');

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const data = new FormData(event.currentTarget);
    const valid = String(data.get('email') ?? '').trim() !== '' && String(data.get('password') ?? '').trim() !== '';
    setResult(valid ? 'success' : 'error');
  };

  return (
    <form className="demo-stack demo-fixed-width" noValidate onSubmit={handleSubmit}>
      <Alert severity="error" title="Check the form" open={result === 'error'}>
        Email and password are required.
      </Alert>
      <Alert severity="success" open={result === 'success'}>
        Signed in successfully.
      </Alert>
      <TextField label="Email" variant="outlined" type="email" name="email" autoComplete="email" />
      <TextField label="Password" variant="outlined" type="password" name="password" autoComplete="current-password" />
      <Button variant="contained" type="submit">
        Sign in
      </Button>
    </form>
  );
}

Uso programático#

El equivalente de close()/open() es la prop open. onOpen y onClosed equivalen a los eventos mtx:alert:open y mtx:alert:close; las alertas nuevas simplemente se renderizan.

Uso programático open_in_new
import { useState } from 'react';
import { Alert, type AlertSeverity } from '@rubenchodev/materix-react/components/alert';
import { Button } from '@rubenchodev/materix-react/components/button';

const SEVERITIES: AlertSeverity[] = ['success', 'info', 'warning', 'error'];

export default function Demo() {
  const [open, setOpen] = useState(true);
  const [dynamic, setDynamic] = useState<number[]>([]);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [...lines, `${new Date().toLocaleTimeString()}  ${text}`]);

  return (
    <div className="demo-stack demo-wide">
      <Alert
        severity="info"
        open={open}
        onClose={() => setOpen(false)}
        onClosed={() => write('onClosed  ← controlled alert')}
        onOpen={() => write('onOpen    ← controlled alert')}
      >
        Controlled from React state.
      </Alert>
      {dynamic.map((id) => (
        <Alert key={id} severity={SEVERITIES[id % 4]} dismissible onClosed={() => write(`onClosed  ← dynamic alert #${id}`)}>
          Dynamic alert #{id}
        </Alert>
      ))}
      <div className="demo-row">
        <Button variant="outlined" onClick={() => setOpen(false)}>
          open = false
        </Button>
        <Button variant="outlined" onClick={() => setOpen(true)}>
          open = true
        </Button>
        <Button
          variant="contained"
          onClick={() => {
            const id = dynamic.length + 1;
            setDynamic((list) => [...list, id]);
            write(`render <Alert> #${id}`);
          }}
        >
          Create alert
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accesibilidad#

  • La raíz tiene role="alert", que los lectores de pantalla anuncian de inmediato. Para mensajes informativos que no deben interrumpir, pasa role="status".
  • Los iconos SVG generados tienen aria-hidden="true" y focusable="false"; el significado debe estar en el texto, no solo en el color.
  • El botón de cierre es un <button type="button"> nativo con un aria-label configurable mediante closeLabel.
  • Si pasas un nodo de icono propio, márcalo con aria-hidden="true".
TeclaAcción
TabMueve el foco a la acción y al botón de cierre.
Enter / EspacioActiva el botón enfocado (cierre o acción).
