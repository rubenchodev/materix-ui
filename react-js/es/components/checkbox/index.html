Checkbox

Casilla para seleccionar una o varias opciones de una lista o confirmar una condición; admite estado indeterminado.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Checkbox } from '@rubenchodev/materix-react';

Checkbox permite seleccionar cero, una o varias opciones de un conjunto, o confirmar una condición («Acepto los términos»). Renderiza un <input type="checkbox"> nativo dentro de un <label class="mtx-checkbox">, por lo que funciona en formularios, con teclado y con lectores de pantalla sin código extra. Si la opción aplica un cambio inmediato, usa un Switch; si solo puede elegirse una opción, usa Radio.

lightbulb

¿Checkbox, Switch o Radio?

ComponenteCuándo usarlo
CheckboxVarias opciones independientes, o una confirmación que se aplica al enviar un formulario.
SwitchActivar/desactivar una preferencia con efecto inmediato, sin botón «Guardar».
RadioElegir exactamente una opción de un grupo pequeño y visible.
import '@rubenchodev/materix-ui/base.css';
import { Checkbox } from '@rubenchodev/materix-react';

<Checkbox label="Recordarme" defaultChecked />

Uso básico#

Basta un elemento con label: el componente renderiza el <label> envolvente, el input nativo, la caja visual y el texto. Las props nativas (id, name, value, required, autoFocus, form) van al <input>.

Uso básico open_in_new
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';

export default function Demo() {
  return (
    <div className="demo-row">
      <Checkbox label="Remember me" defaultChecked />
      <Checkbox label="Receive updates" />
    </div>
  );
}

Tamaños#

Dos tamaños, como en MUI: medium (caja de 18px, por defecto) y small (16px con texto de 14px) con size="small", para tablas y formularios densos.

Texto de ayuda y error (FormHelperText)#

helperText envuelve la casilla en .mtx-form-control y añade debajo un .mtx-form-helper-text, fuera del <label>, enlazado con aria-describedby. error añade aria-invalid="true" al input, colorea el borde de la caja vacía y pone el texto en rojo; pasa el mensaje de error como helperText. También puedes componer las piezas con FormControl y FormHelperText: la casilla hereda error/disabled y enlaza el texto automáticamente.

Ayuda y error (FormHelperText) open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { FormControl, FormHelperText } from '@rubenchodev/materix-react/components/form-helper-text';

export default function Demo() {
  const [accepted, setAccepted] = useState(false);
  const [submitted, setSubmitted] = useState(false);
  const showError = submitted && !accepted;

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    setSubmitted(true);
  };

  return (
    <div className="demo-stack">
      <div className="demo-grid-3">
        <div className="demo-group">
          <span className="demo-label">Helper text</span>
          <Checkbox label="Email me the receipt" helperText="It will be sent to jane@example.com" defaultChecked />
        </div>
        <div className="demo-group">
          <span className="demo-label">Error without message · error</span>
          <Checkbox label="I confirm I am of legal age" helperText="Legal requirement" error />
        </div>
        <div className="demo-group">
          <span className="demo-label">Validation on submit</span>
          <form className="demo-stack" noValidate onSubmit={handleSubmit}>
            <Checkbox
              label="I accept the terms and the privacy policy"
              required
              checked={accepted}
              onChange={(_, checked) => setAccepted(checked)}
              error={showError}
              helperText={showError ? 'You must accept the terms to continue.' : undefined}
            />
            <div className="demo-row">
              <Button variant="contained" type="submit">
                Create account
              </Button>
            </div>
          </form>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">FormControl + FormHelperText</span>
        <FormControl>
          <Checkbox label="Subscribe to the newsletter" />
          <FormHelperText>One email a month, no spam.</FormHelperText>
        </FormControl>
      </div>
    </div>
  );
}

Indeterminado#

El estado indeterminado indica que solo algunas opciones hijas están marcadas. Como en MUI, indeterminate lo controla el padre: el componente mantiene la propiedad DOM input.indeterminate y aria-checked="mixed" sincronizadas con la prop en cada render.

Indeterminado open_in_new
import { useState } from 'react';
import '@rubenchodev/materix-ui/utilities.css';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { Stack } from '@rubenchodev/materix-react/components/stack';

const PERMISSIONS = ['Read', 'Write', 'Delete'];

export default function Demo() {
  const [checked, setChecked] = useState([true, false, false]);
  const count = checked.filter(Boolean).length;

  return (
    <div className="demo-panel demo-fixed-width">
      <Checkbox
        label="All permissions"
        checked={count === checked.length}
        indeterminate={count > 0 && count < checked.length}
        onChange={(_, next) => setChecked(checked.map(() => next))}
      />
      <Stack spacing={1} alignItems="start" className="mtx-ps-3">
        {PERMISSIONS.map((permission, index) => (
          <Checkbox
            key={permission}
            label={permission}
            checked={checked[index]}
            onChange={(_, next) => setChecked(checked.map((value, i) => (i === index ? next : value)))}
          />
        ))}
      </Stack>
    </div>
  );
}

Uso controlado#

Con checked + onChange el estado lo gestiona el padre; los métodos de la instancia vanilla pasan a ser cambios de estado (toggle() → setChecked(!checked), disable() → disabled, setError() → error + helperText) y focus() usa inputRef.

Uso controlado open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';

export default function Demo() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [checked, setChecked] = useState(false);
  const [indeterminate, setIndeterminate] = useState(false);
  const [disabled, setDisabled] = useState(false);
  const [error, setError] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ['toggle', () => { setIndeterminate(false); setChecked((value) => !value); }],
    ['checked = true', () => setChecked(true)],
    ['indeterminate = true', () => setIndeterminate(true)],
    ['disabled = true', () => setDisabled(true)],
    ['disabled = false', () => setDisabled(false)],
    ['focus()', () => inputRef.current?.focus()],
    ['error = true', () => setError(true)],
    ['error = false', () => setError(false)],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Controlled checkbox</span>
        <div className="demo-row">
          <Checkbox
            label="Controlled checkbox"
            inputRef={inputRef}
            checked={checked}
            indeterminate={indeterminate}
            disabled={disabled}
            error={error}
            helperText={error ? 'Check this box.' : undefined}
            onChange={(_, next) => {
              setIndeterminate(false);
              setChecked(next);
              write(`onChange (user) → checked: ${next}`);
            }}
          />
          <span className="demo-status">
            checked: {String(checked)} · indeterminate: {String(indeterminate)} · disabled: {String(disabled)}
          </span>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          {actions.map(([label, run]) => (
            <Button
              key={label}
              variant="outlined"
              size="small"
              onClick={() => {
                run();
                write(label);
              }}
            >
              {label}
            </Button>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

Accesibilidad#

  • El input nativo sigue en el DOM: conserva el envío de formularios, required y la semántica de casilla.
  • Toda la fila (<label>) es clicable. Sin label, usa aria-label o aria-labelledby.
  • El estado marcado lo expone el input nativo (sin aria-checked redundante); indeterminate añade aria-checked="mixed". En modo no controlado el input es nativo (defaultChecked), así que form.reset() lo restaura.
  • El texto de ayuda queda fuera del <label> (no se mezcla con el nombre accesible) y se enlaza con aria-describedby, conservando los ids que pases. error añade aria-invalid="true".
  • Agrupa las opciones relacionadas bajo un FormLabel (role="group" + aria-labelledby) o un <fieldset> con <legend>.
