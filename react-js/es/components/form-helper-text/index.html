Form Helper Text

Texto de ayuda y de error bajo un control de formulario, con FormControl y FormLabel para compartir error, deshabilitado y requerido con los controles internos.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { FormHelperText, FormControl, FormLabel, useFormControl } from '@rubenchodev/materix-react';

FormHelperText es el texto bajo un control que explica qué introducir o por qué el valor no es válido. FormControl agrupa un rótulo, un control y su texto de ayuda y comparte error, disabled y required mediante un contexto, para que todas las piezas cambien a la vez; FormLabel es el rótulo del grupo. Checkbox, Switch y RadioGroup ya renderizan estas piezas con helperText y error; úsalas directamente para componer tus propias maquetaciones o crear controles nuevos con useFormControl().

lightbulb

Cuándo componerlo a mano

Para un único control, usa las props helperText/error de Checkbox, Switch o Radio. Recurre a FormControl cuando varios controles comparten un rótulo y un mensaje, o cuando escribes un control propio.

import '@rubenchodev/materix-ui/base.css';
import { FormControl, FormHelperText, FormLabel } from '@rubenchodev/materix-react';

<FormControl error>
  <FormLabel>Consentimiento</FormLabel>
  {/* control */}
  <FormHelperText>Debes aceptar los términos.</FormHelperText>
</FormControl>

Uso básico#

FormHelperText renderiza un <p class="mtx-form-helper-text"> con un id generado. error lo pone en rojo; disabled lo atenúa y añade aria-disabled.

Uso básico open_in_new
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { FormControl, FormHelperText } from '@rubenchodev/materix-react/components/form-helper-text';

export default function Demo() {
  return (
    <div className="demo-grid-3">
      <div className="demo-group">
        <span className="demo-label">Helper text</span>
        <FormControl>
          <Checkbox label="Email me the receipt" defaultChecked />
          <FormHelperText>We will never share your email.</FormHelperText>
        </FormControl>
      </div>
      <div className="demo-group">
        <span className="demo-label">Error · error</span>
        <FormControl error>
          <Checkbox label="I accept the terms" required />
          <FormHelperText>This field is required.</FormHelperText>
        </FormControl>
      </div>
      <div className="demo-group">
        <span className="demo-label">Disabled · disabled</span>
        <FormControl disabled>
          <Checkbox label="Priority support" />
          <FormHelperText>Not available on your plan.</FormHelperText>
        </FormControl>
      </div>
    </div>
  );
}

FormControl y FormLabel#

Dentro de un FormControl, el rótulo, el texto de ayuda y los controles heredan error y disabled. Checkbox, Switch y RadioGroup además enlazan cada FormHelperText del grupo con aria-describedby.

FormControl y FormLabel open_in_new
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { Switch } from '@rubenchodev/materix-react/components/switch';
import { FormControl, FormHelperText, FormLabel } from '@rubenchodev/materix-react/components/form-helper-text';

export default function Demo() {
  return (
    <div className="demo-grid-3">
      <FormControl role="group" aria-labelledby="fht-default-label">
        <FormLabel id="fht-default-label">Newsletter</FormLabel>
        <Checkbox label="Weekly digest" defaultChecked />
        <FormHelperText>One email a week.</FormHelperText>
      </FormControl>
      <FormControl role="group" aria-labelledby="fht-error-label" error>
        <FormLabel id="fht-error-label">Consent</FormLabel>
        <Checkbox label="I accept the terms" />
        <FormHelperText>You must accept the terms.</FormHelperText>
      </FormControl>
      <FormControl role="group" aria-labelledby="fht-disabled-label" aria-disabled="true" disabled>
        <FormLabel id="fht-disabled-label">Security</FormLabel>
        <Switch label="Security alerts" defaultChecked />
        <FormHelperText>Managed by your organization.</FormHelperText>
      </FormControl>
    </div>
  );
}

Contenido (contained)#

contained añade un margen lateral de 14px para alinear el texto con el contenido de un campo de texto outlined o filled.

Contenido (contained) open_in_new
import { FormControl, FormHelperText } from '@rubenchodev/materix-react/components/form-helper-text';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Default · aligned with the field edge</span>
        <FormControl>
          <TextField label="Company" variant="standard" />
          <FormHelperText>As it appears on your invoices.</FormHelperText>
        </FormControl>
      </div>
      <div className="demo-group">
        <span className="demo-label">contained · 14px inset (outlined/filled fields)</span>
        <FormControl>
          <TextField label="Company" variant="outlined" />
          <FormHelperText contained>Aligned with the text of the outlined field.</FormHelperText>
        </FormControl>
      </div>
    </div>
  );
}

Control propio con useFormControl#

useFormControl() devuelve el estado del FormControl más cercano (o undefined): error, disabled, required y helperTextIds, los ids de los textos de ayuda con contenido, listos para aria-describedby.

Control propio con useFormControl open_in_new
import { useState } from 'react';
import { FormControl, FormHelperText, FormLabel, useFormControl } from '@rubenchodev/materix-react/components/form-helper-text';
import { Switch } from '@rubenchodev/materix-react/components/switch';
import { TextField } from '@rubenchodev/materix-react/components/text-field';
import { Typography } from '@rubenchodev/materix-react/components/typography';

/** Indicador propio que lee el estado del FormControl más cercano. */
function FieldStatus() {
  const formControl = useFormControl();
  const label = formControl?.disabled ? 'Disabled' : formControl?.error ? 'Invalid' : 'Valid';
  return (
    <Typography variant="caption" className="mtx-mt-1" color={formControl?.error ? 'error' : 'text-secondary'}>
      Status: {label} · describedby: {formControl?.helperTextIds.length ?? 0} helper(s)
    </Typography>
  );
}

export default function Demo() {
  const [value, setValue] = useState('');
  const [disabled, setDisabled] = useState(false);
  const error = value.length > 0 && value.length < 3;
  return (
    <div className="demo-stack">
      <Switch label="Disable the group" checked={disabled} onChange={(_, next) => setDisabled(next)} />
      <FormControl error={error} disabled={disabled} required>
        <FormLabel>Account</FormLabel>
        <TextField label="Username" value={value} onChange={(_, next) => setValue(next)} />
        <FormHelperText contained>{error ? 'At least 3 characters.' : 'Letters and numbers only.'}</FormHelperText>
        <FieldStatus />
      </FormControl>
    </div>
  );
}

Referencia de la API#

Props de FormHelperText#

PropTipoPor defectoDescripción
errorbooleande FormControlColor de error (--error).
disabledbooleande FormControlAtenúa el texto (--disabled + aria-disabled). Heredado solo como aria-disabled.
containedbooleanfalseMargen lateral de un campo outlined/filled (--contained).
idstringautomáticoId usado por aria-describedby.
refRef<HTMLParagraphElement>—Ref al <p>.

Props de FormControl#

PropTipoPor defectoDescripción
errorbooleanfalseEstado de error compartido con los hijos (.mtx-form-control--error).
disabledbooleanfalseEstado deshabilitado compartido con los hijos (.mtx-form-control--disabled).
requiredbooleanfalseEstado requerido compartido con los hijos.
refRef<HTMLDivElement>—Ref al <div>.

Props de FormLabel#

Atributos nativos de <div>; renderiza .mtx-form-label (color primario con foco interno; colores de error y deshabilitado según FormControl).

useFormControl()#

Devuelve { error, disabled, required, helperTextIds, registerHelperText } | undefined. FormHelperText usa registerHelperText(id), que devuelve la función de desregistro. Solo se registran los helpers de nivel FormControl: el helperText de Checkbox, Switch o RadioGroup describe solo a su control, y un control con helperText propio no enlaza los del grupo.

className, style y el resto de atributos van al elemento raíz de cada componente.

Accesibilidad#

  • El texto de ayuda se enlaza con el control mediante aria-describedby: se lee después del nombre del control sin formar parte de él.
  • El error se comunica con aria-invalid="true" en el control, no solo con color: escribe el motivo en el texto de ayuda.
  • Los textos de ayuda deshabilitados llevan aria-disabled="true" para que su color atenuado se trate como contenido deshabilitado.
  • Nombra los grupos de controles con FormLabel + aria-labelledby (y role="group" en el FormControl).
