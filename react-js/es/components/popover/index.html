Popover

Paper flotante con contenido arbitrario anclado a un disparador. Se cierra al hacer clic fuera o con Escape y devuelve el foco al disparador.

codeCódigo fuente play_circleCódigo de las demos open_in_newReferencia MUI
Importar import { Popover } from '@rubenchodev/materix-react';

Un Popover muestra cualquier contenido (texto, formularios, tarjetas) en una superficie Paper flotante anclada a otro elemento, como el Popover de MUI. Úsalo para filtros, detalles rápidos, pequeñas confirmaciones o una tarjeta de cuenta. Para una lista de acciones usa un Menu; para una etiqueta de texto breve, un Tooltip; para una tarea que bloquea la página, un Dialog.

También es la base flotante sobre la que se construyen otros componentes (selectores de fecha, paneles de filtros): resuelve el posicionamiento, la pila de capas, el foco y el cierre.

import { Popover, usePopover } from '@rubenchodev/materix-react';
// o solo este componente:
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';

Uso básico#

usePopover() es el equivalente de data-open-popover="#id": extiende getTriggerProps() en el disparador y popoverProps en el <Popover>. Se abre debajo del disparador alineado a su borde inicial, con elevación 8. El foco pasa al primer control (o al panel) y vuelve al disparador al cerrarse.

Uso básico open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const popover = usePopover();
  return (
    <div className="demo-row">
      <Button variant="contained" {...popover.getTriggerProps()}>
        Open popover
      </Button>
      <Popover {...popover.popoverProps} label="Basic popover" className="mtx-p-2">
        The content of the popover.
      </Popover>
    </div>
  );
}

El panel se renderiza en un portal sobre document.body, así que los ancestros con overflow: hidden o su propio z-index nunca lo recortan. El relleno del contenido lo decides tú: usa utilidades como mtx-p-2.

Colocación#

placement usa el mismo motor que Tooltip (top|bottom|left|right con -start|-end; bottom-start por defecto), con volteo y desplazamiento automáticos. offset fija la separación en px (0 por defecto, como en MUI).

Colocación open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import type { PopoverProps } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';

/** Disparador con su propio popover colocado. */
function Placed({ label, text, ...props }: { label: string; text: string } & Partial<PopoverProps>) {
  const popover = usePopover();
  return (
    <>
      <Button variant="outlined" {...popover.getTriggerProps()}>
        {label}
      </Button>
      <Popover {...popover.popoverProps} label={label} className="mtx-p-2" {...props}>
        {text}
      </Popover>
    </>
  );
}

export default function Demo() {
  return (
    <div className="demo-row">
      <Placed label="top" text="Above and centered." placement="top" offset={8} />
      <Placed label="bottom-end" text="Below, aligned to the end." placement="bottom-end" />
      <Placed label="right · offset 8" text="To the right." placement="right" offset={8} />
      <Placed label="left · offset 8" text="To the left." placement="left" offset={8} />
    </div>
  );
}

Orígenes de anclaje#

La API de MUI: anchorOrigin={{ vertical, horizontal }} es el punto del ancla y transformOrigin el punto del popover que se une a él. Los valores son top|center|bottom y left|center|right, o píxeles (números). El popover se mantiene a marginThreshold px (16) de los bordes del viewport y la animación de crecimiento parte del origen de transformación.

Orígenes de anclaje open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import type { PopoverOrigin } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';

const CASES: Array<{ anchor: PopoverOrigin; transform: PopoverOrigin }> = [
  { anchor: { vertical: 'bottom', horizontal: 'left' }, transform: { vertical: 'top', horizontal: 'left' } },
  { anchor: { vertical: 'center', horizontal: 'center' }, transform: { vertical: 'center', horizontal: 'center' } },
  { anchor: { vertical: 'top', horizontal: 'right' }, transform: { vertical: 'bottom', horizontal: 'right' } },
];

const describe = (origin: PopoverOrigin) => `${origin.vertical} ${origin.horizontal}`;

/** Disparador con orígenes MUI. */
function Origin({ anchor, transform, index }: { anchor: PopoverOrigin; transform: PopoverOrigin; index: number }) {
  const popover = usePopover();
  return (
    <>
      <Button variant="outlined" {...popover.getTriggerProps()}>
        {describe(anchor)} → {describe(transform)}
      </Button>
      <Popover
        {...popover.popoverProps}
        anchorOrigin={anchor}
        transformOrigin={transform}
        label={`Origin ${index + 1}`}
        className="mtx-p-2"
      >
        anchor: {describe(anchor)} · transform: {describe(transform)}
      </Popover>
    </>
  );
}

export default function Demo() {
  return (
    <div className="demo-row">
      {CASES.map((item, index) => (
        <Origin key={index} index={index} anchor={item.anchor} transform={item.transform} />
      ))}
    </div>
  );
}

Si se indica cualquiera de los orígenes, tiene prioridad sobre placement.

Con iconos#

Cualquier botón puede ser el disparador. Los de solo icono necesitan un nombre accesible (aria-label). El disparador recibe aria-haspopup="dialog", aria-controls y un aria-expanded sincronizado. Varios disparadores pueden compartir un popover: da a cada uno una key (getTriggerProps({ key })) para que solo el activo quede expandido; cada disparador pasa a ser el ancla al pulsarlo.

Con iconos open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  const popover = usePopover();
  return (
    <div className="demo-row">
      <IconButton icon="info" aria-label="Order information" {...popover.getTriggerProps({ key: 'icon' })} />
      <Button variant="outlined" startIcon="tune" {...popover.getTriggerProps({ key: 'details' })}>
        Details
      </Button>
      <Button variant="text" endIcon="expand_more" {...popover.getTriggerProps({ key: 'more' })}>
        More
      </Button>
      <Popover {...popover.popoverProps} className="mtx-p-2 demo-fixed-width">
        <h3 className="mtx-typography--subtitle2 mtx-mb-1">Order #48213</h3>
        <p className="mtx-typography--body2 mtx-color-text-secondary">
          Shipped on October 12 with estimated delivery in 48 h.
        </p>
      </Popover>
    </div>
  );
}

El encabezado interno se convierte automáticamente en su nombre (aria-labelledby).

Estados#

Un disparador deshabilitado no abre el popover. Los elementos con data-mtx-popover-close dentro del popover lo cierran (motivo action) y devuelven el foco.

  );
}

Posición por coordenadas#

anchorReference="anchorPosition" con anchorPosition={{ top, left }} ancla el popover a un punto del viewport en lugar de a un elemento, por ejemplo la posición del cursor en un evento contextmenu. usePopover().openPopover({ x, y }) hace lo mismo. Con anchorReference="none" el popover se centra en el viewport.

Posición por coordenadas open_in_new
import { useState } from 'react';
import { Popover } from '@rubenchodev/materix-react/components/popover';

export default function Demo() {
  const [point, setPoint] = useState<{ top: number; left: number } | null>(null);
  return (
    <>
      <div
        className="demo-panel"
        tabIndex={0}
        aria-label="Area with a context menu"
        onContextMenu={(event) => {
          event.preventDefault();
          setPoint({ top: event.clientY, left: event.clientX });
        }}
      >
        <p>Right-click here to open a popover at the cursor.</p>
      </div>
      <Popover
        open={point !== null}
        anchorReference="anchorPosition"
        anchorPosition={point ?? undefined}
        onClose={() => setPoint(null)}
        label="Point details"
        className="mtx-p-2"
      >
        {point && `x: ${point.left} · y: ${point.top}`}
      </Popover>
    </>
  );
}

Modal#

Por defecto el popover es no modal: no atrapa el foco ni bloquea el scroll, y salir de él con Tab lo cierra (motivo tabOut). Con modal atrapa Tab, bloquea el scroll de la página y añade aria-modal="true", como el Popover de MUI; un clic fuera lo sigue cerrando (motivo clickaway) y llega al elemento pulsado, como en vanilla. data-autofocus en un control elige el foco inicial.

Modal open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  const popover = usePopover();
  return (
    <div className="demo-row">
      <Button variant="outlined" {...popover.getTriggerProps()}>
        Open modal
      </Button>
      <Popover {...popover.popoverProps} modal className="mtx-p-2">
        <h3 className="mtx-typography--subtitle2 mtx-mb-2">Rename</h3>
        <TextField label="Name" size="small" defaultValue="Q3 report" inputProps={{ 'data-autofocus': '' }} />
        <div className="mtx-d-flex mtx-justify-content-end mtx-gap-1 mtx-mt-2">
          <Button variant="text" data-mtx-popover-close="">
            Cancel
          </Button>
          <Button variant="contained" data-mtx-popover-close="">
            Save
          </Button>
        </div>
      </Popover>
    </div>
  );
}

Dialog desde un popover#

Un botón dentro del popover puede abrir un Dialog. Interactuar con el diálogo no cuenta como “clic fuera” para el popover, el primer Escape cierra solo el diálogo (el foco vuelve al botón dentro del popover) y el segundo cierra el popover.

Dialog desde un popover open_in_new
import { useState } from 'react';
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const popover = usePopover();
  const [dialogOpen, setDialogOpen] = useState(false);
  const closeDialog = () => setDialogOpen(false);
  return (
    <div className="demo-row">
      <Button variant="outlined" startIcon="tune" {...popover.getTriggerProps()}>
        Options
      </Button>
      <Popover {...popover.popoverProps} label="Options" className="mtx-p-2">
        <Checkbox label="Only mine" defaultChecked />
        <div className="mtx-d-flex mtx-justify-content-end mtx-mt-1">
          <Button variant="text" onClick={() => setDialogOpen(true)}>
            Advanced…
          </Button>
        </div>
      </Popover>
      <Dialog
        open={dialogOpen}
        onClose={closeDialog}
        maxWidth="xs"
        title="Advanced options"
        description="Press Escape once to close this dialog; the popover stays open."
        actions={
          <Button variant="text" onClick={closeDialog}>
            Close
          </Button>
        }
      />
    </div>
  );
}

Capa desde un popover#

Un popover también puede abrir otro popover (o un menú). Ambas comparten la pila de capas: interactuar con la capa superior no cuenta como “clic fuera” para el popover, el primer Escape cierra solo la capa superior (el foco vuelve a su disparador dentro del popover) y el segundo cierra el popover.

Capa desde un popover open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';

export default function Demo() {
  const outer = usePopover();
  const inner = usePopover();
  return (
    <div className="demo-row">
      <Button variant="outlined" startIcon="tune" {...outer.getTriggerProps()}>
        Options
      </Button>
      <Popover {...outer.popoverProps} label="Options" className="mtx-p-2">
        <Checkbox label="Only mine" defaultChecked />
        <div className="mtx-d-flex mtx-justify-content-end mtx-mt-1">
          <Button variant="text" {...inner.getTriggerProps()}>
            Advanced…
          </Button>
        </div>
        <Popover
          {...inner.popoverProps}
          placement="right-start"
          offset={8}
          label="Advanced options"
          className="mtx-p-2 demo-fixed-width"
        >
          <p className="mtx-typography--body2 mtx-mb-1">
            Press Escape once to close this layer; the first popover stays open.
          </p>
          <Checkbox label="Include archived" />
        </Popover>
      </Popover>
    </div>
  );
}

Interacción al pasar el ratón#

El patrón hover de MUI: abrir en mouseenter/focus y cerrar en mouseleave/blur, con disableAutoFocus, disableRestoreFocus y la utilidad mtx-pointer-events-none para que el popover nunca robe el puntero ni el foco.

Interacción al pasar el ratón open_in_new
import { useRef, useState } from 'react';
import { Popover } from '@rubenchodev/materix-react/components/popover';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const anchorRef = useRef<HTMLSpanElement>(null);
  return (
    <>
      <div className="demo-row">
        <span
          ref={anchorRef}
          className="mtx-typography--body1"
          tabIndex={0}
          aria-describedby={open ? 'popover-hover' : undefined}
          onMouseEnter={() => setOpen(true)}
          onMouseLeave={() => setOpen(false)}
          onFocus={() => setOpen(true)}
          onBlur={() => setOpen(false)}
        >
          Hover or focus this text
        </span>
      </div>
      <Popover
        id="popover-hover"
        open={open}
        anchorEl={anchorRef}
        anchorOrigin={{ vertical: 'bottom', horizontal: 'left' }}
        transformOrigin={{ vertical: 'top', horizontal: 'left' }}
        onClose={() => setOpen(false)}
        disableAutoFocus
        disableRestoreFocus
        label="Hover details"
        className="mtx-p-2 mtx-pointer-events-none"
      >
        I use Popover.
      </Popover>
    </>
  );
}

Uso programático#

La prop open equivale a open()/close(). usePopover() expone openPopover(anchor), close() y toggle(anchor); onOpen y onClose(event, reason) equivalen a mtx:popover:open y mtx:popover:close. La ref action expone updatePosition() (el update() de vanilla).

Uso programático open_in_new
import { useRef, useState } from 'react';
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [`[${new Date().toLocaleTimeString()}] ${text}`, ...lines]);
  const anchorRef = useRef<HTMLButtonElement>(null);
  const popover = usePopover({ onClose: (reason) => write(`onClose → ${reason}`) });

  return (
    <div className="demo-stack demo-wide">
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          <Button
            variant="outlined"
            size="small"
            ref={anchorRef}
            onClick={() => anchorRef.current && popover.openPopover(anchorRef.current)}
          >
            openPopover(anchor)
          </Button>
          <Button variant="outlined" size="small" onClick={(event) => popover.toggle(event.currentTarget)}>
            toggle(anchor)
          </Button>
        </div>
      </div>
      <Popover {...popover.popoverProps} label="Programmatic popover" className="mtx-p-2" onOpen={() => write('onOpen')}>
        <p className="mtx-mb-1">Opened from code.</p>
        <Button variant="text" size="small" onClick={popover.close}>
          close()
        </Button>
      </Popover>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

Disparador manual#

El equivalente del uso BEM manual de vanilla: puedes prescindir de usePopover y conectar el disparador a mano con aria-controls, aria-haspopup="dialog" y aria-expanded, dando al popover un id y nombrándolo con aria-labelledby. Un clic en un elemento cuyo aria-controls apunta al popover nunca se trata como “fuera”.

Disparador manual (aria-controls) open_in_new
import { useRef, useState } from 'react';
import { Popover } from '@rubenchodev/materix-react/components/popover';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const triggerRef = useRef<HTMLButtonElement>(null);
  return (
    <div className="demo-row">
      <button
        ref={triggerRef}
        type="button"
        className="mtx-button mtx-button--outlined"
        aria-haspopup="dialog"
        aria-controls={open ? 'popover-manual' : undefined}
        aria-expanded={open}
        onClick={() => setOpen((value) => !value)}
      >
        Open (aria-controls)
      </button>
      <Popover
        id="popover-manual"
        open={open}
        anchorEl={triggerRef}
        onClose={() => setOpen(false)}
        aria-labelledby="popover-manual-title"
        className="mtx-p-2"
      >
        <h3 className="mtx-typography--subtitle2" id="popover-manual-title">
          Full markup
        </h3>
        <p className="mtx-typography--body2">Triggered through aria-controls.</p>
      </Popover>
    </div>
  );
}

Reutilización en otros componentes#

Popover está pensado como base flotante de otras superficies. Estas son las props en las que se apoyan:

<Popover
  open={open}
  anchorEl={inputRef}                 // ref o elemento; o un ancla virtual
  placement="bottom-start"            // o anchorOrigin/transformOrigin
  offset={4}
  modal={isMobile}                    // atrapa Tab y bloquea el scroll
  disableAutoFocus                    // el propietario mueve el foco
  disableRestoreFocus                 // el propietario restaura el foco
  onClose={(event, reason) => …}      // escapeKeyDown | clickaway | tabOut | action
  role="dialog" aria-label="Elegir fecha"
  className="mtx-date-picker__popover"
/>

También se exportan resolveOrigin() (origen MUI a píxeles) y las constantes POPOVER_MARGIN_THRESHOLD y POPOVER_EXIT_DURATION.

Accesibilidad#

  • El popover tiene role="dialog" y tabindex="-1". Su nombre viene de label (aria-label), de data-popover-title o del primer encabezado interno (aria-labelledby). Con modal también recibe aria-modal="true".
  • El disparador recibe aria-haspopup="dialog", aria-controls y un aria-expanded sincronizado con el estado (getTriggerProps).
  • Al abrirse, el foco pasa a [data-autofocus], al primer control enfocable o al propio panel. Al cerrarse con Escape, el disparador o un botón de cierre, el foco vuelve al elemento que lo tenía (o al ancla si el navegador no lo enfocó al hacer clic, como en Safari).
  • Un clic fuera lo cierra sin robar el foco al elemento pulsado; si el foco se fuera a perder, vuelve al disparador.
  • Si el disparador solo muestra un avatar o iniciales, nómbralo con texto visualmente oculto (<span className="mtx-visually-hidden">…</span>) en lugar de un aria-label que no contenga el texto visible (WCAG 2.5.3 Label in Name).
TeclaAcción
Enter / Espacio en el disparadorAbre o cierra el popover.
Tab / Shift+TabRecorre sus controles. No modal: salir del popover lo cierra. Modal: el foco circula dentro.
EscapeLo cierra y devuelve el foco al disparador, solo si es la capa superior.
