Internacionalización

Idioma de los textos incluidos (botones de cierre, selectores de fecha, paginación…): I18nProvider, useT, locale por componente, textos sobrescritos e idiomas propios.

Los componentes que muestran textos propios (aria-labels, el selector de fecha, la paginación, el botón de cierre del Drawer…) los toman de un diccionario. Se incluyen inglés (en) y español (es); puedes sobrescribir cualquier texto o registrar idiomas nuevos.

Elegir el idioma#

Precedencia, de mayor a menor:

  1. La prop locale de un componente que la admita.
  2. El locale del I18nProvider (o MaterixProvider) más cercano.
  3. El atributo lang de <html>.
  4. en.

Se aceptan códigos regionales (es-MX, en-GB): los textos salen del idioma base y las fechas y números se formatean con el código completo mediante Intl.

import { I18nProvider } from '@rubenchodev/materix-react';

export function App() {
  return (
    <I18nProvider locale="es-MX">
      <Checkout />
    </I18nProvider>
  );
}

MaterixProvider acepta las mismas props locale y messages, así que rara vez necesitas I18nProvider por separado. Los proveedores se pueden anidar: uno interior cambia el idioma de su subárbol.

Sobrescribir textos#

Pasa messages, por idioma, solo con los textos que quieras cambiar. Se combinan en profundidad sobre el diccionario incluido:

<I18nProvider
  locale="es"
  messages={{
    en: { drawer: { close: 'Hide menu' } },
    es: { drawer: { close: 'Ocultar menú' } },
  }}
>
  <App />
</I18nProvider>

Registrar un idioma#

Registra el diccionario una vez, al arrancar, fuera de React. Las claves que falten se toman del inglés.

import { addLocale, updateLocale } from '@rubenchodev/materix-react';

addLocale('fr', {
  code: 'fr',
  name: 'Français',
  drawer: { close: 'Fermer' },
});

// Cambia algunos textos de un idioma existente para toda la app.
updateLocale('es', { drawer: { close: 'Cerrar panel' } });

Los componentes se vuelven a renderizar automáticamente cuando cambia el registro.

useT en tus propios componentes#

useT(component) devuelve una función de traducción ligada al idioma actual. Úsala en componentes propios que deban seguir el mismo idioma que Materix:

import { useT } from '@rubenchodev/materix-react';

function CloseLabel() {
  const t = useT('drawer');
  return <span>{t('close')}</span>;
}

t(key, params?, fallback?) sustituye los marcadores {name} con params. Hooks relacionados: useLocale() devuelve el idioma resuelto (es) y useIntlLocale() el código completo para Intl (es-MX).
