React + TypeScript · v0.1.0

Componentes Material UI, nativos de React

Componentes React + TypeScript nativos con la estética de Material UI: el mismo CSS y los mismos design tokens de Materix UI, sin atributos data-mtx ni envoltorios sobre el DOM.

Empezar arrow_forward Ver componentes Versión vanilla

Instalación con npm

npm install @rubenchodev/materix-react

Importa el CSS y usa los componentes

import '@rubenchodev/materix-ui/base.css';
import { Button } from '@rubenchodev/materix-react';

export function App() {
  return <Button variant="contained">Save</Button>;
}

Por qué Materix UI

  • code

    React nativo

    Componentes React reales con props, estado y refs. Sin envoltorios sobre el DOM ni atributos data-mtx.

  • data_object

    TypeScript primero

    Props, eventos y refs tipados. Tu editor autocompleta cada variante, tamaño y color.

  • palette

    Fiel a Material UI

    Forma de 4px, Roboto, paleta, sombras y estados de interacción de MUI y Material Design 2.

  • accessibility_new

    Accesible por defecto

    Semántica nativa, navegación con teclado, foco visible y ARIA gestionado por cada componente.

  • dark_mode

    Tema claro y oscuro

    Los mismos design tokens --mtx-* que la versión vanilla, controlados con ThemeProvider y useTheme().

  • dns

    Listo para SSR

    Funciona con Vite y Next.js: componentes 'use client' y getThemeScript() para evitar parpadeos de tema.

Funcionando en un minuto#

Instala el paquete, importa la hoja de estilos base una sola vez y usa los componentes como con cualquier librería de React.

npm install @rubenchodev/materix-react

import '@rubenchodev/materix-ui/base.css';
import { Button, MaterixProvider } from '@rubenchodev/materix-react';

export function App() {
  return (
    <MaterixProvider defaultMode="system">
      <Button variant="contained">Guardar</Button>
    </MaterixProvider>
  );
}
info

Fuentes recomendadas

Los componentes usan Roboto y la fuente Material Icons. Cárgalas desde Google Fonts para obtener el aspecto exacto de MUI; sin ellas todo sigue funcionando con la fuente del sistema. Consulta Instalación.

El mismo sistema de diseño, dos sabores#

Materix UI · React comparte el CSS, los design tokens --mtx-* y las reglas visuales de la versión vanilla. Lo que cambia es la API: en lugar de atributos data-* e inicialización automática, tienes componentes React tipados con props, estado, refs y eventos. Si vienes de la librería vanilla, lee Migración desde vanilla.

Componentes

Layout

  • grid_view Grid Grilla flexbox de 12 columnas con cinco breakpoints (xs–xl), separación con gap en múltiplos de 8px (también por breakpoint) y alineación, para páginas responsivas.
  • format_paint CSS Baseline Base global de Materix: tipografía Roboto, colores de fondo y texto del tema, box-sizing, foco visible y color-scheme claro u oscuro.
  • crop_free Container Centra el contenido de la página con un ancho máximo por breakpoint y márgenes laterales responsive (16px en móvil, 24px desde 600px).
  • view_agenda Stack Apila elementos en una dirección (columna o fila) con separación uniforme, alineación, ajuste de línea, divisores y cambios por breakpoint.

Entradas

  • smart_button Button Botón de acción con variantes text, outlined y contained, tres alturas canónicas (48/40/32px), colores de la paleta, iconos y estado de carga.
  • view_week Button Group Agrupa botones relacionados en una sola pieza con bordes unidos, separadores y la variante, tamaño y color heredados.
  • ads_click Icon Button Botón circular de solo icono para acciones compactas en barras de herramientas, tarjetas y filas de tabla. Siempre con aria-label.
  • add_circle Fab Botón de acción flotante para la acción principal de una pantalla: circular (56/48/40px) o extendido con texto (48px).
  • check_box Checkbox Casilla para seleccionar una o varias opciones de una lista o confirmar una condición; admite estado indeterminado.
  • info Form Helper Text Texto de ayuda y de error bajo un control de formulario, con FormControl y FormLabel para compartir error, deshabilitado y requerido con los controles internos.
  • radio_button_checked Radio Botón de radio para elegir exactamente una opción de un grupo visible; RadioGroup lee y establece el valor del grupo.
  • star_half Rating Valoración con estrellas para opinar sobre un producto o mostrar una puntuación media, accesible con radios nativos y teclado.
  • tune Slider Permite elegir un valor o un rango arrastrando sobre una pista, construido sobre inputs range nativos accesibles.
  • toggle_on Switch Interruptor que activa o desactiva una opción al instante, como una preferencia de ajustes; usa role=switch sobre un checkbox nativo.
  • edit Text Field Campo de texto con label flotante, variantes MUI, iconos, contadores, máscaras de entrada y validación.
  • list Select Selector con menú propio al estilo MUI: búsqueda, selección múltiple, acciones masivas, grupos, límites e iconos o imágenes en las opciones.
  • arrow_drop_down_circle Native Select El <select> del navegador con estética MUI: ligero, accesible por defecto y con el selector táctil nativo en móviles.
  • manage_search Autocomplete Campo de texto con sugerencias filtrables: selección única o múltiple con chips, valores libres, grupos y carga asíncrona.
  • event Date Time Picker Selectores de fecha, hora, fecha y hora y rangos con calendario, reloj radial MD2, popover, modal o modo estático, límites y formatos.
  • toggle_off Toggle Button Los botones de alternancia agrupan opciones relacionadas con selección exclusiva o múltiple; solos funcionan como interruptor de una única acción.

Visualización de datos

  • account_circle Avatar Representa a una persona o entidad con una imagen, sus iniciales o un icono; AvatarGroup apila varios y resume el excedente.
  • notifications Badge Muestra un número o un punto de estado en la esquina de un icono, avatar o botón para señalar elementos nuevos o pendientes.
  • label Chip Elemento compacto que representa una etiqueta, un filtro, una entrada o una acción; puede llevar icono, avatar y botón de eliminar.
  • horizontal_rule Divider Línea fina que separa y agrupa contenido en listas, menús y maquetaciones, en horizontal o vertical y opcionalmente con texto.
  • format_list_bulleted List Lista vertical continua de texto, iconos o avatares; con ítems estáticos o interactivos, subcabeceras, densidad y selección.
  • table_chart Table Muestra conjuntos de datos en filas y columnas sobre una tabla HTML semántica, con densidad, cabecera fija, ordenación, selección y paginación.
  • text_fields Typography Aplica la escala tipográfica de MUI (h1 a overline) a cualquier elemento, separando la semántica HTML del estilo visual.
  • info Tooltip Etiqueta informativa breve que aparece al pasar el puntero, enfocar con teclado o mantener pulsado. Envuelve cualquier elemento con <Tooltip title>.

Feedback

  • warning Alert Mensaje breve y destacado que informa del resultado de una acción o del estado del sistema sin interrumpir al usuario.
  • gradient Backdrop Capa a pantalla completa que oscurece la página y centra un indicador mientras dura una operación; no sustituye a un diálogo.
  • open_in_browser Dialog Ventana modal que interrumpe la tarea para pedir una decisión o mostrar información crítica, con foco atrapado y cierre por Escape.
  • donut_large Progress Indicadores circulares y lineales que comunican que una operación está en curso o cuánto falta para terminarla.
  • view_day Skeleton Placeholders con la forma del contenido mientras se cargan los datos, con animación pulse o wave.
  • chat_bubble Snackbar Notificación breve y temporal en un borde de la pantalla que confirma una acción y puede ofrecer deshacerla.

Superficies

  • expand_circle_down Accordion Paneles que muestran y ocultan secciones de contenido relacionado tras un resumen pulsable; ideal para FAQ y ajustes agrupados.
  • view_headline App Bar Barra superior con el título, la navegación y las acciones principales de la pantalla actual.
  • web Card Superficie que agrupa contenido y acciones sobre un mismo tema: encabezado, imagen, texto y botones.
  • layers Paper Superficie base de Material Design con fondo, radio y sombra que agrupa contenido y expresa elevación.
  • picture_in_picture Popover Paper flotante con contenido arbitrario anclado a un disparador. Se cierra al hacer clic fuera o con Escape y devuelve el foco al disparador.

Navegación

  • more_horiz Breadcrumbs Ruta de navegación jerárquica que muestra dónde está el usuario y le permite volver a cualquier nivel superior.
  • menu_open Drawer Panel lateral de navegación o contenido auxiliar: temporal, persistente, permanente o responsive, con cabecera y pie generados y patrón app shell.
  • link Link Enlace de texto con estilo MUI sobre un <a> nativo: colores de la paleta y tres modos de subrayado, sin perder la semántica.
  • more_vert Menu Lista temporal de opciones anclada a un disparador: iconos, atajos, separadores, selección, opciones marcables, submenús, menú contextual y navegación completa por teclado.
  • last_page Pagination Permite elegir una página dentro de un conjunto grande de resultados, con elipsis, botones primera/última y modo enlaces para SSR.
  • tab Tabs Pestañas para alternar entre vistas del mismo nivel, con indicador animado, iconos, orientación vertical y navegación completa por teclado.
  • touch_app Speed Dial Botón de acción flotante que despliega de tres a seis acciones relacionadas con etiquetas, en cuatro direcciones, por clic o al pasar el cursor.
  • linear_scale Stepper Muestra el progreso a lo largo de una secuencia de pasos numerados, horizontal o vertical, lineal o con pasos clicables, y su versión móvil compacta.
