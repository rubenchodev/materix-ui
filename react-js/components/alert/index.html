Alert

A short, prominent message that reports the outcome of an action or the state of the system without interrupting the user.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Alert, AlertTitle } from '@rubenchodev/materix-react';

Alert shows a short, important message inside the page flow, with a color and an icon that communicate its severity (success, info, warning, error). Use it to confirm an operation, warn about a problem or explain a validation error next to the affected content. Don’t use it for temporary notifications that disappear on their own (use a Snackbar) or for decisions that block the task (use a Dialog).

import { Alert, AlertTitle } from '@rubenchodev/materix-react';
// or only this component:
import { Alert, AlertTitle } from '@rubenchodev/materix-react/components/alert';

Basic usage#

<Alert severity="…"> is enough: the component renders the severity icon, the .mtx-alert__message container and, with title, the title.

Basic usage open_in_new
import { Alert } from '@rubenchodev/materix-react/components/alert';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <Alert severity="success">Your changes were saved successfully.</Alert>
      <Alert severity="error" title="Error">
        Could not connect to the server.
      </Alert>
    </div>
  );
}

Variants#

Three variants, as in MUI: standard (soft background, default), filled (solid background) and outlined (border only). standard and outlined use the severity color darkened in the light theme and lightened in the dark theme, so the text keeps its contrast.

Variants open_in_new
import { Alert, type AlertVariant } from '@rubenchodev/materix-react/components/alert';
import { Grid } from '@rubenchodev/materix-react/components/grid';

const VARIANTS: Array<[AlertVariant, string]> = [
  ['standard', 'Standard'],
  ['filled', 'Filled'],
  ['outlined', 'Outlined'],
];

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {VARIANTS.map(([variant, name]) => (
        <Grid key={variant} size={{ xs: 12, md: 4 }}>
          <div className="demo-group">
            <span className="demo-label">{name}</span>
            <div className="demo-stack">
              <Alert severity="success" variant={variant}>
                Success: order confirmed.
              </Alert>
              <Alert severity="info" variant={variant}>
                Info: a new version is available.
              </Alert>
              <Alert severity="warning" variant={variant}>
                Warning: your plan expires soon.
              </Alert>
              <Alert severity="error" variant={variant}>
                Error: payment declined.
              </Alert>
            </div>
          </div>
        </Grid>
      ))}
    </Grid>
  );
}

With and without icons#

By default the severity SVG icon is rendered at 22px, as in MUI. icon replaces it (a node, or a Material Icons name, which keeps its 24px grid) and icon={false} removes it.

With and without icons open_in_new
import { Alert } from '@rubenchodev/materix-react/components/alert';
import { Grid } from '@rubenchodev/materix-react/components/grid';

export default function Demo() {
  return (
    <Grid container spacing={2}>
      <Grid size={{ xs: 12, md: 4 }}>
        <div className="demo-group">
          <span className="demo-label">Automatic icon</span>
          <Alert severity="info">Icon generated from the severity.</Alert>
        </div>
      </Grid>
      <Grid size={{ xs: 12, md: 4 }}>
        <div className="demo-group">
          <span className="demo-label">Custom icon</span>
          <Alert
            severity="success"
            icon={
              <span className="material-icons" aria-hidden="true">
                cloud_done
              </span>
            }
          >
            Backup completed.
          </Alert>
        </div>
      </Grid>
      <Grid size={{ xs: 12, md: 4 }}>
        <div className="demo-group">
          <span className="demo-label">No icon</span>
          <Alert severity="warning" icon={false}>
            Alert without an icon.
          </Alert>
        </div>
      </Grid>
    </Grid>
  );
}

Severities#

severity sets the color and the icon. Use success, info, warning or error according to the meaning of the message; without the prop, success is applied.

Severities open_in_new
import { Alert } from '@rubenchodev/materix-react/components/alert';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <Alert severity="success" variant="filled">
        success — the operation completed successfully.
      </Alert>
      <Alert severity="info" variant="filled">
        info — neutral or contextual information.
      </Alert>
      <Alert severity="warning" variant="filled">
        warning — something needs attention soon.
      </Alert>
      <Alert severity="error" variant="filled">
        error — the operation failed and action is required.
      </Alert>
    </div>
  );
}

title renders a bold .mtx-alert__title above the message. You can also write <AlertTitle> as the first child, as in MUI.

Title open_in_new

Actions#

action places content to the right of the message (for example, an “Undo” button).

Actions open_in_new
import { Alert } from '@rubenchodev/materix-react/components/alert';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <Alert
        severity="success"
        action={
          <Button variant="text" size="small" color="success">
            Undo
          </Button>
        }
      >
        1 conversation was deleted.
      </Alert>
      <Alert
        severity="warning"
        variant="outlined"
        title="Storage almost full"
        action={
          <Button variant="text" size="small" color="warning">
            Upgrade
          </Button>
        }
      >
        You have used 92% of your space.
      </Alert>
    </div>
  );
}

Dismissible#

onClose (or dismissible) adds an accessible close button; closeLabel changes its label for screen readers (by default, Close / Cerrar from the i18n dictionary). When closed, the alert fades out for 200 ms, receives hidden (it leaves the flow: no gap is left) and calls onClosed. Uncontrolled alerts close by themselves; with open, onClose is a request and you update the state.

Dismissible open_in_new
import { useState } from 'react';
import { Alert } from '@rubenchodev/materix-react/components/alert';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const [notice, setNotice] = useState(true);
  const [critical, setCritical] = useState(true);
  return (
    <div className="demo-stack demo-wide">
      <Alert severity="info" open={notice} onClose={() => setNotice(false)} closeLabel="Dismiss notice">
        You can dismiss this notice.
      </Alert>
      <Alert severity="error" variant="filled" title="Critical error" open={critical} onClose={() => setCritical(false)}>
        Synchronization has stopped.
      </Alert>
      <div className="demo-row">
        <Button
          variant="outlined"
          onClick={() => {
            setNotice(true);
            setCritical(true);
          }}
        >
          Restore closed alerts
        </Button>
      </div>
    </div>
  );
}

In forms#

Bind open to the validation result (the fields are outlined TextFields): a closed alert has hidden and takes no space. Submit the empty form to see the error and fill it in to see the success message.

In forms open_in_new
import { useState, type FormEvent } from 'react';
import { Alert } from '@rubenchodev/materix-react/components/alert';
import { Button } from '@rubenchodev/materix-react/components/button';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  const [result, setResult] = useState<'idle' | 'error' | 'success'>('idle');

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const data = new FormData(event.currentTarget);
    const valid = String(data.get('email') ?? '').trim() !== '' && String(data.get('password') ?? '').trim() !== '';
    setResult(valid ? 'success' : 'error');
  };

  return (
    <form className="demo-stack demo-fixed-width" noValidate onSubmit={handleSubmit}>
      <Alert severity="error" title="Check the form" open={result === 'error'}>
        Email and password are required.
      </Alert>
      <Alert severity="success" open={result === 'success'}>
        Signed in successfully.
      </Alert>
      <TextField label="Email" variant="outlined" type="email" name="email" autoComplete="email" />
      <TextField label="Password" variant="outlined" type="password" name="password" autoComplete="current-password" />
      <Button variant="contained" type="submit">
        Sign in
      </Button>
    </form>
  );
}

Programmatic usage#

The equivalent of close()/open() is the open prop. onOpen and onClosed are the equivalents of the mtx:alert:open and mtx:alert:close events; new alerts are just rendered.

Programmatic usage open_in_new
import { useState } from 'react';
import { Alert, type AlertSeverity } from '@rubenchodev/materix-react/components/alert';
import { Button } from '@rubenchodev/materix-react/components/button';

const SEVERITIES: AlertSeverity[] = ['success', 'info', 'warning', 'error'];

export default function Demo() {
  const [open, setOpen] = useState(true);
  const [dynamic, setDynamic] = useState<number[]>([]);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [...lines, `${new Date().toLocaleTimeString()}  ${text}`]);

  return (
    <div className="demo-stack demo-wide">
      <Alert
        severity="info"
        open={open}
        onClose={() => setOpen(false)}
        onClosed={() => write('onClosed  ← controlled alert')}
        onOpen={() => write('onOpen    ← controlled alert')}
      >
        Controlled from React state.
      </Alert>
      {dynamic.map((id) => (
        <Alert key={id} severity={SEVERITIES[id % 4]} dismissible onClosed={() => write(`onClosed  ← dynamic alert #${id}`)}>
          Dynamic alert #{id}
        </Alert>
      ))}
      <div className="demo-row">
        <Button variant="outlined" onClick={() => setOpen(false)}>
          open = false
        </Button>
        <Button variant="outlined" onClick={() => setOpen(true)}>
          open = true
        </Button>
        <Button
          variant="contained"
          onClick={() => {
            const id = dynamic.length + 1;
            setDynamic((list) => [...list, id]);
            write(`render <Alert> #${id}`);
          }}
        >
          Create alert
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accessibility#

  • The root has role="alert", which screen readers announce immediately. For informational messages that shouldn’t interrupt, pass role="status".
  • Generated SVG icons have aria-hidden="true" and focusable="false"; the meaning must be in the text, not only in the color.
  • The close button is a native <button type="button"> with an aria-label configurable through closeLabel.
  • If you pass a custom icon node, mark it with aria-hidden="true".
KeyAction
TabMoves focus to the action and the close button.
Enter / SpaceActivates the focused button (close or action).
