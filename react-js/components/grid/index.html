Grid

A 12-column flexbox grid with five breakpoints (xs–xl), gap-based spacing in multiples of 8px (also per breakpoint) and alignment, for responsive layouts.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Grid } from '@rubenchodev/materix-react';

Grid splits the available width into 12 columns and lets each item declare how many it spans at each breakpoint, just like MUI’s Grid (v2: flexbox with gap, no negative margins). Use it to lay out pages, forms and dashboards that change their number of columns with the screen width. To stack elements in a single direction with a fixed gap you don’t need a grid: use Stack; to center and cap the page width, Container.

import { Grid } from '@rubenchodev/materix-react';
// or only this component
import { Grid } from '@rubenchodev/materix-react/components/grid';

Basic usage#

A <Grid container> with spacing and items with columns per breakpoint through size (MUI Grid v2 API). Resize the window: 1 column on mobile, 2 on tablet and 4 on desktop.

Basic usage open_in_new
import './demo.css';
import { Grid } from '@rubenchodev/materix-react/components/grid';

export const description = {
  en: 'A `<Grid container>` with `spacing` and items with columns per breakpoint. Resize the window: 1 column on mobile, 2 on tablet and 4 on desktop.',
  es: 'Un `<Grid container>` con `spacing` e ítems con columnas por breakpoint. Redimensiona la ventana: 1 columna en móvil, 2 en tablet y 4 en escritorio.',
};

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {[1, 2, 3, 4].map((n) => (
        <Grid key={n} size={{ xs: 12, sm: 6, md: 3 }}>
          <div className="demo-grid-item">xs=12 sm=6 md=3</div>
        </Grid>
      ))}
    </Grid>
  );
}

A Grid with neither container nor a size behaves as a container (same as vanilla), and a Grid with a size is an item. Sizes can be written as size={{ xs: 12, md: 6 }}, as an array size={[12, 6]} (from xs) or with the individual xs, sm, md, lg, xl props (the data-xs… attributes of vanilla); the individual props win over size.

Columns#

Each item takes n/12 of the width. When the sum exceeds 12, the next items wrap to a new line.

import { Grid, type GridSize } from '@rubenchodev/materix-react/components/grid';

  es: 'Cada ítem ocupa `n/12` del ancho. Cuando la suma supera 12, los siguientes ítems saltan a una nueva línea.',
};

  [12, false],
  [6, false],
  [6, false],
  [4, false],
  [4, false],
  [4, false],
  [3, false],
  [3, false],
  [3, false],
  [3, false],
  [8, true],
  [4, true],
];
const pairs = Array.from({ length: 11 }, (_, i) => i + 1) as GridSize[];

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">12 · 6+6 · 4+4+4 · 3×4 · 8+4</span>
        <Grid container spacing={1}>
          {rows.map(([size, isAlt], i) => (
            <Grid key={i} size={size}>
              <div className={isAlt ? 'demo-grid-item demo-grid-item--alt' : 'demo-grid-item'}>{String(size)}</div>
            </Grid>
          ))}
        </Grid>
      </div>
      <div className="demo-group">
        <span className="demo-label">Pairs that add up to 12: n + (12 − n)</span>
        <Grid container spacing={1}>

            <Grid key={`a${String(n)}`} size={n}>
              <div className="demo-grid-item">{String(n)}</div>
            </Grid>,
            <Grid key={`b${String(n)}`} size={(12 - Number(n)) as GridSize}>
              <div className="demo-grid-item demo-grid-item--alt">{12 - Number(n)}</div>
            </Grid>,
          ])}
        </Grid>
      </div>
    </div>
  );
}

Spacing#

spacing={n} separates rows and columns by n × 8px using CSS gap, like MUI Grid v2. There are no negative margins or item paddings, so the grid never overflows its parent and needs no overflow: hidden wrapper. Each column width subtracts its proportional share of the gap (100% · n/12 − gap · (12 − n)/12), so 12 columns always add up to 100%.

Any integer from 0 to 12 is valid, plus the half steps 0.5, 1.5 and 2.5 (4, 12 and 20px). Values outside the scale are ignored with a warning in development. Spacing only applies to containers.

Spacing open_in_new
import './demo.css';
import { Grid, type GridSpacing } from '@rubenchodev/materix-react/components/grid';

export const description = {
  en: '`spacing={n}` separates rows and columns by `n × 8px` using `gap` (like MUI Grid v2): no negative margins or padding on the items, so the grid never overflows its parent. Values: any integer from 0 to 12 and the half steps `0.5`, `1.5` and `2.5`. Each column width subtracts its proportional share of the gap, so 12 columns always add up to 100%.',
  es: '`spacing={n}` separa filas y columnas `n × 8px` con `gap` (como MUI Grid v2): sin márgenes negativos ni rellenos en los ítems, así que la grilla nunca desborda a su padre. Valores: cualquier entero de 0 a 12 y los medios pasos `0.5`, `1.5` y `2.5`. El ancho de cada columna descuenta su parte proporcional del gap, de modo que 12 columnas siempre suman el 100%.',
};

const values: GridSpacing[] = [0, 0.5, 1, 1.5, 2, 2.5, 3, 4, 5, 6, 7, 8, 10, 12];

export default function Demo() {
  return (
    <div className="demo-stack">
      {values.map((spacing) => (
        <div className="demo-group" key={spacing}>
          <span className="demo-label">
            spacing={'{'}
            {spacing}
            {'}'} · {Number(spacing) * 8}px
          </span>
          <Grid container spacing={spacing}>
            {[1, 2, 3].map((n) => (
              <Grid key={n} size={4}>
                <div className="demo-grid-item">{spacing}</div>
              </Grid>
            ))}
          </Grid>
        </div>
      ))}
    </div>
  );
}

Alignment and direction#

justifyContent distributes the items horizontally (flex-start, center, flex-end, space-between, space-around, space-evenly) and alignItems aligns them vertically (flex-start, center, flex-end, stretch, baseline). The short aliases start, end, between, around and evenly are accepted too.

Alignment open_in_new

};

const justify: GridJustify[] = ['flex-start', 'center', 'flex-end', 'space-between', 'space-around', 'space-evenly'];
const align: GridAlign[] = ['flex-start', 'center', 'flex-end', 'stretch'];

export default function Demo() {
  return (

          <span className="demo-label">justifyContent=&quot;{value}&quot;</span>

            <Grid size={3}>

            </Grid>
            <Grid size={3}>
              <div className="demo-grid-item">{value}</div>

      ))}
      {align.map((value) => (

Controlled props#

In vanilla, setSpacing(n, bp?), setRowSpacing(), setColumnSpacing(), setJustifyContent(), setAlignItems() and setDirection() replace classes and new items are registered with Materix.init(). In React the props are the API and new items are just new children.

Controlled props open_in_new
import { useEffect, useRef, useState } from 'react';
import './demo.css';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Grid, type GridJustify, type GridSpacing } from '@rubenchodev/materix-react/components/grid';

export const description = {
  en: 'The vanilla `setSpacing()`, `setJustifyContent()` and `setDirection()` become props driven by state, and new items are just new children (no `Materix.init()`). Grid emits no events: the log shows the resulting classes.',
  es: 'Los `setSpacing()`, `setJustifyContent()` y `setDirection()` de vanilla pasan a ser props controladas por el estado y los ítems nuevos son simplemente nuevos hijos (sin `Materix.init()`). Grid no emite eventos: el registro muestra las clases resultantes.',
};

export default function Demo() {
  const [spacing, setSpacing] = useState<GridSpacing>(2);
  const [justify, setJustify] = useState<GridJustify>('flex-start');
  const [reversed, setReversed] = useState(false);
  const [count, setCount] = useState(3);
  const [log, setLog] = useState<string[]>([]);
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const classes = Array.from(ref.current?.classList ?? []).filter((c) => c.startsWith('mtx-grid--'));
    setLog((lines) => [...lines.slice(-5), `items=${count} → ${classes.join(' ')}`]);
  }, [spacing, justify, reversed, count]);

  return (
    <div className="demo-stack">
      <div className="demo-row">
        {([0, 2, 4] as GridSpacing[]).map((value) => (
          <Button key={value} variant="outlined" onClick={() => setSpacing(value)}>
            spacing {value}
          </Button>
        ))}
        <Button variant="outlined" onClick={() => setJustify('center')}>
          justify center
        </Button>
        <Button variant="outlined" onClick={() => setJustify('flex-start')}>
          justify flex-start
        </Button>
        <Button variant="outlined" aria-pressed={reversed} onClick={() => setReversed((r) => !r)}>
          direction reverse
        </Button>
        <Button variant="contained" onClick={() => setCount((c) => c + 1)}>
          Add item
        </Button>
      </div>
      <Grid ref={ref} container spacing={spacing} justifyContent={justify} direction={reversed ? 'row-reverse' : 'row'}>
        {Array.from({ length: count }, (_, i) => (
          <Grid key={i} size={{ xs: 6, md: 3 }}>
            <div className="demo-grid-item">{i + 1}</div>
          </Grid>
        ))}
      </Grid>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

      <div className="mtx-grid mtx-grid--item mtx-grid--xs-12 mtx-grid--md-5">
        <div className="demo-grid-item">mtx-grid--xs-12 mtx-grid--md-5</div>
      </div>
    </div>
  );
}

Props#

spacingGridResponsive<GridSpacing>—Row and column gap × 8px (containers only).

GridSize is 1–12, true / 'grow' or 'auto'. GridSpacing is 0–12, 0.5, 1.5 or 2.5. GridResponsive<T> is T, { xs?, sm?, md?, lg?, xl? } or an array from xs. Any other prop is forwarded to the root element. The helpers normalizeGridSize() and normalizeGridSpacing() are exported too.

Accessibility#

  • The grid is purely visual: it adds no roles and doesn’t change semantics. Use meaningful elements (component="main", "section", "form") for the blocks you lay out.
  • Reading and tab order follow the JSX, not the visual position. With direction="row-reverse" or column-reverse the visual order is reversed but the keyboard order isn’t: only use them when the order doesn’t matter.
  • Check that the content remains readable at a width of 320px (WCAG 1.4.10): always set xs so the columns stack on mobile.
