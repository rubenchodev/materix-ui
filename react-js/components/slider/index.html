Slider

Lets users pick a value or a range by dragging along a track, built on accessible native range inputs.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Slider } from '@rubenchodev/materix-react';

Slider lets the user select a value (or a range) from a continuous or stepped scale: volume, brightness, price filters, temperatures. As in MUI, every thumb is backed by a visually hidden native <input type="range">, so the keyboard, screen readers and form submission work without extra code. For an exact number the user must type, use a text field with type="number"; for a few discrete options, use Radio buttons.

import '@rubenchodev/materix-ui/base.css';
import { Slider } from '@rubenchodev/materix-react';

<Slider aria-label="Volume" name="volume" defaultValue={30} />

Basic usage#

One element is enough: the component renders the rail, the track, the thumb with its native input and the value label. Name it with aria-label (or aria-labelledby).

Basic usage open_in_new
import { Slider } from '@rubenchodev/materix-react/components/slider';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <Slider aria-label="Volume" name="volume" defaultValue={30} />
    </div>
  );
}

Value label#

The value label is a Material Design 2 teardrop balloon. valueLabelDisplay is off (default), auto (on hover, focus and drag) or on (always visible). valueLabelFormat accepts a template with {value} (the localized number, also used as aria-valuetext) or a function (value, index) => ReactNode; getAriaValueText sets a different spoken text.

Marks#

Range slider#

An array value (defaultValue={[20, 60]}) or range creates two thumbs, each with its own native input named {name}-start and {name}-end and labelled “Minimum” / “Maximum” (prefixed with aria-label or the aria-labelledby text). When the thumbs cross they swap, as in MUI; disableSwap blocks them and minDistance enforces a minimum gap.

Real-world examples#

A controlled price filter that updates a summary while dragging and submits both native inputs.

Real-world examples open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Slider } from '@rubenchodev/materix-react/components/slider';
import type { SliderValue } from '@rubenchodev/materix-react/components/slider';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [price, setPrice] = useState<SliderValue>([200, 700]);
  const [status, setStatus] = useState('');
  const [low, high] = price as number[];

  const submit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const data = new FormData(event.currentTarget);
    setStatus(`Applied: price-start=${data.get('price-start')}, price-end=${data.get('price-end')}`);
  };

  return (
    <form className="demo-stack demo-wide" aria-label="Product filter" onSubmit={submit}>
      <Typography variant="subtitle2" component="span" id="slider-filter-label">
        Price (USD)
      </Typography>
      <Slider
        name="price"
        min={0}
        max={1000}
        step={10}
        value={price}
        minDistance={50}
        valueLabelDisplay="auto"
        valueLabelFormat="${value}"
        aria-labelledby="slider-filter-label"
        onChange={(_, value) => setPrice(value)}
      />
      <Stack direction="row" spacing={2} alignItems="center">
        <Typography variant="body2" component="span" aria-live="polite">
          ${low} – ${high}
        </Typography>
        <Button variant="contained" type="submit">
          Apply filter
        </Button>
      </Stack>
      {status ? (
        <Typography variant="body2" color="text-secondary">
          {status}
        </Typography>
      ) : null}
    </form>
  );
}

Controlled usage#

With value + onChange the parent owns the state. onChange fires while dragging or with the keyboard and onChangeCommitted when the pointer is released (or after a keyboard change). The vanilla setters (value, max, disable()) become prop changes and focus() uses inputRef.

Controlled usage open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Slider } from '@rubenchodev/materix-react/components/slider';
import type { SliderValue } from '@rubenchodev/materix-react/components/slider';

export default function Demo() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [value, setValue] = useState<SliderValue>(40);
  const [max, setMax] = useState(100);
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ['value = 75', () => setValue(75)],
    ['max = 200', () => setMax(200)],
    ['max = 100', () => setMax(100)],
    ['disabled = true', () => setDisabled(true)],
    ['disabled = false', () => setDisabled(false)],
    ['focus()', () => inputRef.current?.focus()],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-group demo-wide">
        <span className="demo-label">Controlled slider</span>
        <Slider
          aria-label="Controlled slider"
          inputRef={inputRef}
          value={value}
          max={max}
          disabled={disabled}
          valueLabelDisplay="auto"
          onChange={(_, next) => {
            setValue(next);
            write(`onChange → ${String(next)}`);
          }}
          onChangeCommitted={(_, next) => write(`onChangeCommitted → ${String(next)}`)}
        />
        <span className="demo-status">
          value: {String(value)} · max: {max} · disabled: {String(disabled)}
        </span>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          {actions.map(([label, run]) => (
            <Button
              key={label}
              variant="outlined"
              size="small"
              onClick={() => {
                run();
                write(label);
              }}
            >
              {label}
            </Button>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

Accessibility#

  • Each thumb is a native <input type="range">: the browser exposes role="slider", aria-valuemin, aria-valuemax and aria-valuenow. With valueLabelFormat or getAriaValueText the component also sets aria-valuetext (“21 °C”).
  • In range mode each thumb gets a translated name: “Price: Minimum” / “Price: Maximum” (“Precio: Mínimo” / “Precio: Máximo” in Spanish). The prefix taken from the aria-labelledby element is read once (on mount or when aria-labelledby changes); if that text changes later, pass aria-label or getAriaLabel instead.
  • Vertical sliders set aria-orientation="vertical". The value label and marks are decorative (aria-hidden).
  • The focus indicator is the 8px halo around the thumb; animations are disabled with prefers-reduced-motion.
KeyAction
TabMoves focus to the thumb (each thumb of a range is a tab stop).
→ / ↑Increases by one step (in RTL, ← increases).
