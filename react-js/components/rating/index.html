Rating

Star rating to review a product or display an average score, accessible through native radios and the keyboard.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Rating } from '@rubenchodev/materix-react';

Rating lets the user pick a score from 1 to N icons (stars by default) or displays an average in read-only mode. As in MUI, it is backed by hidden native radios with labels (“3 Stars”), so it works with the keyboard, screen readers and forms without extra code. For a long numeric scale use a Slider or a Native Select.

import '@rubenchodev/materix-ui/base.css';
import { Rating } from '@rubenchodev/materix-react';

<Rating defaultValue={3} name="product-score" aria-label="Product rating" />

Basic usage#

A single <Rating /> renders five stars. defaultValue sets the initial value and name the radios’ name (submitted with the form; generated when omitted). Clicking the current value clears it (null).

Basic usage open_in_new
import { Rating } from '@rubenchodev/materix-react/components/rating';

export const description = {
  en: "A single `<Rating />` renders five stars. `defaultValue` sets the initial value and `name` the radios' `name` (submitted with the form). Clicking the current value clears it.",
  es: "Un único `<Rating />` genera cinco estrellas. `defaultValue` fija el valor inicial y `name` el `name` de los radios (se envía con el formulario). Un clic sobre el valor actual lo borra.",
};

export default function Demo() {
  return <Rating defaultValue={3} name="product-score" aria-label="Product rating" />;
}

Precision#

precision={0.5} allows half stars: each star contains two radios and its left half picks the x.5 value. Other fractions of 1 such as 0.25 also work; values are rounded to the precision.

Sizes#

MUI sizes through size: small 18px, medium 24px (default) and large 30px.

info

Icons and size

The built-in icons (star, star_border, star_outline, favorite, favorite_border, thumb_up, thumb_up_off_alt, circle, radio_button_unchecked) are drawn as SVG, which scales without losing sharpness. Any other name uses the Material Icons glyph at its native 24px in every size: its font-size is never forced (Materix iconography rule). A custom SVG passed as a node scales with --mtx-rating-icon-size.

icon (filled) and emptyIcon (empty) accept a Material Icons name or any React node (for example your own <svg>). If you only set icon, the empty state uses the same icon in gray. Customize the color with --mtx-rating-color.

Hover feedback#

onChangeActive(event, value) reports the value under the pointer or the focused radio (null on leave) so you can show a descriptive label, like MUI’s hover feedback demo. getLabelText customizes each radio’s accessible label.

Hover feedback open_in_new
import { useState } from 'react';
import { Rating } from '@rubenchodev/materix-react/components/rating';

export const description = {
  en: "`onChangeActive` reports the value under the pointer or the focused radio (`null` on leave) to show a descriptive text, like MUI's hover feedback example. `getLabelText` adds it to each radio label.",
  es: "`onChangeActive` informa del valor bajo el cursor o del radio enfocado (`null` al salir) para mostrar un texto descriptivo, como el ejemplo hover feedback de MUI. `getLabelText` lo añade a la etiqueta de cada radio.",
};

const LABELS: Record<number, string> = {
  0.5: 'Useless',
  1: 'Useless+',
  1.5: 'Poor',
  2: 'Poor+',
  2.5: 'Ok',
  3: 'Ok+',
  3.5: 'Good',
  4: 'Good+',
  4.5: 'Excellent',
  5: 'Excellent+',
};

export default function Demo() {
  const [value, setValue] = useState<number | null>(2);
  const [active, setActive] = useState<number | null>(null);
  const shown = active ?? value;
  return (
    <div className="demo-row">
      <Rating
        value={value}
        precision={0.5}
        aria-label="Quality"
        getLabelText={(n) => `${n} Star${n !== 1 ? 's' : ''}, ${LABELS[n]}`}
        onChange={(_, next) => setValue(next)}
        onChangeActive={(_, next) => setActive(next)}
      />
      <span className="demo-status">{shown !== null ? LABELS[shown] : 'No rating'}</span>
    </div>
  );
}

import { useState } from 'react';
import type { FormEvent } from 'react';
import { Rating } from '@rubenchodev/materix-react/components/rating';

import { Typography } from '@rubenchodev/materix-react/components/typography';

export const description = {
  en: "A product card with the read-only average and a review form that submits the value like any other radio.",
  es: "Una tarjeta de producto con la media en solo lectura y un formulario de reseña que envía el valor como cualquier otro radio.",

export default function Demo() {
  const [status, setStatus] = useState('');

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const score = new FormData(event.currentTarget).get('review-score');

  return (
    <div className="demo-grid-2">
      <Card elevation={1}>
        <CardContent>
          <Typography variant="h6" component="h3">Wireless headphones</Typography>
          <div className="demo-row">
            <Rating value={4.5} precision={0.5} size="small" readOnly />
            <Typography variant="body2" color="text-secondary">4.5 · 1,284 reviews</Typography>
          </div>
        </CardContent>
      </Card>
      <form className="demo-stack" aria-label="Write a review" onSubmit={handleSubmit}>
        <Typography variant="subtitle2" component="span" id="rating-review-label">Your rating</Typography>
        <Rating name="review-score" aria-labelledby="rating-review-label" />

Controlled usage#

With value + onChange the parent owns the value; the vanilla instance members become state changes (rating.value = 5 → setValue(5), disable() → disabled).

Controlled usage open_in_new
import { useRef, useState } from 'react';
import { Rating } from '@rubenchodev/materix-react/components/rating';
import { Button } from '@rubenchodev/materix-react/components/button';

export const description = {
  en: "With `value` + `onChange` the parent owns the value: the vanilla `value = …`, `disable()`/`enable()` and `focus()` become state changes. The log shows `onChange` and `onChangeActive`.",
  es: "Con `value` + `onChange` el padre es dueño del valor: `value = …`, `disable()`/`enable()` y `focus()` de vanilla pasan a ser cambios de estado. El registro muestra `onChange` y `onChangeActive`.",
};

export default function Demo() {
  const ref = useRef<HTMLSpanElement>(null);
  const [value, setValue] = useState<number | null>(3);
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const focus = () => {
    const root = ref.current;
    const target = root?.querySelector<HTMLInputElement>('input:checked:not([value=""])') ?? root?.querySelector('input');
    target?.focus();
  };

  const actions: Array<[string, () => void]> = [
    ['value = 5', () => setValue(5)],
    ['value = null', () => setValue(null)],
    ['disabled = true', () => setDisabled(true)],
    ['disabled = false', () => setDisabled(false)],
    ['focus()', focus],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Rating
          ref={ref}
          value={value}
          disabled={disabled}
          aria-label="Controlled rating"
          onChange={(_, next) => {
            setValue(next);
            write(`onChange → ${String(next)}`);
          }}
          onChangeActive={(_, next) => write(`onChangeActive → ${String(next)}`)}
        />
        <span className="demo-status">value: {String(value)} · disabled: {String(disabled)}</span>
      </div>
      <div className="demo-row">
        {actions.map(([label, run]) => (
          <Button
            key={label}
            variant="outlined"
            size="small"
            onClick={() => {
              run();
              write(label);
            }}
          >
            {label}
          </Button>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accessibility#

  • Interactive: native radios sharing a name, each with a translated label (“1 Star”, “3 Stars”; “3 estrellas” in Spanish) plus an “Empty” radio. The browser handles mutual exclusion and the arrow keys.
  • When the component has a name (label, aria-label or aria-labelledby) it gets role="radiogroup".
  • Read-only: role="img" with a translated aria-label (“Rated 4 out of 5” / “Valoración: 4 de 5”); the icons are decorative.
  • Keyboard focus is shown as a ring around the focused icon.
