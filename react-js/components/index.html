Components

Every Materix UI React component grouped by purpose. Each one is a typed React component that follows the Material UI design.

Layout

  • grid_view Grid A 12-column flexbox grid with five breakpoints (xs–xl), gap-based spacing in multiples of 8px (also per breakpoint) and alignment, for responsive layouts.
  • format_paint CSS Baseline Materix global baseline: Roboto typography, theme background and text colors, box-sizing, visible focus and a light or dark color-scheme.
  • crop_free Container Centers page content with a per-breakpoint max width and responsive side gutters (16px on mobile, 24px from 600px).
  • view_agenda Stack Stacks elements in one direction (column or row) with even spacing, alignment, wrapping, dividers and per-breakpoint changes.

Inputs

  • smart_button Button Action button with text, outlined and contained variants, three canonical heights (48/40/32px), palette colors, icons and loading state.
  • view_week Button Group Groups related buttons into a single piece with joined borders, separators and inherited variant, size and color.
  • ads_click Icon Button Circular icon-only button for compact actions in toolbars, cards and table rows. Always with an aria-label.
  • add_circle Fab Floating action button for a screen's primary action: circular (56/48/40px) or extended with text (48px).
  • check_box Checkbox A box for selecting one or more options from a list or confirming a condition; supports an indeterminate state.
  • info Form Helper Text Helper and error text below a form control, plus FormControl and FormLabel to share error, disabled and required state with the controls inside.
  • radio_button_checked Radio Radio button to choose exactly one option from a visible group; RadioGroup reads and sets the group's value.
  • star_half Rating Star rating to review a product or display an average score, accessible through native radios and the keyboard.
  • tune Slider Lets users pick a value or a range by dragging along a track, built on accessible native range inputs.
  • toggle_on Switch Toggle that turns an option on or off instantly, like a settings preference; uses role=switch on a native checkbox.
  • edit Text Field Text field with a floating label, MUI variants, icons, counters, input masks and validation.
  • list Select Select with a custom MUI-style menu: search, multiple selection, bulk actions, groups, limits and icons or images in the options.
  • arrow_drop_down_circle Native Select The browser's <select> with MUI styling: lightweight, accessible by default and with the native touch picker on mobile.
  • manage_search Autocomplete Text field with filterable suggestions: single or multiple selection with chips, free values, groups and asynchronous loading.
  • event Date Time Picker Date, time, date-time and range pickers with a calendar, MD2 radial clock, popover, modal or static mode, limits and formats.
  • toggle_off Toggle Button Toggle buttons group related options with exclusive or multiple selection; on their own they work as an on/off switch for a single action.

Data display

  • account_circle Avatar Represents a person or entity with an image, initials or an icon; AvatarGroup stacks several and summarizes the overflow.
  • notifications Badge Displays a number or a status dot at the corner of an icon, avatar or button to flag new or pending items.
  • label Chip A compact element that represents a tag, a filter, an input or an action; it can have an icon, an avatar and a delete button.
  • horizontal_rule Divider A thin line that separates and groups content in lists, menus and layouts, horizontally or vertically and optionally with text.
  • format_list_bulleted List Continuous vertical list of text, icons or avatars, with static or interactive items, subheaders, density and selection.
  • table_chart Table Displays data sets in rows and columns on a semantic HTML table, with density, sticky header, sorting, selection and pagination.
  • text_fields Typography Applies the MUI type scale (h1 to overline) to any element, separating HTML semantics from visual style.
  • info Tooltip Short informative label shown on hover, keyboard focus or long press. Wrap any element with <Tooltip title>.

Feedback

  • warning Alert A short, prominent message that reports the outcome of an action or the state of the system without interrupting the user.
  • gradient Backdrop Full-screen layer that dims the page and centers an indicator while an operation runs; it does not replace a dialog.
  • open_in_browser Dialog A modal window that interrupts the task to ask for a decision or show critical information, with trapped focus and Escape to close.
  • donut_large Progress Circular and linear indicators that show an operation is in progress or how much is left before it finishes.
  • view_day Skeleton Content-shaped placeholders shown while data loads, with a pulse or wave animation.
  • chat_bubble Snackbar Brief, temporary notification at an edge of the screen that confirms an action and can offer to undo it.

Surfaces

  • expand_circle_down Accordion Panels that show and hide related sections of content behind a clickable summary, ideal for FAQs and grouped settings.
  • view_headline App Bar Top bar with the title, navigation and primary actions of the current screen.
  • web Card A surface that groups content and actions about a single subject: header, image, text and buttons.
  • layers Paper The base Material Design surface, with background, border radius and shadow, that groups content and expresses elevation.
  • picture_in_picture Popover Floating Paper with arbitrary content anchored to a trigger. Closes on click away or Escape and returns focus to the trigger.

Navigation

  • more_horiz Breadcrumbs Hierarchical navigation trail that shows where the user is and lets them jump back to any parent level.
  • menu_open Drawer Side panel for navigation or supplementary content: temporary, persistent, permanent or responsive, with a generated header and footer and an app shell pattern.
  • link Link MUI-styled text link on a native <a>: palette colors and three underline modes, without losing semantics.
  • more_vert Menu Temporary list of options anchored to a trigger: icons, shortcuts, dividers, selection, checkable items, submenus, context menu and full keyboard navigation.
  • last_page Pagination Lets users pick a page within a large set of results, with ellipsis, first/last buttons and a link mode for SSR.
  • tab Tabs Tabs to switch between views at the same level, with an animated indicator, icons, vertical orientation and full keyboard navigation.
  • touch_app Speed Dial Floating action button that reveals three to six related, labeled actions in four directions, on click or on hover.
  • linear_scale Stepper Shows progress through a sequence of numbered steps, horizontal or vertical, linear or with clickable steps, plus its compact mobile version.

Common conventions#

All components share the same rules, so what you learn in one applies to the rest:

ConventionDetails
ImportNamed exports from @rubenchodev/materix-react (or @rubenchodev/materix-react/components/{name} to import just one).
StylesImport @rubenchodev/materix-ui/base.css once; each component brings its own CSS.
PropsMUI-like names: variant, color, size, disabled, startIcon… fully typed in TypeScript.
Native attributesExtra props (id, aria-*, data-*, event handlers) are forwarded to the root element; className is merged.
Refsref points to the root DOM element.
ThemeLight and dark through --mtx-* design tokens and data-mtx-theme (see Theming).
AccessibilityNative semantics, keyboard, visible focus and ARIA managed by the component.
