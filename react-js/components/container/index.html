Container

Centers page content with a per-breakpoint max width and responsive side gutters (16px on mobile, 24px from 600px).

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Container } from '@rubenchodev/materix-react';

Container is the most basic layout block: it centers its content horizontally, caps it at a max width and adds side padding (gutters) that grows with the screen, just like MUI’s Container. Use it to wrap <main>, landing page sections or a toolbar. To split columns inside it use Grid; to stack blocks, Stack.

import { Container } from '@rubenchodev/materix-react';
// or only this component
import { Container } from '@rubenchodev/materix-react/components/container';

Basic usage#

A single <Container>. Without maxWidth the cap is lg (1200px), as in MUI. The shaded area is the container; the inner strip, its gutters.

Basic usage open_in_new
import './demo.css';
import { Container } from '@rubenchodev/materix-react/components/container';

export default function Demo() {
  return (
    <div className="demo-container-frame">
      <Container>
        <div className="demo-container-box">Centered content · max. 1200px</div>
      </Container>
    </div>
  );
}

Max width#

maxWidth sets the cap: xs 444px, sm 600px, md 900px, lg 1200px, xl 1536px or false to take the full width.

Max width open_in_new
import './demo.css';
import { Container, type ContainerMaxWidth } from '@rubenchodev/materix-react/components/container';

const options: Array<{ value: ContainerMaxWidth; label: string }> = [
  { value: 'xs', label: 'maxWidth="xs" · 444px' },
  { value: 'sm', label: 'maxWidth="sm" · 600px' },
  { value: 'md', label: 'maxWidth="md" · 900px' },
  { value: 'lg', label: 'maxWidth="lg" · 1200px (default)' },
  { value: false, label: 'maxWidth={false} · fluid' },
];

export default function Demo() {
  return (
    <div className="demo-stack">
      {options.map(({ value, label }) => (
        <div className="demo-group" key={String(value)}>
          <span className="demo-label">{label}</span>
          <div className="demo-container-frame">
            <Container maxWidth={value}>
              <div className="demo-container-box">{String(value)}</div>
            </Container>
          </div>
        </div>
      ))}
    </div>
  );
}

Fixed#

fixed makes the max width jump to the minimum of each breakpoint (600, 900, 1200, 1536px) instead of growing fluidly. Useful when the design targets specific widths. Resize the window to see it.

Fixed open_in_new
import './demo.css';
import { Container } from '@rubenchodev/materix-react/components/container';

export default function Demo() {
  return (
    <div className="demo-container-frame">
      <Container fixed>
        <div className="demo-container-box">fixed</div>
      </Container>
    </div>
  );
}

Gutters#

By default the container adds 16px of side padding on mobile and 24px from 600px. disableGutters removes them, for example to make an image or a table touch the edges.

Gutters open_in_new
import './demo.css';
import { Container } from '@rubenchodev/materix-react/components/container';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">With gutters</span>
        <div className="demo-container-frame">
          <Container maxWidth="sm">
            <div className="demo-container-box">16px / 24px on each side</div>
          </Container>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">disableGutters</span>
        <div className="demo-container-frame">
          <Container maxWidth="sm" disableGutters>
            <div className="demo-container-box">No side padding</div>
          </Container>
        </div>
      </div>
    </div>
  );
}

Grid#

Container bounds the width and Grid splits the columns inside it. No wrapper with overflow is needed: Grid spaces items with gap.

Grid open_in_new
import './demo.css';
import { Container } from '@rubenchodev/materix-react/components/container';
import { Grid } from '@rubenchodev/materix-react/components/grid';

export default function Demo() {
  return (
    <div className="demo-container-frame">
      <Container maxWidth="md">
        <Grid container spacing={2}>
          <Grid size={{ xs: 12, sm: 6, md: 4 }}>
            <div className="demo-container-box">xs=12 sm=6 md=4</div>
          </Grid>
          <Grid size={{ xs: 12, sm: 6, md: 4 }}>
            <div className="demo-container-box">xs=12 sm=6 md=4</div>
          </Grid>
          <Grid size={{ xs: 12, md: 4 }}>
            <div className="demo-container-box">xs=12 md=4</div>
          </Grid>
        </Grid>
      </Container>
    </div>
  );
}

Real-world examples#

An article page: a full-width header and a reading body capped at sm to keep a comfortable line length. component renders the right semantic element (<main>, <article>, <section>).

Real-world use cases open_in_new
import '@rubenchodev/materix-ui/utilities.css';
import './demo.css';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Container } from '@rubenchodev/materix-react/components/container';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-container-frame">
      <div className="mtx-bg-primary mtx-py-4">
        <Container maxWidth="md">
          <Typography variant="h5" component="h3" gutterBottom color="inherit">
            What&apos;s new in version 0.1
          </Typography>
          <Typography variant="body2" color="inherit">
            Layout utilities, Container and Stack.
          </Typography>
        </Container>
      </div>
      <Container component="article" maxWidth="sm" className="mtx-py-3">
        <Typography variant="body1" className="mtx-mb-2">
          Materix ships a mobile-first utility system for building layouts without writing your own CSS. Container
          centers the content and Stack stacks blocks with even spacing.
        </Typography>
        <Stack direction="row" spacing={1}>
          <Button variant="contained">Read more</Button>
          <Button variant="text">Share</Button>
        </Stack>
      </Container>
    </div>
  );
}

Controlled props#

In vanilla, setMaxWidth(), setGutters() and setFixed() swap classes on an existing element. In React the props are the API: change them from state and the component re-renders with the matching classes.

Controlled props open_in_new
import { useEffect, useRef, useState } from 'react';
import './demo.css';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Container, type ContainerMaxWidth } from '@rubenchodev/materix-react/components/container';

const sizes: ContainerMaxWidth[] = ['xs', 'sm', 'md', false];

export default function Demo() {
  const [maxWidth, setMaxWidth] = useState<ContainerMaxWidth>('sm');
  const [gutters, setGutters] = useState(true);
  const [fixed, setFixed] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const classes = ref.current?.className ?? '';
    setLog((lines) => [...lines.slice(-5), `maxWidth=${String(maxWidth)} gutters=${gutters} fixed=${fixed} → ${classes}`]);
  }, [maxWidth, gutters, fixed]);

  return (
    <div className="demo-stack">
      <div className="demo-row">
        {sizes.map((value) => (
          <Button
            key={String(value)}
            variant={maxWidth === value ? 'contained' : 'outlined'}
            aria-pressed={maxWidth === value}
            onClick={() => setMaxWidth(value)}
          >
            {String(value)}
          </Button>
        ))}
        <Button variant="outlined" aria-pressed={!gutters} onClick={() => setGutters((g) => !g)}>
          Toggle gutters
        </Button>
        <Button variant="outlined" aria-pressed={fixed} onClick={() => setFixed((f) => !f)}>
          Toggle fixed
        </Button>
      </div>
      <div className="demo-container-frame">
        <Container ref={ref} maxWidth={maxWidth} disableGutters={!gutters} fixed={fixed}>
          <div className="demo-container-box">Container controlled by React state</div>
        </Container>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Full BEM syntax#

The classes work without the component (for example, in server-rendered markup).

Manual BEM usage open_in_new
import '@rubenchodev/materix-ui/components/container.css';
import './demo.css';

export default function Demo() {
  return (
    <div className="demo-container-frame">
      <div className="mtx-container mtx-container--sm mtx-container--disable-gutters">
        <div className="demo-container-box">mtx-container mtx-container--sm mtx-container--disable-gutters</div>
      </div>
    </div>
  );
}

API reference#

Props#

PropTypeDefaultDescription
maxWidth'xs' | 'sm' | 'md' | 'lg' | 'xl' | false— (lg in CSS)Max width cap. false takes the full width (mtx-container--fluid).
fixedbooleanfalseThe max width jumps to the minimum of each breakpoint.
disableGuttersbooleanfalseRemoves the 16px / 24px side padding.
componentElementType'div'Root element or component (main, section, article…).
classNamestring—Merged with the component classes.
refRef<HTMLElement>—Points to the root element.

Any other prop (id, aria-*, data-*, events, style) is forwarded to the root element.

Equivalence with vanilla#

VanillaReact
data-mtx="container"<Container>
data-max-width="md"maxWidth="md"
data-max-width="false"maxWidth={false}
data-fixedfixed
data-disable-guttersdisableGutters
setMaxWidth(v), setFixed(b), setGutters(b)Change the matching prop.

CSS classes#

ClassDescription
mtx-containerBase block: centered, width: 100%, gutters.
mtx-container--{xs|sm|md|lg|xl}Max width cap.
mtx-container--fluidNo cap (maxWidth={false}).
mtx-container--fixedWidth fixed per breakpoint.
mtx-container--disable-guttersNo side padding.

Callbacks#

Container has no events of its own.

CSS variables#

VariableUsage
--mtx-container-maxCurrent width cap (set by the mtx-container--* modifiers).
--mtx-container-fixedFixed width of the current breakpoint.
--mtx-spacing-2, --mtx-spacing-3Gutters on mobile and from 600px.

Accessibility#

  • Container is purely visual: it adds no roles. Use component to render the right semantic element (<main>, <header>, <section>, <footer>) instead of adding an extra <div>.
  • Gutters keep text away from the screen edges on mobile; don’t disable them on text blocks.
  • Capping the reading width (sm or md) improves legibility: 60–80 characters per line.
