Switch

Toggle that turns an option on or off instantly, like a settings preference; uses role=switch on a native checkbox.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Switch } from '@rubenchodev/materix-react';

Switch turns a single option on or off with immediate effect: Wi-Fi, dark mode, notifications. It renders a native <input type="checkbox" role="switch"> inside a <label class="mtx-switch">, so it is announced as “on / off”. If the change only applies when a form is submitted, or there are several options to confirm, use a Checkbox.

lightbulb

Switch or Checkbox?

Ask yourself whether the user expects to see the effect without pressing “Save”. If the answer is yes, it is a Switch (“Dark mode”). If the value is submitted with a form (“I accept the terms”, “Subscribe to the newsletter”), it is a Checkbox.

import '@rubenchodev/materix-ui/base.css';
import { Switch } from '@rubenchodev/materix-react';

<Switch label="Wi-Fi" defaultChecked />

One element with label is enough: the component renders the <label>, the native input, the track with its thumb and the text.

Real-world examples#

A preferences panel where each switch applies its change immediately.

Use cases open_in_new
import { useEffect, useState } from 'react';
import { Switch } from '@rubenchodev/materix-react/components/switch';

export const description = {
  en: "A settings panel where each switch applies the change immediately, with no \"Save\" button. Turning on \"Dark mode\" really changes this page's theme.",
  es: "Un panel de ajustes donde cada interruptor aplica el cambio al instante, sin botón «Guardar». Activar «Modo oscuro» cambia de verdad el tema de esta página.",
};

/** Lee el tema activo de la página (`<html data-mtx-theme>`). */
const isDarkPage = () => typeof document !== 'undefined' && document.documentElement.getAttribute('data-mtx-theme') === 'dark';

export default function Demo() {
  const [dark, setDark] = useState(false);

  // Sincroniza el interruptor con el tema real de la página (también si se cambia desde la barra superior).
  useEffect(() => {
    const root = document.documentElement;
    setDark(isDarkPage());
    const observer = new MutationObserver(() => setDark(isDarkPage()));
    observer.observe(root, { attributes: true, attributeFilter: ['data-mtx-theme'] });
    return () => observer.disconnect();
  }, []);

  const handleTheme = (next: boolean) => {
    const theme = next ? 'dark' : 'light';
    const root = document.documentElement;
    root.setAttribute('data-mtx-theme', theme);
    root.style.colorScheme = theme;
    document.dispatchEvent(new CustomEvent('demo:themechange', { detail: { theme } }));
  };

  return (
    <div className="demo-panel demo-fixed-width">
      <span className="demo-label">Preferences</span>
      <Switch label="Dark mode" checked={dark} onChange={(_, next) => handleTheme(next)} />
      <Switch label="Autoplay videos" defaultChecked />
      <Switch label="Show link previews" defaultChecked />
    </div>
  );
}

Controlled usage#

With checked + onChange the parent owns the state; toggle(), disable() and setError() from vanilla become state changes and focus() uses inputRef.

Controlled usage open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Switch } from '@rubenchodev/materix-react/components/switch';

export const description = {
  en: "With checked + onChange the parent owns the state: toggle(), disable() and setError() from vanilla become state changes and focus() uses inputRef. User changes call onChange and are logged below.",
  es: "Con checked + onChange el estado lo gestiona el padre: toggle(), disable() y setError() de vanilla pasan a ser cambios de estado y focus() usa inputRef. Los cambios del usuario llaman a onChange y se registran abajo.",
};

export default function Demo() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [checked, setChecked] = useState(false);
  const [disabled, setDisabled] = useState(false);
  const [error, setError] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ['toggle', () => setChecked((value) => !value)],
    ['checked = true', () => setChecked(true)],
    ['checked = false', () => setChecked(false)],
    ['disabled = true', () => setDisabled(true)],
    ['disabled = false', () => setDisabled(false)],
    ['focus()', () => inputRef.current?.focus()],
    ['error = true', () => setError(true)],
    ['error = false', () => setError(false)],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Controlled switch</span>
        <div className="demo-row">
          <Switch
            label="Controlled switch"
            inputRef={inputRef}
            checked={checked}
            disabled={disabled}
            error={error}
            helperText={error ? 'Turn this option on.' : undefined}
            onChange={(_, next) => {
              setChecked(next);
              write(`onChange (user) → checked: ${next}`);
            }}
          />
          <span className="demo-status">
            checked: {String(checked)} · disabled: {String(disabled)}
          </span>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          {actions.map(([label, run]) => (
            <Button
              key={label}
              variant="outlined"
              size="small"
              onClick={() => {
                run();
                write(label);
              }}
            >
              {label}
            </Button>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

API reference#

Props#

PropTypeDefaultDescription
checkedboolean—On state (controlled).
defaultCheckedbooleanfalseInitial state (uncontrolled).
onChange(event, checked: boolean) => void—Fired when the user toggles the switch.
labelReactNode—Visible text (.mtx-switch__label). children works too.
size'medium' | 'small''medium'Track size.
color'primary' | 'secondary' | 'error' | 'warning' | 'info' | 'success''primary'Color when on.
disabledbooleanfrom FormControlDisables the input.
readOnlybooleanfalseFocusable but not editable.
requiredbooleanfrom FormControlNative required.
errorbooleanfrom FormControlaria-invalid and error colors.
helperTextReactNode—Helper or error text below the switch.
disableRipplebooleanfalseDisables the ripple.
id, name, value, form, autoFocus—Forwarded to the <input>.
aria-label, aria-labelledby, aria-describedby, onFocus, onBlur—Forwarded to the <input>.
inputRefRef<HTMLInputElement>—Ref to the native input.
inputPropsInputHTMLAttributes—Extra attributes for the native input.
refRef<HTMLLabelElement>—Ref to the root <label>.

className, style and any other attribute go to the root <label>, which is always rendered inside a stable .mtx-form-control so toggling helperText never remounts the input.

Accessibility#

  • The input keeps its native semantics with role="switch": screen readers announce “switch, on/off” from the native checked state (no redundant aria-checked). Uncontrolled switches are native (defaultChecked), so form.reset() restores them.
  • The helper text stays outside the <label> and is linked with aria-describedby; error adds aria-invalid="true".
  • The whole row is clickable. Without label, use aria-label or aria-labelledby.
  • readOnly keeps the control focusable and readable without faking a disabled state.
KeyAction
Tab / Shift+TabMoves focus to the next / previous switch.
SpaceTurns the switch on or off (unless readOnly or disabled).
