Autocomplete

Text field with filterable suggestions: single or multiple selection with chips, free values, groups and asynchronous loading.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Autocomplete } from '@rubenchodev/materix-react';

Autocomplete is a text input enhanced with a list of suggestions: the user types, the list is filtered (ignoring case and accents) and they choose with the mouse or keyboard. It follows the WAI-ARIA 1.2 combobox with listbox pattern. Use it when the list is long and searching is faster than scrolling, when values come from a server or when free values are allowed. For short lists without search, use Select or NativeSelect; for free text with no suggestions, use TextField.

import '@rubenchodev/materix-ui/base.css';
import { Autocomplete } from '@rubenchodev/materix-react';

<Autocomplete
  label="Country"
  name="country"
  options={[
    { value: 'co', label: 'Colombia' },
    { value: 'mx', label: 'Mexico' },
  ]}
/>

Basic usage#

One element with label and options is enough: the component renders the TextField (label, notched border), the clear and open buttons, the listbox in a portal and the hidden input that submits the option’s value under name. Type to filter, ignoring case and accents.

Basic usage open_in_new
import { Autocomplete } from '@rubenchodev/materix-react/components/autocomplete';
import { COUNTRIES } from './data';

export default function Demo() {
  return (
    <div className="demo-fixed-width">
      <Autocomplete label="Country" options={COUNTRIES} name="country" />
    </div>
  );
}

Options can be strings or objects { value, label, group?, disabled?, icon?, description? }, the same format as vanilla. Any other shape works with getOptionLabel (and getOptionValue for the submitted key).

Groups and disabled options#

group on each option (or groupBy) shows a sticky subheader; consecutive options with the same group are grouped, as in MUI. Disabled options (disabled or getOptionDisabled) are skipped with the keyboard and cannot be clicked. The time zone field uses its own objects with getOptionLabel, getOptionValue and groupBy.

Asynchronous loading#

Listen to onInputChange (with debounce={300} the input reason waits until the user stops typing), turn on loading, fetch the data and pass the new options. filterOptions={false} leaves filtering to the server (and disables the highlighting). The demo simulates 800 ms of latency and aborts the pending request on every new search and on unmount.

Asynchronous loading open_in_new
import { useEffect, useRef, useState } from 'react';
import { Autocomplete } from '@rubenchodev/materix-react/components/autocomplete';
import type { AutocompleteOption } from '@rubenchodev/materix-react/components/autocomplete';

const REPOS = [
  'materix-ui', 'material-ui', 'mui-x', 'vite', 'vitest', 'hugo', 'react', 'vue', 'svelte',
  'angular', 'bootstrap', 'tailwindcss', 'lit', 'preact', 'solid', 'alpine', 'htmx', 'jquery',
];

/**
 * Simula una búsqueda remota con 800 ms de latencia; se cancela con la señal.
 * @param {string} query Texto buscado.
 * @param {AbortSignal} signal Señal de cancelación.
 * @returns {Promise<AutocompleteOption[]>} Resultados.
 */
function searchRepos(query: string, signal: AbortSignal): Promise<AutocompleteOption[]> {
  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => {
      const q = query.toLowerCase();
      resolve(
        REPOS.filter((name) => name.includes(q)).map((name, i) => ({
          value: name,
          label: name,
          description: `${1200 - i * 57} stars`,
        })),
      );
    }, 800);
    signal.addEventListener('abort', () => {
      clearTimeout(timer);
      reject(new DOMException('Aborted', 'AbortError'));
    });
  });
}

export default function Demo() {
  const [options, setOptions] = useState<AutocompleteOption[]>([]);
  const [loading, setLoading] = useState(false);
  const controller = useRef<AbortController | null>(null);

  // Cancela la petición pendiente al desmontar.
  useEffect(() => () => controller.current?.abort(), []);

  const search = (query: string) => {
    controller.current?.abort();
    const text = query.trim();
    if (!text) {
      setOptions([]);
      setLoading(false);
      return;
    }
    const current = new AbortController();
    controller.current = current;
    setLoading(true);
    searchRepos(text, current.signal)
      .then((results) => {
        setOptions(results);
        setLoading(false);
      })
      .catch(() => undefined);
  };

  return (
    <div className="demo-fixed-width">
      <Autocomplete
        label="Repository"
        name="repo"
        startIcon="search"
        debounce={300}
        filterOptions={false}
        options={options}
        loading={loading}
        onInputChange={(_event, value, reason) => {
          if (reason === 'input') search(value);
        }}
      />
    </div>
  );
}
const [options, setOptions] = useState([]);
const [loading, setLoading] = useState(false);

<Autocomplete
  label="Repository"
  debounce={300}
  filterOptions={false}
  options={options}
  loading={loading}
  onInputChange={async (_event, text, reason) => {
    if (reason !== 'input') return;
    setLoading(true);
    setOptions(await searchRepos(text)); // [{ value, label, description }]
    setLoading(false);
  }}
/>

Forms#

name goes to hidden inputs: one with the value in single selection; one per value in multiple selection (like <select multiple>) or a single field with valueFormat="csv" (and separator). required uses native validation (a typed text that is not an option is invalid unless freeSolo); the form’s reset restores the initial value.

Form open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Autocomplete } from '@rubenchodev/materix-react/components/autocomplete';
import { Button } from '@rubenchodev/materix-react/components/button';
import { COUNTRIES } from './data';

const LANGUAGES = [
  { value: 'en', label: 'English' },
  { value: 'es', label: 'Spanish' },
  { value: 'pt', label: 'Portuguese' },
  { value: 'fr', label: 'French' },
];

export default function Demo() {
  const [log, setLog] = useState('');

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const form = event.currentTarget;
    if (!form.checkValidity()) {
      form.reportValidity();
      setLog('Invalid form');
      return;
    }
    const pairs: string[] = [];
    new FormData(form).forEach((value, key) => pairs.push(`${key}=${String(value)}`));
    setLog(`submit → ${pairs.join('&')}`);
  };

  return (
    <form className="demo-stack demo-wide" noValidate onSubmit={handleSubmit} onReset={() => setLog('reset')}>
      <Autocomplete label="Country of residence" options={COUNTRIES} name="country" required />
      <Autocomplete label="Languages" multiple name="languages" options={LANGUAGES} defaultValue={['en']} />
      <Autocomplete label="Interests (CSV)" multiple freeSolo name="interests" valueFormat="csv" options={['design', 'music', 'travel']} />
      <div className="demo-row">
        <Button variant="contained" type="submit">
          Submit
        </Button>
        <Button variant="text" type="reset">
          Reset
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log}
      </pre>
    </form>
  );
}

Controlled usage#

With value + onChange, inputValue + onInputChange and open + onOpen/onClose the parent owns the state; the vanilla instance methods become state changes (value = 'matrix', open(), clear(), setOptions(), disable()) and focus() uses inputRef. value accepts an option, an option key ('matrix') or, in freeSolo, a string; onChange returns the option.

Controlled usage open_in_new
import { useRef, useState } from 'react';
import { Autocomplete } from '@rubenchodev/materix-react/components/autocomplete';
import type { AutocompleteOption } from '@rubenchodev/materix-react/components/autocomplete';
import { Button } from '@rubenchodev/materix-react/components/button';
import { FILMS } from './data';

const OTHER_FILMS: AutocompleteOption[] = [
  { value: 'alien', label: 'Alien', description: '1979', group: 'Science fiction' },
  { value: 'blade-runner', label: 'Blade Runner', description: '1982', group: 'Science fiction' },
  { value: 'amelie', label: 'Amélie', description: '2001', group: 'Comedy' },
];

export default function Demo() {
  const [value, setValue] = useState<AutocompleteOption | string | null>(null);
  const [open, setOpen] = useState(false);
  const [options, setOptions] = useState(FILMS);
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const inputRef = useRef<HTMLInputElement>(null);

  const write = (line: string) => setLog((prev) => [...prev.slice(-7), line]);

  return (
    <div className="demo-stack">
      <div className="demo-fixed-width">
        <Autocomplete
          label="Movie"
          options={options}
          value={value}
          open={open}
          disabled={disabled}
          inputRef={inputRef}
          onChange={(_event, next, reason) => {
            setValue(next);
            const key = next && typeof next === 'object' ? next.value : next;
            write(`onChange → ${JSON.stringify({ value: key, reason })}`);
          }}
          onInputChange={(_event, inputValue, reason) => write(`onInputChange → ${JSON.stringify({ inputValue, reason })}`)}
          onOpen={(_event, reason) => {
            setOpen(true);
            write(`onOpen → ${reason}`);
          }}
          onClose={(_event, reason) => {
            setOpen(false);
            write(`onClose → ${reason}`);
          }}
        />
      </div>
      <div className="demo-row">
        <Button variant="outlined" onClick={() => setValue('matrix')}>
          value = matrix
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            inputRef.current?.focus();
            setOpen(true);
          }}
        >
          Open
        </Button>
        <Button variant="outlined" onClick={() => setValue(null)}>
          Clear
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setOptions(OTHER_FILMS);
            write('options = [...3 grouped options]');
          }}
        >
          Change options
        </Button>
        <Button variant="outlined" onClick={() => setDisabled((prev) => !prev)}>
          {disabled ? 'Enable' : 'Disable'}
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accessibility#

  • WAI-ARIA 1.2 combobox with listbox pattern: focus stays on the <input role="combobox"> with aria-autocomplete="list", aria-expanded (true when there are options visible), aria-controls (the listbox while open) and aria-activedescendant (the highlighted option).
  • The list is a role="listbox" labelled by the label (aria-labelledby, or aria-label without a label), with aria-multiselectable in multiple mode and aria-busy while loading; each option is a role="option" with aria-selected and aria-disabled. Groups use role="group" labelled by their subheader.
  • A role="status" live region announces “N results available”, “No options” or “Loading…” after filtering.
  • The clear and open/close buttons have a translated aria-label and stay out of the tab order (tabindex="-1"), as in MUI: everything can be done from the keyboard in the field.
  • aria-required, aria-readonly, aria-invalid and aria-describedby (helper text) are synchronized; required uses native validation.
  • Escape goes through the common layer stack: only the top layer closes and it does not reach a containing Dialog.
  • Chips are reachable with the arrow keys from the field (tabindex="-1", outside the tab order, as in MUI) and are deleted with Backspace/Delete.
