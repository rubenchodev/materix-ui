Icon Button

Circular icon-only button for compact actions in toolbars, cards and table rows. Always with an aria-label.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { IconButton } from '@rubenchodev/materix-react';

Icon Button triggers an action represented solely by a recognizable icon: search, close, share, open a menu. It is the right choice in toolbars, card headers and per-row actions, where space is limited. If the icon is not unambiguous, use a Button with text; if it is the primary action of the screen, use a Fab.

warning

aria-label is required

An Icon Button has no visible text: without aria-label (or aria-labelledby) screen readers would only announce “button”. Describe the action, not the icon: “Delete invoice”, not “trash can”.

import { IconButton } from '@rubenchodev/materix-react';
// or only this component:
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

Basic usage#

Pass the Material Icons name in icon. The component renders <button type="button" class="mtx-icon-button">, the 24px glyph (with aria-hidden="true") and the centered ripple.

Basic usage open_in_new
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  return (
    <div className="demo-row">
      <IconButton icon="search" aria-label="Search" />
      <IconButton icon="favorite" color="error" aria-label="Add to favorites" />
      <IconButton icon="share" color="primary" aria-label="Share" />
      <IconButton icon="delete" aria-label="Delete" />
    </div>
  );
}

Icons#

Colors#

Without color the icon uses the active action gray (--mtx-color-action-active), as in MUI. color accepts any palette color, or inherit to take the color of the surrounding text (dark or colored surfaces such as an AppBar).

Colors open_in_new
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

const colors = ['primary', 'secondary', 'success', 'error', 'warning', 'info'] as const;

export default function Demo() {
  return (
    <>
      <div className="demo-row">
        <IconButton icon="star" aria-label="Default" />
        {colors.map((color) => (
          <IconButton key={color} icon="star" color={color} aria-label={color[0].toUpperCase() + color.slice(1)} />
        ))}
      </div>
      <div className="demo-group">
        <span className="demo-label">inherit · inherits the container&apos;s color</span>
        <div className="mtx-bg-primary mtx-d-flex mtx-flex-wrap mtx-align-items-center mtx-gap-2 mtx-p-2 mtx-rounded">
          <IconButton icon="menu" color="inherit" edge="start" aria-label="Open menu" />
          <span className="mtx-flex-1">Panel</span>
          <IconButton icon="search" color="inherit" aria-label="Search" />
        </div>
      </div>
    </>
  );
}

States#

Hover shows a subtle background, keyboard focus a ring in the primary color, and a press a centered ripple. disabled sets the native attribute (on links, aria-disabled="true" and tabIndex={-1}, and the click is blocked).

Edge placement#

edge="start|end" applies a negative 12px margin so the glyph is optically aligned with the content edge, like MUI’s edge prop. Use it on the first or last item of a bar.

With badge#

Wrap the Icon Button in a Badge to show counters and include the number in the aria-label. The button does not clip its content (the ripple is clipped by an inner container), so the badge is never cut off.

With badge open_in_new
import { Badge } from '@rubenchodev/materix-react/components/badge';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  return (
    <div className="demo-row">
      <Badge badgeContent={4} color="error">
        <IconButton icon="notifications" aria-label="Notifications: 4 unread" />
      </Badge>
      <Badge badgeContent={12} color="primary">
        <IconButton icon="mail" aria-label="Mail: 12 new messages" />
      </Badge>
    </div>

}

With tooltip#

An icon alone is not always self-explanatory. Wrap the Icon Button in a Tooltip to show its name on hover, keyboard focus or long press. If the button has no aria-label, the tooltip text becomes its accessible name; if it already has one, the tooltip is linked as a description (aria-describedby).

With tooltip open_in_new
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';

export default function Demo() {
  return (
    <div className="demo-row">
      <Tooltip title="Delete">
        <IconButton icon="delete" />
      </Tooltip>
      <Tooltip title="Archive (E)">
        <IconButton icon="archive" aria-label="Archive" />
      </Tooltip>
      <Tooltip title="More options" placement="top" arrow>
        <IconButton icon="more_vert" />
      </Tooltip>
    </div>
  );
}
lightbulb

Recommended for icon-only buttons

MUI recommends wrapping every icon-only button in a Tooltip. A disabled button does not receive pointer events: wrap it in a <span> inside the Tooltip.

Programmatic usage#

The vanilla methods become props: disabled replaces disable()/enable(), and ref gives you the DOM element. Icon Button emits no events of its own: use onClick and any other native handler.

Programmatic usage open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

const icons = ['bookmark', 'push_pin', 'flag', 'label'];

export default function Demo() {
  const [disabled, setDisabled] = useState(false);
  const [extra, setExtra] = useState<string[]>([]);
  const [log, setLog] = useState<string[]>([]);
  const ref = useRef<HTMLElement>(null);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const toggle = (value: boolean) => {
    setDisabled(value);
    write(`disabled = ${value}`);
  };

  const add = () => {
    const icon = icons[extra.length % icons.length];
    setExtra((prev) => [...prev, icon]);
    write(`render <IconButton icon="${icon}" /> · ref.current: <${ref.current?.tagName.toLowerCase()}>`);
  };

  return (
    <>
      <div className="demo-group">
        <span className="demo-label">Controlled button</span>
        <div className="demo-row">
          <IconButton
            ref={ref}
            icon="favorite"
            color="error"
            aria-label="Like"
            disabled={disabled}
            onClick={() => write('click on "Like"')}
          />
          <span className="demo-status">disabled: {String(disabled)}</span>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          <Button variant="outlined" size="small" onClick={() => toggle(true)}>
            disabled = true
          </Button>
          <Button variant="outlined" size="small" onClick={() => toggle(false)}>
            disabled = false
          </Button>
          <Button variant="outlined" size="small" onClick={add}>
            Add button
          </Button>
        </div>
        <div className="demo-row">
          {extra.map((icon, index) => (
            <IconButton key={index} icon={icon} aria-label={`Action ${index + 1}`} />
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </>
  );
}

API reference#

Props#

PropTypeDefaultDescription
iconReactNode—Material Icons name ("search") or a node (SVG…). Ignored when there are children.
size'small' | 'medium' | 'large''medium'32 / 40 / 48px area.
color'default' | 'inherit' | 'primary' | 'secondary' | 'success' | 'error' | 'warning' | 'info''default'Icon color.
edge'start' | 'end' | falsefalseNegative 12px margin on that side.
disabledbooleanfalseNative disabled; aria-disabled on links.
disableRipplebooleanfalseTurns off the centered ripple.
hrefstring—Renders an <a>.
componentElementType'button' / 'a'Custom root element (e.g. a router link).
childrenReactNode—Own content (nested icon).
className, style, ref, aria-*, on*…——Forwarded to the root; className is merged.

type defaults to "button" so it never submits a form by accident.

Accessibility#

  • It renders a native <button>: focusable and activable with Enter / Space without extra code.
  • aria-label is required; the generated icon has aria-hidden="true".
  • For toggle buttons (favorite, bold) add aria-pressed={pressed}.
  • The focus ring only appears during keyboard navigation (:focus-visible).
KeyAction
Tab / Shift+TabMoves focus to the next / previous element.
Enter / SpaceTriggers the action.
