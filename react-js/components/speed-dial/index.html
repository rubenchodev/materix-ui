Speed Dial

Floating action button that reveals three to six related, labeled actions in four directions, on click or on hover.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { SpeedDial, SpeedDialAction, SpeedDialIcon } from '@rubenchodev/materix-react';

SpeedDial is a primary Fab that, when pressed, reveals several secondary actions as small labeled FABs, just like MUI’s SpeedDial. Use it when a screen’s primary action has three to six related variants (create document, spreadsheet, presentation). If there is only one action, use a Fab; if there are many options or they are not creation actions, use a Menu.

import { SpeedDial, SpeedDialAction, SpeedDialIcon } from '@rubenchodev/materix-react';
// or only this component:
import { SpeedDial, SpeedDialAction, SpeedDialIcon } from '@rubenchodev/materix-react/components/speed-dial';

Basic usage#

ariaLabel names the primary FAB and each SpeedDialAction takes an icon and a tooltipTitle. The component renders the FAB, the actions container and the labels.

Basic usage open_in_new
import '@rubenchodev/materix-ui/utilities.css';
import { SpeedDial, SpeedDialAction } from '@rubenchodev/materix-react/components/speed-dial';

/** Esquina inferior derecha del panel (utilidades de posición). */
const corner = 'mtx-position-absolute mtx-right-0 mtx-bottom-0 mtx-m-2';

export default function Demo() {
  return (
    <div className="demo-panel demo-panel--tall">
      <SpeedDial ariaLabel="Create" className={corner}>
        <SpeedDialAction icon="description" tooltipTitle="Document" />
        <SpeedDialAction icon="table_chart" tooltipTitle="Spreadsheet" />
        <SpeedDialAction icon="slideshow" tooltipTitle="Presentation" />
      </SpeedDial>
    </div>
  );
}
<SpeedDial ariaLabel="Create">
  <SpeedDialAction icon="description" tooltipTitle="Document" />
  <SpeedDialAction icon="table_chart" tooltipTitle="Spreadsheet" />
  <SpeedDialAction icon="slideshow" tooltipTitle="Presentation" />
</SpeedDial>
warning

Accessible name for each action

tooltipTitle creates the visible label and, if the action has no aria-label, is also used as its aria-label, so icon-only actions always have an accessible name. If tooltipTitle is not a string, pass aria-label yourself.

When closed, the actions are invisible but still take up their space in the layout flow, as in MUI: place the SpeedDial in a corner with absolute or fixed positioning, for example with the utilities className="mtx-position-absolute mtx-right-0 mtx-bottom-0 mtx-m-2" inside a positioned container (see “Hidden and position”).

Directions#

direction sets where the actions open: up (default), down, left or right. Vertically, labels appear to the left of each action; horizontally, above it. The arrow keys follow the direction.

Directions open_in_new
import '@rubenchodev/materix-ui/utilities.css';
import { SpeedDial, SpeedDialAction } from '@rubenchodev/materix-react/components/speed-dial';
import type { SpeedDialDirection } from '@rubenchodev/materix-react/components/speed-dial';

const items: Array<{ direction: SpeedDialDirection; icon: string; label: string; note: string; place: string }> = [
  { direction: 'up', icon: 'north', label: 'Upwards', note: 'up · default', place: 'mtx-position-absolute mtx-right-0 mtx-bottom-0 mtx-m-2' },
  { direction: 'down', icon: 'south', label: 'Downwards', note: 'down', place: 'mtx-position-absolute mtx-right-0 mtx-top-0 mtx-m-2' },
  {
    direction: 'left',
    icon: 'west',
    label: 'To the left',
    note: 'left · tooltipHover',
    place: 'mtx-position-absolute mtx-top-0 mtx-bottom-0 mtx-right-0 mtx-m-2',
  },
  {
    direction: 'right',
    icon: 'east',
    label: 'To the right',
    note: 'right · tooltipHover',
    place: 'mtx-position-absolute mtx-top-0 mtx-bottom-0 mtx-left-0 mtx-m-2',
  },
];

export default function Demo() {
  return (
    <div className="demo-grid-2">
      {items.map(({ direction, icon, label, note, place }) => (
        <div key={direction} className="demo-group">
          <span className="demo-label">{note}</span>
          <div className="demo-panel demo-panel--tall">
            <SpeedDial
              ariaLabel={label}
              icon={icon}
              direction={direction}
              tooltipHover={direction === 'left' || direction === 'right'}
              className={place}
            >
              <SpeedDialAction icon="content_copy" tooltipTitle="Copy" />
              <SpeedDialAction icon="share" tooltipTitle="Share" />
              <SpeedDialAction icon="print" tooltipTitle="Print" />
            </SpeedDial>
          </div>
        </div>
      ))}
    </div>
  );
}

Labels#

By default the labels of all actions are visible while the SpeedDial is open (MUI’s tooltipOpen), styled with the Tooltip tokens. With tooltipHover on the SpeedDial each action uses a real Tooltip that appears on hover or keyboard focus, to the left for vertical directions and above for horizontal ones; recommended for horizontal directions so labels do not overlap. On an action, tooltipOpen forces one mode and tooltipPlacement moves its Tooltip.

info

Keyboard

In both modes the label is visible while moving through the actions: in the persistent mode it always is, and with tooltipHover the Tooltip appears on keyboard focus and hides with Escape. Each action’s accessible name is still its aria-label (persistent labels are aria-hidden so they are not read twice).

Opening on hover#

event="hover" opens the SpeedDial when the mouse enters and closes it when it leaves. Clicking the FAB still toggles it, so it also works on touch screens and with the keyboard.

Icons#

Without icon the FAB shows <SpeedDialIcon /> (add), which rotates 45° when open. openIcon (on the SpeedDial or on SpeedDialIcon) replaces it with another icon while open: the closed icon rotates and fades out while the open one rotates into place. Icons can be Material Icons names or nodes such as an <svg> (24px).

Real-world examples#

Photo gallery: the SpeedDial is controlled, so each action performs its task and closes it.

Real-world examples open_in_new
import '@rubenchodev/materix-ui/utilities.css';
import { useState } from 'react';
import { SpeedDial, SpeedDialAction } from '@rubenchodev/materix-react/components/speed-dial';

/** Esquina inferior derecha del panel (utilidades de posición). */
const corner = 'mtx-position-absolute mtx-right-0 mtx-bottom-0 mtx-m-2';
const actions = [
  ['photo_camera', 'Take photo'],
  ['upload', 'Upload file'],
  ['create_new_folder', 'New album'],
] as const;

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [status, setStatus] = useState('Choose an action.');

  return (
    <div className="demo-panel demo-panel--tall">
      <p className="demo-status mtx-m-2" aria-live="polite">
        {status}
      </p>
      <SpeedDial
        ariaLabel="Add to gallery"
        icon="add_a_photo"
        open={open}
        onOpen={() => setOpen(true)}
        onClose={() => setOpen(false)}
        className={corner}
      >
        {actions.map(([icon, label]) => (
          <SpeedDialAction
            key={icon}
            icon={icon}
            tooltipTitle={label}
            onClick={() => {
              setStatus(`Action: ${label}`);
              setOpen(false);
            }}
          />
        ))}
      </SpeedDial>
    </div>
  );
}

Hidden and position#

hidden shrinks the primary FAB with a scale transition and closes the actions (for example while scrolling): if it was open, onClose(null, 'hidden') is called and it reappears closed. position="fixed-br" and "fixed-bl" pin it 24px from the bottom-right or bottom-left corner of the viewport, above the content (z-index 1050).

Hidden and position open_in_new
import '@rubenchodev/materix-ui/utilities.css';

  return (

      <div className="demo-row">

        <span className="demo-status">hidden: {String(hidden)}</span>
      </div>
      <div className="demo-panel demo-panel--tall">

Programmatic usage#

The vanilla open(), close(), toggle() and direction become the open and direction props. In uncontrolled mode use defaultOpen; onOpen and onClose receive the event and the reason.

Programmatic usage open_in_new
import '@rubenchodev/materix-ui/utilities.css';
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { SpeedDial, SpeedDialAction } from '@rubenchodev/materix-react/components/speed-dial';
import type { SpeedDialDirection } from '@rubenchodev/materix-react/components/speed-dial';

/** Esquina inferior derecha del panel (utilidades de posición). */
const corner = 'mtx-position-absolute mtx-right-0 mtx-bottom-0 mtx-m-2';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [direction, setDirection] = useState<SpeedDialDirection>('up');
  const [log, setLog] = useState<string[]>([]);
  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));
  const nextDirection: SpeedDialDirection = direction === 'up' ? 'left' : 'up';

  return (
    <>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          <Button variant="outlined" size="small" onClick={() => setOpen(true)}>
            open()
          </Button>
          <Button variant="outlined" size="small" onClick={() => setOpen(false)}>
            close()
          </Button>
          <Button variant="outlined" size="small" onClick={() => setOpen((value) => !value)}>
            toggle()
          </Button>
          <Button variant="outlined" size="small" onClick={() => setDirection(nextDirection)}>
            direction = &apos;{nextDirection}&apos;
          </Button>
        </div>
      </div>
      <div className="demo-panel demo-panel--tall">
        <SpeedDial
          ariaLabel="Share actions"
          open={open}
          direction={direction}
          tooltipHover={direction === 'left'}
          onOpen={(_, reason) => {
            setOpen(true);
            write(`onOpen (reason: ${reason})`);
          }}
          onClose={(_, reason) => {
            setOpen(false);
            write(`onClose (reason: ${reason})`);
          }}
          className={corner}
        >
          <SpeedDialAction icon="mail" tooltipTitle="Email" onClick={() => write('click on "Email"')} />
          <SpeedDialAction icon="link" tooltipTitle="Link" onClick={() => write('click on "Link"')} />
        </SpeedDial>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log · open: {String(open)}</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </>
  );
}
const [open, setOpen] = useState(false);

<SpeedDial
  ariaLabel="Actions"
  open={open}
  onOpen={(event, reason) => setOpen(true)}   // 'toggle' | 'mouseEnter'
  onClose={(event, reason) => setOpen(false)} // 'toggle' | 'mouseLeave' | 'escapeKeyDown' | 'clickaway' | 'hidden'
>
  …
</SpeedDial>

API reference#

SpeedDial props#

PropTypeDefaultDescription
ariaLabelstringi18n speedDial.actions (Actions / Acciones)aria-label of the primary FAB.
iconReactNode<SpeedDialIcon />Material Icons name, node or SpeedDialIcon.
openIconReactNode—Icon while open when icon is a name or omitted.
direction'up' | 'down' | 'left' | 'right''up'Opening direction.
openboolean—Controlled state.
defaultOpenbooleanfalseInitial uncontrolled state.
onOpen(event, reason) => void—Open request ('toggle' | 'mouseEnter').
onClose(event, reason) => void—Close request ('toggle' | 'mouseLeave' | 'escapeKeyDown' | 'clickaway' | 'hidden'); event is null with 'hidden'.
event'click' | 'hover''click'With hover it also opens when the mouse enters and closes when it leaves.
tooltipHoverbooleanfalseReplaces the persistent labels with one Tooltip per action.
colorFab colors'primary'Color of the primary FAB.
hiddenbooleanfalseHides the primary FAB with a scale transition; if it was open, it closes and calls onClose(null, 'hidden'), so it does not reappear open.
position'fixed-br' | 'fixed-bl'—Pinned to a corner of the viewport.
FabPropsPartial<FabProps>—Extra props for the primary FAB.
localestring—Language of the default ariaLabel.
className, style, ref, on*…——Forwarded to the root <div>.

Accessibility#

  • The primary FAB gets aria-haspopup="true", a synchronized aria-expanded and aria-controls pointing to the actions container; its name comes from ariaLabel.
  • Actions are native <button> elements with a decorative icon (aria-hidden), named by tooltipTitle or aria-label.
  • While closed, the actions container gets inert and aria-hidden="true" and each action tabIndex={-1}, so invisible actions are out of the tab order. If focus is inside the actions when it closes, it returns to the FAB.
  • Persistent labels are aria-hidden (the name is already in the aria-label); in tooltipHover mode the Tooltip does not duplicate the name when it matches the text.
  • Escape goes through the shared layer stack: a visible Tooltip hides first, then the SpeedDial closes.
  • It respects prefers-reduced-motion: the icon rotation and the openIcon swap have no transition.
