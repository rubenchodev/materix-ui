Table

Displays data sets in rows and columns on a semantic HTML table, with density, sticky header, sorting, selection and pagination.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Table, TableContainer, TableHead, TableBody, TableFooter, TableRow, TableCell, TableCaption, TableSortLabel, TablePagination, TableToolbar, useTableSelection, useTableSort } from '@rubenchodev/materix-react';

Table implements MUI’s table family on a semantic <table>: TableContainer, TableHead, TableBody, TableFooter, TableRow and TableCell, plus the interactive pieces TableSortLabel, TablePagination and TableToolbar. Row selection is data-driven with the useTableSelection hook and the existing Checkbox. Use it for multi-column data that users compare or scan. For a single column of items use List; for summary cards use Card.

import '@rubenchodev/materix-ui/base.css';
import { Table, TableBody, TableCell, TableContainer, TableHead, TableRow } from '@rubenchodev/materix-react';

<TableContainer>
  <Table aria-label="Inventory">
    <TableHead>
      <TableRow><TableCell>Product</TableCell><TableCell align="right">Stock</TableCell></TableRow>
    </TableHead>
    <TableBody>
      <TableRow><TableCell>Keyboard</TableCell><TableCell align="right">12</TableCell></TableRow>
    </TableBody>
  </Table>
</TableContainer>

Anatomy#

  • TableContainer: <div class="mtx-table-container"> that scrolls horizontally (and vertically with maxHeight).
  • Table: <table class="mtx-table">; shares size, padding, hover and selectable with its children through context.
  • TableHead / TableBody / TableFooter: <thead>, <tbody> and <tfoot>. Cells inside TableHead render as <th scope="col">.
  • TableRow / TableCell: <tr class="mtx-table-row"> and <th>/<td class="mtx-table-cell">.
  • TableCaption: <caption class="mtx-table-caption">, shown below the table.

Sticky header#

stickyHeader on TableContainer (or Table) keeps the header visible and maxHeight (number in px or any CSS value) limits the height. While the container scrolls it becomes a focusable region (tabindex="0", role="region") named by the caption, the table’s aria-labelledby/aria-label or a translated fallback; a ResizeObserver keeps it in sync, as in vanilla.

Sorting#

TableSortLabel is controlled: active and direction describe the current order and onSort(event, { direction, active, key }) reports the requested one (the equivalent of mtx:table:sort). The parent <th> gets aria-sort automatically. useTableSort() keeps a single active column and sortRows + getComparator sort the data with a stable sort. In right-aligned columns the arrow is placed on the left.

Sorting open_in_new
import {
  Table,
  TableBody,
  TableCell,
  TableContainer,
  TableHead,
  TableRow,
  TableSortLabel,
  getComparator,
  sortRows,
  useTableSort,
} from '@rubenchodev/materix-react/components/table';

interface Dessert {
  name: string;
  kcal: number;
  fat: number;
}

const DESSERTS: Dessert[] = [
  { name: 'Donut', kcal: 452, fat: 25.0 },
  { name: 'Eclair', kcal: 262, fat: 16.0 },
  { name: 'Cupcake', kcal: 305, fat: 3.7 },
  { name: 'Gingerbread', kcal: 356, fat: 16.0 },
  { name: 'Frozen yoghurt', kcal: 159, fat: 6.0 },
];

export default function Demo() {
  const sort = useTableSort<keyof Dessert>({ defaultOrderBy: 'name' });

    <TableContainer>

            </TableCell>

Selection#

useTableSelection(rows, getId, options) reproduces vanilla’s data-selectable: the header checkbox selects every selectable, enabled row and turns indeterminate with a partial selection; rows get aria-selected; the selection is stored by id, so it survives sorting, filtering and pagination. isRowSelectable excludes a row (data-no-select), isRowDisabled disables its checkbox and selectOnClick toggles a row when clicking outside its controls.

By default the keys of rows that are no longer in rows are kept, so numSelected and the toolbar still count them. When rows is the whole data set and rows can be deleted (or reloaded from the server), pass pruneMissing: true to drop those keys automatically (it calls onSelectionChange with reason: 'api'). Do not use it when rows is only the filtered or current page, or the selection would be lost on filtering or paging.

Pagination#

TablePagination renders the native rows-per-page select, the displayed range (live region) and the navigation buttons. It can be controlled (page, rowsPerPage) or uncontrolled (defaultPage, defaultRowsPerPage); -1 in rowsPerPageOptions means “All” and count={-1} an unknown total. Slice the data with paginateRows(rows, page, rowsPerPage). Changing the rows per page resets the page to 0 without calling onPageChange; in controlled mode reset page in onRowsPerPageChange.

Pagination open_in_new
import { useState } from 'react';
import {
  Table,
  TableBody,
  TableCell,
  TableContainer,
  TableHead,
  TablePagination,
  TableRow,
  paginateRows,
} from '@rubenchodev/materix-react/components/table';

const COUNTRIES = [
  ['AR', 'Argentina', 'Buenos Aires'],
  ['BO', 'Bolivia', 'Sucre'],
  ['CL', 'Chile', 'Santiago'],
  ['CO', 'Colombia', 'Bogotá'],
  ['CR', 'Costa Rica', 'San José'],
  ['EC', 'Ecuador', 'Quito'],
  ['ES', 'Spain', 'Madrid'],
  ['MX', 'Mexico', 'Mexico City'],
  ['PE', 'Peru', 'Lima'],
  ['UY', 'Uruguay', 'Montevideo'],
];

export default function Demo() {
  const [page, setPage] = useState(0);
  const [rowsPerPage, setRowsPerPage] = useState(4);
  const visible = paginateRows(COUNTRIES, page, rowsPerPage);
  return (
    <div className="demo-stack">
      <div>
        <TableContainer>
          <Table size="small" aria-label="Countries">
            <TableHead>
              <TableRow>
                <TableCell>Code</TableCell>
                <TableCell>Country</TableCell>
                <TableCell>Capital</TableCell>
              </TableRow>
            </TableHead>
            <TableBody>
              {visible.map(([code, country, capital]) => (
                <TableRow key={code}>
                  <TableCell>{code}</TableCell>
                  <TableCell>{country}</TableCell>
                  <TableCell>{capital}</TableCell>
                </TableRow>
              ))}
            </TableBody>
          </Table>
        </TableContainer>
        <TablePagination
          count={COUNTRIES.length}
          page={page}
          rowsPerPage={rowsPerPage}
          rowsPerPageOptions={[4, 8, -1]}
          showFirstButton
          showLastButton
          onPageChange={(_event, next) => setPage(next)}
          onRowsPerPageChange={(_event, next) => {
            setRowsPerPage(next);
            setPage(0);
          }}
        />
      </div>
      <div className="demo-group">
        <span className="demo-label">Disabled · unknown total (count = -1)</span>
        <TablePagination count={-1} defaultRowsPerPage={10} disabled />
      </div>
    </div>
  );
}

A data table with a customer search (TextField), bulk delete, selection, sorting, status chips (Chip) and local pagination.

Data table open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { Chip } from '@rubenchodev/materix-react/components/chip';
import { Paper } from '@rubenchodev/materix-react/components/paper';
import {
  Table,
  TableBody,
  TableCell,
  TableContainer,
  TableHead,
  TablePagination,
  TableRow,
  TableSortLabel,
  TableToolbar,
  getComparator,
  paginateRows,
  sortRows,
  useTableSelection,
  useTableSort,
} from '@rubenchodev/materix-react/components/table';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

type Status = 'paid' | 'pending' | 'shipped' | 'cancelled';

interface Order {
  id: string;
  client: string;
  status: Status;
  total: number;
}

const STATUS: Record<Status, { label: string; color: 'success' | 'warning' | 'info' | 'error' }> = {
  paid: { label: 'Paid', color: 'success' },
  pending: { label: 'Pending', color: 'warning' },
  shipped: { label: 'Shipped', color: 'info' },
  cancelled: { label: 'Cancelled', color: 'error' },
};

const INITIAL: Order[] = (
  [
    ['1001', 'Ana García', 'paid', 120], ['1002', 'Luis Pérez', 'pending', 89.5], ['1003', 'María Torres', 'shipped', 42.9],
    ['1004', 'James Parker', 'paid', 310], ['1005', 'Emily Clark', 'cancelled', 15.75], ['1006', 'Carlos Ruiz', 'shipped', 230.4],
    ['1007', 'Rose Davis', 'paid', 64], ['1008', 'Andrew Lopez', 'pending', 512.2], ['1009', 'Grace Miller', 'shipped', 98.1],
    ['1010', 'Oscar Nash', 'paid', 27.3], ['1011', 'Ellen Reed', 'pending', 145], ['1012', 'Paul Gilbert', 'shipped', 76.6],
  ] as const
).map(([id, client, status, total]) => ({ id, client, status, total }));

const money = new Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' });

export default function Demo() {
  const [orders, setOrders] = useState(INITIAL);
  const [query, setQuery] = useState('');
  const [page, setPage] = useState(0);
  const [rowsPerPage, setRowsPerPage] = useState(5);
  const sort = useTableSort<'client' | 'total'>({ defaultOrderBy: 'client', onSortChange: () => setPage(0) });

  const filtered = orders.filter((order) => order.client.toLowerCase().includes(query.trim().toLowerCase()));
  const sorted = sortRows(filtered, getComparator(sort.order, sort.orderBy ?? 'client', 'en'));
  const visible = paginateRows(sorted, page, rowsPerPage);
  const selection = useTableSelection(visible, (order) => order.id, { getRowLabel: (order) => order.client });

  const deleteSelected = () => {
    setOrders((current) => current.filter((order) => !selection.isSelected(order.id)));
    selection.clearSelection();
    setPage(0);
  };

  return (
    <Paper variant="outlined">
      <TableToolbar
        title="Orders"
        numSelected={selection.numSelected}
        actions={
          <TextField
            label="Search customer"
            size="small"
            type="search"
            startIcon="search"
            autoComplete="off"
            value={query}
            onChange={(_event, value) => {
              setQuery(value);
              setPage(0);
            }}
          />
        }
        selectedActions={
          <Button color="error" startIcon="delete" onClick={deleteSelected}>
            Delete
          </Button>
        }
      />
      <TableContainer>
        <Table selectable hover aria-label="Orders">
          <TableHead>
            <TableRow>
              <TableCell padding="checkbox">
                <span className="mtx-visually-hidden">Select</span>
                <Checkbox {...selection.getHeaderCheckboxProps()} />
              </TableCell>
              <TableCell>Order</TableCell>
              <TableCell>
                <TableSortLabel {...sort.getSortLabelProps('client')}>Customer</TableSortLabel>
              </TableCell>
              <TableCell>Status</TableCell>
              <TableCell align="right">
                <TableSortLabel {...sort.getSortLabelProps('total')}>Amount</TableSortLabel>
              </TableCell>
            </TableRow>
          </TableHead>
          <TableBody>
            {visible.map((order) => (
              <TableRow key={order.id} {...selection.getRowProps(order)}>
                <TableCell padding="checkbox">
                  <Checkbox {...selection.getRowCheckboxProps(order)} />
                </TableCell>
                <TableCell>#{order.id}</TableCell>
                <TableCell>{order.client}</TableCell>
                <TableCell>
                  <Chip label={STATUS[order.status].label} size="small" variant="outlined" color={STATUS[order.status].color} />
                </TableCell>
                <TableCell align="right">{money.format(order.total)}</TableCell>
              </TableRow>
            ))}
            {visible.length === 0 ? (
              <TableRow>
                <TableCell colSpan={5} align="center">No orders</TableCell>
              </TableRow>
            ) : null}
          </TableBody>
        </Table>
      </TableContainer>
      <TablePagination
        count={sorted.length}
        page={page}
        rowsPerPage={rowsPerPage}
        rowsPerPageOptions={[5, 10, -1]}
        onPageChange={(_event, next) => setPage(next)}
        onRowsPerPageChange={(_event, next) => {
          setRowsPerPage(next);
          setPage(0);
        }}
      />
    </Paper>
  );
}

import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import {
  Table,
  TableBody,
  TableCell,
  TableContainer,
  TableHead,
  TablePagination,
  TableRow,
  useTableSelection,
} from '@rubenchodev/materix-react/components/table';

const TEAM = [
  { id: 'ana', name: 'Ana García' },
  { id: 'luis', name: 'Luis Pérez' },
  { id: 'maria', name: 'María Torres' },
];

export default function Demo() {
  const [log, setLog] = useState<string[]>([]);
  const [count, setCount] = useState(48);
  const [page, setPage] = useState(0);
  const [rowsPerPage, setRowsPerPage] = useState(10);
  const [disabled, setDisabled] = useState(false);
  const write = (line: string) => setLog((lines) => [line, ...lines].slice(0, 6));
  const selection = useTableSelection(TEAM, (row) => row.id, {
    getRowLabel: (row) => row.name,
    onSelectionChange: (selected, detail) => write(`selection-change ${JSON.stringify(selected)} (${detail.reason})`),
  });
  const lastPage = Math.max(0, Math.ceil(count / rowsPerPage) - 1);

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="outlined" onClick={selection.selectAll}>selectAll()</Button>
        <Button variant="outlined" onClick={selection.clearSelection}>clearSelection()</Button>
        <Button variant="outlined" onClick={() => selection.toggleRow('maria')}>toggleRow(&apos;maria&apos;)</Button>
        <Button variant="outlined" onClick={() => selection.setSelected(['ana'])}>setSelected([&apos;ana&apos;])</Button>
      </div>
      <TableContainer>
        <Table selectable size="small" aria-label="Team (API)">
          <TableHead>
            <TableRow>
              <TableCell padding="checkbox">
                <span className="mtx-visually-hidden">Select</span>
                <Checkbox {...selection.getHeaderCheckboxProps()} />
              </TableCell>
              <TableCell>Name</TableCell>
            </TableRow>
          </TableHead>

            {TEAM.map((row) => (

                <TableCell padding="checkbox">
                  <Checkbox {...selection.getRowCheckboxProps(row)} />
                </TableCell>
                <TableCell>{row.name}</TableCell>
              </TableRow>
            ))}
          </TableBody>
        </Table>
      </TableContainer>
      <TablePagination
        count={count}
        page={page}
        rowsPerPage={rowsPerPage}
        disabled={disabled}
        showFirstButton
        showLastButton
        onPageChange={(_event, next, detail) => {
          setPage(next);
          write(`page-change ${next} (${detail.reason})`);
        }}
        onRowsPerPageChange={(_event, next) => {
          setRowsPerPage(next);
          setPage(0);
          write(`rows-per-page-change ${next}`);
        }}
      />
      <div className="demo-row">
        <Button variant="outlined" onClick={() => setPage(0)}>page = 0</Button>
        <Button variant="outlined" onClick={() => setPage((p) => Math.min(lastPage, p + 1))}>page + 1</Button>
        <Button variant="outlined" onClick={() => setPage(lastPage)}>last page</Button>
        <Button variant="outlined" onClick={() => setPage(2)}>page = 2</Button>
        <Button variant="outlined" onClick={() => setCount(120)}>count = 120</Button>
        <Button variant="outlined" onClick={() => setDisabled((value) => !value)}>disabled = {String(!disabled)}</Button>
      </div>
      <pre className="demo-log" aria-live="polite">{log.join('\n')}</pre>
    </div>
  );
}

Rows per page and the current page

When the rows per page change, the page goes back to 0 without calling onPageChange (vanilla does the same: the event detail carries page: 0). In controlled mode, reset the page yourself in onRowsPerPageChange: onRowsPerPageChange={(e, n) => { setRowsPerPage(n); setPage(0); }}.

Accessibility#

  • Semantic <table> with <th scope="col"> headers and <th scope="row"> row headers; give the table a name with aria-label or TableCaption.
  • A scrolling TableContainer is a focusable, named region so keyboard users can scroll it (WCAG 2.1.1).
  • TableSortLabel is a native <button> (Tab, Enter, Space) and the active column publishes aria-sort.
  • Selection checkboxes have translated names (“Select all rows”, “Select {row}”), the header checkbox reports aria-checked="mixed" and rows publish aria-selected.
  • TableToolbar is a role="toolbar" and announces the selected count with aria-live="polite"; TablePagination announces the displayed range.
