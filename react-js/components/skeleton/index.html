Skeleton

Content-shaped placeholders shown while data loads, with a pulse or wave animation.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Skeleton, SkeletonRegion } from '@rubenchodev/materix-react';

Skeleton displays a grey block shaped like content that hasn’t arrived yet (text, avatar, image, card). It reduces perceived waiting and avoids layout shifts when the data appears. Use it for short loads of content with a known structure; if you don’t know what shape the result will have, or the operation doesn’t load content (saving, sending), use Progress.

import { Skeleton, SkeletonRegion } from '@rubenchodev/materix-react';
// or only this component:
import { Skeleton, SkeletonRegion } from '@rubenchodev/materix-react/components/skeleton';

Basic usage#

Without a variant, <Skeleton /> is a line of text that fills the available width and takes the height of the typography. width and height accept numbers (px) or any CSS unit.

Basic usage open_in_new
import { Skeleton } from '@rubenchodev/materix-react/components/skeleton';

export const description = {
  en: 'Without a variant, `Skeleton` is a line of text that fills the available width and takes the height of the typography; `width` and `height` accept numbers (px) or any CSS unit.',
  es: 'Sin variante, `Skeleton` es una línea de texto que ocupa el ancho disponible y toma la altura de la tipografía; `width` y `height` aceptan números (px) o cualquier unidad CSS.',
};

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <Skeleton />
      <Skeleton variant="circular" width={40} height={40} />
      <Skeleton variant="rectangular" width={210} height={60} />
      <Skeleton variant="rounded" width={210} height={60} />
    </div>
  );
}

Variants#

Four shapes, as in MUI: text (default, scaled down to 60% of the line height), circular, rectangular (no radius) and rounded (4px radius).

Variants open_in_new

  es: 'Cuatro formas, como en MUI: `text` (por defecto, reducida al 60 % de la altura de línea), `circular`, `rectangular` (sin radio) y `rounded` (radio de 4px).',
};

export default function Demo() {
  return (
    <div className="demo-grid-4">
      <div className="demo-group">
        <span className="demo-label">text</span>
        <Skeleton variant="text" />
      </div>
      <div className="demo-group">
        <span className="demo-label">circular</span>
        <Skeleton variant="circular" width={56} height={56} />
      </div>
      <div className="demo-group">
        <span className="demo-label">rectangular</span>
        <Skeleton variant="rectangular" height={56} />

Animations#

animation="pulse" (default), "wave" or false (static; the string "false" is accepted too). With prefers-reduced-motion: reduce the animation is turned off automatically.

Animations open_in_new
import { Skeleton, type SkeletonAnimation } from '@rubenchodev/materix-react/components/skeleton';

export const description = {
  en: '`animation="pulse"` (default, the opacity oscillates), `"wave"` (a band sweeps across the block) or `false` (static). With `prefers-reduced-motion: reduce` the animation is turned off automatically.',
  es: '`animation="pulse"` (por defecto, la opacidad oscila), `"wave"` (una banda recorre el bloque) o `false` (estático). Con `prefers-reduced-motion: reduce` la animación se desactiva automáticamente.',
};

const animations: SkeletonAnimation[] = ['pulse', 'wave', false];

export default function Demo() {
  return (
    <div className="demo-grid-3">
      {animations.map((animation) => (
        <div key={String(animation)} className="demo-group">
          <span className="demo-label">{String(animation)}</span>
          <Skeleton variant="rounded" height={80} animation={animation} />
        </div>
      ))}
    </div>
  );
}

Sizes#

The text variant inherits the size of the typography it sits in: place it inside the same element that will hold the real text. Circular shapes follow the canonical Avatar sizes (24, 40 and 56px).

Sizes open_in_new
import { Skeleton } from '@rubenchodev/materix-react/components/skeleton';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export const description = {
  en: 'The `text` variant inherits the size of the typography it sits in: just place it inside the same element that will hold the real text. Circular shapes follow the canonical Avatar sizes (24, 40 and 56px).',
  es: 'La variante `text` hereda el tamaño de la tipografía que la contiene: basta con colocarla dentro del mismo elemento que tendrá el texto real. Las formas circulares siguen los tamaños canónicos de Avatar (24, 40 y 56px).',
};

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      {(['h3', 'h5', 'body1'] as const).map((variant) => (
        <div key={variant} className="demo-group">
          <span className="demo-label">{variant}</span>
          <Typography variant={variant} component="div">
            <Skeleton />
          </Typography>
        </div>
      ))}
      <div className="demo-group">
        <span className="demo-label">caption</span>
        <Typography variant="caption" component="div">
          <Skeleton width="40%" />
        </Typography>
      </div>
      <div className="demo-row">
        <Skeleton variant="circular" width={24} height={24} />
        <Skeleton variant="circular" width={40} height={40} />
        <Skeleton variant="circular" width={56} height={56} />
      </div>
    </div>
  );
}

Paragraphs#

lines={3} generates a .mtx-skeleton-lines block with several lines of text; the last one is shorter (60% by default, configurable with lastWidth). With lines, variant and height have no effect.

  es: '`lines={3}` genera varias líneas de texto; la última es más corta (60 % por defecto, configurable con `lastWidth`).',
};

export default function Demo() {
  return (
    <div className="demo-grid-2">

        <Skeleton lines={3} />
      </div>

With children#

When the skeleton wraps content, it takes its exact size and hides it (visibility: hidden, class .mtx-skeleton--with-children). Direct text is wrapped in .mtx-skeleton__text so it is hidden too instead of being transparent text that fails contrast checks.

With children open_in_new
import { Avatar } from '@rubenchodev/materix-react/components/avatar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Skeleton } from '@rubenchodev/materix-react/components/skeleton';

export const description = {
  en: 'When the skeleton wraps content, it takes its exact size and hides it (`visibility: hidden`). Useful to avoid repeating dimensions: an Avatar or a Button inside becomes its own placeholder.',
  es: 'Cuando el skeleton envuelve contenido, toma su tamaño exacto y lo oculta (`visibility: hidden`). Útil para no repetir dimensiones: un Avatar o un Button dentro se convierte en su propio placeholder.',
};

export default function Demo() {
  return (
    <div className="demo-row">
      <Skeleton component="div" variant="circular">
        <Avatar icon="person" />
      </Skeleton>
      <Skeleton component="div" variant="rounded">
        <Button variant="contained" tabIndex={-1}>Save changes</Button>
      </Skeleton>
      <Skeleton component="div" className="mtx-typography--h5">
        A title of real length
      </Skeleton>
    </div>
  );
}

States#

Loading region#

SkeletonRegion is the React equivalent of Materix.skeleton.set(). While loading is true it renders data-loading and aria-busy="true" on the root, shows the placeholder (inside [data-skeleton-placeholder], always aria-hidden) and hides the children (inside [data-skeleton-content]). Both wrappers stay mounted and the CSS hides the inactive one, so the content keeps its state. With aria-live="polite" the content is announced when loading finishes. Use placeholderProps and contentProps to style the wrappers.

States open_in_new
import { useState } from 'react';
import { Avatar } from '@rubenchodev/materix-react/components/avatar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Skeleton, SkeletonRegion } from '@rubenchodev/materix-react/components/skeleton';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export const description = {
  en: '`SkeletonRegion` shows its `placeholder` while `loading` and its children afterwards, syncing `data-loading` and `aria-busy` (the React equivalent of `Materix.skeleton.set()`). With `aria-live="polite"` the content is announced when loading finishes.',
  es: '`SkeletonRegion` muestra su `placeholder` mientras `loading` y sus hijos después, sincronizando `data-loading` y `aria-busy` (el equivalente React de `Materix.skeleton.set()`). Con `aria-live="polite"` el contenido se anuncia al terminar la carga.',
};

const row = { className: 'mtx-d-flex mtx-align-items-center mtx-gap-2' };

export default function Demo() {
  const [loading, setLoading] = useState(true);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="outlined" aria-controls="skeleton-region" onClick={() => setLoading((value) => !value)}>
          Toggle loading
        </Button>
      </div>
      <SkeletonRegion
        id="skeleton-region"
        className="demo-fixed-width"
        aria-live="polite"
        loading={loading}
        placeholderProps={row}
        contentProps={row}
        placeholder={
          <>
            <Skeleton variant="circular" width={40} height={40} />
            <div className="mtx-flex-1">
              <Skeleton width="60%" />
              <Skeleton width="40%" />
            </div>
          </>
        }
      >
        <Avatar color="secondary">LM</Avatar>
        <div>
          <Typography variant="body1" component="div">Lucy Martin</Typography>
          <Typography variant="body2" color="text-secondary" component="div">Product designer</Typography>
        </div>
      </SkeletonRegion>
    </div>
  );
}

If you prefer to unmount the content while loading, the MUI pattern also works: loading ? <Skeleton /> : <Content />.

Controlled usage#

variant and animation are ordinary props (they replace setVariant() and setAnimation()); SkeletonRegion calls onChange({ loading }) whenever loading changes after mounting.

Controlled usage open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import {
  Skeleton,
  SkeletonRegion,
  type SkeletonAnimation,
  type SkeletonVariant,
} from '@rubenchodev/materix-react/components/skeleton';

export const description = {
  en: 'The `variant` and `animation` props replace the vanilla `setVariant()` and `setAnimation()`; `SkeletonRegion` calls `onChange({ loading })` when `loading` changes (the `mtx:skeleton:change` event).',
  es: 'Las props `variant` y `animation` sustituyen a `setVariant()` y `setAnimation()` de vanilla; `SkeletonRegion` llama a `onChange({ loading })` cuando cambia `loading` (el evento `mtx:skeleton:change`).',
};

const variants: SkeletonVariant[] = ['rounded', 'circular', 'rectangular', 'text'];
const animations: SkeletonAnimation[] = ['pulse', 'wave', false];

export default function Demo() {
  const [v, setV] = useState(0);
  const [a, setA] = useState(0);
  const [loading, setLoading] = useState(true);
  const [log, setLog] = useState<string[]>([]);
  const write = (line: string) => setLog((lines) => [line, ...lines].slice(0, 6));

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Skeleton variant={variants[v]} animation={animations[a]} width={120} height={120} />
        <SkeletonRegion
          loading={loading}
          onChange={({ loading: value }) => write(`onChange → loading = ${value}`)}
          placeholder={<Skeleton width={160} />}
        >
          Content loaded
        </SkeletonRegion>
      </div>
      <div className="demo-row">
        <Button
          variant="outlined"
          onClick={() => {
            const next = (v + 1) % variants.length;
            setV(next);
            write(`variant="${variants[next]}"`);
          }}
        >
          Change variant
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            const next = (a + 1) % animations.length;
            setA(next);
            write(`animation=${JSON.stringify(animations[next])}`);
          }}
        >
          Change animation
        </Button>
        <Button variant="outlined" onClick={() => setLoading((value) => !value)}>
          Toggle loading
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">{log.join('\n')}</pre>
    </div>
  );
}

widthnumber | string—Width (number = px).

Accessibility#

  • Every skeleton is decorative (aria-hidden="true").
  • Announce the loading state on the container: SkeletonRegion sets aria-busy and, with aria-live="polite", the content is read when it arrives.
  • Animations respect prefers-reduced-motion.
