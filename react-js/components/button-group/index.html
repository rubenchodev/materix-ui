Button Group

Groups related buttons into a single piece with joined borders, separators and inherited variant, size and color.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Button, ButtonGroup } from '@rubenchodev/materix-react';

Button Group joins related Buttons into a single piece: shared borders, separators between them and the same variant, size and color. Use it for sets of actions of the same level (text alignment, period filters, export formats) and for the split button pattern.

Import#

import { Button, ButtonGroup } from '@rubenchodev/materix-react';

Basic usage#

A <ButtonGroup> with <Button> children: the group passes its variant (outlined by default) to the buttons through context, computes their position (first / middle / last) and renders role="group". Give it a name with label or aria-label.

Basic usage open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';
import { ButtonGroup } from '@rubenchodev/materix-react/components/button-group';

export default function Demo() {
  return (
    <div className="demo-row">
      <ButtonGroup variant="contained" label="Basic actions">
        <Button>One</Button>
        <Button>Two</Button>
        <Button>Three</Button>
      </ButtonGroup>
    </div>
  );
}

Variants#

variant="outlined|contained|text", as in MUI. Outlined overlaps the borders; contained separates with the dark shade of the color and moves the elevation to the group; text separates with a 50% line.

Variants open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';
import { ButtonGroup } from '@rubenchodev/materix-react/components/button-group';

const VARIANTS = ['outlined', 'contained', 'text'] as const;

export default function Demo() {
  return (
    <div className="demo-stack">
      {VARIANTS.map((variant) => (
        <div className="demo-group" key={variant}>
          <span className="demo-label">{variant === 'outlined' ? 'outlined (default)' : variant}</span>
          <ButtonGroup variant={variant} label={variant}>
            <Button>One</Button>
            <Button>Two</Button>
            <Button>Three</Button>
          </ButtonGroup>
        </div>
      ))}
    </div>
  );
}

Sizes#

size="small|medium|large" is inherited by every button (32, 40 and 48px).

Sizes open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';
import { ButtonGroup } from '@rubenchodev/materix-react/components/button-group';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

const SIZES = [
  { size: 'large', label: 'Large · 48px' },
  { size: 'medium', label: 'Medium · 40px' },
  { size: 'small', label: 'Small · 32px' },
] as const;

export default function Demo() {
  return (
    <div className="demo-stack">
      {SIZES.map(({ size, label }) => (
        <div className="demo-group" key={size}>
          <span className="demo-label">{label}</span>
          <div className="demo-row">
            <ButtonGroup size={size} label={label}>
              <Button>One</Button>
              <Button>Two</Button>
              <Button>Three</Button>
            </ButtonGroup>
            {size === 'medium' ? (
              <TextField label="Search" size="small" type="text" />
            ) : (
              <IconButton icon="more_vert" size={size} aria-label="More options" />
            )}
          </div>
        </div>
      ))}
    </div>
  );
}

With icons#

Each child accepts the Button props (startIcon, endIcon). For icon-only buttons, put a .material-icons span as the only child and an aria-label: the group compacts their padding.

With icons open_in_new

import { ButtonGroup } from '@rubenchodev/materix-react/components/button-group';

const ALIGN = [
  { icon: 'format_align_left', label: 'Align left' },
  { icon: 'format_align_center', label: 'Center' },
  { icon: 'format_align_right', label: 'Align right' },
  { icon: 'format_align_justify', label: 'Justify' },
];

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">No icon</span>
        <ButtonGroup label="No icon">
          <Button>Day</Button>
          <Button>Week</Button>
          <Button>Month</Button>
        </ButtonGroup>
      </div>
      <div className="demo-group">
        <span className="demo-label">Start icon</span>
        <ButtonGroup variant="contained" label="Start icon">
          <Button startIcon="content_copy">Copy</Button>
          <Button startIcon="content_cut">Cut</Button>
          <Button startIcon="content_paste">Paste</Button>
        </ButtonGroup>
      </div>
      <div className="demo-group">
        <span className="demo-label">End icon</span>
        <ButtonGroup label="End icon">
          <Button endIcon="send">Send</Button>
          <Button endIcon="schedule_send">Schedule</Button>
        </ButtonGroup>
      </div>
      <div className="demo-group">
        <span className="demo-label">Icon only</span>
        <ButtonGroup label="Text alignment">
          {ALIGN.map(({ icon, label }) => (
            <Button key={icon} aria-label={label}>
              <span className="material-icons" aria-hidden="true">
                {icon}
              </span>
            </Button>
          ))}
        </ButtonGroup>
      </div>
    </div>
  );
}

Orientation#

orientation="vertical" stacks the buttons. It keeps role="group", which doesn’t allow aria-orientation; with role="toolbar" the group adds aria-orientation="vertical".

Orientation open_in_new

import { ButtonGroup } from '@rubenchodev/materix-react/components/button-group';

const VARIANTS = ['outlined', 'contained', 'text'] as const;

export default function Demo() {
  return (
    <div className="demo-row demo-row--start">
      {VARIANTS.map((variant) => (
        <ButtonGroup key={variant} orientation="vertical" variant={variant} label={`Vertical ${variant}`}>
          <Button>One</Button>
          <Button>Two</Button>
          <Button>Three</Button>
        </ButtonGroup>
      ))}
    </div>
  );
}

States#

disabled disables every button of the group and sets aria-disabled="true" on it; a single child can be disabled on its own. disableElevation removes the shadow of the contained group.

States open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';
import { ButtonGroup } from '@rubenchodev/materix-react/components/button-group';

const VARIANTS = ['outlined', 'contained', 'text'] as const;

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Disabled group</span>
        <div className="demo-row">
          {VARIANTS.map((variant) => (
            <ButtonGroup key={variant} variant={variant} disabled label={`Disabled ${variant}`}>
              <Button>One</Button>
              <Button>Two</Button>
              <Button>Three</Button>
            </ButtonGroup>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">One disabled button</span>
        <ButtonGroup variant="contained" label="One disabled child">
          <Button>One</Button>
          <Button disabled>Two</Button>
          <Button>Three</Button>
        </ButtonGroup>
      </div>
      <div className="demo-group">
        <span className="demo-label">No elevation</span>
        <ButtonGroup variant="contained" disableElevation label="No elevation">
          <Button>One</Button>
          <Button>Two</Button>
        </ButtonGroup>
      </div>
    </div>
  );
}

Split button#

MUI pattern: the primary action plus an arrow button that opens a menu with the alternatives. Give the arrow an aria-label and aria-haspopup="menu"; the Menu adds aria-expanded and aria-controls, and should anchor to the group so it aligns with its full width. In this demo the arrow opens a Menu anchored to the group (matchWidth); choosing an option makes it the primary action and focus returns to the arrow.

Split button open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { ButtonGroup } from '@rubenchodev/materix-react/components/button-group';
import { Menu, MenuItem } from '@rubenchodev/materix-react/components/menu';

const OPTIONS = ['Create a merge commit', 'Squash and merge', 'Rebase and merge'];

export default function Demo() {
  const [index, setIndex] = useState(1);
  const [open, setOpen] = useState(false);
  const [focusItem, setFocusItem] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const groupRef = useRef<HTMLDivElement>(null);
  const arrowRef = useRef<HTMLButtonElement>(null);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 6));

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <ButtonGroup ref={groupRef} variant="contained" label="Merge pull request">
          <Button onClick={() => write(`click → ${OPTIONS[index]}`)}>{OPTIONS[index]}</Button>
          <Button
            ref={arrowRef}
            aria-label="Choose merge strategy"
            aria-haspopup="menu"
            aria-expanded={open}
            aria-controls={open ? 'split-button-menu' : undefined}
            onClick={(event) => {
              // `detail === 0`: abierto con teclado → foco en la opción seleccionada.
              setFocusItem(event.detail === 0);
              setOpen((value) => !value);
            }}
          >
            <span className="material-icons" aria-hidden="true">
              arrow_drop_down
            </span>
          </Button>
        </ButtonGroup>
        <Menu
          id="split-button-menu"
          open={open}
          anchorEl={groupRef}
          restoreFocusTo={arrowRef}
          matchWidth
          autoFocusItem={focusItem}
          onClose={() => setOpen(false)}
          onSelect={({ value }) => {
            const next = OPTIONS.indexOf(value ?? '');
            if (next >= 0) {
              setIndex(next);
              write(`onSelect → "${OPTIONS[next]}"`);
            }
          }}
        >
          {OPTIONS.map((option, i) => (
            <MenuItem key={option} value={option} selected={i === index} disabled={i === 2}>
              {option}
            </MenuItem>
          ))}
        </Menu>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Programmatic usage#

The group is declarative: change disabled or render more children and the positions are recomputed on every render (no refresh() needed).

Programmatic usage open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { ButtonGroup } from '@rubenchodev/materix-react/components/button-group';

const NAMES = ['One', 'Two', 'Three', 'Four', 'Five'];

export default function Demo() {
  const [disabled, setDisabled] = useState(false);
  const [count, setCount] = useState(2);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 6));

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <ButtonGroup disabled={disabled} label="Programmatic group">
          {NAMES.slice(0, count).map((name) => (
            <Button key={name}>{name}</Button>
          ))}
        </ButtonGroup>
      </div>
      <div className="demo-row">
        <Button
          variant="outlined"
          onClick={() => {
            setDisabled(!disabled);
            write(`disabled = ${!disabled}`);
          }}
        >
          Toggle disabled
        </Button>
        <Button
          variant="outlined"
          disabled={count >= NAMES.length}
          onClick={() => {
            setCount(count + 1);
            write(`${count + 1} buttons`);
          }}
        >
          Add button
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

API reference#

Props#

PropTypeDefaultDescription
variant'outlined' | 'contained' | 'text''outlined'Variant inherited by the buttons.
size'small' | 'medium' | 'large''medium'Inherited size.
color'primary' | 'secondary' | 'success' | 'error' | 'warning' | 'info' | 'inherit''primary'Inherited color.
orientation'horizontal' | 'vertical''horizontal'Layout direction.
fullWidthbooleanfalseFull width; also passed to the buttons.
disabledbooleanfalseDisables every button.
disableElevationbooleanfalseNo shadow in contained.
labelstring—Accessible name (aria-label).
rolestring'group'Root role (toolbar if you add arrow-key navigation).

Other props go to the root <div>; className is merged and ref points to it.

There is no “Manual BEM usage” section: the group always renders the full BEM structure and computes the position classes on every render.

Accessibility#

  • The container renders role="group"; name it with label or aria-label so screen readers announce the purpose of the set.
  • Each child is a native <button> (or <a>): tab order is the natural one, without roving tabindex.
  • Icon-only buttons need aria-label; the icon, aria-hidden="true".
  • disabled uses the native disabled (or aria-disabled on links) and sets aria-disabled="true" on the group.
KeyAction
Tab / Shift+TabMoves focus between the group’s buttons.
Enter / SpaceActivates the focused button.
