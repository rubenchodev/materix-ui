Dialog

A modal window that interrupts the task to ask for a decision or show critical information, with trapped focus and Escape to close.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Dialog, DialogTitle, DialogContent, DialogContentText, DialogActions } from '@rubenchodev/materix-react';

Dialog opens a modal panel over the page: it locks scrolling, traps keyboard focus and requires a decision before continuing. Use it for confirmations, short forms or information the user must not miss. Don’t use it for notices that need no response (use Snackbar or Alert) or for side navigation (use a Drawer).

import { Dialog, DialogTitle, DialogContent, DialogContentText, DialogActions } from '@rubenchodev/materix-react';
// or only this component:
import { Dialog } from '@rubenchodev/materix-react/components/dialog';

Basic usage#

The simplest form is a single element: <Dialog open={…} onClose={…} title="…"> with the content as children. open is controlled: onClose(event, reason) asks to close it and you update the state. The dialog is rendered in a portal on document.body, with the shared Backdrop as its background; Escape and a click on the backdrop close it.

Basic usage open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [open, setOpen] = useState(false);
  return (
    <div className="demo-row">
      <Button variant="contained" onClick={() => setOpen(true)}>
        Open dialog
      </Button>
      <Dialog open={open} onClose={() => setOpen(false)} title="Use the device location">
        <p>Let apps determine your location to show you nearby results. Press Escape or click outside to close.</p>
      </Dialog>
    </div>
  );
}

With actions#

actions wraps its buttons in a DialogActions, always placed at the end of the panel, outside the content. description generates a DialogContentText at the start of the content and links it with aria-describedby. Any element with data-mtx-dialog-close inside the dialog asks to close it (reason closeButtonClick). The main action uses contained and the secondary one text.

Actions alignment#

As in MUI, actions go on the right by default (end). Change it with align="start|center|end|between" on DialogActions, or for the whole dialog with actionsAlign (it applies to the actions without their own align). between separates an auxiliary action on the left from the main ones on the right. disableSpacing removes the gap between buttons.

Actions alignment open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog, DialogActions } from '@rubenchodev/materix-react/components/dialog';

    <div className="demo-row">

        <Button key={align} variant="outlined" onClick={() => setOpen(align)}>
          {align === 'end' ? 'end (default)' : align}
        </Button>
      ))}
      <Dialog
        open={open === 'end'}
        onClose={close}
        maxWidth="sm"
        title="Actions on the right"
        description="Without props, the actions are aligned to the end of the panel."
        actions={
          <>
            <Button onClick={close}>Cancel</Button>
            <Button variant="contained" onClick={close}>
              OK
            </Button>
          </>
        }

      <Dialog
        open={open === 'start'}

Sizes#

maxWidth sets the panel’s maximum width: xs (20rem), sm (24rem), md (32rem, default), lg (48rem), xl (64rem) or false (no limit). The panel takes 100% of the available width up to that maximum; fullWidth={false} makes it as wide as its content. fullScreen takes the whole window and removes the rounded corners, the recommended pattern on mobile for long tasks.

Sizes open_in_new

  { key: 'md', maxWidth: 'md', label: 'MD · 32rem', title: 'MD size', text: 'Max width of 32rem; this is the default value.' },
  { key: 'lg', maxWidth: 'lg', label: 'LG · 48rem', title: 'LG size', text: 'Max width of 48rem, useful for two-column forms.' },

Destructive confirmation#

For irreversible actions use a title phrased as a question, explain the consequence and color the action with color="error". role="alertdialog" tells assistive technologies that the dialog requires an urgent response, and data-dialog-autofocus sends the initial focus to “Cancel”, the safe option.

Destructive confirmation open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [status, setStatus] = useState('');
  const close = () => setOpen(false);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" color="error" onClick={() => setOpen(true)}>
          Delete project
        </Button>
      </div>
      <p className="demo-status" role="status">
        {status}
      </p>
      <Dialog
        open={open}
        onClose={close}
        role="alertdialog"
        maxWidth="sm"
        title="Delete the project?"
        description="Its 24 files will be deleted and you will not be able to recover them."
        actions={
          <>
            <Button onClick={close} data-dialog-autofocus>
              Cancel
            </Button>
            <Button
              variant="contained"
              color="error"
              onClick={() => {
                setStatus('Project deleted');
                close();
              }}
            >
              Delete
            </Button>
          </>
        }
      />
    </div>
  );
}

Form inside a dialog#

A <form> can hold the TextField fields and be submitted from a button in the actions (type="submit" form="…"). The first field gets focus on open, or the one marked with data-dialog-autofocus, and Tab doesn’t leave the panel. If the content starts directly with a field, the shared CSS reserves space at the top so the floating label is not clipped.

Form inside a dialog open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog, DialogActions, DialogContent, DialogContentText } from '@rubenchodev/materix-react/components/dialog';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

const AUTOFOCUS = { 'data-dialog-autofocus': '' };

export default function Demo() {
  const [open, setOpen] = useState<'subscribe' | 'rename' | null>(null);
  const [status, setStatus] = useState('');
  const close = () => setOpen(null);

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const form = event.currentTarget;
    if (!form.checkValidity()) {
      form.reportValidity();
      return;
    }
    const email = (form.elements.namedItem('email') as HTMLInputElement).value;
    setStatus(`Subscribed: ${email}`);
    close();
  };

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" onClick={() => setOpen('subscribe')}>
          Subscribe
        </Button>
        <Button variant="outlined" onClick={() => setOpen('rename')}>
          Rename (field first)
        </Button>
      </div>
      <p className="demo-status" role="status">
        {status}
      </p>
      <Dialog open={open === 'subscribe'} onClose={close} maxWidth="sm" title="Subscribe to the newsletter">
        <DialogContent>
          <form className="demo-stack" id="dlg-form-el" onSubmit={handleSubmit}>
            <DialogContentText>Get the Materix UI news once a month.</DialogContentText>
            <TextField label="Name" name="name" defaultValue="Jane" required fullWidth />
            <TextField label="Email" type="email" name="email" required fullWidth inputProps={AUTOFOCUS} />
          </form>
        </DialogContent>
        <DialogActions>
          <Button onClick={close}>Cancel</Button>
          <Button variant="contained" type="submit" form="dlg-form-el">
            Subscribe
          </Button>
        </DialogActions>
      </Dialog>
      <Dialog
        open={open === 'rename'}
        onClose={close}
        maxWidth="sm"
        title="Rename file"
        actions={
          <>
            <Button onClick={close}>Cancel</Button>
            <Button variant="contained" onClick={close}>
              Rename
            </Button>
          </>
        }
      >
        <TextField label="File name" defaultValue="quarterly-report.pdf" fullWidth inputProps={AUTOFOCUS} />
      </Dialog>
    </div>
  );
}
<Dialog open={open} onClose={close} maxWidth="sm" title="Subscribe to the newsletter">
  <DialogContent>
    <form id="subscribe" onSubmit={handleSubmit}>
      <DialogContentText>Get the Materix UI news once a month.</DialogContentText>

      <TextField label="Email" type="email" name="email" required fullWidth

Scroll: paper and body#

With scroll="paper" (default) the content scrolls inside the panel; DialogContent dividers separates the areas and DialogTitle sticky / DialogActions sticky pin the title and the actions. With scroll="body" the panel grows with its content and the dialog container is what scrolls.

Scroll: paper and body open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog, DialogActions, DialogContent } from '@rubenchodev/materix-react/components/dialog';

const TERMS = [

  'Aenean lacinia bibendum nulla sed consectetur. Duis mollis, est non commodo luctus, nisi erat porttitor ligula.',
];

export default function Demo() {
  const [open, setOpen] = useState<'paper' | 'body' | null>(null);
  const close = () => setOpen(null);
  return (
    <div className="demo-row">
      <Button variant="contained" onClick={() => setOpen('paper')}>
        scroll = paper
      </Button>
      <Button variant="outlined" onClick={() => setOpen('body')}>
        scroll = body
      </Button>
      <Dialog open={open === 'paper'} onClose={close} scroll="paper" title="Terms and conditions">
        <DialogContent dividers>

        title="Release notes"
        actions={
          <Button variant="contained" onClick={close}>
            Got it
          </Button>
        }
      >
        <p>The panel does not limit its height: it grows with the content and the whole dialog scrolls with the wheel or the keyboard.</p>

Modal behavior#

By default the dialog closes with a click on the backdrop (backdropClick) and with Escape (escapeKeyDown). disableBackdropClose and disableEscapeKeyDown force the user to choose an explicit action (Escape is still consumed by the dialog, so it doesn’t reach the layers below). While it is open, page scrolling is locked (disableScrollLock turns it off).

Modal behavior open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [open, setOpen] = useState<'backdrop' | 'strict' | null>(null);
  const close = () => setOpen(null);
  return (
    <div className="demo-row">
      <Button variant="outlined" onClick={() => setOpen('backdrop')}>
        No backdrop close
      </Button>
      <Button variant="outlined" onClick={() => setOpen('strict')}>
        No backdrop or Escape
      </Button>
      <Dialog
        open={open === 'backdrop'}
        onClose={close}
        disableBackdropClose
        maxWidth="sm"
        title="Unsaved changes"
        actions={
          <>
            <Button onClick={close}>Discard</Button>
            <Button variant="contained" onClick={close}>
              Save
            </Button>
          </>
        }
      >
        Clicking outside the panel does not close it; Escape does.
      </Dialog>
      <Dialog
        open={open === 'strict'}
        onClose={close}
        disableBackdropClose
        disableEscapeKeyDown
        maxWidth="sm"
        title="Accept to continue"
        actions={
          <Button variant="contained" onClick={close}>
            Accept
          </Button>
        }
      >
        Neither the backdrop nor Escape closes this dialog: only the buttons do.
      </Dialog>
    </div>
  );
}

Nested dialogs and Escape#

Dialogs join the shared layer stack: a dialog opened from another one is stacked above it (its z-index rises automatically), focus is trapped only in the top one, and each Escape closes only the top layer.

Nested dialogs and Escape open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';
import type { DialogCloseReason } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [share, setShare] = useState(false);
  const [permissions, setPermissions] = useState(false);
  const [confirm, setConfirm] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [...lines.slice(-5), text]);
  const closer =
    (name: string, setter: (value: boolean) => void) =>
    (_event: unknown, reason: DialogCloseReason) => {
      write(`${name} closed (${reason})`);
      setter(false);
    };

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" onClick={() => setShare(true)}>
          Open dialog
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
      <Dialog
        open={share}
        onClose={closer('Share', setShare)}
        maxWidth="sm"
        title="Share report"
        description="Each Escape closes only the top dialog; the ones below stay open."
        actions={
          <>
            <Button variant="outlined" startIcon="tune" onClick={() => setPermissions(true)}>
              Permissions
            </Button>
            <Button onClick={() => setShare(false)}>Close</Button>
          </>
        }
      >
        <Dialog
          open={permissions}
          onClose={closer('Permissions', setPermissions)}
          maxWidth="xs"
          title="Permissions"
          description="Remove access for everyone outside the team?"
          actions={
            <>
              <Button onClick={() => setPermissions(false)}>Back</Button>
              <Button variant="contained" color="error" onClick={() => setConfirm(true)}>
                Remove
              </Button>
            </>
          }
        >
          <Dialog
            open={confirm}
            onClose={closer('Confirm', setConfirm)}
            role="alertdialog"
            maxWidth="xs"
            title="Are you sure?"
            description="Third level: Escape closes this one first."
            actions={
              <Button
                variant="contained"
                onClick={() => {
                  write('Access removed');
                  setConfirm(false);
                  setPermissions(false);
                }}
              >
                Confirm
              </Button>
            }
          />
        </Dialog>
      </Dialog>
    </div>
  );
}

Stacked layers and Escape#

A Popover, a Menu and a Tooltip opened inside a dialog join the same layer stack: each Escape closes only the top layer (a visible tooltip first), focus moves into them without being pulled back to the panel, and interacting with them never closes the dialog.

Stacked layers and Escape open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';
import { Menu, MenuGroup, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';

Programmatic usage#

The equivalent of open()/close() is the open prop. onOpen and onClose(event, reason) are the equivalents of mtx:dialog:open and mtx:dialog:close; onEntered and onExited fire when the panel animation ends. With keepMounted the dialog stays in the DOM while closed.

Programmatic usage open_in_new
import { useEffect, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';
import type { DialogCloseReason } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [auto, setAuto] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) =>
    setLog((lines) => [...lines.slice(-7), `${new Date().toLocaleTimeString()}  ${text}`]);

  // Equivalente a `open()` + `close('timeout-demo')` tras 2 s.
  useEffect(() => {
    if (!auto) return undefined;
    const timer = setTimeout(() => {
      write('close  reason=timeout-demo');
      setOpen(false);
      setAuto(false);
    }, 2000);
    return () => clearTimeout(timer);
  }, [auto]);

  const handleClose = (_event: unknown, reason: DialogCloseReason) => {
    write(`onClose  reason=${reason}`);
    setOpen(false);
    setAuto(false);
  };

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" onClick={() => setOpen(true)}>
          open
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setOpen(true);
            setAuto(true);
          }}
        >
          open and close after 2 s
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
      <Dialog
        open={open}
        onClose={handleClose}
        onOpen={() => write('onOpen')}
        onExited={() => write('onExited')}
        keepMounted
        maxWidth="sm"
        title="Programmatic dialog"
        actions={
          <Button variant="contained" data-mtx-dialog-close>
            Close
          </Button>
        }
      >
        Controlled with the <code>open</code> prop. Close it with Escape, the backdrop or the button.
      </Dialog>
    </div>
  );
}

Composition#

For full control, compose the parts: DialogTitle names the dialog (aria-labelledby) and the first DialogContentText describes it (aria-describedby); the ids are generated from the dialog id (or a unique id). You can mix both forms: title and actions are still added when you use DialogContent as a child.

Composition open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import {
  Dialog,
  DialogActions,
  DialogContent,
  DialogContentText,
  DialogTitle,
} from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const close = () => setOpen(false);
  return (
    <div className="demo-row">
      <Button variant="contained" onClick={() => setOpen(true)}>
        Open composed dialog
      </Button>
      <Dialog open={open} onClose={close} maxWidth="sm">
        <DialogTitle sticky>Composed structure</DialogTitle>
        <DialogContent>
          <DialogContentText>
            DialogTitle names the dialog (aria-labelledby) and the first DialogContentText describes it
            (aria-describedby), with no ids to write by hand.
          </DialogContentText>
        </DialogContent>
        <DialogActions sticky>
          <Button onClick={close}>Cancel</Button>
          <Button variant="contained" onClick={close}>
            OK
          </Button>
        </DialogActions>
      </Dialog>
    </div>
  );
}

Accessibility#

  • The panel has role="dialog" (or alertdialog) and aria-modal="true"; it is named by the title (aria-labelledby) and described by the first DialogContentText (aria-describedby). Without a title, give it an aria-label.
  • On open, focus goes to the element with data-dialog-autofocus, to the first focusable control, or to the panel; on close it returns to the element that had it.
  • Focus is trapped inside the top dialog; layers opened from it (popover, menu) keep their own focus.
  • Page scrolling is locked while it is open.
KeyAction
EscapeCloses the top dialog (unless disableEscapeKeyDown).
Tab / Shift+TabMoves cyclically through the controls of the panel.
