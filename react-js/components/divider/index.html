Divider

A thin line that separates and groups content in lists, menus and layouts, horizontally or vertically and optionally with text.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Divider } from '@rubenchodev/materix-react';

Divider is a 1px line in the theme’s divider color that separates groups of content. It can be horizontal or vertical, inset or with a margin on both sides, and can carry centered or aligned text.

import { Divider } from '@rubenchodev/materix-react';
// or only this component:
import { Divider } from '@rubenchodev/materix-react/components/divider';

Basic usage#

<Divider /> renders an <hr class="mtx-divider">, which has the separator role natively.

Basic usage open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';

export default function Demo() {
  return (
    <div className="demo-panel">
      <span>Content of the first section.</span>
      <Divider className="demo-wide" />
      <span>Content of the second section.</span>
    </div>
  );
}

Variants#

fullWidth (default) spans the whole width; middle leaves 16px on each side; inset leaves 72px on the left to line up with the text of lists with icons.

Variants open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Full width</span>
        <Divider />
      </div>
      <div className="demo-group">
        <span className="demo-label">Middle · 16px on each side</span>
        <Divider variant="middle" />
      </div>
      <div className="demo-group">
        <span className="demo-label">Inset · 72px on the left</span>
        <Divider variant="inset" />
      </div>
    </div>
  );
}

Vertical orientation#

orientation="vertical" renders a <div> with role="separator" and aria-orientation="vertical". Inside a flex row, flexItem stretches it to the height of the row.

Vertical orientation open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Between icon buttons</span>
        <div className="demo-row" role="toolbar" aria-label="Text formatting">
          <IconButton icon="format_bold" aria-label="Bold" />
          <IconButton icon="format_italic" aria-label="Italic" />
          <Divider orientation="vertical" flexItem />
          <IconButton icon="format_align_left" aria-label="Align left" />
          <IconButton icon="format_align_center" aria-label="Center" />
          <IconButton icon="format_align_right" aria-label="Align right" />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Between text</span>
        <div className="demo-row">
          <span>Home</span>
          <Divider orientation="vertical" />
          <span>Products</span>
          <Divider orientation="vertical" />
          <span>Contact</span>
        </div>
      </div>
    </div>
  );
}

With text#

The children become the text of the divider (wrapped in .mtx-divider__text). textAlign moves it to left or right; it is centered by default.

With text open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Centered (children)</span>
        <Divider>CENTER</Divider>
      </div>
      <div className="demo-group">
        <span className="demo-label">Left (textAlign="left")</span>
        <Divider textAlign="left">LEFT</Divider>
      </div>
      <div className="demo-group">
        <span className="demo-label">Right (textAlign="right")</span>
        <Divider textAlign="right">RIGHT</Divider>
      </div>
    </div>
  );
}

In lists#

Use component="li" to keep the HTML of a list valid. Like vanilla, the <li> keeps its list item role (a list cannot contain role="separator") and, when empty, it is hidden from screen readers with aria-hidden="true". inset lines the line up with the text. Alternatively, divider on each ListItem draws a bottom border.

In lists open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';
import { List, ListItem } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Inset divider between items</span>
        <Paper variant="outlined">
          <List aria-label="Mailbox">
            <ListItem icon="inbox">Inbox</ListItem>
            <Divider component="li" variant="inset" />
            <ListItem icon="drafts">Drafts</ListItem>
            <Divider component="li" variant="inset" />
            <ListItem icon="send">Sent</ListItem>
          </List>
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">divider on the items</span>
        <Paper variant="outlined">
          <List aria-label="Folders">
            <ListItem icon="folder" divider>
              Documents
            </ListItem>
            <ListItem icon="image" divider>
              Photos
            </ListItem>
            <ListItem icon="videocam">Videos</ListItem>
          </List>
        </Paper>
      </div>
    </div>
  );
}

  return (
    <div className="demo-panel">
      <div className="demo-stack demo-fixed-width">

Grid layout#

Metrics in a grid with a divider between the figure and its description.

Grid layout open_in_new
import { Divider } from '@rubenchodev/materix-react/components/divider';
import { Grid } from '@rubenchodev/materix-react/components/grid';
import { Paper } from '@rubenchodev/materix-react/components/paper';

const metrics = [
  { value: '1,284', label: 'Orders this month' },
  { value: '96%', label: 'On-time deliveries' },
  { value: '4.8', label: 'Average rating' },
];

export default function Demo() {
  return (
    <Grid container spacing={2}>
      {metrics.map(({ value, label }) => (
        <Grid key={label} xs={12} sm={4}>
          <Paper variant="outlined">
            <div className="demo-panel">
              <strong>{value}</strong>
              <Divider className="demo-wide" />
              <span>{label}</span>
            </div>
          </Paper>
        </Grid>
      ))}
    </Grid>
  );
}

Programmatic usage#

Dividers are rendered from state like any other element; there is nothing to initialize.

Programmatic usage open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Divider } from '@rubenchodev/materix-react/components/divider';

export default function Demo() {
  const [count, setCount] = useState(0);
  const blocks = Array.from({ length: count }, (_, i) => i + 1);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="outlined" onClick={() => setCount((n) => n + 1)}>
          Add divider with text
        </Button>
        <Button variant="text" onClick={() => setCount(0)}>
          Clear
        </Button>
      </div>
      <div className="demo-stack">
        {blocks.map((n) => (
          <Divider key={n} textAlign={n % 2 === 0 ? 'left' : 'center'}>
            Block {n}
          </Divider>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {blocks
          .map((n) => `<Divider${n % 2 === 0 ? ' textAlign="left"' : ''}>Block ${n}</Divider> → role="separator"`)
          .join('\n')}
      </pre>
    </div>
  );
}

API#

Props#

PropTypeDefaultDescription
orientation'horizontal' | 'vertical''horizontal'vertical adds .mtx-divider--vertical and aria-orientation="vertical".
variant'fullWidth' | 'middle' | 'inset''fullWidth'Adds .mtx-divider--middle or .mtx-divider--inset.
flexItembooleanfalseAdds .mtx-divider--flex-item (stretches in a flex row).
textAlign'center' | 'left' | 'right''center'Text position; adds .mtx-divider--text-{left|right}.
childrenReactNode—Divider text: adds .mtx-divider--text and the .mtx-divider__text span.
componentElementType'hr' ('div' if vertical or with text)Root element. 'li' keeps the list item role.
classNamestring—Merged with the component classes.
refRef<HTMLElement>—Points to the root element.

Any other prop (role, aria-*, style, data-*…) is forwarded to the root element; your own role or aria-orientation take precedence.

Callbacks#

Divider emits no events.

CSS classes#

ClassDescription
.mtx-divider1px line in --mtx-color-divider.
.mtx-divider--verticalVertical line that stretches to the height of its row.
.mtx-divider--middle / .mtx-divider--inset16px margin on both sides / 72px on the left.
.mtx-divider--flex-itemalign-self: stretch with automatic height.
.mtx-divider--textLine — text — line layout.
.mtx-divider--text-left / .mtx-divider--text-rightText aligned to one side.
.mtx-divider__textText container.

Accessibility#

  • <hr> has the implicit separator role; it is the default for horizontal dividers without text.
  • On a <div> (vertical or with text) the component adds role="separator" unless you pass your own role (for example role="presentation" for a purely decorative divider), and aria-orientation="vertical" on vertical dividers, as MUI does.
  • With component="li" the divider keeps the list item role; if it is empty it gets aria-hidden="true", and with text it stays readable.
  • The text of a divider is readable content: write it meaningfully (“or”, “Section 2”), not with symbols.

data-orientation="vertical"orientation="vertical"
data-variant="middle|inset"variant="middle|inset"
data-flex-itemflexItem
