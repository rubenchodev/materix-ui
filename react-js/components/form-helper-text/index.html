Form Helper Text

Helper and error text below a form control, plus FormControl and FormLabel to share error, disabled and required state with the controls inside.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { FormHelperText, FormControl, FormLabel, useFormControl } from '@rubenchodev/materix-react';

FormHelperText is the caption below a control that explains what to enter or why the value is invalid. FormControl groups a label, a control and its helper text and shares error, disabled and required through a context, so every piece updates together; FormLabel is the group label. Checkbox, Switch and RadioGroup already render these pieces for you with helperText and error; use them directly to compose your own layouts or to build new controls with useFormControl().

lightbulb

When to compose it yourself

For a single control, prefer the helperText/error props of Checkbox, Switch or Radio. Reach for FormControl when several controls share one label and one message, or when you write a custom control.

import '@rubenchodev/materix-ui/base.css';
import { FormControl, FormHelperText, FormLabel } from '@rubenchodev/materix-react';

<FormControl error>
  <FormLabel>Consent</FormLabel>
  {/* control */}
  <FormHelperText>You must accept the terms.</FormHelperText>
</FormControl>

Basic usage#

FormHelperText renders a <p class="mtx-form-helper-text"> with an auto-generated id. error turns it red; disabled dims it and sets aria-disabled.

Basic usage open_in_new
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { FormControl, FormHelperText } from '@rubenchodev/materix-react/components/form-helper-text';

export default function Demo() {
  return (
    <div className="demo-grid-3">
      <div className="demo-group">
        <span className="demo-label">Helper text</span>
        <FormControl>
          <Checkbox label="Email me the receipt" defaultChecked />
          <FormHelperText>We will never share your email.</FormHelperText>
        </FormControl>
      </div>
      <div className="demo-group">
        <span className="demo-label">Error · error</span>
        <FormControl error>
          <Checkbox label="I accept the terms" required />
          <FormHelperText>This field is required.</FormHelperText>
        </FormControl>
      </div>
      <div className="demo-group">
        <span className="demo-label">Disabled · disabled</span>
        <FormControl disabled>
          <Checkbox label="Priority support" />
          <FormHelperText>Not available on your plan.</FormHelperText>
        </FormControl>
      </div>
    </div>
  );
}

FormControl and FormLabel#

Inside a FormControl, the label, the helper text and the controls inherit error and disabled. Checkbox, Switch and RadioGroup also link every FormHelperText of the group with aria-describedby.

FormControl and FormLabel open_in_new
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { Switch } from '@rubenchodev/materix-react/components/switch';
import { FormControl, FormHelperText, FormLabel } from '@rubenchodev/materix-react/components/form-helper-text';

export default function Demo() {
  return (
    <div className="demo-grid-3">
      <FormControl role="group" aria-labelledby="fht-default-label">
        <FormLabel id="fht-default-label">Newsletter</FormLabel>
        <Checkbox label="Weekly digest" defaultChecked />
        <FormHelperText>One email a week.</FormHelperText>
      </FormControl>
      <FormControl role="group" aria-labelledby="fht-error-label" error>
        <FormLabel id="fht-error-label">Consent</FormLabel>
        <Checkbox label="I accept the terms" />
        <FormHelperText>You must accept the terms.</FormHelperText>
      </FormControl>
      <FormControl role="group" aria-labelledby="fht-disabled-label" aria-disabled="true" disabled>
        <FormLabel id="fht-disabled-label">Security</FormLabel>
        <Switch label="Security alerts" defaultChecked />
        <FormHelperText>Managed by your organization.</FormHelperText>
      </FormControl>
    </div>
  );
}

Contained#

contained adds a 14px inline margin so the text lines up with the content of an outlined or filled text field.

Contained open_in_new
import { FormControl, FormHelperText } from '@rubenchodev/materix-react/components/form-helper-text';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Default · aligned with the field edge</span>
        <FormControl>
          <TextField label="Company" variant="standard" />
          <FormHelperText>As it appears on your invoices.</FormHelperText>
        </FormControl>
      </div>
      <div className="demo-group">
        <span className="demo-label">contained · 14px inset (outlined/filled fields)</span>
        <FormControl>
          <TextField label="Company" variant="outlined" />
          <FormHelperText contained>Aligned with the text of the outlined field.</FormHelperText>
        </FormControl>
      </div>
    </div>
  );
}

Custom control with useFormControl#

useFormControl() returns the closest FormControl state (or undefined): error, disabled, required and helperTextIds, the ids of the helper texts with content, ready for aria-describedby.

Custom control with useFormControl open_in_new
import { useState } from 'react';
import { FormControl, FormHelperText, FormLabel, useFormControl } from '@rubenchodev/materix-react/components/form-helper-text';
import { Switch } from '@rubenchodev/materix-react/components/switch';
import { TextField } from '@rubenchodev/materix-react/components/text-field';
import { Typography } from '@rubenchodev/materix-react/components/typography';

/** Indicador propio que lee el estado del FormControl más cercano. */
function FieldStatus() {
  const formControl = useFormControl();
  const label = formControl?.disabled ? 'Disabled' : formControl?.error ? 'Invalid' : 'Valid';
  return (
    <Typography variant="caption" className="mtx-mt-1" color={formControl?.error ? 'error' : 'text-secondary'}>
      Status: {label} · describedby: {formControl?.helperTextIds.length ?? 0} helper(s)
    </Typography>
  );
}

export default function Demo() {
  const [value, setValue] = useState('');
  const [disabled, setDisabled] = useState(false);
  const error = value.length > 0 && value.length < 3;
  return (
    <div className="demo-stack">
      <Switch label="Disable the group" checked={disabled} onChange={(_, next) => setDisabled(next)} />
      <FormControl error={error} disabled={disabled} required>
        <FormLabel>Account</FormLabel>
        <TextField label="Username" value={value} onChange={(_, next) => setValue(next)} />
        <FormHelperText contained>{error ? 'At least 3 characters.' : 'Letters and numbers only.'}</FormHelperText>
        <FieldStatus />
      </FormControl>
    </div>
  );
}

API reference#

FormHelperText props#

PropTypeDefaultDescription
errorbooleanfrom FormControlError color (--error).
disabledbooleanfrom FormControlDims the text (--disabled + aria-disabled). Inherited only as aria-disabled.
containedbooleanfalseInline margin of an outlined/filled field (--contained).
idstringautoId used by aria-describedby.
refRef<HTMLParagraphElement>—Ref to the <p>.

FormControl props#

PropTypeDefaultDescription
errorbooleanfalseError state shared with the children (.mtx-form-control--error).
disabledbooleanfalseDisabled state shared with the children (.mtx-form-control--disabled).
requiredbooleanfalseRequired state shared with the children.
refRef<HTMLDivElement>—Ref to the <div>.

FormLabel props#

PropTypeDefaultDescription
requiredbooleanfrom FormControlAppends an asterisk ( *, aria-hidden).
errorbooleanfrom FormControlError color.
disabledbooleanfrom FormControlDimmed color.

Renders .mtx-form-label (primary color on focus within). Vanilla has no CSS for the asterisk nor for a standalone label in error/disabled state, so the asterisk is a plain <span aria-hidden="true"> and the state colors are applied inline with the --mtx-color-error-text / --mtx-color-text-disabled tokens.

Differences with MUI: FormControl has no fullWidth, margin, variant, size or focused props, because vanilla has no CSS for them; use layout utilities around it. The controls of this library stretch their own wrapper when they are fullWidth.

useFormControl()#

Returns { error, disabled, required, helperTextIds, registerHelperText } | undefined. registerHelperText(id) is used by FormHelperText and returns the unregister function. Only group-level helpers are registered: the helperText of Checkbox, Switch or RadioGroup describes only its own control, and a control with its own helperText does not link the group helpers.

className, style and other attributes go to the root element of each component.

CSS classes#

ClassElement
.mtx-form-controlWrapper (--error, --disabled).
.mtx-form-labelGroup label.
.mtx-form-helper-textHelper text (--error, --contained, --disabled).

Accessibility#

  • The helper text is linked to the control with aria-describedby, so it is read after the control name without being part of it.
  • Error state is conveyed with aria-invalid="true" on the control, not by color alone: put the reason in the helper text.
  • Disabled helper texts carry aria-disabled="true" so their dimmed color is treated as disabled content.
  • Name groups of controls with FormLabel + aria-labelledby (and role="group" on the FormControl).
  • A standalone Radio inside a FormControl inherits aria-invalid and the helper texts in aria-describedby, like Checkbox and Switch; inside a RadioGroup both go on the radiogroup.
