CSS Baseline

Materix global baseline: Roboto typography, theme background and text colors, box-sizing, visible focus and a light or dark color-scheme.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { CssBaseline, ScopedCssBaseline } from '@rubenchodev/materix-react';

CssBaseline adds the mtx-root class to <body>, which enables the Materix style baseline: Roboto typography at 16px, the theme’s background and text colors, box-sizing: border-box across the whole tree, an accessible focus ring and a color-scheme consistent with the light or dark theme. It also imports @rubenchodev/materix-ui/base.css (tokens + baseline). Render it once at the top of your app; use ScopedCssBaseline instead when Materix lives alongside other styles. It isn’t a full reset: it doesn’t remove heading or list margins, nor does it normalize forms.

import { CssBaseline, ScopedCssBaseline } from '@rubenchodev/materix-react';
// or only this component
import { CssBaseline } from '@rubenchodev/materix-react/components/css-baseline';

Basic usage#

Render <CssBaseline /> once, next to your app. It adds mtx-root to <body> in an effect (SSR-safe) and removes it on unmount, unless the class was already there. Several instances are reference-counted: the class stays until the last one unmounts. Children, if any, are rendered as is.

export function App() {
  return (
    <>
      <CssBaseline />
      <Main />
    </>
  );
}
Basic usage open_in_new
import { useEffect, useState } from 'react';
import { CssBaseline } from '@rubenchodev/materix-react/components/css-baseline';

export default function Demo() {
  const [bodyClass, setBodyClass] = useState('');

  useEffect(() => {
    const read = () => setBodyClass(document.body.className);
    read();
    const observer = new MutationObserver(read);
    observer.observe(document.body, { attributes: true, attributeFilter: ['class'] });
    return () => observer.disconnect();
  }, []);

  return (
    <div className="demo-group">
      <CssBaseline />
      <span className="demo-label">Current body classes</span>
      <p className="demo-status" aria-live="polite">
        class=&quot;{bodyClass}&quot;
      </p>
    </div>
  );
}

Equivalence

<CssBaseline />, <body data-mtx="css-baseline"> and <body class="mtx-root"> are equivalent. Writing the class in your HTML template (or using MaterixProvider, which renders a .mtx-root container) avoids a visual jump before React hydrates.

What it applies#

All rules come from base.css and are scoped to .mtx-root and its descendants. The reduced-motion rule only touches Materix elements (mtx-* classes).

SelectorPropertiesEffect
.mtx-root, .mtx-root *, ::before, ::afterbox-sizing: border-boxPadding and border are included in the width.
body.mtx-rootmargin: 0Removes the margin of the <body>. A scoped container keeps its own margin.
.mtx-rootfont-family: var(--mtx-font-family); font-weight: 400; font-size: 1rem; line-height: 1.5Base Roboto typography (equivalent to body1).
.mtx-rootcolor: var(--mtx-color-text-primary); background-color: var(--mtx-color-background-default)Text and background colors of the active theme.
.mtx-rootcolor-scheme: lightLight native controls, scrollbars and autofill.
.mtx-root[data-mtx-theme='dark'], [data-mtx-theme='dark'] .mtx-rootcolor-scheme: darkDark native controls when the theme is dark.
.mtx-root-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscaleFont smoothing on macOS.
.mtx-root strong, .mtx-root bfont-weight: 700True bold with Roboto 700.
.mtx-root :focus-visible (except input, textarea, select and .mtx-menu)outline: var(--mtx-focus-ring-width) solid var(--mtx-focus-ring-color); outline-offset: 2pxFocus ring for keyboard only.
.mtx-root .mtx-menu-itemoutline: none !importantMenu items indicate focus with their background.
@media (prefers-reduced-motion: reduce) → [class*='mtx-']Animations and transitions set to 0.01msRespects the reduced-motion preference on Materix elements only.
@media print → .mtx-rootbackground-color: #fff; color-scheme: lightPrinting on a white background.

Box sizing#

Inside mtx-root everything uses box-sizing: border-box: a box with width: 100%, 16px of padding and a 4px border does not overflow its container.

Box sizing open_in_new
import './demo.css';
import { ScopedCssBaseline } from '@rubenchodev/materix-react/components/css-baseline';

export default function Demo() {
  return (
    <ScopedCssBaseline className="demo-group">
      <span className="demo-label">width 100% + padding 16px + border 4px</span>
      <div className="demo-css-baseline-sizing">Takes exactly the available width.</div>
    </ScopedCssBaseline>
  );
}

Visible focus#

Use Tab: buttons, links and focusable elements show the --mtx-focus-ring-color ring only when navigating with the keyboard. Text fields are excluded because their border already shows focus.

Visible focus open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';
import { ScopedCssBaseline } from '@rubenchodev/materix-react/components/css-baseline';
import { Link } from '@rubenchodev/materix-react/components/link';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  return (
    <ScopedCssBaseline className="demo-row">
      <Button variant="outlined">Button</Button>
      <Link href="#focus">Link</Link>
      <TextField label="Field" variant="outlined" size="small" type="text" />
    </ScopedCssBaseline>
  );
}

Light and dark theme#

The theme is chosen with data-mtx-theme on <html> (or on any ancestor), usually through ThemeProvider / MaterixProvider (see Theming). The tokens change and .mtx-root adopts the matching background, text and color-scheme, so native controls (<input type="date">, scrollbars) also look dark. Switch this page’s theme to see it.

Color scheme open_in_new
import { useEffect, useRef, useState } from 'react';
import { ScopedCssBaseline } from '@rubenchodev/materix-react/components/css-baseline';

export default function Demo() {
  const ref = useRef<HTMLDivElement>(null);
  const [scheme, setScheme] = useState('');

  useEffect(() => {
    const read = () => setScheme(ref.current ? getComputedStyle(ref.current).colorScheme : '');
    read();
    const observer = new MutationObserver(read);
    observer.observe(document.documentElement, { attributes: true, attributeFilter: ['data-mtx-theme'] });
    return () => observer.disconnect();
  }, []);

  return (
    <ScopedCssBaseline ref={ref} className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Native controls</span>
        <div className="demo-row">
          <input type="date" aria-label="Native date" />
          <input type="color" aria-label="Native color" defaultValue="#4818d0" />
          <select aria-label="Native select">
            <option>Native option</option>
            <option>Another option</option>
          </select>
          <input type="range" aria-label="Native range" />
        </div>
      </div>
      <p className="demo-status" aria-live="polite">
        color-scheme: {scheme}
      </p>
    </ScopedCssBaseline>
  );
}

Scoped baseline#

ScopedCssBaseline renders a .mtx-root container (a div, or the element given in component) instead of touching <body>, for example when embedding a Materix widget in a page with other styles. Only that subtree receives the typography, colors and box-sizing.

Scoped baseline open_in_new
import './demo.css';
import { ScopedCssBaseline } from '@rubenchodev/materix-react/components/css-baseline';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Container without baseline</span>
        <div className="demo-css-baseline-box demo-css-baseline-raw">
          <h3>External widget</h3>
          <p>Inherits the host site styles.</p>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">&lt;ScopedCssBaseline component=&quot;section&quot;&gt;</span>
        <ScopedCssBaseline component="section" className="demo-css-baseline-box">
          <Typography variant="h6" component="h3" gutterBottom>
            Materix widget
          </Typography>
          <Typography variant="body2">Theme typography and colors inside the container.</Typography>
        </ScopedCssBaseline>
      </div>
    </div>
  );
}
info

Scope

A scoped container keeps its margin (only body.mtx-root gets margin: 0). The prefers-reduced-motion rule only reduces the animations of elements with mtx-* classes; the rest of the page keeps its own.

Apply at runtime#

In vanilla, Materix.init(el, 'css-baseline') marks a container created at runtime. In React, render ScopedCssBaseline conditionally.

Apply at runtime open_in_new
import { useEffect, useRef, useState } from 'react';
import './demo.css';
import { Button } from '@rubenchodev/materix-react/components/button';
import { ScopedCssBaseline } from '@rubenchodev/materix-react/components/css-baseline';

export default function Demo() {
  const [applied, setApplied] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!applied || !ref.current) return;
    const el = ref.current;
    setLog((lines) => [...lines.slice(-5), `apply → class="${el.className}" · font-family: ${getComputedStyle(el).fontFamily}`]);
  }, [applied]);

  const toggleTheme = () => {
    const root = document.documentElement;
    const next = root.getAttribute('data-mtx-theme') === 'dark' ? 'light' : 'dark';
    root.setAttribute('data-mtx-theme', next);
    setLog((lines) => [...lines.slice(-5), `data-mtx-theme="${next}" → color-scheme: ${getComputedStyle(document.body).colorScheme}`]);
  };

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" aria-pressed={applied} onClick={() => setApplied((a) => !a)}>
          {applied ? 'Remove from the box' : 'Apply to the box'}
        </Button>
        <Button variant="outlined" onClick={toggleTheme}>
          Toggle theme
        </Button>
      </div>
      {applied ? (
        <ScopedCssBaseline ref={ref} className="demo-css-baseline-box">
          <p>Box with the baseline applied from React.</p>
        </ScopedCssBaseline>
      ) : (
        <div className="demo-css-baseline-box demo-css-baseline-raw">
          <p>Box created without baseline. Click &quot;Apply to the box&quot;.</p>
        </div>
      )}
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

API reference#

CssBaseline props#

PropTypeDefaultDescription
target'body' | 'html''body'Global element that receives mtx-root.
childrenReactNode—Rendered as is (optional).

CssBaseline renders no element of its own, so it takes no ref or className.

ScopedCssBaseline props#

PropTypeDefaultDescription
componentElementType'div'Root element or component (section, main…).
classNamestring—Merged with mtx-root.
refRef<HTMLElement>—Points to the root element.

Any other prop is forwarded to the root element.

Equivalence with vanilla#

VanillaReact
<body data-mtx="css-baseline"><CssBaseline />
<div data-mtx="css-baseline"><ScopedCssBaseline>
<section data-mtx="css-baseline"><ScopedCssBaseline component="section">
Materix.init(el, 'css-baseline')Render ScopedCssBaseline conditionally.
data-mtx-theme on an ancestorSame attribute, usually managed by ThemeProvider.

CSS classes#

ClassDescription
mtx-rootEnables the baseline described in “What it applies” for the element and its descendants.

Callbacks#

CssBaseline and ScopedCssBaseline have no events.

CSS variables#

VariableUsage
--mtx-font-familyBase font family.
--mtx-color-text-primaryText color.
--mtx-color-background-defaultBackground color.
--mtx-focus-ring-width, --mtx-focus-ring-color:focus-visible ring.

Accessibility#

  • The focus ring only appears with the keyboard (:focus-visible) and has a 2px offset so it doesn’t cover the content. Text fields are excluded because they already indicate focus with their border.
  • color-scheme makes native controls and scrollbars respect the contrast of the dark theme.
  • With prefers-reduced-motion: reduce, the animations and transitions of Materix elements are reduced to 0.01ms.
  • The baseline doesn’t change semantics: keep using real headings, lists and landmarks.
