Link

MUI-styled text link on a native <a>: palette colors and three underline modes, without losing semantics.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Link } from '@rubenchodev/materix-react';

Link applies MUI’s link style (primary color, always underlined by default) to a native <a>, to a <button> for actions that don’t navigate, or to your router’s link component. It inherits the typography of the surrounding text.

import { Link } from '@rubenchodev/materix-react';
// or only this component:
import { Link } from '@rubenchodev/materix-react/components/link';

Basic usage#

<Link href="…"> renders an <a class="mtx-link">. With no other props it uses the primary color and is always underlined (MUI v5 default), so it never relies on color alone.

Basic usage open_in_new
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  return (
    <div className="demo-row">
      <Link href="#basic">View documentation</Link>
      <Link href="#basic" color="secondary">
        Services
      </Link>
      <Link href="#basic" underline="hover">
        Terms
      </Link>
    </div>
  );
}

Underline#

The link’s variant is its underline: underline="always|hover|none". always is the default: a soft underline (40% of the color) that becomes solid on hover. Use hover or none only for links outside running text (navigation, lists, footers).

Underline open_in_new
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">always · default</span>
        <div className="demo-row">
          <Link href="#underline">Always underlined</Link>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">hover</span>
        <div className="demo-row">
          <Link href="#underline" underline="hover">
            Underlined on hover
          </Link>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">none</span>
        <div className="demo-row">
          <Link href="#underline" underline="none">
            Never underlined
          </Link>
        </div>
      </div>
    </div>
  );
}

Colors#

color accepts the six palette colors, the text colors (text-primary, text-secondary) and inherit, which takes the color of the surrounding text (here, inside an Alert).

Colors open_in_new
import { Alert } from '@rubenchodev/materix-react/components/alert';
import { Link, type LinkColor } from '@rubenchodev/materix-react/components/link';

const palette: LinkColor[] = ['primary', 'secondary', 'error', 'warning', 'info', 'success'];

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Palette</span>
        <div className="demo-row">
          {palette.map((color) => (
            <Link key={color} href="#colors" color={color === 'primary' ? undefined : color}>
              {color}
            </Link>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Text</span>
        <div className="demo-row">
          <Link href="#colors" color="text-primary">
            text-primary
          </Link>
          <Link href="#colors" color="text-secondary">
            text-secondary
          </Link>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">inherit · inside an alert</span>
        <Alert severity="info">
          A new version is available.{' '}
          <Link href="#colors" color="inherit" underline="always">
            See what&apos;s new
          </Link>
        </Alert>
      </div>
    </div>
  );
}

States#

Hover to see the underline and use Tab to see the focus ring. disabled disables the link: on <a> it sets aria-disabled="true", removes it from the tab order and cancels clicks; on <button> it uses the native disabled attribute.

States open_in_new
import { useState } from 'react';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { Link } from '@rubenchodev/materix-react/components/link';

export default function Demo() {
  const [disabled, setDisabled] = useState(true);
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Normal · hover · focus-visible</span>
        <div className="demo-row">
          <Link href="#states">Normal link</Link>
          <Link href="#states" underline="hover">
            Underlined on hover
          </Link>
          <Link href="#states" color="text-secondary">
            Secondary link
          </Link>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Disabled · disabled</span>
        <div className="demo-row">
          <Link href="#states" disabled={disabled}>
            Disabled link
          </Link>
          <Link component="button" disabled={disabled}>
            Disabled link button
          </Link>
          <Checkbox label="disabled" checked={disabled} onChange={(_, checked) => setDisabled(checked)} />
        </div>
      </div>
    </div>
  );
}

As a button#

For actions that don’t navigate but should look like a link inside text, use component="button" (no native background, border or padding, and the typography of the surrounding text). Without type, it gets type="button" so it doesn’t submit forms.

As a button open_in_new
import { useState } from 'react';
import { Link } from '@rubenchodev/materix-react/components/link';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [sent, setSent] = useState(0);
  return (
    <div className="demo-group">
      <span className="demo-label">Inside a body2 and a body1 paragraph</span>
      <Typography variant="body2">
        Didn&apos;t get the code?{' '}
        <Link component="button" onClick={() => setSent((n) => n + 1)}>
          Resend code
        </Link>
        {sent > 0 ? <span role="status"> · Sent {sent}×</span> : null}
      </Typography>
      <Typography variant="body1">
        Forgot your password?{' '}
        <Link component="button" underline="always">
          Recover it here
        </Link>
      </Typography>
    </div>
  );
}

In a paragraph#

Inside running text keep the default underline (always) so the link doesn’t rely on color alone (WCAG 1.4.1). The link inherits the paragraph’s typography, so it fits any variant.

In a paragraph open_in_new
import { Link } from '@rubenchodev/materix-react/components/link';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-group">
      <span className="demo-label">body2 paragraph</span>
      <Typography variant="body2" className="demo-wide">
        By creating an account you accept the <Link href="#in-paragraph">terms of service</Link> and the{' '}
        <Link href="#in-paragraph">privacy policy</Link>. You can change your preferences at any time from the settings panel.
      </Typography>
    </div>
  );
}

External links#

With target="_blank" always add rel="noopener noreferrer" and announce the change of context in the visible text or in an aria-label that contains it.

External links open_in_new

Programmatic usage and router links#

Links are created from state (there are no methods). component renders the Link style on any component: React Router’s Link, Next.js Link, etc. Their props (to, prefetch…) are forwarded.

Programmatic usage open_in_new
import { forwardRef, useState, type AnchorHTMLAttributes } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Link, type LinkColor } from '@rubenchodev/materix-react/components/link';

/** Simula el `Link` de un router: recibe `to` en lugar de `href`. */
const RouterLink = forwardRef<HTMLAnchorElement, AnchorHTMLAttributes<HTMLAnchorElement> & { to: string }>(
  function RouterLink({ to, ...props }, ref) {
    return <a ref={ref} href={`#${to}`} {...props} />;
  },
);

interface DynamicLink {
  id: number;
  color: LinkColor;
  underline?: 'always';
}

export default function Demo() {
  const [links, setLinks] = useState<DynamicLink[]>([]);
  const add = (color: LinkColor, underline?: 'always') =>
    setLinks((prev) => [...prev, { id: prev.length + 1, color, underline }]);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="outlined" onClick={() => add('primary')}>
          Create primary link
        </Button>
        <Button variant="outlined" onClick={() => add('error', 'always')}>
          Create error link · always
        </Button>
        <Button variant="text" onClick={() => setLinks([])}>
          Clear
        </Button>
      </div>
      <div className="demo-row" aria-live="polite">
        <Link component={RouterLink} to="/dashboard">
          Router link
        </Link>
        {links.map(({ id, color, underline }) => (
          <Link key={id} href="#programmatic" color={color} underline={underline}>
            Dynamic link {id}
          </Link>
        ))}
      </div>
      <pre className="demo-log">
        {links
          .map(({ id, color, underline }) => `Dynamic link ${id} → mtx-link mtx-link--${color} mtx-link--color-${color}${underline ? ` mtx-link--underline-${underline}` : ''}`)
          .join('\n')}
      </pre>
    </div>
  );
}
import { Link as RouterLink } from 'react-router-dom';

<Link component={RouterLink} to="/dashboard">Dashboard</Link>

API#

Props#

PropTypeDefaultDescription
color'primary' | 'secondary' | 'error' | 'warning' | 'info' | 'success' | 'text-primary' | 'text-secondary' | 'inherit'primary (CSS)Adds .mtx-link--{color} and .mtx-link--color-{color}.
underline'always' | 'hover' | 'none'always (CSS)Adds .mtx-link--underline-{mode}.
disabledbooleanfalse<button>: disabled. Others: aria-disabled="true", tabIndex={-1} and clicks cancelled.
componentElementType'a'Root element or component ('button', a router link…).
classNamestring—Merged with the component classes.
refRef<HTMLElement>—Points to the root element.

Any other prop (href, target, rel, onClick, aria-*…) is forwarded to the root element.

Callbacks#

CallbackDescription
onClick(event)Native click. It is not called while disabled.

CSS classes#

ClassDescription
.mtx-linkBase: primary color, always underline, focus ring.
.mtx-link--{color} / .mtx-link--color-{color}Link color.
.mtx-link--underline-{always|hover|none}Underline mode.
button.mtx-linkRemoves the native button look.

Accessibility#

  • Use <a href> for navigation: it is focusable, activates with Enter and is announced as a link. For an action without a destination inside text use component="button"; for prominent actions, Button.
  • The text must describe the destination (“Read the privacy policy”), not “click here”.
  • Inside paragraphs keep the always underline (WCAG 1.4.1, axe link-in-text-block).
  • A disabled <a> keeps its href but is removed from the tab order and announced as disabled.
  • Keyboard focus shows a --mtx-focus-ring-width ring with a 2px offset.
KeyAction
Tab / Shift+TabMoves focus to the next or previous link.
EnterFollows the link (or runs the action with component="button").
SpaceRuns the action with component="button".

Vanilla equivalence#

Vanilla (data-*)React
<a data-mtx="link" href="/"><Link href="/">
<button data-mtx="link"><Link component="button">
data-color="secondary"color="secondary"
data-underline="hover"underline="hover"
data-disabled / link.disable() / link.enable()disabled (controlled by the prop)

The rendered DOM (classes, type, disabled, aria-disabled and tabindex) is identical to the vanilla component after initialization.
