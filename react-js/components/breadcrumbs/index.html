Breadcrumbs

Hierarchical navigation trail that shows where the user is and lets them jump back to any parent level.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Breadcrumbs, Link } from '@rubenchodev/materix-react';

Breadcrumbs renders the path from the root of the site or app to the current page, like MUI’s Breadcrumbs: a <nav> with an ordered list, separators hidden from assistive technologies and the last item marked with aria-current="page". Use it in hierarchies of three or more levels (catalogs, documentation, file managers). Do not use it as primary navigation or for linear flows.

Import#

import { Breadcrumbs, Link } from '@rubenchodev/materix-react';

Basic usage#

Pass Links and the current page as children. Each child goes into an <li>, links get color="inherit" and underline on hover (unless they set their own), plain text becomes a <span class="mtx-breadcrumbs__text">, and the last item is marked as the current page. Native <a> and <button> children are converted into Links.

Basic usage open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';

export const description = {
  en: "Links and the current page as children: links get `color=\"inherit\"` and underline on hover, separators are added and the last item gets `aria-current=\"page\"`.",
  es: "Enlaces y la página actual como hijos: los enlaces reciben `color=\"inherit\"` y subrayado en hover, se añaden los separadores y el último ítem recibe `aria-current=\"page\"`.",
};

export default function Demo() {
  return (
    <div className="demo-stack">
      <Breadcrumbs>
        <Link href="#">Home</Link>
        <Link href="#">Catalog</Link>
        Accessories
      </Breadcrumbs>
    </div>
  );
}

Current page as a link#

If the last item must stay a link, set aria-current="page" yourself: the component respects it and does not mark any other item.

Current page as a link open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';

export const description = {
  en: "Set `aria-current=\"page\"` yourself to keep the current page as a link; no other item is marked.",
  es: "Pon tú `aria-current=\"page\"` para mantener la página actual como enlace; no se marca ningún otro ítem.",
};

export default function Demo() {
  return (
    <div className="demo-stack">
      <Breadcrumbs>
        <Link href="#">Home</Link>
        <Link href="#">Catalog</Link>
        <Link href="#" aria-current="page">
          Headphones
        </Link>
      </Breadcrumbs>
    </div>
  );
}

Separators#

separator accepts any text (default /), any node, or the name of a Material icon: a string made of lowercase letters, digits and underscores, with three or more characters (navigate_next, chevron_right), is rendered as an icon.

Separators open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';

export const description = {
  en: "`separator` accepts text, a node or a Material icon name such as `navigate_next`.",
  es: "`separator` acepta texto, un nodo o un nombre de icono Material como `navigate_next`.",
};

const SEPARATORS = ['›', '-', 'navigate_next'];

export default function Demo() {
  return (
    <div className="demo-stack">
      {SEPARATORS.map((separator) => (
        <Breadcrumbs key={separator} separator={separator} aria-label={`breadcrumb (${separator})`}>
          <Link href="#">Home</Link>
          <Link href="#">Catalog</Link>
          Accessories
        </Breadcrumbs>
      ))}
    </div>
  );
}

With icons#

data-icon on a child (or icon in items) adds a decorative Material icon before the label. As in MUI, the icon sits outside the text flow: only the label is underlined on hover.

With icons open_in_new

  es: "`data-icon` en un hijo, o `icon` en `items`, añade un icono decorativo; en hover solo se subraya la etiqueta.",
};

export default function Demo() {
  return (
    <div className="demo-stack">
      <Breadcrumbs>
        <Link href="#" data-icon="home">
          Home
        </Link>
        <Link href="#" data-icon="whatshot">
          Projects
        </Link>
        <span data-icon="grain">Website redesign</span>
      </Breadcrumbs>

        aria-label="breadcrumb (items)"
        separator="chevron_right"
        items={[
          { label: 'Home', href: '#', icon: 'home' },
          { label: 'Library', href: '#', icon: 'local_library' },

}

Collapsed breadcrumbs#

When there are more items than maxItems (8 by default), only itemsBeforeCollapse (1) and itemsAfterCollapse (1) are shown, separated by a “Show path” button. Activating it reveals the hidden items, moves focus to the first one and calls onExpand. The trail collapses again when its items change.

Collapsed breadcrumbs open_in_new
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Link } from '@rubenchodev/materix-react/components/link';

export const description = {
  en: "Above `maxItems` only `itemsBeforeCollapse` and `itemsAfterCollapse` stay visible around a \"Show path\" button that reveals the rest and moves focus.",
  es: "Por encima de `maxItems` solo quedan visibles `itemsBeforeCollapse` e `itemsAfterCollapse` alrededor de un botón \"Mostrar ruta\" que revela el resto y mueve el foco.",
};

export default function Demo() {
  return (
    <div className="demo-stack">
      <Breadcrumbs maxItems={2} aria-label="breadcrumb (maxItems 2)">
        <Link href="#">Home</Link>
        <Link href="#">Catalog</Link>
        <Link href="#">Accessories</Link>
        <Link href="#">New collection</Link>
        Belts
      </Breadcrumbs>
      <Breadcrumbs
        maxItems={4}
        itemsBeforeCollapse={2}
        itemsAfterCollapse={2}
        separator="navigate_next"
        aria-label="breadcrumb (2 + 2)"
      >
        <Link href="#">Home</Link>
        <Link href="#">Documents</Link>
        <Link href="#">2026</Link>
        <Link href="#">Accounting</Link>
        <Link href="#">Q3</Link>
        Invoices
      </Breadcrumbs>
    </div>
  );
}

Typography#

Like MUI, it uses body1 in text.secondary and the current page in text.primary. For a more compact trail, use variant="body2" (it adds the Typography class mtx-typography--body2).

  return (

From a list of items#

items describes the trail as data ({ label, href?, icon?, current?, disabled?, data? }), equivalent to vanilla’s setItems(). Items with href are Links; the current page (the last one, unless an item sets current) is text; the rest are Links on a <button>. data becomes data-* attributes.

Programmatic usage#

onNavigate(event, detail) fires when a trail link or button is activated, with { index, href, label, current, item }. Return false or call event.preventDefault() to cancel the native navigation and handle it yourself (SPA routers, folder navigation).

Programmatic usage: folder navigation open_in_new
import { useState } from 'react';
import { Breadcrumbs } from '@rubenchodev/materix-react/components/breadcrumbs';
import { Button } from '@rubenchodev/materix-react/components/button';

export const description = {
  en: "Folder navigation with `items`: `onNavigate` calls `preventDefault()` and moves to the chosen level; `onExpand` reports the collapse button.",
  es: "Navegación de carpetas con `items`: `onNavigate` llama a `preventDefault()` y va al nivel elegido; `onExpand` informa del botón de colapso.",
};

const FOLDERS = ['My Drive', 'Projects', 'Andina client', 'Deliverables', 'Q3 report'];

export default function Demo() {
  const [depth, setDepth] = useState(0);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 6));

  const items = FOLDERS.slice(0, depth + 1).map((name, index) => ({
    label: name,
    icon: index === 0 ? 'folder' : undefined,
    data: { depth: index },
  }));

  return (
    <div className="demo-stack">
      <Breadcrumbs
        separator="chevron_right"
        maxItems={4}
        items={items}
        aria-label="Folders"
        onExpand={() => write('onExpand')}
        onNavigate={(event, detail) => {
          event.preventDefault();
          setDepth(detail.index);
          write(`onNavigate → index ${detail.index} (${detail.label})`);
        }}
      />
      <div className="demo-row">
        <Button
          variant="outlined"
          disabled={depth >= FOLDERS.length - 1}
          onClick={() => {
            setDepth(depth + 1);
            write(`open "${FOLDERS[depth + 1]}"`);
          }}
        >
          Open subfolder
        </Button>
        <Button variant="text" disabled={depth === 0} onClick={() => setDepth(0)}>
          Reset
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}
<Breadcrumbs
  items={folders.map((name, index) => ({ label: name, data: { depth: index } }))}
  onNavigate={(event, detail) => {
    event.preventDefault();
    openFolder(detail.index);
  }}
/>

Accessibility#

  • <nav> landmark with aria-label="breadcrumb" (translated through i18n breadcrumbs.label; your own aria-label or aria-labelledby is kept).
  • Ordered list (<ol>): screen readers announce the number of levels.
  • Separators are <li aria-hidden="true">, so they are not read.
  • The current page has aria-current="page".
  • The collapse button is a real <button> with the translated label “Show path”; after expanding, focus moves to the first revealed item so it is not lost.
