Tooltip

Short informative label shown on hover, keyboard focus or long press. Wrap any element with <Tooltip title>.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Tooltip } from '@rubenchodev/materix-react';

A Tooltip shows a short text label that identifies or explains an element when the user hovers over it, focuses it with the keyboard or long-presses it on a touch screen, just like MUI’s Tooltip. It is ideal for icon-only buttons and toolbars. Do not put essential information or interactive content in it (links, buttons): for persistent messages use a helper text or an Alert.

import { Tooltip } from '@rubenchodev/materix-react';
// or only this component:
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';

Basic usage#

Wrap a single child with <Tooltip title="…">. The child receives the merged ref and chained pointer and focus handlers, so it must be an element or a component that forwards them (every Materix component does). If the child has no accessible name (an icon-only IconButton), the title becomes its aria-label.

Basic usage open_in_new
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';

import { Button } from '@rubenchodev/materix-react/components/button';
import { Link } from '@rubenchodev/materix-react/components/link';

Placement#

placement accepts 12 positions (top|bottom|left|right with -start|-end); the default is bottom. If it doesn’t fit, it flips to the opposite side and shifts to stay on screen.

Placement open_in_new
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';
import type { TooltipProps } from '@rubenchodev/materix-react/components/tooltip';
import { Button } from '@rubenchodev/materix-react/components/button';

export const description = {
  en: '`placement` accepts 12 positions (`top|bottom|left|right` with `-start|-end`); the default is `bottom`. If it doesn\'t fit, it flips to the opposite side and shifts to stay on screen.',
  es: '`placement` admite 12 posiciones (`top|bottom|left|right` con `-start|-end`); por defecto `bottom`. Si no cabe, voltea al lado opuesto y se desplaza para seguir en pantalla.',
};

type Placement = NonNullable<TooltipProps['placement']>;

const GROUPS: Array<{ label: string; placements: Placement[] }> = [
  { label: 'Top', placements: ['top-start', 'top', 'top-end'] },
  { label: 'Bottom', placements: ['bottom-start', 'bottom', 'bottom-end'] },
  { label: 'Left and right', placements: ['left-start', 'left', 'left-end', 'right-start', 'right', 'right-end'] },
];

export default function Demo() {
  return (
    <div className="demo-grid-3">
      {GROUPS.map(({ label, placements }) => (
        <div className="demo-group" key={label}>
          <span className="demo-label">{label}</span>
          <div className="demo-row">
            {placements.map((placement) => (
              <Tooltip key={placement} title={placement} placement={placement}>
                <Button variant="outlined">{placement}</Button>
              </Tooltip>
            ))}
          </div>
        </div>
      ))}
    </div>
  );
}

Accessibility demo#

If the trigger has no accessible name, the text is applied as aria-label. If it already has one, the tooltip describes it with aria-describedby while visible.

import { useEffect, useRef, useState } from 'react';
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {

Programmatic usage#

open makes the tooltip controlled: onOpen(event) and onClose(event) ask to change it (equivalents of mtx:tooltip:open and mtx:tooltip:close). For one-off actions without state, the action ref exposes open(), close(), toggle(), update() and isOpen, the equivalent of Materix.tooltip.show/hide and getTooltip(). hideAllTooltips() hides every visible tooltip.

Programmatic usage open_in_new
import { useRef, useState } from 'react';
import { Tooltip } from '@rubenchodev/materix-react/components/tooltip';
import type { TooltipActions } from '@rubenchodev/materix-react/components/tooltip';
import { Button } from '@rubenchodev/materix-react/components/button';

export const description = {
  en: '`open` makes it controlled and `onOpen`/`onClose` replace `mtx:tooltip:open`/`close`. The `action` ref exposes `open()`, `close()`, `toggle()`, `update()` and `isOpen`, like `Materix.tooltip.show/hide`.',
  es: '`open` lo hace controlado y `onOpen`/`onClose` sustituyen a `mtx:tooltip:open`/`close`. La ref `action` expone `open()`, `close()`, `toggle()`, `update()` e `isOpen`, como `Materix.tooltip.show/hide`.',
};

export default function Demo() {
  const actions = useRef<TooltipActions>(null);
  const [open, setOpen] = useState(false);
  const [text, setText] = useState('Copy link');
  const [log, setLog] = useState<string[]>([]);
  const write = (line: string) => setLog((lines) => [`${new Date().toLocaleTimeString()}  ${line}`, ...lines]);

  return (
    <div className="demo-stack demo-wide">
      <div className="demo-group">
        <span className="demo-label">Controlled (open / onOpen / onClose)</span>
        <div className="demo-row">
          <Tooltip
            title={text}
            placement="top"
            open={open}
            onOpen={() => {
              write('onOpen');
              setOpen(true);
            }}
            onClose={() => {
              write('onClose');
              setOpen(false);
            }}
          >
            <Button variant="outlined" startIcon="content_copy">
              Copy
            </Button>
          </Tooltip>
          <Button variant="text" size="small" onClick={() => setOpen(true)}>
            open = true
          </Button>
          <Button variant="text" size="small" onClick={() => setOpen(false)}>
            open = false
          </Button>
          <Button
            variant="text"
            size="small"
            onClick={() => {
              setText('Copied!');
              setOpen(true);
            }}
          >
            title = &apos;Copied!&apos;
          </Button>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Imperative (action ref)</span>
        <div className="demo-row">
          <Tooltip title="Opened from code" action={actions} arrow>
            <Button variant="outlined" startIcon="code">
              Target
            </Button>
          </Tooltip>
          <Button variant="text" size="small" onClick={() => actions.current?.open()}>
            action.open()
          </Button>
          <Button variant="text" size="small" onClick={() => actions.current?.close()}>
            action.close()
          </Button>
        </div>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}
const actions = useRef<TooltipActions>(null);

<Tooltip title="Copied!" action={actions}>
  <Button onClick={() => actions.current?.open()}>Copy</Button>
</Tooltip>;

API reference#

Tooltip props#

PropTypeDefaultDescription
titleReactNode—Content. Empty ('', null, false) disables the tooltip.
childrenReactElement—Single trigger; receives ref and the handlers.
placementPlacement'bottom'top, bottom, left, right + -start/-end. Flips and shifts automatically.
arrowbooleanfalseShows the arrow.
enterDelaynumber100Delay before showing on hover or focus (ms).
enterNextDelaynumber0Delay when another tooltip closed less than 800 ms ago.
leaveDelaynumber0Delay before hiding when the pointer leaves (ms).
enterTouchDelaynumber700Long-press duration (ms).
leaveTouchDelaynumber1500Time visible after releasing the long press (ms).
followCursorbooleanfalseThe tooltip follows the pointer.
openboolean—Controlled visibility.
onOpen(event) => void—Open request.
onClose(event) => void—Close request (leave, blur, Escape, another tooltip opening).
disableHoverListenerbooleanfalseDoesn’t open on hover.
disableFocusListenerbooleanfalseDoesn’t open on keyboard focus.
disableTouchListenerbooleanfalseDoesn’t open on long press.
disableInteractivebooleanfalseThe tooltip doesn’t retain the pointer (implicit with followCursor).
describeChildbooleanfalseThe title describes the child (aria-describedby) instead of naming it.
idstringgeneratedId of the surface.
actionRef<TooltipActions>—Imperative API.
container / disablePortal—document.bodyPortal target or render in place.
slotProps{ tooltip?, arrow? }—Extra props (className, style, data-*…) of the surface and the arrow.

ref, className, style and any other prop go to the child (as in MUI); the child’s own props take precedence and its handlers are chained.

Accessibility#

  • The surface has role="tooltip" and is linked to the trigger following the WAI-ARIA tooltip pattern:
    • If the trigger has no accessible name, the text is applied as its aria-label (marked with data-mtx-tooltip-label and removed on unmount).
    • If it already has a name, it is kept and the tooltip is linked with aria-describedby while visible; if both texts match, it is not duplicated. describeChild always uses aria-describedby.
  • It opens on keyboard focus (Tab yes, mouse click no) and hides on blur.
  • Hoverable (WCAG 1.4.13): the pointer can move from the trigger onto the tooltip without it disappearing.
  • Dismissible: Escape hides it without moving focus, and only it: a menu or dialog underneath stays open.
  • Persistent: it stays visible until hover or focus are removed or it is dismissed.
  • On touch screens it appears with a long press (700 ms) and hides 1.5 s after release; touching elsewhere hides it.
  • It respects prefers-reduced-motion and draws a border in forced-colors mode.
