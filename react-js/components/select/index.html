Select

Select with a custom MUI-style menu: search, multiple selection, bulk actions, groups, limits and icons or images in the options.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Select } from '@rubenchodev/materix-react';

Select lets users pick one or more values from a list through a custom MUI-styled menu with search, multiple selection with checkboxes, bulk actions, groups and options with an icon or image. A hidden native <select> mirrors the selection, so the value is submitted with the form and required is validated by the browser. If you only need the operating system’s dropdown, lighter and better on mobile, use NativeSelect; for free-text input, use TextField.

import '@rubenchodev/materix-ui/base.css';
import { Select } from '@rubenchodev/materix-react';

<Select label="City" name="city">
  <option value="mdx">Mexico City</option>
  <option value="gdl">Guadalajara</option>
</Select>

Basic usage#

One element with label is enough: the component renders the container, the floating label, the combobox, the hidden native <select>, the chevron and, in outlined, the notched border. Options are written as <option>/<optgroup> children (with data-icon/data-image as in vanilla) or passed through the options prop. Without defaultValue the first enabled option is selected, like a native select.

Grid and form#

A shipping form in mtx-grid combining Select, TextField and Button: each field takes the full width of its column (one column on mobile, three on desktop). name is submitted with the form (several entries with multiple) and the form’s reset restores the initial value.

Grid and form open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import '@rubenchodev/materix-ui/components/grid.css';
import { Select } from '@rubenchodev/materix-react/components/select';
import { TextField } from '@rubenchodev/materix-react/components/text-field';
import { Button } from '@rubenchodev/materix-react/components/button';

export const description = {
  en: "A shipping form in `mtx-grid` combining Select, TextField and Button: one column on mobile and three on desktop. `name` is submitted with the form and Reset restores the initial values.",
  es: "Un formulario de envío en `mtx-grid` que combina Select, TextField y Button: una columna en móvil y tres en escritorio. `name` se envía con el formulario y Reset restaura los valores iniciales.",
};

export default function Demo() {
  const [submitted, setSubmitted] = useState('');

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const data = new FormData(event.currentTarget);
    const entries: Record<string, string | string[]> = {};
    data.forEach((value, key) => {
      const text = String(value);
      const prev = entries[key];
      entries[key] = prev === undefined ? text : ([] as string[]).concat(prev, text);
    });
    setSubmitted(JSON.stringify(entries));
  };

  return (
    <div className="demo-surface">
      <form className="mtx-grid mtx-grid--container mtx-grid--spacing-2" onSubmit={handleSubmit}>
        <div className="mtx-grid mtx-grid--item mtx-grid--xs-12 mtx-grid--md-4">

Controlled usage#

With value + onChange and open + onOpen/onClose the parent owns the state; the vanilla instance methods become state changes (value = …, open(), disable(), helperText = …) and focus() uses controlRef.

Controlled usage open_in_new
import { useRef, useState } from 'react';
import { Select } from '@rubenchodev/materix-react/components/select';
import { Button } from '@rubenchodev/materix-react/components/button';

export const description = {
  en: "With `value` + `onChange` and `open` + `onOpen` / `onClose` the parent owns the state; the buttons replace the vanilla instance methods and `focus()` uses `controlRef`.",
  es: "Con `value` + `onChange` y `open` + `onOpen` / `onClose` el estado lo lleva el padre; los botones sustituyen a los métodos de la instancia vanilla y `focus()` usa `controlRef`.",
};

export default function Demo() {
  const controlRef = useRef<HTMLDivElement>(null);
  const [env, setEnv] = useState('dev');
  const [regions, setRegions] = useState<string[]>([]);
  const [open, setOpen] = useState(false);
  const [disabled, setDisabled] = useState(false);
  const [helper, setHelper] = useState('Use the buttons or the menu');
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ["value = 'prod'", () => setEnv('prod')],
    ["value = ['eu', 'sa']", () => setRegions(['eu', 'sa'])],
    ['open = true', () => setOpen(true)],
    ['disabled = !disabled', () => setDisabled((prev) => !prev)],
    ['helperText', () => setHelper(`Updated at ${new Date().toLocaleTimeString()}`)],
    ['focus()', () => controlRef.current?.focus()],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-grid-2">
        <Select
          label="Environment"
          controlRef={controlRef}
          helperText={helper}
          value={env}
          open={open}
          disabled={disabled}
          onOpen={() => {
            setOpen(true);
            write('onOpen');
          }}
          onClose={() => {
            setOpen(false);
            write('onClose');
          }}
          onChange={(_, next) => {
            setEnv(next as string);
            write(`onChange → ${JSON.stringify(next)}`);
          }}
          options={[
            { value: 'dev', label: 'Development' },
            { value: 'staging', label: 'Staging' },
            { value: 'prod', label: 'Production' },
          ]}
        />
        <Select
          label="Regions"
          multiple
          actionsBox
          value={regions}
          onChange={(_, next) => {
            setRegions(next as string[]);
            write(`onChange → ${JSON.stringify(next)}`);
          }}
          options={[
            { value: 'us', label: 'United States' },
            { value: 'eu', label: 'Europe' },
            { value: 'sa', label: 'South America' },
          ]}
        />
      </div>
      <span className="demo-status">
        env: {env} · regions: {JSON.stringify(regions)} · open: {String(open)} · disabled: {String(disabled)}
      </span>
      <div className="demo-row">
        {actions.map(([label, run]) => (
          <Button
            key={label}
            variant="outlined"
            size="small"
            onClick={() => {
              run();
              write(label);
            }}
          >
            {label}
          </Button>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Inside a Dialog#

The portaled menu registers itself as an upper layer: the Dialog focus trap lets focus into its search box, Esc closes only the menu (a second press closes the dialog) and its z-index stays above the dialog.

import { Select } from '@rubenchodev/materix-react/components/select';

};

export default function Demo() {
  const [open, setOpen] = useState(false);

Accessibility#

  • WAI-ARIA select-only combobox pattern: the control has role="combobox", aria-haspopup="listbox", aria-expanded and aria-controls; the menu contains a role="listbox" with role="option" items (aria-selected, aria-disabled) and role="group" for groups. With multiple, the listbox has aria-multiselectable.
  • Focus stays on the combobox and the active option is announced through aria-activedescendant; with search, focus moves to the search box, which carries aria-activedescendant.
  • The label names the combobox (aria-labelledby); without a label use aria-label. error sets aria-invalid, required aria-required, readOnly aria-readonly, and helperText is linked with aria-describedby.
  • The hidden native <select> is aria-hidden and out of the tab order; Escape is delivered through the common layer stack (only the top layer closes).
