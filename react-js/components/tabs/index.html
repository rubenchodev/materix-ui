Tabs

Tabs to switch between views at the same level, with an animated indicator, icons, vertical orientation and full keyboard navigation.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Tabs, Tab, TabPanel, TabContext, TabsContainer } from '@rubenchodev/materix-react';

Tabs organizes related content into views at the same level and lets users switch between them without leaving the page, with an indicator that slides under the active tab. Use it when there are between two and about seven sibling sections that users consult one at a time (profile, security, notifications). Don’t use it for sequential steps or to navigate between top-level pages.

import '@rubenchodev/materix-ui/base.css';
import { Tab, TabContext, TabPanel, Tabs, TabsContainer } from '@rubenchodev/materix-react';

<TabContext defaultValue="overview">
  <Tabs aria-label="Project">
    <Tab value="overview" label="Overview" />
    <Tab value="activity" label="Activity" />
  </Tabs>
  <TabPanel value="overview">…</TabPanel>
  <TabPanel value="activity">…</TabPanel>
</TabContext>

Basic usage#

TabContext shares the active value between Tabs and the TabPanels: it generates the ids, links aria-controls / aria-labelledby and hides the inactive panels with hidden. Without defaultValue, the first enabled tab is active. TabsContainer is optional: it groups tabs and panels on an outlined surface (.mtx-tabs-container).

Basic usage open_in_new
import { Tab, TabContext, TabPanel, Tabs, TabsContainer } from '@rubenchodev/materix-react/components/tabs';

export default function Demo() {
  return (
    <TabContext defaultValue="overview">
      <TabsContainer>
        <Tabs aria-label="Project">
          <Tab value="overview" label="Overview" />
          <Tab value="activity" label="Activity" />
          <Tab value="settings" label="Settings" />
        </Tabs>
        <TabPanel value="overview">Project overview: 12 open tasks and 3 pending reviews.</TabPanel>
        <TabPanel value="activity">Last activity 5 minutes ago.</TabPanel>
        <TabPanel value="settings">Project preferences.</TabPanel>
      </TabsContainer>
    </TabContext>
  );
}

Variants#

By default tabs have their natural width (variant="standard"). variant="fullWidth" distributes the width among them and centered centers them. A Tab without value receives its index, so a bar without panels only needs <Tab label> children. TabsContainer adds a bordered surface; with borderless it only groups.

Variants open_in_new

Colors#

The active tab and the indicator use --mtx-color-primary; as in vanilla, there are no textColor / indicatorColor props. For another hue, redefine the token on a container.

States#

A disabled tab is dimmed, does not respond to clicks and is skipped by the keyboard. Hover to see the hover background, press to see the ripple (disableRipple turns it off) and use Tab to see the focus ring.

Scrollable#

When the tabs don’t fit, the bar scrolls horizontally (touch, wheel or keyboard) and the indicator follows the active tab. The scrollbar is hidden and there are no arrow buttons (unlike MUI’s variant="scrollable").

Scrollable open_in_new
import { Tab, Tabs } from '@rubenchodev/materix-react/components/tabs';

const MONTHS = [
  'January',

  'March',

  'June',
  'July',
  'August',
  'September',

      {MONTHS.map((month) => (
        <Tab key={month} value={month} label={month} />

}

Manual and automatic activation#

By default the arrow keys only move focus and the tab is activated with Enter or Space (manual activation, recommended by WAI-ARIA when loading a panel is expensive). With selectionFollowsFocus the tab is activated as soon as it receives focus.

Manual and automatic activation open_in_new
import { Tab, TabContext, TabPanel, Tabs, TabsContainer } from '@rubenchodev/materix-react/components/tabs';

function Group({ follows }: { follows: boolean }) {
  return (
    <TabContext defaultValue="day">
      <TabsContainer>
        <Tabs selectionFollowsFocus={follows} aria-label={follows ? 'Automatic activation' : 'Manual activation'}>
          <Tab value="day" label="Day" />
          <Tab value="week" label="Week" />
          <Tab value="month" label="Month" />
        </Tabs>
        <TabPanel value="day">Daily view.</TabPanel>
        <TabPanel value="week">Weekly view.</TabPanel>
        <TabPanel value="month">Monthly view.</TabPanel>
      </TabsContainer>
    </TabContext>
  );
}

export default function Demo() {
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Manual · arrows move focus, Enter/Space activate</span>
        <Group follows={false} />
      </div>
      <div className="demo-group">
        <span className="demo-label">selectionFollowsFocus · arrows activate</span>
        <Group follows />
      </div>
    </div>
  );
}

Several groups without an id#

Ids come from useId, so several groups without an id (or TabContext without id) never repeat ids and aria-controls / aria-labelledby always point to the right element.

Several groups without an id open_in_new
import { useEffect, useRef, useState } from 'react';
import { Tab, Tabs } from '@rubenchodev/materix-react/components/tabs';

export default function Demo() {
  const rootRef = useRef<HTMLDivElement>(null);
  const [log, setLog] = useState('');

  useEffect(() => {
    const ids = Array.from(rootRef.current?.querySelectorAll('[role="tab"]') ?? []).map((tab) => tab.id);
    const unique = new Set(ids).size === ids.length;
    setLog(`ids: ${ids.join(', ')}\n${unique ? 'No duplicates ✓' : 'Duplicate ids ✗'}`);
  }, []);

  return (
    <div className="demo-stack" ref={rootRef}>
      <div className="demo-group">
        <span className="demo-label">Group A</span>
        <Tabs aria-label="Group A">
          <Tab label="One" />
          <Tab label="Two" />
        </Tabs>
      </div>
      <div className="demo-group">
        <span className="demo-label">Group B</span>
        <Tabs aria-label="Group B">
          <Tab label="One" />
          <Tab label="Two" />
        </Tabs>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log}
      </pre>
    </div>
  );
}

Controlled usage and cancelable change#

Control the value with value + onChange on TabContext or on Tabs: inside a TabContext, the value of a controlled Tabs is mirrored in the context so the panels follow it (defaultValue on Tabs is ignored there, with a development warning). Tab children wrapped in a Fragment are flattened. onBeforeChange(value, previousValue) runs before the change: returning false cancels it (the equivalent of the cancelable mtx:tabs:before-change).

Controlled usage and cancelable change open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Tab, TabContext, TabPanel, Tabs, TabsContainer } from '@rubenchodev/materix-react/components/tabs';
import type { TabValue } from '@rubenchodev/materix-react/components/tabs';

export default function Demo() {
  const [value, setValue] = useState<TabValue>('general');
  const [log, setLog] = useState<string[]>([]);
  const write = (message: string) => setLog((prev) => [message, ...prev].slice(0, 12));

  return (
    <div className="demo-stack">
      <TabContext value={value} onChange={(_, next) => setValue(next)}>
        <TabsContainer>
          <Tabs
            aria-label="Settings"
            onBeforeChange={(next, previous) => {
              if (next === 'locked') {
                write(`onBeforeChange(${next}, ${previous}) → false: change cancelled`);
                return false;
              }
              return true;
            }}
            onChange={(_, next) => write(`onChange → ${next}`)}
          >
            <Tab value="general" label="General" />
            <Tab value="advanced" label="Advanced" />
            <Tab value="locked" label="Locked" />
          </Tabs>
          <TabPanel value="general">General settings.</TabPanel>
          <TabPanel value="advanced">Advanced settings.</TabPanel>
          <TabPanel value="locked">Should never be visible.</TabPanel>
        </TabsContainer>
      </TabContext>
      <Stack direction="row" spacing={1} wrap alignItems="center">
        <Button variant="outlined" size="small" onClick={() => setValue('general')}>
          value = &apos;general&apos;
        </Button>
        <Button variant="outlined" size="small" onClick={() => setValue('advanced')}>
          value = &apos;advanced&apos;
        </Button>
        <span className="demo-status">value: {String(value)}</span>
      </Stack>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}
const [value, setValue] = useState('general');

<Tabs value={value} onChange={(event, next) => setValue(next)} onBeforeChange={(next) => next !== 'locked'}>
  <Tab value="general" label="General" />
  <Tab value="locked" label="Locked" />
</Tabs>;

Accessibility#

  • The bar has role="tablist" and aria-orientation; each tab role="tab", aria-selected and, with a TabPanel, aria-controls; each panel role="tabpanel" and aria-labelledby.
  • Roving tabindex: only the active tab is in the tab order (tabindex="0"); the others are reached with the arrow keys.
  • Disabled tabs carry aria-disabled="true" and are skipped by the keyboard.
  • Name the bar with aria-label and give icon-only tabs an aria-label; the generated icon is decorative.
KeyAction
TabEnters the active tab; the next Tab leaves the bar.
→ / ←Next / previous tab (horizontal), wrapping around.
↓ / ↑Next / previous tab (vertical), wrapping around.
Home / EndFirst / last enabled tab.
Enter / SpaceActivates the focused tab (manual activation).
