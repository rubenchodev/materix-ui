Badge

Displays a number or a status dot at the corner of an icon, avatar or button to flag new or pending items.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Badge } from '@rubenchodev/materix-react';

Badge wraps an element (icon, avatar, button) and places a counter or a dot at its corner. Use it to flag unread messages, pending notifications or an online status. Don’t use it for standalone text labels (use Chip) or for page-level status messages (use Alert).

import { Badge } from '@rubenchodev/materix-react';
// or only this component:
import { Badge } from '@rubenchodev/materix-react/components/badge';

Basic usage#

Wrap the content with <Badge> and pass the value in badgeContent. The component renders the .mtx-badge__badge node after the children and positions it.

Basic usage open_in_new
import { Badge } from '@rubenchodev/materix-react/components/badge';

export default function Demo() {
  return (
    <div className="demo-row mtx-gap-4 mtx-pt-1 mtx-px-1">
      <Badge badgeContent={4} color="primary">
        <span className="material-icons" aria-hidden="true">mail</span>
      </Badge>
      <Badge badgeContent={12} color="error">
        <span className="material-icons" aria-hidden="true">notifications</span>
      </Badge>
      <Badge variant="dot" color="success">
        <span className="material-icons" aria-hidden="true">chat</span>
      </Badge>
    </div>
  );
}

Variants#

standard (default) shows the content, a number or a short text. dot shows an 8px dot and ignores badgeContent.

On icons, avatars and buttons#

The badge wraps any element. With an icon button it can go inside, wrapping the icon (MUI pattern), or outside, wrapping the button. The badge is decorative (aria-hidden="true"), so the number must be part of the button aria-label.

On icons, avatars and buttons open_in_new
import { Avatar } from '@rubenchodev/materix-react/components/avatar';
import { Badge } from '@rubenchodev/materix-react/components/badge';
import { Button } from '@rubenchodev/materix-react/components/button';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  return (
    <>
      <div className="demo-group">
        <span className="demo-label">Icon</span>
        <div className="demo-row mtx-gap-4 mtx-pt-1 mtx-px-1">
          <Badge badgeContent={3} color="primary">
            <span className="material-icons" aria-hidden="true">shopping_cart</span>
          </Badge>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Avatar</span>
        <div className="demo-row mtx-gap-4 mtx-pt-1 mtx-px-1">
          <Badge badgeContent={2} color="error" overlap="circular">
            <Avatar color="primary">AG</Avatar>
          </Badge>
          <Badge badgeContent={9} color="error">
            <Avatar variant="rounded" color="secondary">CR</Avatar>
          </Badge>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">IconButton and Button</span>
        <div className="demo-row mtx-gap-4 mtx-pt-1 mtx-px-1">
          <IconButton aria-label="Notifications, 17 unread">
            <Badge badgeContent={17} color="error">
              <span className="material-icons" aria-hidden="true">notifications</span>
            </Badge>
          </IconButton>
          <Badge badgeContent={4} color="primary" overlap="circular">
            <IconButton icon="mail" aria-label="Mail, 4 unread messages" />
          </Badge>
          <Badge badgeContent={8} color="error">
            <Button variant="outlined" aria-label="To do, 8 tasks">To do</Button>
          </Badge>
        </div>
      </div>
    </>
  );
}

Colors#

Without color (or with default) the badge is a neutral gray that adapts to the theme, as in MUI. The other values use the palette with its contrast text.

Colors open_in_new
import { Badge, type BadgeColor } from '@rubenchodev/materix-react/components/badge';

const colors: BadgeColor[] = ['default', 'primary', 'secondary', 'error', 'warning', 'info', 'success'];

export default function Demo() {
  return (
    <>
      <div className="demo-group">
        <span className="demo-label">Standard</span>
        <div className="demo-row mtx-gap-4 mtx-pt-1 mtx-px-1">
          {colors.map((color) => (
            <Badge key={color} badgeContent={4} color={color}>
              <span className="material-icons" aria-hidden="true">mail</span>
            </Badge>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Dot</span>
        <div className="demo-row mtx-gap-4 mtx-pt-1 mtx-px-1">
          {colors.map((color) => (
            <Badge key={color} variant="dot" color={color}>
              <span className="material-icons" aria-hidden="true">mail</span>
            </Badge>
          ))}
        </div>
      </div>
    </>
  );
}

States#

The badge is hidden (.mtx-badge--invisible, scale animation) when badgeContent is 0, null or missing. showZero shows the zero, invisible always hides it and max (99 by default) turns larger numbers into max+. max only applies to numbers or numeric strings.

States open_in_new
import { Badge } from '@rubenchodev/materix-react/components/badge';

const icon = <span className="material-icons" aria-hidden="true">mail</span>;

export default function Demo() {
  return (
    <>
      <div className="demo-group">
        <span className="demo-label">Value 0 · with showZero · invisible</span>
        <div className="demo-row mtx-gap-4 mtx-pt-1 mtx-px-1">
          <Badge badgeContent={0} color="primary">{icon}</Badge>
          <Badge badgeContent={0} showZero color="primary">{icon}</Badge>
          <Badge badgeContent={5} invisible color="primary">{icon}</Badge>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Maximum value: 99 with max 9 · 150 (max 99) · 1000 with max 999</span>
        <div className="demo-row mtx-gap-4 mtx-pt-1 mtx-px-1">
          <Badge badgeContent={99} max={9} color="error">{icon}</Badge>
          <Badge badgeContent={150} color="error">{icon}</Badge>
          <Badge badgeContent={1000} max={999} color="error">{icon}</Badge>
        </div>
      </div>
    </>
  );
}

Inline (standalone)#

standalone renders the badge in the text flow with no anchored element: counters in navigation, lists or tabs. Its number is then content (no aria-hidden). With label, a visually hidden .mtx-badge__label is added for screen readers ({0} is replaced by the displayed content) and the visible badge becomes decorative again.

Inline (standalone) open_in_new
import { Badge } from '@rubenchodev/materix-react/components/badge';
import { List, ListItemButton } from '@rubenchodev/materix-react/components/list';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Badge standalone badgeContent={4} color="primary" />
        <Badge standalone badgeContent={120} color="error" />
        <Badge standalone badgeContent="New" />
        <Badge standalone variant="dot" color="success" />
      </div>
      <div className="demo-fixed-width">
        <List aria-label="Folders">
          <li>
            <ListItemButton href="#standalone" icon="inbox" primary="Inbox" disableSelect>
              <Badge standalone badgeContent={4} color="primary" label="{0} unread" className="mtx-ms-auto" />
            </ListItemButton>
          </li>
          <li>
            <ListItemButton href="#standalone" icon="send" primary="Sent" disableSelect>
              <Badge standalone badgeContent={0} className="mtx-ms-auto" />
            </ListItemButton>
          </li>
        </List>
      </div>
    </div>
  );
}

Position#

anchor places the badge at top-right (default), top-left, bottom-right or bottom-left. The MUI anchorOrigin={{ vertical, horizontal }} is also accepted and wins over anchor.

Position open_in_new
import { Badge, type BadgeAnchor } from '@rubenchodev/materix-react/components/badge';

const anchors: BadgeAnchor[] = ['top-left', 'top-right', 'bottom-left', 'bottom-right'];

export default function Demo() {
  return (
    <div className="demo-row mtx-gap-4 mtx-pt-1 mtx-px-1">
      {anchors.map((anchor) => (
        <Badge key={anchor} badgeContent={3} anchor={anchor} color="primary">
          <span className="material-icons" aria-hidden="true">mail</span>
        </Badge>
      ))}
    </div>
  );
}

Grid layout#

Dashboard shortcuts in Grid: 2 columns on mobile and 4 from md.

import { Grid } from '@rubenchodev/materix-react/components/grid';

const items: Array<{ icon: string; label: string; content?: number; color: BadgeColor; dot?: boolean }> = [

  { icon: 'notifications', label: 'Alerts', content: 120, color: 'error' },

Controlled usage#

In React the badge is driven by props: change badgeContent or invisible and the next render applies max and the zero rule. This replaces the vanilla content and invisible setters.

Controlled usage open_in_new
import { useState } from 'react';
import { Badge } from '@rubenchodev/materix-react/components/badge';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const [content, setContent] = useState<number | null>(1);
  const [invisible, setInvisible] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const apply = (call: string, next: number | null, hidden: boolean) => {
    setContent(next);
    setInvisible(hidden);
    setLog((lines) => [...lines, `${call} → badgeContent: ${next}, invisible: ${hidden}`].slice(-6));
  };
  return (
    <div className="demo-stack">
      <div className="demo-row mtx-gap-4 mtx-pt-1 mtx-px-1">
        <Badge badgeContent={content} invisible={invisible} max={9} color="primary">
          <span className="material-icons" aria-hidden="true">notifications</span>
        </Badge>
        <Button variant="outlined" onClick={() => apply('badgeContent + 1', (content ?? 0) + 1, invisible)}>
          content + 1
        </Button>
        <Button variant="outlined" onClick={() => apply('badgeContent = 0', 0, invisible)}>
          content = 0
        </Button>
        <Button variant="outlined" onClick={() => apply('badgeContent = null', null, invisible)}>
          content = null
        </Button>
        <Button variant="outlined" onClick={() => apply('invisible = !invisible', content, !invisible)}>
          Toggle invisible
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">{log.join('\n')}</pre>
    </div>
  );
}

API#

Props#

PropTypeDefaultDescription
badgeContentReactNode—Content of the badge (number or short text).
variant'standard' | 'dot''standard'dot adds .mtx-badge--dot.
color'default' | 'primary' | 'secondary' | 'error' | 'warning' | 'info' | 'success''default'Adds .mtx-badge--{color}.
anchor'top-right' | 'top-left' | 'bottom-right' | 'bottom-left''top-right'Corner of the badge.
anchorOrigin{ vertical: 'top' | 'bottom', horizontal: 'left' | 'right' }—MUI alternative to anchor.
overlap'rectangular' | 'circular''rectangular'circular adds .mtx-badge--overlap-circular.
maxnumber99Larger numeric values show max+.
showZerobooleanfalseShows the badge when the content is 0.
invisiblebooleanfalseAlways hides the badge.
standalonebooleanfalseInline badge with no anchored element.
labelstring—Screen reader text; {0} = content.
componentElementType'span'Root element or component.
classNamestring—Merged with the component classes.
refRef<HTMLElement>—Points to the root element.

Any other prop is forwarded to the root element. The helper formatBadgeContent(content, max) is also exported.

Callbacks#

Badge emits no events.

CSS classes#

ClassDescription
.mtx-badgeRoot (relative inline-flex).
.mtx-badge__badgeThe badge itself.
.mtx-badge__labelVisually hidden text (label).
.mtx-badge--dot8px dot.
.mtx-badge--{color}Palette color (default, primary…).
.mtx-badge--top-left / --bottom-right / --bottom-leftAnchor (top-right has no class).
.mtx-badge--overlap-circularPosition for round shapes.
.mtx-badge--invisibleHidden (scale 0).
.mtx-badge--standaloneInline badge.

Accessibility#

  • Anchored badges are decorative (aria-hidden="true"): include the number in the accessible name of the wrapped control (aria-label="Notifications, 17 unread").
  • In standalone mode the number is read as content; with label the screen reader text replaces it.
  • The badge is never focusable and the color is not the only carrier of meaning.
  • The scale animation is turned off with prefers-reduced-motion: reduce.
