Radio

Radio button to choose exactly one option from a visible group; RadioGroup reads and sets the group's value.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Radio, RadioGroup } from '@rubenchodev/materix-react';

Radio lets the user choose exactly one option from a small set where it helps to see all the alternatives at once (plan, shipping method, frequency). Each option is a native <input type="radio">, so arrow-key navigation and form submission work with no extra code. RadioGroup shares a name (generated if you omit it), owns the selected value and adds role="radiogroup", a label and helper/error text.

Helper and error (FormHelperText)#

helperText adds a .mtx-form-helper-text below the group, linked with aria-describedby. Combine error with the message in helperText to validate on submit.

Helper and error (FormHelperText) open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Radio, RadioGroup } from '@rubenchodev/materix-react/components/radio';

export const description = {
  en: "helperText creates a .mtx-form-helper-text below the group and links it with aria-describedby. error flags the error (helper text in red, aria-invalid on the radiogroup); pass the message as helperText. The form validates on submit and clears the error when an option is chosen.",
  es: "helperText crea un .mtx-form-helper-text bajo el grupo y lo enlaza con aria-describedby. error marca el error (texto en rojo, aria-invalid en el radiogroup); pasa el mensaje como helperText. El formulario valida al enviar y limpia el error al elegir una opción.",
};

export default function Demo() {
  const [size, setSize] = useState<string | null>(null);
  const [error, setError] = useState(false);

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    setError(size === null);
  };

  const handleReset = () => {
    setSize(null);
    setError(false);
  };

  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Helper text</span>
        <RadioGroup label="Billing" helperText="You can change it at any time." defaultValue="monthly">
          <Radio value="monthly" label="Monthly" />
          <Radio value="yearly" label="Yearly (2 months free)" />
        </RadioGroup>
      </div>
      <div className="demo-group">
        <span className="demo-label">Validation on submit</span>
        <form className="demo-stack" noValidate onSubmit={handleSubmit} onReset={handleReset}>
          <RadioGroup
            label="Size"
            row
            value={size}
            onChange={(_, value) => {
              setSize(value);
              setError(false);
            }}
            error={error}
            helperText={error ? 'Choose a size to continue.' : 'Check the size guide.'}
          >
            <Radio value="s" label="S" />
            <Radio value="m" label="M" />
            <Radio value="l" label="L" />
          </RadioGroup>
          <div className="demo-row">
            <Button variant="contained" type="submit">
              Add to cart
            </Button>
            <Button type="reset">
              Reset
            </Button>
          </div>
        </form>
      </div>
    </div>
  );
}

Controlled usage#

With value + onChange the parent owns the selection: group.value = 'low' from vanilla becomes setValue('low'), disable()/setError() become props and focus() uses inputRef.

Controlled usage open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Radio, RadioGroup } from '@rubenchodev/materix-react/components/radio';

export const description = {
  en: "With value + onChange the parent owns the selection: onChange(event, value) is the equivalent of mtx:radio-group:change. Each Radio accepts disabled and inputRef (for focus()).",
  es: "Con value + onChange la selección la gestiona el padre: onChange(event, value) equivale a mtx:radio-group:change. Cada Radio acepta disabled e inputRef (para focus()).",
};

export default function Demo() {
  const highRef = useRef<HTMLInputElement>(null);
  const [value, setValue] = useState<string | null>('medium');
  const [highDisabled, setHighDisabled] = useState(false);
  const [groupDisabled, setGroupDisabled] = useState(false);
  const [error, setError] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ["value = 'low'", () => setValue('low')],
    ["value = 'high'", () => setValue('high')],
    ['High: disabled = true', () => setHighDisabled(true)],
    ['High: disabled = false', () => setHighDisabled(false)],
    ['High: focus()', () => highRef.current?.focus()],
    ['group: error = true', () => setError(true)],
    ['group: error = false', () => setError(false)],
    ['group: disabled = true', () => setGroupDisabled(true)],
    ['group: disabled = false', () => setGroupDisabled(false)],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Controlled group</span>
        <RadioGroup
          row
          aria-label="Priority"
          value={value}
          disabled={groupDisabled}
          error={error}
          helperText={error ? 'Pick a priority.' : undefined}
          onChange={(_, next) => {
            setValue(next);
            write(`onChange → value: "${next}"`);
          }}
        >
          <Radio value="low" label="Low" />
          <Radio value="medium" label="Medium" />
          <Radio value="high" label="High" inputRef={highRef} disabled={highDisabled || undefined} />
        </RadioGroup>
        <span className="demo-status">value: &quot;{value ?? ''}&quot;</span>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          {actions.map(([label, run]) => (
            <Button
              key={label}
              variant="outlined"
              size="small"
              onClick={() => {
                run();
                write(label);
              }}
            >
              {label}
            </Button>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

className, style and other attributes go to the root element of each component. useRadioGroup() returns the group context (name, value — undefined when uncontrolled —, defaultValue, disabled, onChange) for custom options. An uncontrolled group uses native defaultChecked radios, so form.reset() restores defaultValue. The group is always rendered inside a stable .mtx-form-control.

Accessibility#

  • Native inputs share the group name: the browser handles mutual exclusion, roving focus and arrow keys.
  • RadioGroup renders role="radiogroup"; name it with label, aria-label or aria-labelledby. The radio relies on its native state (no aria-checked).
  • The whole row is clickable; without label, use aria-label on each Radio.
  • error sets aria-invalid="true" on the group and the helper text is linked with aria-describedby.
KeyAction
TabEnters the group (on the selected option) or leaves it.
↓ / →Selects the next option.
↑ / ←Selects the previous option.
SpaceSelects the focused option if it is not already selected.
