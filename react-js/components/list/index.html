List

Continuous vertical list of text, icons or avatars, with static or interactive items, subheaders, density and selection.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { List, ListItem, ListItemButton, ListItemText, ListItemIcon, ListItemAvatar, ListItemSecondaryAction, ListSubheader, ListSelectionProvider } from '@rubenchodev/materix-react';

List groups related items in a continuous column: navigation menus, inboxes, settings or results. Each row can carry an icon or avatar, primary and secondary text, and a trailing action. For data with several comparable columns use Table; for a floating menu use Menu.

import { List, ListItem, ListItemButton } from '@rubenchodev/materix-react';
// or just this component:
import { List, ListItem } from '@rubenchodev/materix-react/components/list';

Basic usage#

A List (a <ul>) with ListItem rows (<li>). The icon prop adds the icon and secondary the secondary text; text children become the primary text (the equivalent of the vanilla single-element syntax).

Basic usage open_in_new
import { List, ListItem } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';

export default function Demo() {
  return (
    <Paper variant="outlined" className="demo-fixed-width">
      <List aria-label="Mail">
        <ListItem icon="inbox" secondary="3 new messages">
          Inbox
        </ListItem>
        <ListItem icon="drafts" secondary="Saved 2 hours ago">
          Drafts
        </ListItem>
        <ListItem icon="send">Sent</ListItem>
      </List>
    </Paper>
  );
}

Row content#

Text only, with an icon, with an avatar and with primary and secondary text. avatar accepts an image URL (painted as an Avatar with avatarAlt, decorative by default) or any node, for example an <Avatar>; it is wrapped in ListItemAvatar (56px). alignItems="flex-start" aligns the avatar with the first line of long texts.

Interactive rows#

ListItemButton renders a <button type="button"> (or an <a> with href) with hover, focus, ripple and selection: clicking a row selects it and unselects the previous one within the same List. The selection is uncontrolled by default (defaultValue, the value of the initial row) or controlled with value + onSelect. With selectable={false} the rows only run their action.

Subheaders#

ListSubheader titles groups (an <li> by default). inset aligns the title with the text of rows that have an icon; sticky pins it while the list scrolls. You can also pass it through the subheader prop of List.

Nested lists#

A List with nested inside a row indents its rows by 48px (nested={2}: 72px) and shares the selection of the parent list. Wrap it in Collapse (exported by the package) to expand and collapse it; the parent row uses aria-expanded, aria-controls and disableSelect so it is not selected.

Nested open_in_new
import { useId, useState } from 'react';
import { Collapse } from '@rubenchodev/materix-react';
import { List, ListItemButton } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';

export default function Demo() {
  const [open, setOpen] = useState(true);
  const nestedId = useId();
  return (
    <Paper variant="outlined" className="demo-fixed-width">
      <List aria-label="Folders">
        <li>
          <ListItemButton
            icon="inbox"
            primary="Inbox"
            disableSelect
            aria-expanded={open}
            aria-controls={nestedId}
            onClick={() => setOpen((value) => !value)}
          >
            <span className="material-icons" aria-hidden="true">
              {open ? 'expand_less' : 'expand_more'}
            </span>
          </ListItemButton>
          <Collapse in={open}>
            <List nested id={nestedId} aria-label="Subfolders">
              <li>
                <ListItemButton icon="star_border">Starred</ListItemButton>
              </li>
              <li>
                <ListItemButton icon="label">Invoices</ListItemButton>
              </li>
            </List>
          </Collapse>
        </li>
        <li>
          <ListItemButton icon="send">Sent</ListItemButton>
        </li>
      </List>
    </Paper>
  );
}

Real-world examples#

Side navigation#

With href the rows are links; the selected one gets aria-current="page". In vanilla the selection scope is the containing nav or Drawer, so several lists share one selection; in React, wrap them in ListSelectionProvider (value, defaultValue, onSelect, selectable). Without a provider each root List keeps its own selection, and a List with its own value, defaultValue or onSelect does not join the provider.

Programmatic usage#

onSelect is the equivalent of the vanilla mtx:list:select event: it receives { item, value } (the row element and its value). The selected setter and disable()/enable() become the value prop of List (or selected on a row) and disabled.

Programmatic usage open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { List, ListItemButton } from '@rubenchodev/materix-react/components/list';
import type { ListSelectDetail } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';

export default function Demo() {
  const [value, setValue] = useState<string | null>(null);
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((prev) => [...prev.slice(-5), text]);

  const handleSelect = ({ item, value: next }: ListSelectDetail) => {
    setValue(next);
    write(`onSelect  value: "${next}" · item: "${item.textContent?.trim()}"`);
  };

  return (
    <div className="demo-stack">
      <Paper variant="outlined" className="demo-fixed-width">
        <List aria-label="Views" value={value} onSelect={handleSelect}>
          <li>
            <ListItemButton value="list" icon="view_list">
              List
            </ListItemButton>
          </li>
          <li>
            <ListItemButton value="grid" icon="grid_view">
              Grid
            </ListItemButton>
          </li>
          <li>
            <ListItemButton value="calendar" icon="calendar_month" disabled={disabled}>
              Calendar
            </ListItemButton>
          </li>
        </List>
      </Paper>
      <div className="demo-row">
        <Button
          variant="outlined"
          onClick={() => {
            setValue('calendar');
            write('value="calendar"');
          }}
        >
          Select Calendar
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setValue(null);
            write('value={null}');
          }}
        >
          Clear selection
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setDisabled((current) => !current);
            write(`Calendar disabled={${!disabled}}`);
          }}
        >
          Toggle disabled
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accessibility#

  • Keep <ul>/<li> so screen readers announce the number of items, and give the list a name with aria-label when it has no visible title.
  • Interactive rows must be a <button> (actions) or an <a href> (navigation) inside an <li>; with component and no role, the row gets role="button", tabIndex={0} and Enter/Space.
  • Selection is conveyed with valid ARIA for each element: an <a> gets aria-current="page"; a <button>, aria-current="true"; only rows with role="option" or role="tab" (or another selectable role) get aria-selected.
  • Icons generated with icon are decorative; the row text is the accessible name. Secondary action buttons need their own aria-label.
