App Bar

Top bar with the title, navigation and primary actions of the current screen.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { AppBar, Toolbar, ToolbarTitle, ToolbarOffset } from '@rubenchodev/materix-react';

AppBar is the application’s top bar: it displays the screen title, the navigation button and the most frequent actions inside a Toolbar. Use it once per screen as a header. To switch between views at the same level use Tabs, for primary navigation combine it with a Drawer, and for a floating primary action use a Fab.

import { AppBar, Toolbar } from '@rubenchodev/materix-react';
// or just this component:
import { AppBar, Toolbar } from '@rubenchodev/materix-react/components/app-bar';

Basic usage#

title, startIcon and endIcon generate the Toolbar, the title and the IconButtons (the equivalent of the vanilla single-element syntax). Any children are placed after the title. The bar is fixed by default; these demos use position="static" so it stays inside the page.

Basic usage open_in_new
import { AppBar } from '@rubenchodev/materix-react/components/app-bar';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  return (
    <div className="demo-stack">
      <AppBar position="static" color="primary" title="News" startIcon="menu">
        <Button variant="text">Login</Button>
      </AppBar>
    </div>
  );
}

Colors#

color accepts primary, secondary, default (paper surface; the default value), transparent and inherit. elevation changes the shadow (4 by default); it is written to the --mtx-app-bar-shadow variable so transparent and --flat can cancel it. With elevation={0} the bar gets mtx-app-bar--flat and, in default, a single bottom divider instead of the shadow.

Sizes#

The regular Toolbar is 56px tall on mobile and 64px from 600px up, with 16 and 24px side gutters. dense reduces it to 48px and toolbarVariant="prominent" raises it to 128px with the title at the bottom. disableGutters removes the side gutters.

With and without icons#

startIcon adds the navigation button (.mtx-toolbar__navigation-icon) and endIcon a trailing action; both accept a Material Icons name or a node. Set their accessible names with startIconLabel and endIconLabel; without them, the menu icon (or any start icon with navigationControls) is labeled “Open navigation” from the i18n dictionary (appBar.openNavigation) and other icons fall back to their name. For several actions write them as children and mark the title with ToolbarTitle. Inside the Toolbar, text and outlined Buttons and IconButtons inherit the bar color; contained buttons keep their own colors.

Position#

position defines how the bar behaves when the page scrolls.

ValueBehavior
fixed (default)Fixed to the top of the viewport (app bar z-index). Start the content with <ToolbarOffset /> to reserve its height (56px, 64px from 600px; dense 48px).
stickyFlows with the content and sticks to the top when it reaches it.
staticPart of the normal flow; scrolls with the page.
absoluteAnchored to the top of the positioned ancestor; with bottom, to the bottom.
relativeRelative position, no anchoring.

clipped raises the z-index above a clipped Drawer. When the page has a fixed or sticky bar, the CSS adds scroll-padding-top to <html> so #anchor targets aren’t hidden under it (tune it with --mtx-scroll-padding-top). In the demo, the fixed bar is contained by a transform on its frame; on a real page it stays fixed to the window.

Menu and search#

Actions open a Menu with useMenu() (the equivalent of vanilla data-open-menu). For search, use the .mtx-app-bar-search pattern (40px tall, with --grow, --right, --centered and --compact modifiers) or a TextField with variant="no-label" and size="small", which can shrink inside the Toolbar. Their fill, text and placeholder derive from the bar color, so they keep their contrast on primary, secondary, default and in the dark theme. Wrap the pattern with role="search" and give the input an aria-label.

Scroll#

elevateOnScroll starts without a shadow and applies the elevation on scroll; hideOnScroll hides the bar when scrolling down (past 50px) and shows it when scrolling up. The window is observed by default; scrollTarget accepts a ref, an element, a function or a CSS selector of the scrolling container. The calculation runs once per frame and the pending frame is canceled on unmount.

Scroll open_in_new

With Drawer#

In vanilla, data-drawer="id" turns the navigation button into the trigger of a Drawer. In React, onNavigationClick opens the Drawer and navigationControls / navigationExpanded keep aria-controls and aria-expanded in sync. For the full app shell (fixed bar + responsive clipped Drawer + ToolbarOffset), see the Drawer page.

import type { AppBarColor, AppBarPosition } from '@rubenchodev/materix-react/components/app-bar';
import { Button } from '@rubenchodev/materix-react/components/button';

const colors: AppBarColor[] = ['primary', 'secondary', 'default', 'transparent'];
const positions: AppBarPosition[] = ['static', 'relative'];
const elevations = [0, 4, 8, 16];

/**
 * Grupo de botones de opción exclusiva.
 * @param {object} props Etiqueta, opciones, valor y callback.
 * @returns {JSX.Element} Grupo.
 */
function Options<T extends string | number>({ label, options, value, onChange }: { label: string; options: T[]; value: T; onChange: (next: T) => void }) {
  return (
    <div className="demo-row" role="group" aria-label={label}>
      {options.map((option) => (
        <Button key={option} variant={option === value ? 'contained' : 'outlined'} aria-pressed={option === value} onClick={() => onChange(option)}>
          {`${label.toLowerCase()} ${option}`}
        </Button>
      ))}
    </div>
  );
}

export default function Demo() {
  const [color, setColor] = useState<AppBarColor>('primary');
  const [position, setPosition] = useState<AppBarPosition>('static');
  const [elevation, setElevation] = useState(4);
  return (
    <div className="demo-stack">
      <AppBar position={position} color={color} elevation={elevation} title={`${color} · ${position} · elevation ${elevation}`} />
      <Options label="Color" options={colors} value={color} onChange={setColor} />
      <Options label="Position" options={positions} value={position} onChange={setPosition} />
      <Options label="Elevation" options={elevations} value={elevation} onChange={setElevation} />
    </div>
  );
}

Composition with Toolbar#

If the children include a Toolbar, no Toolbar is generated (the equivalent of the vanilla full BEM syntax): use it for several Toolbars, prominent bars or full control of the content.

Composition with Toolbar open_in_new
import { AppBar, Toolbar, ToolbarTitle } from '@rubenchodev/materix-react/components/app-bar';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  return (
    <div className="demo-stack">
      <AppBar position="static" color="primary">
        <Toolbar variant="prominent">
          <IconButton className="mtx-toolbar__navigation-icon" icon="menu" aria-label="Open navigation" />
          <ToolbarTitle>Prominent title</ToolbarTitle>
          <IconButton icon="search" aria-label="Search" />
        </Toolbar>
      </AppBar>
      <AppBar position="static" color="secondary">
        <Toolbar variant="dense">
          <ToolbarTitle>First toolbar</ToolbarTitle>
        </Toolbar>
        <Toolbar variant="dense">
          <ToolbarTitle>Second toolbar</ToolbarTitle>
          <IconButton icon="filter_list" aria-label="Filter" />
        </Toolbar>
      </AppBar>
    </div>
  );
}

CSS classes and variables#

The same as the vanilla library: mtx-app-bar (--fixed, --sticky, --static, --absolute, --relative, --primary, --secondary, --default, --transparent, --inherit, --flat, --bottom, --clipped, --hidden, --animated), mtx-toolbar (--dense, --prominent, --disable-gutters, __navigation-icon, __title, __spacer), mtx-toolbar-offset (--dense) and mtx-app-bar-search (--grow, --right, --centered, --compact). --animated is added after the first painted frame so the initial color and elevation are not animated. Variables: --mtx-app-bar-shadow, --mtx-app-bar-height, --mtx-scroll-padding-top, --mtx-app-bar-search-max-width, --mtx-z-index-app-bar and --mtx-toolbar-action-gap.

Accessibility#

  • The root is a <header>: it’s the banner landmark when it sits at the top level of the page.
  • Generated IconButtons always have an aria-label (startIconLabel/endIconLabel, the i18n “Open navigation” or the icon name) and their icons are aria-hidden. Set explicit labels for icons whose name isn’t meaningful.
  • With navigationControls, the navigation button exposes aria-controls and the aria-expanded you pass in navigationExpanded.
  • Group navigation links in a <nav aria-label="…">. Transitions follow the token durations and are disabled with prefers-reduced-motion; with hideOnScroll the bar reappears when scrolling up.
