Avatar

Represents a person or entity with an image, initials or an icon; AvatarGroup stacks several and summarizes the overflow.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Avatar, AvatarGroup } from '@rubenchodev/materix-react';

Avatar shows the identity of a person or entity in a compact space: a photo, their initials or an icon. Use it in user lists, card headers, comments or app bars. If you need a removable or clickable text label, use Chip; for a numeric indicator on top of an icon, use Badge.

import { Avatar, AvatarGroup } from '@rubenchodev/materix-react';
// or only this component:
import { Avatar, AvatarGroup } from '@rubenchodev/materix-react/components/avatar';

Basic usage#

Initials go as children, src renders the image and icon inserts a Material icon (a string is the icon name; any node, such as an SVG, is also accepted).

  es: 'Un solo `Avatar`: las iniciales van como hijos, `src` genera la imagen e `icon` inserta un icono de Material.',
};

export default function Demo() {
  return (
    <div className="demo-row">
      <Avatar color="primary">RD</Avatar>
      <Avatar icon="folder" color="secondary" role="img" aria-label="Folder" />
      <Avatar src="https://i.pravatar.cc/120?img=47" alt="Anna Grant" />
      <Avatar icon="assignment" variant="rounded" color="success" role="img" aria-label="Tasks" />
    </div>
  );
}

States#

Avatar is not interactive: its states are about content. Without an image or icon it is in fallback mode (.mtx-avatar--fallback) and shows the children. If the image fails to load, the <img> gets hidden, the root switches to fallback mode and, when there are no children, a .mtx-avatar__fallback with the initial of alt is added (● without alt), exactly like vanilla. A new src retries the load.

Grouping#

AvatarGroup overlaps its avatars. max (5 by default, minimum 2) also counts the +N indicator; total counts users that are not rendered; spacing sets the overlap (medium = 8px, small = 16px, or pixels). Overflowing avatars stay mounted with hidden. The +N indicator has a translated aria-label ({count} more) that surplusLabel replaces.

Grouping open_in_new

};

Controlled usage#

The group recalculates on every render, so changing max, total or the children replaces the vanilla max/total setters and refresh().

Controlled usage open_in_new
import { useState } from 'react';
import { Avatar, AvatarGroup, type AvatarColor } from '@rubenchodev/materix-react/components/avatar';
import { Button } from '@rubenchodev/materix-react/components/button';

export const description = {
  en: 'In React the group recalculates on every render: `max`, `total` and the children replace the vanilla `max`/`total` setters and `refresh()`. Avatar and AvatarGroup emit no events; the log shows each change and the resulting state.',
  es: 'En React el grupo se recalcula en cada render: `max`, `total` y los hijos sustituyen a los setters `max`/`total` y a `refresh()` de vanilla. Avatar y AvatarGroup no emiten eventos; el registro muestra cada cambio y el estado resultante.',
};

const colors: AvatarColor[] = ['primary', 'secondary', 'success', 'info', 'warning', 'error'];

export default function Demo() {
  const [state, setState] = useState<{ max: number; total: number | null; count: number }>({ max: 5, total: null, count: 6 });
  const [log, setLog] = useState<string[]>([]);
  const apply = (call: string, patch: Partial<typeof state>) => {
    const next = { ...state, ...patch };
    setState(next);
    const total = Math.max(next.total ?? next.count, next.count);
    const visible = total <= next.max ? next.count : Math.max(1, next.max - 1);
    setLog((lines) => [...lines, `${call} → max: ${next.max}, total: ${total}, visible: ${visible}`].slice(-6));
  };
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <AvatarGroup max={state.max} total={state.total} label="Team">
          {Array.from({ length: state.count }, (_, i) => (
            <Avatar key={i} color={colors[i % colors.length]}>
              {String.fromCharCode(65 + (i % 26))}
            </Avatar>
          ))}
        </AvatarGroup>
      </div>
      <div className="demo-row">
        <Button variant="outlined" onClick={() => apply('max = 3', { max: 3 })}>max = 3</Button>
        <Button variant="outlined" onClick={() => apply('max = 5', { max: 5 })}>max = 5</Button>
        <Button variant="outlined" onClick={() => apply('total = 20', { total: 20 })}>total = 20</Button>
        <Button variant="outlined" onClick={() => apply('total = null', { total: null })}>total = null</Button>
        <Button variant="outlined" onClick={() => apply('add avatar', { count: state.count + 1 })}>Add avatar</Button>
      </div>
      <pre className="demo-log" aria-live="polite">{log.join('\n')}</pre>
    </div>
  );
}

API#

Avatar props#

PropTypeDefaultDescription
srcstring—Image source.
altstring—Alternative text; its initial is the fallback when the image fails.
srcSet / sizesstring—Responsive image attributes.
imgPropsImgHTMLAttributes—Extra attributes of the <img> (onError is still called).
iconReactNode—Icon when there is no image: Material Icons name or a node.
variant'circular' | 'rounded' | 'square''circular'Shape.
color'primary' | 'secondary' | 'error' | 'warning' | 'info' | 'success'—Background color.
size'small' | 'medium' | 'large' | number—Canonical size or pixels.
componentElementType'div'Root element or component.
className / ref—Merged / root element.

AvatarGroup props#

PropTypeDefaultDescription
maxnumber5Visible items, including +N (minimum 2).
totalnumber | null—Logical total of users.
spacing'small' | 'medium' | number'medium'Overlap (--mtx-avatar-group-overlap).
labelstring—Accessible name of the group (aria-label).
surplusLabelstringtranslatedTemplate of the +N label; {count} = amount.
localestring—Local language of the texts.
className / ref—Merged / root <div>.

Other props are forwarded to the root element. The helpers getAvatarInitial(alt) and getAvatarGroupLayout(count, max, total) are also exported.

Callbacks#

Avatar and AvatarGroup emit no events (use imgProps.onError to know when an image fails).

CSS classes#

ClassDescription
.mtx-avatarRoot (40px, circular).
.mtx-avatar--fallbackNo image (or broken image).
.mtx-avatar__fallbackGenerated initial when the image fails.
.mtx-avatar--rounded / --squareShape.
.mtx-avatar--small / --medium / --large24 / 40 / 56px.
.mtx-avatar--{color}Palette background.
.mtx-avatar-groupGroup.
.mtx-avatar--surplus+N indicator.

Accessibility#

  • With an image, alt describes the person; use alt="" when the name is already next to it.
  • Icon avatars that convey meaning need role="img" and an aria-label; the generated icon is aria-hidden.
  • Give AvatarGroup a label and keep the +N aria-label meaningful (surplusLabel).
  • The default background meets AA contrast (4.6:1).
