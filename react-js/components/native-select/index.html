Native Select

The browser's <select> with MUI styling: lightweight, accessible by default and with the native touch picker on mobile.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { NativeSelect } from '@rubenchodev/materix-react';

NativeSelect applies MUI styling to the browser’s <select> without replacing its menu: the list is drawn by the operating system, which makes it the lightest picker, fast with long lists and comfortable on mobile. Use it in simple forms. If you need search, multiple selection with checkboxes or icons in the options, use Select.

info

Select or NativeSelect?

NeedSelectNativeSelect
Menu with MUI styling (Paper, check mark)YesNo, uses the system’s
Search within the menuYesNo
Comfortable multiple selectionYes, with checkboxesNative list (multiple, Ctrl/Cmd + click)
Icons or images in the optionsYesNo
Weight and performance with thousands of optionsMediumMinimal
Native touch experience on mobileCustom menuSystem picker

Rule of thumb: NativeSelect for simple forms and long lists on mobile; Select when you need search, multiple selection, icons or full visual consistency.

import '@rubenchodev/materix-ui/base.css';
import { NativeSelect } from '@rubenchodev/materix-react';

<NativeSelect label="Age" name="age" defaultValue="20">
  <option value="10">Ten</option>
  <option value="20">Twenty</option>
</NativeSelect>

Basic usage#

One element with label is enough: the component renders the container, the floating label (associated through for/id, so the select already has an accessible name), the native <select> and the chevron. As in MUI NativeSelect, the default variant is standard. Options are written as <option>/<optgroup> children or passed through the options prop.

Basic usage open_in_new
import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';

export default function Demo() {
  return (
    <div className="demo-fixed-width">
      <NativeSelect label="Age" name="age" defaultValue="20">
        <option value="10">Ten</option>
        <option value="20">Twenty</option>
        <option value="30">Thirty</option>
      </NativeSelect>
    </div>
  );
}

Variants#

outlined (full border), filled (background and rounded top corners) and standard (bottom line, default) through variant.

Variants open_in_new
import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';

const COUNTRIES = [
  { value: 'co', label: 'Colombia' },
  { value: 'mx', label: 'Mexico' },
  { value: 'es', label: 'Spain' },
];

export default function Demo() {
  return (
    <div className="demo-grid-3">
      {(['outlined', 'filled', 'standard'] as const).map((variant) => (
        <div key={variant} className="demo-group">
          <span className="demo-label">{variant}</span>
          <NativeSelect variant={variant} label="Country" options={COUNTRIES} />
        </div>
      ))}
    </div>
  );
}

Sizes#

Medium 56px (default) and small 40px with size="small" (it also reduces the text to 14px). The heights match TextField and Select, so a small NativeSelect lines up with a small TextField and a medium Button.

import { Fab } from '@rubenchodev/materix-react/components/fab';

const OPTIONS = [

  { value: '2', label: 'Option 2' },
];

export default function Demo() {
  return (

States#

error paints the border, label and chevron red and sets aria-invalid="true"; disabled disables the <select>; required adds the native attribute and the asterisk to the label. On focus, the border and label switch to the primary color.

Helper and error text#

Outside a FormControl the field is always wrapped in .mtx-form-control (so the select is not remounted and keeps focus when the helper appears); helperText adds a FormHelperText below it, linked with aria-describedby. Combined with error it becomes the error message. Inside a FormControl the select inherits error, disabled and required.

Helper and error text open_in_new
import { useState } from 'react';
import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';

const SIZES = [
  { value: '', label: 'Not chosen' },
  { value: 's', label: 'S' },
  { value: 'm', label: 'M' },
  { value: 'l', label: 'L' },
];

export default function Demo() {
  const [size, setSize] = useState('');
  return (
    <div className="demo-grid-2">
      <NativeSelect
        variant="outlined"
        label="Shipping"
        helperText="Delivery time depends on the method."
        options={[{ value: 'std', label: 'Standard (5 days)' }, { value: 'exp', label: 'Express (1 day)' }]}
      />
      <NativeSelect
        variant="outlined"
        label="Size"
        required
        value={size}
        onChange={(_, value) => setSize(value as string)}
        error={size === ''}
        helperText={size === '' ? 'Choose a size.' : `Size ${size.toUpperCase()} selected.`}
        options={SIZES}
      />
    </div>
  );
}

Groups and multiple selection#

<optgroup> and <option disabled> work natively, also through options (an item with options becomes an <optgroup>). With multiple (and htmlSize for the visible rows) the browser’s list box is shown with the border or background of its variant and no chevron; value/onChange then use an array.

Grid#

Inside a Grid each select takes the full width of its column: one per row on mobile, two from 600px and four from 900px.

import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';
import { Grid } from '@rubenchodev/materix-react/components/grid';

const FIELDS: Array<[string, string[]]> = [
  ['Year', ['2024', '2025', '2026']],
  ['Month', ['January', 'February', 'March']],
  ['Day', ['1', '2', '3']],
  ['Currency', ['USD', 'EUR', 'COP']],

export default function Demo() {
  return (

Controlled usage#

With value + onChange the parent owns the value; the vanilla instance methods become state changes (value = … → setValue, disable() → disabled) and focus() uses inputRef.

Controlled usage open_in_new
import { useRef, useState } from 'react';
import { NativeSelect } from '@rubenchodev/materix-react/components/native-select';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const inputRef = useRef<HTMLSelectElement>(null);
  const [value, setValue] = useState('s');
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ['value = "l"', () => setValue('l')],
    ['disabled = !disabled', () => setDisabled((prev) => !prev)],
    ['focus()', () => inputRef.current?.focus()],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <div className="demo-fixed-width">
          <NativeSelect
            variant="outlined"
            label="Size"
            inputRef={inputRef}
            value={value}
            disabled={disabled}
            onChange={(_, next) => {
              setValue(next as string);
              write(`onChange (user) → value: ${String(next)}`);
            }}
            options={[{ value: 's', label: 'S' }, { value: 'm', label: 'M' }, { value: 'l', label: 'L' }]}
          />
        </div>
        <span className="demo-status">
          value: {value} · disabled: {String(disabled)}
        </span>
      </div>
      <div className="demo-row">
        {actions.map(([label, run]) => (
          <Button
            key={label}
            variant="outlined"
            size="small"
            onClick={() => {
              run();
              write(label);
            }}
          >
            {label}
          </Button>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accessibility#

  • It is a real <select>: the browser and screen readers announce and handle it natively.
  • The label is associated with the <select> via for/id, so the accessible name is the label text. Without a label, use aria-label or aria-labelledby.
  • error adds aria-invalid="true"; helperText is linked with aria-describedby; the chevron is decorative (aria-hidden).
KeyAction
TabFocuses the select.
↓ / ↑Changes the option (or opens the list, depending on the OS).
Alt + ↓ / SpaceOpens the system list.
LettersJump to the option that starts with that letter.
EscCloses the list without changing the value.
