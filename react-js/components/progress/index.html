Progress

Circular and linear indicators that show an operation is in progress or how much is left before it finishes.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { CircularProgress, LinearProgress } from '@rubenchodev/materix-react';

Progress tells the user that an operation is running. CircularProgress fits small spaces (buttons, cards, a loading page) and LinearProgress is placed at the edge of a container or next to the task it measures. Use the indeterminate variant when the remaining time is unknown and determinate when you know the percentage.

Import#

import { CircularProgress, LinearProgress } from '@rubenchodev/materix-react';

Basic usage#

A single <CircularProgress /> or <LinearProgress /> renders the SVG or the bars, role="progressbar" and the accessible name. Without value it is indeterminate; with value it becomes determinate.

Basic usage open_in_new
import { CircularProgress, LinearProgress } from '@rubenchodev/materix-react/components/progress';

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <div className="demo-row">
        <CircularProgress />
        <CircularProgress value={75} />
      </div>
      <LinearProgress />
      <LinearProgress value={40} />
    </div>
  );
}

Variants#

Circular#

As in MUI: indeterminate (spins with a stroke that grows and shrinks), determinate (an arc proportional to value) and disableShrink (spin only, useful when the main thread is very busy). track adds the background ring.

Circular open_in_new
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';

export default function Demo() {
  return (
    <div className="demo-grid-4">
      <div className="demo-group">
        <span className="demo-label">Indeterminate</span>
        <div className="demo-row">
          <CircularProgress />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Disable shrink</span>
        <div className="demo-row">
          <CircularProgress disableShrink />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Determinate · 25 / 50 / 100</span>
        <div className="demo-row">
          <CircularProgress value={25} />
          <CircularProgress value={50} />
          <CircularProgress value={100} />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">With track</span>
        <div className="demo-row">
          <CircularProgress value={65} track />
          <CircularProgress track />
        </div>
      </div>
    </div>
  );
}

Linear#

Four variants: indeterminate, determinate, buffer (inferred from valueBuffer) and query (reversed indeterminate, for the phase before loading starts). 4px high, as in MUI; rounded rounds the ends.

  return (

        <LinearProgress />
      </div>
      <div className="demo-group">
        <span className="demo-label">Determinate · 60</span>
        <LinearProgress value={60} />
      </div>
      <div className="demo-group">
        <span className="demo-label">Buffer · 30 / 55</span>
        <LinearProgress value={30} valueBuffer={55} />
      </div>
      <div className="demo-group">
        <span className="demo-label">Query</span>
        <LinearProgress variant="query" />
      </div>
      <div className="demo-group">
        <span className="demo-label">Rounded</span>
        <LinearProgress value={70} rounded />
      </div>
    </div>
  );
}

size sets the diameter in px (40 by default) and thickness the stroke width (3.6). The height of the linear bar is changed with the --mtx-linear-progress-height variable.

With label#

showLabel shows the rounded percentage: centered in the circle and to the right of the bar. The visual figure is aria-hidden; screen readers get the value from aria-valuenow.

With label open_in_new

  return (
    <div className="demo-stack demo-wide">

        <CircularProgress value={48} showLabel track />
        <CircularProgress value={100} showLabel color="success" />
      </div>
      <LinearProgress value={35} showLabel />
      <LinearProgress value={82} showLabel color="secondary" />
    </div>
  );
}

Colors#

color accepts the palette colors and inherit (takes the container’s text color). The linear track is lightened in the light theme and darkened in the dark theme.

Colors open_in_new
import { CircularProgress, LinearProgress, type ProgressColor } from '@rubenchodev/materix-react/components/progress';
import { Typography } from '@rubenchodev/materix-react/components/typography';

const COLORS: ProgressColor[] = ['primary', 'secondary', 'error', 'warning', 'info', 'success'];

export default function Demo() {
  return (
    <div className="demo-stack demo-wide">
      <div className="demo-row">
        {COLORS.map((color) => (
          <CircularProgress key={color} color={color} label={`Loading (${color})`} />
        ))}
        <Typography color="text-secondary" component="span">
          <CircularProgress color="inherit" label="Loading (inherit)" />
        </Typography>
      </div>
      {COLORS.map((color) => (
        <LinearProgress key={color} color={color} value={color === 'success' ? undefined : 50} label={`Progress (${color})`} />
      ))}
    </div>
  );
}

Custom scale#

min and max change the scale (0–100 by default): <LinearProgress max={10} value={7} /> exposes aria-valuemax="10" and fills 70%. If max <= min, max becomes min + 100. The value is clamped to the range.

States#

The default accessible name is “Loading” / “Cargando” depending on the language (I18nProvider, <html lang> or the locale prop). Customize it with label, aria-label or aria-labelledby. Mark the region being updated with aria-busy="true" while it loads.

States and accessibility open_in_new
import { useId } from 'react';
import { CircularProgress, LinearProgress } from '@rubenchodev/materix-react/components/progress';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const titleId = useId();
  return (
    <div className="demo-grid-2">
      <div className="demo-group">
        <span className="demo-label">Custom name (aria-labelledby)</span>
        <Typography variant="body2" component="span" id={titleId}>
          Uploading report.pdf
        </Typography>
        <LinearProgress value={64} aria-labelledby={titleId} />
      </div>
      <div className="demo-group">
        <span className="demo-label">Busy region (aria-busy)</span>
        <div className="demo-row" aria-busy="true" aria-live="polite">
          <CircularProgress size={24} label="Loading comments" />
          <Typography variant="body2" component="span">
            Loading comments…
          </Typography>
        </div>
      </div>
    </div>
  );
}

Real-world examples#

File upload with value and buffer, seat and storage usage on a custom scale, and a Button with loading, which uses a decorative CircularProgress inside.

Real-world examples open_in_new
import { useEffect, useId, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Card, CardContent } from '@rubenchodev/materix-react/components/card';
import { LinearProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

/** Simula una subida con valor y buffer. */
function useUpload() {
  const [state, setState] = useState({ value: 0, buffer: 10 });
  useEffect(() => {
    const reduce = window.matchMedia?.('(prefers-reduced-motion: reduce)').matches;
    const id = setInterval(() => {
      setState(({ value }) => {
        const next = value >= 100 ? 0 : Math.min(100, value + Math.round(Math.random() * 8));
        return { value: next, buffer: Math.min(100, next + 10 + Math.round(Math.random() * 10)) };
      });
    }, reduce ? 1500 : 600);
    return () => clearInterval(id);
  }, []);
  return state;
}

export default function Demo() {
  const upload = useUpload();
  const seatsId = useId();
  const storageId = useId();
  const [saving, setSaving] = useState(false);

  const save = () => {
    setSaving(true);
    setTimeout(() => setSaving(false), 2000);
  };

  return (
    <div className="demo-grid-3">
      <Card>
        <CardContent>
          <Stack spacing={1}>
            <Typography variant="subtitle2" component="span">
              Uploading 3 files
            </Typography>
            <LinearProgress value={upload.value} valueBuffer={upload.buffer} showLabel label="File upload" />
            <Typography variant="caption" color="text-secondary" component="span">
              {upload.value >= 100 ? 'Completed' : `${Math.round(upload.value)}% · 3 files`}
            </Typography>
          </Stack>
        </CardContent>
      </Card>
      <Card>
        <CardContent>
          <Stack spacing={1}>
            <Typography variant="subtitle2" component="span" id={seatsId}>
              Team seats · 7 of 10
            </Typography>
            <LinearProgress max={10} value={7} rounded aria-labelledby={seatsId} />
            <Typography variant="subtitle2" component="span" id={storageId} className="mtx-mt-2">
              Storage · 46 of 50 GB
            </Typography>
            <LinearProgress max={50} value={46} color="warning" rounded aria-labelledby={storageId} />
          </Stack>
        </CardContent>
      </Card>
      <Card>
        <CardContent>
          <Typography variant="subtitle2" gutterBottom>
            Save changes
          </Typography>
          <div className="demo-row">
            <Button variant="contained" loading={saving} loadingPosition="start" startIcon="save" onClick={save}>
              {saving ? 'Saving…' : 'Save'}
            </Button>
          </div>
        </CardContent>
      </Card>
    </div>
  );
}

Programmatic usage#

Progress is a controlled component: update value, valueBuffer, color or variant from your state. Passing value={undefined} switches back to indeterminate.

Programmatic usage open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress, LinearProgress, type ProgressColor } from '@rubenchodev/materix-react/components/progress';

const COLORS: ProgressColor[] = ['primary', 'secondary', 'success', 'warning', 'error', 'info'];

export default function Demo() {
  const [value, setValue] = useState<number | undefined>(30);
  const [colorIndex, setColorIndex] = useState(0);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 6));
  const color = COLORS[colorIndex];

  const step = (delta: number) => {
    const next = Math.min(100, Math.max(0, (value ?? 0) + delta));
    setValue(next);
    write(`value = ${next}`);
  };

  return (
    <div className="demo-stack demo-wide">
      <div className="demo-row">
        <CircularProgress value={value} showLabel size={56} color={color} />
      </div>
      <LinearProgress value={value} showLabel color={color} />
      <div className="demo-row">
        <Button variant="outlined" onClick={() => step(-10)}>-10</Button>
        <Button variant="outlined" onClick={() => step(10)}>+10</Button>
        <Button
          variant="outlined"
          onClick={() => {
            const next = (colorIndex + 1) % COLORS.length;
            setColorIndex(next);
            write(`color = "${COLORS[next]}"`);
          }}
        >
          Change color
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setValue(undefined);
            write('value = undefined → indeterminate');
          }}
        >
          Indeterminate
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accessibility#

  • The root has role="progressbar" and an accessible name: label, aria-label or aria-labelledby; if none is present, “Loading” / “Cargando”.
  • aria-valuenow, aria-valuemin and aria-valuemax are only exposed for determinate and buffer, as WAI-ARIA recommends.
  • The SVG and the percentage label have aria-hidden="true", so the value is announced only once.
  • Inside a control that already communicates loading (aria-busy), use decorative to avoid a duplicate announcement.
  • Honors prefers-reduced-motion. It is not interactive: it doesn’t receive focus.
