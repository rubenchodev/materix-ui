Popover

Floating Paper with arbitrary content anchored to a trigger. Closes on click away or Escape and returns focus to the trigger.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Popover } from '@rubenchodev/materix-react';

A Popover displays any content (text, forms, cards) on a floating Paper surface anchored to another element, like MUI’s Popover. Use it for filters, quick details, small confirmations or an account card. For a list of actions use a Menu; for a short text label, a Tooltip; for a task that blocks the page, a Dialog.

It is also the floating base other components build on (date pickers, filter panels): it handles positioning, the layer stack, focus and closing.

import { Popover, usePopover } from '@rubenchodev/materix-react';
// or only this component:
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';

Basic usage#

usePopover() is the equivalent of data-open-popover="#id": spread getTriggerProps() on the trigger and popoverProps on the <Popover>. It opens below the trigger aligned to its start edge, with elevation 8. Focus moves to the first control (or to the panel) and returns to the trigger when it closes.

Basic usage open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const popover = usePopover();
  return (
    <div className="demo-row">
      <Button variant="contained" {...popover.getTriggerProps()}>
        Open popover
      </Button>
      <Popover {...popover.popoverProps} label="Basic popover" className="mtx-p-2">
        The content of the popover.
      </Popover>
    </div>
  );
}

The panel is rendered in a portal on document.body, so ancestors with overflow: hidden or their own z-index never clip it. Content padding is up to you: use utilities such as mtx-p-2.

Placement#

placement uses the same engine as Tooltip (top|bottom|left|right with -start|-end; default bottom-start), with automatic flipping and shifting. offset sets the gap in px (0 by default, as in MUI).

Placement open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import type { PopoverProps } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';

/** Disparador con su propio popover colocado. */
function Placed({ label, text, ...props }: { label: string; text: string } & Partial<PopoverProps>) {
  const popover = usePopover();
  return (
    <>
      <Button variant="outlined" {...popover.getTriggerProps()}>
        {label}
      </Button>
      <Popover {...popover.popoverProps} label={label} className="mtx-p-2" {...props}>
        {text}
      </Popover>
    </>
  );
}

export default function Demo() {
  return (
    <div className="demo-row">
      <Placed label="top" text="Above and centered." placement="top" offset={8} />
      <Placed label="bottom-end" text="Below, aligned to the end." placement="bottom-end" />
      <Placed label="right · offset 8" text="To the right." placement="right" offset={8} />
      <Placed label="left · offset 8" text="To the left." placement="left" offset={8} />
    </div>
  );
}

Anchor origins#

MUI’s API: anchorOrigin={{ vertical, horizontal }} is the point on the anchor and transformOrigin the point on the popover attached to it. Values are top|center|bottom and left|center|right, or pixels (numbers). The popover stays marginThreshold px (16) from the viewport edges and the grow animation starts from the transform origin.

Anchor origins open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import type { PopoverOrigin } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';

const CASES: Array<{ anchor: PopoverOrigin; transform: PopoverOrigin }> = [
  { anchor: { vertical: 'bottom', horizontal: 'left' }, transform: { vertical: 'top', horizontal: 'left' } },
  { anchor: { vertical: 'center', horizontal: 'center' }, transform: { vertical: 'center', horizontal: 'center' } },
  { anchor: { vertical: 'top', horizontal: 'right' }, transform: { vertical: 'bottom', horizontal: 'right' } },
];

const describe = (origin: PopoverOrigin) => `${origin.vertical} ${origin.horizontal}`;

/** Disparador con orígenes MUI. */
function Origin({ anchor, transform, index }: { anchor: PopoverOrigin; transform: PopoverOrigin; index: number }) {
  const popover = usePopover();
  return (
    <>
      <Button variant="outlined" {...popover.getTriggerProps()}>
        {describe(anchor)} → {describe(transform)}
      </Button>
      <Popover
        {...popover.popoverProps}
        anchorOrigin={anchor}
        transformOrigin={transform}
        label={`Origin ${index + 1}`}
        className="mtx-p-2"
      >
        anchor: {describe(anchor)} · transform: {describe(transform)}
      </Popover>
    </>
  );
}

export default function Demo() {
  return (
    <div className="demo-row">
      {CASES.map((item, index) => (
        <Origin key={index} index={index} anchor={item.anchor} transform={item.transform} />
      ))}
    </div>
  );
}

When either origin is set it takes precedence over placement.

With icons#

Any button can be the trigger. Icon-only ones need an accessible name (aria-label). The trigger gets aria-haspopup="dialog", aria-controls and a synchronized aria-expanded. Several triggers can share one popover: give each one a key (getTriggerProps({ key })) so only the active one is expanded, and each trigger becomes the anchor when clicked.

With icons open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';

export default function Demo() {
  const popover = usePopover();
  return (
    <div className="demo-row">
      <IconButton icon="info" aria-label="Order information" {...popover.getTriggerProps({ key: 'icon' })} />
      <Button variant="outlined" startIcon="tune" {...popover.getTriggerProps({ key: 'details' })}>
        Details
      </Button>
      <Button variant="text" endIcon="expand_more" {...popover.getTriggerProps({ key: 'more' })}>
        More
      </Button>
      <Popover {...popover.popoverProps} className="mtx-p-2 demo-fixed-width">
        <h3 className="mtx-typography--subtitle2 mtx-mb-1">Order #48213</h3>
        <p className="mtx-typography--body2 mtx-color-text-secondary">
          Shipped on October 12 with estimated delivery in 48 h.
        </p>
      </Popover>
    </div>
  );
}

The heading inside the popover becomes its name automatically (aria-labelledby).

States#

A disabled trigger does not open the popover. Elements with data-mtx-popover-close inside the popover close it (reason action) and return focus.

Anchor position#

anchorReference="anchorPosition" with anchorPosition={{ top, left }} anchors the popover to a viewport point instead of an element, for example the cursor position in a contextmenu event. usePopover().openPopover({ x, y }) does the same. With anchorReference="none" the popover is centered in the viewport.

Position by coordinates open_in_new
import { useState } from 'react';
import { Popover } from '@rubenchodev/materix-react/components/popover';

export default function Demo() {
  const [point, setPoint] = useState<{ top: number; left: number } | null>(null);
  return (
    <>
      <div
        className="demo-panel"
        tabIndex={0}
        aria-label="Area with a context menu"
        onContextMenu={(event) => {
          event.preventDefault();
          setPoint({ top: event.clientY, left: event.clientX });
        }}
      >
        <p>Right-click here to open a popover at the cursor.</p>
      </div>
      <Popover
        open={point !== null}
        anchorReference="anchorPosition"
        anchorPosition={point ?? undefined}
        onClose={() => setPoint(null)}
        label="Point details"
        className="mtx-p-2"
      >
        {point && `x: ${point.left} · y: ${point.top}`}
      </Popover>
    </>
  );
}

Modal#

By default the popover is non-modal: it does not trap focus or lock scrolling, and tabbing out of it closes it (reason tabOut). With modal it traps Tab, locks page scrolling and sets aria-modal="true", like MUI’s Popover; a click outside still closes it (reason clickaway) and reaches the clicked element, as in vanilla. data-autofocus on a control chooses the initial focus.

Modal open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  const popover = usePopover();
  return (
    <div className="demo-row">
      <Button variant="outlined" {...popover.getTriggerProps()}>
        Open modal
      </Button>
      <Popover {...popover.popoverProps} modal className="mtx-p-2">
        <h3 className="mtx-typography--subtitle2 mtx-mb-2">Rename</h3>
        <TextField label="Name" size="small" defaultValue="Q3 report" inputProps={{ 'data-autofocus': '' }} />
        <div className="mtx-d-flex mtx-justify-content-end mtx-gap-1 mtx-mt-2">
          <Button variant="text" data-mtx-popover-close="">
            Cancel
          </Button>
          <Button variant="contained" data-mtx-popover-close="">
            Save
          </Button>
        </div>
      </Popover>
    </div>
  );
}

Dialog from a popover#

A button inside the popover can open a Dialog. Interacting with the dialog is not a “click outside” for the popover, the first Escape closes only the dialog (focus returns to the button inside the popover) and the second one closes the popover.

Dialog from a popover open_in_new
import { useState } from 'react';
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { Dialog } from '@rubenchodev/materix-react/components/dialog';

export default function Demo() {
  const popover = usePopover();
  const [dialogOpen, setDialogOpen] = useState(false);
  const closeDialog = () => setDialogOpen(false);
  return (
    <div className="demo-row">
      <Button variant="outlined" startIcon="tune" {...popover.getTriggerProps()}>
        Options
      </Button>
      <Popover {...popover.popoverProps} label="Options" className="mtx-p-2">
        <Checkbox label="Only mine" defaultChecked />
        <div className="mtx-d-flex mtx-justify-content-end mtx-mt-1">
          <Button variant="text" onClick={() => setDialogOpen(true)}>
            Advanced…
          </Button>
        </div>
      </Popover>
      <Dialog
        open={dialogOpen}
        onClose={closeDialog}
        maxWidth="xs"
        title="Advanced options"
        description="Press Escape once to close this dialog; the popover stays open."
        actions={
          <Button variant="text" onClick={closeDialog}>
            Close
          </Button>
        }
      />
    </div>
  );
}

Layer from a popover#

A popover can also open another popover (or a menu). Both share the layer stack: interacting with the upper layer is not a “click outside” for the popover, the first Escape closes only the upper layer (focus returns to its trigger inside the popover) and the second one closes the popover.

Layer from a popover open_in_new
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';

export default function Demo() {
  const outer = usePopover();
  const inner = usePopover();
  return (
    <div className="demo-row">
      <Button variant="outlined" startIcon="tune" {...outer.getTriggerProps()}>
        Options
      </Button>
      <Popover {...outer.popoverProps} label="Options" className="mtx-p-2">
        <Checkbox label="Only mine" defaultChecked />
        <div className="mtx-d-flex mtx-justify-content-end mtx-mt-1">
          <Button variant="text" {...inner.getTriggerProps()}>
            Advanced…
          </Button>
        </div>
        <Popover
          {...inner.popoverProps}
          placement="right-start"
          offset={8}
          label="Advanced options"
          className="mtx-p-2 demo-fixed-width"
        >
          <p className="mtx-typography--body2 mtx-mb-1">
            Press Escape once to close this layer; the first popover stays open.
          </p>
          <Checkbox label="Include archived" />
        </Popover>
      </Popover>
    </div>
  );
}

Mouse over interaction#

MUI’s hover pattern: open on mouseenter/focus, close on mouseleave/blur, with disableAutoFocus, disableRestoreFocus and the mtx-pointer-events-none utility so the popover never steals the pointer or the focus.

Mouse over interaction open_in_new
import { useRef, useState } from 'react';
import { Popover } from '@rubenchodev/materix-react/components/popover';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const anchorRef = useRef<HTMLSpanElement>(null);
  return (
    <>
      <div className="demo-row">
        <span
          ref={anchorRef}
          className="mtx-typography--body1"
          tabIndex={0}
          aria-describedby={open ? 'popover-hover' : undefined}
          onMouseEnter={() => setOpen(true)}
          onMouseLeave={() => setOpen(false)}
          onFocus={() => setOpen(true)}
          onBlur={() => setOpen(false)}
        >
          Hover or focus this text
        </span>
      </div>
      <Popover
        id="popover-hover"
        open={open}
        anchorEl={anchorRef}
        anchorOrigin={{ vertical: 'bottom', horizontal: 'left' }}
        transformOrigin={{ vertical: 'top', horizontal: 'left' }}
        onClose={() => setOpen(false)}
        disableAutoFocus
        disableRestoreFocus
        label="Hover details"
        className="mtx-p-2 mtx-pointer-events-none"
      >
        I use Popover.
      </Popover>
    </>
  );
}

Programmatic usage#

The open prop is the equivalent of open()/close(). usePopover() exposes openPopover(anchor), close() and toggle(anchor); onOpen and onClose(event, reason) are the equivalents of mtx:popover:open and mtx:popover:close. The action ref exposes updatePosition() (vanilla’s update()).

Programmatic usage open_in_new
import { useRef, useState } from 'react';
import { Popover, usePopover } from '@rubenchodev/materix-react/components/popover';
import { Button } from '@rubenchodev/materix-react/components/button';

  const anchorRef = useRef<HTMLButtonElement>(null);
  const popover = usePopover({ onClose: (reason) => write(`onClose → ${reason}`) });

  return (
    <div className="demo-stack demo-wide">

          >
            openPopover(anchor)
          </Button>
          <Button variant="outlined" size="small" onClick={(event) => popover.toggle(event.currentTarget)}>
            toggle(anchor)

      </div>

        </pre>
      </div>
    </div>
  );
}

Manual trigger#

The equivalent of vanilla’s manual BEM usage: you can skip usePopover and wire the trigger yourself with aria-controls, aria-haspopup="dialog" and aria-expanded, giving the popover an id and naming it with aria-labelledby. A click on an element whose aria-controls points to the popover is never treated as “outside”.

Manual trigger (aria-controls) open_in_new
import { useRef, useState } from 'react';
import { Popover } from '@rubenchodev/materix-react/components/popover';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const triggerRef = useRef<HTMLButtonElement>(null);
  return (
    <div className="demo-row">
      <button
        ref={triggerRef}
        type="button"
        className="mtx-button mtx-button--outlined"
        aria-haspopup="dialog"
        aria-controls={open ? 'popover-manual' : undefined}
        aria-expanded={open}
        onClick={() => setOpen((value) => !value)}
      >
        Open (aria-controls)
      </button>
      <Popover
        id="popover-manual"
        open={open}
        anchorEl={triggerRef}
        onClose={() => setOpen(false)}
        aria-labelledby="popover-manual-title"
        className="mtx-p-2"
      >
        <h3 className="mtx-typography--subtitle2" id="popover-manual-title">
          Full markup
        </h3>
        <p className="mtx-typography--body2">Triggered through aria-controls.</p>
      </Popover>
    </div>
  );
}

Reuse in other components#

Popover is designed as the floating base for other surfaces. The props they rely on:

<Popover
  open={open}
  anchorEl={inputRef}                 // ref or element; or a virtual anchor
  placement="bottom-start"            // or anchorOrigin/transformOrigin
  offset={4}
  modal={isMobile}                    // traps Tab and locks scroll
  disableAutoFocus                    // the owner moves focus itself
  disableRestoreFocus                 // the owner restores focus itself
  onClose={(event, reason) => …}      // escapeKeyDown | clickaway | tabOut | action
  role="dialog" aria-label="Choose date"
  className="mtx-date-picker__popover"
/>

resolveOrigin() (MUI origin to pixels) and the constants POPOVER_MARGIN_THRESHOLD and POPOVER_EXIT_DURATION are also exported.

Accessibility#

  • The popover has role="dialog" and tabindex="-1". Its name comes from label (aria-label), from data-popover-title or from the first internal heading (aria-labelledby). With modal it also gets aria-modal="true".
  • The trigger gets aria-haspopup="dialog", aria-controls and an aria-expanded synchronized with the state (getTriggerProps).
  • When it opens, focus moves to [data-autofocus], to the first focusable control or to the panel itself. When it closes with Escape, the trigger or a close button, focus returns to the element that had it (or to the anchor if the browser did not focus it on click, as in Safari).
  • Clicking outside closes it without stealing focus from the element that was clicked; if focus would be lost, it returns to the trigger.
  • If the trigger only shows an avatar or initials, name it with visually hidden text (<span className="mtx-visually-hidden">…</span>) instead of an aria-label that does not contain the visible text (WCAG 2.5.3 Label in Name).
KeyAction
Enter / Space on the triggerOpens or closes the popover.
Tab / Shift+TabMoves through its controls. Non-modal: leaving the popover closes it. Modal: focus cycles inside.
EscapeCloses it and returns focus to the trigger, only if it is the top layer.
