Checkbox

A box for selecting one or more options from a list or confirming a condition; supports an indeterminate state.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Checkbox } from '@rubenchodev/materix-react';

Checkbox lets users select zero, one or several options from a set, or confirm a condition (“I accept the terms”). It renders a native <input type="checkbox"> inside a <label class="mtx-checkbox">, so it works in forms, with the keyboard and with screen readers without extra code. If the option applies a change immediately, use a Switch; if only one option can be chosen, use Radio.

lightbulb

Checkbox, Switch or Radio?

ComponentWhen to use it
CheckboxSeveral independent options, or a confirmation applied when a form is submitted.
SwitchTurning a preference on/off with an immediate effect, without a “Save” button.
RadioChoosing exactly one option from a small, visible group.
import '@rubenchodev/materix-ui/base.css';
import { Checkbox } from '@rubenchodev/materix-react';

<Checkbox label="Remember me" defaultChecked />

Basic usage#

One element with label is enough: the component renders the wrapping <label>, the native input, the visual box and the text. Native props (id, name, value, required, autoFocus, form) go to the <input>.

Basic usage open_in_new
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';

export default function Demo() {
  return (
    <div className="demo-row">
      <Checkbox label="Remember me" defaultChecked />
      <Checkbox label="Receive updates" />
    </div>
  );
}

Without label, only the box is rendered. In that case give it an accessible name with aria-label or aria-labelledby (both are forwarded to the input), for example in a table’s selection column.

Helper and error text (FormHelperText)#

helperText wraps the checkbox in .mtx-form-control and adds a .mtx-form-helper-text below it, outside the <label>, linked with aria-describedby. error adds aria-invalid="true" to the input, colors the empty box border and turns the helper red; pass the error message as helperText. You can also compose the pieces yourself with FormControl and FormHelperText: the checkbox inherits error/disabled and links the helper automatically.

Helper and error (FormHelperText) open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { FormControl, FormHelperText } from '@rubenchodev/materix-react/components/form-helper-text';

export default function Demo() {
  const [accepted, setAccepted] = useState(false);
  const [submitted, setSubmitted] = useState(false);
  const showError = submitted && !accepted;

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    setSubmitted(true);
  };

  return (
    <div className="demo-stack">
      <div className="demo-grid-3">
        <div className="demo-group">
          <span className="demo-label">Helper text</span>
          <Checkbox label="Email me the receipt" helperText="It will be sent to jane@example.com" defaultChecked />
        </div>
        <div className="demo-group">
          <span className="demo-label">Error without message · error</span>
          <Checkbox label="I confirm I am of legal age" helperText="Legal requirement" error />
        </div>
        <div className="demo-group">
          <span className="demo-label">Validation on submit</span>
          <form className="demo-stack" noValidate onSubmit={handleSubmit}>
            <Checkbox
              label="I accept the terms and the privacy policy"
              required
              checked={accepted}
              onChange={(_, checked) => setAccepted(checked)}
              error={showError}
              helperText={showError ? 'You must accept the terms to continue.' : undefined}
            />
            <div className="demo-row">
              <Button variant="contained" type="submit">
                Create account
              </Button>
            </div>
          </form>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">FormControl + FormHelperText</span>
        <FormControl>
          <Checkbox label="Subscribe to the newsletter" />
          <FormHelperText>One email a month, no spam.</FormHelperText>
        </FormControl>
      </div>
    </div>
  );
}

Indeterminate#

The indeterminate state shows that only some child options are checked. As in MUI, indeterminate is controlled by the parent: the component keeps the DOM property input.indeterminate and aria-checked="mixed" in sync with the prop. A user click clears the mixed state, as the browser and vanilla do, until the prop changes again.

Indeterminate open_in_new
import { useState } from 'react';
import '@rubenchodev/materix-ui/utilities.css';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';
import { Stack } from '@rubenchodev/materix-react/components/stack';

const PERMISSIONS = ['Read', 'Write', 'Delete'];

export default function Demo() {
  const [checked, setChecked] = useState([true, false, false]);
  const count = checked.filter(Boolean).length;

  return (
    <div className="demo-panel demo-fixed-width">
      <Checkbox
        label="All permissions"
        checked={count === checked.length}
        indeterminate={count > 0 && count < checked.length}
        onChange={(_, next) => setChecked(checked.map(() => next))}
      />
      <Stack spacing={1} alignItems="start" className="mtx-ps-3">
        {PERMISSIONS.map((permission, index) => (
          <Checkbox
            key={permission}
            label={permission}
            checked={checked[index]}
            onChange={(_, next) => setChecked(checked.map((value, i) => (i === index ? next : value)))}
          />
        ))}
      </Stack>
    </div>
  );
}

Controlled usage#

With checked + onChange the parent owns the state; the vanilla instance methods become state changes (toggle() → setChecked(!checked), disable() → disabled, setError() → error + helperText) and focus() uses inputRef.

Controlled usage open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Checkbox } from '@rubenchodev/materix-react/components/checkbox';

export default function Demo() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [checked, setChecked] = useState(false);
  const [indeterminate, setIndeterminate] = useState(false);
  const [disabled, setDisabled] = useState(false);
  const [error, setError] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  const actions: Array<[string, () => void]> = [
    ['toggle', () => { setIndeterminate(false); setChecked((value) => !value); }],
    ['checked = true', () => setChecked(true)],
    ['indeterminate = true', () => setIndeterminate(true)],
    ['disabled = true', () => setDisabled(true)],
    ['disabled = false', () => setDisabled(false)],
    ['focus()', () => inputRef.current?.focus()],
    ['error = true', () => setError(true)],
    ['error = false', () => setError(false)],
  ];

  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Controlled checkbox</span>
        <div className="demo-row">
          <Checkbox
            label="Controlled checkbox"
            inputRef={inputRef}
            checked={checked}
            indeterminate={indeterminate}
            disabled={disabled}
            error={error}
            helperText={error ? 'Check this box.' : undefined}
            onChange={(_, next) => {
              setIndeterminate(false);
              setChecked(next);
              write(`onChange (user) → checked: ${next}`);
            }}
          />
          <span className="demo-status">
            checked: {String(checked)} · indeterminate: {String(indeterminate)} · disabled: {String(disabled)}
          </span>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          {actions.map(([label, run]) => (
            <Button
              key={label}
              variant="outlined"
              size="small"
              onClick={() => {
                run();
                write(label);
              }}
            >
              {label}
            </Button>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

Accessibility#

  • The native input stays in the DOM: it keeps form submission, required and checkbox semantics.
  • The whole row (<label>) is clickable. Without label, use aria-label or aria-labelledby.
  • The checked state comes from the native input (no redundant aria-checked); indeterminate adds aria-checked="mixed". In uncontrolled mode the input is native (defaultChecked), so form.reset() restores it.
  • The helper text stays outside the <label> (so it is not merged into the accessible name) and is linked with aria-describedby, keeping any ids you pass. error adds aria-invalid="true".
  • Group related options under a FormLabel (role="group" + aria-labelledby) or a <fieldset> with <legend>.
KeyAction
Tab / Shift+TabMoves focus to the next / previous checkbox.
SpaceChecks or unchecks the focused checkbox.
