Backdrop

Full-screen layer that dims the page and centers an indicator while an operation runs; it does not replace a dialog.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Backdrop } from '@rubenchodev/materix-react';

Backdrop covers the whole screen with a semi-transparent layer and centers its content, usually a CircularProgress. Use it to signal that the page is busy during a short operation (saving, syncing, processing a payment). It is not a dialog: it has no role, doesn’t trap focus and offers no title or actions; if the user must read a message or make a decision, use a Dialog, which already includes its own backdrop (it reuses this component).

import { Backdrop } from '@rubenchodev/materix-react';
// or only this component:
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';

Basic usage#

<Backdrop open={…}> with the content to center. open is controlled: onClose asks to close it and you update the state. With closeOnClick a click on the layer closes it, and with closeOnEscape, the Escape key. The content is white by default, so a CircularProgress color="inherit" stands out in both themes.

Basic usage open_in_new
import { useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  const [open, setOpen] = useState(false);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="contained" onClick={() => setOpen(true)}>
        Show backdrop
      </Button>
      <Backdrop open={open} onClose={() => setOpen(false)} closeOnClick closeOnEscape>
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
    </Stack>
  );
}

Variants#

Two variants, as in MUI: the default one dims the page with --mtx-backdrop-bg, and invisible keeps the layer transparent (it still blocks clicks). With invisible the content keeps the text color, so use a colored indicator.

Variants open_in_new
import { useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  const [open, setOpen] = useState<'default' | 'invisible' | null>(null);
  const close = () => setOpen(null);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="outlined" onClick={() => setOpen('default')}>
        Default (dimmed)
      </Button>
      <Button variant="outlined" onClick={() => setOpen('invisible')}>
        Invisible
      </Button>
      <Backdrop open={open === 'default'} onClose={close} closeOnClick closeOnEscape>
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
      <Backdrop open={open === 'invisible'} invisible onClose={close} closeOnClick closeOnEscape>
        <CircularProgress label="Loading" />
      </Backdrop>
    </Stack>
  );
}

With content#

Children are centered with flexbox; combine them with Stack and Typography. Any element marked with data-mtx-backdrop-close closes the layer (reason click), even without closeOnClick.

import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';

  const [open, setOpen] = useState(false);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">

        Sync with message

    </Stack>
  );
}

Closing#

  • closeOnClick: a click on the layer or on non-interactive content asks to close (reason click). Clicks on buttons, links or fields inside the content are ignored.
  • closeOnEscape: Escape asks to close (reason escape) through the shared layer stack, so it only reaches the top layer.
  • Without either flag the layer only closes when you set open={false} (for example, when the operation ends).
Closing open_in_new
import { useEffect, useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import type { BackdropCloseReason } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

type Mode = 'click' | 'escape' | 'timer';

export default function Demo() {
  const [open, setOpen] = useState<Mode | null>(null);
  const [last, setLast] = useState('—');
  const close = (_event: unknown, reason: BackdropCloseReason) => {
    setLast(reason);
    setOpen(null);
  };

  useEffect(() => {
    if (open !== 'timer') return undefined;
    const timer = setTimeout(() => {
      setOpen(null);
      setLast('timer (open = false)');
    }, 2000);
    return () => clearTimeout(timer);
  }, [open]);

  return (
    <Stack spacing={2}>
      <Stack direction="row" spacing={2} wrap alignItems="center">
        <Button variant="outlined" onClick={() => setOpen('click')}>
          Close on click
        </Button>
        <Button variant="outlined" onClick={() => setOpen('escape')}>
          Close with Escape
        </Button>
        <Button variant="outlined" onClick={() => setOpen('timer')}>
          Close after 2 s
        </Button>
      </Stack>
      <Typography variant="caption" color="text-secondary" component="p" role="status">
        Last reason: {last}
      </Typography>
      <Backdrop open={open === 'click'} closeOnClick onClose={close}>
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
      <Backdrop open={open === 'escape'} closeOnEscape onClose={close}>
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
      <Backdrop open={open === 'timer'}>
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
    </Stack>
  );
}

States#

lockScroll locks the <body> scroll while it is open (modal manager shared with Dialog), and inertOthers marks the rest of the document as inert (no focus, no clicks, hidden from screen readers) and restores it on close. With either of them the backdrop joins the layer stack and consumes Escape even if it doesn’t close with it.

States open_in_new
import { useEffect, useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  const [open, setOpen] = useState(false);

  useEffect(() => {
    if (!open) return undefined;
    const timer = setTimeout(() => setOpen(false), 3000);
    return () => clearTimeout(timer);
  }, [open]);

  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="outlined" onClick={() => setOpen(true)}>
        Lock scroll and inert (3 s)
      </Button>
      <Backdrop open={open} lockScroll inertOthers>
        <CircularProgress color="inherit" label="Processing payment" />
      </Backdrop>
    </Stack>
  );
}

Real-world examples#

Saving a form: the backdrop covers the page while the request runs and closes by itself when it finishes; then a Snackbar confirms the result. The project name is a TextField.

Real-world examples open_in_new
import { useEffect, useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { TextField } from '@rubenchodev/materix-react/components/text-field';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [saving, setSaving] = useState(false);
  const [saved, setSaved] = useState(false);

  useEffect(() => {
    if (!saving) return undefined;
    const timer = setTimeout(() => {
      setSaving(false);
      setSaved(true);
    }, 2000);
    return () => clearTimeout(timer);
  }, [saving]);

  return (
    <Stack component="form" spacing={2} alignItems="flex-start" onSubmit={(event) => {
      event.preventDefault();
      setSaving(true);
    }}>
      <TextField label="Project name" variant="outlined" defaultValue="Materix UI" name="project" />
      <Button type="submit" variant="contained" startIcon="save">
        Save
      </Button>
      <Backdrop open={saving} lockScroll>
        <Stack spacing={2} alignItems="center">
          <CircularProgress color="inherit" decorative />
          <Typography variant="subtitle1" color="inherit" role="status">
            Saving changes…
          </Typography>
        </Stack>
      </Backdrop>
      <Snackbar open={saved} onClose={() => setSaved(false)} message="Project saved" role="status" autoHideDuration={4000} />
    </Stack>
  );
}

Grid layout#

The layer is rendered in a portal on document.body and does not take part in the layout; here a grid of triggers opens the same backdrop with different messages.

Grid layout open_in_new
import { useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Grid } from '@rubenchodev/materix-react/components/grid';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

const ACTIONS = [
  { label: 'Export', message: 'Exporting report…' },
  { label: 'Invite', message: 'Sending invitations…' },
  { label: 'Archive', message: 'Archiving project…' },
];

export default function Demo() {
  const [message, setMessage] = useState<string | null>(null);
  const [lastMessage, setLastMessage] = useState('');
  const show = (text: string) => {
    setLastMessage(text);
    setMessage(text);
  };
  return (
    <>
      <Grid container spacing={2}>
        {ACTIONS.map(({ label, message: text }) => (
          <Grid key={label} size={{ xs: 12, sm: 4 }}>
            <Button variant="outlined" fullWidth onClick={() => show(text)}>
              {label}
            </Button>
          </Grid>
        ))}
      </Grid>
      <Backdrop open={message !== null} onClose={() => setMessage(null)} closeOnClick closeOnEscape>
        <Stack spacing={2} alignItems="center">
          <CircularProgress color="inherit" decorative />
          <Typography variant="subtitle1" color="inherit" role="status">
            {lastMessage}
          </Typography>
        </Stack>
      </Backdrop>
    </>
  );
}

Programmatic usage#

The equivalent of open()/close()/toggle() is the open prop. onOpen and onClose(event, reason) are the equivalents of mtx:backdrop:open and mtx:backdrop:close; onExited fires when the fade-out ends.

Programmatic usage open_in_new
import { useEffect, useState } from 'react';
import { Backdrop } from '@rubenchodev/materix-react/components/backdrop';
import { Button } from '@rubenchodev/materix-react/components/button';
import { CircularProgress } from '@rubenchodev/materix-react/components/progress';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [auto, setAuto] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [...lines, `${new Date().toLocaleTimeString()}  ${text}`]);

  useEffect(() => {
    if (!auto) return undefined;
    const timer = setTimeout(() => {
      setAuto(false);
      setOpen(false);
      write('open = false (after 1.5 s)');
    }, 1500);
    return () => clearTimeout(timer);
  }, [auto]);

  return (
    <Stack spacing={2}>
      <Stack direction="row" spacing={2} wrap alignItems="center">
        <Button variant="contained" onClick={() => setOpen(true)}>
          open = true
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setOpen(true);
            setAuto(true);
          }}
        >
          Open and close after 1.5 s
        </Button>
      </Stack>
      <Typography variant="caption" color="text-secondary" component="p" role="status">
        open: {String(open)}
      </Typography>
      <Backdrop
        open={open}
        closeOnClick
        closeOnEscape
        onOpen={() => write('onOpen')}
        onClose={(_event, reason) => {
          write(`onClose   reason: ${reason}`);
          setAuto(false);
          setOpen(false);
        }}
        onExited={() => write('onExited')}
      >
        <CircularProgress color="inherit" label="Loading" />
      </Backdrop>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </Stack>
  );
}

Reuse in other overlays#

Dialog, Drawer and other modal components render Backdrop as their background layer. These are the props they rely on:

<Backdrop
  open={open}                 // shows the layer with the fade
  invisible={false}           // transparent layer for menus/popovers
  onClick={handleBackdropClick} // always called, before the close logic
  className="mtx-dialog__backdrop"
  transitionDuration={{ enter: 225, exit: 195 }}
  disablePortal               // the overlay already renders inside its own portal
/>

API reference#

Backdrop props#

PropTypeDefaultDescription
openboolean—Shows the layer (controlled).
invisiblebooleanfalseTransparent layer (.mtx-backdrop--invisible).
closeOnClickbooleanfalseA click on the layer or non-interactive content asks to close.
closeOnEscapebooleanfalseEscape asks to close (layer stack).
lockScrollbooleanfalseLocks the <body> scroll while open.
inertOthersbooleanfalseMarks the rest of the document as inert while open.
onClick(event) => void—Click on the layer; always called.
onClose(event, reason: 'click' | 'escape') => void—Close request.
onOpen() => void—open goes from false to true.
onExited() => void—The fade-out finished.
transitionDurationnumber | { enter?, exit? }{ enter: 225, exit: 195 }Fade duration in ms.
disablePortalbooleanfalseRenders in place instead of on document.body.
containerElement | ref | () => Elementdocument.bodyPortal target.
keepMountedbooleanfalseKeeps the node (with hidden) while closed.

className is merged; ref, style (for example a custom zIndex) and any other attribute go to the root <div>.

Callbacks#

CallbackVanilla eventFired when
onOpen()mtx:backdrop:openopen goes from false to true (not on the initial render).
onClose(event, reason)mtx:backdrop:closeClick (click) or Escape (escape) asks to close.
onExited()—The fade-out ends and the node is unmounted.

ClassElement

CSS variables#

VariableUsage
--mtx-backdrop-bgLayer color (rgba(0, 0, 0, 0.5)).

Accessibility#

  • The backdrop has no role and doesn’t move focus: it is a visual indicator. Give the indicator an accessible name (CircularProgress label="Loading").
  • While closed or fading out it has aria-hidden="true".
  • To keep keyboard and screen reader users out of the page while it is busy, use inertOthers. For messages or decisions, use a Dialog, which traps focus.
KeyAction
EscapeCloses the layer with closeOnEscape (only if it is the top layer).
TabMoves through interactive content inside the layer.
