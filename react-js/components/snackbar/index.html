Snackbar

Brief, temporary notification at an edge of the screen that confirms an action and can offer to undo it.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Snackbar, SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react';

Snackbar shows a short floating message at an edge of the screen to confirm the outcome of an action (“Email sent”, “Item deleted”) and, optionally, offer a single action such as “Undo”. It does not interrupt the user and can close on its own. Do not use it for errors the user must resolve (use an Alert next to the content) or for mandatory decisions (use a Dialog).

import { Snackbar, SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react';
// or only this component:
import { Snackbar, SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react/components/snackbar';

Basic usage#

<Snackbar open={…} message="…"> is enough. open is controlled: onClose(event, reason) asks to close it and you update the state. It closes with Escape, on a click outside or, with autoHideDuration, when the time runs out.

Basic usage open_in_new
import { useState } from 'react';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';

export default function Demo() {
  const [open, setOpen] = useState(false);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="contained" onClick={() => setOpen(true)}>
        Show snackbar
      </Button>
      <Snackbar open={open} onClose={() => setOpen(false)} message="Message archived" autoHideDuration={4000} />
    </Stack>
  );
}

With action#

A text action renders the .mtx-snackbar__action button on the right; onAction runs when it is pressed and closeOnAction closes the snackbar (reason action). Any other node (for example an IconButton) is rendered as is.

With action open_in_new
import { useState } from 'react';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [open, setOpen] = useState<'text' | 'node' | null>(null);
  const [status, setStatus] = useState('');
  const close = () => setOpen(null);
  return (
    <Stack spacing={2}>
      <Stack direction="row" spacing={2} wrap alignItems="center">
        <Button variant="outlined" onClick={() => setOpen('text')}>
          Delete email
        </Button>
        <Button variant="outlined" onClick={() => setOpen('node')}>
          Custom action
        </Button>
      </Stack>
      <Typography variant="caption" color="text-secondary" component="p" role="status">
        {status}
      </Typography>
      <Snackbar
        open={open === 'text'}
        onClose={close}
        message="Email deleted"
        action="Undo"
        onAction={() => setStatus('Email restored')}
        closeOnAction
        autoHideDuration={6000}
      />
      <Snackbar
        open={open === 'node'}
        onClose={close}
        message="Draft saved"
        autoHideDuration={6000}
        action={
          <IconButton size="small" color="inherit" aria-label="Close" onClick={close}>
            <span className="material-icons">close</span>
          </IconButton>
        }
      />
    </Stack>
  );
}

Position#

anchorOrigin combines vertical (top/bottom) with horizontal (left/center/right); by default, bottom center. Below 600px the snackbar spans the full width with an 8px side margin.

Position open_in_new
import { useState } from 'react';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import type { SnackbarOrigin } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

const HORIZONTAL: SnackbarOrigin['horizontal'][] = ['left', 'center', 'right'];
const VERTICAL: SnackbarOrigin['vertical'][] = ['top', 'bottom'];

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [origin, setOrigin] = useState<SnackbarOrigin>({ vertical: 'bottom', horizontal: 'center' });
  const show = (next: SnackbarOrigin) => {
    setOrigin(next);
    setOpen(true);
  };
  return (
    <Stack spacing={2}>
      {VERTICAL.map((vertical) => (
        <Stack key={vertical} spacing={1.5}>
          <Typography variant="overline" color="text-secondary" component="span">
            {vertical === 'top' ? 'Top' : 'Bottom'}
          </Typography>
          <Stack direction="row" spacing={2} wrap alignItems="center">
            {HORIZONTAL.map((horizontal) => (
              <Button key={horizontal} variant="outlined" onClick={() => show({ vertical, horizontal })}>
                {vertical}-{horizontal}
              </Button>
            ))}
          </Stack>
        </Stack>
      ))}
      <Snackbar
        open={open}
        onClose={() => setOpen(false)}
        anchorOrigin={origin}
        message={`${origin.vertical} ${origin.horizontal}`}
        autoHideDuration={3000}
      />
    </Stack>
  );
}

Duration#

Without autoHideDuration (or with null) the snackbar does not close by itself. The timer pauses while the pointer or focus is on it and restarts with the full duration when they leave.

Duration open_in_new
import { useState } from 'react';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';

type Mode = 'short' | 'long' | 'persistent';

export default function Demo() {
  const [open, setOpen] = useState<Mode | null>(null);
  const close = () => setOpen(null);
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      <Button variant="outlined" onClick={() => setOpen('short')}>
        2 seconds
      </Button>
      <Button variant="outlined" onClick={() => setOpen('long')}>
        8 seconds
      </Button>
      <Button variant="outlined" onClick={() => setOpen('persistent')}>
        No auto-hide
      </Button>
      <Snackbar open={open === 'short'} onClose={close} message="Closes in 2 seconds" autoHideDuration={2000} />
      <Snackbar
        open={open === 'long'}
        onClose={close}
        message="Closes in 8 seconds (hover over it to pause)"
        autoHideDuration={8000}
      />
      <Snackbar open={open === 'persistent'} onClose={close} message="Stays until you close it" action="Close" closeOnAction />
    </Stack>
  );
}

Consecutive#

SnackbarProvider keeps a queue and shows one notice at a time: a new notice closes the visible one and appears when its exit transition ends, as in MUI’s Consecutive Snackbars example.

Consecutive open_in_new
import { SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';

function Buttons() {
  const { enqueue } = useSnackbar();
  return (
    <Stack direction="row" spacing={2} wrap alignItems="center">
      {['A', 'B', 'C'].map((name) => (
        <Button key={name} variant="outlined" onClick={() => enqueue({ message: `Message ${name}`, duration: 2500 })}>
          Message {name}
        </Button>
      ))}
    </Stack>
  );
}

export default function Demo() {
  return (
    <SnackbarProvider>
      <Buttons />
    </SnackbarProvider>
  );
}

With Alert#

For notifications with a severity, place an Alert as the child of a snackbar without message. The mtx-p-0 mtx-bg-transparent utilities remove the snackbar padding and background, and mtx-flex-1 stretches the alert.

import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';

  return (

      <Button variant="outlined" onClick={() => setOpen('error')}>
        Error
      </Button>
      <Snackbar
        open={open === 'success'}
        onClose={close}
        autoHideDuration={4000}
        anchorOrigin={{ vertical: 'bottom', horizontal: 'left' }}

        <Alert severity="success" variant="filled" className="mtx-flex-1">

        </Alert>
      </Snackbar>

Quick notices with useSnackbar()#

For one-off confirmations you don’t need to declare a snackbar: wrap the app once with <SnackbarProvider> and call useSnackbar().enqueue(message | options). The shared snackbar uses role="status" and a 4 s duration by default; onAction runs when the action is pressed and closes the notice. enqueue returns a key that close(key) accepts.

Quick notices with useSnackbar() open_in_new
import { useState } from 'react';
import { SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

function Actions() {
  const { enqueue } = useSnackbar();
  const [status, setStatus] = useState('');
  return (
    <Stack spacing={2}>
      <Stack direction="row" spacing={2} wrap alignItems="center">
        <Button variant="contained" onClick={() => enqueue('Link copied')}>
          Copy link
        </Button>
        <Button
          variant="outlined"
          onClick={() =>
            enqueue({
              message: 'Conversation archived',
              action: 'Undo',
              onAction: () => setStatus('Conversation restored'),
              duration: 6000,
              anchorOrigin: { vertical: 'bottom', horizontal: 'left' },
            })
          }
        >
          Archive with undo
        </Button>
      </Stack>
      <Typography variant="caption" color="text-secondary" component="p" role="status">
        {status}
      </Typography>
    </Stack>
  );
}

export default function Demo() {
  return (
    <SnackbarProvider>
      <Actions />
    </SnackbarProvider>
  );
}

Real-world examples#

A subscription form with an Email TextField: when the address is valid, the shared snackbar confirms it and offers to undo it.

Real-world examples open_in_new
import { useState } from 'react';
import type { FormEvent } from 'react';
import { SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

const EMAIL_RE = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

function SubscribeForm() {
  const { enqueue } = useSnackbar();
  const [email, setEmail] = useState('');
  const [error, setError] = useState(false);

  const submit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    if (!EMAIL_RE.test(email)) {
      setError(true);
      return;
    }
    setError(false);
    const subscribed = email;
    setEmail('');
    enqueue({
      message: `${subscribed} subscribed`,
      action: 'Undo',
      onAction: () => setEmail(subscribed),
      duration: 6000,
    });
  };

  return (
    <Stack component="form" spacing={2} alignItems="flex-start" className="demo-fixed-width" noValidate onSubmit={submit}>
      <TextField
        label="Email"
        type="email"
        name="email"
        variant="outlined"
        value={email}
        onChange={(_event, value) => setEmail(value)}
        error={error}
        helperText={error ? 'Enter a valid email address.' : 'We will send you one email per month.'}
      />
      <Button type="submit" variant="contained" startIcon="mail">
        Subscribe
      </Button>
    </Stack>
  );
}

export default function Demo() {
  return (
    <SnackbarProvider>
      <SubscribeForm />
    </SnackbarProvider>
  );
}

Grid layout#

A typical case: actions in a Grid where each one confirms its result with the shared snackbar.

Grid layout open_in_new
import { SnackbarProvider, useSnackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import type { ButtonColor } from '@rubenchodev/materix-react/components/button';
import { Grid } from '@rubenchodev/materix-react/components/grid';

const ACTIONS: Array<{ label: string; message: string; color?: ButtonColor }> = [
  { label: 'Copy', message: 'File copied' },
  { label: 'Move', message: 'File moved' },
  { label: 'Delete', message: 'File deleted', color: 'error' },
];

function Actions() {
  const { enqueue } = useSnackbar();
  return (
    <Grid container spacing={2}>
      {ACTIONS.map(({ label, message, color }) => (
        <Grid key={label} size={{ xs: 12, sm: 4 }}>
          <Button variant="contained" color={color} fullWidth onClick={() => enqueue({ message, duration: 3000 })}>
            {label}
          </Button>
        </Grid>
      ))}
    </Grid>
  );
}

export default function Demo() {
  return (
    <SnackbarProvider anchorOrigin={{ vertical: 'bottom', horizontal: 'left' }}>
      <Actions />
    </SnackbarProvider>
  );
}

Programmatic usage#

The equivalent of open()/close() is the open prop; setMessage()/setAction() are the message and action props. onOpen, onAction and onClose(event, reason) are the equivalents of mtx:snackbar:open, mtx:snackbar:action and mtx:snackbar:close. Escape only closes the most recent snackbar, and never while a dialog or menu is open on top.

Programmatic usage open_in_new
import { useState } from 'react';
import { Snackbar } from '@rubenchodev/materix-react/components/snackbar';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Stack } from '@rubenchodev/materix-react/components/stack';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [message, setMessage] = useState('Controlled from React state');
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [...lines, `${new Date().toLocaleTimeString()}  ${text}`]);

  return (
    <Stack spacing={2}>
      <Stack direction="row" spacing={2} wrap alignItems="center">
        <Button variant="contained" onClick={() => setOpen(true)}>
          open = true
        </Button>
        <Button
          variant="outlined"
          onClick={() => {
            setMessage(`Draft saved at ${new Date().toLocaleTimeString()}`);
            setOpen(true);
          }}
        >
          Change message
        </Button>
        <Button variant="outlined" onClick={() => setOpen(false)}>
          open = false
        </Button>
      </Stack>
      <Typography variant="caption" color="text-secondary" component="p" role="status">
        open: {String(open)}
      </Typography>
      <Snackbar
        open={open}
        message={message}
        action="Close"
        closeOnAction
        autoHideDuration={5000}
        onOpen={() => write('onOpen')}
        onAction={() => write('onAction')}
        onClose={(_event, reason) => {
          write(`onClose   reason: ${reason}`);
          setOpen(false);
        }}
        onExited={() => write('onExited')}
      />
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </Stack>
  );
}

API reference#

Snackbar props#

PropTypeDefaultDescription
openboolean—Shows the snackbar (controlled).
onClose(event, reason) => void—Close request; reason is timeout, clickaway, escapeKeyDown or action (api is reserved for useSnackbar().close()).
messageReactNode—Message (.mtx-snackbar__message).
actionReactNode—Text → .mtx-snackbar__action button; node → rendered as is.
onAction(event) => void—Click on the generated action.
closeOnActionbooleanfalseThe generated action closes the snackbar (reason action).
autoHideDurationnumber | nullnullAuto-close in ms; null disables it.
anchorOrigin{ vertical, horizontal }{ vertical: 'bottom', horizontal: 'center' }Position.
role'alert' | 'status''alert'Live role of the message.
disableClickAwaybooleanfalseA click outside doesn’t ask to close.
onOpen() => void—open goes from false to true.
onExited() => void—The exit transition finished (the node is unmounted).
childrenReactNode—Extra content between the message and the action (for example an Alert).

className is merged; ref, style and any other attribute go to the root <div>.

Accessibility#

  • The message has role="alert" (urgent, announced immediately) or role="status" for non-urgent notices; the shared snackbar of SnackbarProvider uses status.
  • The generated action is a native <button type="button">; the timer pauses while it has focus so keyboard users have time to use it.
  • Avoid essential information that disappears: use a long autoHideDuration (or none) when the notice has an action.
KeyAction
EscapeCloses the most recent snackbar (reason escapeKeyDown) if no dialog or menu is open.
TabMoves focus to the action.
Enter / SpaceActivates the action.
