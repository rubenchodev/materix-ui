Toggle Button

Toggle buttons group related options with exclusive or multiple selection; on their own they work as an on/off switch for a single action.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { ToggleButton, ToggleButtonGroup } from '@rubenchodev/materix-react';

Toggle Button groups related options in a block with joined borders: text alignment, formatting, list or grid view. A ToggleButtonGroup handles exclusive selection (like a radio) or multiple selection (like checkboxes), and a standalone ToggleButton switches a single action on and off, such as marking a favorite. To choose among many options use a Select; for a setting that applies immediately, a Switch.

warning

aria-label is required on icon-only buttons

A button without visible text needs an aria-label (or aria-labelledby) that describes the option: “Align left”, not “arrow”. Also name the group with aria-label or label.

Import#

import { ToggleButton, ToggleButtonGroup } from '@rubenchodev/materix-react';

Basic usage#

A <ToggleButtonGroup> with <ToggleButton> children. Each button only needs value and, when icon-only, icon and aria-label; the group joins their borders, manages aria-pressed and passes its size, color and disabled state through context.

Basic usage open_in_new
import { ToggleButton, ToggleButtonGroup } from '@rubenchodev/materix-react/components/toggle-button';

export default function Demo() {
  return (
    <div className="demo-row">
      <ToggleButtonGroup exclusive defaultValue="left" aria-label="Text alignment">
        <ToggleButton value="left" icon="format_align_left" aria-label="Align left" />
        <ToggleButton value="center" icon="format_align_center" aria-label="Center" />
        <ToggleButton value="right" icon="format_align_right" aria-label="Align right" />
        <ToggleButton value="justify" icon="format_align_justify" aria-label="Justify" disabled />
      </ToggleButtonGroup>
    </div>
  );
}

Exclusive and multiple selection#

With exclusive only one button can be active and the value is a string (or null). Without it the selection is multiple (MUI’s default) and the value is a string[] in DOM order.

Exclusive and multiple selection open_in_new
import { ToggleButton, ToggleButtonGroup } from '@rubenchodev/materix-react/components/toggle-button';

export default function Demo() {
  return (
    <div className="demo-row">
      <div className="demo-group">
        <span className="demo-label">exclusive</span>
        <ToggleButtonGroup exclusive defaultValue="center" aria-label="Alignment">
          <ToggleButton value="left" icon="format_align_left" aria-label="Left" />
          <ToggleButton value="center" icon="format_align_center" aria-label="Center" />
          <ToggleButton value="right" icon="format_align_right" aria-label="Right" />
        </ToggleButtonGroup>
      </div>
      <div className="demo-group">
        <span className="demo-label">multiple</span>
        <ToggleButtonGroup defaultValue={['bold', 'italic']} aria-label="Text formatting">
          <ToggleButton value="bold" icon="format_bold" aria-label="Bold" />
          <ToggleButton value="italic" icon="format_italic" aria-label="Italic" />
          <ToggleButton value="underlined" icon="format_underlined" aria-label="Underline" />
          <ToggleButton value="color" icon="format_color_fill" aria-label="Fill color" />
        </ToggleButtonGroup>
      </div>
    </div>
  );
}

Sizes#

size on the group (or on each button). The icon keeps its native 24px grid; the padding changes (7, 11 and 15px, as in MUI). Each row aligns with the Text Field and Button of the same height.

enforceValueSet prevents deselecting the last active button, so the group always has a value (MUI’s enforce value set pattern), in exclusive and multiple mode.

Standalone button#

A ToggleButton outside a group toggles its own state (defaultSelected) or is controlled with selected + onChange(event, selected, value).

Standalone button open_in_new
import { useState } from 'react';
import { ToggleButton } from '@rubenchodev/materix-react/components/toggle-button';

export default function Demo() {
  const [favorite, setFavorite] = useState(false);
  return (
    <div className="demo-row">
      <ToggleButton
        value="favorite"
        icon={favorite ? 'star' : 'star_border'}
        color="warning"
        selected={favorite}
        onChange={(_, selected) => setFavorite(selected)}
        aria-label="Mark as favorite"
      />
      <ToggleButton value="done" icon="check" color="success" defaultSelected aria-label="Mark as done" />
      <ToggleButton value="wifi" icon="wifi" size="small" defaultSelected>
        Wi-Fi
      </ToggleButton>
    </div>
  );
}

Real-world example#

An editor toolbar: multiple formatting and required exclusive alignment, both controlled.

Real-world example: editor toolbar open_in_new
import { useState } from 'react';
import type { ReactNode } from 'react';
import { Paper } from '@rubenchodev/materix-react/components/paper';
import { ToggleButton, ToggleButtonGroup } from '@rubenchodev/materix-react/components/toggle-button';
import type { ToggleButtonGroupValue } from '@rubenchodev/materix-react/components/toggle-button';
import { Typography } from '@rubenchodev/materix-react/components/typography';

type Align = 'left' | 'center' | 'right';

export default function Demo() {
  const [formats, setFormats] = useState<ToggleButtonGroupValue>(['bold']);
  const [align, setAlign] = useState<ToggleButtonGroupValue>('left');
  const list = Array.isArray(formats) ? formats : [];

  let text: ReactNode = 'The quick brown fox jumps over the lazy dog.';
  if (list.includes('underlined')) text = <u>{text}</u>;
  if (list.includes('italic')) text = <em>{text}</em>;
  if (list.includes('bold')) text = <strong>{text}</strong>;

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <ToggleButtonGroup size="small" value={formats} onChange={(_, next) => setFormats(next)} aria-label="Formatting">
          <ToggleButton value="bold" icon="format_bold" aria-label="Bold" />
          <ToggleButton value="italic" icon="format_italic" aria-label="Italic" />
          <ToggleButton value="underlined" icon="format_underlined" aria-label="Underline" />
        </ToggleButtonGroup>
        <ToggleButtonGroup
          exclusive
          enforceValueSet
          size="small"
          value={align}
          onChange={(_, next) => setAlign(next)}
          aria-label="Alignment"
        >
          <ToggleButton value="left" icon="format_align_left" aria-label="Left" />
          <ToggleButton value="center" icon="format_align_center" aria-label="Center" />
          <ToggleButton value="right" icon="format_align_right" aria-label="Right" />
        </ToggleButtonGroup>
      </div>
      <Paper variant="outlined" className="demo-panel">
        <Typography variant="body1" align={align as Align}>
          {text}
        </Typography>
      </Paper>
    </div>
  );
}

Programmatic usage#

The group is controlled with value + onChange(event, value): writing value from code fires no onChange, as the vanilla setter.

Programmatic usage open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { ToggleButton, ToggleButtonGroup } from '@rubenchodev/materix-react/components/toggle-button';
import type { ToggleButtonGroupValue } from '@rubenchodev/materix-react/components/toggle-button';

export default function Demo() {
  const [value, setValue] = useState<ToggleButtonGroupValue>(['bold']);
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 6));

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <ToggleButtonGroup
          value={value}
          disabled={disabled}
          onChange={(_, next) => {
            setValue(next);
            write(`onChange → ${JSON.stringify(next)}`);
          }}
          aria-label="Formatting"
        >
          <ToggleButton value="bold" icon="format_bold" aria-label="Bold" />
          <ToggleButton value="italic" icon="format_italic" aria-label="Italic" />
          <ToggleButton value="underlined" icon="format_underlined" aria-label="Underline" />
        </ToggleButtonGroup>
      </div>
      <div className="demo-row">
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setValue(['italic', 'underlined']);
            write('value = ["italic","underlined"]');
          }}
        >
          Set italic + underline
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setDisabled(!disabled);
            write(`disabled = ${!disabled}`);
          }}
        >
          Toggle disabled
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}
const [formats, setFormats] = useState<ToggleButtonGroupValue>(['bold']);

<ToggleButtonGroup value={formats} onChange={(event, next) => setFormats(next)} aria-label="Formatting">
  <ToggleButton value="bold" icon="format_bold" aria-label="Bold" />
  <ToggleButton value="italic" icon="format_italic" aria-label="Italic" />
</ToggleButtonGroup>

Accessibility#

  • Every button is a native <button> with aria-pressed (WAI-ARIA toggle button pattern), also in exclusive mode. As in MUI, the group uses role="group" rather than radiogroup: the buttons keep their button semantics, all of them are tabbable and they can be deselected. For strict single-choice semantics, use Radio.
  • Name the group with aria-label, aria-labelledby or label, and every icon-only button with aria-label.
  • Icons carry aria-hidden="true". Disabled buttons use the native disabled.
KeyAction
Tab / Shift+TabMoves through the buttons (all are tabbable, as in MUI).
→ / ←Next/previous enabled button in horizontal groups (wraps around; reversed in RTL).
↓ / ↑Same in vertical groups.
Home / EndFirst / last enabled button.
Space / EnterToggles the focused button.
