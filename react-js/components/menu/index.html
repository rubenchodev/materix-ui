Menu

Temporary list of options anchored to a trigger: icons, shortcuts, dividers, selection, checkable items, submenus, context menu and full keyboard navigation.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Menu, MenuItem, MenuList, MenuDivider, MenuGroup, Submenu, ContextMenu, useMenu, useContextMenu } from '@rubenchodev/materix-react';

Menu displays a temporary list of actions or options on an elevated surface, anchored to the element that opens it, like MUI’s Menu (Popper + Paper + MenuList). Use it for contextual actions on an item (edit, duplicate, delete), account menus or compact toolbars. To pick a value in a form use a NativeSelect; for the app’s main navigation, use Tabs.

import { Menu, MenuItem, useMenu } from '@rubenchodev/materix-react';
// or only this component:
import { Menu, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';

Anatomy: .mtx-menu__popper (positioned in a portal) › .mtx-menu__paper (elevation 8) › .mtx-menu (role="menu") › .mtx-menu-item (role="menuitem") with optional .mtx-menu-item__icon, text, shortcut and .mtx-menu-item__check / .mtx-menu-item__expand.

Basic usage#

useMenu() is the equivalent of vanilla’s data-open-menu: spread triggerProps on the trigger and menuProps on the Menu. The trigger toggles the menu and gets aria-haspopup, aria-expanded and aria-controls. The menu closes when an option is chosen, on a click outside, with Escape or with Tab.

Basic usage open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';
import { Menu, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';

export default function Demo() {
  const menu = useMenu();
  return (
    <div className="demo-row">
      <Button variant="contained" {...menu.triggerProps}>
        Open menu
      </Button>
      <Menu {...menu.menuProps}>
        <MenuItem>Profile</MenuItem>
        <MenuItem>My account</MenuItem>
        <MenuItem>Sign out</MenuItem>
      </Menu>
    </div>
  );
}

Triggers#

Without useMenu, the menu is fully controlled, as in MUI: open, anchorEl and onClose. A single Menu can serve every row of a list: each button stores itself as anchorEl, so rows added later work too (vanilla needed click delegation for that).

Triggers open_in_new
import { useState } from 'react';
import type { MouseEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { IconButton } from '@rubenchodev/materix-react/components/icon-button';
import { List, ListItem } from '@rubenchodev/materix-react/components/list';
import { Paper } from '@rubenchodev/materix-react/components/paper';
import { Menu, MenuDivider, MenuItem } from '@rubenchodev/materix-react/components/menu';

export default function Demo() {
  const [rows, setRows] = useState([
    { name: 'Annual report.pdf', size: '2.4 MB' },
    { name: 'Budget.xlsx', size: '310 KB' },
  ]);
  const [anchor, setAnchor] = useState<{ el: HTMLElement; name: string } | null>(null);
  const [log, setLog] = useState<string[]>([]);

  const openFor = (name: string) => (event: MouseEvent<HTMLElement>) => {
    const el = event.currentTarget;
    setAnchor((prev) => (prev?.el === el ? null : { el, name }));
  };

  return (
    <div className="demo-stack">
      <Paper variant="outlined" className="demo-wide">
        <List aria-label="Files">
          {rows.map((row) => (
            <ListItem
              key={row.name}
              icon="description"
              secondary={row.size}
              secondaryAction={
                <IconButton
                  icon="more_vert"
                  aria-label={`Actions for ${row.name}`}
                  aria-haspopup="menu"
                  aria-expanded={anchor?.name === row.name}
                  aria-controls={anchor?.name === row.name ? 'menu-row-actions' : undefined}
                  onClick={openFor(row.name)}
                />
              }
            >
              {row.name}
            </ListItem>
          ))}
        </List>
      </Paper>
      <Menu
        id="menu-row-actions"
        open={anchor !== null}
        anchorEl={anchor?.el}
        onClose={() => setAnchor(null)}
        onSelect={({ value }) => setLog((lines) => [`${value} → ${anchor?.name}`, ...lines].slice(0, 5))}
      >
        <MenuItem icon="edit" value="rename">
          Rename
        </MenuItem>
        <MenuItem icon="content_copy" value="duplicate">
          Duplicate
        </MenuItem>
        <MenuDivider />
        <MenuItem icon="delete" value="delete">
          Delete
        </MenuItem>
      </Menu>
      <div className="demo-row">
        <Button
          variant="outlined"
          startIcon="add"
          onClick={() => setRows((list) => [...list, { name: `New file ${list.length + 1}.txt`, size: '1 KB' }])}
        >
          Add row
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

States#

selected highlights the current option and receives focus when the menu is opened with the keyboard; disabled adds aria-disabled="true" and removes it from the navigation.

States open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Menu, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';

const VIEWS = [
  { value: 'list', label: 'List', icon: 'view_list', disabled: false },
  { value: 'grid', label: 'Grid', icon: 'grid_view', disabled: false },
  { value: 'timeline', label: 'Timeline (coming soon)', icon: 'view_timeline', disabled: true },
];

export default function Demo() {
  const menu = useMenu();
  const [view, setView] = useState('list');
  const current = VIEWS.find((v) => v.value === view) ?? VIEWS[0];
  return (
    <div className="demo-row">
      <Button variant="outlined" {...menu.triggerProps}>
        View: {current.label}
      </Button>
      <Menu {...menu.menuProps} onSelect={({ value }) => value && setView(value)}>
        {VIEWS.map((v) => (
          <MenuItem key={v.value} value={v.value} icon={v.icon} selected={v.value === view} disabled={v.disabled}>
            {v.label}
          </MenuItem>
        ))}
      </Menu>
    </div>
  );
}

Checkable options#

role="menuitemcheckbox" toggles aria-checked on click (checked + onCheckedChange, or defaultChecked). role="menuitemradio" items inside a MenuGroup with value/defaultValue behave as a single choice; onSelect also receives the new checked state. The check mark only shows on checked options.

Checkable options open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Menu, MenuDivider, MenuGroup, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';

export default function Demo() {
  const menu = useMenu();
  const [ruler, setRuler] = useState(true);
  const [grid, setGrid] = useState(false);
  const [density, setDensity] = useState('Comfortable');
  return (
    <div className="demo-row">
      <Button variant="outlined" {...menu.triggerProps}>
        View
      </Button>
      <Menu {...menu.menuProps}>
        <MenuItem role="menuitemcheckbox" checked={ruler} onCheckedChange={setRuler}>
          Ruler
        </MenuItem>
        <MenuItem role="menuitemcheckbox" checked={grid} onCheckedChange={setGrid}>
          Grid
        </MenuItem>
        <MenuDivider />
        <MenuGroup label="Density" value={density} onChange={setDensity}>
          <MenuItem role="menuitemradio" value="Comfortable">
            Comfortable
          </MenuItem>
          <MenuItem role="menuitemradio" value="Compact">
            Compact
          </MenuItem>
        </MenuGroup>
      </Menu>
      <span className="demo-status" aria-live="polite">
        Ruler: {ruler ? 'yes' : 'no'} · Grid: {grid ? 'yes' : 'no'} · Density: {density}
      </span>
    </div>

Positioning#

The menu opens below the anchor, aligned to its start edge (placement="bottom-start"); if there is no room it flips upwards, and while the page scrolls it keeps the chosen side (lockSide). The height is limited to the available space and, in RTL, the alignment is mirrored. matchWidth matches the anchor width; anchorEl can be any element, a ref or a virtual anchor. If the anchor leaves the viewport the menu asks to close with anchorHidden.

Positioning open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Chip } from '@rubenchodev/materix-react/components/chip';
import { Menu, MenuItem, useMenu } from '@rubenchodev/materix-react/components/menu';

const SORTS = ['Relevance', 'Newest', 'Price'];
const FILTERS = ['All', 'Active', 'Archived'];

export default function Demo() {
  const sort = useMenu();
  const top = useMenu();
  const [sortBy, setSortBy] = useState('Relevance');
  const chipRef = useRef<HTMLElement>(null);
  const [filterOpen, setFilterOpen] = useState(false);
  const [filter, setFilter] = useState('All');

  return (
    <div className="demo-row">
      <div className="demo-group">
        <span className="demo-label">matchWidth</span>
        <div className="demo-row">
          <Button variant="contained" {...sort.triggerProps}>
            Sort by: {sortBy.toLowerCase()}
          </Button>
          <Menu {...sort.menuProps} matchWidth onSelect={({ value }) => value && setSortBy(value)}>
            {SORTS.map((s) => (
              <MenuItem key={s} value={s} selected={s === sortBy}>
                {s}
              </MenuItem>
            ))}
          </Menu>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">placement=&quot;top-start&quot;</span>
        <div className="demo-row">
          <Button variant="outlined" {...top.triggerProps}>
            Open upwards
          </Button>
          <Menu {...top.menuProps} placement="top-start">
            <MenuItem>Above</MenuItem>
            <MenuItem>The trigger</MenuItem>
          </Menu>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">anchorEl = Chip</span>
        <div className="demo-row">
          <Chip
            ref={chipRef}
            variant="outlined"
            label={`Filter: ${filter.toLowerCase()}`}
            clickable
            aria-haspopup="menu"
            aria-expanded={filterOpen}
            aria-controls={filterOpen ? 'menu-anchor-chip' : undefined}
            onClick={() => setFilterOpen((v) => !v)}
          />
          <Menu
            id="menu-anchor-chip"
            open={filterOpen}
            anchorEl={chipRef}
            onClose={() => setFilterOpen(false)}
            onSelect={({ value }) => value && setFilter(value)}
          >
            {FILTERS.map((f) => (
              <MenuItem key={f} value={f} selected={f === filter}>
                {f}
              </MenuItem>
            ))}
          </Menu>
        </div>
      </div>
    </div>
  );
}

Submenus#

<Submenu label icon> renders an item with aria-haspopup="menu" and a chevron that opens a nested menu next to it: on hover (after 100 ms), on click, or with →, Enter or Space. Hovering another item closes it after 50 ms; ← or Escape close it and return focus to its item. Choosing an option closes the whole chain and reaches the root onSelect. In RTL it opens to the left, the chevron is mirrored and the arrow keys are swapped; if there is no room, it flips to the other side.

Context menu#

<ContextMenu target items> is the equivalent of Materix.Menu.createContextMenu(selector, items): target is an element, a ref or a CSS selector (delegated on document, so areas added later also work); each item accepts label, icon, image, shortcut, disabled, divider, action and submenu. It opens on right-click at the pointer position (anchorPosition); with the Menu key or Shift+F10 it anchors to the area and focuses the first option. For your own markup, useContextMenu() returns onContextMenu and the props of a Menu.

Context menu open_in_new
import { useRef, useState } from 'react';
import { ContextMenu, Menu, MenuItem, useContextMenu } from '@rubenchodev/materix-react/components/menu';

export default function Demo() {
  const areaRef = useRef<HTMLDivElement>(null);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 5));
  const custom = useContextMenu();

  return (
    <div className="demo-stack">
      <div ref={areaRef} className="demo-panel" tabIndex={0} role="region" aria-label="Context menu area">
        Right-click here (ContextMenu)
      </div>
      <ContextMenu
        target={areaRef}
        items={[
          { label: 'Copy', icon: 'content_copy', shortcut: '⌘C', action: () => write('Copy') },
          { label: 'Paste', icon: 'content_paste', disabled: true },
          { divider: true },
          {
            label: 'Share',
            icon: 'share',
            submenu: [
              { label: 'Email', icon: 'mail', action: () => write('Share → Email') },
              { label: 'Copy link', icon: 'link', action: () => write('Share → Copy link') },
            ],
          },
        ]}
      />
      <div
        className="demo-panel"
        tabIndex={0}
        role="region"
        aria-label="Custom context menu area"
        onContextMenu={custom.onContextMenu}
      >
        Right-click here (useContextMenu)
      </div>
      <Menu {...custom.menuProps} onSelect={({ value }) => value && write(`useContextMenu → ${value}`)}>
        <MenuItem icon="refresh" value="reload">
          Reload
        </MenuItem>
        <MenuItem icon="print" value="print">
          Print
        </MenuItem>
      </Menu>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Programmatic usage#

The equivalent of open()/close() is the open prop. onOpen, onSelect(detail, event) and onClose(event, reason) are the equivalents of mtx:menu:open, mtx:menu:select and mtx:menu:close. restoreFocusTo chooses who receives focus when the menu closes.

Programmatic usage open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Menu, MenuItem } from '@rubenchodev/materix-react/components/menu';

export default function Demo() {
  const anchorRef = useRef<HTMLButtonElement>(null);
  const [open, setOpen] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((lines) => [text, ...lines].slice(0, 6));

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button ref={anchorRef} variant="outlined">
          Menu anchor
        </Button>
        <Button variant="contained" onClick={() => setOpen(true)}>
          setOpen(true)
        </Button>
        <Button variant="text" onClick={() => write(`open = ${open}`)}>
          Read open
        </Button>
      </div>
      <Menu
        open={open}
        anchorEl={anchorRef}
        restoreFocusTo={anchorRef}
        onOpen={() => write('onOpen')}
        onSelect={({ value }) => write(`onSelect → ${value}`)}
        onClose={(_event, reason) => {
          write(`onClose → ${reason}`);
          setOpen(false);
        }}
      >
        <MenuItem icon="save" value="save">
          Save
        </MenuItem>
        <MenuItem icon="file_download" value="export">
          Export
        </MenuItem>
      </Menu>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Composition: MenuList#

Menu is made of a portal, a Grow transition, the paper and a MenuList. MenuList on its own (inside a Paper) keeps the keyboard navigation for always-visible menus. The split button of Button Group anchors a Menu to the whole group with matchWidth and returns focus to the arrow.

Full composition#

The equivalent of vanilla’s Manual BEM usage: there is no hand-written markup in React, but every part can be replaced. Items can be native <button> elements (component="button"), icons can be any node (an inline SVG) and checked options show their .mtx-menu-item__check; the resulting DOM is the same BEM structure.

Full composition open_in_new

Accessibility#

  • The list has role="menu" and each item role="menuitem" (or menuitemcheckbox / menuitemradio with a synchronized aria-checked) and tabindex="-1" (roving focus); separators have role="separator". useMenu gives the trigger aria-haspopup="menu", aria-expanded, aria-controls (while open) and labels the menu with aria-labelledby.
  • Opened from the keyboard, focus goes to the selected or first enabled option; with the mouse, to the menu container. After Escape or a choice, focus returns to the trigger; after a click outside, it stays where the user clicked.
  • Generated icons are decorative (aria-hidden). Give icon-only triggers an aria-label.
  • Escape is delivered through the shared layer stack: it closes only the topmost menu or submenu, never a dialog underneath.
  • With prefers-reduced-motion the menu appears without the Grow animation.
KeyAction
Enter / Space (trigger)Opens the menu and focuses the first option.
↓ / ↑Next / previous option, wrapping around.

Enter / SpaceActivates the focused option (opens a submenu).
