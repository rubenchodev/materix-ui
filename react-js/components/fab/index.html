Fab

Floating action button for a screen's primary action: circular (56/48/40px) or extended with text (48px).

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Fab } from '@rubenchodev/materix-react';

Fab (Floating Action Button) represents the primary or most common action on a screen —compose, create, add— and floats above the content with high elevation. Use at most one per screen. For secondary actions use a Button; for compact actions in toolbars or rows, an Icon Button.

import { Fab } from '@rubenchodev/materix-react';
// or only this component:
import { Fab } from '@rubenchodev/materix-react/components/fab';

Basic usage#

icon generates a circular FAB; adding label turns it into an extended FAB with text. The circular FAB needs an aria-label.

Basic usage open_in_new
import { Fab } from '@rubenchodev/materix-react/components/fab';

export const description = {
  en: '`icon` generates a circular FAB; add `label` and it becomes extended. The circular FAB needs an `aria-label` because it only shows an icon.',
  es: '`icon` genera un FAB circular; añade `label` y pasa a ser extendido. El FAB circular necesita `aria-label` porque solo muestra un icono.',
};

export default function Demo() {
  return (
    <div className="demo-row">
      <Fab icon="add" aria-label="Create" />
      <Fab icon="edit" color="secondary" aria-label="Edit" />
      <Fab icon="navigation" label="Navigate" />
    </div>
  );
}

Variants#

  • Circular (default): icon only, 56px.
  • Extended (mtx-fab--extended): icon and text, 48px tall. It is enabled automatically with label, or with variant="extended" if you write the content yourself as children.

  es: 'El FAB circular es la forma estándar. El extendido añade un texto para hacer la acción más explícita: actívalo con `label`, o con `variant="extended"` si escribes tú el contenido.',
};

export default function Demo() {
  return (
    <div className="demo-grid-3">
      <div className="demo-group">
        <span className="demo-label">Circular</span>
        <div className="demo-row">
          <Fab icon="add" aria-label="Create" />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Extended · label</span>
        <div className="demo-row">
          <Fab icon="add" label="New ticket" />
        </div>

      <div className="demo-group">

}

With icons#

Combine icon and label: icon only, icon and text, or text only. A string icon is decorative (aria-hidden="true"); icon also accepts a node such as an <svg> (24px). The label text is the accessible name of the extended FAB.

Position#

position="fixed-br" and "fixed-bl" pin the FAB 24px from the bottom-right or bottom-left corner of the window (z-index of the SpeedDial layer). "absolute-center" centers it over the top edge of its positioned container, as in a bottom bar.

Programmatic usage#

The vanilla size/color setters and disable()/enable() become props driven by your state. ref gives you the DOM element. Fab emits no events of its own: use onClick.

Programmatic usage open_in_new
import { Button } from '@rubenchodev/materix-react/components/button';
import { useState } from 'react';
import { Fab } from '@rubenchodev/materix-react/components/fab';
import type { FabColor, FabSize } from '@rubenchodev/materix-react/components/fab';

export const description = {
  en: 'The vanilla `size`/`color` setters and `disable()`/`enable()` become props driven by state. Fab emits no events of its own: use `onClick`.',
  es: 'Los setters `size`/`color` y `disable()`/`enable()` de vanilla pasan a ser props controladas por estado. Fab no emite eventos propios: usa `onClick`.',
};

const sizes: FabSize[] = ['small', 'medium', 'large'];
const colors: FabColor[] = ['primary', 'secondary', 'success'];

export default function Demo() {
  const [size, setSize] = useState<FabSize>('large');
  const [color, setColor] = useState<FabColor>('primary');
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);

  const write = (message: string) =>
    setLog((prev) => [`[${new Date().toLocaleTimeString()}] ${message}`, ...prev].slice(0, 20));

  return (
    <>
      <div className="demo-group">
        <span className="demo-label">Controlled FAB</span>
        <div className="demo-row">
          <Fab
            icon="bolt"
            aria-label="Quick action"
            size={size}
            color={color}
            disabled={disabled}
            onClick={() => write('click on "Quick action"')}
          />
          <span className="demo-status">
            size: {size} · color: {color} · disabled: {String(disabled)}
          </span>
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Actions</span>
        <div className="demo-row">
          {sizes.map((value) => (
            <Button
              key={value}
              variant="outlined" size="small"
              onClick={() => {
                setSize(value);
                write(`size = '${value}'`);
              }}
            >
              size = &apos;{value}&apos;
            </Button>
          ))}
        </div>
        <div className="demo-row">
          {colors.map((value) => (
            <Button
              key={value}
              variant="outlined" size="small"
              onClick={() => {
                setColor(value);
                write(`color = '${value}'`);
              }}
            >
              color = &apos;{value}&apos;
            </Button>
          ))}
        </div>
        <div className="demo-row">
          {[true, false].map((value) => (
            <Button
              key={String(value)}
              variant="outlined" size="small"
              onClick={() => {
                setDisabled(value);
                write(`disabled = ${value}`);
              }}
            >
              disabled = {String(value)}
            </Button>
          ))}
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </>
  );
}

API reference#

Props#

PropTypeDefaultDescription
iconReactNode—Leading icon: Material Icons name ("add") or a node (SVG…).
labelReactNode—Text in a <span>; makes the FAB extended.
variant'circular' | 'extended''circular'Forces the extended variant (always extended with label).
size'small' | 'medium' | 'large''large'See the sizes table.
color'primary' | 'secondary' | 'default' | 'success' | 'error' | 'warning' | 'info' | 'inherit''primary'FAB color.
position'fixed-br' | 'fixed-bl' | 'absolute-center'—Floating position.
disabledbooleanfalseNative disabled; aria-disabled on links.
disableRipplebooleanfalseTurns off the ripple.
hrefstring—Renders an <a>.
componentElementType'button' / 'a'Custom root element.
childrenReactNode—Extra content after the icon and the label.
className, style, ref, aria-*, on*…——Forwarded to the root; className is merged.

CSS classes#

ClassDescription
mtx-fabBase class: 56px circle with elevation 6.

Accessibility#

  • It renders a native <button> with type="button". The circular FAB needs an aria-label; the extended FAB takes its name from its text.
  • Place it at a sensible point of the reading order: even though it floats visually, its position in the DOM sets the tab order.
  • disabled removes it from the tab order.
KeyAction
Tab / Shift+TabMoves focus.
Enter / SpaceActivates the action.
