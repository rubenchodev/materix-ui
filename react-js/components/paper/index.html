Paper

The base Material Design surface, with background, border radius and shadow, that groups content and expresses elevation.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Paper } from '@rubenchodev/materix-react';

Paper is the physical surface of Material Design: a container with a paper background, a 4px border radius and a shadow that conveys its elevation. It is the visual foundation of Card, Dialog, Menu and AppBar. Use it to group arbitrary content on top of the page background; if the block has a header, an image and actions, use a Card directly.

import { Paper } from '@rubenchodev/materix-react';
// or only this component:
import { Paper } from '@rubenchodev/materix-react/components/paper';

Basic usage#

<Paper> renders a <div class="mtx-paper"> with elevation 1. Change the shadow with elevation.

Basic usage open_in_new
import { Paper } from '@rubenchodev/materix-react/components/paper';

const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface">
      <Paper className={boxClass} style={box}>
        Elevation 1
      </Paper>
      <Paper elevation={8} className={boxClass} style={box}>
        Elevation 8
      </Paper>
    </div>
  );
}

Variants#

The default variant (elevation) sets the surface apart with a shadow. variant="outlined" outlines it with a 1px border (--mtx-color-divider) and no shadow; elevation={0} makes it flat.

Variants open_in_new
import { Paper } from '@rubenchodev/materix-react/components/paper';

const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface">
      <div className="demo-group">
        <span className="demo-label">Elevation</span>
        <Paper className={boxClass} style={box}>
          Shadow
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">Outlined</span>
        <Paper variant="outlined" className={boxClass} style={box}>
          Border
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">Elevation 0</span>
        <Paper elevation={0} className={boxClass} style={box}>
          Flat
        </Paper>
      </div>
    </div>
  );
}

Elevations#

Only MUI elevations 0 to 8, 12, 16 and 24 exist as tokens (--mtx-elevation-*). Any other value generates an unstyled class and the surface keeps the base elevation 1.

Elevations open_in_new
import { Paper, type PaperElevation } from '@rubenchodev/materix-react/components/paper';

const levels: PaperElevation[] = [0, 1, 2, 3, 4, 5, 6, 7, 8, 12, 16, 24];
const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface">
      {levels.map((level) => (
        <Paper key={level} elevation={level} className={boxClass} style={box}>
          {level}
        </Paper>
      ))}
    </div>
  );
}

Shape#

Corners use --mtx-shape-radius (4px). square makes them straight, which is useful for surfaces flush with the edges of the viewport.

Shape open_in_new
import { Paper } from '@rubenchodev/materix-react/components/paper';

const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface">
      <div className="demo-group">
        <span className="demo-label">Rounded · 4px</span>
        <Paper elevation={3} className={boxClass} style={box}>
          Rounded
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">Square</span>
        <Paper elevation={3} square className={boxClass} style={box}>
          Square
        </Paper>
      </div>
      <div className="demo-group">
        <span className="demo-label">Outlined square</span>
        <Paper variant="outlined" square className={boxClass} style={box}>
          Outlined
        </Paper>
      </div>
    </div>
  );
}

Dark theme#

Paper consumes --mtx-color-background-paper and --mtx-color-text-primary, so it follows the theme. data-mtx-theme="dark" also works on a specific container. In the dark theme, as in MUI, each elevation adds a white overlay (--mtx-overlay-elevation-N) through background-image, so higher surfaces look lighter; outlined has no overlay.

Surfaces in the dark theme open_in_new
import { Paper } from '@rubenchodev/materix-react/components/paper';

const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface" data-mtx-theme="dark">
      {[0, 1, 4, 8, 24].map((level) => (
        <Paper key={level} elevation={level} className={boxClass} style={box}>
          Elevation {level}
        </Paper>
      ))}
      <Paper variant="outlined" className={boxClass} style={box}>
        Outlined
      </Paper>
    </div>
  );
}

Grid#

Paper is the usual container for grid items: the column sets the width and Paper provides the surface.

Grid open_in_new
import { Grid } from '@rubenchodev/materix-react/components/grid';

const box = { height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  return (
    <div className="demo-surface">
      <Grid container spacing={2} className="mtx-w-100">
        <Grid xs={12} md={8}>
          <Paper className={boxClass} style={box}>
            xs=12 md=8
          </Paper>
        </Grid>
        <Grid xs={12} md={4}>
          <Paper className={boxClass} style={box}>
            xs=12 md=4
          </Paper>
        </Grid>
        <Grid xs={6} md={4}>
          <Paper variant="outlined" className={boxClass} style={box}>
            xs=6 md=4
          </Paper>
        </Grid>
        <Grid xs={6} md={8}>
          <Paper variant="outlined" className={boxClass} style={box}>
            xs=6 md=8
          </Paper>
        </Grid>
      </Grid>
    </div>
  );
}

Programmatic usage#

There is nothing to initialize: elevation, variant and square are ordinary props, so changing them updates the classes on the next render.

Programmatic usage open_in_new
import { useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { Paper, type PaperElevation } from '@rubenchodev/materix-react/components/paper';

const levels: PaperElevation[] = [0, 1, 2, 3, 4, 6, 8, 12, 16, 24];
const box = { width: 120, height: 120 } as const;
const boxClass = 'mtx-d-flex mtx-align-items-center mtx-justify-content-center mtx-text-center';

export default function Demo() {
  const [items, setItems] = useState<PaperElevation[]>([]);
  const add = () => setItems((prev) => [...prev, levels[prev.length % levels.length]]);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Button variant="contained" onClick={add}>
          Create Paper
        </Button>
        <Button variant="outlined" onClick={() => setItems([])}>
          Clear
        </Button>
      </div>
      <div className="demo-surface">
        {items.map((level, index) => (
          <Paper key={index} elevation={level} className={boxClass} style={box}>
            Elevation {level}
          </Paper>
        ))}
      </div>
      <pre className="demo-log" aria-live="polite">
        {items.map((level) => `<Paper elevation={${level}} /> → mtx-paper mtx-paper--elevation-${level}`).join('\n')}
      </pre>
    </div>
  );
}

Semantic element and composition#

component changes the root tag (section, article, aside…) without changing the look. Combine it with Typography for the content.

Semantic element and composition open_in_new
import { Paper } from '@rubenchodev/materix-react/components/paper';
import { Typography } from '@rubenchodev/materix-react/components/typography';

export default function Demo() {
  return (
    <div className="demo-surface">
      <Paper component="section" elevation={2} aria-labelledby="order-summary" className="mtx-p-2 demo-wide">
        <Typography id="order-summary" component="h3" variant="h6" gutterBottom>
          Order summary
        </Typography>
        <Typography variant="body2">3 items · Standard shipping · Total $74.90</Typography>
      </Paper>
    </div>
  );
}

API#

Props#

PropTypeDefaultDescription
elevation0–8 | 12 | 16 | 24—Adds .mtx-paper--elevation-{n}. Without it the base shadow (elevation 1) applies.
variant'elevation' | 'outlined''elevation'outlined adds .mtx-paper--outlined (border, no shadow).
squarebooleanfalseAdds .mtx-paper--square (no border radius).
componentElementType'div'Root element or component.
classNamestring—Merged with the component classes.
refRef<HTMLElement>—Points to the root element.

Any other prop (id, style, aria-*, data-*, events) is forwarded to the root element.

Callbacks#

Paper emits no events.

CSS classes#

ClassDescription
.mtx-paperPaper background, primary text color, 4px radius and elevation 1.
.mtx-paper--elevation-{n}--mtx-elevation-{n} shadow for n = 0–8, 12, 16, 24.
.mtx-paper--outlined1px --mtx-color-divider border, no shadow (wins over any elevation class).
.mtx-paper--squareborder-radius: 0.

Accessibility#

  • Paper is purely visual and adds no roles or ARIA: pick the semantic element with component (section, article, aside) and give it a heading (aria-labelledby) when it groups relevant content.
  • Elevation does not convey information on its own; use outlined or a heading when the surface must be clearly delimited.
  • It is not interactive: if the whole surface must be clickable, use a Card with an action area.
