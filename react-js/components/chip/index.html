Chip

A compact element that represents a tag, a filter, an input or an action; it can have an icon, an avatar and a delete button.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { Chip } from '@rubenchodev/materix-react';

Chip represents a compact piece of information: a tag, an active filter, a recipient or a short action. Use it for tag lists, selectable filters or inputs the user can remove. For a primary action use a Button; for a counter on an icon use a Badge.

import { Chip } from '@rubenchodev/materix-react';
// or only this component:
import { Chip } from '@rubenchodev/materix-react/components/chip';

Basic usage#

A single <Chip label="…" /> is enough. icon adds a start icon (a Material Icons name or any node) and onDelete adds the delete icon.

Basic usage open_in_new
import { Chip } from '@rubenchodev/materix-react/components/chip';

export default function Demo() {
  return (
    <div className="demo-row">
      <Chip label="Tag" />
      <Chip label="JavaScript" icon="code" color="primary" />
      <Chip label="Deletable" color="secondary" onDelete={() => {}} />
      <Chip label="Outlined" variant="outlined" icon="tag" />
    </div>
  );
}

filled (default) uses a solid background; outlined uses a border and a transparent background.

States#

A chip with onClick (or clickable) is interactive: pointer cursor, hover state, focus ring, role="button" and activation with Enter or Space. With component="button" the chip is a native <button> without browser border or padding. disabled lowers the opacity, removes focus and blocks the callbacks.

States open_in_new
import { Chip } from '@rubenchodev/materix-react/components/chip';

export default function Demo() {
  return (
    <div className="demo-stack">
      <div className="demo-group">
        <span className="demo-label">Normal · clickable (hover, focus, pressed)</span>
        <div className="demo-row">
          <Chip label="Static" />
          <Chip label="Clickable" clickable />
          <Chip label="Clickable primary" clickable color="primary" />
          <Chip label="Clickable outlined" clickable variant="outlined" />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">On a native &lt;button&gt;</span>
        <div className="demo-row">
          <Chip component="button" type="button" label="Button filled" clickable />
          <Chip component="button" type="button" label="Button outlined" variant="outlined" clickable />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Disabled</span>
        <div className="demo-row">
          <Chip label="Disabled" disabled />
          <Chip label="Outlined" variant="outlined" disabled />
          <Chip label="Clickable" color="primary" disabled onClick={() => {}} />
          <Chip label="Deletable" disabled onDelete={() => {}} />
        </div>
      </div>
    </div>
  );
}

Deletable#

onDelete shows the delete icon and is called when it is clicked or when Delete/Backspace is pressed while the chip has focus. The chip doesn’t remove itself: you update your state.

Deletable open_in_new
import { useState } from 'react';
import { Chip } from '@rubenchodev/materix-react/components/chip';
import { Button } from '@rubenchodev/materix-react/components/button';

const INITIAL = ['React', 'Vue', 'Svelte', 'Angular'];

export default function Demo() {
  const [tags, setTags] = useState(INITIAL);
  return (
    <div className="demo-stack">
      <div className="demo-row">
        {tags.map((tag) => (
          <Chip
            key={tag}
            label={tag}
            deleteLabel={`Remove ${tag}`}
            onDelete={() => setTags((current) => current.filter((item) => item !== tag))}
          />
        ))}
      </div>
      <div className="demo-row">
        <Button variant="text" onClick={() => setTags(INITIAL)}>
          Restore tags
        </Button>
      </div>
    </div>
  );
}

Filters#

Clickable chips that toggle between outlined (inactive) and primary (active), with aria-pressed as the accessible state.

Filters open_in_new
import { useState } from 'react';
import { Chip } from '@rubenchodev/materix-react/components/chip';

const FILTERS = ['Open', 'In review', 'Closed', 'Blocked'];

export default function Demo() {
  const [active, setActive] = useState<string[]>(['Open']);
  const toggle = (name: string) =>
    setActive((current) => (current.includes(name) ? current.filter((item) => item !== name) : [...current, name]));
  return (
    <div className="demo-stack">
      <div className="demo-row" role="group" aria-label="Filter issues">
        {FILTERS.map((name) => {
          const pressed = active.includes(name);
          return (
            <Chip
              key={name}
              label={name}
              color={pressed ? 'primary' : 'default'}
              variant={pressed ? 'filled' : 'outlined'}
              aria-pressed={pressed}
              onClick={() => toggle(name)}
            />
          );
        })}
      </div>
      <p className="demo-status" aria-live="polite">
        Active filters: {active.join(', ') || 'none'}
      </p>
    </div>
  );
}

Programmatic usage#

The label, the disabled state and the rest of the props are React state; ref points to the root element (for example, to focus it). The log shows the onClick and onDelete callbacks.

Programmatic usage open_in_new
import { useRef, useState } from 'react';
import { Chip } from '@rubenchodev/materix-react/components/chip';
import { Button } from '@rubenchodev/materix-react/components/button';

export default function Demo() {
  const [label, setLabel] = useState('Test chip');
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const chipRef = useRef<HTMLElement>(null);
  const write = (text: string) => setLog((lines) => [...lines, text]);

  const toggleLabel = () => {
    const next = label === 'Test chip' ? 'Updated label' : 'Test chip';
    setLabel(next);
    write(`label = "${next}"`);
  };
  const changeDisabled = (value: boolean) => {
    setDisabled(value);
    write(`disabled = ${value}`);
  };

  return (
    <div className="demo-stack">
      <div className="demo-row">
        <Chip
          ref={chipRef}
          label={label}
          icon="science"
          color="primary"
          disabled={disabled}
          onClick={(event) => write(`onClick (${event.type})`)}
          onDelete={(event) => write(`onDelete (${event.type})`)}
        />
      </div>
      <div className="demo-row">
        <Button variant="outlined" onClick={toggleLabel}>
          Change label
        </Button>
        <Button variant="outlined" onClick={() => changeDisabled(true)}>
          Disable
        </Button>
        <Button variant="outlined" onClick={() => changeDisabled(false)}>
          Enable
        </Button>
        <Button variant="text" onClick={() => chipRef.current?.focus()}>
          Focus (ref)
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
    </div>
  );
}

Accessibility#

  • Static chips are text with no role. Clickable or deletable chips get role="button" and tabindex="0" (unless component is button or a); disabled ones get aria-disabled="true" and tabindex="-1".
  • As in MUI, the delete icon is not a nested control: it is a <span aria-hidden="true"> that is never focusable. The chip is deleted with the mouse on the icon or with Delete/Backspace while it has focus, announced with aria-keyshortcuts="Delete Backspace".
  • The icon’s title comes from the i18n dictionary (Delete / Eliminar); make it specific with deleteLabel (for example, “Remove React”).
  • For filters, indicate the active state with aria-pressed.
  • String icons are rendered with aria-hidden="true"; mark your own icon nodes the same way.
KeyAction
Tab / Shift+TabMoves focus between interactive chips.
Enter / SpaceActivates a clickable chip (onClick).
Delete / BackspaceOn a deletable chip, calls onDelete.
EscapeRemoves focus from the chip.
