Text Field

Text field with a floating label, MUI variants, icons, counters, input masks and validation.

codeSource code play_circleDemo sources open_in_newMUI reference
Import import { TextField } from '@rubenchodev/materix-react';

TextField lets users enter and edit text in forms: name, email, password, amounts or long comments. It renders the same markup as the vanilla component after initialization: the floating <label>, the notched border (NotchedOutline, a fieldset with legend), the icons, the helper text and the counter, around a native <input>, <textarea> or <select>. To choose from a closed set of options use Select or NativeSelect.

import '@rubenchodev/materix-ui/base.css';
import { TextField } from '@rubenchodev/materix-react';

<TextField label="Full name" />

Basic usage#

A single element with label is enough. Native props (id, name, type, autoComplete, required, disabled, readOnly, maxLength, autoFocus…) go to the native control; className, style and other attributes go to the root <div>. Without label, the placeholder becomes the label (as in vanilla). multiline renders a <textarea>.

Basic usage open_in_new
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  return (
    <div className="demo-grid-3">
      <TextField label="Full name" />
      <TextField placeholder="Email (label from placeholder)" type="email" />
      <TextField label="Comment" multiline rows={1} />
    </div>
  );
}

Variants#

outlined (default, with border and notch), filled (background and bottom line) and standard (bottom line only). variant="no-label" draws a full border with no label or notch, for search boxes and filters. With select, the field wraps a native <select> (options as children) and adds a single chevron.

With icons#

startIcon and endIcon accept a Material Icons name ("email"), an image URL (rendered as <img class="mtx-text-field__adornment--image">) or a node (SVG, Material Symbols). With a start icon, the label is translated exactly 32px so its first letter lines up with the typed text. startAdornment and endAdornment take free content such as a $ prefix or a kg suffix; as in MUI, a free startAdornment keeps the label floated and aligned with the start of the field (the prefix sits where the text would start), in all three variants, because its width is not the 24px of an icon.

Interactive adornments#

The equivalent of MUI’s InputAdornment + IconButton. passwordToggle (only with type="password") adds the show/hide button with aria-pressed, aria-controls and a translated name, and calls onPasswordVisibilityChange(visible); the state can be controlled with passwordVisible. startAction / endAction create an IconButton with the given icon and call onAdornmentClick({ position, button, input }); name them with startActionLabel / endActionLabel. A mouse click does not steal focus from the field, and the buttons are disabled together with it.

Interactive adornments open_in_new
import { useState } from 'react';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  const [search, setSearch] = useState('Materix');
  const [location, setLocation] = useState('');
  const [log, setLog] = useState<string[]>([]);
  const write = (text: string) => setLog((prev) => [`${new Date().toLocaleTimeString()}  ${text}`, ...prev].slice(0, 6));
  const onVisibility = (visible: boolean) => write(`onPasswordVisibilityChange → visible: ${visible}`);

  return (
    <div className="demo-stack">
      <div className="demo-grid-3">
        <div className="demo-group">
          <span className="demo-label">Password · outlined</span>
          <TextField
            label="Password"
            type="password"
            passwordToggle
            autoComplete="new-password"
            helperText="At least 8 characters"
            onPasswordVisibilityChange={onVisibility}
          />
        </div>
        <div className="demo-group">
          <span className="demo-label">Password · filled + start icon</span>
          <TextField
            label="Password"
            variant="filled"
            startIcon="lock"
            type="password"
            passwordToggle
            autoComplete="new-password"
            onPasswordVisibilityChange={onVisibility}
          />
        </div>
        <div className="demo-group">
          <span className="demo-label">Password · small + counter</span>
          <TextField
            label="PIN"
            size="small"
            type="password"
            passwordToggle
            maxLength={6}
            inputMode="numeric"
            autoComplete="off"
            onPasswordVisibilityChange={onVisibility}
          />
        </div>
        <div className="demo-group">
          <span className="demo-label">End action · clear</span>
          <TextField
            label="Search"
            startIcon="search"
            endAction="close"
            endActionLabel="Clear search"
            type="search"
            value={search}
            onChange={(_, next) => setSearch(next)}
            onAdornmentClick={({ input }) => {
              setSearch('');
              input?.focus();
              write('onAdornmentClick (end) → field cleared');
            }}
          />
        </div>
        <div className="demo-group">
          <span className="demo-label">Start action · standard</span>
          <TextField
            label="Location"
            variant="standard"
            startAction="my_location"
            startActionLabel="Use my location"
            value={location}
            onChange={(_, next) => setLocation(next)}
            onAdornmentClick={() => {
              setLocation('Seattle, WA');
              write('onAdornmentClick (start) → approximate location');
            }}
          />
        </div>
        <div className="demo-group">
          <span className="demo-label">Disabled</span>
          <TextField label="Password" type="password" passwordToggle defaultValue="secret" disabled />
        </div>
      </div>
      <div className="demo-group">
        <span className="demo-label">Event log</span>
        <pre className="demo-log" aria-live="polite">
          {log.join('\n')}
        </pre>
      </div>
    </div>
  );
}

Input masks#

mask accepts a pattern (0 digit, a lowercase letter, A uppercase letter, * alphanumeric; any other character is a literal), a preset (phone, phone-intl, credit-card, date, date-short, time, time-ampm, time-seconds, cpf, cnpj, zip, postal-code) or currency, configurable with currencyOptions (prefix, suffix, thousands, decimal, precision). The value is formatted as you type and the caret keeps its position. onChange receives the formatted value and { unmaskedValue, isMaskComplete }.

Validation#

Combine native validation (required, type, checkValidity() through inputRef) with error and helperText. Inside a FormControl, the field inherits error, disabled and required and links the FormControl helper texts with aria-describedby. In uncontrolled mode, a form reset restores the initial value.

Validation open_in_new
import { useRef, useState } from 'react';
import type { FormEvent } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { TextField } from '@rubenchodev/materix-react/components/text-field';

export default function Demo() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [message, setMessage] = useState('');

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const input = inputRef.current;
    if (!input) return;
    if (input.checkValidity()) setMessage('');
    else setMessage(input.value ? 'Invalid email' : 'Email is required');
  };

  return (
    <form className="demo-stack demo-wide" noValidate onSubmit={handleSubmit} onReset={() => setMessage('')}>
      <TextField
        inputRef={inputRef}
        label="Email"
        startIcon="email"
        required
        type="email"
        error={Boolean(message)}
        helperText={message || 'We will send you the confirmation'}
      />
      <div className="mtx-d-flex mtx-justify-content-end mtx-gap-1">
        <Button variant="text" type="reset">
          Clear
        </Button>
        <Button variant="contained" type="submit">
          Validate
        </Button>
      </div>
    </form>
  );
}

              <Button variant="contained" type="submit">
                Create account
              </Button>
            </div>
          </Grid>
        </Grid>
      </form>
    </div>
  );
}

Controlled usage#

With value + onChange the parent owns the value. With a mask, value can be the raw value ("125000"): it is displayed formatted ("$ 1,250.00"). The vanilla instance methods become state: value/unmaskedValue = … → setValue(), setError()/clearError() → error + helperText, disable()/enable() → disabled, and focus() uses inputRef. Fields created at runtime are just new elements in the state (the equivalent of Materix.init() / initAll()).

Controlled usage open_in_new
import { useRef, useState } from 'react';
import { Button } from '@rubenchodev/materix-react/components/button';
import { TextField, isMaskComplete, resolveMask, unmaskValue } from '@rubenchodev/materix-react/components/text-field';

const CURRENCY = resolveMask('currency');

const DYNAMIC: { variant: 'outlined' | 'filled' | 'standard'; startIcon?: string }[] = [
  { variant: 'outlined', startIcon: 'edit' },
  { variant: 'filled' },
  { variant: 'standard' },
];

export default function Demo() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [value, setValue] = useState('');
  const [error, setError] = useState('');
  const [disabled, setDisabled] = useState(false);
  const [log, setLog] = useState<string[]>([]);
  const [fields, setFields] = useState<number[]>([]);
  const write = (text: string) => setLog((prev) => [`${new Date().toLocaleTimeString()}  ${text}`, ...prev].slice(0, 8));

  return (
    <div className="demo-stack">
      <div className="demo-fixed-width">
        <TextField
          inputRef={inputRef}
          label="Controlled field"
          mask="currency"
          value={value}
          onChange={(_, next, details) => {
            setValue(next);
            write(`onChange → value "${next}" · unmaskedValue "${details.unmaskedValue}"`);
          }}
          onFocus={() => write('focus')}
          onBlur={() => write('blur')}
          disabled={disabled}
          error={Boolean(error)}
          helperText={error || 'Type or use the buttons'}
        />
      </div>
      <div className="demo-row">
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setValue('125000');
            write('value = "125000" → "$ 1,250.00"');
          }}
        >
          value = 125000
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setError('Amount out of range');
            write('error + helperText');
          }}
        >
          Set error
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setError('');
            write('error cleared');
          }}
        >
          Clear error
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            setDisabled(!disabled);
            write(`disabled = ${!disabled}`);
          }}
        >
          Disable / enable
        </Button>
        <Button variant="outlined" size="small" onClick={() => inputRef.current?.focus()}>
          Focus (inputRef)
        </Button>
        <Button
          variant="outlined"
          size="small"
          onClick={() => {
            const shown = inputRef.current?.value ?? '';
            write(`value "${shown}" · unmaskedValue "${unmaskValue(shown, CURRENCY)}" · isMaskComplete ${isMaskComplete(shown, CURRENCY)}`);
          }}
        >
          Read values
        </Button>
      </div>
      <pre className="demo-log" aria-live="polite">
        {log.join('\n')}
      </pre>
      <div className="demo-group">
        <span className="demo-label">Create fields dynamically</span>
        <div className="demo-row">
          <Button
            variant="text"
            onClick={() => {
              const next = fields.length + 1;
              setFields([...fields, next]);
              write(`field #${next} added to the state`);
            }}
          >
            Add field
          </Button>
          <Button variant="text" disabled={!fields.length} onClick={() => setFields([])}>
            Remove all
          </Button>
        </div>
        <div className="demo-grid-3">
          {fields.map((n) => {
            const config = DYNAMIC[(n - 1) % DYNAMIC.length];
            return <TextField key={n} label={`Field #${n}`} variant={config.variant} startIcon={config.startIcon} />;
          })}
        </div>
      </div>
    </div>
  );
}

Accessibility#

  • The label is a <label for> linked to the control id (generated with useId when missing).
  • The helper text and the counter (.mtx-text-field__supporting-text) are linked with aria-describedby, keeping the ids you pass and those of a parent FormControl.
  • The error state (error, a parent FormControl or an exceeded limit) sets aria-invalid="true".
  • The counter uses aria-live="polite". Generated icons carry aria-hidden="true".
  • In no-label and hiddenLabel there is no visible label: add an aria-label.
  • required adds the visual asterisk; the native attribute announces it to screen readers.
  • The password button is a <button type="button"> with a translated aria-label, aria-pressed and aria-controls; action buttons need startActionLabel / endActionLabel.
