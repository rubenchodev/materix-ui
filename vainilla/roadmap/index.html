Roadmap

Materix UI development status: completed milestones and pending work.

  • Define the name and naming convention.
  • Define the vanilla CSS + JS architecture.
  • Define the mtx- prefix.
  • Define declarative initialization.
  • Create the project’s base structure.
  • Configure Vite.
  • Create the initial Button + Ripple component.
  • Adapt the design tokens to the MUI look and feel.
  • Implement the Light theme.
  • Implement the Dark theme.
  • Reset: keep only the Button component.
  • Build TextField with the MUI variations (outlined/filled/standard, small, margins, multiline, select, adornments, hidden label, colors).
  • Build additional components following MUI (List, Tabs, etc.).
  • Build Paper, Divider and IconButton following MUI.
  • Build Card, Checkbox, Switch, Dialog and Select (extended native select with search and multiple selection) following MUI.
  • Rewrite Select and create Chip, NativeSelect, Radio, Menu, MenuItem, List, Typography, Link, Avatar, Badge, Alert, Snackbar, Tabs, Drawer and Table following MUI.
  • Create /examples/button.
  • Complete the Hugo documentation for Button.
  • Address Button accessibility.
  • Define the SemVer versioning strategy.
  • Define the npm publishing strategy.
  • Evaluate an optional MutationObserver for dynamic content.
  • Create automated tests for critical components.
