CSS + JavaScript vanilla · v0.2.0

Componentes Material UI para cualquier HTML

Librería de componentes inspirada en Material UI que se usa con atributos data-mtx: sin React, sin Web Components y sin paso de compilación obligatorio.

Empezar arrow_forward Ver componentes

Instalación con npm

npm install materix-ui

O desde una CDN

<link rel="stylesheet" href="https://unpkg.com/materix-ui@0.2.0/dist/materix.min.css">
<script src="https://unpkg.com/materix-ui@0.2.0/dist/materix.umd.js"></script>
Crear cuenta Componentes reales, inicializados con data-mtx

Por qué Materix UI

  • code_off

    Sin frameworks

    CSS y JavaScript vanilla. Funciona en HTML estático, PHP, Django, Rails, Laravel o dentro de cualquier SPA.

  • bolt

    Un solo elemento

    Escribe <input data-mtx="text-field"> y la librería genera label, borde e iconos por ti.

  • palette

    Fiel a Material UI

    Forma de 4px, Roboto, paleta, sombras y estados de interacción de MUI y Material Design 2.

  • accessibility_new

    Accesible por defecto

    Semántica nativa, navegación con teclado, foco visible y ARIA gestionado por cada componente.

  • dark_mode

    Tema claro y oscuro

    Design tokens --mtx-* centralizados: cambia todo el tema con un atributo.

  • terminal

    API programática

    Cuando lo necesites: new Materix.Dialog(el), Materix.initAll(container) o Materix.watch().

Uso en 30 segundos#

Carga la hoja de estilos y el script, escribe HTML con data-mtx y listo: al cargar el DOM los componentes se inicializan solos.

<link rel="stylesheet" href="dist/materix.min.css">

<button class="mtx-button mtx-button--contained" data-mtx="button">Guardar</button>
<input data-mtx="text-field" data-label="Correo electrónico" data-variant="outlined" data-start-icon="email" type="email" />

<script src="dist/materix.umd.js"></script>
info

Fuentes recomendadas

Los componentes usan Roboto y la fuente Material Icons. Cárgalas desde Google Fonts para obtener el aspecto MUI exacto; sin ellas todo sigue funcionando con la fuente del sistema.

Para activar el tema oscuro basta con un atributo en <html>:

<html data-mtx-theme="dark">

Componentes

Ver todoschevron_right

Layout

  • grid_view Grid Grilla flexbox de 12 columnas con cinco breakpoints (xs–xl), separación con gap en múltiplos de 8px (también por breakpoint) y alineación, para páginas responsivas.
  • format_paint CSS Baseline Base global de Materix: tipografía Roboto, colores de fondo y texto del tema, box-sizing, foco visible y color-scheme claro u oscuro.
  • crop_free Container Centra el contenido de la página con un ancho máximo por breakpoint y márgenes laterales responsive (16px en móvil, 24px desde 600px).
  • view_agenda Stack Apila elementos en una dirección (columna o fila) con una separación uniforme, alineación, ajuste de línea, divisores y cambios por breakpoint.

Entradas

  • smart_button Button Botón de acción con variantes text, outlined y contained, tres alturas canónicas (48/40/32px), colores de la paleta e iconos.
  • view_week Button Group Agrupa botones relacionados en una sola pieza con bordes unidos, separadores y la variante, tamaño y color heredados.
  • ads_click Icon Button Botón circular de solo icono para acciones compactas en barras de herramientas, tarjetas y filas de tabla. Siempre con aria-label.
  • add_circle Fab Botón de acción flotante para la acción principal de una pantalla: circular (56/48/40px) o extendido con texto (48px).
  • check_box Checkbox Casilla para seleccionar una o varias opciones de una lista o confirmar una condición; admite estado indeterminado.
  • radio_button_checked Radio Botón de opción para elegir exactamente una alternativa de un grupo visible; RadioGroup lee y fija el valor del grupo.
  • star_half Rating Valoración con estrellas para opinar sobre un producto o mostrar una puntuación media, accesible con radios nativos y teclado.
  • tune Slider Permite elegir un valor o un rango deslizando sobre una pista, basado en inputs range nativos accesibles.
  • toggle_on Switch Interruptor que activa o desactiva una opción al instante, como una preferencia de ajustes; usa role=switch sobre un checkbox nativo.
  • edit Text Field Campo de texto con label flotante, variantes MUI, iconos, contadores, máscaras de entrada y validación, declarado con un solo elemento.
  • list Select Selector con menú propio estilo MUI: búsqueda, multiselección, acciones en lote, grupos, límites e iconos o imágenes en las opciones.
  • arrow_drop_down_circle Native Select El <select> del navegador con estética MUI: ligero, accesible por defecto y con el selector táctil nativo en móviles.
  • manage_search Autocomplete Campo de texto con sugerencias filtrables: selección única o múltiple con chips, valores libres, grupos y carga asíncrona.
  • event Date Time Picker Selectores de fecha, hora, fecha y hora y rangos con calendario, reloj radial MD2, popover, modal o modo estático, límites y formatos.
  • toggle_off Toggle Button Botones de alternancia para agrupar opciones relacionadas con selección exclusiva o múltiple; también sirven solos como interruptor de una acción.

Visualización de datos

  • account_circle Avatar Representa a una persona o entidad con una imagen, sus iniciales o un icono; AvatarGroup apila varios y resume el excedente.
  • notifications Badge Muestra un número o un punto de estado en la esquina de un icono, avatar o botón para señalar novedades o pendientes.
  • label Chip Elemento compacto que representa una etiqueta, un filtro, una entrada o una acción; puede llevar icono, avatar y botón de eliminar.
  • horizontal_rule Divider Línea fina que separa y agrupa contenido en listas, menús y diseños, en horizontal o vertical y opcionalmente con texto.
  • format_list_bulleted List Lista vertical continua de texto, iconos o avatares; con ítems estáticos o interactivos, subcabeceras, densidad y selección.
  • table_chart Table Muestra conjuntos de datos en filas y columnas sobre una tabla HTML semántica, con densidad, cabecera fija, ordenación, selección y paginación.
  • text_fields Typography Aplica la escala tipográfica de MUI (h1 a overline) a cualquier elemento, separando la semántica HTML del estilo visual.
  • info Tooltip Etiqueta informativa breve que aparece en hover, foco de teclado o pulsación larga. Añade data-mtx-tooltip a cualquier elemento: sin inicialización.

Feedback

  • warning Alert Mensaje breve y destacado que informa del resultado de una acción o del estado del sistema sin interrumpir al usuario.
  • gradient Backdrop Capa a pantalla completa que oscurece la página y centra un indicador mientras dura una operación; no sustituye a un diálogo.
  • open_in_browser Dialog Ventana modal que interrumpe la tarea para pedir una decisión o mostrar información crítica, con foco atrapado y cierre por Escape.
  • donut_large Progress Indicadores circulares y lineales que comunican que una operación está en curso o cuánto falta para terminarla.
  • view_day Skeleton Marcadores de posición con la forma del contenido que se muestran mientras los datos cargan, con animación pulse o wave.
  • chat_bubble Snackbar Notificación breve y temporal en un borde de la pantalla que confirma una acción y puede ofrecer deshacerla.

Superficies

  • expand_circle_down Accordion Paneles que muestran y ocultan secciones de contenido relacionadas con un resumen pulsable, ideales para FAQs y ajustes agrupados.
  • view_headline App Bar Barra superior con el título, la navegación y las acciones principales de la pantalla actual.
  • web Card Superficie que agrupa contenido y acciones sobre un único tema: cabecera, imagen, texto y botones.
  • layers Paper Superficie base de Material Design con fondo, radio y sombra que agrupa contenido y expresa elevación.
  • picture_in_picture Popover Paper flotante con contenido arbitrario anclado a un disparador. Se cierra al hacer clic fuera o con Escape y devuelve el foco al disparador.

Navegación

  • more_horiz Breadcrumbs Ruta de navegación jerárquica: muestra dónde está el usuario y permite volver a cualquier nivel superior.
  • menu_open Drawer Panel lateral de navegación o contenido auxiliar: temporal, persistente, permanente o responsive, con cabecera y pie generados y patrón app shell.
  • link Link Enlace de texto con el estilo de MUI sobre un <a> nativo: colores de la paleta y tres modos de subrayado, sin perder semántica.
  • more_vert Menu Lista temporal de opciones anclada a un disparador: iconos, separadores, selección, submenús, menú contextual y navegación completa por teclado.
  • last_page Pagination Permite elegir una página dentro de un conjunto grande de resultados, con elipsis, primera/última página y modo enlaces para SSR.
  • tab Tabs Pestañas para alternar entre vistas del mismo nivel con indicador animado, iconos, orientación vertical y navegación completa por teclado.
  • touch_app Speed Dial Botón de acción flotante que despliega de tres a seis acciones relacionadas con etiquetas, en cuatro direcciones, por clic o al pasar el cursor.
  • linear_scale Stepper Muestra el progreso a lo largo de una secuencia de pasos numerados, horizontal o vertical, lineal o con pasos clicables, y su versión móvil compacta.
