Roadmap

Estado del desarrollo de Materix UI: hitos completados y trabajo pendiente.

  • Definir nombre y naming convention.
  • Definir arquitectura CSS + JS vanilla.
  • Definir prefijo mtx-.
  • Definir inicialización declarativa.
  • Crear estructura base del proyecto.
  • Configurar Vite.
  • Crear componente inicial Button + Ripple.
  • Adaptar los design tokens a la estética MUI.
  • Implementar tema Light.
  • Implementar tema Dark.
  • Reset: mantener únicamente el componente Button.
  • Construir TextField con las variaciones de MUI (outlined/filled/standard, small, margins, multiline, select, adornments, hidden label, colores).
  • Construir componentes adicionales siguiendo MUI (List, Tabs, etc.).
  • Construir Paper, Divider e IconButton siguiendo MUI.
  • Construir Card, Checkbox, Switch, Dialog y Select (nativo extendido con búsqueda y selección múltiple) siguiendo MUI.
  • Reescribir Select y crear Chip, NativeSelect, Radio, Menu, MenuItem, List, Typography, Link, Avatar, Badge, Alert, Snackbar, Tabs, Drawer y Table siguiendo MUI.
  • Crear /examples/button.
  • Completar documentación Hugo de Button.
  • Resolver accesibilidad de Button.
  • Definir estrategia de versionado SemVer.
  • Definir estrategia de publicación en npm.
  • Evaluar MutationObserver opcional para contenido dinámico.
  • Crear pruebas automatizadas para componentes críticos.
