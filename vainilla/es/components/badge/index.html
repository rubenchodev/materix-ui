Badge

Muestra un número o un punto de estado en la esquina de un icono, avatar o botón para señalar novedades o pendientes.

play_circleEjemplo en vivo codeCódigo fuente open_in_newReferencia MUI
Inicialización declarativa data-mtx="badge"

Badge envuelve un elemento (icono, avatar, botón) y coloca en su esquina un contador o un punto. Úsalo para señalar mensajes sin leer, notificaciones pendientes o un estado en línea. No lo uses para etiquetas de texto independientes (usa Chip) ni para mensajes de estado de página (usa Alert).

Uso básico#

Envuelve el contenido con data-mtx="badge" e indica el valor en data-content. El componente crea el nodo de la insignia y lo posiciona.

Visibilidad#

Como en MUI, la insignia se oculta cuando el valor es 0 o no hay contenido. data-show-zero muestra el cero y data-invisible la oculta siempre (también en la variante dot). Al ocultarse se encoge con una transición, sin mover el contenido.

En línea (standalone)#

data-standalone coloca la insignia en el flujo del texto, sin elemento anclado: contadores de navegación, listas o pestañas. Con contenido 0 desaparece del todo (salvo data-show-zero). En línea el número sí se lee; con data-label ({0} = contenido mostrado) se añade además un texto solo para lectores de pantalla.

Sintaxis BEM completa#

Si la insignia ya viene renderizada (.mtx-badge__badge), el componente la reutiliza y solo calcula visibilidad y valor máximo a partir de data-content.

<span class="mtx-badge mtx-badge--error mtx-badge--overlap-circular" data-mtx="badge" data-content="6">
  <span class="mtx-avatar mtx-avatar--secondary">R</span>
  <span class="mtx-badge__badge" aria-hidden="true">6</span>
</span>

Uso programático#

// Inicializar un badge creado dinámicamente
const badge = Materix.init(document.getElementById('inbox-badge'));

// Instanciación directa o recuperación de la instancia
const same = Materix.getInstance(document.getElementById('inbox-badge'));

// Cambiar contenido y visibilidad
badge.content = 5;        // aplica data-max y la regla del cero
badge.content = null;     // sin contenido: se oculta
badge.invisible = true;   // oculta aunque tenga valor

Con ES modules:

import { Badge } from '@rubenchodev/materix-ui';

Referencia de API#

Atributos data-*#

AtributoValoresPredeterminadoDescripción
data-contentTexto o número—Contenido de la insignia. Sin contenido (variante standard) la insignia se oculta.
data-variantstandard, dotstandarddot muestra un punto de 8px e ignora el contenido.
data-colordefault, primary, secondary, error, warning, info, successdefaultColor de fondo con texto de contraste.
data-maxNúmero99Si el contenido es un entero mayor, se muestra {max}+.
data-standaloneBooleano (presencia)ausenteInsignia en línea, sin hijo anclado (mtx-badge--standalone). Sin contenido visible desaparece.
data-labelTexto con {0}—Texto accesible oculto (mtx-badge__label); {0} se sustituye por el contenido mostrado.
data-show-zeroBooleano (presencia; "false" lo desactiva)ausenteMuestra la insignia cuando el valor es 0.
data-invisibleBooleano (presencia; "false" lo desactiva)ausenteOculta la insignia aunque tenga contenido.
data-anchortop-right, top-left, bottom-right, bottom-lefttop-rightEsquina de anclaje.
data-overlaprectangular, circularrectangularAjusta la posición para formas circulares.

ClaseDescripción

Métodos#

PropiedadRetornaDescripción
content (get/set)string | nullContenido actual. Al asignarlo se vuelve a aplicar data-max, la regla del cero y la visibilidad.
invisible (get/set)booleanLee si está oculta; al asignar fuerza u anula la ocultación explícita.

Eventos#

Badge no emite eventos.

Variables CSS#

VariableUso
--mtx-color-text-primary, --mtx-color-background-paperFondo (mezcla al 60%) y texto del color default.
--mtx-color-{palette}, --mtx-color-{palette}-contrastFondo y texto de cada color.
--mtx-font-familyTipografía de la insignia (12px, peso 500).
--mtx-duration-short, --mtx-easing-standardTransición de aparición y ocultación.

Accesibilidad#

  • Anclada a un hijo, la insignia lleva aria-hidden="true": incluye la información en el nombre accesible del control, por ejemplo aria-label="Notificaciones, 17 nuevas" en el botón. En modo data-standalone el número se lee como texto; usa data-label para darle contexto (“4 sin leer”).
  • Marca los iconos decorativos con aria-hidden="true".
  • No transmitas información solo con el color de la insignia: el texto del aria-label o el contexto deben indicar su significado.
  • Badge no es interactivo ni recibe foco; si el elemento envuelto es un botón, el foco y el teclado los gestiona ese botón.
