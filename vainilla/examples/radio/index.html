Radio

Radio button to choose exactly one option from a visible group; RadioGroup reads and sets the group's value.

Basic usage Sizes Orientation Colors States Helper and error Accessible grouping Use cases Grid Programmatic usage Manual BEM usage

Basic usage

Each option is a single <input type="radio"> with data-mtx="radio" and data-label; sharing the same name makes them mutually exclusive. The data-mtx="radio-group" container adds role="radiogroup", turns data-label into its label (FormLabel) and exposes the selected value.

<div data-mtx="radio-group" data-name="plan" data-label="Plan">
  <input type="radio" data-mtx="radio" name="plan" value="basic" data-label="Basic" checked />
  <input type="radio" data-mtx="radio" name="plan" value="pro" data-label="Professional" />
</div>

Sizes

Two sizes: medium (20px circle, default) and small (16px with body2 text) via data-size="small".

Small · 16px circle

Orientation

By default the group is vertical, the easiest layout to scan. With data-row="true" the options sit in a row (and wrap when they don't fit); use it only with a few short options.

Vertical (default)
Row · data-row="true"

Colors

Primary is the default. Use data-color on the input (or the mtx-radio--{color} class, which is moved to the generated wrapper).

Select each option to see its color in the checked state.

States

Hover to see the colored border, press to see the ripple, and use Tab to enter the group and the arrow keys to change the option. The native radio does not support readonly: use disabled to lock it.

Helper and error (FormHelperText)

data-helper-text creates a .mtx-form-helper-text below the group and links it with aria-describedby. An empty data-error flags the error (helper text in red, aria-invalid on the radiogroup); with text, that message replaces the helper. The form validates on submit with setError() and clears with clearError().

Accessible grouping

Every group needs an accessible name. The simplest option is data-label (it generates the label and aria-labelledby). A <fieldset> with a <legend> or your own aria-labelledby also work; the group always gets role="radiogroup" unless you declare another role.

Use cases

Choosing the shipping method at checkout: a few options, all visible and mutually exclusive. With more than 5–7 options, a Select would take up less space.

Shipping method

Grid

With mtx-grid the options of a single group are spread across responsive columns; they share the name, so they remain mutually exclusive and navigable with the arrow keys.

Programmatic usage

The RadioGroup instance exposes the value property (read and write) and emits mtx:radio-group:change with detail.value when the user changes the selection. Each Radio exposes checked, disable(), enable() and focus().

Manual BEM usage

      
The full structure declares each <label class="mtx-radio"> with its input, the visual circle and the label. The library reuses the existing nodes.

      

        
        
      

      
<div class="mtx-radio-group" data-mtx="radio-group" data-name="bem" role="radiogroup" aria-label="Example">
  <label class="mtx-radio" data-mtx="radio">
    <input type="radio" name="bem" value="one" checked />
    <span class="mtx-radio__box"></span>
    <span class="mtx-radio__label">Option one</span>
  </label>
</div>
