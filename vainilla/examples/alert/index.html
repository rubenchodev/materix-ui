Alert

A short, prominent message that reports the outcome of an action or the state of the system without interrupting the user.

Basic usage

A single <div data-mtx="alert"> is enough: the component adds the severity icon, the message container and the optional title.

Your changes were saved successfully.
Could not connect to the server.
<div data-mtx="alert" data-severity="success">Your changes were saved successfully.</div>
<div data-mtx="alert" data-severity="error" data-title="Error">Could not connect to the server.</div>

Variants

Three variants, as in MUI: standard (soft background, default), filled (solid background) and outlined (border only). They are chosen with data-variant. As in MUI, standard and outlined use the severity color darkened in the light theme and lightened in the dark theme, so the text keeps its contrast.

With and without icons

By default the severity SVG icon is generated at 22px, as in MUI. You can replace it with a .mtx-alert__icon child (a .material-icons keeps its 24px grid) or remove it with data-icon="false".

Severities

The severity (data-severity) sets the color and the icon. Use success, info, warning or error according to the meaning of the message; without the attribute, success is applied.

success — the operation completed successfully.
info — neutral or contextual information.
warning — something needs attention soon.
error — the operation failed and action is required.

Title

data-title generates a bold .mtx-alert__title above the message, equivalent to MUI's AlertTitle.

Actions

To place buttons on the right, write the text inside .mtx-alert__message and leave the button as a sibling: the component does not move it into the message.

1 conversation was deleted.
You have used 92% of your space.

Dismissible

data-dismissible adds an accessible close button; data-close-label changes its label for screen readers. When closed, the alert fades out, receives hidden (it leaves the flow: no gap is left) and emits mtx:alert:close. Without data-close-label, the label comes from the i18n dictionary (Close / Cerrar).

In forms

Put hidden directly on the alert and remove it on validation: .mtx-alert[hidden] is hidden and takes no space. Submit the empty form to see the error and fill it in to see the success message.

Email and password are required.

Grid layout

Alerts take the width of their container, so they fit any mtx-grid column.

Programmatic usage

Get the instance with Materix.getInstance(el) and use close() and open(), or create new alerts with Materix.init(el).

Controlled from JavaScript.

      
const alert = Materix.getInstance(document.getElementById('alert-api'));
alert.close();
alert.open();

const el = document.createElement('div');
el.setAttribute('data-severity', 'success');
el.textContent = 'Created dynamically';
container.append(el);
Materix.init(el, 'alert');
