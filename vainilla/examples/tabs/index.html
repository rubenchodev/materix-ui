Basic usage

A data-mtx="tabs" container with data-mtx="tab" buttons; data-panel links each tab to its panel. Give each group an id: the tab ids are derived from it.

Colors

The active tab and the indicator use --mtx-color-primary. There are no color attributes; for another hue, redefine the token on the container (here, with the secondary value).

primary · default
--mtx-color-primary: var(--mtx-color-secondary)

States

Normal, active, disabled (data-disabled + disabled). Hover to see the hover background and use Tab and the arrow keys to see focus: the disabled tab is skipped.

Active · disabled · available

Scrollable

When the tabs don't fit, the bar scrolls horizontally (hidden scrollbar, no arrow buttons). The indicator follows the active tab.

Vertical

data-orientation="vertical" stacks the tabs with the indicator on the right; navigate with ↑ and ↓.

Manual and automatic activation

By default the arrow keys only move focus and Enter/Space activate. With data-selection-follows-focus the tab is activated as soon as it receives focus. Try both with the keyboard.

Several groups without an id

Without an id on the container, each group gets a unique prefix (mtx-tabs-1, mtx-tabs-2…): tab ids are never repeated and aria-labelledby / aria-controls always point to the right element.
