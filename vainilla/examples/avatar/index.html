Avatar

Represents a person or entity with an image, initials or an icon; AvatarGroup stacks several and summarizes the overflow.

Basic usage Variants Sizes Image, letters and icon Colors States Grouping Use cases Grid layout Programmatic usage Manual BEM usage

Basic usage

A single element with data-mtx="avatar": initials go as content, data-src generates the image and data-icon inserts an icon.

RD
<div data-mtx="avatar" data-color="primary">RD</div>
<div data-mtx="avatar" data-icon="folder" data-color="secondary" role="img" aria-label="Folder"></div>
<div data-mtx="avatar" data-src="/users/anna.jpg" data-alt="Anna Grant"></div>

data-variant sets the shape: circular (default), rounded (4px radius) or square.

Image, letters and icon

Content is resolved in order: a child <img>, data-src, data-icon and, if there is nothing, the element text. Icons keep their native 24px grid.

Colors

Without data-color, grey 600 with white text is used (--mtx-avatar-default-bg / --mtx-avatar-default-color, 4.6:1 AA contrast; MUI uses grey 400 at 1.8:1). data-color applies any palette color with its contrast text.

States

Avatar is not interactive: its states are about content. With an image it shows the photo; without an image or icon it switches to fallback mode (mtx-avatar--fallback) and shows the initials or the element text.

data-mtx="avatar-group" overlaps avatars. data-max also counts the +N indicator, and data-total indicates users that are not mounted in the DOM.
