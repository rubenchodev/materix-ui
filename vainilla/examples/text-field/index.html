Text Field

Text field with a floating label, MUI variants, icons, counters, input masks and validation, declared with a single element.

Basic usage

A single <input> or <textarea> with data-mtx="text-field" and data-label. The JavaScript generates the floating label, the border notch and the helper text; if data-label is missing, the placeholder is used.

<input data-mtx="text-field" data-label="Full name" type="text" />
<input data-mtx="input" placeholder="Email" type="email" />
<textarea data-mtx="textarea" data-label="Comment"></textarea>

data-variant: outlined (default), filled, standard and no-label (full border without a label, for search boxes).

Interactive adornments

The equivalent of MUI's InputAdornment + IconButton. data-password-toggle (only on type="password") adds the show/hide button with aria-pressed and a translated name; data-start-action and data-end-action create an IconButton with the given icon and emit mtx:text-field:adornment-click. The icon sits in the same position as a static icon, so the label stays aligned.

Programmatic usage

      
The buttons call the instance's real API (Materix.getInstance(el)); the console logs the field's native events.

      

        Existing instance
        

          
        

        

          
          
          
          
          
          
        

        

      

      

        Create and initialize dynamically
        

          
          
          
        

        

      

      
const field = Materix.getInstance(document.getElementById('tf-api'));
field.unmaskedValue = '125000';     // "$ 1,250.00"
field.setError('Amount out of range');
field.clearError();
field.disabled ? field.enable() : field.disable();
field.input.addEventListener('input', () => console.log(field.value, field.unmaskedValue));

    


    

      
Manual BEM usage

      
Full structure for SSR or fine-grained control. The component reuses the existing nodes and only adds the notch fieldset and whatever is missing.

      

        

          
          

            email
            
          

          

            We'll never share your email
          

        

        

          
          

            
          

        

      

      
<div class="mtx-text-field mtx-text-field--outlined mtx-text-field--adorned-start" data-mtx="text-field">
  <label class="mtx-text-field__label" for="email">Email address</label>
  <div class="mtx-text-field__container">
    <span class="mtx-text-field__adornment mtx-text-field__adornment--start material-icons" aria-hidden="true">email</span>
    <input class="mtx-text-field__input" id="email" type="email" placeholder=" " />
  </div>
  <div class="mtx-text-field__supporting-text">
    <span class="mtx-text-field__helper-text">We'll never share your email</span>
  </div>
</div>
