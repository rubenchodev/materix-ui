Rating

Star rating to review a product or display an average score, accessible through native radios and the keyboard.

Basic usage

A single <span data-mtx="rating"> generates five stars with hidden native radios and translated labels ("3 stars"). data-name sets the name for forms; clicking the current value clears it.

<span data-mtx="rating" data-value="3" data-name="basic-rating" aria-label="Product rating"></span>

Precision

data-precision="0.5" allows half stars: each star contains two radios and the left half selects the x.5 value.

Whole · 1 (default)
Half · 0.5

Sizes

Three sizes as in MUI: small 18px, medium 24px and large 30px. The built-in icons are SVG, so they scale crisply without forcing the font-size of Material Icons.

Large · 30px
Medium · 24px (default)
Small · 18px

Icons

data-icon and data-empty-icon accept Material Icons names. star, star_border, favorite, favorite_border, thumb_up, circle and similar ones are drawn as scalable SVG; the rest use the font glyph at its native 24px size.

Hearts · favorite / favorite_border
Gray filled star as empty (data-empty-icon="star")
Thumbs · thumb_up
Font glyph · pets (24px)

States

Hover for the preview (the active star grows 1.2×), and use Tab and the arrow keys to change the value with a visible focus ring.

Highlight selected only

data-highlight-selected-only highlights only the chosen icon, useful for satisfaction scales.

Maximum

data-max changes the number of icons (5 by default).

Hover feedback

The mtx:rating:active event reports the value under the cursor (or null on leave) so you can show a descriptive text, like MUI's hover feedback example.

Manual BEM usage

      
For SSR you can write the generated structure: one .mtx-rating__item per icon with its hidden radio and its <label> (data-rating-value). The library reuses the nodes and adds any missing icons.

      
        
          
          
        
        
          
          
        
        
          
          
        
        
        
      
      
<span class="mtx-rating" data-mtx="rating" role="radiogroup" aria-label="Rating">
  <span class="mtx-rating__item">
    <input class="mtx-rating__input" type="radio" name="score" id="score-1" value="1" />
    <label class="mtx-rating__label" for="score-1" data-rating-value="1">
      <span class="mtx-rating__visually-hidden">1 star</span>
    </label>
  </span>
  <!-- …one .mtx-rating__item per star… -->
  <input class="mtx-rating__input mtx-rating__input--empty" type="radio" name="score" id="score-empty" value="" />
  <label class="mtx-rating__visually-hidden" for="score-empty">No rating</label>
</span>
