Stepper

Shows progress through a sequence of numbered steps, horizontal or vertical, linear or with clickable steps, plus its compact mobile version.

Basic usage

An <ol data-mtx="stepper"> with one <li data-label> per step. The component generates the numbered icon, the connectors and the accessible text ("Step 2 of 3"), and marks the active step with aria-current="step". data-active-step is the index (starting at 0).

<ol data-mtx="stepper" data-active-step="1" aria-label="Reset password">
  <li data-label="Email"></li>
  <li data-label="Verify code"></li>
  <li data-label="New password"></li>
</ol>

Linear with actions

In linear mode the steps before the active one are completed and the following ones disabled. Buttons with data-mtx-stepper-action="back|next|reset" and data-target control the stepper without JavaScript; data-panel shows the active step's panel and data-finished-panel the final panel.

Step 2: define audiences and placements (optional).

Step 3: write the ad and check the preview.

Alternative label

data-alternative-label places the label below the icon and splits the width evenly; it is the most stable option on narrow screens.

Non-linear

With data-non-linear each step is a <button> (StepButton) with ripple, visible focus and activation with Enter/Space. Completion is no longer inferred from the order: mark it with data-completed or setCompleted(). Use Tab to move through the steps.

Non-linear with alternative label

Vertical

data-orientation="vertical" stacks the steps. The content of the <li> becomes StepContent, which expands only on the active step (or with data-expanded). The buttons inside use data-mtx-stepper-action without data-target: they act on their own stepper.

With and without icons

By default the icon is the step number (24px StepIcon). data-icon uses a custom Material Icon; completed shows a check and error a warning, in both cases replacing the icon.

States

Active, completed, optional (data-optional, with custom text if given a value), error with a message (data-error="message") and disabled (data-disabled). The connector turns primary before active or completed steps.

Mobile stepper

data-mtx="mobile-stepper" is MUI's compact version: generated Back/Next buttons and a dots (default), text or progress indicator. data-position="bottom|top" pins it to the edge of the viewport.

Programmatic usage

API: next(), back(), goTo(i), reset(), setCompleted(i, bool), setError(i, message|false) and the activeStep getter.

const stepper = Materix.getInstance(document.querySelector('#wizard'));
stepper.next();
stepper.setError(1, 'Required field');
document.querySelector('#wizard').addEventListener('mtx:stepper:change', (event) => {
  if (!isValid(event.detail.previousStep)) event.preventDefault();
});

Manual BEM usage

For SSR or fine-grained control: if each <li class="mtx-step"> already includes .mtx-step__label-container, the component reuses it and only renders the icon, the accessible texts and the states.
