Link

MUI-styled text link on a native <a>: palette colors and three underline modes, without losing semantics.

Basic usage

A single <a> with data-mtx="link". With no other attributes it uses the primary color and is always underlined (MUI v5 default), so it never relies on color alone.

<a data-mtx="link" data-underline="hover" href="/terms">Terms</a>

Underline

The link's variant is its underline: data-underline="always|hover|none". always is the default, as in MUI v5: a soft underline (40% of the color) that becomes solid on hover. Use hover or none only for links that are not inside running text (navigation, lists, footers).

As a button

For actions that don't navigate but should look like a link inside text, use <button data-mtx="link"> (MUI's component="button"): no native background, border or padding, and the typography of the surrounding text. Without type, it gets type="button" so it doesn't submit forms.

In a paragraph

Inside running text keep the default underline (always) so the link doesn't rely on color alone (WCAG 1.4.1). The link inherits the paragraph's typography (like MUI's variant="inherit"), so it fits any variant.

Programmatic usage

Link has no methods of its own: its API is initialization. Create links at runtime and register them with Materix.init(el, 'link'); the log shows the resulting classes.


      
const a = document.createElement('a');
a.href = '#';
a.textContent = 'Dynamic link';
a.setAttribute('data-color', 'error');
a.setAttribute('data-underline', 'always');
container.append(a);
Materix.init(a, 'link');
