CSS Baseline

Materix global baseline: Roboto typography, theme background and text colors, box-sizing, visible focus and a light or dark color-scheme.

Basic usage

This page uses <body data-mtx="css-baseline">: the component adds the mtx-root class, which applies the typography, the theme colors and box-sizing.

Box sizing

Inside mtx-root everything uses box-sizing: border-box: a box with width: 100%, 16px of padding and a 4px border does not overflow its container.

width 100% + padding 16px + border 4px
Takes exactly the available width.

Visible focus

Use Tab: buttons, links and focusable elements show the --mtx-focus-ring-color ring only when navigating with the keyboard. Text fields are excluded because their border already shows focus.

Link

Color scheme

Switch the theme with the button in the top bar: with data-mtx-theme="dark" on <html>, mtx-root switches to color-scheme: dark and native controls are drawn dark.

Native controls

Scoped baseline

The baseline can also be applied to a specific container, which is handy for embedding Materix in pages with other styles. The container also gets margin: 0.

Programmatic usage

new Materix.CssBaseline(el) or Materix.init(el, 'css-baseline') apply the baseline to a container created at runtime. The component emits no events; the log shows the element's real state.

Box created without baseline. Click "Apply to the box".


      
const box = document.getElementById('widget');
Materix.init(box, 'css-baseline');           // adds mtx-root
document.documentElement.setAttribute('data-mtx-theme', 'dark');
