Skeleton

Content-shaped placeholders shown while data loads, with a pulse or wave animation.

Basic usage Variants Animations Sizes Paragraphs With children States Real-world examples Grid Programmatic usage Manual BEM usage

Basic usage

A single element with data-mtx="skeleton". Without a variant it is a line of text that fills the available width and takes the height of the typography; data-width and data-height accept numbers (px) or any CSS unit.

<span data-mtx="skeleton"></span>
<span data-mtx="skeleton" data-variant="circular" data-width="40" data-height="40"></span>
<span data-mtx="skeleton" data-variant="rectangular" data-width="210" data-height="60"></span>
<span data-mtx="skeleton" data-variant="rounded" data-width="210" data-height="60"></span>

Variants

Four shapes, as in MUI: text (default, scaled down to 60% of the line height), circular, rectangular (no radius) and rounded (4px radius).

Animations

data-animation="pulse" (default, the opacity oscillates), "wave" (a band sweeps across the block) or "false" (static). With prefers-reduced-motion: reduce the animation is turned off automatically.

Sizes

The text variant inherits the size of the typography it sits in: just place it inside the same element that will hold the real text.

Paragraphs

data-lines="3" generates several lines of text; the last one is shorter (60% by default, configurable with data-last-width).

With children

When the skeleton wraps content, it takes its exact size and hides it (visibility: hidden). Useful to avoid repeating dimensions: an Avatar or a Button inside becomes its own placeholder.

A title of real length

States

A region with data-loading shows its [data-skeleton-placeholder] children and hides the [data-skeleton-content] ones. Materix.skeleton.set(region, bool) toggles the state and syncs aria-busy; with aria-live="polite" the content is announced when loading finishes.

Materix.skeleton.set('#profile', false); // shows the content

Grid

Programmatic usage

The instance exposes setVariant(v), setAnimation(a), variant and animation. The Materix.skeleton helper provides set(), toggle() and isLoading() and emits mtx:skeleton:change.


      
const block = Materix.getInstance(document.getElementById('skeleton-api'));
block.setVariant('circular').setAnimation('wave');

document.addEventListener('mtx:skeleton:change', (e) => console.log(e.detail.loading));
Materix.skeleton.set('#skeleton-region', false);

    


    

      
Manual BEM usage

      
For SSR: the mtx-skeleton--{variant} and mtx-skeleton--{pulse|wave|no-animation} classes are respected on initialization. They also render without JavaScript (add aria-hidden="true" yourself).

      

        
        
        

          
          
        

      

      
<span class="mtx-skeleton mtx-skeleton--text mtx-skeleton--wave" data-mtx="skeleton" aria-hidden="true"></span>
<div class="mtx-skeleton-lines" data-mtx="skeleton" data-lines="2" aria-hidden="true">
  <span class="mtx-skeleton mtx-skeleton--text mtx-skeleton--pulse"></span>
  <span class="mtx-skeleton mtx-skeleton--text mtx-skeleton--pulse"></span>
</div>
