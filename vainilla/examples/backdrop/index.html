Backdrop

Full-screen layer that dims the page and centers an indicator while an operation runs; it does not replace a dialog.

Basic usage Variants With content Closing States Real-world examples Grid layout Programmatic usage Manual BEM usage

Basic usage

A data-mtx="backdrop" with the content you want to center and a data-mtx-backdrop-open="id" trigger. With data-close-on-click, a click on the layer closes it. The content color is white by default, so a CircularProgress with data-color="inherit" stands out in both themes.

<button class="mtx-button mtx-button--contained" data-mtx="button" data-mtx-backdrop-open="backdrop-basic">Show backdrop</button>
<div data-mtx="backdrop" id="backdrop-basic" data-close-on-click data-close-on-escape>
  <div data-mtx="circular-progress" data-color="inherit" data-label="Loading"></div>
</div>

Variants

By default the layer is rgba(0, 0, 0, 0.5) (token --mtx-backdrop-bg). data-invisible makes it transparent: it still captures clicks, which is useful to close your own surfaces when clicking outside.

Invisible layer: click anywhere to close.

Closing

Three optional mechanisms that can be combined: data-close-on-click (click on the layer or on non-interactive content), data-close-on-escape and any inner element with data-mtx-backdrop-close. Without any of them, it only closes from code.

States

data-lock-scroll locks body scrolling (modal manager shared with Dialog) and data-inert marks the rest of the page as inert while it is open, so Tab and screen readers cannot reach the covered content. data-open shows it on load.

Real-world examples

Programmatic usage

The instance exposes open(), close(), toggle() and isOpen, and emits mtx:backdrop:open and mtx:backdrop:close (detail.reason: api, click or escape).


      
const backdrop = Materix.getInstance(document.getElementById('backdrop-api'));
backdrop.open();
setTimeout(() => backdrop.close(), 1500);

document.addEventListener('mtx:backdrop:close', (e) => console.log(e.detail.reason));
