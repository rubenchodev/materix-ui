Autocomplete

Text field with filterable suggestions: single or multiple selection with chips, free values, groups and asynchronous loading.

Basic usage

A single <input> with data-mtx="autocomplete", data-label and data-options pointing to a <datalist>. Type to filter (case- and accent-insensitive: try "peru"). The value (the option's value) is submitted in a hidden input with the name.

<input data-mtx="autocomplete" data-label="Country" data-options="#ac-countries" name="country" />
<datalist id="ac-countries">
  <option value="co">Colombia</option>
  <option value="mx">Mexico</option>
</datalist>

Groups and disabled options

With a <select> as the source, each <optgroup> is a group with a sticky subheader. In a <datalist> use data-group on each option (it groups consecutive options, as in MUI). disabled options are skipped with the keyboard.

Multiple with chips

data-multiple shows each value as a deletable Chip (button, or Backspace with empty text; ← and → move between chips). data-limit-tags limits the chips visible without focus; data-disable-close-on-select keeps the list open; data-filter-selected-options hides those already chosen.

Free solo

data-free-solo accepts values that are not in the list: Enter confirms the text (in single selection also when leaving the field). With no matching options, neither the popup nor the open button is shown.

Behavior and keyboard

↓/↑ open and move, Page Up/Page Down jump 5, Home/End go to the ends, Enter selects, Escape closes. Options: data-auto-highlight (highlights the first one), data-auto-select (Tab/blur accepts the active one), data-clear-on-escape, data-open-on-focus, data-disable-clearable and data-match-from="start".

Asynchronous loading

Listen to mtx:autocomplete:input (with data-debounce="300" the event waits until the user stops typing), turn on loading, fetch the data and call setOptions(). data-filter="false" leaves filtering to the server. The response is simulated with 800 ms of latency.

field.addEventListener('mtx:autocomplete:input', async (event) => {
  if (event.detail.reason !== 'input') return;
  ac.loading = true;
  const results = await searchRepos(event.detail.inputValue);
  ac.setOptions(results);   // [{ value, label, description }]
  ac.loading = false;
});

Form

The name moves to hidden inputs: one with the value in single selection; one per value in multiple selection (like <select multiple>) or a single field with data-value-format="csv". required uses native validation; the Reset button restores the initial values.

Manual BEM usage

      
For SSR or fine-grained control: a .mtx-autocomplete container with the TextField already rendered and an inner <datalist>. The component reuses the existing nodes.

  <div class="mtx-text-field mtx-text-field--outlined">
    <label class="mtx-text-field__label" for="ac-bem">City</label>
    <div class="mtx-text-field__container">
      <input class="mtx-text-field__input" id="ac-bem" name="city" />
