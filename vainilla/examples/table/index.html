Components · Data display

Table

Displays data sets in rows and columns on a semantic HTML table, with density, sticky header, sorting, selection and pagination.

Basic usage

A standard HTML table with data-mtx="table": the component styles the sections, rows and cells and adds scope="col". table-container scrolls horizontally inside its box.

Sorting

table-sort-label toggles the direction, keeps a single column active, updates aria-sort and emits mtx:table:sort; the page reorders the rows when it receives the event. In right-aligned columns the arrow goes on the left. Use Tab and Enter to sort with the keyboard.

Selection

data-selectable adds the checkbox column: the header checkbox selects everything and turns indeterminate with a partial selection. Each row is identified by data-id and the table emits mtx:table:selection-change. With data-select-on-click a row is also selected by clicking it.

Toolbar

data-mtx="table-toolbar" with data-table follows the table's selection: with nothing selected it shows the title and the data-show="default" group; with a selection it is highlighted (--highlight), announces the count (aria-live) and shows the data-show="selected" group.

Data table

A complete recipe with minimal JavaScript: a toolbar with search and bulk actions, selection by data-id, sorting, status chips and local pagination. The rows are rendered from an array; the table styles them and adds the checkboxes to new rows by itself, and keeps the selection when reordering or filtering.

Order Status 
// Own state: data, order and filter. Selection and pagination are handled by Materix.
const render = () => {
  body.innerHTML = visibleOrders().map((o) => `<tr data-id="${o.id}">...</tr>`).join('');
  Materix.initAll(body);          // status chips of the new rows
  pager.page = 0; pager.update(); // recalculates the local pagination
};
table.addEventListener('mtx:table:sort', (e) => { sort = e.detail; render(); });
deleteButton.addEventListener('click', () => {
  orders = orders.filter((o) => !tableApi.isSelected(o.id));
  tableApi.clearSelection();
  render();
});
