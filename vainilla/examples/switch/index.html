Components · Inputs

Switch

Toggle that turns an option on or off instantly, like a settings preference; uses role="switch" on a native checkbox.

Basic usage Sizes With and without label Colors States Helper and error Grouping Use cases Grid Programmatic usage Manual BEM usage

Basic usage

Write only the <input type="checkbox"> with data-mtx="switch" and data-label. The library generates the track, the thumb and the label, and adds role="switch" so it is announced as "on / off".

<input type="checkbox" data-mtx="switch" data-label="Wi-Fi" checked />

Sizes

Two sizes: medium (34×20px track, default) and small (28×16px and body2 text) with data-size="small".

Medium · 34×20px track (default)
Small · 28×16px track

With and without label

Without data-label only the switch is drawn; in that case add aria-label or aria-labelledby to give it an accessible name.

With visible label
Switch only · aria-label

Colors

Primary is the default. Use data-color on the input (or the mtx-switch--{color} class, which is moved to the generated container). The color shows in the on state.

States

Click to see the ripple on the thumb and use Tab and Space to focus and toggle. disabled dims the control; readonly keeps it focusable and legible but blocks changes.

Helper and error (FormHelperText)

data-helper-text adds a .mtx-form-helper-text below the switch, linked with aria-describedby. data-error (empty or with a message) turns on the error state with aria-invalid="true"; setError() and clearError() control it from code.

Helper text
Error with message
Disabled with helper 
<input type="checkbox" data-mtx="switch" data-label="Automatic backups" data-helper-text="Every night at 2:00 AM." />
<input type="checkbox" data-mtx="switch" data-label="Two-step verification" data-error="Required for administrators." />

Grouping

Group related switches in a <fieldset> with a <legend>. Each one stays independent: turning one on does not affect the others.

Notifications

Use cases

A settings panel where each switch applies the change immediately, with no "Save" button. Turning on "Dark mode" really changes this page's theme.

Preferences

Grid

In an mtx-grid the switches are spread across columns: one on mobile, two from 600px and three from 900px.

Programmatic usage

Materix.getInstance(input) returns the instance (also from the generated <label>). Changes made from code do not fire events; user changes emit the input's native change, which is logged below.

Manual BEM usage

      
The full structure declares the <label class="mtx-switch"> with the input, the track with its thumb, and the label. The library reuses the nodes and adds role="switch" to the input.

      

        
        
      

      
<label class="mtx-switch" data-mtx="switch">
  <input type="checkbox" checked />
  <span class="mtx-switch__track"><span class="mtx-switch__thumb"></span></span>
  <span class="mtx-switch__label">Wi-Fi</span>
</label>
