Progress

Circular and linear indicators that show an operation is in progress or how much is left before it finishes.

Basic usage

A single element with data-mtx="circular-progress" or data-mtx="linear-progress" generates the SVG or the bars, the role="progressbar" and the accessible name. Without data-value it is indeterminate; with data-value it becomes determinate.

<div data-mtx="circular-progress"></div>
<div data-mtx="circular-progress" data-value="75"></div>
<div data-mtx="linear-progress"></div>
<div data-mtx="linear-progress" data-value="40"></div>

Circular

As in MUI: indeterminate (spins with a stroke that grows and shrinks), determinate (an arc proportional to data-value) and data-disable-shrink (spin only, useful when the main thread is very busy). data-track adds the background ring.

Linear

Four variants: indeterminate, determinate, buffer (inferred from data-value-buffer) and query (reversed indeterminate, for the phase before loading starts). 4px high, as in MUI.

Sizes

data-size sets the diameter in px (40 by default) and data-thickness the stroke width (3.6). The height of the linear bar is changed with the --mtx-linear-progress-height variable.

Circular · 16 / 24 / 40 / 56 / 80px
Thickness · 2 / 3.6 / 6
Next to a 40px button 
<div data-mtx="circular-progress" data-size="24"></div>
<div data-mtx="circular-progress" data-thickness="6" data-value="70"></div>

With label

data-show-label shows the rounded percentage: centered in the circle and to the right of the bar. The visual figure is aria-hidden; screen readers get the value from aria-valuenow.

<div data-mtx="circular-progress" data-value="48" data-show-label></div>
<div data-mtx="linear-progress" data-value="35" data-show-label></div>

Colors

data-color accepts the palette colors and inherit (takes the container's text color). The linear track is lightened in the light theme and darkened in the dark theme.

<div data-mtx="circular-progress" data-color="secondary"></div>
<div data-mtx="linear-progress" data-value="50" data-color="warning"></div>

States and accessibility

The default accessible name is "Loading" / "Cargando" depending on the language. Customize it with data-label, aria-label or aria-labelledby. Mark the region being updated with aria-busy="true" while it loads and remove it when done. With prefers-reduced-motion the animations slow down and the stroke stops shrinking.

Busy region (aria-busy)

<section aria-busy="true" aria-live="polite">
  <div data-mtx="circular-progress" data-size="24" data-label="Loading comments"></div>
</section>

Programmatic usage

The instance exposes value (getter/setter), setValue(n), variant, color and, on the linear one, valueBuffer / setBuffer(n).


      
const linear = Materix.getInstance(document.getElementById('progress-api-linear'));
linear.setValue(linear.value + 10);
linear.color = 'success';
linear.variant = 'indeterminate';

// Spinner para un botón en carga (decorativo: el botón lleva aria-busy)
const spinner = Materix.createCircularProgress({ size: 20, color: 'inherit', decorative: true });
button.prepend(spinner);
