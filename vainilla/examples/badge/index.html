Badge

Displays a number or a status dot at the corner of an icon, avatar or button to flag new or pending items.

Basic usage Variants On icons, avatars and buttons Colors States Inline (standalone) Position Overlap Use cases Grid layout Programmatic usage Manual BEM usage

Basic usage

Wrap the content with data-mtx="badge" and put the value in data-content; the component creates and positions the badge.

</div>

States

The badge is hidden when the value is 0 or empty. data-show-zero shows the zero, data-invisible always hides it and data-max (99 by default) caps the number.

Inline (standalone)

data-standalone shows the badge in the text flow, with no anchored element: useful for counters in navigation, lists or tabs. With content 0 it disappears (unless data-show-zero). data-label adds text for screen readers ({0} = content).

  • Inbox
  • Sent 
<span data-mtx="badge" data-standalone data-content="4" data-color="primary" data-label="{0} unread"></span>

Programmatic usage

The content and invisible properties update the badge, applying data-max and the zero rule. Badge does not emit events; the log shows each call and the resulting state.
