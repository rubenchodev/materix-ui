Icon Button

Circular icon-only button for compact actions in toolbars, cards and table rows. Always with an aria-label.

Basic usage

An empty <button> with data-icon: the library adds the mtx-icon-button class, injects the 24px icon (decorative, with aria-hidden) and the centered ripple. The accessible name comes from aria-label.

<button data-mtx="icon-button" data-icon="search" aria-label="Search"></button>

Sizes

Three sizes with data-size: large 48px, medium 40px (default) and small 32px. The icon always keeps its native 24px grid; only the touch area changes. Each row aligns it with controls of the same height.

Large · 48px — next to a large Button and a medium FAB
Medium · 40px (default) — next to a small TextField and a medium Button
Small · 32px — next to a small Button and a Chip

Icons

There are two ways to set the icon: data-icon (the library creates the <span class="material-icons">) or writing the icon yourself inside the button, useful for other families such as Material Symbols. If the button already has content, data-icon is ignored.

Colors

Without data-color the icon uses the active action gray (--mtx-color-action-active), as in MUI. With data-color it takes a palette color; inherit inherits the color of the surrounding text.

inherit · inherits the container's color

States

Hover to see the hover background, press to see the centered ripple and use Tab to see the focus ring. Disable it with the native disabled attribute.

Edge position

data-edge="start|end" (classes mtx-icon-button--edge-start and --edge-end) apply a negative 12px margin so the glyph is optically aligned with the edge of the content (equivalent to MUI's edge). Notice how the menu icon lines up with the text of the row below.

With badge

A common combination: an IconButton wrapped in a Badge to show counters. The aria-label must include the number for screen readers. The button no longer clips its content (the ripple is clipped in an inner container), so the badge is never cut off.

Manual BEM usage

      
With the full structure you write the base class, the size and color modifiers and the nested icon. Useful for SSR or when the HTML is generated by a template.

      

        
        
        
      

      
<button class="mtx-icon-button mtx-icon-button--large mtx-icon-button--primary"
        data-mtx="icon-button" type="button" aria-label="Edit">
  <span class="material-icons" aria-hidden="true">edit</span>
</button>
