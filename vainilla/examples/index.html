Component catalog

46 components and a utility system in vanilla CSS + JavaScript that follow Material UI (MUI). Each card opens a working page that uses the real compiled library, with its variants, sizes and states.

  • code A single lineWrite the element with data-mtx and the library builds the rest.
  • dark_mode Light and darkSwitch the theme from the top bar to check both modes.
  • search Quick searchPress / to filter components in the side menu.
