Native Select

The browser's <select> with MUI styling: lightweight, accessible by default and with the native touch picker on mobile.

Basic usage Variants Sizes States Groups and multiple Select or NativeSelect? Grid Programmatic usage Manual BEM usage

Basic usage

Just the <select> with data-mtx="native-select" and data-label. As in MUI NativeSelect, the default variant is standard; the generated label is associated through for/id, so the select already has an accessible name. The list is drawn by the operating system.

<select data-mtx="native-select" data-label="Age" name="age">
  <option value="10">Ten</option>
  <option value="20">Twenty</option>
</select>

Groups and multiple selection

<optgroup> and <option disabled> work natively. With multiple and size the browser's list is shown with its variant's border or background and no chevron (use Ctrl/Cmd + click).

Select or NativeSelect?

The same data with both components. NativeSelect opens the system menu; Select draws its own menu with search and icons.

NativeSelect · system menu
Select · MUI menu with search

Grid

Address form in mtx-grid: one column on mobile and three on desktop.

Programmatic usage

The buttons call the real API; the console logs the native change and focus events of the <select>.


      
const ns = Materix.getInstance(document.getElementById('ns-api'));
ns.value = 'l';                    // does not emit change
ns.disabled ? ns.enable() : ns.disable();
ns.input.addEventListener('change', () => console.log(ns.value));

    


    

      
Manual BEM usage

      
Full structure with the label associated through for/id. If the markup includes an empty mtx-native-select__chevron, the JavaScript adds the icon to it; if it doesn't exist, it creates it.

      

        

          
          
          
        

      

      
<div class="mtx-native-select mtx-native-select--outlined" data-mtx="native-select">
  <label class="mtx-native-select__label" for="age">Age</label>
  <select class="mtx-native-select__input" id="age">
    <option value="10">Ten</option>
    <option value="20">Twenty</option>
  </select>
  <span class="mtx-native-select__chevron" aria-hidden="true"></span>
</div>
