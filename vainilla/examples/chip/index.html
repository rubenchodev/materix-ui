Chip

A compact element that represents a tag, a filter, an input or an action; it can have an icon, an avatar and a delete button.

Basic usage Variants Sizes With icons and avatar Colors States Deletable Filters Grid Programmatic usage Manual BEM usage

Basic usage

An empty element with data-mtx="chip" and data-label; the component generates the label, icon and delete button from the attributes.

<div data-mtx="chip" data-label="JavaScript" data-icon="code" data-color="primary"></div>
<div data-mtx="chip" data-label="Deletable" data-deletable></div>

Variants

filled (default) uses a solid background; outlined uses a border and a transparent background.

Deletable

The chip emits mtx:chip:delete but does not remove itself. Here the page listens for the event and removes the tag; it also works with Delete or Backspace on the focused chip.
