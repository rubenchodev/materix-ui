Toggle Button

Toggle buttons group related options with exclusive or multiple selection; on their own they work as an on/off switch for a single action.

Basic usage

A data-mtx="toggle-button-group" container with plain <button> elements: each button only needs data-value and, if it is icon-only, data-icon and aria-label. The group initializes the buttons, joins their borders and manages aria-pressed.

<div data-mtx="toggle-button-group" data-exclusive data-value="left" aria-label="Text alignment">
  <button data-value="left" data-icon="format_align_left" aria-label="Align left"></button>
  <button data-value="center" data-icon="format_align_center" aria-label="Center"></button>
  <button data-value="right" data-icon="format_align_right" aria-label="Align right"></button>
</div>

Exclusive and multiple

With data-exclusive only one button can be active (the value is a string or null). Without it, selection is multiple and the value is an array; data-value accepts a comma-separated list.

Exclusive · data-exclusive
Multiple (default)

Sizes

Three sizes with data-size on the group (or on each button). The icon always keeps its native 24px grid; only the padding changes (7, 11 and 15px, as in MUI).

Large · 56px (aligns with Text Field medium)
Medium · 48px (default, aligns with Button large)
Small · 40px (aligns with Button medium and Text Field small)

With and without icons

Buttons can have text only, icon and text (data-icon is inserted before the text) or icon only, which requires an aria-label.

States

Hover to see the hover background, use Tab to see the focus ring and click to see the ripple. A button with disabled (or data-disabled) is dimmed; data-disabled on the group disables all of them.

Normal, selected and disabled

Orientation and width

data-orientation="vertical" stacks the buttons (the up/down arrows move focus) and data-full-width spreads them across the available width.

Vertical
Full width · data-full-width

Enforce value set

With data-enforce-value-set the last active button cannot be deselected: the group always has a value (MUI enforce value set pattern).

Standalone button

A single data-mtx="toggle-button" toggles its own state and emits mtx:toggle-button:change. Use it for on/off actions such as marking a favorite; data-selected sets the initial state.

Use cases

Editor toolbar
Theme switcher (Materix.theme with [data-mtx-theme-toggle])

Grid

Inside mtx-grid, data-full-width makes each group fill its column; on mobile the columns stack.

Programmatic usage

The group instance exposes value (read and write, no events), buttons, disable() and enable(), and emits mtx:toggle-button-group:change with detail.value when the user changes the selection.

Manual BEM usage

      
The full structure writes the classes and the aria-pressed state; the library reuses the nodes and the existing icon.

      

        
        
      

      
<div class="mtx-toggle-button-group" data-mtx="toggle-button-group" data-exclusive role="group" aria-label="View">
  <button type="button" class="mtx-toggle-button" data-mtx="toggle-button" data-value="list" aria-pressed="true" aria-label="List">
    <span class="material-icons" aria-hidden="true">view_list</span>
  </button>
  <button type="button" class="mtx-toggle-button" data-mtx="toggle-button" data-value="grid" aria-pressed="false" aria-label="Grid">
    <span class="material-icons" aria-hidden="true">grid_view</span>
  </button>
</div>
