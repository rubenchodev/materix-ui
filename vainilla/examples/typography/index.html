Typography

Applies the MUI type scale (h1 to overline) to any element, separating HTML semantics from visual style.

Basic usage Type scale Semantics vs. style Colors Alignment Margins and truncation Responsive Use cases Grid Programmatic usage Manual BEM usage

Basic usage

Headings <h1>–<h6> with data-mtx="typography" pick up their variant automatically; on other tags set it with data-variant.

Monthly report

Sales grew 12% over the previous month, driven by the online channel.

<h3 data-mtx="typography" data-variant="h4" data-gutter-bottom>Monthly report</h3>
<p data-mtx="typography" data-variant="body1">Sales grew 12%...</p>

Type scale

The 13 MUI variants with their size, weight and line height. As in MUI, no variant has a margin (h1–h6 included): add one with data-gutter-bottom or data-paragraph. The headings in this demo use <p> with data-variant so the page hierarchy is not altered.

Margins and truncation

data-gutter-bottom adds a 0.35em bottom margin; data-paragraph (class mtx-typography--paragraph) adds 16px; data-no-wrap truncates to a single line with an ellipsis.

Responsive typography

Variant per breakpoint (mobile-first: sm 600, md 900, lg 1200, xl 1536px) with data-variant-{bp} or the mtx-typography--{bp}-{variant} class; and fluid h1–h6 scaling with data-responsive / mtx-typography--responsive (like MUI's responsiveFontSizes). Resize the window to see it.
