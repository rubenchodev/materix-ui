Materix traduce los textos que **genera ella misma**: botones y nombres de meses del DateTimePicker, el buscador y los contadores del Select, y las etiquetas de TablePagination. Tus textos (labels, helper text, contenido) los escribes tú en el idioma que quieras.

Incluye dos idiomas: `en` (inglés, el predeterminado) y `es` (español).

## Cómo se elige el idioma

Para cada componente, Materix usa el primer idioma **registrado** que encuentre en este orden:

1. `data-locale`, `data-lang` o `lang` en el propio elemento o en su ancestro más cercano que tenga alguno de esos atributos (el `lang` de `<html>` no cuenta en este paso; `data-locale`/`data-lang` en `<html>` sí).
2. El idioma global fijado explícitamente con `setLocale()`.
3. `lang` de `<html>`.
4. `en`.

Los códigos regionales se reducen a su idioma: `es-MX` y `es-ES` resuelven a `es`.

Mientras no llames a `setLocale()`, **`<html lang>` decide el idioma** de toda la página:

```html
<html lang="es">  <!-- calendario, Select y paginación en español -->
```

{{< callout type="info" title="setLocale() se impone a <html lang>, no a un lang local" >}}
En una página con `<html lang="es">`, `Materix.setLocale('en')` pasa los componentes a inglés. Un `lang`, `data-locale` o `data-lang` en el componente o en un ancestro por debajo de `<html>` sigue ganando, de modo que una `<section lang="es">` se mantiene en español. `resetLocale()` descarta el idioma explícito y vuelve a seguir `<html lang>`.
{{< /callout >}}

## Idioma por contenedor o por componente

`data-locale` en un contenedor o en el propio componente fuerza su idioma:

```html
<html lang="en">
  ...
  <!-- Este picker en español -->
  <input data-mtx="date-picker" data-locale="es">

  <!-- Todo lo de este bloque en español -->
  <section data-locale="es">
    <select data-mtx="select" data-label="Etiquetas" data-search multiple>
      <option>Diseño</option>
      <option>Desarrollo</option>
    </select>
  </section>
</html>
```

`data-lang` es equivalente a `data-locale`. Si el ancestro más cercano declara un idioma no registrado (por ejemplo `lang="fr"` sin haber añadido `fr`), Materix pasa directamente al idioma global explícito, luego a `<html lang>` y por último a `en`.

{{< callout type="info" >}}
En el DateTimePicker, usa en `data-locale` el código de dos letras (`es`, no `es-MX`). El picker lee ese atributo tal cual y un código regional en su propio elemento cae al inglés.
{{< /callout >}}

## Cambiar de idioma en caliente

`setLocale()` cambia el idioma global y emite `mtx:locale:change` en `document` (el alias deprecado `mtx:localechange` se sigue emitiendo hasta la 1.0). DateTimePicker, Select y TablePagination lo escuchan y vuelven a pintar sus textos:

```javascript
Materix.setLocale('es');   // true
Materix.getLocale();       // 'es'
Materix.setLocale('es-AR'); // true: se reduce a 'es'
Materix.setLocale('fr');   // false: no registrado, se mantiene el actual y avisa en consola
```

`setLocale()` prevalece sobre `<html lang>`, así que basta por sí solo. Aun así, mantener `<html lang>` sincronizado es buena práctica para lectores de pantalla y el navegador:

```javascript
/**
 * Cambia el idioma de la página y de los componentes.
 * @param {string} locale Código de idioma registrado ('en', 'es'...).
 */
function changeLanguage(locale) {
  document.documentElement.lang = locale;
  Materix.setLocale(locale); // emite mtx:locale:change y los componentes se actualizan
}
```

Escucha el mismo evento para actualizar tus propios textos:

```javascript
document.addEventListener('mtx:locale:change', (event) => {
  console.log('Nuevo idioma:', event.detail.locale);
});
```

## Sobrescribir un texto en un componente

Los atributos `data-*` tienen prioridad sobre cualquier diccionario. Úsalos para cambiar un texto concreto sin tocar el idioma:

```html
<input data-mtx="date-picker" data-ok-text="Confirmar" data-cancel-text="Volver" data-today-text="Hoy mismo">

<select data-mtx="select" data-label="Ciudades" multiple data-search data-actions-box
        data-none-results-text="Nada coincide con «{0}»"
        data-select-all-text="Marcar todas"
        data-deselect-all-text="Desmarcar todas">
  <option>Bogotá</option>
  <option>Madrid</option>
</select>
```

| Componente | Atributo | Texto que reemplaza |
|---|---|---|
| DateTimePicker | `data-ok-text` | Botón OK. |
| | `data-cancel-text` | Botón Cancelar. |
| | `data-today-text` | Botón Hoy. |
| Select | `data-none-results-text` (alias `data-no-results-text`) | Sin resultados de búsqueda. `{0}` es el texto buscado. |
| | `data-select-all-text` | Botón Seleccionar todo (`data-actions-box`). |
| | `data-deselect-all-text` (alias `data-clear-all-text`) | Botón Deseleccionar todo. |
| | `data-placeholder` | Texto sin selección (no tiene traducción por defecto). |
| TablePagination | `data-label-rows-per-page` | "Filas por página:". |
| | `data-label-all` | Opción "Todas". |
| | `data-label-of` | "de" en "1–10 de 100". |
| | `data-label-more-than` | "más de" cuando el total es desconocido. |
| | `data-label-first`, `data-label-previous`, `data-label-next`, `data-label-last` | `aria-label` de los botones de navegación. |

## Añadir un idioma

`addLocale(code, dictionary)` registra un idioma nuevo (o reemplaza uno completo). Las claves que falten se toman del inglés, así que puedes empezar por las que necesitas:

```javascript
Materix.addLocale('fr', {
  name: 'Français',
  dateTimePicker: {
    today: "Aujourd'hui",
    cancel: 'Annuler',
    ok: 'OK',
    months: ['Janvier', 'Février', 'Mars', 'Avril', 'Mai', 'Juin',
             'Juillet', 'Août', 'Septembre', 'Octobre', 'Novembre', 'Décembre'],
    weekdays: ['D', 'L', 'M', 'M', 'J', 'V', 'S'],
  },
  select: {
    searchPlaceholder: 'Rechercher…',
    noneResultsText: 'Aucun résultat pour « {0} »',
  },
  tablePagination: {
    rowsPerPage: 'Lignes par page :',
    of: 'sur',
  },
});

document.documentElement.lang = 'fr';
Materix.setLocale('fr');
```

Registra el idioma **antes** de que se inicialicen los componentes que lo usan, o llama a `setLocale()` después para que se actualicen.

## Modificar un idioma existente

`updateLocale(code, partial)` mezcla (deep merge) las claves que pases y conserva el resto. Si el idioma no existe, lo crea:

```javascript
Materix.updateLocale('es', {
  dateTimePicker: { ok: 'Listo' },
  select: { searchPlaceholder: 'Filtrar…' },
});
```

Los componentes ya pintados no se actualizan solos tras `updateLocale`: llama a `Materix.setLocale(Materix.getLocale())` para emitir `mtx:locale:change`.

## Referencia de API

| Función | Retorna | Descripción |
|---|---|---|
| `setLocale(code)` | `boolean` | Fija el idioma global (prevalece sobre `<html lang>`) y emite `mtx:locale:change`. `false` si no está registrado. |
| `resetLocale()` | `void` | Descarta el idioma fijado con `setLocale()` (vuelve a `<html lang>` y luego a `en`) y emite `mtx:locale:change`. Disponible como `Materix.i18n.resetLocale()`. |
| `getLocale()` | `string` | Idioma global efectivo: el fijado con `setLocale()`; si no, `<html lang>` (si está registrado); si no, `en`. `t()` y `getDictionary()` sin idioma usan este valor. |
| `addLocale(code, dictionary)` | `void` | Registra o reemplaza un idioma completo. |
| `updateLocale(code, partial)` | `void` | Mezcla claves en un idioma existente (o lo crea). |
| `t(component, key, params?, fallback?, locale?)` | `*` | Devuelve una traducción. `params` interpola `{0}` (array) o `{nombre}` (objeto). |
| `getComponentLocale(element)` | `string` | Idioma que usará un componente montado en `element`. |
| `i18n.getDictionary(code?)` | `object` | Diccionario completo (el de `getLocale()` si se omite). Solo accesible vía `Materix.i18n`. |

```javascript
Materix.t('select', 'noneResultsText', ['react']);           // 'No results found for "react"'
Materix.t('tablePagination', 'of', null, null, 'es');        // 'de'
Materix.getComponentLocale(document.querySelector('#date')); // 'es'
```

### Claves del diccionario

| Sección | Claves |
|---|---|
| `dateTimePicker` | `today`, `cancel`, `ok`, `date`, `time`, `dates`, `start`, `end`, `startTimeHeader`, `endTimeHeader`, `selectRange`, `selectEnd`, `enterTime`, `selectTime`, `hour`, `minute`, `switchToClock`, `switchToKeyboard`, `months` (12), `monthsShort` (12), `weekdays` (7, desde domingo), `weekdaysShort` (7, desde domingo) |
| `select` | `searchPlaceholder`, `searchAriaLabel`, `noneResultsText`, `selectAllText`, `deselectAllText`, `selectedCountSingular`, `selectedCountPlural` |
| `tablePagination` | `rowsPerPage`, `all`, `of`, `moreThan`, `firstPage`, `previousPage`, `nextPage`, `lastPage` |
| `dialog` | `cancel`, `ok` (definidas en el diccionario, pero Dialog no genera botones y no las usa) |
| `alert` | `close` (botón de cierre de Alert) |
| `chip` | `delete` (botón de eliminar de Chip) |
| `avatarGroup` | `surplus` (marcador `{count}`, etiqueta del indicador `+N`) |
| `speedDial` | `actions` (FAB principal generado) |
| `card` | `actions` (IconButton de la cabecera) |
| `theme` | `toggle`, `switchToDark`, `switchToLight`, `light`, `dark`, `system` (botones `[data-mtx-theme-toggle]`) |

Algunas etiquetas ARIA de otros componentes aún no pasan por i18n. Ver [Accesibilidad]({{< relref "/guide/accessibility" >}}#lo-que-te-toca-a-ti).
